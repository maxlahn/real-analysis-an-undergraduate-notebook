    Section 6.1 Riemann Sums and Integrals

    In this section, we construct the Riemann integral as a limit of Riemann sums. We prove several equivalent characterizations of integrability and explore some preliminary properties of integration.
    🔗

    Subsection 6.1.1 Finite Integration Methods

    Before we introduce the Riemann integral of a function, we must develop some preliminary results about Riemann sums. These sums are associated to a function and a tagged partition of a closed interval, which both decomposes the interval into a union of closed subintervals and specifies a point in each subinterval.
    🔗

    Definition 6.1.1. Partitions.

    Fix real numbers \(a , b \in \R \) so that \(a \leq b \text{.}\)
    • Partition.
      A partition \(P \) of the closed interval \(\clint{ a }{ b } \) is an increasing finite sequence \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) whose first entry is \(x_{ 0 } = a \) and whose last entry is \(x_{ n } = b \text{;}\) that is,
      \begin{equation*} a = x_{ 0 } \lt x_{ 1 } \lt x_{ 2 } \lt \dotsb \lt x_{ n - 1 } \lt x_{ n } = b\text{.} \end{equation*}
      The mesh \(\mesh \of{ P } \) of such a partition \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) is the maximal distance between any adjacent entries of \(P \text{;}\) that is,
      \begin{equation*} \mesh \of{ P } = \max_{ 0 \leq k \lt n }{ \abs{ x_{ k + 1 } - x_{ k } } } = \max_{ 0 \leq k \lt n }{ \of{ x_{ k + 1 } - x_{ k } } }\text{.} \end{equation*}
      🔗
      🔗
    • Tagged partition.
      A tagged partition of the closed interval \(\clint{ a }{ b } \) is an ordered pair \(\of{ P , t } \text{,}\) where \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) is a partition of \(\clint{ a }{ b } \) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \) is a finite sequence of points \(x_{ k } \leq t_{ k } \leq x_{ k + 1 } \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 6.1.2. Tagged partitions.

    The following are examples of tagged partitions:
    • Left and right tagged partitions.
      Let \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) be a partition of a closed interval \(\clint{ a }{ b } \text{.}\) The associated left tagged partition \(\of{ P , l } \) is defined by the formula \(l_{ k } = x_{ k } \) for all indices \(0 \leq k \lt n \text{.}\) Similarly, the associated right tagged partition \(\of{ P , r } \) is defined by the formula \(r_{ k } = x_{ k + 1 } \) for all indices \(0 \leq k \lt n \text{.}\)
      🔗
      For example, let \(n \geq 1 \) be a positive integer, and consider the partition \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) of the closed interval \(\clint{ 0 }{ 1 } \) defined by the formula \(x_{ k } = \frac{ k }{ n } \text{.}\) The associated left tagged partition is \(\of{ P , l } \text{,}\) where \(l = \of{ l_{ k } }_{ k = 0 }^{ n - 1 } \) is given by the formula
      \begin{equation*} l_{ k } = x_{ k } = \frac{ k }{ n }\text{,} \end{equation*}
      and the associated right tagged partition is \(\of{ P , r } \text{,}\) where \(r = \of{ r_{ k } }_{ k = 0 }^{ n - 1 } \) is given by the formula
      \begin{equation*} r_{ k } = x_{ k + 1 } = \frac{ k + 1 }{ n }\text{.} \end{equation*}
      We note that the mesh \(\mesh \of{ P } \) does not depend on the tagging, and is \(\mesh \of{ P } = \frac{ 1 }{ n } \) in this example.
      🔗
      🔗
    • Centrally tagged partitions.
      Let \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) be a partition of a closed interval \(\clint{ a }{ b } \text{.}\) The associated centrally tagged partition \(\of{ P , c } \) is defined by the formula
      \begin{equation*} c_{ k } = \frac{ x_{ k } + x_{ k + 1 } }{ 2 } \end{equation*}
      for all indices \(0 \leq k \lt n \text{.}\)
      🔗
      For example, let \(n \geq 1 \) be a positive integer, and consider the partition \(P = \of{ x_{ k } }_{ k = 0 }^{ 2^{ n } } \) of the closed interval \(\clint{ 0 }{ 1 } \) defined by the formula \(x_{ k } = k 2^{ -n } \text{.}\) The associated left tagged partition is \(\of{ P , c } \text{,}\) where \(c = \of{ c_{ k } }_{ k = 0 }^{ 2^{ n } - 1 } \) is given by the formula
      \begin{equation*} l_{ k } = \frac{ x_{ k } + x_{ k + 1 } }{ 2 } = \frac{ k 2^{ -n } + \of{ k + 1 } 2^{ -k } }{ 2 }\text{.} \end{equation*}
      We note that the mesh \(\mesh \of{ P } \) does not depend on the tagging, and is \(\mesh \of{ P } = 2^{ -n } \) in this example.
      🔗
      🔗
    🔗
    🔗
    We remark that it is not required for the subintervals determined by a partition to be of equal length, although on occasion such a requirement makes it easier to compute associated quantities. Moreover, it is not required that the tagging of each subinterval be done in a coherent way.
    🔗

    Definition 6.1.3. Comparison of partitions.

    Let \(P = \of{ x_{ j } }_{ j = 0 }^{ m } \) and \(Q = \of{ y_{ k } }_{ k = 0 }^{ n } \) be partitions of a closed interval \(\clint{ a }{ b } \text{.}\) If \(\set{ x_{ j } }_{ j = 0 }^{ m } \subseteq \set{ y_{ k } }_{ k = 0 }^{ n } \text{,}\) then we write \(P \preceq Q \) and say that \(P \) is coarser than \(Q \text{;}\) that \(Q \) is finer than \(P \text{;}\) \(Q \) is a refinement of \(P \text{;}\) and/or that \(P \) is a coarsening of \(Q \text{.}\)
    🔗
    Let \(\of{ P , s } \) and \(\of{ Q , t } \) be tagged partitions of the closed interval \(\clint{ a }{ b } \text{,}\) where \(P = \of{ x_{ j } }_{ j = 0 }^{ m } \text{,}\) \(Q = \of{ y_{ k } }_{ k = 0 }^{ n } \text{,}\) \(s = \of{ s_{ j } }_{ j = 0 }^{ m - 1 } \text{,}\) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{.}\) If both \(\set{ x_{ j } }_{ j = 0 }^{ m } \subseteq \set{ y_{ k } }_{ k = 0 }^{ n } \) and \(\set{ s_{ j } }_{ j = 0 }^{ m - 1 } \subseteq \set{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{,}\) then we write \(\of{ P , s } \preceq \of{ Q , t } \) and say that \(\of{ P , s } \) is coarser than \(\of{ Q , t } \text{;}\) that \(\of{ Q , t } \) is finer than \(\of{ P , s } \text{;}\) \(\of{ Q , t } \) is a refinement of \(\of{ P , s } \text{;}\) and/or that \(\of{ P , s } \) is a coarsening of \(\of{ Q , t } \text{.}\)
    🔗
    🔗
    Both partitions and tagged partitions are partially ordered by containment. In fact, the sets of partitions and tagged partitions of a closed interval form an upwards directed set, in that any pair of such (tagged) partitions has a common refinement.
    🔗

    Lemma 6.1.4. Partitions are directed.

    The sets of partitions and tagged partitions of a closed interval are directed upwards by the partial order \(\preceq \text{.}\)
    🔗
    🔗

    Proof.
    Let \(P = \of{ x_{ j } }_{ j = 0 }^{ m } \) and \(Q = \of{ y_{ k } }_{ k = 0 }^{ n } \) be partitions of a closed interval. Let \(R = \of{ z_{ l } }_{ l = 0 }^{ p } \) be an increasing sequence which enumerates
    \begin{equation*} \set{ z_{ l } }_{ l = 0 }^{ p } = \set{ x_{ j } }_{ j = 0 }^{ m } \cup \set{ y_{ k } }_{ k = 0 }^{ n }\text{.} \end{equation*}
    Since
    \begin{align*} \min_{ 0 \leq l \leq p }{ z_{ l } } \amp = \min \of{ \set{ \min_{ 0 \leq j \leq m }{ x_{ j } } , \min_{ 0 \leq k \leq n }{ y_{ k } } } }\\ \amp = \min \of{ \set{ a , a } } = a \end{align*}
    and
    \begin{align*} \max_{ 0 \leq l \leq p }{ z_{ l } } \amp = \max \of{ \set{ \max_{ 0 \leq j \leq m }{ x_{ j } } , \max_{ 0 \leq k \leq n }{ y_{ k } } } }\\ \amp = \max \of{ \set{ b , b } } = b\text{,} \end{align*}
    \(R \) is a partition of \(\clint{ a }{ b } \text{.}\) Moreover, \(R \) was constructed to be a common refinement of \(P \) and \(Q \text{.}\)
    🔗
    If \(P \) and \(Q \) were tagged, then we note that each subinterval determined by \(R \) is contained in a subinterval determined by \(P \) and a subinterval determined by \(Q \text{.}\) If each such subinterval contains at most one tag from either \(P \) or \(Q \text{,}\) we may choose arbitrary tags in other subintervals. Otherwise, we may subdivide further so that this process produces a tagging of \(R \) which is a refinement of those on \(P \) and \(Q \text{.}\)
    🔗
    🔗
    Associated to each real-valued function and tagged partition is a Riemann sum. This sum is meant to approximate the signed area enclosed by the graph of said function, and does so with varying success depending on the integrability of the function and the mesh of the partition.
    🔗

    Definition 6.1.5. Riemann sum.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\) The Riemann sum \(\mathcal{ R }_{ f } \of{ P , t } \) of \(f \) associated to a tagged partition \(\of{ P , t } \) of \(\clint{ a }{ b } \) is the real number
    \begin{equation*} \mathcal{ R }_{ f } \of{ P , t } = \sum_{ k = 0 }^{ n - 1 }{ f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } }\text{,} \end{equation*}
    where \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{.}\)
    🔗
    🔗

    Example 6.1.6. Riemann sums.

    The following are examples of Riemann sums:
    • Left and right Riemann sums.
      The left Riemann sum of a function \(f \) associated to a partition \(P \) of a closed interval \(\clint{ a }{ b } \) is the Riemann sum \(\mathcal{ R }_{ f } \of{ P , l } \) of \(f \) associated to the associated left tagged partition \(\of{ P , l } \) of \(\clint{ a }{ b } \text{.}\) Similarly, the right Riemann sum of \(f \) associated \(P \) is the Riemann sum \(\mathcal{ R }_{ f } \of{ P , r } \) of \(f \) associated to the associated right tagged partition \(\of{ P , r } \) of \(\clint{ a }{ b } \text{.}\)
      🔗
      For example, consider the function \(f \colon \clint{ 0 }{ 16 } \to \R \) defined by the formula \(f \of{ x } = \sqrt{ x } \) and the partition \(P = \of{ 0 , 1 , 4 , 9 , 16 } \) of the closed interval \(\clint{ 0 }{ 16 } \text{.}\) The left Riemann sum of \(f \) associated to \(P \) is
      \begin{align*} \mathcal{ R }_{ f } \of{ P , l } \amp = f \of{ 0 } \of{ 1 - 0 } + f \of{ 1 } \of{ 4 - 1 } + f \of{ 4 } \of{ 9 - 4 } + f \of{ 9 } \of{ 16 - 9 }\\ \amp = 0 \cdot 1 + 1 \cdot 3 + 2 \cdot 5 + 3 \cdot 7 = 0 + 3 + 10 + 21 = 34\text{,} \end{align*}
      while the right Riemann sum of \(f \) associated to \(P \) is
      \begin{align*} \mathcal{ R }_{ f } \of{ P , r } \amp = f \of{ 1 } \of{ 1 - 0 } + f \of{ 4 } \of{ 4 - 1 } + f \of{ 9 } \of{ 9 - 4 } + f \of{ 16 } \of{ 16 - 9 }\\ \amp = 1 \cdot 1 + 2 \cdot 3 + 3 \cdot 5 + 4 \cdot 7 = 1 + 6 + 15 + 28 = 50\text{.} \end{align*}
      🔗
      🔗
    • Central Riemann sums.
      The central Riemann sum of a function \(f \) associated to a partition \(P \) of a closed interval \(\clint{ a }{ b } \) is the Riemann sum \(\mathcal{ R }_{ f } \of{ P , c } \) of \(f \) associated to the associated central tagged partition \(\of{ P , c } \) of \(\clint{ a }{ b } \text{.}\)
      🔗
      For example, consider the function \(g \colon \clint{ 0 }{ 100 } \to \R \) defined by the formula \(g \of{ x } = 3 x - 25 \) and the partition \(P = \of{ 0 , 10 , 50 , 70 , 100 } \) of the closed interval \(\clint{ 0 }{ 16 } \text{.}\) The central Riemann sum of \(g \) associated to \(P \) is
      \begin{align*} \mathcal{ R }_{ g } \of{ P , c } \amp = g \of{ 5 } \of{ 10 - 0 } + g \of{ 30 } \of{ 50 - 10 } + g \of{ 60 } \of{ 70 - 50 } + g \of{ 85 } \of{ 100 - 70 }\\ \amp = \of{ -10 } \cdot 10 + 65 \cdot 40 + 155 \cdot 20 + 230 \cdot 30 = 12{,}500\text{.} \end{align*}
      🔗
      🔗
    🔗

    Related to the notion of Riemann sums are the Darboux sums. These sums are associated to an untagged partition. Rather than using the value of the function at a chosen point, the height of each term of a Darboux sum is determined by the supremum or infimum of the function over the given subinterval.
    🔗

    Definition 6.1.7. Darboux sum.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\)
    • Upper Darboux sum.
      The upper Darboux sum \(\mathcal{ U }_{ f } \of{ P } \) of \(f \) associated to a partition \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) of \(\clint{ a }{ b } \) is the extended real number
      \begin{equation*} \mathcal{ U }_{ f } \of{ P } = \sum_{ k = 0 }^{ n - 1 }{ \sup_{ x_{ k } \leq t \leq x_{ k + 1 } }{ f \of{ t } } \of{ x_{ k + 1 } - x_{ k } } } \end{equation*}
      🔗
      🔗
    • Lower Darboux sum.
      The upper Darboux sum \(\mathcal{ L }_{ f } \of{ P } \) of \(f \) associated to a partition \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) of \(\clint{ a }{ b } \) is the extended real number
      \begin{equation*} \mathcal{ L }_{ f } \of{ P } = \sum_{ k = 0 }^{ n - 1 }{ \inf_{ x_{ k } \leq t \leq x_{ k + 1 } }{ f \of{ t } } \of{ x_{ k + 1 } - x_{ k } } } \end{equation*}
      🔗
      🔗
    🔗
    🔗
    We note that if the integrand is continuous, then Darboux sums are Riemann sums. However, Darboux sums need not be Riemann sums in general. We will show that the Riemann integral is also a limit of Darboux sums. In order to prove such a result, we will require the following properties:
    🔗

    Proposition 6.1.8. Properties of Darboux sums.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\)
    1. Monotonicity.
      For any partitions \(P \) and \(Q \) of \(\clint{ a }{ b } \text{,}\) if \(P \preceq Q \text{,}\) then \(\mathcal{ U }_{ f } \of{ P } \geq \mathcal{ U }_{ f } \of{ Q } \) and \(\mathcal{ L }_{ f } \of{ P } \leq \mathcal{ L }_{ f } \of{ Q } \text{.}\)
      🔗
      🔗
    2. Bounds on Riemann sums.
      For any tagged partition \(\of{ P , t } \) of \(\clint{ a }{ b } \text{,}\)
      \begin{equation*} \mathcal{ L }_{ f } \of{ P } \leq \mathcal{ R }_{ f } \of{ P , t } \leq \mathcal{ U }_{ f } \of{ P }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. You will have an opportunity to prove this in the problems for this section.
      🔗
      🔗
    2. Let \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{.}\) We observe that
      \begin{align*} \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } \of{ x_{ k + 1 } - x_{ k } } \amp \leq f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } }\\ \amp \leq \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } \of{ x_{ k + 1 } - x_{ k } } \end{align*}
      for all indices \(0 \leq k \lt n \text{,}\) and so
      \begin{align*} \sum_{ k = 0 }^{ n - 1 }{ \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } \of{ x_{ k + 1 } - x_{ k } } } \amp \leq \sum_{ k = 0 }^{ n - 1 }{ f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp \leq \leq \sum_{ k = 0 }^{ n - 1 }{ \sup_{ x_{ k } x \leq x_{ k + 1 } }{ f \of{ x } } \of{ x_{ k + 1 } - x_{ k } } }\text{;} \end{align*}
      that is, \(\mathcal{ L }_{ f } \of{ P } \leq \mathcal{ R }_{ f } \of{ P , t } \leq \mathcal{ U }_{ f } \of{ P } \text{.}\)
      🔗
      🔗
    🔗
    While Riemann sums and Darboux sums may give decent approximations of area computations, we will need to involve limits in order to perform precise computations.

    Subsection 6.1.2 Riemann Integrability

    We now explore the Riemann integrability of various functions and introduce the Riemann integral. We will see several equivalent characterizations of this property, expressed as conditions on limits of certain nets of Riemann sums and Darboux sums.
    🔗

    Theorem 6.1.9. Riemann integrability.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a bounded real-valued function defined on a closed interval \(\clint{ a }{ b } \text{,}\) and let \(I \in \R \) be a real number. The following are equivalent:
    1. For any positive real number \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that
      \begin{equation*} \abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \lt \epsilon \end{equation*}
      for all tagged partitions \(\of{ P , t } \) of \(\clint{ a }{ b } \) of mesh \(\mesh \of{ P } \lt \delta \text{.}\)
      🔗
      🔗
    2. The net \(\mathcal{ R }_{ f } = \of{ \mathcal{ R }_{ f } \of{ P , t } }_{ \of{ P , t } } \) of real numbers which associates to each tagged partition \(\of{ P , t } \) of \(\clint{ a }{ b } \) the corresponding Riemann sum of \(f \) converges upwards to \(I \text{.}\)
      🔗
      🔗
    3. The nets \(\mathcal{ U }_{ f } = \of{ \mathcal{ U }_{ f } \of{ P } }_{ P } \) and \(\mathcal{ L }_{ f } = \of{ \mathcal{ L }_{ f } \of{ P } }_{ P } \) of real numbers which associate to each partition \(P \) of \(\clint{ a }{ b } \) the corresponding upper and lower Darboux sums of \(f \) converge upwards to \(I \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    Let \(B = \sup_{ a \leq x \leq b }{ \abs{ f \of{ x } } } \text{.}\) If \(B = 0 \text{,}\) then \(f \of{ x } = 0 \) for all \(a \leq x \leq b \text{,}\) and so each of the three above properties holds. Thus we may suppose for the remainder of the proof that \(B \gt 0 \text{.}\) First suppose that for any positive real number \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \lt \epsilon \end{equation*}
    for all tagged partitions \(\of{ P , t } \) of \(\clint{ a }{ b } \) of mesh \(\mesh \of{ P } \lt \delta \text{.}\) Let \(N \in \Nbhd_{ \R } \of{ I } \) be a neighborhood of \(I \) in \(\R \text{,}\) and note that \(\mB_{ \epsilon } \of{ I } \subseteq N \) for some positive real number \(\epsilon \gt 0 \text{.}\) Choose a tagged partition \(\of{ P_{ \epsilon } , t_{ \epsilon } } \) of mesh \(\mesh \of{ P_{ \epsilon } } \lt \delta \text{.}\) Then for all refinements \(\of{ P , t } \succeq \of{ P_{ \epsilon } , t_{ \epsilon } } \) of \(\of{ P_{ \epsilon } , t_{ \epsilon } } \text{,}\) \(\mesh \of{ P } \leq \mesh \of{ P_{ \epsilon } } \lt \delta \text{,}\) and so
    \begin{equation*} \abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \lt \epsilon\text{.} \end{equation*}
    We conclude that the net \(\mathcal{ R }_{ f } = \of{ \mathcal{ R }_{ f } \of{ P , t } }_{ \of{ P , t } } \) converges upwards to \(I \text{.}\)
    🔗
    Now suppose that the net \(\mathcal{ R }_{ f } = \of{ \mathcal{ R }_{ f } \of{ P , t } }_{ \of{ P , t } } \) converges upwards to \(I \text{.}\) Since the nets \(\mathcal{ U }_{ f } = \of{ \mathcal{ U }_{ f } \of{ P } }_{ P } \) and \(\mathcal{ L }_{ f } = \of{ \mathcal{ L }_{ f } \of{ P } }_{ P } \) are monotone and bounded by Proposition 6.1.8 Properties of Darboux sums, they converge to real numbers
    \begin{align*} U \amp = \lim_{ P \uparrow }{ \mathcal{ U }_{ f } \of{ P } } = \inf_{ P }{ \mathcal{ U }_{ f } \of{ P } }\\ L \amp = \lim_{ P \uparrow }{ \mathcal{ L }_{ f } \of{ P } } = \sup_{ P }{ \mathcal{ U }_{ f } \of{ P } } \end{align*}
    by a net analogue of the Monotone convergence theorem. So it suffices to show \(I = U = L \text{.}\) We first observe that for any partition \(P \) of \(\clint{ a }{ b } \) and positive real number \(\epsilon \gt 0 \text{,}\) there is some tagged partition \(\of{ Q , t } \) so that \(P \preceq Q \) and \(\abs{ \mathcal{ R }_{ f } \of{ Q , t } - I } \lt \epsilon \text{.}\) In particular,
    \begin{equation*} \mathcal{ L }_{ f } \of{ P } \leq \mathcal{ L }_{ f } \of{ Q } \leq \mathcal{ R }_{ f } \of{ Q , t } \lt I + \epsilon\text{,} \end{equation*}
    and
    \begin{equation*} \mathcal{ U }_{ f } \of{ P } \geq \mathcal{ U }_{ f } \of{ Q } \geq \mathcal{ R }_{ f } \of{ Q , t } \gt I - \epsilon\text{.} \end{equation*}
    Since this holds for all partitions \(P \) and all positive real numbers \(\epsilon \gt 0 \text{,}\)
    \begin{equation*} L = \sup_{ P }{ \mathcal{ L }_{ f } \of{ P } } \leq I \leq \inf_{ P }{ \mathcal{ U }_{ f } \of{ P } } = U\text{.} \end{equation*}
    It remains to show that \(U \leq I \leq L \text{.}\) We will show that \(U \leq I \text{;}\) the proof that \(I \leq L \) is similar.
    🔗
    To that end, let \(\epsilon \gt 0 \) be a positive real number. Then there is some tagged partition \(\of{ P_{ \epsilon } , t_{ \epsilon } } \) of \(\clint{ a }{ b } \) so that
    \begin{equation*} \abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \lt \frac{ \epsilon }{ 3 } \end{equation*}
    for all refinements \(\of{ P , t } \succeq \of{ P_{ \epsilon } , s_{ \epsilon } } \text{.}\) In particular, by further refining \(\of{ P_{ \epsilon } , s_{ \epsilon } } \) we may assume without loss of generality that it is left tagged. Let \(P_{ \epsilon } = \of{ x_{ k } }_{ k = 0 }^{ n } \text{.}\) We aim to define a further refinement of \(P_{ \epsilon } \text{.}\)
    🔗
    For each index \(0 \leq k \lt n \text{,}\) there is some point \(x_{ k } \leq u_{ k } \leq x_{ k + 1 } \) so that
    \begin{equation*} f \of{ u_{ k } } + \frac{ \epsilon }{ 3 \of{ b - a } } \gt \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } }\text{.} \end{equation*}
    If we may choose \(u_{ k } = x_{ k } \text{,}\) do so. Otherwise, we subdivide \(\clint{ x_{ k } }{ x_{ k + 1 } } \) into the union of two closed intervals, one of length
    \begin{equation*} L_{ k } \leq \frac{ \epsilon }{ 6 B n } \end{equation*}
    containing \(x_{ k } \) and the other of length \(x_{ k + 1 } - x_{ k } - L_{ k } \) containing \(u_{ k } \text{.}\) Tagging these intervals with \(x_{ k } \) and \(u_{ k } \text{,}\) respectively, we obtain a further refinement \(\of{ Q_{ \epsilon } , t_{ \epsilon } } \succeq \of{ P_{ \epsilon } , s_{ \epsilon } } \text{.}\) Moreover, we may replace the tagging \(s_{ \epsilon } \) with \(u = \of{ u_{ k } }_{ k = 0 }^{ n - 1 } \) to obtain a tagged partition \(\of{ P_{ \epsilon } , u } \text{.}\) We observe that
    \begin{align*} \mathcal{ R }_{ f } \of{ Q_{ \epsilon } , t_{ \epsilon } } - \mathcal{ R }_{ f } \of{ P_{ \epsilon } , u } \amp = \sum_{ k = 0 }^{ n - 1 }{ f \of{ x_{ k } } L_{ k } + f \of{ u_{ k } } \of{ x_{ k + 1 } - x_{ k } - L_{ k } } }\\ \amp \qquad - \sum_{ k = 0 }^{ n - 1 }{ f \of{ u_{ k } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp = \sum_{ k = 0 }^{ n - 1 }{ \of{ f \of{ x_{ k } } - f \of{ u_{ k } } } L_{ k } }\text{.} \end{align*}
    In particular,
    \begin{align*} \abs{ \mathcal{ R }_{ f } \of{ Q_{ \epsilon } , t_{ \epsilon } } - \mathcal{ R }_{ f } \of{ P_{ \epsilon } , u } } \amp = \abs{ \sum_{ k = 0 }^{ n - 1 }{ \of{ f \of{ x_{ k } } - f \of{ u_{ k } } } L_{ k } } }\\ \amp \leq \sum_{ k = 0 }^{ n - 1 }{ \abs{ f \of{ x_{ k } } - f \of{ u_{ k } } } L_{ k } }\\ \amp \leq \sum_{ k = 0 }^{ n - 1 }{ \of{ \abs{ f \of{ x_{ k } } } + \abs{ f \of{ u_{ k } } } } L_{ k } }\\ \amp \leq \sum_{ k = 0 }^{ n - 1 }{ \frac{ 2 B \epsilon }{ 6 B n } } = \frac{ \epsilon }{ 3 }\text{.} \end{align*}
    Similarly,
    \begin{align*} \mathcal{ R }_{ f } \of{ P_{ \epsilon } , u } \amp = \sum_{ k = 0 }^{ n - 1 }{ f \of{ u_{ k } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp \gt \sum_{ k = 0 }^{ n - 1 }{ \of{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } - \frac{ \epsilon }{ 3 \of{ b - a } } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp = \sum_{ k = 0 }^{ n - 1 }{ \of{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } \of{ x_{ k + 1 } - x_{ k } } - \of{ \frac{ \epsilon }{ 3 \of{ b - a } } } \of{ x_{ k + 1 } - x_{ k } } } }\\ \amp = \mathcal{ U }_{ f } \of{ P_{ \epsilon } } - \frac{ \epsilon }{ 3 } \end{align*}
    so that \(\abs{ \mathcal{ U }_{ f } \of{ P_{ \epsilon } } - \mathcal{ R }_{ f } \of{ P_{ \epsilon } , u } } \lt \frac{ \epsilon }{ 3 } \text{.}\) We conclude that
    \begin{align*} \abs{ \mathcal{ U }_{ f } \of{ P_{ \epsilon } } - I } \amp \leq \abs{ \mathcal{ U }_{ f } \of{ P_{ \epsilon } } - \mathcal{ R }_{ f } \of{ P_{ \epsilon } , u } } + \abs{ \mathcal{ R }_{ f } \of{ P_{ \epsilon } , u } - \mathcal{ R }_{ f } \of{ Q_{ \epsilon } , t_{ \epsilon } } }\\ \amp \qquad + \abs{ \mathcal{ R }_{ f } \of{ Q_{ \epsilon } , t_{ \epsilon } } - I }\\ \amp \lt \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } = \epsilon\text{.} \end{align*}
    In particular,
    \begin{equation*} U = \inf_{ P }{ \mathcal{ U }_{ f } \of{ P } } \leq \mathcal{ U }_{ f } \of{ \mathcal{ P }_{ \epsilon } } \lt I + \epsilon\text{;} \end{equation*}
    since \(\epsilon \) was an arbitrary positive real number, \(U \leq I \text{.}\)
    🔗
    Finally, now suppose that the nets \(\mathcal{ U }_{ f } = \of{ \mathcal{ U }_{ f } \of{ P } }_{ P } \) and \(\mathcal{ L }_{ f } = \of{ \mathcal{ L }_{ f } \of{ P } }_{ P } \) converge upwards to \(I \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Then there is a partition \(P_{ \epsilon } = \of{ y_{ k } }_{ k = 0 }^{ n } \) of \(\clint{ a }{ b } \) so that
    \begin{equation*} \max \of{ \set{ \abs{ \mathcal{ U }_{ f } \of{ P } - I } , \abs{ \mathcal{ L }_{ f } \of{ P } - I } } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
    for all refinements \(P \succeq P_{ \epsilon } \text{.}\) Without loss of generality, we may assume that \(n \geq 2 \text{.}\) Let
    \begin{equation*} \delta = \min \of{ \set{ y_{ k + 1 } - y_{ k } }_{ k = 0 }^{ n - 1 } \cup \set{ \frac{ \epsilon }{ 4 \of{ n - 1 } B } , 1 } }\text{.} \end{equation*}
    🔗
    Suppose that \(\of{ P , t } \) is a tagged partition of \(\clint{ a }{ b } \) of mesh \(\mesh \of{ P } \lt \delta \text{,}\) where \(P = \of{ x_{ j } }_{ j = 0 }^{ m } \) and \(t = \of{ t_{ j } }_{ j = 0 }^{ m - 1 } \text{.}\) For each index \(0 \leq j \lt m \text{,}\) the corresponding subinterval \(\clint{ x_{ j } }{ x_{ j + 1 } } \) either lies entirely inside a subinterval \(\clint{ y_{ k } }{ y_{ k + 1 } } \) determined by \(P_{ \epsilon } \) or lies in the union \(\clint{ y_{ k } }{ y_{ k + 2 } } = \clint{ y_{ k } }{ y_{ k + 1 } } \cup \clint{ y_{ k + 1 } }{ y_{ k + 2 } } \) of two adjacent such subintervals. In particular,
    \begin{equation*} x_{ j + 1 } - x_{ j } \leq \mesh \of{ P } \lt \delta \leq \min \of{ \set{ y_{ k + 1 } - y_{ k } }_{ k = 0 }^{ n - 1 } }\text{,} \end{equation*}
    so that \(\clint{ x_{ j } }{ x_{ j + 1 } } \) cannot span the union of three or more such intervals. Moreover, it cannot occur more than \(n - 1 \) times that a subinterval determined by \(P \) spans two adjacent subintervals determined by \(P_{ \epsilon } \text{.}\)
    🔗
    We observe that if \(\clint{ x_{ j } }{ x_{ j + 1 } } \subseteq \clint{ y_{ k } }{ y_{ k + 1 } } \) for some index \(0 \leq k \lt n \text{,}\) then
    \begin{equation*} \inf_{ y_{ k } \leq x \leq y_{ k + 1 } }{ f \of{ x } } \of{ x_{ j + 1 } - x_{ j } } \leq f \of{ t_{ j } } \of{ x_{ j + 1 } - x_{ j } } \leq \sup_{ y_{ k } \leq x \leq y_{ k + 1 } }{ f \of{ x } } \of{ x_{ j + 1 } - x_{ j } }\text{.} \end{equation*}
    On the other hand, if otherwise \(\clint{ x_{ j } }{ x_{ j + 1 } } \subseteq \clint{ y_{ k } }{ y_{ k + 2 } } \) for some index \(0 \leq k \lt n - 1 \text{,}\) then
    \begin{equation*} y_{ k } \lt x_{ j } \lt y_{ k + 1 } \lt x_{ j + 1 } \lt y_{ k + 2 }\text{.} \end{equation*}
    In this case, if \(x_{ j } \leq t_{ j } \leq y_{ k + 1 } \text{,}\) then
    \begin{equation*} \inf_{ y_{ k } \leq x \leq y_{ k + 1 } }{ f \of{ x } } \of{ y_{ k + 1 } - x_{ j } } \leq f \of{ t_{ j } } \of{ y_{ k + 1 } - x_{ j } } \leq \sup_{ y_{ k } \leq x \leq y_{ k + 1 } }{ f \of{ x } } \of{ y_{ k + 1 } - x_{ j } }\text{,} \end{equation*}
    and
    \begin{align*} \abs{ f \of{ t_{ j } } - \sup_{ y_{ k + 1 } \leq x \leq y_{ k + 2 } }{ f \of{ x } } } \of{ x_{ j + 1 } - y_{ k + 1 } } \amp \lt 2 B \delta \leq \frac{ \epsilon }{ 2 \of{ n - 1 } }\\ \abs{ f \of{ t_{ j } } - \inf_{ y_{ k + 1 } \leq x \leq y_{ k + 2 } }{ f \of{ x } } } \of{ x_{ j + 1 } - y_{ k + 1 } } \amp \lt 2 B \delta \leq \frac{ \epsilon }{ 2 \of{ n - 1 } }\text{.} \end{align*}
    Since this can occur a maximum of \(n - 1 \) times, we conclude that
    \begin{equation*} I - \epsilon \lt \mathcal{ L }_{ f } \of{ P_{ \epsilon } } - \frac{ \epsilon }{ 2 } \lt \mathcal{ R }_{ f } \of{ P , t } \lt \mathcal{ U }_{ f } \of{ P_{ \epsilon } } + \frac{ \epsilon }{ 2 } \lt I + \epsilon\text{,} \end{equation*}
    so that \(\abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \lt \epsilon \text{.}\)

    The limits of upper and lower Darboux sums are called the upper and lower Darboux integrals. The third condition in Theorem 6.1.9 Riemann integrability, that the upper and lower Darboux integrals agree, is sometimes called Darboux integrability. Theorem 6.1.9 Riemann integrability shows that Darboux integrability is equivalent to other characterizations of what we call Riemann integrability.

    Definition 6.1.10. Riemann integrability/integral.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\) \(f \) is Riemann integrable if there is a real number \(I \in \R \) satisfying any (and therefore all) of the equivalent conditions in Theorem 6.1.9 Riemann integrability. In this case, that \(\R \) is Hausdorff implies that \(I \) is uniquely defined by these properties. We call this number
    \begin{equation*} I = \lim_{ \of{ P , t } \uparrow }{ \mathcal{ R }_{ f } \of{ P , t } } = \lim_{ P \uparrow }{ \mathcal{ U }_{ f } \of{ P , t } } = \lim_{ P \uparrow }{ \mathcal{ L }_{ f } \of{ P , t } } = \inf_{ P }{ \mathcal{ U }_{ f } \of{ P } } = \sup_{ P }{ \mathcal{ L }_{ f } \of{ P } } \end{equation*}
    the (definite) Riemann integral of \(f \) from \(a \) to \(b \text{,}\) and we denote it by
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}

    🔗

    Example 6.1.11. Riemann integrability.

    The following are examples and non-examples of Riemann integrable functions and their Riemann integrals:
    • Let \(c \in \R \) be a real number, and consider the constant function \(f \colon \clint{ a }{ b } \to \R \) defined by the formula \(f \of{ x } = c \text{.}\) We observe that
      \begin{align*} \mathcal{ R }_{ f } \of{ P , t } \amp = \sum_{ k = 0 }^{ n - 1 }{ f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } } = \sum_{ k = 0 }^{ n - 1 }{ c \of{ x_{ k + 1 } - x_{ k } } }\\ \amp = c \sum_{ k = 0 }^{ n - 1 }{ \of{ x_{ k + 1 } - x_{ k } } } = c \of{ b - a } \end{align*}
      for all tagged partitions \(\of{ P , t } \) of \(\clint{ a }{ b } \text{,}\) where \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{.}\) This implies that
      \begin{equation*} \lim_{ \of{ P , t } \uparrow }{ \mathcal{ R }_{ f } \of{ P , t } } = \lim_{ \of{ P , t } \uparrow }{ c \of{ b - a } } = c \of{ b - a }\text{;} \end{equation*}
      that is, \(f \) is Riemann integrable, with Riemann integral
      \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \int_{ a }^{ b }{ c \, \diff{ x } } = c \of{ b - a }\text{.} \end{equation*}
      🔗
      🔗
    • Let \(g \colon \clint{ 0 }{ 2 } \to \R \) be the real-valued function defined piecewise on the closed interval \(\clint{ 0 }{ 2 } \) by the formula
      \begin{equation*} g \of{ y } = \begin{cases} 1 \amp 0 \leq y \leq 1 \\ 2 \amp 1 \lt y \leq 2 \text{.}\end{cases} \end{equation*}
      Let \(P = \of{ y_{ k } }_{ k = 0 }^{ n } \) be a partition of \(\clint{ 0 }{ 2 } \text{.}\) Then there is a unique index \(0 \leq j \lt n \) so that \(y_{ j } \leq 1 \lt y_{ j + 1 } \text{.}\) We observe that the restriction of \(g \) to every other subinterval of the partition is constant, so that
      \begin{align*} \mathcal{ U }_{ g } \of{ P } - \mathcal{ L }_{ g } \of{ P } \amp = \sum_{ k = 0 }^{ n - 1 }{ \sup_{ y_{ k } \leq y \leq y_{ k + 1 } }{ g \of{ y } } \of{ y_{ k + 1 } - y_{ k } } } - \sum_{ k = 0 }^{ n - 1 }{ \inf_{ y_{ k } \leq y \leq y_{ k + 1 } }{ g \of{ y } } \of{ y_{ k + 1 } - y_{ k } } }\\ \amp = \sum_{ k = 0 }^{ n - 1 }{ \of{ \sup_{ y_{ k } \leq y \leq y_{ k + 1 } }{ g \of{ y } } - \inf_{ y_{ k } \leq y \leq y_{ k + 1 } }{ g \of{ y } } } \of{ y_{ k + 1 } - y_{ k } } }\\ \amp = \of{ \sup_{ y_{ j } \leq y \leq y_{ j + 1 } }{ g \of{ y } } - \inf_{ y_{ j } \leq y \leq y_{ j + 1 } }{ g \of{ y } } } \of{ y_{ j + 1 } - y_{ j } }\\ \amp = 1 \of{ y_{ j + 1 } - y_{ j } } \leq \mesh \of{ P }\text{.} \end{align*}
      This implies that \(g \) is Riemann integrable, although this method does not necessarily directly compute the Riemann integral \(\int_{ 0 }^{ 2 }{ g \of{ y } \, \diff{ y } } \text{.}\)
      🔗
      🔗
    • More generally, let \(h \colon \clint{ a }{ b } \to \R \) be a non-decreasing real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\) We observe that
      \begin{align*} \mathcal{ U }_{ g } \of{ P } - \mathcal{ L }_{ g } \of{ P } \amp = \sum_{ k = 0 }^{ n - 1 }{ \sup_{ z_{ k } \leq z \leq z_{ k + 1 } }{ h \of{ z } } \of{ z_{ k + 1 } - z_{ k } } } - \sum_{ k = 0 }^{ n - 1 }{ \inf_{ z_{ k } \leq z \leq z_{ k + 1 } }{ h \of{ z } } \of{ z_{ k + 1 } - z_{ k } } }\\ \amp = \sum_{ k = 0 }^{ n - 1 }{ h \of{ z_{ k + 1 } } \of{ z_{ k + 1 } - z_{ k } } } - \sum_{ k = 0 }^{ n - 1 }{ h \of{ z_{ k } } \of{ z_{ k + 1 } - z_{ k } } }\\ \amp = \sum_{ k = 0 }^{ n - 1 }{ \of{ h \of{ z_{ k + 1 } } - h \of{ z_{ k } } } \of{ z_{ k + 1 } - z_{ k } } } \leq \sum_{ k = 0 }^{ n - 1 }{ \of{ h \of{ z_{ k + 1 } } - h \of{ z_{ k } } } \mesh \of{ P } }\\ \amp = \of{ h \of{ b } - h \of{ a } } \mesh \of{ P } \end{align*}
      for any partition \(P = \of{ z_{ k } }_{ k = 0 }^{ n } \) of \(\clint{ a }{ b } \text{.}\) This implies that \(h \) is Riemann integrable, but the above computation doesn’t necessarily aid in the computation of the Riemann integral \(\int_{ a }^{ b }{ h \of{ z } \, \diff{ z } } \text{.}\)
      🔗
      🔗
    • Let \(\chi \colon \clint{ 0 }{ 1 } \to \R \) be the real-valued function defined piecewise by the formula
      \begin{equation*} \chi \of{ x } = \begin{cases} 1 \amp x \in \Q \\ 0 \amp x \notin \Q \text{.}\end{cases} \end{equation*}
      Since any closed interval contains both rational and irrational numbers,
      \begin{align*} \mathcal{ U }_{ \chi } \of{ P } \amp = \sum_{ k = 0 }^{ n - 1 }{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ \chi \of{ x } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp = \sum_{ k = 0 }^{ n - 1 }{ 1 \of{ x_{ k + 1 } - x_{ k } } } = 1 - 0 = 1 \end{align*}
      and
      \begin{align*} \mathcal{ L }_{ \chi } \of{ P } \amp = \sum_{ k = 0 }^{ n - 1 }{ \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ \chi \of{ x } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp = \sum_{ k = 0 }^{ n - 1 }{ 0 \of{ x_{ k + 1 } - x_{ k } } } = 0 \end{align*}
      for any partition \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) of \(\clint{ 0 }{ 1 } \text{.}\) We conclude that \(\chi \) is not Riemann integrable.
      🔗
      🔗

    🔗
    In general, it can be quite difficult to compute Riemann integrals without additional tools. We will see some such tools in Section 6.2 The Fundamental Theorems of Calculus, but even without differential calculus, we may still expand our inventory of Riemann integrable functions significantly. For example, any continuous function defined on a closed interval is Riemann integrable.
    🔗

    Proposition 6.1.12. Continuity implies integrability.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\) If \(f \) is continuous, then it is Riemann integrable.
    🔗
    🔗

    Proof.
    Let
    \begin{align*} U \amp = \lim_{ P \uparrow }{ \mathcal{ U }_{ f } \of{ P } } \amp L \amp = \lim_{ P \uparrow }{ \mathcal{ L }_{ f } \of{ P } }\text{.} \end{align*}
    We will show that \(U \leq L \text{.}\) To that end, the Heine-Cantor theorem implies that \(f \) is uniformly continuous on \(\clint{ a }{ b } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Then there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \abs{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } \lt \frac{ \epsilon }{ b - a } \end{equation*}
    for all points \(x_{ 1 } , x_{ 2 } \in \clint{ a }{ b } \) so that \(\abs{ x_{ 1 } - x_{ 2 } } \lt \delta \text{.}\) We observe that
    \begin{align*} \abs{ \mathcal{ U }_{ f } \of{ P } - \mathcal{ L }_{ f } \of{ P } } \amp = \abs{ \sum_{ k = 0 }^{ n - 1 }{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } \of{ x_{ k + 1 } - x_{ k } } } - \sum_{ k = 0 }^{ n - 1 }{ \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } \of{ x_{ k + 1 } - x_{ k } } } }\\ \amp = \abs{ \sum_{ k = 0 }^{ n - 1 }{ \of{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } - \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } } \of{ x_{ k + 1 } - x_{ k } } } }\\ \amp \leq \sum_{ k = 0 }^{ n - 1 }{ \abs{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } - \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp \leq \sum_{ k = 0 }^{ n - 1 }{ \of{ \frac{ \epsilon }{ b - a } } \of{ x_{ k + 1 } - x_{ k } } } = \of{ \frac{ \epsilon }{ b - a } } \of{ b - a } = \epsilon \end{align*}
    for any partition \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) of \(\clint{ a }{ b } \) of mesh \(\mesh \of{ P } \lt \delta \text{.}\) In particular, \(\abs{ U - L } \leq \epsilon \) for all positive real numbers \(\epsilon \gt 0 \text{,}\) and so \(U = L \text{.}\) Theorem 6.1.9 Riemann integrability implies that \(f \) is Riemann integrable.
    🔗
    🔗
    We end this section with a few results about the interplay between Riemann integrals and arithmetic, comparison, and limits. First, the set of Riemann integrable functions is a vector space, and the Riemann integral is a linear functional on this vector space.
    🔗

    Proposition 6.1.13. Linearity of Riemann integration.

    Let
    \begin{equation*} f = \sum_{ j = 1 }^{ m }{ a_{ j } f_{ j } } \end{equation*}
    be a real linear combination of real-valued functions \(f_{ j } \colon \clint{ a }{ b } \to \R \) defined on a closed interval \(\clint{ a }{ b } \text{.}\) If each \(f_{ j } \) is Riemann integrable, then so too is \(f \text{,}\) and
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \sum_{ j = 1 }^{ m }{ a_{ j } \int_{ a }^{ b }{ f_{ j } \of{ x } \, \diff{ x } } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    We observe that for each tagged partition \(\of{ P , t } \) of \(\clint{ a }{ b } \text{,}\)
    \begin{align*} \mathcal{ R }_{ f } \of{ P , t } \amp = \sum_{ k = 0 }^{ n - 1 }{ f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } } = \sum_{ k = 0 }^{ n - 1 }{ \of{ \sum_{ j = 1 }^{ m }{ a_{ j } f_{ j } \of{ t_{ k } } } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp = \sum_{ k = 0 }^{ n - 1 }{ \sum_{ j = 1 }^{ m }{ a_{ j } f_{ j } \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } } } = \sum_{ j = 1 }^{ m }{ a_{ j } \sum_{ k = 0 }^{ n - 1 }{ f_{ j } \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } } }\\ \amp = \sum_{ j = 1 }^{ m }{ a_{ j } \mathcal{ R }_{ f_{ j } } \of{ P , t } }\text{,} \end{align*}
    where \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{.}\) Thus
    \begin{align*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } \amp = \lim_{ \of{ P , t } \uparrow }{ \mathcal{ R }_{ f } \of{ P , t } } = \lim_{ \of{ P , t } \uparrow }{ \sum_{ j = 1 }^{ m }{ a_{ j } \mathcal{ R }_{ f_{ j } } \of{ P , t } } }\\ \amp = \sum_{ j = 1 }^{ m }{ a_{ j } \lim_{ \of{ P , t } \uparrow }{ \mathcal{ R }_{ f_{ j } } \of{ P , t } } } = \sum_{ j = 1 }^{ m }{ a_{ j } \int_{ a }^{ b }{ f_{ j } \of{ x } \, \diff{ x } } }\text{.} \end{align*}
    🔗
    🔗
    We emphasize that while it is true that the product of Riemann integrable functions is also Riemann integrable, it is not in general true that the Riemann integral of such a product is the product of the Riemann integrals of the factors; that is,
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } g \of{ x } \, \diff{ x } } \neq \of{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } \of{ \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } } }\text{.} \end{equation*}
    You will have an opportunity to explore this further in the problems for this section. First, however, we note that definite integrals preserve comparison of functions.
    🔗

    Lemma 6.1.14. Riemann integration and comparison.

    Let \(f , g \colon \clint{ a }{ b } \to \R \) be real-valued functions defined on a closed interval \(\clint{ a }{ b } \text{.}\) If \(f \) and \(g \) are Riemann integrable and \(f \of{ x } \leq g \of{ x } \) for all points \(a \leq x \leq b \text{,}\) then
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } \leq \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    We observe that for all tagged partitions \(\of{ P , t } \) of \(\clint{ a }{ b } \text{,}\)
    \begin{align*} \mathcal{ R }_{ f } \of{ P , t } \amp = \sum_{ k = 0 }^{ n - 1 }{ f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp \leq \sum_{ k = 0 }^{ n - 1 }{ g \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } } = \mathcal{ R }_{ g } \of{ P , t }\text{,} \end{align*}
    where \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{.}\) Thus
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \lim_{ \of{ P , t } \uparrow }{ \mathcal{ R }_{ f } \of{ P , t } } \leq \lim_{ \of{ P , t } \uparrow }{ \mathcal{ R }_{ g } \of{ P , t } } = \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗
    While the behavior of Riemann integrals under limits can unfortunately be quite subtle, we can establish some preliminary properties. The following theorem establishes the continuity of the Riemann integral on the vector space of Riemann integrable functions on a closed interval, taken with the compact open topology:
    🔗

    Theorem 6.1.15. Uniform convergence and Riemann integrability.

    Let \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) be a uniformly convergent sequence of real-valued functions \(f_{ n } \colon \clint{ a }{ b } \to \R \) defined on a closed interval \(\clint{ a }{ b } \text{.}\) If each \(f_{ n } \) is Riemann integrable, then the uniform limit \(\uniflim_{ n \to \infty }{ f_{ n } } \) is Riemann integrable, with Riemann integral
    \begin{equation*} \int_{ a }^{ b }{ \uniflim_{ n \to \infty }{ f_{ n } } \of{ x } \, \diff{ x } } = \lim_{ n \to \infty }{ \int_{ a }^{ b }{ f_{ n } \of{ x } \, \diff{ x } } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    We first argue that the sequence \(\of{ I_{ n } }_{ n = 0 }^{ \infty } \) of Riemann integrals
    \begin{equation*} I_{ n } = \int_{ a }^{ b }{ f_{ n } \of{ x } \, \diff{ x } } \end{equation*}
    is Cauchy. To that end, let \(f = \uniflim_{ n \to \infty }{ f_{ n } } \text{.}\) Since \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to \(f \text{,}\) there is some natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} \abs{ f_{ n } \of{ x } - f \of{ x } } \lt \frac{ \epsilon }{ 6 \of{ b - a } } \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \) and points \(a \leq x \leq b \text{.}\) In particular,
    \begin{align*} \abs{ f_{ m } \of{ x } - f_{ n } \of{ x } } \amp \leq \abs{ f_{ m } \of{ x } - f \of{ x } } + \abs{ f_{ n } \of{ x } - f \of{ x } }\\ \amp \lt \frac{ \epsilon }{ 6 \of{ b - a } } + \frac{ \epsilon }{ 6 \of{ b - a } } = \frac{ \epsilon }{ 3 \of{ b - a } } \end{align*}
    for all indices \(m , n \geq n_{ \epsilon } \) and points \(a \leq x \leq b \text{,}\) and so
    \begin{align*} \abs{ \mathcal{ R }_{ f_{ m } } \of{ P , t } - \mathcal{ R }_{ f_{ n } } \of{ P , t } } \amp = \abs{ \sum_{ i = 0 }^{ l - 1 }{ f_{ m } \of{ t_{ i } } \of{ x_{ i + 1 } - x_{ i } } } - \sum_{ i = 0 }^{ l - 1 }{ f_{ n } \of{ t_{ i } } \of{ x_{ i + 1 } - x_{ i } } } }\\ \amp \leq \sum_{ i = 0 }^{ l - 1 }{ \abs{ f_{ m } \of{ t_{ i } } - f_{ n } \of{ t_{ i } } } \of{ x_{ i + 1 } - x_{ i } } }\\ \amp \lt \sum_{ i = 0 }^{ l - 1 }{ \of{ \frac{ \epsilon }{ 3 \of{ b - a } } } \of{ x_{ i + 1 } - x_{ i } } }\\ \amp = \of{ \frac{ \epsilon }{ 3 \of{ b - a } } } \of{ b - a } = \frac{ \epsilon }{ 3 } \end{align*}
    for all indices \(m , n \geq n_{ \epsilon } \) and tagged partitions \(\of{ P , t } \) of \(\clint{ a }{ b } \text{,}\) where \(P = \of{ x_{ i } }_{ i = 0 }^{ l } \) and \(t = \of{ t_{ i } }_{ i = 0 }^{ l - 1 } \text{.}\)
    🔗
    Let \(\of{ P , t } \) be a tagged partition of \(\clint{ a }{ b } \) so that
    \begin{align*} \abs{ \mathcal{ R }_{ f_{ m } } \of{ P , t } - I_{ m } } \amp \lt \frac{ \epsilon }{ 3 }\\ \abs{ \mathcal{ R }_{ f_{ n } } \of{ P , t } - I_{ n } } \amp \lt \frac{ \epsilon }{ 3 }\text{.} \end{align*}
    Thus
    \begin{align*} \abs{ I_{ m } - I_{ n } } \amp \leq \abs{ I_{ m } - \mathcal{ R }_{ f_{ m } } \of{ P , t } } + \abs{ \mathcal{ R }_{ f_{ m } } \of{ P , t } - \mathcal{ R }_{ f_{ n } } \of{ P , t } } + \abs{ \mathcal{ R }_{ f_{ n } } \of{ P , t } - I_{ n } }\\ \amp \lt \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } = \epsilon\text{.} \end{align*}
    We conclude that \(\of{ I_{ n } }_{ n = 0 }^{ \infty } \) is Cauchy.
    🔗
    Corollary 3.6.15 Completeness of the real line implies that this sequence converges to a real number \(I \in \R \text{.}\) We will show that
    \begin{equation*} \lim_{ \of{ P , t } \uparrow }{ \mathcal{ R }_{ f } \of{ P , t } } = I\text{.} \end{equation*}
    To that end, let \(\epsilon \gt 0 \) be a positive real number. Since \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to \(f \text{,}\) there is some natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} \abs{ f_{ n } \of{ x } - f \of{ x } } \lt \frac{ \epsilon }{ 3 \of{ b - a } } \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \) and points \(a \leq x \leq b \text{.}\) In particular,
    \begin{align*} \abs{ \mathcal{ R }_{ f } \of{ P , t } - \mathcal{ R }_{ f_{ n } } \of{ P , t } } \amp = \abs{ \sum_{ i = 0 }^{ l - 1 }{ f \of{ t_{ i } } \of{ x_{ i + 1 } - x_{ i } } } - \sum_{ i = 0 }^{ l - 1 }{ f_{ n } \of{ t_{ i } } \of{ x_{ i + 1 } - x_{ i } } } }\\ \amp \leq \sum_{ i = 0 }^{ l - 1 }{ \abs{ f_{ n } \of{ t_{ i } } - f \of{ t_{ i } } } \of{ x_{ i + 1 } - x_{ i } } }\\ \amp \lt \sum_{ i = 0 }^{ l - 1 }{ \of{ \frac{ \epsilon }{ 3 \of{ b - a } } } \of{ x_{ i + 1 } - x_{ i } } }\\ \amp = \of{ \frac{ \epsilon }{ 3 \of{ b - a } } } \of{ b - a } = \frac{ \epsilon }{ 3 } \end{align*}
    for all indices \(n \geq n_{ \epsilon } \) and tagged partitions \(\of{ P , t } \) of \(\clint{ a }{ b } \text{.}\) Since \(\of{ I_{ n } }_{ n = 0 }^{ \infty } \) converges to \(I \text{,}\) there is a natural number \(m_{ \epsilon } \in \N \) so that
    \begin{equation*} \abs{ I_{ n } - I } \lt \frac{ \epsilon }{ 3 } \end{equation*}
    for all indices \(n \geq m_{ \epsilon } \text{.}\) Fix \(n \geq \max \of{ \set{ m_{ \epsilon } , n_{ \epsilon } } } \text{.}\) Then there is some tagged partition \(\of{ P_{ \epsilon } , t_{ \epsilon } } \) of \(\clint{ a }{ b } \) so that
    \begin{equation*} \abs{ \mathcal{ R }_{ f_{ n } } \of{ P , t } - I_{ n } } \lt \frac{ \epsilon }{ 3 } \end{equation*}
    for all refinements \(\of{ P , t } \succeq \of{ P_{ \epsilon } , t_{ \epsilon } } \text{.}\) We observe that
    \begin{align*} \abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \amp \leq \abs{ \mathcal{ R }_{ f } \of{ P , t } - \mathcal{ R }_{ f_{ n } } \of{ P , t } } + \abs{ \mathcal{ R }_{ f_{ n } } \of{ P , t } - I_{ n } } + \abs{ I_{ n } - I }\\ \amp \lt \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } = \epsilon \end{align*}
    for all refinements \(\of{ P , t } \succeq \of{ P_{ \epsilon } , t_{ \epsilon } } \text{.}\) Thus the net \(\of{ \mathcal{ R }_{ f } \of{ P , t } }_{ \of{ P , t } } \) converges to \(I \text{,}\) and so \(f \) is Riemann integrable, with Riemann integral
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = I = \lim_{ n \to \infty }{ I_{ n } } = \lim_{ n \to \infty }{ \int_{ a }^{ b }{ f_{ n } \of{ x } \, \diff{ x } } }\text{.} \end{equation*}
