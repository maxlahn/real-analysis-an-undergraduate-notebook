    Section 3.2 Convergence and Limits

    In this section, we introduce the most fundamental notion of all of mathematical analysis: that of convergence. Convergence is a formalization of limiting behavior and closeness in metric spaces and, as we will see in the next chapter, other related analytical settings. In this section we will be concerned with convergence in the setting of abstract metric spaces, which can be interpreted as a rigorous formalization of the informal phrase “eventually close.” In the following section, we will gain a more detailed understanding of limiting behavior in less general example of the Euclidean spaces. Note also that in this chapter, we will be concerned only with the convergence of sequences in metric spaces and maps between metric spaces, but in the next chapter, we will make generalizations which in some ways subsume the discussion in this section.
    🔗

    Subsection 3.2.1 Sequential Convergence

    First, we will investigate the limiting behavior of a sequence in a metric space. Informally, a sequence in a metric space converges to a point if the values of the sequence eventually grows arbitrarily close to that point; that is, a sequence converges to a point if the values of the sequence are close to that point for large indices. Such a sequence is called convergent, and the point to which it converges (which we will see to be uniquely determined by this property) is called its limit.
    🔗

    Definition 3.2.1. Sequential convergence/divergence.

    A sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \) converges to a point \(x \in X \) if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} \rho \of{ x_{ n } , x } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\)
    🔗
    A sequence of points in a metric space is called convergent if it converges to a point and divergent if it does not converge to any point.
    🔗
    🔗
    So a sequence converges to a point in a metric space if the values of the sequence can be made arbitrarily close to that point solely by choosing large enough indices, and the sequence diverges if this cannot be done.
    🔗

    Example 3.2.2. Sequential convergence/divergence.

    Consider the sequence \(\of{ x_{ n } }_{ n = 1 }^{ \infty } \) of real numbers defined by the formula
    \begin{equation*} x_{ n } = \frac{ 1 }{ n }\text{.} \end{equation*}
    We will show that \(\of{ x_{ n } }_{ n = 1 }^{ \infty } \) converges to \(0 \) in the Euclidean metric \(d \) on \(\R \text{.}\)
    🔗
    Indeed, let \(\epsilon \gt 0 \) be a positive real number. By the Archimedean principle, there is a natural number \(n_{ \epsilon } \in \N \) so that \(\epsilon \cdot n_{ \epsilon } \gt 1 \text{.}\) For all indices \(n \geq n_{ \epsilon } \text{,}\) we observe that
    \begin{equation*} d \of{ x_{ n } , 0 } = \abs{ \frac{ 1 }{ n } - 0 } = \frac{ 1 }{ \abs{ n } } = \frac{ 1 }{ n } \leq \frac{ 1 }{ n_{ \epsilon } } \lt \epsilon\text{.} \end{equation*}
    🔗
    In summary, we have shown that for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is an index \(n_{ \epsilon } \in \N \) so that \(d \of{ x_{ n } , 0 } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) Thus \(\of{ x_{ n } }_{ n = 1 }^{ \infty } \) converges to \(0 \text{.}\)
    🔗
    Note that, in this example, the data of the sequence, the limiting value, the ground set, and the metric are necessary for convergence. By altering any one of these, we may invalidate the convergence we just proved. For example, if we consider \(\of{ x_{ n } }_{ n = 1 }^{ \infty } \) as a sequence in the metric subspace \(\opint{ 0 }{ \infty } \) of the real line \(\R \) consisting of only positive real numbers, then the sequence diverges, since it does not converge in the Euclidean metric to a positive real number.
    🔗
    Similarly, if we change the metric, then the sequence \(\of{ x_{ n } }_{ n = 1 }^{ \infty } \) may not converge. We have just proven that this sequence is convergent in the Euclidean metric \(d \) by finding a point \(0 \in \R \) to which it converges, but it is divergent in the discrete metric \(\delta_{ \R } \text{.}\) All this is to say that all of the data of a sequence, a metric space, and a purported limiting value are all necessary for claims of convergence or divergence.
    🔗
    🔗
    Ideally, we would like “the limit” of a convergent sequence in a metric space, which is “the point” to which that sequence converges, to be unique with this property. That is, if a sequence in a metric space converges to a point, then we would like this point to be the only such point to which it converges, which a priori need not be the case. Thankfully, the limits of convergent sequences in metric spaces are indeed unique.
    🔗

    Proposition 3.2.3. Uniqueness of sequential limits in a metric space.

    Convergent sequences of points in metric spaces converge to unique points.
    🔗
    🔗

    Proof.
    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \text{,}\) and suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to two points \(x , y \in X \text{.}\) We will show that \(x = y \text{.}\)
    🔗
    To that end, let \(\epsilon \) be a positive real number, and note that \(\frac{ \epsilon }{ 2 } \) is a positive real number. There are thus natural numbers \(m_{ \frac{ \epsilon }{ 2 } } , n_{ \frac{ \epsilon }{ 2 } } \in \N \) so that \(\rho \of{ x_{ n } , x } \lt \frac{ \epsilon }{ 2 } \) for all indices \(n \geq m_{ \frac{ \epsilon }{ 2 } } \) and \(\rho \of{ x_{ n } , y } \lt \frac{ \epsilon }{ 2 } \) for all indices \(n \geq n_{ \frac{ \epsilon }{ 2 } } \text{.}\)
    🔗
    Let \(p_{ \epsilon } = \max \of{ m_{ \frac{ \epsilon }{ 2 } } , n_{ \frac{ \epsilon }{ 2 } } } \text{,}\) and note that \(p_{ \epsilon } \geq m_{ \frac{ \epsilon }{ 2 } } \) and \(p_{ \epsilon } \geq n_{ \frac{ \epsilon }{ 2 } } \text{.}\) We conclude that
    \begin{equation*} \rho \of{ x , y } \leq \rho \of{ x , x_{ p_{ \epsilon } } } + \rho \of{ x_{ p_{ \epsilon } } , y } = \rho \of{ x_{ p_{ \epsilon } } , x } + \rho \of{ x_{ p_{ \epsilon } } , y } \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon\text{.} \end{equation*}
    In summary, we have shown that \(\rho \of{ x , y } \lt \epsilon \) for all positive real numbers \(\epsilon \gt 0 \text{.}\) Since \(\rho \of{ x , y } \geq 0 \) by Lemma 3.1.4 Metrics are non-negative, we conclude that \(\rho \of{ x , y } = 0 \) and hence \(x = y \text{.}\)
    🔗
    🔗
    So if a sequence in a metric space converges to a point, then that point is unique with this property, and is called the limit of the sequence. Many texts in analysis place limits of both sequences and maps (we will define this shortly) in the spotlight; limits are certainly the most important analytical concept introduced in this text. However, we have tried to emphasize the more abstract notion of convergence over that of a limit. We have just proven that the two notions are equivalent in a metric space, but in the next chapter we will explore an analytical setting in which convergent sequences need not converge to a unique limit.
    🔗

    Definition 3.2.4. Sequential limit.

    The unique point \(x \in X \) to which a convergent sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \) converges is called the limit of said sequence, and it is denoted
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = x\text{.} \end{equation*}
    🔗
    🔗

    Example 3.2.5. Sequential limits.

    Let \(x \in X \) be a point in a metric space \(\of{ X , \rho } \text{,}\) and consider the constant sequence \(\of{ x_{ n } }_{ n = 1 }^{ \infty } \) of points defined by the formula \(x_{ n } = x \text{.}\) For all positive real numbers \(\epsilon \gt 0 \) and all indices \(n \geq 0 \text{,}\) we observe that
    \begin{equation*} \rho \of{ x_{ n } , x } = \rho \of{ x , x } = 0 \lt \epsilon\text{.} \end{equation*}
    Thus \(\of{ x_{ n } }_{ n = 0 }^{ \infty } = \of{ x }_{ n = 0 }^{ \infty } \) converges to \(x \text{;}\) that is,
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = \lim_{ n \to \infty }{ x } = x\text{.} \end{equation*}
    🔗
    🔗
    Note that the notation introduced in the above definition is somewhat ambiguous; nowhere does it specify with respect to which metric a sequence converges or in which ground set the values of the sequence are considered to lie. We will try to avoid these ambiguities, but (at least in this text) both the ground set and the metric should always be clear from context. If the expression to the right of the limit operator is a real or complex number, then it’s a safe bet to assume that convergence is in the standard Euclidean metric \(d \) on the real numbers \(\R \) or complex numbers \(\C \text{,}\) respectively. Similarly, if the expression to the right of the limit operator is a real or complex coordinate vector, then you should assume that we are working in real or complex coordinate space, respectively, taken with the Euclidean metric. We will properly investigate Euclidean convergence in the section to come.
    🔗
    We next establish a necessary and sufficient condition for sequence convergence in any metric space; that the distances between the points of the sequence and the limiting value converge to zero in the real line. The proof of the following proposition follows directly from the definitions of convergence and limit.
    🔗

    Proposition 3.2.6. Sequential convergence.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \text{.}\) Then for any point \(x \in X \text{,}\)
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = x \end{equation*}
    if and only if
    \begin{equation*} \lim_{ n \to \infty }{ \rho \of{ x_{ n } , x } } = 0\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    We observe that
    \begin{equation*} d \of{ \rho \of{ x_{ n } , x } , 0 } = \abs{ \rho \of{ x_{ n } , x } - 0 } = \abs{ \rho \of{ x_{ n } , x } } = \rho \of{ x_{ n } , x } \end{equation*}
    for all indices \(n \in \N \text{.}\) First suppose that
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = x\text{,} \end{equation*}
    and let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that \(\rho \of{ x_{ n } , x } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
    \begin{equation*} d \of{ \rho \of{ x_{ n } , x } , 0 } = \rho \of{ x_{ n } , x } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{,}\) and so
    \begin{equation*} \lim_{ n \to \infty }{ \rho \of{ x_{ n } , x } } = 0\text{.} \end{equation*}
    🔗
    Conversely, now suppose that
    \begin{equation*} \lim_{ n \to \infty }{ \rho \of{ x_{ n } , x } } = 0\text{,} \end{equation*}
    and let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that \(d \of{ \rho \of{ x_{ n } , x } , 0 } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
    \begin{equation*} \rho \of{ x_{ n } , x } = d \of{ \rho \of{ x_{ n } , x } , 0 } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{,}\) and so
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = x\text{.} \end{equation*}
    🔗
    🔗
    The implications of the above result are that in order to understand sequential convergence and divergence in any metric space, it suffices to understand the convergence and divergence of sequences of real numbers in the Euclidean metric. In the next section, we will examine the properties of convergence and divergence in the Euclidean metric, and use the standard ordering on the real numbers to enrich our understanding of limiting behavior in the real numbers.
    🔗
    We have just seen that the question of convergence or divergence in an arbitrary metric space can be reduced to the question of convergence or divergence of a related sequence of real numbers in the Euclidean metric. We will begin our study of these Euclidean limits by generalizing to the metric induced on real coordinate space by an arbitrary \(p \)-norm. In real coordinate space, sequential convergence in the Euclidean metric is equivalent to sequential convergence in any of the metrics induced on real coordinate space by a \(p \)-norm. In fact, something much stronger and much more useful is true; we can reduce the question of convergence or divergence of any sequence of complex coordinate vectors in such a metric to the question of the convergence or divergence of the component sequences in the Euclidean metric on the real numbers.
    🔗

    Theorem 3.2.7. Sequential convergence in the \(p \)-metric.

    Let \(m \in \N \) be a natural number, and consider a sequence \(\of{ \vect{ x }_{ n } }_{ n = 0 }^{ \infty } \) of vectors \(\vect{ x }_{ n } = \of{ x_{ j , n } }_{ j = 1 }^{ m } \in \R^{ m } \text{.}\)
    🔗
    For any vector \(\vect{ x } = \of{ x_{ j } }_{ j = 1 }^{ m } \) and real number \(1 \leq p \lt \infty \text{,}\) the sequence \(\of{ \vect{ x }_{ n } }_{ n = 0 }^{ \infty } \) converges to \(\vect{ x } \) in the \(p \)-metric \(d_{ p } \) on \(\R^{ m } \) if and only if for all indices \(1 \leq j \leq m \text{,}\) the sequence \(\of{ x_{ j , n } }_{ n = 0 }^{ \infty } \) converges to \(x_{ j } \) in the Euclidean metric \(d \) on \(\R \text{.}\)
    🔗
    🔗

    Proof.
    First suppose that \(\of{ \vect{ x }_{ n } }_{ n = 0 }^{ \infty } \) converges to \(\vect{ x } \) in the \(p \)-metric \(d_{ p } \) on \(\R^{ m } \text{.}\) Let \(1 \leq j \leq m \text{,}\) and consider a positive real number \(\epsilon \gt 0 \text{.}\) Then there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} d_{ p } \of{ \vect{ x }_{ n } , \vect{ x } } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) We observe that
    \begin{align*} d \of{ x_{ j , n } , x_{ j } }^{ p } \amp = \abs{ x_{ j , n } - x_{ j } }^{ p } \leq \sum_{ k = 1 }^{ m }{ \abs{ x_{ k , n } - x_{ k } }^{ p } }\\ \amp = \norm{ \vect{ x }_{ n } - \vect{ x } }_{ p }^{ p } = d_{ p } \of{ \vect{ x }_{ n } , \vect{ x } }^{ p } \lt \epsilon^{ p }\text{,} \end{align*}
    so that \(d \of{ x_{ j , n } , x_{ j } } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular, \(\of{ x_{ j , n } }_{ n = 0 }^{ \infty } \) converges to \(x_{ j } \) in the Euclidean metric \(d \) on \(\R \text{.}\)
    🔗
    Conversely, now suppose that for all indices \(1 \leq j \leq m \text{,}\) \(\of{ x_{ j , n } }_{ n = 0 }^{ \infty } \) converges to \(x_{ j } \) in the Euclidean metric \(d \) on \(\R \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Then \(\frac{ \epsilon }{ m^{ \frac{ 1 }{ p } } } \gt 0 \) is a positive real number, and so for each index \(1 \leq j \leq m \) there is a natural number \(n_{ j , \epsilon } \) so that
    \begin{equation*} d \of{ x_{ j , n } , x_{ j } } \lt \frac{ \epsilon }{ m^{ \frac{ 1 }{ p } } } \end{equation*}
    for all indices \(n \geq n_{ j , \epsilon } \text{.}\) Let \(n_{ \epsilon } = \max_{ 1 \leq j \leq m }{ n_{ j , \epsilon } } \text{,}\) and note that
    \begin{gather*} d_{ p } \of{ \vect{ x }_{ n } , \vect{ x } }^{ p } = \sum_{ j = 1 }^{ m }{ \abs{ x_{ j , n } - x_{ j } }^{ p } } = \sum_{ j = 1 }^{ m }{ d \of{ x_{ j , n } , x_{ j } }^{ p } }\\ \lt \sum_{ j = 1 }^{ m }{ \of{ \frac{ \epsilon }{ m^{ \frac{ 1 }{ p } } } }^{ p } } = \sum_{ j = 1 }^{ m }{ \frac{ \epsilon^{ p } }{ m } } = \epsilon^{ p } \end{gather*}
    and therefore \(d_{ p } \of{ \vect{ x }_{ n } , \vect{ x } } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that \(\of{ \vect{ x }_{ n } }_{ n = 0 }^{ \infty } \) converges to \(\vect{ x } \) in the \(p \)-metric \(d_{ p } \) on \(\R^{ n } \text{.}\)
    🔗
    🔗
    Theorem 3.2.7 Sequential convergence in the \(p \)-metric implies that, in order to know everything about sequential convergence and divergence in the metric induced on real coordinate space by a \(p \)-norm, it suffices to know about the convergence and divergence of sequences of real numbers in the Euclidean metric. Moreover, all of the \(p \)-metrics induced on real coordinate space by the \(p \)-norms are equivalent with respect to the question of sequential convergence and divergence; that is, the convergence of a sequence of real coordinate vectors converges in the metric induced on real coordinate space by a \(p \)-norm does not depend on \(p \text{.}\)
    🔗
    The reduction of problems of sequential convergence in a metric space to that of convergence of one or more sequences of real numbers in the Euclidean metric will be a common theme in this chapter. In some respect, this reduction is possible because
    1. given a point, a metric necessarily associates the other points of a space with the positive real numbers \(\opint{ 0 }{ \infty } \text{;}\) and
      🔗
      🔗
    2. convergence in the Euclidean metric \(d \) can be defined solely in terms of the standard order \(\leq \) on the real line \(\R \text{.}\)
      🔗
      🔗
    In the following section, we will discuss sequential convergence and divergence in the Euclidean metric on the real numbers in greater detail.

    Subsection 3.2.2 Pointwise and Uniform Convergence

    Later in this chapter, we will establish metrics on certain collections of maps with codomain a given metric space. However, without yet defining a metric on these sets, there are two related but distinct modes of convergence of a sequence of such maps. A sequence of maps to a metric space is said to converge pointwise to a limit map if the images of each input in the domain converge to their images under the limit map. Stronger than pointwise convergence is the notion of uniform convergence, which requires that the speed of pointwise convergence not depend on the given input.
    🔗

    Definition 3.2.8. Pointwise convergence/divergence.

    Let \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of maps \(f_{ n } \colon X \to Y \) from a set \(X \) to a metric space \(\of{ Y , \rho } \text{.}\)
    • Pointwise convergence.
      The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges pointwise to a map \(f \colon X \to Y \) from \(X \) to \(Y \) if for all inputs \(x \in X \text{,}\) the sequence \(\of{ f_{ n } \of{ x } }_{ n = 0 }^{ \infty } \) of corresponding outputs \(f_{ n } \of{ x } \in Y \) converges to \(f \of{ x } \text{.}\)
      🔗
      The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) is called pointwise convergent if it converges pointwise to a map from \(X \) to \(Y \text{.}\)
      🔗
      🔗
    • Pointwise divergence.
      The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) is called pointwise divergent if it does not converge pointwise to any map from \(X \) to \(Y \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 3.2.9. Pointwise convergence.

    Consider the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of functions \(f_{ n } \colon \clint{ 0 }{ 1 } \to \clint{ 0 }{ 1 } \) defined by the formulae \(f_{ n } \of{ x } = x^{ n } \text{.}\) Since
    \begin{equation*} \lim_{ n \to \infty }{ f_{ n } \of{ x } } = \lim_{ n \to \infty }{ x^{ n } } = \begin{cases} 0 \amp 0 \leq x \lt 1 \\ 1 \amp x = 1 \text{,}\end{cases} \end{equation*}
    the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges pointwise to the function \(f \colon \clint{ 0 }{ 1 } \to \clint{ 0 }{ 1 } \) defined piecewise by the formula
    \begin{equation*} f \of{ x } = \begin{cases} 0 \amp 0 \leq x \lt 1 \\ 1 \amp x = 1 \text{.}\end{cases} \end{equation*}
    🔗
    🔗
    Because of the uniqueness of limits of sequences in metric spaces, if a sequence of maps to a metric space converges pointwise to a map, then this map is unique with this property. In this case, the map is called the pointwise limit of the sequence.
    🔗

    Definition 3.2.10. Pointwise limit.

    For any pointwise convergent sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of maps \(f_{ n } \colon X \to Y \) from a set \(X \) to a metric space \(\of{ Y , \rho } \text{,}\) the unique map \(f \colon X \to Y \) from \(X \) to \(Y \) to which \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges pointwise is called the pointwise limit of \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and is denoted
    \begin{equation*} \lim_{ n \to \infty }{ f_{ n } } = f\text{.} \end{equation*}
    🔗
    🔗
    While some properties of a pointwise convergent sequence of maps to a metric space are shared with its pointwise limit, pointwise convergence does not in general preserve all desirable properties of maps. In particular, Example 3.2.9 Pointwise convergence implies that a pointwise limit of a sequence of continuous maps need not itself be continuous. We will explore continuity in metric spaces and its relationship with convergence later in this chapter. In order to preserve these properties, we will need a stronger notion of convergence. Informally, a sequence of maps to a metric space is said to converge uniformly it converges pointwise at roughly the same rate at each point in the domain.
    🔗

    Definition 3.2.11. Uniform convergence.

    Let \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of maps \(f_{ n } \colon X \to Y \) from a set \(X \) to a metric space \(\of{ Y , \rho } \text{.}\)
    • Uniform convergence.
      The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to a map \(f \colon X \to Y \) from \(X \) to \(Y \) if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
      \begin{equation*} \rho \of{ f_{ n } \of{ x } , f \of{ x } } \lt \epsilon \end{equation*}
      for all inputs \(x \in X \) and indices \(n \geq n_{ \epsilon } \text{.}\)
      🔗
      The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) is called uniformly convergent if it converges uniformly to a map from \(X \) to \(Y \text{.}\)
      🔗
      🔗
    • Uniform divergence.
      The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) is called uniformly divergent if it does not converge uniformly to any map from \(X \) to \(Y \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 3.2.12. Uniform convergence/divergence.

    The following are examples of uniformly convergent and divergent sequences of maps:
    • Consider the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of functions \(f_{ n } \colon \clint{ 0 }{ 1 } \to \clint{ 0 }{ 1 } \) defined by the formulae \(f_{ n } \of{ x } = x^{ n } \text{,}\) and let \(f \colon \clint{ 0 }{ 1 } \to \clint{ 0 }{ 1 } \) be the function defined piecewise by the formula
      \begin{equation*} f \of{ x } = \begin{cases} 0 \amp 0 \leq x \lt 1 \\ 1 \amp x = 1 \text{.}\end{cases} \end{equation*}
      We observe that
      \begin{align*} d \of{ f_{ n } \of{ x } , f \of{ x } } \amp = \abs{ f_{ n } \of{ x } - f \of{ x } } = \abs{ x^{ n } - 0 } = \abs{ x^{ n } } = x^{ n }\\ \amp \gt \of{ \frac{ 1 }{ 2^{ \frac{ 1 }{ n } } } }^{ n } = \frac{ 1 }{ 2 } \end{align*}
      for all positive integers \(n \geq 1 \) and inputs \(\frac{ 1 }{ \sqrt[ n ]{ 2 } } \leq x \lt 1 \text{.}\) We conclude that \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) does not converge uniformly to \(f \text{.}\)
      🔗
      🔗
    • Consider the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of functions \(f_{ n } \colon \R \to \clint{ -1 }{ 1 } \) defined by the formulae
      \begin{equation*} f_{ n } \of{ x } = \frac{ \sin \of{ n x } }{ n }\text{,} \end{equation*}
      and let \(f \colon \R \to \clint{ -1 }{ 1 } \) be the function defined by the formula \(f \of{ x } = 0 \text{.}\) For all positive real numbers \(\epsilon \gt 0 \text{,}\) the Archimedean principle implies that \(n_{ \epsilon } \cdot \epsilon \gt 1 \) for some positive integer \(n_{ \epsilon } \geq 1 \text{.}\) We observe that
      \begin{align*} d \of{ f_{ n } \of{ x } , f \of{ x } } \amp = \abs{ f_{ n } \of{ x } - f \of{ x } } = \abs{ \frac{ \sin \of{ n x } }{ n } - 0 } = \abs{ \frac{ \sin \of{ n x } }{ n } }\\ \amp = \frac{ \abs{ \sin \of{ n x } } }{ n } \leq \frac{ 1 }{ n } \leq \frac{ 1 }{ n_{ \epsilon } } \lt \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \) and inputs \(x \in \R \text{.}\) We conclude that \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to \(f \text{.}\)
      🔗
      🔗
    🔗
    🔗
    We remark that pointwise and uniform convergence are distinct concepts; that is, there are sequences of maps to a metric space which converge pointwise but not uniformly. However, the opposite relationship is not true: uniform convergence is a stronger condition on sequences of maps to a metric space than pointwise convergence; that is, a sequence of maps to a metric space converges uniformly only if it converges pointwise.
    🔗

    Proposition 3.2.13. Pointwise and uniform convergence.

    If a sequence of maps from a set to a metric space converges uniformly, then it converges pointwise.
    🔗
    🔗

    Proof.
    Suppose that a sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of maps \(f_{ n } \colon X \to Y \) from a set \(X \) to a metric space \(\of{ Y , \rho } \) converges uniformly to a map \(f \colon X \to Y \) from \(X \) to \(Y \text{.}\) Then for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} \rho \of{ f_{ n } \of{ x } , f \of{ x } } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \) and inputs \(x \in X \text{.}\) In particular, for each input \(x \in X \text{,}\)
    \begin{equation*} \rho \of{ f_{ n } \of{ x } , f \of{ x } } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{,}\) and so the sequence \(\of{ f_{ n } \of{ x } }_{ n = 0 }^{ \infty } \) converges to \(f \of{ x } \text{.}\) We conclude that \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges pointwise to \(f \text{.}\)
    🔗
    🔗
    Taken with the uniqueness of the pointwise limit of a sequence of maps to a metric space, Proposition 3.2.13 Pointwise and uniform convergence immediately implies that if a sequence of maps to a metric space converges uniformly to a map, then this map is unique with this property. In this case, the map is called the uniform limit of the sequence.
    🔗

    Definition 3.2.14. Uniform limit.

    For any uniformly convergent sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of maps \(f_{ n } \colon X \to Y \) from a set \(X \) to a metric space \(\of{ Y , \rho } \text{,}\) the unique map \(f \colon X \to Y \) from \(X \) to \(Y \) to which \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly is called the uniform limit of \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and is denoted
    \begin{equation*} \uniflim_{ n \to \infty }{ f_{ n } } = f\text{.} \end{equation*}
    🔗
    🔗

    Example 3.2.15. Uniform limit.

    Consider the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of functions \(f_{ n } \colon \R \to \clint{ -1 }{ 1 } \) defined by the formulae
    \begin{equation*} f_{ n } \of{ x } = \frac{ \sin \of{ n x } }{ n }\text{,} \end{equation*}
    and let \(f \colon \R \to \clint{ -1 }{ 1 } \) be the function defined by the formula \(f \of{ x } = 0 \text{.}\) Since \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to \(f \) as shown in Example 3.2.12 Uniform convergence/divergence, \(f \) is the uniform limit of \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \text{;}\) that is,
    \begin{equation*} \uniflim_{ n \to \infty }{ f_{ n } } = f\text{.} \end{equation*}
    We might also write that
    \begin{equation*} \uniflim_{ n \to \infty }{ \frac{ \sin \of{ n x } }{ n } } = 0\text{.} \end{equation*}
    🔗
    🔗
    So a sequence of maps to a metric space converges uniformly only if it converges pointwise. The reverse implication, however, is not in general true. In the following sections, we will see that, unlike in the case of pointwise convergence, many of the desirable properties of maps between metric spaces are preserved under uniform convergence.

    Subsection 3.2.3 Map Convergence

    Just as we can use a metric to define the convergence of a sequence of points or maps in a metric space, we can similarly consider the convergence of maps between metric spaces. In our definition of sequence convergence, we considered a sequence to converge to a limit if the points of the sequence could be made arbitrarily close to the limit point solely by choosing large enough indices. We will similarly consider a map between metric spaces to converge to a limit in the codomain at a point in the domain if we can make outputs close to the limit in the codomain solely by choosing inputs close to the point in the domain.
    🔗
    In the case of sequential convergence, we used the standard ordering on the natural numbers to induce a notion of limiting behavior by considering arbitrarily large indices. For map convergence, however, we use the metric in the domain to consider arbitrarily close points to the point in question.
    🔗

    Definition 3.2.16. Map convergence.

    Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\)
    • Map convergence.
      \(f \) converges at a point \(c \in X \) to a point \(l \in Y \) if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there exists a positive real number \(\delta \gt 0 \) so that
      \begin{equation*} \rho_{ Y } \of{ f \of{ x } , l } \lt \epsilon \end{equation*}
      for all inputs \(x \in X \) so that \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{.}\)
      🔗
      The map \(f \) is called convergent at a point \(c \in X \) if it converges at \(c \) to some point \(l \in Y \text{.}\)
      🔗
      🔗
    • Map divergence.
      The map \(f \) is called divergent at a point \(c \in X \) if it does not converge at \(c \) to any point \(l \in Y \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 3.2.17. Map convergence.

    Consider the real-valued function \(f \colon \R \to \R \) defined piecewise by the formula
    \begin{equation*} f \of{ x } = \begin{cases} x \sin \of{ \frac{ 1 }{ x } } \amp x \neq 0 \\ 0 \amp x = 0 \text{.}\end{cases} \end{equation*}
    As the graph of \(y = f \of{ x } \) suggests, \(f \) converges to \(0 \) at \(0 \) in the Euclidean metric \(d \) on \(\R \text{.}\)
    🔗
    Indeed, let \(\epsilon \gt 0 \) be a positive real number, and let \(\delta = \epsilon \gt 0 \text{.}\) Then
    \begin{align*} d \of{ f \of{ x } , 0 } \amp = \abs{ x \sin \of{ \frac{ 1 }{ x } } - 0 } = \abs{ x } \cdot \abs{ \sin \of{ \frac{ 1 }{ x } } }\\ \amp \leq \abs{ x } = \abs{ x - 0 } = d \of{ x , 0 } \lt \delta = \epsilon \end{align*}
    for all inputs \(x \in \R \) so that \(0 \lt d \of{ x , 0 } \lt \delta \text{.}\)
    🔗
    🔗
    In analogy to the case of sequential convergence, in order to study map convergence between metric spaces, it suffices to study the convergence of real-valued functions on metric spaces.
    🔗

    Proposition 3.2.18. Map convergence.

    Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) For each point \(l \in Y \text{,}\) let \(g_{ l } \colon X \to \R \) be the real-valued function on \(X \) defined by the formula
    \begin{equation*} g_{ l } \of{ x } = \rho_{ Y } \of{ f \of{ x } , l }\text{.} \end{equation*}
    Then \(f \) converges to \(l \) at \(c \) if and only if \(g_{ c , l } \) converges to \(0 \) at \(c \text{.}\)
    🔗
    🔗

    Proof.
    We first observe that
    \begin{equation*} d \of{ g_{ l } \of{ x } , 0 } = \abs{ \rho_{ Y } \of{ f \of{ x } , l } - 0 } = \abs{ \rho_{ Y } \of{ f \of{ x } , l } } = \rho_{ Y } \of{ f \of{ x } , l } \end{equation*}
    for all \(x \in X \text{.}\)
    🔗
    Suppose first that \(f \) converges to \(l \) at \(c \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Then there is some positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x } , l } \lt \epsilon \end{equation*}
    for all inputs \(x \in X \) so that \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{.}\) We observe that
    \begin{equation*} d \of{ g_{ l } \of{ x } , 0 } = \rho_{ Y } \of{ f \of{ x } , l } \lt \epsilon \end{equation*}
    for all inputs \(x \in X \) so that \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{,}\) and so \(g_{ l } \) converges to \(0 \) at \(c \text{.}\)
    🔗
    Conversely, now suppose that \(g_{ l } \) converges to \(0 \) at \(c \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Then there is some positive real number \(\delta \gt 0 \) so that
    \begin{equation*} d \of{ g_{ l } \of{ x } , 0 } \lt \epsilon \end{equation*}
    for all inputs \(x \in X \) so that \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{.}\) We observe that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x } , l } = d \of{ g_{ l } \of{ x } , 0 } \lt \epsilon \end{equation*}
    for all inputs \(x \in X \) so that \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{,}\) and so \(f \) converges to \(l \) at \(c \text{.}\)
    🔗
    🔗
    So we can reduce the question of convergence for maps between metric spaces to that of Euclidean convergence of real-valued functions on metric spaces. We will study the important topic of convergence of such real-valued functions under the Euclidean metric on the real numbers in detail in Section 3.3 Limits in the Euclidean Metric.
    🔗
    The following theorem establishes another necessary and sufficient condition for map convergence; a map between metric spaces converges if and only if all convergent sequences in the domain can be “pushed through” to convergent sequences in the codomain.
    🔗

    Theorem 3.2.19. Sequential characterization of map convergence.

    Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) For all points \(c \in X \) and \(l \in Y \text{,}\) \(f \) converges to \(l \) at \(c \) if and only if for all sequences \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \setminus \set{ c } \text{,}\) if
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{,} \end{equation*}
    then
    \begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = l\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    First suppose that \(f \) converges to \(l \) at \(c \text{,}\) and consider a sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \setminus \set{ c } \) which converges to \(c \text{.}\) We observe that \(\rho_{ X } \of{ x_{ n } , c } \gt 0 \) for all indices \(n \in \N \text{.}\)
    🔗
    Let \(\epsilon \gt 0 \) be a positive real number. Then there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x } , l } \lt \epsilon \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{.}\) Since \(\delta \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} 0 \lt \rho_{ X } \of{ x_{ n } , c } \lt \delta \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular, this implies that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x_{ n } } , l } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that \(\of{ f \of{ x_{ n } } }_{ n = 0 }^{ \infty } \) converges to \(l \text{.}\)
    🔗
    Conversely, now suppose that \(f \) does not converge to \(l \) at \(c \text{.}\) Then there is a positive real number \(\epsilon \) so that for all positive real numbers \(\delta \gt 0 \text{,}\) there is a point \(x \in X \setminus \set{ c } \) so that
    \begin{equation*} 0 \lt \rho_{ X } \of{ x , c } \lt \delta \end{equation*}
    but
    \begin{equation*} \rho_{ Y } \of{ f \of{ x } , l } \geq \epsilon\text{.} \end{equation*}
    In particular, let \(\of{ \delta_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of positive real numbers \(\delta_{ n } \geq 0 \) which converges in the Euclidean metric to \(0 \text{.}\) For each index \(n \in \N \text{,}\) there is a point \(x_{ n } \in X \setminus \set{ c } \) so that
    \begin{equation*} 0 \lt \rho_{ X } \of{ x_{ n } , c } \lt \delta_{ n } \end{equation*}
    but
    \begin{equation*} \rho_{ Y } \of{ f \of{ x_{ n } } , l } \geq \epsilon\text{.} \end{equation*}
    Since
    \begin{equation*} d \of{ \rho_{ X } \of{ x_{ n } , c } , 0 } = \abs{ \rho_{ X } \of{ x_{ n } , c } - 0 } = \rho_{ X } \of{ x_{ n } , c } \lt \delta_{ n } \end{equation*}
    for all indices \(n \in \N \text{,}\) Proposition 3.2.6 Sequential convergence implies that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(c \) but \(\of{ f \of{ x_{ n } } }_{ n = 0 }^{ \infty } \) does not converge to \(l \text{.}\)
    🔗
    🔗
    The above result relates map convergence and sequential convergence. Note, however, that this theorem and the uniqueness of sequential limits in metric spaces do not necessarily imply the uniqueness of the limit of a convergent map between metric spaces. In fact, map limits need not be uniquely determined in some metric spaces.
    🔗

    Example 3.2.20. Non-uniqueness of map limits.

    Consider the discrete metric \(\delta_{ B } \) on the set \(B = \set{ 0 , 1 } \text{,}\) and consider the function \(f \colon B \to B \) defined by the formula \(f \of{ b } = b \text{.}\) Then \(f \) converges to \(0 \) at \(0 \text{,}\) and \(f \) converges to \(1 \) at \(0 \text{.}\)
    🔗
    Indeed, let \(c = 0 \text{,}\) and consider \(l \in B \text{.}\) For all positive real numbers \(\epsilon \gt 0 \text{,}\) let \(\delta = \frac{ 1 }{ 2 } \text{,}\) and note that there are no points \(b \in B \) so that \(0 \lt \delta_{ B } \of{ b , c } \lt \frac{ 1 }{ 2 } \text{.}\) Thus \(f \) converges to \(l \) at \(c \) vacuously.
    🔗
    🔗
    So the limit of a convergent map between metric spaces is not necessarily unique. However, this undesirable situation may be rectified by restricting our attention to certain points in the domain of such a map. Note that the uniqueness of the limit in Example 3.2.20 Non-uniqueness of map limits failed because the point \(c = 0 \) is far away from the rest of the set \(B \text{;}\) that is, there are no points close to but distinct from \(0 \text{;}\) equivalently, any sequence in \(B \) converging to \(0 \) must eventually take only \(0 \) as a value. Such points are called isolated points, and other points are called limit points.
    🔗

    Definition 3.2.21. Accumulation; isolation.

    Consider a subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \text{.}\)
    • Limit point.
      We say that \(U \) accumulates at a point \(c \in X \) if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a point \(u \in U \) so that \(0 \lt \rho \of{ u , c } \lt \epsilon \text{.}\) In this case, \(c \) is called a limit point (or accumulation point) of \(U \) in \(X \text{.}\) The set of such limit points of \(U \) is called the derived set of \(U \text{,}\) and is denoted \(U' \text{.}\)
      🔗
      🔗
    • Isolated point.
      We say that a point \(c \in X \) is isolated from \(U \) if \(c \) is not a limit point of \(U \text{;}\) that is, \(c \) is isolated from \(U \) if there is a positive real number \(\epsilon \gt 0 \) so that \(\rho \of{ u , c } \geq \epsilon \) for all points \(u \in U \) so that \(u \neq c \text{.}\) If \(c \in U \) is isolated from \(U \text{,}\) then \(c \) is called an isolated point of \(U \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 3.2.22. Limit points and isolated points.

    The following are examples of limit points and isolated points in metric spaces:
    • Euclidean space.
      Let \(n \geq 1 \) be a positive integer, and consider a real number \(1 \leq p \lt \infty \text{.}\) If \(\vect{ x } = \of{ x_{ 1 } , \dotsc , x_{ n } } \in \R^{ n } \text{,}\) then consider for each positive real number \(\epsilon \gt 0 \) the vector \(\vect{ x }_{ \epsilon } = \of{ x_{ 1 } + \frac{ \epsilon }{ 2 } , x_{ 2 } , \dotsc , x_{ n } } \text{.}\) We observe that
      \begin{align*} d_{ p } \of{ \vect{ x } , \vect{ x }_{ \epsilon } } \amp = \of{ \abs{ x_{ 1 } - \of{ x_{ 1 } + \frac{ \epsilon }{ 2 } } }^{ p } + \abs{ x_{ 2 } - x_{ 2 } }^{ p } + \dotsb + \abs{ x_{ n } - x_{ n } }^{ p } }^{ \frac{ 1 }{ p } }\\ \amp = \abs{ -\frac{ \epsilon }{ 2 } } = \frac{ \epsilon }{ 2 }\text{.} \end{align*}
      In particular,
      \begin{equation*} 0 \lt d_{ p } \of{ \vect{ x } , \vect{ x }_{ \epsilon } } \lt \epsilon\text{,} \end{equation*}
      and so \(\vect{ x } \) is a limit point of \(\R^{ n } \text{.}\) Since \(\vect{ x } \) was chosen arbitrarily, we conclude that every point of \(\R^{ n } \) is a limit point.
      🔗
      🔗
    • Discrete space.
      Let \(\of{ X , \delta_{ X } } \) be a discrete metric space, and consider a point \(x \in X \text{.}\) Since the values of \(\delta_{ X } \) are \(0 \) and \(1 \text{,}\) there is no point \(y \in X \) so that \(0 \lt \delta_{ X } \of{ x , y } \lt 1 \text{.}\) Thus \(x \) is an isolated point of \(X \text{.}\) Since \(x \) was chosen arbitrarily, we conclude that every point of \(\of{ X , \delta_{ X } } \) is an isolated point.
      🔗
      🔗
    • The only limit point of the set \(\set{ \frac{ 1 }{ n } }_{ n = 1 }^{ \infty } \) in \(\R \) is \(0 \text{.}\)
      🔗
      🔗
    • The only limits point of the set \(\set{ \of{ -1 }^{ n } + \frac{ 1 }{ n } }_{ n = 0 }^{ \infty } \) in \(\R \) are \(1 \) and \(-1 \text{.}\)
      🔗
      🔗
    🔗
    🔗
    A point in a metric space is a limit point of a subset if and only if it is the limit of a sequence of points in that subset which are distinct from that point.
    🔗

    Proposition 3.2.23. Sequential characterization of limit points.

    Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{.}\) A point \(c \in X \) is a limit point of \(U \) if and only if
    \begin{equation*} c = \lim_{ n \to \infty }{ u_{ n } } \end{equation*}
    for some sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) of points \(u_{ n } \in U \setminus \set{ c } \text{.}\)
    🔗
    🔗

    Proof.
    First suppose that \(c \) is a limit point of \(U \text{.}\) Then for each positive integer \(n \geq 1 \text{,}\) \(\frac{ 1 }{ n } \gt 0 \text{,}\) and so there is a point \(u_{ n } \in U \setminus \set{ c } \) so that
    \begin{equation*} 0 \lt \rho \of{ u_{ n } , c } \lt \frac{ 1 }{ n }\text{.} \end{equation*}
    We claim that \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) converges to \(c \text{.}\) Indeed, for any positive real number \(\epsilon \gt 0 \text{,}\) the Archimedean principle implies that there is a natural number \(n_{ \epsilon } \gt \frac{ 1 }{ \epsilon } \text{.}\) We observe that
    \begin{equation*} \rho \of{ u_{ n } , c } \lt \frac{ 1 }{ n } \leq \frac{ 1 }{ n_{ \epsilon } } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that
    \begin{equation*} \lim_{ n \to \infty }{ u_{ n } } = c\text{.} \end{equation*}
    🔗
    Conversely, now suppose that
    \begin{equation*} \lim_{ n \to \infty }{ u_{ n } } = c \end{equation*}
    for some sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) of points \(u_{ n } \in U \setminus \set{ c } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \gt 0 \) so that \(\rho \of{ u_{ n } , c } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
    \begin{equation*} 0 \lt \rho \of{ u_{ n_{ \epsilon } } , c } \lt \epsilon\text{,} \end{equation*}
    since \(u_{ n_{ \epsilon } } \neq c \text{.}\) We conclude that \(c \) is a limit point of \(U \text{.}\)
    🔗
    🔗
    As we have seen, the limit of a convergent map between metric spaces at an isolated point of the domain need not be unique. However, the limit of such a map at a limit point of the domain is unique. This follows immediately from the above results.
    🔗

    Corollary 3.2.24. Uniqueness of map limits.

    Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) If \(f \) converges at a limit point \(c \in X \) of \(X \text{,}\) then it converges to a unique point \(l \in Y \text{.}\)
    🔗
    🔗

    Proof.
    Suppose that \(f \) converges to two points \(l , m \in Y \) at a limit point \(c \in X \) of \(X \text{.}\) Since \(c \) is a limit point of \(X \text{,}\)
    \begin{equation*} c = \lim_{ n \to \infty }{ x_{ n } } \end{equation*}
    for some sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \setminus \set{ c } \) by Proposition 3.2.23 Sequential characterization of limit points. Theorem 3.2.19 Sequential characterization of map convergence now implies that
    \begin{equation*} l = \lim_{ n \to \infty }{ f \of{ x_{ n } } } = m\text{.} \end{equation*}
    🔗
    🔗
    Analogously to the case of unique sequential limits, the above corollary leads naturally to the following definition, which is that of the unique limit of a map between metric spaces at a limit point.
    🔗

    Definition 3.2.25. Map limit.

    Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) If \(f \) converges at a limit point \(c \in X \) of \(X \text{,}\) the unique point \(l \in Y \) to which \(f \) converges at \(c \) is called the limit of \(f \) at \(c \text{,}\) and is denoted
    \begin{equation*} \lim_{ x \to c }{ f \of{ x } } = l\text{.} \end{equation*}
    🔗
    🔗
    Again, note the ambiguity of the above notation; it is entirely unclear with respect to which metrics this convergence is satisfied. Indeed, as in the case of sequential limits, maps between sets may converge in one pair of metrics and diverge in another, or may converge to different limits in different metrics. We will try to avoid this ambiguity if at all possible. Analogously to the case of sequential limits, if the map inside the limit operator is a map between real coordinate spaces, it will usually be safe to assume that convergence is with respect to the relevant Euclidean metrics.
    🔗

    Example 3.2.26. Map limits.

    Consider the real-valued function \(f \colon \R \to \R \) defined by the formula \(f \of{ x } = 2 x + 1 \text{.}\) We claim that
    \begin{equation*} \lim_{ x \to c }{ f \of{ x } } = 2 c + 1 \end{equation*}
    for all points \(c \in \R \text{.}\)
    🔗
    Indeed, let \(\epsilon \gt 0 \) be a positive real number, and consider the positive real number \(\delta = \frac{ \epsilon }{ 2 } \gt 0 \text{.}\) We observe that
    \begin{align*} d \of{ f \of{ x } , 2 c + 1 } = \abs{ 2 x + 1 - \of{ 2 c + 1 } } = \abs{ 2 \of{ x - c } }\\ \amp = 2 \abs{ x - c } = 2 d \of{ x , c } \lt 2 \delta = \epsilon \end{align*}
    for all points \(x \in \R \) so that \(0 \lt d \of{ x , c } \lt \delta \text{,}\) and so \(f \) converges to \(2 c + 1 \) at \(c \text{.}\) Since \(c \) is a limit point of \(\R \text{,}\) we conclude that
    \begin{equation*} \lim_{ x \to c }{ f \of{ x } } = 2 c + 1\text{.} \end{equation*}
