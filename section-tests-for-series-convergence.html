    Section 7.2 Tests for Series Convergence

    In this section, we introduce several results which are invaluable techniques for analyzing the convergence/divergence behavior of infinite series. Foremost among these is the comparison test, which establishes convergence/divergence implications based on termwise estimates. We will also see several related results based on comparisons with well-known series.
    🔗

    Subsection 7.2.1 Sufficient Criteria for Series Convergence

    Before we are able to prove the direct comparison test in full, we establish the following special case:
    🔗

    Lemma 7.2.1. Comparison of non-negative series.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{,}\) and suppose that \(0 \leq x_{ n } \leq y_{ n } \) for all natural numbers \(n \in \N \text{.}\)
    1. If the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converges, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converge.
      🔗
      🔗
    2. If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) diverges, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) diverge.
      🔗
      🔗
    🔗
    🔗

    Proof.
    Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ T_{ n } }_{ n = 0 }^{ \infty } \) be the corresponding sequences of partial sums
    \begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ k } } \amp T_{ n } \amp = \sum_{ k = 0 }^{ n }{ y_{ k } }\text{.} \end{align*}
    We observe that
    \begin{equation*} S_{ n + 1 } = \sum_{ k = 0 }^{ n + 1 }{ x_{ k } } = \sum_{ k = 0 }^{ n }{ x_{ k } } + x_{ n + 1 } \geq S_{ n } \end{equation*}
    for all indices \(n \in \N \text{,}\) so that \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) is non-decreasing. Similarly, \(\of{ T_{ n } }_{ n = 0 }^{ \infty } \) is non-decreasing. The Monotone convergence theorem implies that
    \begin{align*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \amp = \lim_{ n \to \infty }{ S_{ n } } = \sup_{ n \in \N }{ S_{ n } }\\ \sum_{ n = 0 }^{ \infty }{ y_{ n } } \amp = \lim_{ n \to \infty }{ T_{ n } } = \sup_{ n \in \N }{ T_{ n } }\text{.} \end{align*}
    Finally, we observe that
    \begin{equation*} \sup_{ n \in \N }{ S_{ n } } = \sup_{ n \in \N }{ \sum_{ k = 0 }^{ n }{ x_{ k } } } \leq \sup_{ n \in \N }{ \sum_{ k = 0 }^{ n }{ y_{ k } } } = \sup_{ n \in \N }{ T_{ n } } \end{equation*}
    1. If the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converges, then \(\sup_{ n \in \N }{ T_{ n } } \lt \infty \) is finite, and so
      \begin{equation*} \sup_{ n \in \N }{ S_{ n } } \leq \sup_{ n \in \N }{ T_{ n } } \lt \infty \end{equation*}
      is finite as well. This implies that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges.
      🔗
    2. If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) diverges, then \(\sup_{ n \in \N }{ S_{ n } } = \infty \) is infinite, and so
      \begin{equation*} \infty = \sup_{ n \in \N }{ S_{ n } } \leq \sup_{ n \in \N }{ T_{ n } } \leq \infty\text{;} \end{equation*}
      that is, \(\sup_{ n \in \N }{ T_{ n } } = \infty \) is infinite as well. This implies that the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) diverges.
      🔗
    🔗
    🔗
    One consequence of Lemma 7.2.1 Comparison of non-negative series is that any series whose terms are bounded between the terms of two convergent series also converges. This result is called the direct comparison test, and it is one of the most useful tools in the analysis of series.
    🔗

    Theorem 7.2.2. Direct comparison test.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and \(\of{ z_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } , z_{ n } \in \R \text{,}\) and suppose that \(x_{ n } \leq y_{ n } \leq z_{ n } \) for all natural numbers \(n \in \N \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) and \(\sum_{ n = 0 }^{ \infty }{ z_{ n } } \) converge, then so does the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ v_{ n } }_{ n = 0 }^{ \infty } \) be the sequences of real numbers \(u_{ n } , v_{ n } \in \R \) defined by the formulas
    \begin{align*} u_{ n } \amp = y_{ n } - x_{ n } \amp v_{ n } \amp = z_{ n } - x_{ n }\text{.} \end{align*}
    Then \(0 \leq u_{ n } \leq v_{ n } \) for all indices \(n \in \N \text{,}\) and the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ v_{ n } } = \sum_{ n = 0 }^{ \infty }{ \of{ z_{ n } - x_{ n } } } \end{equation*}
    converges by Proposition 7.1.6 Arithmetic of convergent series. Thus the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converges by Lemma 7.2.1 Comparison of non-negative series.
    🔗
    🔗

    Example 7.2.3. Applying the Direct comparison test.

    The following are examples of applications of the Direct comparison test:
    • The series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \frac{ 1 }{ 2^{ n } + n } } \end{equation*}
      converges by direct comparison with the convergent geometric series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \frac{ 1 }{ 2^{ n } } }\text{.} \end{equation*}
      Specifically, we use the estimate
      \begin{equation*} 0 \leq \frac{ 1 }{ 2^{ n } + n } \leq \frac{ 1 }{ 2^{ n } } \end{equation*}
      for all indices \(n \in \N \text{.}\)
      🔗
      🔗
    • The series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ n^{ 2 } } = 0 + 1 + 4 + 9 + 16 + 25 + \dotsb \end{equation*}
      converges by direct comparison with the divergent series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ n } = 0 + 1 + 2 + 3 + 4 + \dotsb\text{.} \end{equation*}
      Specifically, we use the estimate
      \begin{equation*} 0 \leq n \leq n^{ 2 } \end{equation*}
      for all indices \(n \in \N \text{.}\)
      🔗
      🔗
    🔗
    🔗
    We now explore several corollaries of the Direct comparison test. First, we note that our definition of absolute convergence in Subsection 7.1.2 Rearrangements of Infinite Series required convergence of two series; specifically, a series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely if both \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) and \(\sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \) converge. We see by Direct comparison test that we could equivalently only require the second of these series to converge.
    🔗

    Corollary 7.2.4. Absolute convergence implies convergence.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \) converges, then so does the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{.}\)
    🔗
    🔗

    Proof.
    We observe that (2) of Proposition 7.1.6 Arithmetic of convergent series implies that the series \(\sum_{ n = 0 }^{ \infty }{ -\abs{ x_{ n } } } \) converges. Since
    \begin{equation*} -\abs{ x_{ n } } \leq x_{ n } \leq \abs{ x_{ n } } \end{equation*}
    for all indices \(n \in \N \text{,}\) the Direct comparison test implies that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges.
    🔗
    🔗
    It is not always possible to easily make a direct comparison between the terms of a series and the terms of a convergent series. However, we may relax our estimates to asymptotic dominance relations and still obtain similar results.
    🔗

    Corollary 7.2.5. Limit comparison test.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{,}\) and suppose that \(x_{ n } \preccurlyeq y_{ n } \) as \(n \to \infty \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converges absolutely, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{.}\)
    🔗
    🔗

    Proof.
    Since \(x_{ n } \preccurlyeq y_{ n } \) as \(n \to \infty \text{,}\) there is a sequence \(\of{ \lambda_{ n } }_{ n = 0 }^{ \infty } \) of non-negative real numbers \(\lambda_{ n } \geq 0 \) and a non-negative real number \(L \geq 0 \) so that
    \begin{equation*} \lim_{ n \to \infty }{ \lambda_{ n } } = L\text{,} \end{equation*}
    and \(\abs{ x_{ n } } = \lambda_{ n } \abs{ y_{ n } } \) for all indices \(n \in \N \text{.}\) Consider the positive real number
    \begin{equation*} \epsilon \gt \sup_{ n \in \N }{ \abs{ \lambda_{ n } - L } } \geq 0\text{.} \end{equation*}
    We observe that \(L - \epsilon \lt \lambda_{ n } \lt L + \epsilon \) for all indices \(n \in \N \text{,}\) and so
    \begin{equation*} \of{ L - \epsilon } \abs{ y_{ n } } \lt \abs{ x_{ n } } \lt \of{ L + \epsilon } \abs{ y_{ n } } \end{equation*}
    for all indices \(n \in \N \text{.}\) (2) of Proposition 7.1.6 Arithmetic of convergent series and the Direct comparison test imply that the series \(\sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \) converges. Finally, Corollary 7.2.4 Absolute convergence implies convergence implies that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely.
    🔗
    🔗

    Example 7.2.6. Applying the Limit comparison test.

    Consider the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \frac{ 1 }{ 2^{ n } - 1 } }\text{.} \end{equation*}
    Since \(\frac{ 1 }{ 2^{ n } - 1 } \geq \frac{ 1 }{ 2^{ n } } \text{,}\) we cannot easily directly compare this series to a convergent geometric series. However, we note that
    \begin{align*} \lim_{ n \to \infty }{ \abs{ \frac{ \frac{ 1 }{ 2^{ n } } }{ \frac{ 1 }{ 2^{ n } - 1 } } } } = \lim_{ n \to \infty }{ \abs{ \frac{ 2^{ n } - 1 }{ 2^{ n } } } } = \lim_{ n \to \infty }{ 1 + \frac{ 1 }{ 2^{ n } } }\\ \amp = 1\text{,} \end{align*}
    and so \(\frac{ 1 }{ 2^{ n } - 1 } \sim \frac{ 1 }{ 2^{ n } } \) as \(n \to \infty \text{.}\) In particular, \(\frac{ 1 }{ 2^{ n } - 1 } \asymp \frac{ 1 }{ 2^{ n } } \text{,}\) and so \(\frac{ 1 }{ 2^{ n } - 1 } \preccurlyeq \frac{ 1 }{ 2^{ n } } \) as \(n \to \infty \text{.}\) The Limit comparison test now implies that the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \frac{ 1 }{ 2^{ n } - 1 } } \end{equation*}
    converges absolutely.
    🔗
    🔗
    We now briefly touch on the alternating series test, which does not follow from the Direct comparison test. This convergence test deals with alternating series, which are those whose terms alternate in sign between positive and negative. We will see that it is much easier for such a series to converge, as there can be much cancellation in the partial sums.
    🔗

    Theorem 7.2.7 (Gottfried Wilhelm Leibniz). Alternating series test.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a non-increasing sequence of positive numbers \(x_{ n } \in \opint{ 0 }{ \infty } \text{.}\) If
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = 0\text{,} \end{equation*}
    then the series \(\sum_{ n = 0 }^{ \infty }{ \of{ -1 }^{ n } x_{ n } } \) converges.
    🔗
    🔗

    Proof.
    Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) be the corresponding sequence of partial sums
    \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ \of{ -1 }^{ n } x_{ n } }\text{.} \end{equation*}
    We observe that
    \begin{align*} S_{ 2 n + 2 } \amp = \sum_{ k = 0 }^{ 2 n + 2 }{ \of{ -1 }^{ k } x_{ k } } = \sum_{ k = 0 }^{ 2 n }{ \of{ -1 }^{ k } x_{ k } } + \of{ -1 }^{ 2 n + 1 } x_{ 2 n + 1 } + \of{ -1 }^{ 2 n + 2 } x_{ 2 n + 2 }\\ \amp = S_{ 2 n } - x_{ 2 n + 1 } + x_{ 2 n + 2 } \leq S_{ 2 n } \end{align*}
    and
    \begin{align*} S_{ 2 n + 3 } \amp = \sum_{ k = 0 }^{ 2 n + 3 }{ \of{ -1 }^{ k } x_{ k } } = \sum_{ k = 0 }^{ 2 n + 1 }{ \of{ -1 }^{ k } x_{ k } } + \of{ -1 }^{ 2 n + 2 } x_{ 2 n + 2 } + \of{ -1 }^{ 2 n + 3 } x_{ 2 n + 3 }\\ \amp = S_{ 2 n + 1 } + x_{ 2 n + 2 } - x_{ 2 n + 3 } \geq S_{ 2 n + 1 } \end{align*}
    for all indices \(n \in \N \text{.}\) So the subsequences \(\of{ S_{ 2 n } }_{ n = 0 }^{ \infty } \) and \(\of{ S_{ 2 n + 1 } }_{ n = 0 }^{ \infty } \) are non-increasing and non-decreasing respectively, which implies that
    \begin{align*} \lim_{ n \to \infty }{ S_{ 2 n } } \amp = \inf_{ n \in \N }{ S_{ 2 n } } \amp \lim_{ n \to \infty }{ S_{ 2 n + 1 } } = \sup_{ n \in \N }{ S_{ 2 n + 1 } } \end{align*}
    by the Monotone convergence theorem. Since
    \begin{align*} \lim_{ n \to \infty }{ \abs{ S_{ 2 n + 1 } - S_{ 2 n } } } \amp = \lim_{ n \to \infty }{ \abs{ \sum_{ k = 0 }^{ 2 n + 1 }{ \of{ -1 }^{ k } x_{ k } } - \sum_{ k = 0 }^{ 2 n }{ \of{ -1 }^{ k } x_{ k } } } }\\ \amp = \lim_{ n \to \infty }{ \abs{ \of{ -1 }^{ 2 n + 1 } x_{ 2 n + 1 } } } = \lim_{ n \to \infty }{ x_{ 2 n + 1 } } = 0\text{,} \end{align*}
    \(\of{ S_{ 2 n } }_{ n = 0 }^{ \infty } \) cannot diverge to \(-\infty \) and \(\of{ S_{ 2 n + 1 } }_{ n = 0 }^{ \infty } \) cannot diverge to \(\infty \text{.}\) Thus these sequences converge. The above computation also imply that these subsequences have the same limit, and so \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) converges; that is, the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \of{ -1 }^{ n } x_{ n } } = \lim_{ n \to \infty }{ S_{ n } } \end{equation*}
    converges.
    🔗
    🔗

    Example 7.2.8. Applying the Alternating series test.

    Consider a positive real number \(0 \lt p \lt \infty \) and the series
    \begin{equation*} \sum_{ n = 1 }^{ \infty }{ \frac{ \of{ -1 }^{ n } }{ n^{ p } } }\text{.} \end{equation*}
    Since \(\frac{ 1 }{ n^{ p } } \) is decreasing and converges to \(0 \text{,}\) the Alternating series test implies that the above series converges.
    🔗
    🔗
    We will see that when \(0 \lt p \leq 1 \text{,}\) the series introduced in Example 7.2.8 Applying the Alternating series test are conditionally convergent; that is, these series are convergent but not absolutely convergent. The Alternating series test. The case \(p = 1 \) is of particular importance; it is called the alternating harmonic series.
    🔗
    🔗

    Subsection 7.2.2 Comparison with Known Quantities

    There are many more series convergence tests which follow from the Direct comparison test. Direct comparisons with series which are well known to converge or diverge can be used to provide additional criteria sufficient to conclude convergence or divergence. The following two examples, the ratio test and the root test, follow in part from direct comparison with geometric series.
    🔗

    Proposition 7.2.9 (Jean Le Rond d’Alembert). Ratio test.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of non-zero real numbers \(x_{ n } \in \R \setminus \set{ 0 } \text{.}\)
    1. If
      \begin{equation*} \limsup_{ n \to \infty }{ \abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } } \lt 1\text{,} \end{equation*}
      then the series \(\sum_{ n = 0 }^{ \infty }{ a_{ n } } \) converges absolutely.
      🔗
      🔗
    2. If
      \begin{equation*} \liminf_{ n \to \infty }{ \abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } } \gt 1\text{,} \end{equation*}
      then the series \(\sum_{ n = 0 }^{ \infty }{ a_{ n } } \) diverges.
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Let \(L = \limsup_{ n \to \infty }{ \abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } } \lt 1 \text{,}\) and consider the positive real number
      \begin{equation*} r = \frac{ L + 1 }{ 2 } = L + \frac{ 1 - L }{ 2 } \lt 1 \end{equation*}
      Then there is a natural number \(m \in \N \) so that \(\abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } \leq r \) for all indices \(n \geq m \text{.}\) In particular, we see that
      \begin{equation*} 0 \leq \abs{ a_{ n } } \leq \of{ \frac{ \abs{ a_{ m } } }{ r^{ m } } } r^{ n } \end{equation*}
      for all indices \(n \geq m \text{.}\) The Direct comparison test now implies that the series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ a_{ n } } } \end{equation*}
      converges, and so the series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a_{ n } } \end{equation*}
      converges absolutely by Corollary 7.2.4 Absolute convergence implies convergence.
      🔗
      🔗
    2. Let \(L = \liminf_{ n \to \infty }{ \abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } } \gt 1 \text{,}\) and consider the positive real number
      \begin{equation*} r = \frac{ L + 1 }{ 2 } = L - \frac{ L - 1 }{ 2 } \gt 1\text{.} \end{equation*}
      Then there is a natural number \(m \in \N \) so that \(\abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } \geq r \) for all indices \(n \geq m \text{.}\) In particular, we see that
      \begin{equation*} \abs{ a_{ n } } \geq \of{ \frac{ \abs{ a_{ m } } }{ r^{ m } } } r^{ n } \geq \frac{ \abs{ a_{ m } } }{ r^{ m } } \end{equation*}
      for all indices \(n \geq m \text{,}\) and so the sequence \(\of{ a_{ n } }_{ n = 0 }^{ \infty } \) does not converge to \(0 \text{.}\) We conclude by Proposition 7.1.5 Convergent series have convergent terms implies that the series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a_{ n } } \end{equation*}
      diverges.
      🔗
      🔗
    🔗

    Example 7.2.10. Applying the ratio test.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be the sequence of real numbers \(x_{ n } \in \R \) defined by the formula
    \begin{equation*} x_{ n } = \frac{ 1 }{ n! }\text{.} \end{equation*}
    We observe that
    \begin{align*} \limsup_{ n \to \infty }{ \abs{ \frac{ x_{ n + 1 } }{ x_{ n } } } } \amp = \limsup_{ n \to \infty }{ \frac{ \frac{ 1 }{ \of{ n + 1 }! } }{ \frac{ 1 }{ n! } } } = \limsup_{ n \to \infty }{ \frac{ n! }{ \of{ n + 1 }! } }\\ \amp = \limsup_{ n \to \infty }{ \frac{ 1 }{ n + 1 } } = 0 \lt 1\text{.} \end{align*}
    The Ratio test now implies that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely.
    🔗
    🔗
    Since the Ratio test is not always conclusive, we might try to seek out stronger convergence/divergence tests for series. The root test is one such result.
    🔗

    Proposition 7.2.11 (Augustin-Louis Cauchy). Root test.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers, and let
    \begin{equation*} C = \limsup_{ n \to \infty }{ \sqrt[ n ]{ \abs{ x_{ n } } } }\text{.} \end{equation*}
    If \(C \lt 1 \text{,}\) then the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{equation*}
    converges absolutely. On the other hand, if \(C \gt 1 \text{,}\) then this series diverges.
    🔗
    🔗

    Proof.
    Let \(r = \frac{ C + 1 }{ 2 } \text{.}\) If \(C \lt 1 \text{,}\) then
    \begin{equation*} C \lt r \lt 1\text{.} \end{equation*}
    Thus there is a natural number \(m \in \N \) so that \(\sqrt[ n ]{ \abs{ x_{ n } } } \leq r \) for all indices \(n \geq m \text{.}\) We observe that
    \begin{equation*} 0 \leq \abs{ x_{ n } } = \of{ \sqrt[ n ]{ \abs{ x_{ n } } } }^{ n } \leq r^{ n } \end{equation*}
    for all indices \(n \geq m \text{.}\) The Direct comparison test now implies that the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \end{equation*}
    converges, since we compare with the geometric series \(\sum_{ n = 0 }^{ \infty }{ r^{ n } } \text{.}\) Corollary 7.2.4 Absolute convergence implies convergence now implies that the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
    converges absolutely.
    🔗
    On the other hand, if \(C \gt 1 \text{,}\) then
    \begin{equation*} 1 \lt r \lt C\text{.} \end{equation*}
    Thus there are infinitely many indices \(n \in \N \) so that \(\sqrt[ n ]{ \abs{ x_{ n } } } \geq r \gt 1 \text{.}\) In particular, \(\abs{ x_{ n } } \geq r \gt 1 \) for infinitely many indices \(n \in \N \text{,}\) and so the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) does not converge to \(0 \text{.}\) Thus Proposition 7.1.5 Convergent series have convergent terms implies that the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
    diverges.
    🔗
    🔗
    If the Root test makes a conclusion about the convergence/divergence of a given series, then so will the Ratio test. However, the converse implication is not true; the series in the following example is easily addressed by the Root test, but the Ratio test would not be of any use.
    🔗

    Example 7.2.12. Applying the Root test.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be the sequence of real numbers \(x_{ n } \in \R \) defined piecewise by the formula
    \begin{equation*} x_{ n } = \begin{cases} \frac{ 1 }{ 2^{ n } } \amp n \textrm{ is even} \\ \frac{ 1 }{ 3^{ n } } \amp n \textrm{ is odd} \text{.}\end{cases} \end{equation*}
    We observe that
    \begin{equation*} \sqrt[ n ]{ \abs{ x_{ n } } } = \sqrt[ n ]{ x_{ n } } = \begin{cases} \frac{ 1 }{ 2 } \amp n \textrm{ is even} \\ \frac{ 1 }{ 3 } \amp n \textrm{ is odd} \end{cases} \end{equation*}
    for all indices \(n \in \N \text{,}\) and so
    \begin{equation*} \limsup_{ n \to \infty }{ \sqrt[ n ]{ \abs{ x_{ n } } } } = \frac{ 1 }{ 2 } \lt 1\text{.} \end{equation*}
    The Root test now implies that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely.
    🔗
    🔗
    We can also compare infinite series with improper integrals. We present the following result without proof:
    🔗

    Theorem 7.2.13 (Colin Maclaurin; Augustin-Louis Cauchy). Integral test.

    Let \(f \colon \clopint{ a }{ \infty } \to \clopint{ 0 }{ \infty } \) be a continuous and non-increasing non-negative real-valued function defined on the half-closed, half-open interval \(\clopint{ a }{ \infty } \text{.}\) Then the series
    \begin{equation*} \sum_{ n = a }^{ \infty }{ f \of{ n } } \end{equation*}
    converges if and only if the improper integral
    \begin{equation*} \int_{ a }^{ \infty }{ f \of{ x } \, \diff{ x } } \end{equation*}
    converges.
    🔗
    🔗

    Example 7.2.14. \(p \) series.

    The \(p \)-series associated to a positive real number \(0 \lt p \lt \infty \) is the series
    \begin{equation*} \sum_{ n = 1 }^{ \infty }{ \frac{ 1 }{ n^{ p } } }\text{.} \end{equation*}
    Together with Example 6.3.8 Improper Riemann integration, the Integral test implies that the \(p \)-series converges when \(p \gt 1 \) and diverges to \(\infty \) when \(0 \lt p \leq 1 \text{.}\) This fact is sometimes called the \(p \)-test.
    🔗
    🔗
    The \(p \)-series introduced in Example 7.2.14 \(p \) series are ubiquitous, and the values of such convergent series are related to the Riemann zeta function. Of particular importance is the harmonic series, which is the divergent \(p \)-series obtained in the case \(p = 1 \text{.}\)
