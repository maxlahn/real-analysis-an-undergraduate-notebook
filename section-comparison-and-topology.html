    Section 4.2 Comparison and Topology

    In this section, we will explore the relationships between topology and order theory. We will explore the order-theoretic properties of the partial order on the set of topologies on a fixed set, and we will explore ways of generating topologies by specifying some (but not necessarily all) open sets. Finally we will explore some natural topologies inherited by any totally ordered set.
    🔗

    Subsection 4.2.1 The Lattice of Topologies

    We now investigate the structure of the collection of topologies on a given set. As a subcollection of the second power set, this collection of topologies inherits a partial order by containment \(\subseteq \text{.}\) Much of this section will be devoted to exploring the order-theoretic properties of this partially ordered set. In particular, we will see that any collection of topologies has a unique supremum and infimum in this partially ordered set, and therefore that any collection of subsets of a set generates a unique topology.
    🔗

    Definition 4.2.1. Comparison of topologies.

    Denote by \(\Topol_{ X } \subseteq \ps \of{ \ps \of{ X } } \) the set of topologies on a set \(X \text{.}\) \(\Topol_{ X } \) is partially ordered by containment, and the partially ordered set \(\of{ \Topol_{ X } , \subseteq } \) is called the lattice of topologies on \(X \text{.}\)
    • Coarsening.
      For all topologies \(\tau_{ 1 } , \tau_{ 2 } \in \Topol_{ X } \) on \(X \text{,}\) if \(\tau_{ 1 } \subseteq \tau_{ 2 } \text{,}\) then we say that \(\tau_{ 1 } \) is coarser than \(\tau_{ 2 } \text{,}\) or equivalently that \(\tau_{ 1 } \) is a coarsening of \(\tau_{ 2 } \text{.}\)
      🔗
      Similarly, if \(\tau_{ 1 } \subsetneq \tau_{ 2 } \text{,}\) then we say that \(\tau_{ 1 } \) is strictly coarser than \(\tau_{ 2 } \text{,}\) or equivalently that \(\tau_{ 1 } \) is a strict coarsening of \(\tau_{ 2 } \text{.}\)
      🔗
      🔗
    • Refinement.
      For all topologies \(\tau_{ 1 } , \tau_{ 2 } \in \Topol_{ X } \) on \(X \text{,}\) if \(\tau_{ 1 } \supseteq \tau_{ 2 } \text{,}\) then we say that \(\tau_{ 1 } \) is finer than \(\tau_{ 2 } \text{,}\) or equivalently that \(\tau_{ 1 } \) is a refinement of \(\tau_{ 2 } \text{.}\)
      🔗
      Similarly, if \(\tau_{ 1 } \supsetneq \tau_{ 2 } \text{,}\) then we say that \(\tau_{ 1 } \) is strictly finer than \(\tau_{ 2 } \text{,}\) or equivalently that \(\tau_{ 1 } \) is a strict refinement of \(\tau_{ 2 } \text{.}\)
      🔗
      🔗
    🔗
    🔗
    We will eventually see that any collection of topologies on a given set has a unique supremum and infimum in the partial order of topological comparison. More easy to see, however, is that the lattice of topologies on that set itself has a maximum and minimum; any topology is coarser than the discrete topology and finer than the indiscrete topology. This justifies our use of the “top” and “bottom” notation for the discrete topology \(\top_{ X } \) and the indiscrete topology \(\bot_{ X } \) on a set \(X \text{;}\) in the lattice \(\Topol_{ X } \) of topologies on \(X \text{,}\) \(\top_{ X } \) and \(\bot_{ X } \) are the maximum and minimum elements, respectively.
    🔗

    Lemma 4.2.2. Bounds on topologies.

    The lattice of topologies on a set is bounded as a partially ordered set.
    🔗
    🔗

    Proof.
    Consider the lattice \(\Topol_{ X } \) of topologies on a set \(X \text{.}\) We observe that
    \begin{equation*} \bot_{ X } = \set{ \emptyset , X } \subseteq \tau \subseteq \ps \of{ X } = \top_{ X } \end{equation*}
    for all topologies \(\tau \in \Topol_{ X } \text{,}\) and so \(\Topol_{ X } \) is bounded from above and below.
    🔗
    🔗
    As stated previously, we will show that any collection of topologies on a given set has a supremum and a infimum with respect to the partial order by containment. Since the intersection of a collection of topologies on a set is also a topology on that set, the existence of the greatest lower bound, or meet, of such a collection of topologies is easy to show.
    🔗

    Lemma 4.2.3. Intersection of topologies.

    The intersection of a collection of topologies on a set is a topology.
    🔗
    🔗

    Proof.
    Let \(\of{ \tau_{ j } }_{ j \in \mathcal{ J } } \) be an indexed family of topologies \(\tau_{ j } \in \Topol_{ X } \) on a set \(X \text{,}\) and let
    \begin{equation*} \tau = \bigcap_{ j \in \mathcal{ J } }{ \tau_{ j } } \end{equation*}
    be the intersection. Since \(\emptyset , X \in \tau_{ j } \) for each index \(j \in \mathcal{ J } \text{,}\) \(\emptyset , X \in \tau \text{;}\) that is, \(\tau \) is non-degenerate.
    🔗
    Now let \(\of{ U_{ k } }_{ k \in \mathcal{ K } } \) be an indexed family of sets \(U_{ k } \in \tau \text{.}\) We observe that \(U_{ k } \in \tau_{ j } \) for all indices \(j \in \mathcal{ J } \) and \(k \in \mathcal{ K } \text{,}\) and so the stability of each \(\tau_{ j } \) under unions implies that
    \begin{equation*} \bigcup_{ k \in \mathcal{ K } }{ U_{ k } } \in \tau_{ j } \end{equation*}
    for each index \(j \in \mathcal{ J } \text{.}\) Since this holds for all indices \(j \in \mathcal{ J } \text{,}\)
    \begin{equation*} \bigcup_{ k \in \mathcal{ K } }{ U_{ k } } \in \tau\text{;} \end{equation*}
    that is, \(\tau \) is stable under unions.
    🔗
    Finally let \(\of{ U_{ k } }_{ k = 1 }^{ n } \) be a finite sequence of sets \(U_{ k } \in \tau \text{.}\) We observe that \(U_{ k } \in \tau_{ j } \) for all indices \(j \in \mathcal{ J } \) and \(1 \leq k \leq n \text{,}\) and so the stability of each \(\tau_{ j } \) under finite intersection implies that
    \begin{equation*} \bigcap_{ k = 1 }^{ n }{ U_{ k } } \in \tau_{ j } \end{equation*}
    for each index \(j \in \mathcal{ J } \text{.}\) Since this holds for all indices \(j \in \mathcal{ J } \text{,}\)
    \begin{equation*} \bigcup_{ k = 1 }^{ n }{ U_{ k } } \in \tau\text{;} \end{equation*}
    that is, \(\tau \) is stable under finite intersections.
    🔗
    Since \(\tau \) is non-degenerate, stable under unions, and stable under finite intersections, it is a topology on \(X \text{.}\)
    🔗
    🔗
    Since the intersection of sets is the infimum in the partial order by containment, we will see that Lemma 4.2.3 Intersection of topologies implies that the intersection of topologies is also the infimum in the partial order of topological comparison. That is, the intersection of a collection of topologies on a set is the finest common coarsening.
    🔗
    It might seem plausible that the dual notion of union might provide us with a supremum of such a collection with respect to topological comparison. Unfortunately, this is not the case; the union of topologies on a set is not, in general, also a topology on that set. However, there is a unique coarsest common refinement of such a collection. In order to show that this is the case, we need to investigate the ways in which collections of subsets of a set which may not themselves be topologies may generate a topology on that set.
    🔗

    Definition 4.2.4. Generated topology.

    A collection \(\mathcal{ S } \subseteq \ps \of{ X } \) of subsets of a set \(X \) is called a subbase of a topology \(\tau \) (and its elements are called subbasic open sets) on \(X \) if \(\tau \) is the coarsest topology on \(X \) which contains \(\mathcal{ S } \text{;}\) that is, \(\mathcal{ S } \) is a subbase for \(\tau \) if every topology on \(X \) which contains \(\mathcal{ S } \) is a refinement of \(\tau \text{.}\)
    🔗
    Every collection \(\mathcal{ S } \subseteq \ps \of{ X } \) of subsets of a set \(X \) is a subbase of a unique topology
    \begin{equation*} \gen{ \mathcal{ S } } = \bigcap_{ S \subseteq \tau \in \Topol_{ X } }{ \tau } \end{equation*}
    on \(X \) called the topology generated by \(\mathcal{ S } \text{.}\)
    🔗
    🔗

    Example 4.2.5. Subbases.

    The following are examples of subbases of topologies:
    • The metric topology \(\tau_{ \rho } \) induced on a set \(X \) by a metric \(\rho \colon X \times X \to \R \) is generated by the collection of metric open balls; that is,
      \begin{equation*} \tau_{ \rho } = \gen{ \setmid{ \mB_{ r } \of{ x } \in \ps \of{ X } }{ r \gt 0 \textrm{ and } x \in X } }\text{.} \end{equation*}
      🔗
      🔗
    • The indiscrete topology \(\bot_{ X } \) on a set \(X \) is generated by the empty set \(\emptyset \text{;}\) that is, \(\bot_{ X } = \gen{ \emptyset } \text{.}\)
      🔗
      🔗
    • The discrete topology \(\top_{ X } \) on a set \(X \) is generated by the singleton sets \(\setmid{ \set{ x } \in \ps \of{ X } }{ x \in X } \text{;}\) that is,
      \begin{equation*} \top_{ X } = \gen{ \setmid{ \set{ x } \in \ps \of{ X } }{ x \in X } }\text{.} \end{equation*}
      🔗
      🔗
    • Let \(\of{ \of{ X_{ j } , \tau_{ j } } }_{ j \in \mathcal{ J } } \) be an indexed family of topological spaces \(\of{ X_{ j } , \tau_{ j } } \text{.}\) The box topology is the topology
      \begin{equation*} \tau = \gen{ \setmid{ \prod_{ j \in \mathcal{ J } }{ U_{ j } } \in \ps \of{ \prod_{ j \in \mathcal{ J } }{ X_{ j } } } }{ \of{ U_{ j } }_{ j \in \mathcal{ J } } \in \prod_{ j \in \mathcal{ J } }{ \tau_{ j } } } } \end{equation*}
      on the Cartesian product \(\prod_{ j \in \mathcal{ J } }{ X_{ j } } \) of the ground sets generated by products of open sets.
      🔗
      We will see that if the index set \(\mathcal{ J } \) is infinite, then the box topology described above is too fine to be of use. In Section 4.4 Continuity, we will introduce the dual notions of initial and final topologies to give natural topologies on sets constructed from the ground sets of topological spaces, including via Cartesian products, disjoint unions, and quotients.
      🔗
      🔗
    🔗
    🔗
    The concept of generated topologies will now allow us to show that the lattice of topologies on a given set is a complete lattice. That is, any collection of topologies has a unique least upper bound and a unique greatest lower bound.
    🔗

    Theorem 4.2.6. Complete lattice of topologies.

    The lattice \(\Topol_{ X } \) of topologies on a set \(X \) is a complete lattice; that is, any collection \(\mathcal{ S } \subseteq \Topol_{ X } \) of topologies on \(X \) has a unique supremum and infimum.
    🔗
    🔗

    Proof.
    Let \(\mathcal{ S } \subseteq \Topol_{ X } \) be a collection of topologies on a set \(X \text{.}\) Since the intersection
    \begin{equation*} \bigcap_{ \tau \in \mathcal{ S } }{ \tau } \end{equation*}
    is an infimum for \(\mathcal{ S } \) in the partially ordered set \(\of{ \ps \of{ \ps \of{ X } } , \subseteq } \text{,}\) it is an infimum for \(\mathcal{ S } \) in \(\of{ \Topol_{ X } , \subseteq } \text{;}\) that is, this intersection is the finest common coarsening of the topologies in \(\mathcal{ S } \text{.}\) It therefore suffices to show that \(\mathcal{ S } \) has a supremum.
    🔗
    To that end, let
    \begin{equation*} \sigma = \gen{ \bigcup_{ \tau \in \mathcal{ S } }{ \tau } } \end{equation*}
    be the topology on \(X \) generated by the union of all topologies in \(\mathcal{ S } \text{.}\) Then \(\sigma \) is a common refinement of each topology in \(\mathcal{ S } \text{.}\) Moreover, if \(\sigma' \in \Topol_{ X } \) is a common refinement of each topology in \(\mathcal{ S } \text{,}\) then it contains the union of all such topologies, and therefore is a refinement of \(\tau \text{.}\) Thus \(\sigma \) is an infimum for \(\mathcal{ S } \) in \(\of{ \Topol_{ X } , \subseteq } \text{;}\) that is, this intersection is the coarsest common refinement of the topologies in \(\mathcal{ S } \text{.}\)
    🔗
    🔗
    So the lattice of topologies on any given set is in fact a complete lattice under the partial order of containment, where infima are intersections and suprema are the topologies generated by unions. The following alternative characterization of subbases of topology will be useful for specifying certain nice subbases.
    🔗

    Lemma 4.2.7. Subbases of topology.

    A collection \(\mathcal{ S } \subseteq \ps \of{ X } \) of subsets of a set \(X \) is a subbase of a topology \(\tau \) if and only if for every point \(x \in U \) in every open set \(U \in \tau \text{,}\)
    \begin{equation*} x \in \bigcap_{ k = 1 }^{ n }{ S_{ k } } \subseteq U \end{equation*}
    for some finite sequence \(\of{ S_{ k } }_{ k = 1 }^{ n } \) of subbasic open sets \(S_{ k } \in \mathcal{ S } \text{.}\)
    🔗
    🔗
    You will have an opportunity to prove Lemma 4.2.7 Subbases of topology in the problems for this section. For the rest of this section, we will explore the properties of certain nice subbases of topologies known as bases, which can be said to capture the point-set topology of a given topological space.
