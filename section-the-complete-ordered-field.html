    Section 2.3 The Complete Ordered Field

    In the previous section, we gave an explicit and detailed construction of the real number system \(\R \text{.}\) In this section, we give an alternative and non-constructive characterization of \(\R \) as the unique Dedekind complete ordered field. This will set the stage for abandoning the Dedekind cut perspective in favor of an abstract conception of the properties of the real number system.
    🔗

    Subsection 2.3.1 The Ordered Field Axioms

    We begin by revisiting the properties of the arithmetic of Dedekind cuts collected in Section 2.2 Constructing the Real Numbers. These properties define an algebraic object called a field.
    🔗

    Definition 2.3.1. Field.

    Let \(+ \) and \(\cdot \) be binary operations on a set \(F \text{,}\) called addition and multiplication. The ordered triple \(\of{ F , + , \cdot } \) is called a field if the binary operations satisfy the following conditions:
    • Commutativity of addition.
      \(x + y = y + x \) for all elements \(x , y \in F \text{.}\)
      🔗
      🔗
    • Associativity of addition.
      \(\of{ x + y } + z = x + \of{ y + z } \) for all elements \(x , y , z \in F \text{.}\)
      🔗
      🔗
    • Additive identity element.
      There is an element \(0 \in F \) so that \(x + 0 = 0 + x = x \) for all elements \(x \in F \text{.}\)
      🔗
      🔗
    • Additive inverses.
      For all elements \(x \in X \text{,}\) there is an element \(-x \in F \) called the additive inverse of \(x \) so that \(x + \of{ -x } = \of{ -x } + x = 0 \text{.}\)
      🔗
      🔗
    • Commutativity of multiplication.
      \(x \cdot y = y \cdot x \) for all elements \(x , y \in F \text{.}\)
      🔗
      🔗
    • Associativity of addition.
      \(\of{ x \cdot y } \cdot z = x \cdot \of{ y \cdot z } \) for all elements \(x , y , z \in F \text{.}\)
      🔗
      🔗
    • Multiplicative identity element.
      There is an element \(1 \in F \setminus \set{ 0 } \) so that \(x \cdot 1 = 1 \cdot x = x \) for all elements \(x \in F \text{.}\)
      🔗
      🔗
    • Multiplicative inverses.
      For all elements \(x \in X \text{,}\) if \(x \neq 0 \) then there is an element \(x^{ -1 } \in F \) called the multiplicative inverse of \(x \) so that \(x \cdot x^{ -1 } = x^{ -1 } \cdot x = 1 \text{.}\)
      🔗
      🔗
    • Distributivity of multiplication over addition.
      \(x \cdot \of{ y + z } = \of{ x \cdot y } + \of{ x \cdot z } \) and \(\of{ x + y } \cdot z = \of{ x \cdot z } + y \cdot z \) for all elements \(x , y , z \in F \text{.}\)
      🔗
      🔗
    If \(\of{ F , + , \cdot } \) is a field, then the set \(F \) is called its ground set or underlying set. If the binary operations \(+ \) and \(\cdot \) are clear from context, then we will usually abuse notation and refer to a field by the ground set alone.
    🔗
    🔗

    Example 2.3.2. Fields.

    The following are examples of fields:
    • The field of rational numbers.
      Addition \(+ \) and multiplication \(\cdot \) of rational numbers satisfies the above field axioms, and so \(\Q \) is a field.
      🔗
      🔗
    • The field of real numbers.
      Addition \(+ \) and multiplication \(\cdot \) of real numbers satisfies the above field axioms by Theorem 2.2.15 Arithmetic of Dedekind cuts, and so \(\R \) is a field.
      🔗
      🔗
    • The field of rational functions.
      Let \(n \in \N \) be a natural number, and fix real numbers \(x_{ 1 } , \dots c, x_{ n } \in \R \text{.}\) A real-valued function \(f \colon \R \setminus \set{ x_{ 1 } , \dotsc , x_{ n } } \to \R \) is called a rational function if it has a formula of the form
      \begin{equation*} f \of{ x } = \frac{ p \of{ x } }{ q \of{ x } } \end{equation*}
      for some polynomials \(p \of{ x } \) and \(q \of{ x } \text{.}\) Such a rational function \(f \of{ x } \) has a removable discontinuity at \(x_{ k } \) if both \(p \of{ x } \) and \(q \of{ x } \) have a root at \(x = x_{ k } \text{,}\) and the corresponding factor \(\of{ x - x_{ k } } \) appears at least as many times in the factorization of \(p \of{ x } \) as it does in the factorization of \(q \of{ x } \text{.}\)
      🔗
      The set of rational functions without removable discontinuities is denoted \(\R \of{ x } \text{.}\) One can verify that the addition and multiplication of these rational functions satisfies the field axioms, and so \(\R \of{ x } \) is a field.
      🔗
      🔗
    🔗
    🔗
    We have seen that the fields \(\Q \) and \(\R \) of rational and real numbers are equipped with additional structure beyond that of arithmetic: we can compare rational numbers and real numbers by the standard orders \(\leq \) on \(\Q \) and \(\R \text{,}\) respectively. These are total orders, and we have seen they are compatible with arithmetic in key ways. Generalizing these relationships, we arrive at the notion of an ordered field.
    🔗

    Definition 2.3.3. Ordered field.

    Let \(+ \) and \(\cdot \) be binary operations on a set \(F \text{,}\) called addition and multiplication, and consider a binary relation \(\leq \) on \(F \text{,}\) called comparison. The ordered quadruple \(\of{ F , + , \cdot , \leq } \) is called an ordered field if it satisfies the following conditions:
    • The ordered triple \(\of{ F , + , \cdot } \) is a field.
      🔗
      🔗
    • The ordered pair \(\of{ F , \leq } \) is a totally ordered set.
      🔗
      🔗
    • Compatibility of addition and comparison.
      For all elements \(x , y , z \in F \text{,}\) if \(x \leq y \text{,}\) then \(x + z \leq y + z \text{.}\)
      🔗
      🔗
    • Compatibility of multiplication and comparison.
      For all elements \(x , y \in F \text{,}\) if \(0 \leq x \) and \(0 \leq y \text{,}\) then \(0 \leq x \cdot y \text{.}\)
      🔗
      🔗
    If \(\of{ F , + , \cdot , \leq } \) is an ordered field, then the set \(F \) is called its ground set or underlying set. If the binary operations \(+ \) and \(\cdot \) and the binary relation \(\leq \) are clear from context, then we will usually refer to an ordered field by the ground set alone.
    🔗
    🔗

    Example 2.3.4. Ordered fields.

    The following are examples of ordered fields:
    • The ordered field of rational numbers.
      Addition \(+ \text{,}\) multiplication \(\cdot \text{,}\) and comparison \(\leq \) of rational numbers satisfies the above ordered field axioms, and so \(\Q \) is an ordered field.
      🔗
      🔗
    • The ordered field of real numbers.
      Addition \(+ \text{,}\) multiplication \(\cdot \text{,}\) and comparison \(\leq \) of rational numbers satisfies the above ordered field axioms by Theorem 2.2.15 Arithmetic of Dedekind cuts, and so \(\R \) is an ordered field.
      🔗
      🔗
    🔗
    🔗
    That the above list of examples includes both the rational numbers \(\Q \) and the real numbers \(\R \) begs the question: Why bother with the real numbers \(\R \text{,}\) when the rational numbers \(\Q \) are already an ordered field?
    🔗
    🔗

    Subsection 2.3.2 Dedekind completeness

    So far, we have failed to meaningfully distinguish between the properties enjoyed by the rational number system \(\Q \) and the real number system \(\R \text{.}\) We now address this issue via the notion of Dedekind completeness. Informally, Dedekind completeness is defined in terms of the set of upper bounds of a subset which is bounded from above (or dually the set of lower bounds of a subset which is bounded from below).
    🔗

    Definition 2.3.5. Supremum; infimum.

    Let \(U \subseteq X \) be a subset of a partially ordered set \(\of{ X , \preceq } \text{.}\)
    • Supremum.
      If the set of upper bounds for \(U \) in \(X \) has a minimum, then this minimum is called the supremum (or least upper bound) of \(U \) and is denoted \(\sup \of{ U } \text{;}\) that is,
      \begin{equation*} \sup \of{ U } = \min \of{ \setmid{ x \in X }{ u \leq x \textrm{ for all } u \in U } }\text{.} \end{equation*}
      🔗
      🔗
    • Infimum.
      If the set of lower bounds for \(U \) in \(X \) has a maximum, then this maximum is called the infimum (or greatest lower bound) of \(U \) and is denoted \(\inf \of{ U } \text{;}\) that is,
      \begin{equation*} \inf \of{ U } = \max \of{ \setmid{ x \in X }{ x \leq u \textrm{ for all } u \in U } }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Example 2.3.6. Suprema and infima.

    Let \(\of{ U_{ j } }_{ j \in \mathcal{ J } } \) be an indexed family of subsets \(U_{ j } \subseteq X \) of a set \(X \text{.}\) These subsets \(U_{ j } \) are elements of the power set \(\ps \of{ X } \text{,}\) which is partially ordered by set containment \(\subseteq \text{.}\)
    🔗
    We may reinterpret (a) of Problem 1.2.5.5 Indexed intersections and unions as saying that the indexed intersection \(\bigcap_{ j \in \mathcal{ J } }{ U_{ j } } \) and the indexed union \(\bigcup_{ j \in \mathcal{ J } }{ U_{ j } } \) are the infimum and supremum of \(\set{ U_{ j } }_{ j \in \mathcal{ J } } \text{.}\)
    🔗
    🔗

    Remark 2.3.7. Suprema of Dedekind cuts.

    The complement \(\Q \setminus X \) of a Dedekind cut \(X \in \R \) is exactly the set of upper bounds of \(X \) in \(\Q \text{,}\) and so Lemma 2.2.3 Rational Dedekind cuts implies that \(X \) is rational if and only if it has a supremum in \(\Q \text{.}\)
    🔗
    This is the deficiency of the rational numbers \(\Q \) from the analytic perspective: Proposition 2.2.4 Irrational Dedekind cuts posits the existence of subsets of \(\Q \) which are bounded from above and yet do not have suprema. We will shortly see that this is not the case in the real number system \(\R \text{.}\)
    🔗
    🔗

    Definition 2.3.8. Dedekind completeness.

    An ordered field \(\of{ F , + , \cdot , \leq } \) is called Dedekind complete if every non-empty subset of \(F \) which is bounded from above has a supremum.
    🔗
    🔗

    Theorem 2.3.9. Dedekind completeness of the real numbers.

    The real number system \(\of{ \R , + , \cdot , \leq } \) is Dedekind complete.
    🔗
    🔗

    Proof.
    Let \(\emptyset \subsetneq U \subseteq \R \) be a non-empty subset of \(U \) which is bounded from above, and consider the indexed union
    \begin{equation*} S = \bigcup_{ X \in U }{ X } = \setmid{ q \in \Q }{ q \in X \textrm{ for some } X \in U }\text{.} \end{equation*}
    Since \(U \) is a non-empty collection of non-empty subsets of \(\Q \text{,}\) \(S \) is non-empty. Moreover, since \(U \) is bounded from above, there is some Dedekind cut \(Y \in \R \) so that \(X \subseteq Y \) for all \(X \in U \text{.}\) In particular, if \(q \in \Q \setminus Y \text{,}\) then \(q \notin X \) for all \(X \in U \text{,}\) and so \(q \notin S \text{.}\)
    🔗
    Let \(p , q \in \Q \) be rational numbers, and suppose that \(p \leq q \) and \(q \in S \text{.}\) Since \(q \in S \text{,}\) \(q \in X \) for some \(X \in U \text{,}\) and so \(p \in X \subseteq S \text{.}\)
    🔗
    Now let \(p \in S \text{,}\) so that \(p \in X \) for some \(X \in U \text{.}\) Since \(X \) does not have a maximum, there is some rational number \(q \in X \subseteq S \) so that \(p \lt q \text{.}\) We conclude that \(S \) does not have a maximum, and so is a Dedekind cut.
    🔗
    We note that (a) of Problem 1.2.5.5 Indexed intersections and unions implies that for a Dedekind cut \(Y \in \R \text{,}\) \(S \subseteq Y \) if and only if \(X \subseteq Y \) for all \(X \in U \text{;}\) that is, any upper bound for \(U \) in \(\R \) contains \(S \text{,}\) so that
    \begin{equation*} S = \min \of{ \setmid{ Y \in \R }{ X \subseteq Y \textrm{ for all } X \in U } } = \sup \of{ U }\text{.} \end{equation*}
    🔗
    🔗
    We will see that Theorem 2.3.9 Dedekind completeness of the real numbers has far-reaching consequences for the discipline of real analysis, most notably in the existence of limits for certain objects constructed out of the real numbers \(\R \text{.}\) First, however, we present the following non-constructive characterization of \(\R \) as the unique Dedekind complete ordered field.
    🔗

    Theorem 2.3.10. Uniqueness of the real numbers.

    If \(\of{ F , + , \cdot , \leq } \) is a Dedekind complete ordered field, then there is a bijection \(\varphi \colon \R \to F \) so that for all real numbers \(x , y \in \R \text{,}\) \(\varphi \of{ x + y } = \varphi \of{ x } + \varphi \of{ y } \text{,}\) \(\varphi \of{ x \cdot y } = \varphi \of{ x } \cdot \varphi \of{ y } \text{,}\) and if \(x \leq y \text{,}\) then \(\varphi \of{ x } \leq \varphi \of{ y } \text{.}\)
    🔗
    🔗
    With Theorem 2.3.10 Uniqueness of the real numbers, we are now ready to shake off the burden of viewing the real number system \(\R \) through the perspective of Dedekind cuts. All relevant properties of the analysis of real numbers can be derived abstractly from the axioms of a Dedekind complete ordered field, and as a consequence, we will see that we no longer need to rely on any specific formal model of \(\R \text{.}\)
    🔗
    🔗
    In the next section, we will construct various extensions of the real number system \(\R \text{.}\) In particular, we will see the extended real numbers, the complex numbers, and the quaternions.
