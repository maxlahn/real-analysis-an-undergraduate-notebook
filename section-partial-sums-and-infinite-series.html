    Section 7.1 Partial Sums and Infinite Series

    We begin by developing a notion of convergence and divergence for series of real numbers. These ideas build directly on the convergence and divergence of sequences of real numbers. In fact, a series converges/diverges if and only if an associated sequence of real numbers does.
    🔗

    Subsection 7.1.1 Infinitely Iterated Sums

    Because the sum of two real numbers is itself a real number (that is, addition is a binary relation on \(\R \)), the sum of three (or four, or five, or six) real numbers is also a real number. In fact, we can add together any finite sequence of real numbers and obtain a real number. If we instead start with an infinite sequence of real numbers, we can thus form a sequence whose \(n \)th entry is the sum of the first \(n \) numbers.
    🔗

    Definition 7.1.1. Series.

    The series associated to a sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } \in \R \) called terms is a formal expression of the form
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{equation*}
    For each index \(n \in \N \text{,}\) the \(n \)th partial sum \(S_{ n } \) is the finite sum
    \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ k } }\text{,} \end{equation*}
    and the \(n \)th tail \(T_{ n } \) is the series
    \begin{equation*} T_{ n } = \sum_{ k = n + 1 }^{ \infty }{ x_{ k } } = \sum_{ k = 0 }^{ \infty }{ x_{ k + n + 1 } }\text{.} \end{equation*}
    🔗
    🔗

    Example 7.1.2. Geometric series.

    A geometric series of initial value \(a \in \R \) and ratio \(r \in \R \) is the series of the form
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } }\text{.} \end{equation*}
    If \(r = 1 \text{,}\) then the partial sums of such a geometric series are
    \begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ a r^{ k } } = a + a r + a r^{ 2 } + \dotsb + a r^{ n }\\ \amp = a + a + a + \dotsb + a = a \of{ n + 1 } \end{align*}
    On the other hand, if \(r \neq 1 \text{,}\) then we claim that the partial sums of such a geometric series are
    \begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ a r^{ k } } = a + a r + a r^{ 2 } + \dotsb + a r^{ n }\\ \amp = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r }\text{.} \end{align*}
    We can verify this computation by induction on \(n \in \N \text{.}\) Indeed, for the base case \(n = 0 \text{,}\) we see that
    \begin{align*} S_{ n } \amp = S_{ 0 } = \sum_{ k = 0 }^{ 0 }{ a r^{ k } } = a r^{ 0 } = a \\ \amp = a \of{ \frac{ 1 - r }{ 1 - r } } = \frac{ a \of{ 1 - r^{ 1 } } }{ 1 - r } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r }\text{.} \end{align*}
    For the inductive step, suppose that
    \begin{equation*} S_{ n } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } \end{equation*}
    for some index \(n \in \N \text{.}\) We now observe that
    \begin{align*} S_{ n + 1 } \amp = \sum_{ k = 0 }^{ n + 1 }{ a r^{ k } } = \sum_{ k = 0 }^{ n }{ a r^{ k } } + a r^{ n + 1 } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } + a r^{ n + 1 }\\ \amp = \frac{ a \of{ 1 - r^{ n + 1 } } + a r^{ n + 1 } \of{ 1 - r } }{ 1 - r }\\ \amp = \frac{ a - a r^{ n + 1 } + a r^{ n + 1 } - a r^{ n + 2 } }{ 1 - r }\\ \amp = \frac{ a - a r^{ n + 2 } }{ 1 - r } = \frac{ a \of{ 1 - r^{ \of{ n + 1 } + 1 } } }{ 1 - r }\text{.} \end{align*}
    🔗
    🔗

    Definition 7.1.3. Series convergence/divergence.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ m } \in \R \text{,}\) and consider the associated series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{.}\)
    • Series convergence.
      The series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges to a real number \(S \in \R \) if the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) of partial sums
      \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ k } } \end{equation*}
      converges to \(S \text{.}\) In this case, we call \(S \) the value of the series, and write
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } = S = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ k } } }\text{.} \end{equation*}
      🔗
      🔗
    • Series divergence.
      The series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) diverges if the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) of partial sums
      \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ k } } \end{equation*}
      diverges.
      🔗
      A special case of series divergence is series divergence to infinity. If the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(\pm \infty \text{,}\) then we write
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } = \pm \infty = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ k } } }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Example 7.1.4. Series convergence/divergence.

    Consider the geometric series \(\sum_{ n = 0 }^{ \infty }{ a r^{ n } } \) of initial value \(a \in \R \) and ratio \(r \in \R \text{,}\) and let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) be the sequence of partial sums
    \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ a r^{ k } }\text{.} \end{equation*}
    We will see that the convergence or divergence of this geometric series depends on both \(a \) and \(r \text{.}\)
    • We first observe that if \(a = 0 \text{,}\) then
      \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ a r^{ k } } = \sum_{ k = 0 }^{ n }{ 0 } = 0 \end{equation*}
      for all indices \(n \in \N \text{,}\) and so
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \lim_{ n \to \infty }{ 0 } = 0\text{.} \end{equation*}
      🔗
      🔗
    • Now suppose that \(a \neq 0 \) and \(r = 0 \text{.}\) Then
      \begin{equation*} S_{ n } = a \end{equation*}
      for all indices \(n \in \N \text{,}\) and so
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \lim_{ n \to \infty }{ a } = a\text{.} \end{equation*}
      🔗
      🔗
    • Now suppose that \(a \neq 0 \) and \(0 \lt \abs{ r } \lt 1 \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. The Archimedean principle implies that
      \begin{equation*} n_{ \epsilon } \gt \frac{ \ln \of{ \epsilon } + \ln \of{ 1 - r } }{ \ln \of{ \abs{ r } } } - 1 \end{equation*}
      for some natural number \(n_{ \epsilon } \in \N \text{.}\) We observe that
      \begin{align*} \abs{ S_{ n } - \frac{ a }{ 1 - r } } \amp = \abs{ \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } - \frac{ a }{ 1 - r } } = \frac{ \abs{ -r^{ n + 1 } } }{ \abs{ 1 - r } }\\ \amp = \frac{ \abs{ r }^{ n + 1 } }{ 1 - r } \leq \frac{ \abs{ r }^{ n_{ \epsilon } + 1 } }{ 1 - r } \lt \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) Thus the geometric series converges to
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \frac{ a }{ 1 - r }\text{.} \end{equation*}
      🔗
      🔗
    • Now suppose that \(a \gt 0 \) and \(r = 1 \text{.}\) Let \(B \in \R \) be a real number. The Archimedean principle implies that
      \begin{equation*} n_{ B } \gt \frac{ B }{ a } - 1 \end{equation*}
      for some natural number \(n_{ B } \in \N \text{.}\) We observe
      \begin{equation*} S_{ n } = \of{ n + 1 } a \geq \of{ n_{ B } + 1 } a \gt B \end{equation*}
      for all indices \(n \geq n_{ B } \text{.}\) Thus the geometric series diverges to \(\infty \text{;}\) that is,
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \infty\text{.} \end{equation*}
      🔗
      🔗
    • Now suppose that \(a \lt 0 \) and \(r = 1 \text{.}\) Let \(B \in \R \) be a real number. The Archimedean principle implies that
      \begin{equation*} n_{ B } \gt \frac{ B }{ a } - 1 \end{equation*}
      for some natural number \(n_{ B } \in \N \text{.}\) We observe
      \begin{equation*} S_{ n } = \of{ n + 1 } a \leq \of{ n_{ B } + 1 } a \lt B \end{equation*}
      for all indices \(n \geq n_{ B } \text{.}\) Thus the geometric series diverges to \(-\infty \text{;}\) that is,
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = -\infty\text{.} \end{equation*}
      🔗
      🔗
    • Now suppose that \(a \neq 0 \) and \(r = -1 \text{.}\) Then the geometric series has partial sums
      \begin{align*} S_{ n } \amp = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } = \frac{ a \of{ 1 - \of{ -1 }^{ n + 1 } } }{ 1 - \of{ -1 } } = \frac{ a \of{ 1 + \of{ -1 }^{ n + 1 } } }{ 2 }\\ \amp = \begin{cases} a \amp n \textrm{ is even} \\ 0 \amp n \textrm{ is odd} \end{cases} \end{align*}
      🔗
      🔗
    • Now suppose that \(a \gt 0 \) and \(r \gt 1 \text{.}\) Let \(B \in \R \) be a real number. The Archimedean principle implies that
      \begin{equation*} n_{ B } \gt \frac{ \ln \of{ a - B \of{ 1 - r } } - \ln \of{ a } }{ \ln \of{ r } } - 1 \end{equation*}
      for some natural number \(n_{ B } \in \N \text{.}\) We observe that
      \begin{equation*} S_{ n } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } \geq \frac{ a \of{ 1 - r^{ n_{ B } + 1 } } }{ 1 - r } \gt B \end{equation*}
      for all indices \(n \geq n_{ B } \text{.}\) Thus the geometric series diverges to \(\infty \text{;}\) that is,
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \infty\text{.} \end{equation*}
      🔗
      🔗
    • Now suppose that \(a \lt 0 \) and \(r \gt 1 \text{.}\) Let \(B \in \R \) be a real number. The Archimedean principle implies that
      \begin{equation*} n_{ B } \gt \frac{ \ln \of{ a - B \of{ 1 - r } } - \ln \of{ a } }{ \ln \of{ r } } - 1 \end{equation*}
      for some natural number \(n_{ B } \in \N \text{.}\) We observe that
      \begin{equation*} S_{ n } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } \leq \frac{ a \of{ 1 - r^{ n_{ B } + 1 } } }{ 1 - r } \lt B \end{equation*}
      for all indices \(n \geq n_{ B } \text{.}\) Thus the geometric series diverges to \(\infty \text{;}\) that is,
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = -\infty\text{.} \end{equation*}
      🔗
      🔗
    • Finally, suppose that \(a \neq 0 \) and \(r \lt -1 \text{.}\) We observe that
      \begin{equation*} \abs{ S_{ n + 1 } - S_{ n } } = \abs{ \sum_{ k = 0 }^{ n + 1 }{ a r^{ k } } - \sum_{ k = 0 }^{ n }{ a r^{ k } } } = \abs{ a r^{ n + 1 } } = \abs{ a } \abs{ r }^{ n + 1 } \geq 1 \end{equation*}
      for any index \(n \in \N \) so that
      \begin{equation*} n \geq -\frac{ \ln \of{ \abs{ a } } }{ \ln \of{ \abs{ r } } } - 1\text{.} \end{equation*}
      In particular, this implies that the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) cannot be Cauchy, and therefore cannot converge. So the geometric series diverges.
      🔗
      🔗
    To summarize, the geometric series \(\sum_{ n = 0 }^{ \infty }{ a r^{ n } } \) converges if and only if \(a = 0 \) or \(\abs{ r } \lt 1 \text{.}\)
    🔗
    🔗
    Several of the ideas presented above in Example 7.1.4 Series convergence/divergence can be generalized to help determine the convergence or divergence behavior of more general series. For example, the sequence of partial sums cannot be Cauchy unless the sequence of terms converges to \(0 \text{.}\)
    🔗

    Proposition 7.1.5. Convergent series have convergent terms.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\) If the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
    converges, then \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(0 \text{.}\)
    🔗
    🔗

    Proof.
    By contraposition. Suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{.}\) Then there is a positive real number \(\epsilon \gt 0 \) so that \(\abs{ x_{ n } - 0 } \geq \epsilon \) for infinitely many natural numbers \(n \in \N \text{.}\) Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) be the sequence of partial sums
    \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ n } }\text{.} \end{equation*}
    For any positive integer \(n \geq 1 \) so that \(\abs{ x_{ n } - 0 } \geq \epsilon \text{,}\) we observe that
    \begin{align*} \abs{ S_{ n } - S_{ n - 1 } } \amp = \abs{ \sum_{ k = 0 }^{ n }{ x_{ k } } - \sum_{ k = 0 }^{ n - 1 }{ x_{ k } } } = \abs{ x_{ n } }\\ \amp = \abs{ x_{ n } - 0 } \geq \epsilon\text{.} \end{align*}
    Since this occurs for infinitely many positive integers \(n \geq 1 \text{,}\) we conclude that the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) cannot be Cauchy. Proposition 3.6.3 Convergent sequences are Cauchy now implies that \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and therefore the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{,}\) diverges.
    🔗
    🔗
    Series convergence behaves well under termwise arithmetic. In particular, we may add convergent series term by term or scale a convergent series by a real number, and the convergent of the series is preserved.
    🔗

    Proposition 7.1.6. Arithmetic of convergent series.

    1. Addition of convergent series.
      Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) and \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converge, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } + y_{ n } } \text{,}\) and
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } + y_{ n } } = \sum_{ n = 0 }^{ \infty }{ x_{ n } } + \sum_{ n = 0 }^{ \infty }{ y_{ n } }\text{.} \end{equation*}
      🔗
      🔗
    2. Scalar multiplication of convergent series.
      Let \(c \in \R \) be a real number and \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ c x_{ n } } \text{,}\) and
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ c x_{ n } } = c \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{equation*}
      🔗
      🔗
    🔗

    Proof.
    1. Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ T_{ n } }_{ n = 0 }^{ \infty } \) be the sequences of partial sums
      \begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ k } } \amp T_{ n } \amp = \sum_{ k = 0 }^{ n }{ y_{ k } }\text{,} \end{align*}
      and denote by \(X \) and \(Y \) the corresponding values of the series
      \begin{align*} X \amp = \sum_{ n = 0 }^{ \infty }{ x_{ n } } = \lim_{ n \to \infty }{ S_{ n } }\\ Y \amp = \sum_{ n = 0 }^{ \infty }{ y_{ n } } = \lim_{ n \to \infty }{ T_{ n } }\text{.} \end{align*}
      Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that
      \begin{equation*} \abs{ S_{ n } - X } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      and
      \begin{equation*} \abs{ T_{ n } - Y } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We observe that
      \begin{align*} \abs{ \sum_{ k = 0 }^{ n }{ x_{ k } + y_{ k } } - \of{ X + Y } } \amp = \abs{ S_{ n } + T_{ n } - X - Y } \leq \abs{ S_{ n } - X } + \abs{ T_{ n } - Y }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } + y_{ n } } \) converges to
      \begin{align*} \sum_{ n = 0 }^{ \infty }{ x_{ n } + y_{ n } } \amp = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ n } + y_{ n } } } = X + Y\\ \amp = \sum_{ n = 0 }^{ \infty }{ x_{ n } } + \sum_{ n = 0 }^{ \infty }{ y_{ n } }\text{.} \end{align*}
      🔗
      🔗
    2. If \(c = 0 \text{,}\) then
      \begin{equation*} \sum_{ k = 0 }^{ n }{ c x_{ k } } = \sum_{ k = 0 }^{ n }{ 0 } = 0 \end{equation*}
      for all indices \(n \in \N \text{,}\) and so
      \begin{align*} \sum_{ n = 0 }^{ \infty }{ c x_{ n } } \amp = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ c x_{ k } } } = \lim_{ n \to \infty }{ 0 } = 0\\ \amp = 0 \sum_{ n = 0 }^{ \infty }{ x_{ n } } = c \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{align*}
      🔗
      We may therefore assume that \(c \neq 0 \text{.}\) Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) be the sequence of partial sums
      \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ k } }\text{,} \end{equation*}
      and denote by \(X \) the corresponding value of the series
      \begin{equation*} X = \sum_{ n = 0 }^{ \infty }{ x_{ n } } = \lim_{ n \to \infty }{ S_{ n } }\text{.} \end{equation*}
      Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that
      \begin{equation*} \abs{ S_{ n } - X } \lt \frac{ \epsilon }{ \abs{ c } } \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We observe that
      \begin{align*} \abs{ \sum_{ k = 0 }^{ n }{ c x_{ k } } - \of{ c X } } \amp = \abs{ c S_{ n } - c X } = \abs{ c } \abs{ S_{ n } - X }\\ \amp \lt \abs{ c } \of{ \frac{ \epsilon }{ \abs{ c } } } = \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that the series \(\sum_{ n = 0 }^{ \infty }{ c x_{ n } } \) converges to
      \begin{align*} \sum_{ n = 0 }^{ \infty }{ c x_{ n } } \amp = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ c x_{ n } } } = c X\\ \amp = c \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{align*}
      🔗
      🔗
    🔗
    We will also see that termwise multiplication of convergent series produces convergent series. In order to prove this, we will require additional sufficient criteria for series convergence developed in Section 7.2 Tests for Series Convergence. We can, however, compare convergent series by comparing their terms.
    🔗

    Lemma 7.1.7. Comparison of convergent series.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{.}\) If \(x_{ n } \leq y_{ n } \) for all indices \(n \in \N \) and the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) and \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converge, then
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \leq \sum_{ n = 0 }^{ \infty }{ y_{ n } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ T_{ n } }_{ n = 0 }^{ \infty } \) be the sequences of partial sums
    \begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ k } } \amp T_{ n } \amp = \sum_{ k = 0 }^{ n }{ y_{ k } }\text{.} \end{align*}
    Since \(x_{ k } \leq y_{ k } \) for each index \(0 \leq k \leq n \text{,}\) \(S_{ n } \leq T_{ n } \text{.}\) We conclude that
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } = \lim_{ n \to \infty }{ S_{ n } } \leq \lim_{ n \to \infty }{ T_{ n } } = \sum_{ n = 0 }^{ \infty }{ y_{ n } } \end{equation*}
    by Proposition 3.3.2 Comparison of limits.
    🔗

    Subsection 7.1.2 Rearrangements of Infinite Series

    While the commutativity and associativity of addition imply that the order in which one adds up a finite sequence of real numbers does not matter, the same is not always the case for infinite series of real numbers. We will see that the convergence/divergence behavior of certain sequences can be meaningfully affected by rearranging their terms, but other sequences cannot be tampered with in this way.
    🔗

    Definition 7.1.8. Positive/negative part.

    • Positive part.
      The positive part \(x^{ + } \) of a real number \(x \in \R \) is the non-negative real number
      \begin{equation*} x^{ + } = \max \of{ \set{ x , 0 } }\text{.} \end{equation*}
      Similarly, the positive part of a series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) is the series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } = \sum_{ n = 0 }^{ \infty }{ \max \of{ \set{ x , 0 } } }\text{.} \end{equation*}
      🔗
      🔗
    • Negative part.
      The negative part \(x^{ - } \) of a real number \(x \in \R \) is the non-positive real number
      \begin{equation*} x^{ - } = -\min \of{ \set{ x , 0 } } = \max \of{ \set{ -x , 0 } } = \of{ -x }^{ + }\text{.} \end{equation*}
      Similarly, the negative part of a series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) is the series
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ -\min \of{ \set{ x , 0 } } }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    The positive and negative parts of a real number are closely related to its absolute value.
    🔗

    Lemma 7.1.9. Positive/negative parts and magnitude.

    \(x = x^{ + } - x^{ - } \) and \(\abs{ x } = x^{ + } + x^{ - } \) for any real number \(x \in \R \) with positive part \(x^{ + } \geq 0 \) and negative part \(x^{ - } \leq 0 \text{.}\)
    🔗
    🔗

    Proof.
    First suppose that \(x = 0 \text{.}\) Then
    \begin{align*} x^{ + } \amp = \max \of{ \set{ x , 0 } } = \max \of{ \set{ 0 } } = 0\\ x^{ - } \amp = -\min \of{ \set{ x , 0 } } = -\min \of{ \set{ 0 } } = -0 = 0\text{,} \end{align*}
    and so
    \begin{align*} x^{ + } - x^{ - } \amp = 0 - 0 = 0 = x\\ x^{ + } + x^{ - } \amp = 0 + 0 = 0 = \abs{ 0 } = \abs{ x }\text{.} \end{align*}
    🔗
    Now suppose that \(x \gt 0 \) is positive. Then
    \begin{align*} x^{ + } \amp = \max \of{ \set{ x , 0 } } = x\\ x^{ - } \amp = -\min \of{ \set{ x , 0 } } = -0 = 0\text{,} \end{align*}
    and so
    \begin{align*} x^{ + } - x^{ - } \amp = x - 0 = x\\ x^{ + } + x^{ - } \amp = x + 0 = x = \abs{ x }\text{.} \end{align*}
    🔗
    Now suppose that \(x \lt 0 \) is positive. Then
    \begin{align*} x^{ + } \amp = \max \of{ \set{ x , 0 } } = 0\\ x^{ - } \amp = -\min \of{ \set{ x , 0 } } = -x\text{,} \end{align*}
    and so
    \begin{align*} x^{ + } - x^{ - } \amp = 0 - \of{ -x } = x\\ x^{ + } + x^{ - } \amp = 0 + \of{ -x } = -x = \abs{ x }\text{.} \end{align*}
    🔗
    🔗
    If a series of real numbers converges, then the convergence or divergence behavior of its positive and negative parts are not unrelated. The following result establishes a dichotomy of behavior based on whether or not these related series converge or diverge.
    🔗

    Proposition 7.1.10. Absolute/conditional series convergence.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\) If the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
    converges, then its positive and negative parts either both converge, in which case the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \end{equation*}
    converges, or they both diverge to \(\infty \text{,}\) in which case the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \end{equation*}
    diverges to \(\infty \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\of{ P_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ N_{ n } }_{ n = 0 }^{ \infty } \) be the sequences of partial sums
    \begin{align*} P_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ n }^{ + } } \amp N_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ n }^{ - } }\text{.} \end{align*}
    Since both \(x^{ + } \) and \(x^{ - } \) are non-negative for any real number \(x \in \R \text{,}\) we observe that
    \begin{align*} P_{ n + 1 } \amp = \sum_{ k = 0 }^{ n + 1 }{ x_{ k }^{ + } } = \sum_{ k = 0 }^{ n }{ x_{ k }^{ + } } + x_{ n + 1 }^{ + } \geq P_{ n }\\ N_{ n + 1 } \amp = \sum_{ k = 0 }^{ n + 1 }{ x_{ k }^{ - } } = \sum_{ k = 0 }^{ n }{ x_{ k }^{ - } } + x_{ n + 1 }^{ - } \geq N_{ n }\text{;} \end{align*}
    that is, the partial sums \(\of{ P_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ N_{ n } }_{ n = 0 }^{ \infty } \) are non-decreasing. The Monotone convergence theorem now implies that
    \begin{align*} \lim_{ n \to \infty }{ P_{ n } } \amp = \sup_{ n \in \N }{ P_{ n } } \amp \lim_{ n \to \infty }{ N_{ n } } \amp = \sup_{ n \in \N }{ N_{ n } }\text{.} \end{align*}
    In particular, each of the positive and negative parts \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } \) and \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \) either converges or diverges to \(\infty \text{.}\) It remains to show only that one cannot converge while the other diverges to \(\infty \text{.}\)
    🔗
    To that end, we first note that if the positive part \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } \) converges, then Lemma 7.1.9 Positive/negative parts and magnitude and Proposition 7.1.6 Arithmetic of convergent series imply that
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } - x_{ n } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } - \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
    converges, in which case
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } + x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } + \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \end{equation*}
    converges by another application of Lemma 7.1.9 Positive/negative parts and magnitude and (1) of Proposition 7.1.6 Arithmetic of convergent series.
    🔗
    Finally, we note that if the negative part \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \) converges, then Lemma 7.1.9 Positive/negative parts and magnitude and (1) of Proposition 7.1.6 Arithmetic of convergent series imply that
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } = \sum_{ n = 0 }^{ \infty }{ x_{ n } + x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ x_{ n } } + \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \end{equation*}
    converges, in which case
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } + x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } + \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \end{equation*}
    converges by another application of Lemma 7.1.9 Positive/negative parts and magnitude and (1) of Proposition 7.1.6 Arithmetic of convergent series.
    🔗
    🔗
    The dichotomy produced by Proposition 7.1.10 Absolute/conditional series convergence is important enough to be named. A convergent series is called absolutely convergent if its positive and negative parts converge, and conditionally convergent if its positive and negative parts diverge to \(\infty \text{.}\)
    🔗

    Definition 7.1.11. Absolute/conditional series convergence.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\)
    • Absolute convergence.
      The series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely if any two of the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{,}\) \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } \text{,}\) \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \text{,}\) and \(\sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \) converge, in which case they all converge.
      🔗
      🔗
    • Conditional convergence.
      The series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges conditionally if the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges but any of these series \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } \text{,}\) \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \text{,}\) and \(\sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \) diverge to \(\infty \text{,}\) in which case they all diverge to \(\infty \text{.}\)
      🔗
      🔗
    🔗
    🔗
    We will be able to provide many examples of conditionally convergent and absolutely convergent series after establishing more convergence tests in Section 7.2 Tests for Series Convergence.
    🔗
    One of the foundational results in real analysis is concerned with the limiting behavior of conditionally convergent series. We present the following result without proof:
    🔗

    Theorem 7.1.12 (Bernhard Riemann). Rearrangement theorem.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and suppose that the associated series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
    converges.
    1. If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely, then
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ \varphi \of{ n } } } = \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
      for all bijections \(\varphi \colon \N \to \N \text{.}\)
      🔗
      🔗
    2. If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges conditionally, then for any extended real numbers \(-\infty \leq a \leq b \leq \infty \text{,}\) there is a bijection \(\varphi \colon \N \to \N \) so that
      \begin{align*} \liminf_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ \varphi \of{ n } } } } \amp = a \amp \limsup_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ \varphi \of{ n } } } } \amp = b\text{.} \end{align*}
      In particular, for any extended real number \(-\infty \leq c \leq \infty \text{,}\) there is a bijection \(\varphi \colon \N \to \N \) so that
      \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ \varphi \of{ n } } } = c\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗
    One way to interpret Rearrangement theorem is that conditionally convergent series are only convergent because the terms are ordered in such a way to cancel in a particular way, and that we may change the convergence/divergence behavior of such a series in almost any way solely by rearranging the terms. On the other hand, the convergence behavior of absolutely convergent series is completely unaffected by rearrangements.
