    Section 3.4 Open and Closed Sets

    In this section, we generalize the notion of open and closed intervals to subsets of arbitrary metric spaces. Recall that the open interval \(\opint{ a }{ b } \) between two real numbers \(a , b \in \R \) is the subset of the real numbers \(\R \) defined as follows.
    \begin{equation*} \opint{ a }{ b } = \set{ x \in \R : a \lt x \lt b } \subsetneq \R\text{.} \end{equation*}
    Similarly, the closed interval \(\clint{ a }{ b } \) between two real numbers \(a , b \in \R \) is the subset of the real numbers \(\R \) defined as follows.
    \begin{equation*} \clint{ a }{ b } = \set{ x \in \R : a \leq x \leq b } \subsetneq \R\text{.} \end{equation*}
    Soon, we will develop the more general notion of the open and closed subsets of a metric space, which will play a crucial role in the remainder of this text.
    🔗

    Subsection 3.4.1 Neighborhoods in Metric Spaces

    Informally, a subset of a metric space is open if it contains all points which are close to its elements and closed if it contains all of its limit points. These are one of many provably equivalent definitions of openness and closedness. In order to formalize this, we make the following preliminary definitions.
    🔗

    Definition 3.4.1. Open ball; closed disk; sphere.

    Fix a positive real number \(r \gt 0 \) and a point \(c \in X \) in a metric space \(\of{ X , \rho } \text{.}\)
    • Open metric ball.
      The open (metric) ball \(\mB_{ r } \of{ c } \) in \(X \) of radius \(r \) and center \(c \) is the subset of \(X \) defined by
      \begin{equation*} \mB_{ r } \of{ c } = \setmid{ x \in X }{ \rho \of{ x , c } \lt r }\text{.} \end{equation*}
      🔗
      🔗
    • Closed metric disk.
      The closed (metric) disk \(\mD_{ r } \of{ c } \) in \(X \) of radius \(r \) and center \(c \) is the subset of \(X \) defined by
      \begin{equation*} \mD_{ r } \of{ c } = \setmid{ x \in X }{ \rho \of{ x , c } \leq r }\text{.} \end{equation*}
      🔗
      🔗
    • Open metric ball.
      The (metric) sphere \(\mS_{ r } \of{ c } \) in \(X \) of radius \(r \) and center \(c \) is the subset of \(X \) defined by
      \begin{equation*} \mS_{ r } \of{ c } = \setmid{ x \in X }{ \rho \of{ x , c } = r }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗
    So an open ball contains precisely the points of distance strictly less than its radius from its center; a closed disk contains precisely the points of distance at most its radius from its center; and a sphere contains precisely the points of distance precisely its radius from its center. Just as the difference between an open and a closed interval is the question of the inclusion of its endpoints, the distinction between open balls and closed disks is that a closed disk contains all points of distance precisely its radius from its center, while an open ball does not.
    🔗
    We will see that in many ways, this section is an investigation of the properties of subsets of metric spaces which contain or are contained in certain open balls. The following definition, that of a neighborhood, will be a useful notion for both the rest of this chapter and the next chapter as well. Informally, a subset of a metric space is a neighborhood of a point if it contains all points which are very close to that point.
    🔗

    Definition 3.4.2. Neighborhood.

    A subset \(U \subseteq X \) is a neighborhood of a point \(x \in X \) in a metric space \(\of{ X , \rho } \) if \(U \) contains an open ball centered at \(x \text{;}\) that is, \(U \) is a neighborhood of \(x \) if \(\mB_{ r } \of{ x } \subseteq U \) for some positive real number \(r \gt 0 \text{.}\)
    🔗
    🔗

    Example 3.4.3. Neighborhoods.

    Every open ball and closed disk in a metric space is a neighborhood of its center.
    🔗
    🔗

    Remark 3.4.4. Locality.

    The notion of a neighborhood is our latest exposure to the conceptual metaphor of locality. We conceive of metric spaces by spatial reasoning, saying for example that for points \(x , y \in X \) in a metric space \(\of{ X , \rho } \text{,}\) if \(\rho \of{ x , y } \) is a small positive number, then \(x \) and \(y \) are “close”.
    🔗
    This idea is pervasive throughout point-set topology, and it implicitly informs much of the relevant terminology. Just as your neighborhood contains all of the people closest to where you live, a neighborhood in a metric space contains all nearby points.
    🔗
    🔗
    We now have the terminology to make the crucial and titular definitions of this section; that of open and closed subsets of a metric space. A subset of a metric space is open if it is a neighborhood of all of its points, and is closed if its complement is open.
    🔗

    Definition 3.4.5. Open/closed subset.

    Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{.}\)
    • Open subset.
      \(U \) is open in \(X \) if it is a neighborhood of each of its points; that is, \(U \) is open if for each point \(u \in U \text{,}\) there is a positive real number \(r \gt 0 \) so that \(\mB_{ r } \of{ u } \subseteq U \text{.}\)
      🔗
      🔗
    • Closed subset.
      \(U \) is closed in \(X \) if its complement \(X \setminus U \) is open in \(X \text{;}\) that is, \(U \) is closed if each point \(x \in X \setminus U \) has a neighborhood in \(X \) which is disjoint from \(U \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Lemma 3.4.6. Open balls and closed disks.

    Open balls in metric spaces are open, and closed disks are closed.
    🔗
    🔗

    Proof.
    Fix a positive real number \(r \gt 0 \) and a point \(c \in X \) in a metric space \(\of{ X , \rho } \text{.}\) Let \(U = \mB_{ r } \of{ c } \) and \(V = \mD_{ r } \of{ c } \) be the open ball and closed disk of radius \(r \) and center \(c \text{,}\) respectively. We will show that \(U \) and \(V \) are open and closed in \(X \text{,}\) respectively.
    🔗
    To that end, first let \(u \in U \text{,}\) so that \(\rho \of{ u , c } \lt r \text{.}\) Let
    \begin{equation*} s = r - \rho \of{ u , c }\text{.} \end{equation*}
    We note that for a point \(x \in X \text{,}\) if \(\rho \of{ x , u } \lt s \text{,}\) then
    \begin{align*} \rho \of{ x , c } \amp \leq \rho \of{ x , u } + \rho \of{ u , c } \lt s + r\\ \amp = r - \rho \of{ u , c } + \rho \of{ u , c } = r\text{,} \end{align*}
    and so \(x \in U \text{.}\) Thus \(\mB_{ s } \of{ u } \subseteq \mB_{ r } \of{ c } = U \text{.}\) Since \(U \) contains an open ball centered at each of its points, it is a neighborhood of each of its points, and so \(U \) is open in \(X \text{.}\)
    🔗
    On the other hand, now suppose that \(x \in X \setminus V \text{,}\) so that \(\rho \of{ x , c } \gt r \text{.}\) Let
    \begin{equation*} s = \rho \of{ x , c } - r\text{.} \end{equation*}
    We note that for a point \(y \in X \text{,}\) if \(\rho \of{ y , x } \lt s \text{,}\) then
    \begin{align*} r + s \amp = \rho \of{ x , c } \leq \rho \of{ x , y } + \rho \of{ y , c }\\ \amp = \rho \of{ y , x } + \rho \of{ y , c } \lt s + \rho \of{ y , c }\text{.} \end{align*}
    We conclude that \(\rho \of{ y , c } \gt r \text{,}\) and so \(y \notin \mD_{ r } \of{ c } = V \text{.}\) Since \(X \setminus V \) contains an open ball centered at each of its points, it is a neighborhood of each of its points, and so \(X \setminus V \) is open in \(X \text{;}\) that is, \(V \) is closed in \(X \text{.}\)
    🔗
    🔗
    Lemma 3.4.6 Open balls and closed disks illustrates that the names “open” and “closed” for balls and disks are well-deserved; open balls and closed disks in a metric space are open and closed, respectively. This immediately implies that open intervals and closed intervals of real numbers (with finite endpoints) are open and closed, respectively, in the Euclidean metric, since any such interval is either a open ball or a closed disk (depending on whether or not it includes its endpoints) around its center, which is the arithmetic mean of its endpoints.
    🔗
    We next develop a series of point-set topological definitions based on the notion of neighborhoods which will play an important role in both this and the next chapter. Given a subset of a metric space, we may consider open or closed sets which approximate the set as well as possible from the inside or outside, respectively.
    🔗

    Definition 3.4.7. Interior; closure; boundary.

    Fix a subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \text{.}\)
    • Interior.
      A point \(x \in X \) is an interior point of \(U \) if \(U \) is a neighborhood of \(x \text{.}\) The set of interior points of \(U \) is called the interior of \(U \) and is denoted \(\Int \of{ U } \) or \(U^{ \circ } \text{.}\)
      🔗
      🔗
    • Closure.
      A point \(x \in X \) is called a point of closure of \(U \) in \(X \) if \(N \cap U \neq \emptyset \) for all neighborhoods \(N \) of \(x \) in \(X \text{.}\) The set of points of closure of \(U \) in \(X \) is called the closure of \(U \) in \(X \) and is denoted \(\Cl \of{ U } \) or \(\overline{ U } \text{.}\)
      🔗
      🔗
    • Boundary.
      A point \(x \in X \) is called a boundary point of \(U \) in \(X \) if \(N \cap U \neq \emptyset \) and \(N \setminus U \neq \emptyset \) for all neighborhoods \(N \) of \(x \) in \(X \text{.}\) The set of all boundary points of \(U \) in \(X \) is called the boundary of \(U \) in \(X \) and is denoted \(\Bd \of{ U } \) or \(\partial U \text{.}\)
      🔗
      🔗
    🔗
    🔗
    The above definitions are equivalent if we quantify over open balls centered at the point in question rather than over neighborhoods of said point. However, the notion of neighborhood will extend into our discussion in Chapter 4 Topological Spaces, so we will continue in this spirit of generality, which we hope will ease our generalization of the above notions.
    🔗

    Example 3.4.8. Interior, closure, and boundary.

    Consider the half-closed, half-open interval
    \begin{equation*} \clopint{ 0 }{ 1 } = \setmid{ x \in \R }{ 0 \leq x \lt 1 } \end{equation*}
    of real numbers between \(0 \) and \(1 \text{.}\)
    • Interior.
      \(\clopint{ 0 }{ 1 } \) has interior the open interval
      \begin{equation*} \Int \of{ \clopint{ 0 }{ 1 } } = \opint{ 0 }{ 1 } = \setmid{ x \in \R }{ 0 \lt x \lt 1 }\text{.} \end{equation*}
      🔗
      🔗
    • Closure.
      \(\clopint{ 0 }{ 1 } \) has closure the closed interval
      \begin{equation*} \Cl \of{ \clopint{ 0 }{ 1 } } = \clint{ 0 }{ 1 } = \setmid{ x \in \R }{ 0 \leq x \leq 1 }\text{.} \end{equation*}
      🔗
      🔗
    • Boundary.
      \(\clopint{ 0 }{ 1 } \) has boundary the set \(\Bd \of{ \clopint{ 0 }{ 1 } } = \set{ 0 , 1 } \text{.}\)
      🔗
      🔗
    🔗
    🔗
    Clearly, a subset of a metric space is open if and only if it is its own interior. Perhaps less obvious, however, is the second half of the following result; a subset of a metric space is closed if and only if it is its own closure.
    🔗

    Proposition 3.4.9. Interior/closure.

    Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{.}\)
    1. Interior.
      \(U \) is open in \(X \) if and only if \(U = \Int \of{ U } \text{.}\)
      🔗
      🔗
    2. Closure.
      \(U \) is closed in \(X \) if and only if \(U = \Cl \of{ U } \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. We first note that for any point \(x \in \Int \of{ U } \text{,}\) there is some neighborhood \(N \) of \(x \) so that \(N \subseteq U \text{.}\) Since \(N \) is a neighborhood of \(x \text{,}\) it contains some open ball \(\mB_{ r } \of{ x } \subseteq N \text{.}\) We conclude that
      \begin{equation*} x \in \mB_{ r } \of{ x } \subseteq N \subseteq U\text{,} \end{equation*}
      and so \(x \in U \text{.}\) We conclude that \(\Int \of{ U } \subseteq U \text{.}\) Therefore, it suffices to show that \(U \) is open in \(X \) if and only if \(U \subseteq \Int \of{ U } \text{.}\)
      🔗
      To that end, we first suppose that \(U \) is open, and let \(u \in U \text{.}\) Then \(U \) is a neighborhood of \(u \) in \(X \text{,}\) and of course \(U \subseteq U \text{.}\) Thus \(u \in \Int \of{ U } \) is an interior point of \(U \text{.}\) We conclude that \(U \subseteq \Int \of{ U } \text{.}\)
      🔗
      Conversely, now suppose that \(U \subseteq \Int \of{ U } \text{,}\) and let \(u \in U \text{.}\) Then \(u \in \Int \of{ U } \text{,}\) and so \(N \subseteq U \) for some neighborhood \(N \) of \(U \) in \(X \text{.}\) Since \(N \) is a neighborhood of \(u \text{,}\) it contains some open ball \(\mB_{ r } \of{ u } \subseteq N \text{.}\) We conclude that
      \begin{equation*} \mB_{ r } \of{ u } \subseteq N \subseteq U\text{,} \end{equation*}
      and so \(U \) is a neighborhood of \(u \) in \(X \text{.}\) Since this holds for all \(u \in U \text{,}\) \(U \) is open in \(X \text{.}\)
      🔗
      🔗
    2. Let \(N \) be a neighborhood of a point \(u \in U \) in \(X \text{.}\) Then \(N \) contains some open ball \(\mB_{ r } \of{ u } \text{,}\) and so
      \begin{equation*} u \in \mB_{ r } \of{ u } \subseteq N\text{.} \end{equation*}
      In particular, \(u \in N \cap U \text{,}\) and so \(N \cap U \neq \emptyset \) is non-empty. Thus \(u \in \Cl \of{ U } \) is a point of closure of \(U \) in \(X \text{.}\) We conclude that \(U \subseteq \Cl \of{ U } \text{.}\) Therefore, it suffices to show that \(U \) is closed in \(X \) if and only if \(\Cl \of{ U } \subseteq U \text{.}\)
      🔗
      To that end, we first suppose that \(U \) is closed, and let \(x \in X \text{.}\) If \(x \in X \setminus U \text{,}\) then our hypothesis that \(U \) is closed implies that \(x \) has a neighborhood \(N \) in \(X \) so that \(N \cap U = \emptyset \text{.}\) This implies that \(x \in X \setminus \Cl \of{ U } \text{.}\) In summary, we have shown that \(X \setminus U \subseteq X \setminus \Cl \of{ U } \text{,}\) and so \(\Cl \of{ U } \subseteq U \text{.}\)
      🔗
      Conversely, now suppose that \(\Cl \of{ U } \subseteq U \text{,}\) and let \(x \in X \setminus U \text{.}\) Then \(x \notin \Cl \of{ U } \) is not a point of closure of \(U \) in \(X \text{,}\) and so \(N \cap U = \emptyset \) for some neighborhood \(N \) of \(x \) in \(X \text{.}\) This implies that \(N \subseteq X \setminus U \text{,}\) and so \(X \setminus U \) is a neighborhood of \(x \) in \(X \text{.}\) Since this holds for all points \(x \in X \setminus U \text{,}\) we conclude that \(X \setminus U \) is open in \(X \text{;}\) that is, \(U \) is closed in \(X \text{.}\)
      🔗
      🔗
    🔗
    So a subset of a metric space is open if and only if it is its own interior, and it is closed if and only if it is its own closure. One consequence of this is that the interior of a subset is open, and the closure of a set is closed. In order to show this, we make the following observation about the behavior of the openness and closedness conditions under the set operations.
    🔗

    Proposition 3.4.10. Topology of a metric space.

    Let \(\of{ X , \rho } \) be a metric space.
    1. The empty set \(\emptyset \) and the ground set \(X \) are both open and closed in \(X \text{.}\)
      🔗
      🔗
    2. The union of any collection of open subsets of \(X \) is itself open in \(X \text{.}\)
      🔗
      🔗
    3. The intersection of any collection of closed subsets of \(X \) is itself closed in \(X \text{.}\)
      🔗
      🔗
    4. The intersection of finitely many open subsets of \(X \) is itself open in \(X \text{.}\)
      🔗
      🔗
    5. The union of finitely many closed subsets of \(X \) is itself closed in \(X \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. The empty set \(\emptyset \) is vacuously a neighborhood of each of its points, and so \(\emptyset \) is open in \(X \text{.}\) On the other hand, let \(x \in X \text{.}\) Then
      \begin{equation*} \mB_{ 1 } \of{ x } = \setmid{ y \in X }{ \rho \of{ y , x } \lt 1 } \subseteq X\text{,} \end{equation*}
      and so \(X \) is a neighborhood of \(x \) in \(X \text{.}\) We conclude that \(X \) is open in \(X \text{.}\)
      🔗
      Since the empty set \(\emptyset \) and the ground set \(X \) are both open in \(X \text{,}\) their complements \(X \setminus \emptyset = X \) and \(X \setminus X = \emptyset \) are closed in \(X \text{.}\)
      🔗
      🔗
    2. Let \(\of{ U_{ j } }_{ j \in \mathcal{ J } } \) be an indexed family of open sets \(U_{ j } \subseteq X \) in \(X \text{,}\) and consider the union
      \begin{equation*} U = \bigcup_{ j \in \mathcal{ J } }{ U_{ j } }\text{.} \end{equation*}
      Let \(u \in U \text{.}\) Then \(u \in U_{ k } \) for some index \(k \in \mathcal{ J } \text{.}\) Since \(U_{ k } \) is open in \(X \text{,}\) it is a neighborhood of \(x \) in \(X \text{,}\) and so \(\mB_{ r } \of{ x } \subseteq U_{ k } \) for some positive real number \(r \gt 0 \text{.}\)
      🔗
      We observe that
      \begin{equation*} \mB_{ r } \of{ x } \subseteq U_{ k } \subseteq \bigcup_{ j \in \mathcal{ J } }{ U_{ j } } = U\text{,} \end{equation*}
      and so \(U \) is a neighborhood of \(u \) in \(X \text{.}\) Since this holds for all points \(u \in U \text{,}\) \(U \) is open in \(X \text{.}\)
      🔗
      🔗
    3. Let \(\of{ U_{ j } }_{ j \in \mathcal{ J } } \) be an indexed family of closed sets \(U_{ j } \subseteq X \) in \(X \text{,}\) and consider the intersection
      \begin{equation*} U = \bigcap_{ j \in \mathcal{ J } }{ U_{ j } }\text{.} \end{equation*}
      Since for each index \(j \in \mathcal{ J } \text{,}\) \(X \setminus U_{ j } \) is open in \(X \text{,}\) (b) above implies that
      \begin{equation*} X \setminus U = X \setminus \bigcap_{ j \in \mathcal{ J } }{ U_{ j } } = \bigcup_{ j \in \mathcal{ J } }{ \of{ X \setminus U_{ j } } } \end{equation*}
      is open in \(X \text{.}\) We conclude that \(U = X \setminus \of{ X \setminus U } \) is closed in \(X \text{.}\)
      🔗
      🔗
    4. Let \(\of{ U_{ j } }_{ j = 1 }^{ m } \) be a finite sequence of open sets \(U_{ j } \subseteq X \) in \(X \text{,}\) and consider the intersection
      \begin{equation*} U = \bigcap_{ j = 1 }^{ m }{ U_{ j } }\text{.} \end{equation*}
      Let \(u \in U \text{,}\) so that \(u \in U_{ j } \) for all indices \(1 \leq j \leq m \text{.}\) For each index \(1 \leq j \leq m \text{,}\) \(U_{ j } \) is open in \(X \text{,}\) and so \(U_{ j } \) is a neighborhood of \(u \) in \(X \text{;}\) that is, \(\mB_{ r_{ j } } \of{ u } \subseteq U_{ j } \text{.}\)
      🔗
      Let \(r = \min_{ 1 \leq j \leq m }{ r_{ j } } \gt 0 \text{,}\) and note that
      \begin{equation*} \mB_{ r } \of{ u } \subseteq \mB_{ r_{ j } } \of{ u } \subseteq U_{ j } \end{equation*}
      for all indices \(1 \leq j \leq m \text{.}\) We conclude that
      \begin{equation*} \mB_{ r } \of{ u } \subseteq \bigcap_{ j = 1 }^{ m }{ U_{ j } } = U\text{,} \end{equation*}
      so that \(U \) is a neighborhood of \(u \) in \(X \text{.}\) Since this holds for all points \(u \in U \text{,}\) \(U \) is open in \(X \text{.}\)
      🔗
      🔗
    5. Let \(\of{ U_{ j } }_{ j = 1 }^{ m } \) be a finite sequence of closed sets \(U_{ j } \subseteq X \) in \(X \text{,}\) and consider the union
      \begin{equation*} U = \bigcup_{ j = 1 }^{ m }{ U_{ j } }\text{.} \end{equation*}
      Since for each index \(1 \leq j \leq m \text{,}\) \(X \setminus U_{ j } \) is open in \(X \text{,}\) (d) above implies that
      \begin{equation*} X \setminus U = X \setminus \bigcup_{ j = 1 }^{ m }{ U_{ j } } = \bigcap_{ j = 1 }^{ m }{ \of{ X \setminus U_{ j } } } \end{equation*}
      is open in \(X \text{.}\) We conclude that \(U = X \setminus \of{ X \setminus U } \) is closed in \(X \text{.}\)
      🔗
      🔗
    🔗
    Along with Proposition 3.4.10 Topology of a metric space, the following result implies that the interior of a subset of a metric space is the largest open set which is contained in it, the closure of such a subset is the smallest closed set in which it is contained.
    🔗

    Theorem 3.4.11. Interior/closure.

    Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{.}\)
    1. Interior.
      \(U \) has interior
      \begin{equation*} \Int \of{ U } = \bigcup_{ V \in \mathcal{ O }_{ U } }{ V }\text{,} \end{equation*}
      where \(\mathcal{ O }_{ U } \) is the collection of open subsets of \(X \) contained in \(U \text{.}\)
      🔗
      🔗
    2. Closure.
      \(U \) has closure
      \begin{equation*} \Cl \of{ U } = \bigcap_{ V \in \mathcal{ C }_{ U } }{ V }\text{,} \end{equation*}
      where \(\mathcal{ C }_{ U } \) is the collection of closed subsets of \(X \) which contain \(U \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Let \(x \in X \text{,}\) and first suppose that \(x \in \Int \of{ U } \) is an interior point to \(U \) in \(X \text{.}\) Then \(U \) is a neighborhood of \(x \) in \(X \text{,}\) and so \(\mB_{ r } \of{ x } \subseteq U \) for some positive real number \(r \gt 0 \text{.}\) Lemma 3.4.6 Open balls and closed disks implies that \(\mB_{ r } \of{ x } \) is open in \(X \text{,}\) and so \(\mB_{ r } \of{ x } \in \mathcal{ O }_{ U } \text{.}\) We conclude that
      \begin{equation*} x \in \mB_{ r } \of{ x } \subseteq \bigcup_{ V \in \mathcal{ O }_{ U } }{ V }\text{.} \end{equation*}
      🔗
      Conversely, now suppose that \(x \in \bigcup_{ V \in \mathcal{ O }_{ U } }{ V } \text{.}\) Then \(u \in V \) for some \(V \in \mathcal{ O }_{ U } \text{.}\) Since \(V \) is open in \(X \text{,}\) it is a neighborhood of \(x \) in \(X \text{,}\) and so \(\mB_{ r } \of{ x } \subseteq V \) for some positive real number \(r \gt 0 \text{.}\) Since
      \begin{equation*} \mB_{ r } \of{ x } \subseteq V \subseteq U\text{,} \end{equation*}
      \(U \) is a neighborhood of \(x \) in \(X \text{;}\) that is, \(x \in \Int \of{ U } \) is an interior point of \(U \) in \(X \text{.}\)
      🔗
      In summary, we have shown that \(x \in \Int \of{ U } \) if and only if \(x \in \bigcup_{ V \in \mathcal{ O }_{ U } }{ V } \text{,}\) and so
      \begin{equation*} \Int \of{ U } = \bigcup_{ V \in \mathcal{ O }_{ U } }{ V }\text{.} \end{equation*}
      🔗
      🔗
    2. Consider an element \(V \in \mathcal{ C }_{ U } \text{,}\) and let \(x \in X \setminus V \text{.}\) Since \(V \) is closed in \(X \text{,}\) \(X \setminus V \) is open in \(X \text{,}\) and so \(X \setminus V \) is a neighborhood of each of its points. Moreover, since \(U \subseteq V \text{,}\) \(\of{ X \setminus V } \cap U = \emptyset \text{,}\) and so none of the points of \(X \setminus V \) are points of closure of \(U \) in \(X \text{;}\) that is, \(X \setminus V \subseteq X \setminus \Cl \of{ U } \text{.}\) We conclude that \(\Cl \of{ U } \subseteq V \text{.}\) Since this holds for all \(V \in C \text{,}\)
      \begin{equation*} \Cl \of{ U } \subseteq \bigcap_{ V \in \mathcal{ C }_{ U } }{ V }\text{.} \end{equation*}
      🔗
      Conversely, now let \(x \in X \setminus \Cl \of{ U } \text{.}\) Then \(N \cap U = \emptyset \) for some neighborhood \(N \) of \(x \) in \(X \text{.}\) In particular, \(\mB_{ r } \of{ x } \cap U = \emptyset \) for some positive real number \(r \gt 0 \text{.}\) Note that \(X \setminus \mB_{ r } \of{ x } \in \mathcal{ C }_{ U } \text{.}\) However, \(x \notin X \setminus \mB_{ r } \of{ x } \text{,}\) and so \(x \notin \bigcap_{ V \in \mathcal{ C }_{ U } }{ V } \text{.}\) We conclude that
      \begin{equation*} \bigcap_{ V \in \mathcal{ C }_{ U } }{ V } \subseteq \Cl \of{ U }\text{,} \end{equation*}
      and so
      \begin{equation*} \Cl \of{ U } = \bigcap_{ V \in \mathcal{ C }_{ U } }{ V } .\text{.} \end{equation*}
      🔗
      🔗
    🔗

    Corollary 3.4.12. Idempotence of interior/closure.

    Let \(\of{ X , \rho } \) be a metric space.
    1. Idempotence of interior.
      \(\Int \of{ \Int \of{ U } } = \Int \of{ U } \) for all subsets \(U \subseteq X \text{.}\)
      🔗
      🔗
    2. Idempotence of closure.
      \(\Cl \of{ \Cl \of{ U } } = \Cl \of{ U } \) for all subsets \(U \subseteq X \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. (1) of Theorem 3.4.11 Interior/closure implies that \(\Int \of{ U } \) is a union of open sets in \(X \text{,}\) and so \(\Int \of{ U } \) is itself open in \(X \) by (2) of Proposition 3.4.10 Topology of a metric space. Thus
      \begin{equation*} \Int \of{ \Int \of{ U } } = \Int \of{ U } \end{equation*}
      by (1) of Proposition 3.4.9 Interior/closure.
      🔗
      🔗
    2. (2) of Theorem 3.4.11 Interior/closure implies that \(\Cl \of{ U } \) is an intersection of closed sets in \(X \text{,}\) and so \(\Cl \of{ U } \) is itself closed in \(X \) by (3) of Proposition 3.4.10 Topology of a metric space. Thus
      \begin{equation*} \Cl \of{ \Cl \of{ U } } = \Cl \of{ U } \end{equation*}
      by (2) of Proposition 3.4.9 Interior/closure.
      🔗
      🔗
    🔗
    For a subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \text{,}\) the property of being a neighborhood of a point \(x \in X \) is the existence of a certain kind lower bound on \(U \) in the power set \(\ps \of{ X } \) of \(X \text{.}\) We now examine the dual condition, that of metric boundedness.
    🔗

    Subsection 3.4.2 Metrics and Boundedness

    In this section, we have introduced open balls and closed disks of positive radius. While the notion of radius does not easily generalize to arbitrary subsets of metric spaces (even for just open balls and closed disks), the related concept of diameter is easily generalized from its meaning for Euclidean circles and spheres of higher dimension. Informally, the diameter of a subset of a metric space is the largest possible value taken by the metric when considering only points in that subset.
    🔗

    Definition 3.4.13. Diameter.

    The diameter \(\diam \of{ U } \) of a subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \) is the extended real number defined by
    \begin{equation*} \diam \of{ U } = \begin{cases} 0 \amp U = \emptyset \\ \sup_{ u , v \in U }{ \rho \of{ u , v } } \amp U \neq \emptyset \text{.}\end{cases} \end{equation*}
    🔗
    🔗

    Lemma 3.4.14. Diameter and radius.

    Let \(r \gt 0 \) be a positive real number and \(c \in X \) be a point in a metric space \(\of{ X , \rho } \text{.}\) The open ball \(\mB_{ r } \of{ c } \text{,}\) closed disk \(\mD_{ r } \of{ c } \text{,}\) and sphere \(\mS_{ r } \of{ c } \) of radius \(r \) and center \(c \) have diameter at most \(2 r \text{.}\)
    🔗
    🔗

    Proof.
    Since \(c \in \mB_{ r } \of{ c } \) the open ball \(\mB_{ r } \of{ c } \neq \emptyset \) is non-empty. Since
    \begin{equation*} \rho \of{ u , v } \leq \rho \of{ u , c } + \rho \of{ c , v } = \rho \of{ u , c } + \rho \of{ v , c } \lt r + r = 2 r \end{equation*}
    for all points \(u , v \in \mB_{ r } \of{ c } \text{,}\)
    \begin{equation*} \diam \of{ \mB_{ r } \of{ c } } = \sup_{ u , v \in \mB_{ r } \of{ c } }{ \rho \of{ u , v } } \leq 2 r\text{.} \end{equation*}
    🔗
    Similarly, since \(c \in \mD_{ r } \of{ c } \) the closed disk \(\mD_{ r } \of{ c } \neq \emptyset \) is non-empty. Since
    \begin{equation*} \rho \of{ u , v } \leq \rho \of{ u , c } + \rho \of{ c , v } = \rho \of{ u , c } + \rho \of{ v , c } \leq r + r = 2 r \end{equation*}
    for all points \(u , v \in \mD_{ r } \of{ c } \text{,}\)
    \begin{equation*} \diam \of{ \mD_{ r } \of{ c } } = \sup_{ u , v \in \mD_{ r } \of{ c } }{ \rho \of{ u , v } } \leq 2 r\text{.} \end{equation*}
    🔗
    If the sphere \(\mS_{ r } \of{ c } = \emptyset \) is empty, then \(\diam \of{ \mS_{ r } \of{ c } } = \diam \of{ \emptyset } = 0 \lt 2 r \text{.}\) On the other hand, if the sphere \(\mS_{ r } \of{ c } \neq \emptyset \) is non-empty, then we observe that
    \begin{equation*} \rho \of{ u , v } \leq \rho \of{ u , c } + \rho \of{ c , v } = \rho \of{ u , c } + \rho \of{ v , c } \leq r + r = 2 r \end{equation*}
    for all points \(u , v \in \mS_{ r } \of{ c } \text{,}\)
    \begin{equation*} \diam \of{ \mS_{ r } \of{ c } } = \sup_{ u , v \in \mD_{ r } \of{ c } }{ \rho \of{ u , v } } \leq 2 r\text{.} \end{equation*}
    🔗
    🔗
    So the diameter of an open ball, closed disk, or sphere in a metric space is bounded above by twice its radius. Note that, unlike in Euclidean spaces, the diameter of an open ball, closed disk, or sphere in arbitrary metric space need not actually reach this upper bound. This is because, unlike in Euclidean space, in which a given open ball or closed disk has a unique center and radius, balls and disks of different centers and radii may be equal. In particular, the geometry of open balls, closed disks, and spheres may be quite different in a given metric space than our intuition from Euclidean space might suggest.
    🔗

    Lemma 3.4.15. Monotonicity of the diameter.

    Let \(S , T \subseteq X \) be subsets of a metric space \(\of{ X , \rho } \text{.}\) If \(S \subseteq T \text{,}\) then \(\diam \of{ S } \leq \diam \of{ T } \text{.}\)
    🔗
    🔗

    Proof.
    If \(T = \emptyset \text{,}\) then \(S = \emptyset \) as well, and so
    \begin{equation*} \diam \of{ S } = \diam \of{ \emptyset } = \diam \of{ T }\text{.} \end{equation*}
    So we may suppose that \(T \neq \emptyset \) is non-empty. We observe that \(\rho \of{ x , y } \geq 0 \) for all points \(x , y \in T \text{,}\) and so
    \begin{equation*} \diam \of{ S } = 0 \leq \sup_{ x , y \in T }{ \rho \of{ x , y } } = \diam \of{ T }\text{.} \end{equation*}
    Thus we may additionally suppose that \(S \neq \emptyset \) is non-empty. In this case,
    \begin{align*} \diam \of{ S } \amp = \sup \of{ \setmid{ \rho \of{ x , y } \in \R }{ x , y \in S } }\\ \amp \leq \sup \of{ \setmid{ \rho \of{ x , y } \in \R }{ x , y \in T } } = \diam \of{ T } \end{align*}
    🔗
    🔗
    Much of this section thus far has been almost entirely concerned with the properties of subsets of metric spaces which contain certain open balls. We now consider the opposite case; what can we say about subsets which are themselves contained in open balls of finite radius? Such subsets of metric spaces are called bounded.
    🔗

    Definition 3.4.16. Boundedness.

    A subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \) is called bounded (resp. unbounded) if \(\diam \of{ U } \lt \infty \) (resp. \(\diam \of{ U } = \infty \)). A metric space \(\of{ X , \rho } \) is called bounded (resp. unbounded) if its ground set \(X \) is bounded (resp. unbounded).
    🔗
    🔗
    A priori, the above definition of boundedness does not appear to be related to the definition introduced in Section 1.5 Introduction to Order Theory. Namely, that kind of boundedness requires a partial order, and this one requires a metric. However, there is a way to reconcile these perspectives, and the two notions coincide in the real numbers, taken with their standard ordering \(\leq \) and the Euclidean metric \(d \text{.}\)
    🔗

    Example 3.4.17. Boundedness.

    The following are examples of bounded and unbounded subsets of metric spaces:
    • The empty set \(\emptyset \) is a bounded subset of every metric space.
      🔗
      🔗
    • Any discrete metric space is bounded, since its diameter is either \(0 \) or \(1 \text{.}\)
      🔗
      🔗
    • The \(n \)-dimensional Euclidean space \(\R^{ n } \) is bounded when \(n = 0 \) and unbounded when \(n \geq 1 \text{.}\)
      🔗
      🔗
    🔗
    🔗
    Any subset of a bounded subset of a metric space is itself bounded, and any set which contains an unbounded set is itself unbounded. Moreover, any subset of a nonempty metric space is bounded if and only if it is contained in an open ball or closed disk of finite radius.
    🔗

    Proposition 3.4.18. Metric characterization of boundedness.

    A subset of a nonempty metric space is bounded if and only if it is contained in an open ball of finite radius.
    🔗
    🔗

    Proof.
    Let \(U \subseteq X \) be a subset of a non-empty metric space \(\of{ X , \rho } \text{.}\) First suppose that \(U \) is bounded, so that \(\diam \of{ U } \lt \infty \text{.}\) Since \(X \neq \emptyset \) is non-empty, it contains a point \(x \in X \text{.}\) If \(U = \emptyset \) is empty, then \(U = \emptyset \subseteq \mB_{ r } \of{ x } \) for any positive real number \(r \gt 0 \text{.}\)
    🔗
    On the other hand, if \(U \neq \emptyset \) is non-empty, then it contains a point \(u \in U \text{.}\) Let \(r = \diam \of{ U } + 1 \text{,}\) and note that
    \begin{equation*} \rho \of{ u , v } \leq \sup_{ s , t \in U }{ \rho \of{ s , t } } = \diam \of{ U } \lt r \end{equation*}
    for all points \(v \in U \text{,}\) and so \(U \subseteq \mB_{ r } \of{ u } \text{.}\)
    🔗
    Conversely, now suppose that \(U \subseteq \mB_{ r } \of{ x } \) for some point \(x \in X \text{.}\) Then Lemma 3.4.15 Monotonicity of the diameter and Lemma 3.4.14 Diameter and radius imply that
    \begin{equation*} \diam \of{ U } \leq \diam \of{ \mB_{ r } \of{ x } } \leq 2 r \lt \infty\text{,} \end{equation*}
    so that \(U \) is bounded.
    🔗
    🔗
    In fact, something stronger is true for normed vector spaces; a subset of a normed vector space is bounded if and only if it is contained in some open ball of finite radius centered at the origin. This kind of result is typical of analysis done on normed vector spaces; the interplay between the norm and the vector space structure implies that most point-set topological concerns can be reduced to questions which are answerable in a neighborhood of the origin.
    🔗

    Corollary 3.4.19. Norm characterization of boundedness.

    A subset of a normed vector space is bounded if and only if it is contained in an open ball of finite radius centered at the origin.
    🔗
    🔗

    Proof.
    Let \(\of{ V , \norm{ \oparg } } \) be a normed vector space. By Proposition 3.4.18 Metric characterization of boundedness, it suffices to show that any bounded subset of \(V \) is contained in an open ball centered at \(\vect{ 0 } \text{.}\) To that end, let \(U \subseteq V \) be a bounded subset of \(V \text{.}\) Proposition 3.4.18 Metric characterization of boundedness implies that \(U \subseteq \mB_{ r } \of{ \vect{ v } } \) for some positive real number \(r \gt 0 \) and some vector \(\vect{ v } \text{.}\)
    🔗
    Let \(s = r + \norm{ \vect{ v } } \text{,}\) and observe that
    \begin{align*} \norm{ \vect{ u } - \vect{ 0 } } \amp = \norm{ \vect{ u } - \vect{ v } + \vect{ v } } \leq \norm{ \vect{ u } - \vect{ v } } + \norm{ \vect{ v } }\\ \amp \lt r + \norm{ \vect{ v } } = s \end{align*}
    for all \(\vect{ u } \in U \text{.}\) Thus \(U \subseteq \mB_{ s } \of{ \vect{ 0 } } \text{.}\)
    🔗
    🔗
    Any finite subset of a metric space is bounded. In fact, any finite union of bounded subsets of a metric space is itself bounded. In order to see this, it suffices to show that the binary union of two bounded subsets of a metric space is itself bounded.
    🔗

    Proposition 3.4.20. Unions of bounded sets.

    The union of two bounded sets in a metric space is itself bounded.
    🔗
    🔗

    Proof.
    Let \(U , V \subseteq X \) be bounded subsets of a metric space \(\of{ X , \rho } \text{,}\) and consider the union \(U \cup V \text{.}\) If \(X = \emptyset \) is empty, then \(U = V = \emptyset \text{,}\) and so
    \begin{equation*} \diam \of{ U \cup V } = \diam \of{ \emptyset \cup \emptyset } \diam \of{ \emptyset } = 0 \lt \infty\text{,} \end{equation*}
    so that \(U \) and \(V \) are bounded. On the other hand, if \(X \neq \emptyset \) is non-empty, then Proposition 3.4.18 Metric characterization of boundedness implies that \(U \subseteq \mB_{ r } \of{ x } \) and \(V \subseteq \mB_{ s } \of{ y } \) for some positive real numbers \(r , s \gt 0 \) and points \(x , y \in X \text{.}\) Let
    \begin{equation*} t = \max \of{ \set{ r , s + \rho \of{ y , x } } } \gt 0\text{,} \end{equation*}
    and consider a point \(z \in U \cup V \text{.}\) If \(z \in U \text{,}\) then
    \begin{equation*} \rho \of{ z , x } \lt r \leq t\text{,} \end{equation*}
    and if \(z \in V \text{,}\) then
    \begin{equation*} \rho \of{ z , x } \leq \rho \of{ z , y } + \rho \of{ y , x } \lt s + \rho \of{ y , x } \leq t\text{.} \end{equation*}
    In either case, we conclude that \(z \in \mB_{ t } \of{ x } \text{,}\) and so \(U \cup V \subseteq \mB_{ t } \of{ x } \text{.}\) Proposition 3.4.18 Metric characterization of boundedness now implies that \(U \cup V \) is bounded.
    🔗
    🔗
    The following corollary follows immediately from the above result by induction. Essentially, it asserts that the property of boundedness is stable under finite unions.
    🔗

    Corollary 3.4.21. Unions of bounded sets.

    The union of any finite collection of bounded subsets of a metric space is itself bounded.
    🔗
    🔗
    Before we move on to discuss the boundedness of maps between metric spaces, we will briefly mention one stronger kind of boundedness for subsets of metric spaces. A subset of a metric space is called totally bounded if it can be covered by finitely many open balls of arbitrarily small radius.
    🔗

    Definition 3.4.22. Total boundedness.

    A subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \) is called totally bounded if for all positive real numbers \(r \gt 0 \text{,}\) there is a finite list of points \(x_{ 1 } , \dotsc , x_{ n } \in X \) so that
    \begin{equation*} U \subseteq \bigcup_{ k = 1 }^{ n }{ \mB_{ r } \of{ x_{ k } } }\text{.} \end{equation*}
    A metric space \(\of{ X , \rho } \) is called totally bounded if its ground set \(X \) is totally bounded.
    🔗
    🔗

    Example 3.4.23. Total boundedness.

    The following are examples of totally bounded and not totally bounded subsets of metric spaces:
    • The empty set \(\emptyset \) is a totally bounded subset of any metric space. More generally, any finite set of a metric space is totally bounded.
      🔗
      🔗
    • Any infinite subset of a discrete metric space is bounded but not totally bounded.
      🔗
      🔗
    • A subset of \(n \)-dimensional Euclidean space \(\R^{ n } \) is totally bounded if and only if it is bounded.
      🔗
      🔗
    🔗
    🔗
    The above examples illustrate that while boundedness and total boundedness are not in general equivalent for subsets of metric spaces, the two notions are also not necessarily entirely unrelated. In fact, total boundedness is a stronger condition than boundedness for subsets of a metric space.
    🔗

    Proposition 3.4.24. Total boundedness implies boundedness.

    If a subset of a metric space is totally bounded, then it is bounded.
    🔗
    🔗

    Proof.
    Let \(U \subseteq X \) be a totally bounded subset of a metric space \(\of{ X , \rho } \text{.}\) Since \(1 \gt 0 \) is a positive real number,
    \begin{equation*} U \subseteq \bigcup_{ k = 1 }^{ n }{ \mB_{ 1 } \of{ x_{ k } } } \end{equation*}
    for some finite list of points \(x_{ 1 } , \dotsc , x_{ n } \in X \text{.}\) Lemma 3.4.14 Diameter and radius and Corollary 3.4.21 Unions of bounded sets together imply that \(U \) is bounded.
    🔗
    🔗
    We have seen that infinite discrete metric spaces provide a counterexample to the converse of Proposition 3.4.24 Total boundedness implies boundedness. However, in Euclidean space, total boundedness and boundedness are equivalent. We offer this result without proof.
    🔗

    Proposition 3.4.25. Total boundedness in Euclidean space.

    A subset of Euclidean space is totally bounded if and only if it is bounded.
    🔗
    🔗
    One way to see why Proposition 3.4.25 Total boundedness in Euclidean space is true is that any open ball or closed disk of finite radius in Euclidean space is a subset of a cube, which may be subdivided into finitely many appropriately small cubes. While boundedness and total boundedness are equivalent in Euclidean spaces, they are not the same for metric spaces in general. In some of the generalizations of theorems about Euclidean space to results about metric spaces in general, total boundedness is a more natural notion to discuss. We will further discuss totally bounded sets in the Section 3.6 Completeness and Compactness, in which we investigate completeness and compactness for metric spaces. For now, however, we move on in favor of exploring boundedness for maps between metric spaces.
    🔗
    🔗

    Subsection 3.4.3 Bounded maps between metric spaces

    In Section 1.5 Introduction to Order Theory, we defined boundedness for subsets of partially ordered sets, and then we defined a map from a set to a partially ordered set to be bounded if and only if its image was a bounded subset of the codomain. In this section, we have introduced a different notion of boundedness for subsets of a metric space, but an there is an analogous way to extend this notion to maps to metric spaces. A map to a metric space is bounded if its image is bounded in the codomain, and unbounded otherwise.
    🔗
    We note that this is a different notion than a bounded linear transformation between normed vector spaces, which is not bounded in this sense. The homogeneity of a norm on a vector space implies that no nonzero linear transformation to a normed vector space can be bounded in the above sense.}
    🔗

    Definition 3.4.26. Map boundedness.

    Let \(f \colon X \to Y \) be a map from a set \(X \) to a metric space \(\of{ Y , \rho } \text{.}\)
    • Boundedness.
      The map \(f \) is called bounded if its image \(\im \of{ f } = f \of{ X } \) is a bounded subset of \(Y \text{.}\)
      🔗
      🔗
    • Unboundedness.
      The map \(f \) is called unbounded if its image \(\im \of{ f } = f \of{ X } \) is an unbounded subset of \(Y \text{.}\)
      🔗
      🔗
    The set of bounded maps from a set \(X \) to a metric space \(\of{ Y , \rho } \) is denoted \(\Bdd \of{ X , Y } \text{.}\) In the special case \(\of{ Y , \rho } = \of{ \R , d } \text{,}\) the set of bounded real-valued functions on \(X \) is denoted \(\Bdd \of{ X } = \Bdd \of{ X , \R } \text{.}\)
    🔗
    🔗

    Remark 3.4.27. Boundedness for linear transformations.

    We remark that the above definition of boundedness is different than the usual definition of boundedness for linear maps between normed vector spaces. Indeed, in the setting of normed vector spaces, the absolute homogeneity of the norm implies that no non-zero linear transformation to a normed vector space can be bounded in the above sense. Instead, a linear transformation is called bounded if its restriction to the unit sphere around the origin is bounded in the above sense.
    🔗
    🔗

    Example 3.4.28. Bounded functions.

    Let \(f \colon \R \to \R \) be the real-valued function defined by the formula
    \begin{equation*} f \of{ x } = e^{ -x^{ 2 } }\text{.} \end{equation*}
    Then \(f \) is a bounded function on the real line \(\R \text{.}\)
    🔗
    🔗
    Just as in the cases of sequential and map convergence, in attempting to understand boundedness in arbitrary metric spaces, it suffices to investigate boundedness in the real line \(\R \text{.}\) These links between arbitrary metric spaces and the metric space of the real numbers taken with the Euclidean metric stem from the definition of a metric; the structure of a real-valued function such as a metric can be seen to pull back some of the properties of its codomain \(\R \) to its domain. In order to check that a metric space is bounded, it is both necessary and sufficient for the metric itself to be a bounded function.
    🔗

    Lemma 3.4.29. Map boundedness.

    A metric space \(\of{ X , \rho } \) is bounded if and only if the metric \(\rho \colon X \times X \to \R \) is a bounded function.
    🔗
    🔗

    Proof.
    First suppose that \(\of{ X , \rho } \) is bounded, so that \(\diam \of{ X } \lt \infty \text{.}\) If \(X = \emptyset \text{,}\) then
    \begin{align*} \diam \of{ \im \of{ \rho } } \amp = \diam \of{ \rho \of{ \emptyset \times \emptyset } } = \diam \of{ \rho \of{ \emptyset } }\\ \amp = \diam \of{ \emptyset } = 0 \lt \infty\text{,} \end{align*}
    and so \(\rho \) is bounded. Thus we may suppose that \(X \neq \emptyset \) is non-empty. In particular,
    \begin{equation*} 0 \leq \rho \of{ x , y } \leq \diam \of{ X } \end{equation*}
    for all points \(x , y \in X \text{,}\) which implies that
    \begin{equation*} d \of{ \rho \of{ x , y } , 0 } = \abs{ \rho \of{ x , y } - 0 } = \abs{ \rho \of{ x , y } } = \rho \of{ x , y } \leq \diam \of{ X } \end{equation*}
    for all points \(x , y \in X \text{.}\) In particular, this implies that \(\im \of{ \rho } \subseteq \mD_{ \diam \of{ X } } \of{ 0 } \text{.}\) Now Lemma 3.4.15 Monotonicity of the diameter and Lemma 3.4.14 Diameter and radius imply that
    \begin{equation*} \diam \of{ \im \of{ \rho } } \leq \diam \of{ \mD_{ \diam \of{ X } } \of{ 0 } } \leq 2 \diam \of{ X } \lt \infty\text{,} \end{equation*}
    so that \(\im \of{ \rho } \) is bounded.
    🔗
    Conversely, now suppose that \(\rho \) is bounded. Then Corollary 3.4.19 Norm characterization of boundedness implies that \(\im \of{ \rho } \subseteq \mB_{ r } \of{ 0 } \) for some positive real number \(r \gt 0 \text{.}\) This implies that
    \begin{equation*} \rho \of{ x , y } = \abs{ \rho \of{ x , y } - 0 } = d \of{ \rho \of{ x , y } , 0 } \lt r \end{equation*}
    for all \(x , y \in X \text{,}\) so that \(\diam \of{ X } \leq r \lt \infty \text{;}\) that is, \(\of{ X , \rho } \) is bounded.
    🔗
    🔗
    The set of bounded maps to a metric space may inherit some of the structure of the codomain. We will see some examples of this shortly. First, however, a useful observation about the relationship between the boundedness of maps and the boundedness of their codomains.
    🔗

    Remark 3.4.30. Maps to bounded metric spaces.

    Let \(\of{ Y , \rho } \) be a metric space. If \(Y \) is bounded, then Lemma 3.4.15 Monotonicity of the diameter implies that for any set \(X \text{,}\) any map \(f \colon X \to Y \) is bounded; that is, \(\Bdd \of{ X , Y } = Y^{ X } \text{.}\)
    🔗
    🔗
    There is a canonical way of constructing a metric on the set of bounded maps to a metric space.
    🔗

    Definition 3.4.31. Uniform metric.

    Let \(X \) be a set and \(\of{ Y , \rho } \) be a metric space. The uniform metric \(\rho_{ \infty } \) on the set \(\Bdd \of{ X , Y } \) of bounded maps from \(X \) to \(Y \) is the map \(\rho_{ \infty } \colon \Bdd \of{ X , Y } \times \Bdd \of{ X , Y } \to \R \) defined by the formula
    \begin{equation*} \rho_{ \infty } \of{ f , g } = \begin{cases} 0 \amp X = \emptyset \\ \sup_{ x \in X }{ \rho \of{ f \of{ x } , g \of{ x } } } \amp X \neq \emptyset \text{.}\end{cases} \end{equation*}
    🔗
    🔗

    Proposition 3.4.32. Uniform metric.

    The uniform metric is a metric.
    🔗
    🔗

    Proof.
    Let \(X \) be a set and \(\of{ Y , \rho } \) be a metric space. If \(X = \emptyset \text{,}\) then there is exactly one map from \(X \) to \(Y \text{,}\) and this map is bounded. The uniform metric \(\rho_{ \infty } \) is identically zero in this case, and so is a metric on \(\Bdd \of{ X , Y } \text{.}\)
    🔗
    Thus we may suppose that \(X \neq \emptyset \) is non-empty. Let \(f , g \in \Bdd \of{ X , Y } \) be a bounded map from \(X \) to \(Y \text{,}\) and note that if \(f = g \text{,}\) then
    \begin{align*} \rho_{ \infty } \of{ f , g } \amp = \sup_{ x \in X }{ \rho \of{ f \of{ x } , g \of{ x } } } = \sup_{ x \in X }{ \rho \of{ f \of{ x } , f \of{ x } } }\\ \amp = \sup_{ x \in X }{ 0 } = 0\text{.} \end{align*}
    Conversely, if \(\rho_{ \infty } \of{ f , g } = 0 \text{,}\) then
    \begin{equation*} 0 \leq \rho \of{ f \of{ x } , g \of{ x } } \leq \rho_{ \infty } \of{ f , g } = 0 \end{equation*}
    for all inputs \(x \in X \text{,}\) so that \(\rho \of{ f \of{ x } , g \of{ x } } = 0 \text{.}\) The non-degeneracy of the metric \(\rho \) implies that \(f \of{ x } = g \of{ x } \) for all inputs \(x \in X \text{,}\) and so \(f = g \text{.}\) We conclude that \(\rho_{ \infty } \) is non-degenerate.
    🔗
    We observe that the symmetry of the metric \(\rho \) implies that
    \begin{equation*} \rho_{ \infty } \of{ f , g } = \sup_{ x \in X }{ \rho \of{ f \of{ x } , g \of{ x } } } = \sup_{ x \in X }{ \rho \of{ g \of{ x } , f \of{ x } } } = \rho_{ \infty } \of{ g , f } \end{equation*}
    for all bounded maps \(f , g \in \Bdd \of{ X , Y } \text{,}\) and so \(\rho_{ \infty } \) is symmetric.
    🔗
    Finally, we observe that the triangle inequality for the metric \(\rho \) implies that
    \begin{align*} \rho_{ \infty } \of{ f , h } \amp = \sup_{ x \in X }{ \rho \of{ f \of{ x } , h \of{ x } } } \leq \sup_{ x \in X }{ \of{ \rho \of{ f \of{ x } , g \of{ x } } + \rho \of{ g \of{ x } , h \of{ x } } } }\\ \amp \leq \sup_{ x \in X }{ \rho \of{ f \of{ x } , g \of{ x } } } + \sup_{ x \in X }{ \rho \of{ g \of{ x } , h \of{ x } } } = \rho_{ \infty } \of{ f , g } + \rho_{ \infty } \of{ g , h } \end{align*}
    for all bounded maps \(f , g , h \in \Bdd \of{ X , Y } \text{,}\) and so \(\rho_{ \infty } \) is satisfies the triangle inequality.
    🔗
    Since \(\rho_{ \infty } \) is reflexive, symmetric, and satisfies the triangle inequality, it is a metric on \(\Bdd \of{ X , Y } \text{.}\)
    🔗
    🔗
    You will have an opportunity to explore the uniform metric in the setting of normed vector spaces in the problems for this section. In particular, you will see that in this setting, the uniform metric is induced by a norm.
    🔗
    The similarity in the names of the uniform norm and uniformly convergent sequences of functions is no coincidence. In fact, it turns out that for bounded maps to a metric space, these two notions coincide.
    🔗

    Theorem 3.4.33. Convergence in the uniform metric.

    Let \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of bounded maps \(f_{ n } \in \Bdd \of{ X , Y } \) from a set \(X \) to a metric space \(\of{ Y , \rho } \text{.}\) For a bounded map \(f \in \Bdd \of{ X , Y } \text{,}\) \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to \(f \) if and only if it converges to \(f \) in the uniform metric.
