Definition 3.2.4. Sequential limit.

The unique point \(x \in X \) to which a convergent sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \) converges is called the limit of said sequence, and it is denoted
\begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = x\text{.} \end{equation*}
