Definition 3.2.21. Accumulation; isolation.

Consider a subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \text{.}\)
  • Limit point.
    We say that \(U \) accumulates at a point \(c \in X \) if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a point \(u \in U \) so that \(0 \lt \rho \of{ u , c } \lt \epsilon \text{.}\) In this case, \(c \) is called a limit point (or accumulation point) of \(U \) in \(X \text{.}\) The set of such limit points of \(U \) is called the derived set of \(U \text{,}\) and is denoted \(U' \text{.}\)
    🔗
    🔗
  • Isolated point.
    We say that a point \(c \in X \) is isolated from \(U \) if \(c \) is not a limit point of \(U \text{;}\) that is, \(c \) is isolated from \(U \) if there is a positive real number \(\epsilon \gt 0 \) so that \(\rho \of{ u , c } \geq \epsilon \) for all points \(u \in U \) so that \(u \neq c \text{.}\) If \(c \in U \) is isolated from \(U \text{,}\) then \(c \) is called an isolated point of \(U \text{.}\)
