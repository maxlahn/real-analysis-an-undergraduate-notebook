Definition 7.1.8. Positive/negative part.

  • Positive part.
    The positive part \(x^{ + } \) of a real number \(x \in \R \) is the non-negative real number
    \begin{equation*} x^{ + } = \max \of{ \set{ x , 0 } }\text{.} \end{equation*}
    Similarly, the positive part of a series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) is the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } = \sum_{ n = 0 }^{ \infty }{ \max \of{ \set{ x , 0 } } }\text{.} \end{equation*}

  • Negative part.
    The negative part \(x^{ - } \) of a real number \(x \in \R \) is the non-negative real number
    \begin{equation*} x^{ - } = -\min \of{ \set{ x , 0 } } = \max \of{ \set{ -x , 0 } } = \of{ -x }^{ + }\text{.} \end{equation*}
    Similarly, the negative part of a series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) is the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ -\min \of{ \set{ x , 0 } } }\text{.} \end{equation*}
