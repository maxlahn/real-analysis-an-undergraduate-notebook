Definition 7.1.1. Series.

The series associated to a sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } \in \R \) called terms is a formal expression of the form
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{equation*}
For each index \(n \in \N \text{,}\) the \(n \)th partial sum \(S_{ n } \) is the finite sum
\begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ k } }\text{,} \end{equation*}
and the \(n \)th tail \(T_{ n } \) is the series
\begin{equation*} T_{ n } = \sum_{ k = n + 1 }^{ \infty }{ x_{ k } } = \sum_{ k = 0 }^{ \infty }{ x_{ k + n + 1 } }\text{.} \end{equation*}
