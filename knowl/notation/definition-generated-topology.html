Definition 4.2.4. Generated topology.

A collection \(\mathcal{ S } \subseteq \ps \of{ X } \) of subsets of a set \(X \) is called a subbase of a topology \(\tau \) (and its elements are called subbasic open sets) on \(X \) if \(\tau \) is the coarsest topology on \(X \) which contains \(\mathcal{ S } \text{;}\) that is, \(\mathcal{ S } \) is a subbase for \(\tau \) if every topology on \(X \) which contains \(\mathcal{ S } \) is a refinement of \(\tau \text{.}\)
🔗
Every collection \(\mathcal{ S } \subseteq \ps \of{ X } \) of subsets of a set \(X \) is a subbase of a unique topology
\begin{equation*} \gen{ \mathcal{ S } } = \bigcap_{ S \subseteq \tau \in \mathcal{ T }_{ X } }{ \tau } \end{equation*}
on \(X \) called the topology generated by \(\mathcal{ S } \text{.}\)
