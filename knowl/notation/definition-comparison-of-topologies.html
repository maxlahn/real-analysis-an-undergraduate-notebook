Definition 4.2.1. Comparison of topologies.

Denote by \(\mathcal{ T }_{ X } \subseteq \ps \of{ \ps \of{ X } } \) the set of topologies on a set \(X \text{.}\) \(\mathcal{ T }_{ X } \) is partially ordered by containment, and the partially ordered set \(\of{ \mathcal{ T }_{ X } , \subseteq } \) is called the lattice of topologies on \(X \text{.}\)
  • Coarsening.
    For all topologies \(\tau_{ 1 } , \tau_{ 2 } \in \mathcal{ T }_{ X } \) on \(X \text{,}\) if \(\tau_{ 1 } \subseteq \tau_{ 2 } \text{,}\) then we say that \(\tau_{ 1 } \) is coarser than \(\tau_{ 2 } \text{,}\) or equivalently that \(\tau_{ 1 } \) is a coarsening of \(\tau_{ 2 } \text{.}\)
    🔗
    Similarly, if \(\tau_{ 1 } \subsetneq \tau_{ 2 } \text{,}\) then we say that \(\tau_{ 1 } \) is strictly coarser than \(\tau_{ 2 } \text{,}\) or equivalently that \(\tau_{ 1 } \) is a strict coarsening of \(\tau_{ 2 } \text{.}\)
    🔗
    🔗
  • Refinement.
    For all topologies \(\tau_{ 1 } , \tau_{ 2 } \in \mathcal{ T }_{ X } \) on \(X \text{,}\) if \(\tau_{ 1 } \supseteq \tau_{ 2 } \text{,}\) then we say that \(\tau_{ 1 } \) is finer than \(\tau_{ 2 } \text{,}\) or equivalently that \(\tau_{ 1 } \) is a refinement of \(\tau_{ 2 } \text{.}\)
    🔗
    Similarly, if \(\tau_{ 1 } \supsetneq \tau_{ 2 } \text{,}\) then we say that \(\tau_{ 1 } \) is strictly finer than \(\tau_{ 2 } \text{,}\) or equivalently that \(\tau_{ 1 } \) is a strict refinement of \(\tau_{ 2 } \text{.}\)
