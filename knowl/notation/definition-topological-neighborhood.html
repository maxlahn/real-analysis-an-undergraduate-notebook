Definition 4.1.11. Neighborhood.

A subset \(N \subseteq X \) of a topological space \(\of{ X , \tau } \) is called a neighborhood of a point \(x \in X \) in \(X \) if \(x \in U \subseteq N \) for some open set \(U \in \tau \) in \(X \text{.}\) The set of neighborhoods of \(x \) in \(X \) is variously denoted \(\Nbhd \of{ x } \text{,}\) \(\Nbhd_{ X } \of{ x } \text{,}\) and/or \(\Nbhd_{ \of{ X , \tau } } \of{ x } \text{,}\) depending on which information is clear from context.
