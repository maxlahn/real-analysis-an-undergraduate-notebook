Lemma 6.3.2. Compact subintervals are directed.

For any interval \(X \subseteq \R \text{,}\) the set \(\mathcal{ K }_{ X } \) of all compact subintervals of the interior \(\Int \of{ X } \) is directed upwards.
🔗
🔗

Proof.
Let \(U , V \in \mathcal{ K }_{ X } \) be two compact subintervals of the interior \(\Int \of{ X } \text{.}\) Then \(U = \clint{ a }{ b } \) and \(V = \clint{ c }{ d } \) for some real numbers \(a , b , c , d \in \R \) so that \(a \leq b \) and \(c \leq d \text{.}\) Let
\begin{equation*} W = \clint{ \min \of{ \set{ a , c } } }{ \max \of{ \set{ b , d } } }\text{.} \end{equation*}
We observe that \(\min \of{ \set{ a , c } } \in \Int \of{ X } \) and \(\max \of{ \set{ b , d } } \in \Int \of{ X } \text{.}\) Since \(X \) is an interval, so too is \(\Int \of{ X } \text{.}\) We conclude that \(W \subseteq \Int \of{ X } \text{,}\) and so \(W \in \mathcal{ K }_{ X } \text{.}\) Of course \(U , V \subseteq W \text{.}\) Since every pair of elements of \(\mathcal{ K }_{ X } \) has a common upper bound, \(\mathcal{ K }_{ X } \) is directed upwards.
