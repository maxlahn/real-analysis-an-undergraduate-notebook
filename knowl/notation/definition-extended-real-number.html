Definition 2.4.8. Extended real number.

An extended real number is either a real number or one of two infinite elements \(\infty \) or \(-\infty \text{.}\) The set of extended real numbers is denoted \(\overline{ \R } = \R \cup \set{ \infty , -\infty } \text{.}\)
🔗
The standard ordering \(\leq \) on the real numbers \(\R \) is extended to a total order on \(\overline{ \R } \) by requiring \(-\infty \leq x \leq \infty \) for all real numbers \(x \in \R \text{.}\)
