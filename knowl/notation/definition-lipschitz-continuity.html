Definition 3.5.16. Lipschitz continuity.

A map \(f \) from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \) is called Lipschitz continuous if there is a non-negative real number \(L \geq 0 \) so that
\begin{equation*} d_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \leq L d_{ X } \of{ x_{ 1 } , x_{ 2 } } \end{equation*}
for all points \(x_{ 1 } , x_{ 2 } \in X \text{.}\)
🔗
The set of Lipschitz continuous maps from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \) is denoted \(\LC \of{ X , Y } \text{,}\) and the set of Lipschitz continuous real-valued functions on \(\of{ X , \rho_{ X } } \) is denoted \(\LC \of{ X } = \LC \of{ X , \R } \text{.}\)
