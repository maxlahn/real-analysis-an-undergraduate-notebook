Definition 4.3.14. Separation.

Two points \(x_{ 1 } , x_{ 2 } \in X \) in a topological space \(\of{ X , \tau } \) are called separated if there are neighborhoods \(N_{ 1 } \subseteq X \) and \(N_{ 2 } \subseteq X \) of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(x_{ 1 } \notin N_{ 2 } \) and \(x_{ 2 } \notin N_{ 1 } \text{.}\)
🔗
A topological space \(\of{ X , \tau } \) is called \(T_{ 1 } \) or Fréchet if all pairs of distinct points in \(X \) are separated.
