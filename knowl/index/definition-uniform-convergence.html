Definition 3.2.11. Uniform convergence.

Let \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of maps \(f_{ n } \colon X \to Y \) from a set \(X \) to a metric space \(\of{ Y , \rho } \text{.}\)
  • Uniform convergence.
    The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to a map \(f \colon X \to Y \) from \(X \) to \(Y \) if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} \rho \of{ f_{ n } \of{ x } , f \of{ x } } \lt \epsilon \end{equation*}
    for all inputs \(x \in X \) and indices \(n \geq n_{ \epsilon } \text{.}\)
    🔗
    The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) is called uniformly convergent if it converges uniformly to a map from \(X \) to \(Y \text{.}\)
    🔗
    🔗
  • Uniform divergence.
    The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) is called uniformly divergent if it does not converge uniformly to any map from \(X \) to \(Y \text{.}\)
