Definition 6.3.3. Interior exhaustion by compact subintervals.

Let \(\mathcal{ K }_{ X } \) be the directed set of compact subintervals of the interior \(\Int \of{ X } \) of an interval \(X \subseteq \R \text{.}\) A family \(\of{ K_{ \alpha } }_{ \alpha \in A } \) of such compact subintervals \(K_{ \alpha } \in \mathcal{ K }_{ X } \) indexed by an upwards directed set \(\of{ A , \preceq } \) is called an interior exhaustion of \(X \) by compact intervals if it is order-preserving and
\begin{equation*} \Int \of{ X } = \bigcup_{ \alpha \in A }{ K_{ \alpha } }\text{.} \end{equation*}
