Definition 4.4.6. Continuity.

Let \(f \colon X \to Y \) be a map from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \text{.}\)
  • Continuity.
    \(f \) is continuous at a point \(c \in X \) if it satisfies any (and therefore all) of the conditions in Theorem 4.4.5 Characterizations of topological continuity. \(f \) is continuous if it is continuous at every point \(c \in X \text{.}\)
    🔗
    🔗
  • Discontinuity.
    \(f \) is discontinuous at a point \(c \in X \) if it does not satisfies any of the conditions in Theorem 4.4.5 Characterizations of topological continuity. \(f \) is discontinuous if it is discontinuous at some point \(c \in X \text{.}\)
    🔗
    🔗
The set of continuous maps from \(X \) to \(Y \) is denoted \(\CDiff \of{ X , Y } \text{.}\) In the special case \(\of{ Y , \tau_{ Y } } = \of{ \R , \tau_{ d } } \text{,}\) the set of continuous, real-valued functions on a topological space \(\of{ X , \tau_{ X } } \) is denoted \(\CDiff \of{ X } = \CDiff \of{ X , \R } \text{.}\)
