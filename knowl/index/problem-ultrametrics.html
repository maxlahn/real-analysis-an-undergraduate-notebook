Problem 3. Ultrametrics.

A real-valued function \(\rho \colon X^{ 2 } \to \R \) on the Cartesian square \(X^{ 2 } \) of a set \(X \) is called an ultrametric on \(X \text{,}\) which is called the ground set and whose elements are called points if it satisfies the following conditions:
  • Non-degeneracy.
    For any points \(x_{ 1 } , x_{ 2 } \in X \text{,}\) \(\rho \of{ x_{ 1 } , x_{ 2 } } = 0 \) if and only if \(x_{ 1 } = x_{ 2 } \text{.}\)
    🔗
    🔗
  • Symmetry.
    \(\rho \of{ x_{ 1 } , x_{ 2 } } = \rho \of{ x_{ 2 } , x_{ 1 } } \) for any points \(x_{ 1 } , x_{ 2 } \in X \text{.}\)
    🔗
    🔗
  • Strong triangle inequality.
    \(\rho \of{ x_{ 1 } , x_{ 3 } } \leq \max \of{ \set{ \rho \of{ x_{ 1 } , x_{ 2 } } , \rho \of{ x_{ 2 } , x_{ 3 } } } } \) for any points \(x_{ 1 } , x_{ 2 } , x_{ 3 } \in X \text{.}\)
    🔗
    🔗
If a real-valued function \(\rho \colon X^{ 2 } \to \R \) is an ultrametric on \(X \text{,}\) then the ordered pair \(\of{ X , \rho } \) is called an ultrametric space.
🔗

(a)

Prove that any ultrametric is a metric.
🔗
🔗

(b)

Fix a prime number \(p \in \N \text{.}\) The \(p \)-adic valuation \(\abs{ \oparg }_{ p } \colon \Q \to \Q \) is a rational-valued function defined by the formula
\begin{equation*} \abs{ q } = \begin{cases} 0 \amp q = 0 \\ p^{ -k_{ p } \of{ q } } \amp q \neq 0 \text{,}\end{cases} \end{equation*}
where \(k_{ p } \of{ q } \in \Z \) is the unique integer so that \(q = p^{ k_{ p } \of{ q } } \of{ \frac{ a }{ b } } \) for some integers \(a , b \in \Z \) which are not divisible by \(p \text{.}\)
🔗
Prove that the \(p \)-adic valuation \(\abs{ \oparg }_{ p } \) induces an ultrametric \(\rho_{ p } \colon \Q^{ 2 } \to \R \) defined by the formula
\begin{equation*} \rho_{ p } \of{ q_{ 1 } , q_{ 2 } } = \abs{ q_{ 1 } - q_{ 2 } }_{ p }\text{.} \end{equation*}
This ultrametric is called the \(p \)-adic metric on \(\Q \text{.}\)
🔗
🔗

(c)

Prove that for all points \(x_{ 1 } , x_{ 2 } , x_{ 3 } \in X \) in an ultrametric space \(\of{ X , \rho } \text{,}\) if \(\rho_{ x_{ 1 } , x_{ 2 } } \leq \rho \of{ x_{ 2 } , x_{ 3 } } \text{,}\) then \(\rho \of{ x_{ 1 } , x_{ 3 } } = \rho \of{ x_{ 2 } , x_{ 3 } } \text{.}\)
🔗
