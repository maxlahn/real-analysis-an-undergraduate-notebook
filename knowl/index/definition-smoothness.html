Definition 5.1.12. Smoothness.

A real-valued function \(f \colon X \to \R \) on a subset \(X \subseteq \R \) is called smooth if it is \(k \)-times continuously differentiable for all \(k \in \N \text{.}\) The set of smooth functions on \(X \) is denoted
\begin{equation*} \CDiff^{ \infty } \of{ X } = \bigcup_{ k = 0 }^{ \infty }{ \CDiff^{ k } \of{ X } }\text{.} \end{equation*}
