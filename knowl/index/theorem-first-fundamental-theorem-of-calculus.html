Theorem 6.2.3. First fundamental theorem of calculus.

Let \(f \colon \clint{ a }{ b } \to \R \) be a continuous real-valued function defined on a closed interval \(\clint{ a }{ b } \text{,}\) and consider the real-valued function \(F \colon \clint{ a }{ b } \to \R \) defined by the formula
\begin{equation*} F \of{ x } = \int_{ a }^{ x }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
Then \(F \) is differentiable, with derivative \(F' \of{ c } = f \of{ c } \) for all points \(a \leq c \leq b \text{.}\)
🔗
🔗

Proof.
Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) is continuous at \(c \text{,}\) there is a positive real number \(\delta \gt 0 \) so that \(\abs{ f \of{ x } - f \of{ c } } \lt \frac{ \epsilon }{ 2 } \) for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) We observe that Chasles’ relation and the Triangle inequality for Riemann integrals together imply that
\begin{align*} \abs{ \frac{ F \of{ x } - F \of{ c } }{ x - c } - f \of{ c } } \amp = \abs{ \frac{ 1 }{ x - c } \of{ \int_{ a }^{ x }{ f \of{ x } \, \diff{ x } } - \int_{ a }^{ c }{ f \of{ x } \, \diff{ x } } - f \of{ c } \of{ x - c } } }\\ \amp = \abs{ \frac{ 1 }{ x - c } \of{ \int_{ c }^{ x }{ f \of{ x } \, \diff{ x } } - \int_{ c }^{ x }{ f \of{ c } \, \diff{ x } } } }\\ \amp = \frac{ 1 }{ \abs{ x - c } } \abs{ \int_{ c }^{ x }{ f \of{ x } - f \of{ c } \, \diff{ x } } }\\ \amp = \frac{ 1 }{ \abs{ x - c } } \int_{ \min \of{ \set{ c , x } } }^{ \max \of{ \set{ c , x } } }{ \abs{ f \of{ x } - f \of{ c } } \, \diff{ x } }\\ \amp \leq \frac{ 1 }{ \abs{ x - c } } \int_{ \min \of{ \set{ c , x } } }^{ \max \of{ \set{ c , x } } }{ \frac{ \epsilon }{ 2 } \, \diff{ x } }\\ \amp = \frac{ \epsilon \of{ \max \of{ \set{ c , x } } - \min \of{ \set{ c , x } } } }{ 2 \abs{ x - c } }\\ \amp = \frac{ \epsilon \abs{ x - c } }{ 2 \abs{ x - c } } = \frac{ \epsilon }{ 2 } \lt \epsilon \end{align*}
for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) Thus \(F \) is differentiable at \(c \text{,}\) with derivative \(F' \of{ c } = f \of{ c } \text{.}\)
