Definition 3.5.18. Lipschitz constant.

The Lipschitz constant \(L_{ f } \) of a map \(f \colon X \to Y \) from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \) is the infimum
\begin{equation*} L_{ f } = \inf \of{ \setmid{ L \in \clopint{ 0 }{ \infty } }{ \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \leq L \rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \textrm{ for all } x_{ 1 } , x_{ 2 } \in X } }\text{.} \end{equation*}
