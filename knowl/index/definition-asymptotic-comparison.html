Definition 5.4.1. Asymptotic comparison.

Let \(f , g \colon X \to \R \) be real-valued functions defined on a subset \(X \subseteq \R \text{,}\) and fix a limit point \(c \in X' \text{.}\)
  • Asymptotic dominance.
    We say that \(f \) is asymptotically dominated by \(g \) near \(c \) if
    \begin{equation*} \abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \end{equation*}
    for some non-negative real-valued function \(\lambda \colon X \to \clopint{ 0 }{ \infty } \) and non-negative real number \(0 \leq L \lt \infty \) so that
    \begin{equation*} \lim_{ x \to c }{ \lambda \of{ x } } = L\text{.} \end{equation*}
    In this case, we write \(f \preccurlyeq g \) as \(x \to c \text{.}\)

  • Asymptotic comparability.
    We say that \(f \) and \(g \) are asymptotically comparable near \(c \) if
    \begin{equation*} \abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \end{equation*}
    for some non-negative real-valued function \(\lambda \colon X \to \clopint{ 0 }{ \infty } \) and positive real number \(0 \lt L \lt \infty \) so that
    \begin{equation*} \lim_{ x \to c }{ \lambda \of{ x } } = L\text{.} \end{equation*}
    In this case, we write \(f \asymp g \) as \(x \to c \text{.}\)
    🔗
    🔗
  • Asymptotic.
    We say that \(f \) is asymptotic to \(g \) near \(c \) if
    \begin{equation*} \abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \end{equation*}
    for some non-negative real-valued function \(\lambda \colon X \to \clopint{ 0 }{ \infty } \) so that
    \begin{equation*} \lim_{ x \to c }{ \lambda \of{ x } } = 1\text{.} \end{equation*}
    In this case, we write \(f \sim g \) as \(x \to c \text{.}\)
