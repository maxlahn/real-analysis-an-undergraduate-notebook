Definition 7.1.11. Absolute/conditional series convergence.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\)
  • Absolute convergence.
    The series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely if any two of the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{,}\) \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } \text{,}\) \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \text{,}\) and \(\sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \) converge, in which case they all converge.

    🔗
  • Conditional convergence.
    The series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges conditionally if the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges but any of these series \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } \text{,}\) \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \text{,}\) and \(\sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \) diverge to \(\infty \text{,}\) in which case they all diverge to \(\infty \text{.}\)
