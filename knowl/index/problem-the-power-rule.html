Problem 2. The power rule.

For each real number \(p \in \R \text{,}\) consider the power function \(f_{ p } \colon \opint{ 0 }{ \infty } \to \R \) defined by the formula \(f_{ p } \of{ x } = x^{ p } \text{.}\)
🔗

(a)

Prove that for each natural number \(n \in \N \text{,}\) \(f_{ n } \) is differentiable, with derivative
\begin{equation*} f_{ n }' \of{ x } = n x^{ n - 1 }\text{.} \end{equation*}
🔗
Hint.
Either prove the desired result by induction on \(n \in \N \) or use the binomial theorem.
🔗
🔗
🔗

(b)

Show that for any integer \(n \in \Z \text{,}\) \(f_{ n } \) is differentiable, with derivative \(f_{ n }' \of{ x } = n x^{ n - 1 } \text{.}\)
🔗
🔗

(c)

Show that for any rational number \(p \in \Q \) that if \(f_{ p } \) is differentiable, then its derivative is \(f_{ p }' \of{ x } = p x^{ p - 1 } \text{.}\)
🔗
Hint.
Write \(p = \frac{ m }{ n } \) for some integers \(m , n \in \Z \) with \(n \neq 0 \text{,}\) and differentiate the equation \(f_{ p } \of{ x }^{ n } = x^{ m } \text{.}\)
🔗
🔗
🔗
The rules proven above also hold for irrational powers, although we will require additional machinery in order to prove this final extension. In general, this is called the power rule.
