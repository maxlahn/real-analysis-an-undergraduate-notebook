Definition 6.3.11. Absolute/conditional Riemann integrability.

Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{.}\)
  • Absolute Riemann integrability.
    \(f \) is called absolutely Riemann integrable if \(\abs{ f } \) is improperly Riemann integrable. One might also describe the improper Riemann integral
    \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \end{equation*}
    as absolutely convergent in this case.
    🔗
    🔗
  • Conditional Riemann integrability.
    \(f \) is called conditionally Riemann integrable if it is improperly Riemann integrable but not absolutely Riemann integrable; that is \(f \) is conditionally Riemann integrable if \(f \) is improperly Riemann integrable but \(\abs{ f } \) is not. One might also describe the improper Riemann integral
    \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \end{equation*}
    as conditionally convergent in this case.
