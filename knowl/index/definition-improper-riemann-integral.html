Definition 6.3.7. Improper Riemann integral.

Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \text{.}\) \(f \) is called improperly integrable if the restriction of \(f \) to any compact subinterval of the interior \(\Int \of{ X } \) is integrable, and there is a real number \(I \in \R \) which satisfies either (and therefore both) of the conditions in Proposition 6.3.6 Riemann integrals and interior exhaustions. In this case, that \(\R \) is Hausdorff implies that the number \(I \) is uniquely defined by these properties. This number \(I \) is called the improper Riemann integral of \(f \text{,}\) and is denoted
\begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
