Definition 4.3.10. Topological distinguishability.

Two points \(x_{ 1 } , x_{ 2 } \in X \) in a topological space \(\of{ X , \tau } \) are called topologically indistinguishable if a subset \(N \subseteq X \) is a neighborhood of \(x_{ 1 } \) in \(X \) if and only if \(N \) is a neighborhood of \(x_{ 2 } \) in \(X \text{.}\) Two points \(x_{ 1 } , x_{ 2 } \in X \) are called topologically distinguishable otherwise if they are not topologically indistinguishable.
🔗
A topological space \(\of{ X , \tau } \) is called \(T_{ 0 } \) or Kolmogorov if all pairs of distinct points in \(X \) are topologically distinguishable.
