Definition 5.2.1. Critical/regular point/value.

Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{.}\)
  • Critical point/value.
    A point \(x \in X \) is called a critical point of \(f \) if either \(f' \of{ x } = 0 \text{,}\) in which case \(x \) is called a stationary (critical) point of \(f \text{,}\) or \(f \) is not differentiable at \(x \text{.}\)
    🔗
    A real number \(y \in \R \) is called a critical value of \(f \) if \(f \of{ x } = y \) for some critical point \(x \in X \text{.}\)
    🔗
    🔗
  • Regular point/value.
    A point \(x \in X \) is called a regular point of \(f \) if it is not a critical point of \(f \text{;}\) that is, \(x \) is a regular point of \(f \) if \(f \) is differentiable at \(x \) and \(f' \of{ x } \neq 0 \text{.}\)
    🔗
    A real number \(y \in \R \) is called a regular value of \(f \) if it is not a critical value of \(f \text{;}\) that is, \(y \) is a regular value of \(f \) if the pre-image
    \begin{equation*} f^{ -1 } \of{ y } = \setmid{ x \in X }{ f \of{ x } = y } \end{equation*}
    consists only of regular points of \(f \text{.}\)
