Definition 3.6.8. Subsequence.

A sequence \(y \colon \N \to X \) of points in a metric space \(\of{ X , \rho } \) is a subsequence of a sequence \(x \colon \N \to X \) of points in \(X \) if \(y = x \circ f \) for some increasing function \(f \colon \N \to \N \text{.}\) In this case, if \(x = \of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(f = \of{ n_{ k } }_{ k = 0 }^{ \infty } \text{,}\) then we write \(y = \of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \text{.}\)
