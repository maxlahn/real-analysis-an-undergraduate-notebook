Definition 7.1.3. Series convergence/divergence.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ m } \in \R \text{,}\) and consider the associated series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{.}\)
  • Series convergence.
    The series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges to a real number \(S \in \R \) if the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) of partial sums
    \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ k } } \end{equation*}
    converges to \(S \text{.}\) In this case, we call \(S \) the value of the series, and write
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } = S = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ k } } }\text{.} \end{equation*}
    🔗
    🔗
  • Series divergence.
    The series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) diverges if the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) of partial sums
    \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ k } } \end{equation*}
    diverges.
    🔗
    A special case of series divergence is series divergence to infinity. If the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(\pm \infty \text{,}\) then we write
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } = \pm \infty = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ k } } }\text{.} \end{equation*}
