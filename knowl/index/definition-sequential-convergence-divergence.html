Definition 3.2.1. Sequential convergence/divergence.

A sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \) converges to a point \(x \in X \) if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
\begin{equation*} \rho \of{ x_{ n } , x } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{.}\)
🔗
A sequence of points in a metric space is called convergent if it converges to a point and divergent if it does not converge to any point.
