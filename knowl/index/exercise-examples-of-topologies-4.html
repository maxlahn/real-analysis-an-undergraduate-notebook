Exercise 2.

A subset \(U \subseteq X \) of a set \(X \) is called cocountable in \(X \) if the complement \(X \setminus U \) is countable. The cocountable topology
\begin{equation*} \tau = \setmid{ U \in \ps \of{ X } }{ U = \emptyset \textrm{ or } X \setminus U \textrm{ is countable} } \end{equation*}
on \(X \) is the collection of all cocountable subsets of \(X \) along with the empty set \(\emptyset \text{.}\) Verify that \(\tau \) is a topology on \(X \text{.}\)
