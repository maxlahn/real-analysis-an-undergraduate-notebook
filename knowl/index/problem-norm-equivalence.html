Problem 2. Norm equivalence.

Two norms \(\norm{ \oparg }_{ 1 } , \norm{ \oparg }_{ 2 } \colon V \to \R \) on a real or complex vector space \(V \) are called equivalent if there are positive real numbers \(A , B \in \opint{ 0 }{ \infty } \) so that
\begin{equation*} A \norm{ \vect{ v } }_{ 2 } \leq \norm{ \vect{ v } }_{ 1 } \leq B \norm{ \vect{ v } }_{ 2 } \end{equation*}
for all vectors \(\vect{ v } \in V \text{.}\)
🔗

(a)

Prove that norm equivalence is an equivalence relation on the set of norms on \(V \text{.}\)
🔗
🔗

(b)

Prove that for a given natural number \(n \in \N \text{,}\) any two \(p \)-norms \(\norm{ \oparg }_{ p } \) on \(n \)-dimensional real coordinate space \(\R^{ n } \) for \(1 \leq p \leq \infty \) are all equivalent.
