Exercise 3.

Fix an element \(x \in X \) of a set \(X \text{.}\) The particular point topology
\begin{equation*} \tau = \setmid{ U \in \ps \of{ X } }{ U = \emptyset \textrm{ or } x \in U } \end{equation*}
on \(X \) is the collection of all subsets of \(X \) which contain \(x \) along with the empty set \(\emptyset \text{.}\) Verify that \(\tau \) is a topology on \(X \text{.}\)
