Problem 1. From pseudometrics to metrics.

A real-valued function \(\rho \colon X^{ 2 } \to \R \) on the Cartesian square \(X^{ 2 } \) of a set \(X \text{,}\) which is called the ground set and whose elements are called points, is a pseudometric on \(X \) if it has the following properties:
  1. Identity.
    \(\rho \of{ x , x } = 0 \) for any point \(x \in X \text{.}\)
    🔗
    🔗
  2. Symmetry.
    \(\rho \of{ x_{ 1 } , x_{ 2 } } = \rho \of{ x_{ 2 } , x_{ 1 } } \) for any points \(x_{ 1 } , x_{ 2 } \in X \text{.}\)
    🔗
    🔗
  3. Triangle inequality.
    \(\rho \of{ x_{ 1 } , x_{ 3 } } \leq \rho \of{ x_{ 1 } , x_{ 2 } } + \rho \of{ x_{ 2 } , x_{ 3 } } \) for any points \(x_{ 1 } , x_{ 2 } , x_{ 3 } \in X \text{.}\)
    🔗
    🔗
In this case, the ordered pair \(\of{ X , \rho } \) is called a pseudometric space.
🔗

(a)

Let \(\rho \) be a pseudometric on a set \(X \text{,}\) and consider the binary relation \(\equiv_{ \rho } \) on \(X \) defined so that \(x_{ 1 } \equiv_{ \rho } x_{ 2 } \) if and only if \(\rho \of{ x_{ 1 } , x_{ 2 } } = 0 \text{.}\) Prove that \(\equiv_{ \rho } \) is an equivalence relation on \(X \text{.}\)
🔗
🔗

(b)

Prove that a pseudometric \(\rho \) descends to a well-defined metric \(\overline{ \rho } \) on the quotient set \(X / { \equiv_{ \rho } } \) defined by the formula
\begin{equation*} \overline{ \rho } \of{ \class{ x_{ 1 } }_{ \equiv_{ \rho } } , \class{ x_{ 2 } }_{ \equiv_{ \rho } } } = \rho \of{ x_{ 1 } , x_{ 2 } }\text{.} \end{equation*}
