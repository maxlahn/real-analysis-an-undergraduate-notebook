Example 7.1.2. Geometric series.

A geometric series of initial value \(a \in \R \) and ratio \(r \in \R \) is the series of the form
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } }\text{.} \end{equation*}
If \(r = 1 \text{,}\) then the partial sums of such a geometric series are
\begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ a r^{ k } } = a + a r + a r^{ 2 } + \dotsb + a r^{ n }\\ \amp = a + a + a + \dotsb + a = a \of{ n + 1 } \end{align*}
On the other hand, if \(r \neq 1 \text{,}\) then we claim that the partial sums of such a geometric series are
\begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ a r^{ k } } = a + a r + a r^{ 2 } + \dotsb + a r^{ n }\\ \amp = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r }\text{.} \end{align*}
We can verify this computation by induction on \(n \in \N \text{.}\) Indeed, for the base case \(n = 0 \text{,}\) we see that
\begin{align*} S_{ n } \amp = S_{ 0 } = \sum_{ k = 0 }^{ 0 }{ a r^{ k } } = a r^{ 0 } = a \\ \amp = a \of{ \frac{ 1 - r }{ 1 - r } } = \frac{ a \of{ 1 - r^{ 1 } } }{ 1 - r } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r }\text{.} \end{align*}
For the inductive step, suppose that
\begin{equation*} S_{ n } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } \end{equation*}
for some index \(n \in \N \text{.}\) We now observe that
\begin{align*} S_{ n + 1 } \amp = \sum_{ k = 0 }^{ n + 1 }{ a r^{ k } } = \sum_{ k = 0 }^{ n }{ a r^{ k } } + a r^{ n + 1 } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } + a r^{ n + 1 }\\ \amp = \frac{ a \of{ 1 - r^{ n + 1 } } + a r^{ n + 1 } \of{ 1 - r } }{ 1 - r }\\ \amp = \frac{ a - a r^{ n + 1 } + a r^{ n + 1 } - a r^{ n + 2 } }{ 1 - r }\\ \amp = \frac{ a - a r^{ n + 2 } }{ 1 - r } = \frac{ a \of{ 1 - r^{ \of{ n + 1 } + 1 } } }{ 1 - r }\text{.} \end{align*}
