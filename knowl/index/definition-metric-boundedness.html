Definition 3.4.16. Boundedness.

A subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \) is called bounded (resp. unbounded) if \(\diam \of{ U } \lt \infty \) (resp. \(\diam \of{ U } = \infty \)). A metric space \(\of{ X , \rho } \) is called bounded (resp. unbounded) if its ground set \(X \) is bounded (resp. unbounded).
