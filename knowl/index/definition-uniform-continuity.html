Definition 3.5.10. Uniform continuity.

A map \(f \colon X \to Y \) from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \) is called uniformly continuous if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that
\begin{equation*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \lt \epsilon \end{equation*}
for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\)
🔗
The set of uniformly continuous maps from \(X \) to \(Y \) is denoted \(\UC \of{ X , Y } \text{.}\) In the special case \(\of{ Y , \rho_{ Y } } = \of{ \R , d } \text{,}\) the set of uniformly continuous real-valued functions on \(X \) is denoted \(\UC \of{ X } = \UC \of{ X , \R } \text{.}\)
