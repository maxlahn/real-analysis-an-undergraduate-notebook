Problem 3. Opposite of an order.

The opposite \(\op{ R } \) of a binary relation \(R \) on a set \(X \) is the binary relation defined by
\begin{equation*} \op{ R } = \setmid{ \of{ x_{ 2 } , x_{ 1 } } \in X^{ 2 } }{ \of{ x_{ 1 } , x_{ 2 } } \in R }\text{.} \end{equation*}

(a)
