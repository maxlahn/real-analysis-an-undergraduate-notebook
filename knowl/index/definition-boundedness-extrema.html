Definition 1.5.5. Boundedness.

Let \(U \subseteq X \) be a subset of a preordered ordered set \(\of{ X , \precsim } \text{.}\)
  • Upper bound.
    An element \(x \in X \) is called an upper bound for \(U \) if \(u \precsim x \) for all elements \(u \in U \text{.}\) If such an upper bound for \(U \) exists, then \(U \) is called bounded from above in \(X \text{.}\) Otherwise, if no such upper bound for \(U \) exists, then \(U \) is called unbounded from above.
    🔗
    🔗
  • Lower bound.
    An element \(x \in X \) is called a lower bound for \(U \) if \(x \precsim u \) for all elements \(u \in U \text{.}\) If such a lower bound for \(U \) exists, then \(U \) is called bounded from below in \(X \text{.}\) Otherwise, if no such upper bound for \(U \) exists, then \(U \) is called unbounded from below.
    🔗
    🔗
A subset \(U \subseteq X \) is called bounded in \(X \) if it is both bounded from above in \(X \) and bounded from below in \(X \text{,}\) and \(U \) is called unbounded in \(X \) otherwise if it is either unbounded from above in \(X \) or unbounded from below in \(X \text{.}\)
