Definition 5.4.7. Taylor approximation/remainder.

Let \(f \colon X \to \R \) be a real-valued function defined on a subset \(X \subseteq \R \text{.}\) If \(f \) is \(k \)-times differentiable at a point \(c \in X \text{,}\) then the unique polynomial \(P^{ k }_{ c } \of{ f , x } \) of degree at most \(k \) so that \(f \of{ x } - P^{ k }_{ c } \of{ f , x } \prec \of{ x - c }^{ k } \) is called the order \(k \) Taylor approximation of \(f \) at \(c \text{,}\) and \(R^{ k }_{ c } \of{ f , x } = f \of{ x } - P^{ k }_{ c } \of{ f , x } \) is called the order \(k \) Taylor remainder of \(f \) at \(c \text{.}\)
