Definition 3.6.1. Cauchy sequence.

A sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \) is called Cauchy if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that \(\rho \of{ x_{ m } , x_{ n } } \lt \epsilon \) for all indices \(m , n \geq n_{ \epsilon } \text{.}\)
