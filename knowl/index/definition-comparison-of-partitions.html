Definition 6.1.3. Comparison of partitions.

Let \(P = \of{ x_{ j } }_{ j = 0 }^{ m } \) and \(Q = \of{ y_{ k } }_{ k = 0 }^{ n } \) be partitions of a closed interval \(\clint{ a }{ b } \text{.}\) If \(\set{ x_{ j } }_{ j = 0 }^{ m } \subseteq \set{ y_{ k } }_{ k = 0 }^{ n } \text{,}\) then we write \(P \preceq Q \) and say that \(P \) is coarser than \(Q \text{;}\) that \(Q \) is finer than \(P \text{;}\) \(Q \) is a refinement of \(P \text{;}\) and/or that \(P \) is a coarsening of \(Q \text{.}\)
🔗
Let \(\of{ P , s } \) and \(\of{ Q , t } \) be tagged partitions of the closed interval \(\clint{ a }{ b } \text{,}\) where \(P = \of{ x_{ j } }_{ j = 0 }^{ m } \text{,}\) \(Q = \of{ y_{ k } }_{ k = 0 }^{ n } \text{,}\) \(s = \of{ s_{ j } }_{ j = 0 }^{ m - 1 } \text{,}\) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{.}\) If both \(\set{ x_{ j } }_{ j = 0 }^{ m } \subseteq \set{ y_{ k } }_{ k = 0 }^{ n } \) and \(\set{ s_{ j } }_{ j = 0 }^{ m - 1 } \subseteq \set{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{,}\) then we write \(\of{ P , s } \preceq \of{ Q , t } \) and say that \(\of{ P , s } \) is coarser than \(\of{ Q , t } \text{;}\) that \(\of{ Q , t } \) is finer than \(\of{ P , s } \text{;}\) \(\of{ Q , t } \) is a refinement of \(\of{ P , s } \text{;}\) and/or that \(\of{ P , s } \) is a coarsening of \(\of{ Q , t } \text{.}\)
