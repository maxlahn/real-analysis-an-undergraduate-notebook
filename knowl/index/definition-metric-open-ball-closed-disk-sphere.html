Definition 3.4.1. Open ball; closed disk; sphere.

Fix a positive real number \(r \gt 0 \) and a point \(c \in X \) in a metric space \(\of{ X , \rho } \text{.}\)
  • Open metric ball.
    The open (metric) ball \(\mB_{ r } \of{ c } \) in \(X \) of radius \(r \) and center \(c \) is the subset of \(X \) defined by
    \begin{equation*} \mB_{ r } \of{ c } = \setmid{ x \in X }{ \rho \of{ x , c } \lt r }\text{.} \end{equation*}

  • Closed metric disk.
    The closed (metric) disk \(\mD_{ r } \of{ c } \) in \(X \) of radius \(r \) and center \(c \) is the subset of \(X \) defined by
    \begin{equation*} \mD_{ r } \of{ c } = \setmid{ x \in X }{ \rho \of{ x , c } \leq r }\text{.} \end{equation*}

  • Open metric ball.
    The (metric) sphere \(\mS_{ r } \of{ c } \) in \(X \) of radius \(r \) and center \(c \) is the subset of \(X \) defined by
    \begin{equation*} \mS_{ r } \of{ c } = \setmid{ x \in X }{ \rho \of{ x , c } = r }\text{.} \end{equation*}
