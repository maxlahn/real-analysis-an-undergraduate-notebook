Item. Sierpiński space.

The Sierpiński space is the topological space \(\of{ X , \tau } \) with ground set \(X = \set{ 0 , 1 } \) and topology \(\tau = \set{ \emptyset , \set{ 1 } , \set{ 0 , 1 } } \text{.}\) This topological space is a well-known simple counterexample to many false statements about topological spaces that feel true intuitively.
