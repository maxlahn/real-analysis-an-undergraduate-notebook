Definition 3.2.8. Pointwise convergence/divergence.

Let \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of maps \(f_{ n } \colon X \to Y \) from a set \(X \) to a metric space \(\of{ Y , \rho } \text{.}\)
  • Pointwise convergence.
    The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges pointwise to a map \(f \colon X \to Y \) from \(X \) to \(Y \) if for all inputs \(x \in X \text{,}\) the sequence \(\of{ f_{ n } \of{ x } }_{ n = 0 }^{ \infty } \) of corresponding outputs \(f_{ n } \of{ x } \in Y \) converges to \(f \of{ x } \text{.}\)
    🔗
    The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) is called pointwise convergent if it converges pointwise to a map from \(X \) to \(Y \text{.}\)
    🔗
    🔗
  • Pointwise divergence.
    The sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) is called pointwise divergent if it does not converge pointwise to any map from \(X \) to \(Y \text{.}\)
