Corollary 5.4.9 (Joseph-Louis Lagrange). Lagrange form of the Taylor remainder.

Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{,}\) and suppose that \(f \) is \(k \)-times differentiable at an interior point \(c \in \Int \of{ X } \text{,}\) with order \(k \) Taylor approximation \(P^{ k }_{ c } \of{ f , x } \) and order \(k \) Taylor remainder \(R^{ k }_{ c } \of{ f , x } \text{.}\)
🔗
Fix a point \(x \in X \text{.}\) If \(f^{ \of{ k } } \) is continuous on the closed interval \(I_{ x } \) between \(c \) and \(x \) and differentiable on the open interval \(\Int \of{ I_{ x } } \text{,}\) then
\begin{equation*} R^{ k }_{ c } \of{ f , x } = \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - c }^{ k + 1 } }{ \of{ k + 1 }! } \end{equation*}
for some interior point \(y \in \Int \of{ I_{ x } } \text{.}\)
🔗
🔗

Proof.
This follows immediately from Theorem 5.4.8 Mean value form of the Taylor remainder by taking \(G \of{ y } = \of{ x - y }^{ k + 1 } \text{.}\) Indeed, in this case,
\begin{align*} R^{ k }_{ c } \of{ f , x } \amp = \of{ \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - y }^{ k } }{ k! } } \of{ \frac{ G \of{ x } - G \of{ c } }{ G' \of{ y } } }\\ \amp = \of{ \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - y }^{ k } }{ k! } } \of{ \frac{ - \of{ x - c }^{ k + 1 } }{ \of{ k + 1 } \of{ x - y }^{ k } \of{ -1 } } }\\ \amp = \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - c }^{ k + 1 } }{ \of{ k + 1 }! } \end{align*}
for some interior point \(y \in \Int \of{ I_{ x } } \text{.}\)
