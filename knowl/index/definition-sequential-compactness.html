Definition 3.6.17. Sequential compactness.

A subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \) is called (sequentially) compact if every sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) of points \(u_{ n } \in U \) has a subsequence which converges to a limit in \(U \text{,}\) and (sequentially) non-compact otherwise. A metric space \(\of{ X , \rho } \) is called compact (resp. non-compact) if \(X \) is compact (resp. non-compact).
