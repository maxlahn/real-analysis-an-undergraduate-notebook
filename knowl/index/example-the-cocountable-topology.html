Example 4.3.5. The cocountable topology.

The cocountable topology \(\tau \) on a set \(X \) is the set
\begin{equation*} \tau = \setmid{ U \in \ps \of{ X } }{ U = \emptyset \textrm{ or } X \setminus U \textrm{ is countable} }\text{.} \end{equation*}
One can verify that \(\tau \) is a topology on \(X \) for which all convergent sequences are eventually constant. Moreover, if \(X \) is uncountable, then \(\tau \) is not the discrete topology on \(X \text{.}\)
