Definition 4.3.18. Separation by neighborhoods.

Two points \(x_{ 1 } , x_{ 2 } \in X \) in a topological space \(\of{ X , \tau } \) are called separated by neighborhoods if there are neighborhoods \(N_{ 1 } \in \Nbhd \of{ x_{ 1 } } \) and \(N_{ 2 } \in \Nbhd \of{ x_{ 2 } } \) of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(N_{ 1 } \cap N_{ 2 } = \emptyset \text{.}\)
🔗
A topological space \(\of{ X , \tau } \) is called \(T_{ 2 } \) or Hausdorff if all pairs of distinct points in \(X \) are separated by neighborhoods.
