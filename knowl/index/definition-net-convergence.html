Definition 4.3.8. Net convergence.

Let \(\of{ x_{ \alpha } }_{ \alpha \in A } \) be a net of points \(x_{ \alpha } \in X \) in a topological space \(\of{ X , \tau } \) indexed by a directed set \(\of{ A , \preceq } \text{.}\)
  • Upwards convergence.
    Suppose that the indexing set \(A \) is upwards directed. A net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \) converges upwards to a point \(x \in X \) if for all neighborhoods \(N \in \Nbhd \of{ x } \) of \(x \) in \(X \text{,}\) there is an index \(\alpha_{ N } \in A \) so that \(x_{ \alpha } \in N \) for all indices \(\alpha \succeq \alpha_{ N } \text{.}\)
    🔗
    The net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) is called upwards convergent if it converges upward to a point in \(X \text{,}\) and \(\of{ x_{ \alpha } }_{ \alpha \in A } \) is called upwards divergent if it does not converge upwards to any point in \(X \text{.}\)
    🔗
    If \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges upwards to a unique point \(x \in X \text{,}\) then this point is called the upwards limit of \(\of{ x_{ \alpha } }_{ \alpha \in A } \) and is denoted
    \begin{equation*} \lim_{ \alpha \uparrow }{ x_{ \alpha } } = x\text{.} \end{equation*}
    🔗
    🔗
  • Downwards convergence.
    Suppose that the indexing set \(A \) is downwards directed. A net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \) converges downwards to a point \(x \in X \) if for all neighborhoods \(N \in \Nbhd \of{ x } \) of \(x \) in \(X \text{,}\) there is an index \(\alpha_{ N } \in A \) so that \(x_{ \alpha } \in N \) for all indices \(\alpha \preceq \alpha_{ N } \text{.}\)
    🔗
    The net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) is called downwards convergent if it converges downward to a point in \(X \text{,}\) and \(\of{ x_{ \alpha } }_{ \alpha \in A } \) is called downwards divergent if it does not converge downwards to any point in \(X \text{.}\)
    🔗
    If \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges downwards to a unique point \(x \in X \text{,}\) then this point is called the downwards limit of \(\of{ x_{ \alpha } }_{ \alpha \in A } \) and is denoted
    \begin{equation*} \lim_{ \alpha \downarrow }{ x_{ \alpha } } = x\text{.} \end{equation*}
