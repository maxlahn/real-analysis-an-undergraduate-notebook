Definition 5.2.8. Isolated critical point.

Let \(f \colon X \to \R \) be a real-valued function defined on a subset \(X \subseteq \R \text{.}\) A critical point \(x \in X \) of \(f \) is called isolated if there is a neighborhood \(N \in \Nbhd_{ X } \of{ x } \) so that \(N \setminus \set{ x } \) consists only of regular points of \(f \text{.}\)
