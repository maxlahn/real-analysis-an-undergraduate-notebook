Exercise 1.

A subset \(U \subseteq X \) of a set \(X \) is called cofinite in \(X \) if the complement \(X \setminus U \) is finite. The cofinite topology
\begin{equation*} \tau = \setmid{ U \in \ps \of{ X } }{ U = \emptyset \textrm{ or } X \setminus U \textrm{ is finite} } \end{equation*}
on \(X \) is the collection of all cofinite subsets of \(X \) along with the empty set \(\emptyset \text{.}\) Verify that \(\tau \) is a topology on \(X \text{.}\)
