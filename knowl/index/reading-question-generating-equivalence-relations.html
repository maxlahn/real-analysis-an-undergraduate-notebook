Reading Question 3. Generating equivalence relations.

Let \(X \) be a set.
🔗

(a)

Prove that the intersection \(R = \bigcap_{ j \in \mathcal{ J } }{ R_{ j } } \) of any indexed family \(\of{ R_{ j } }_{ j \in \mathcal{ J } } \) of equivalence relations \(R_{ j } \) on \(X \) is an equivalence relation on \(X \text{.}\)
🔗
🔗

(b)

Prove that for any binary relation \(R \) on \(X \text{,}\) there is a unique equivalence relation \(S \) on \(X \) which satisfies the following conditions:
  1. \(S \) is a refinement of \(R \text{;}\) that is, \(R \subseteq S \text{.}\)
    🔗
    🔗
  2. \(S \) is coarser than any equivalence relation which refines \(R \text{;}\) that is, \(S \subseteq T \) for any equivalence relation \(T \) on \(X \) so that \(R \subseteq T \text{.}\)
    🔗
    🔗
🔗
🔗
The unique equivalence relation on \(X \) constructed in (b) above is called the equivalence relation generated by \(R \text{.}\)
