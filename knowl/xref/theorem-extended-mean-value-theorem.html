Theorem 5.2.5 (Augustin-Louis Cauchy). Extended mean value theorem.

Let \(f , g \colon \clint{ a }{ b } \to \R \) be real-valued functions defined on a closed interval \(\clint{ a }{ b } \subsetneq \R \text{.}\) If \(f \) and \(g \) are continuous on the closed interval \(\clint{ a }{ b } \) and differentiable on the open interval \(\opint{ a }{ b } \text{,}\) then
\begin{equation*} f' \of{ c } \of{ g \of{ b } - g \of{ a } } = \of{ f \of{ b } - f \of{ a } } g' \of{ c } \end{equation*}
for some point \(a \lt c \lt b \text{.}\)
🔗
🔗

Proof.
Let \(h \colon \clint{ a }{ b } \to \R \) be the constant real-valued function defined by the formula \(h \of{ x } = 1 \text{,}\) and consider the function \(D \colon \clint{ a }{ b } \to \R \) defined as in Lemma 5.2.4 Generalized mean value theorem. Then
\begin{align*} D \of{ x } \amp = \det \of{ \begin{matrix} f \of{ x } \amp g \of{ x } \amp h \of{ x } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} } = \det \of{ \begin{matrix} f \of{ x } \amp g \of{ x } \amp 1 \\ f \of{ a } \amp g \of{ a } \amp 1 \\ f \of{ b } \amp g \of{ b } \amp 1 \end{matrix} }\\ \amp = f \of{ x } \of{ g \of{ a } - g \of{ b } } - g \of{ x } \of{ f \of{ a } - f \of{ b } } + \of{ f \of{ a } g \of{ b } - f \of{ b } g \of{ a } }\text{,} \end{align*}
and so
\begin{equation*} D' \of{ x } = f' \of{ x } \of{ g \of{ a } - g \of{ b } } - g' \of{ x } \of{ f \of{ a } - f \of{ b } }\text{.} \end{equation*}
Lemma 5.2.4 Generalized mean value theorem implies that there is some interior point \(a \lt c \lt b \) so that \(D' \of{ c } = 0 \text{.}\) We observe that
\begin{align*} 0 = D' \of{ c } \amp = f' \of{ c } \of{ g \of{ a } - g \of{ b } } - g' \of{ c } \of{ f \of{ a } - f \of{ b } }\\ f' \of{ c } \of{ g \of{ b } - g \of{ a } } \amp = g' \of{ c } \of{ f \of{ b } - f \of{ a } }\text{.} \end{align*}
