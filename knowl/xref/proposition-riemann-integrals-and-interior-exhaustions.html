Proposition 6.3.6. Riemann integrals and interior exhaustions.

Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \text{,}\) and suppose that the restriction of \(f \) to any compact subinterval of the interior \(\Int \of{ X } \) is integrable. Then for any real number \(I \in \R \text{,}\) the following are equivalent:
  1. For any interior exhaustion \(\of{ \clint{ a_{ \alpha } }{ b_{ \alpha } } }_{ \alpha \in A } \) of \(X \) by compact subintervals,
    \begin{equation*} \lim_{ \alpha \uparrow }{ \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } = I \end{equation*}
    🔗
    🔗
  2. For any positive real number \(\epsilon \text{,}\) there is a compact subinterval \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \in \mathcal{ K }_{ X } \) of \(\Int \of{ X } \) so that
    \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \epsilon \end{equation*}
    for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{.}\)
    🔗
    🔗
🔗
🔗

Proof.
First suppose that
\begin{equation*} \lim_{ \alpha \uparrow }{ \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } = I \end{equation*}
for any interior exhaustion \(\of{ \clint{ a_{ \alpha } }{ b_{ \alpha } } }_{ \alpha \in A } \) of \(X \) by compact subintervals. Then in particular we may choose the maximal such interior exhaustion \(\of{ K }_{ K \in \mathcal{ K }_{ X } } \text{,}\) obtaining the convergence
\begin{equation*} \lim_{ \clint{ a }{ b } \uparrow }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = I\text{.} \end{equation*}
Thus for any positive real number \(\epsilon \gt 0 \text{,}\) there is a compact subinterval \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \in \mathcal{ K }_{ X } \) so that
\begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \epsilon \end{equation*}
for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{.}\)
🔗
Conversely, now suppose that for any positive real number \(\epsilon \gt 0 \text{,}\) there is a compact subinterval \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \in \mathcal{ K }_{ X } \) so that
\begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \epsilon \end{equation*}
for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{,}\) and let \(\of{ \clint{ a_{ \alpha } }{ b_{ \alpha } } }_{ \alpha \in A } \) be an interior exhaustion of \(X \) by compact intervals \(\clint{ a_{ \alpha } }{ b_{ \alpha } } \text{.}\) Lemma 6.3.4 Interior exhaustion by compact subintervals implies that there is an index \(\alpha_{ \epsilon } \in A \) so that
\begin{equation*} \clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a_{ \alpha_{ \epsilon } } }{ b_{ \alpha_{ \epsilon } } } \subseteq \Int \of{ X }\text{.} \end{equation*}
We observe that
\begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \epsilon \end{equation*}
for all indices \(\alpha \succeq \alpha_{ \epsilon } \text{,}\) since in this case
\begin{equation*} \clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a_{ \alpha_{ \epsilon } } }{ b_{ \alpha_{ \epsilon } } } \subseteq \clint{ a_{ \alpha } }{ b_{ \alpha } } \subseteq \Int \of{ X }\text{.} \end{equation*}
We conclude that
\begin{equation*} \lim_{ \alpha \uparrow }{ \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } = I\text{.} \end{equation*}
