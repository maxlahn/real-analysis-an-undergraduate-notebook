Lemma 3.6.14. Cauchy sequences are bounded.

Any Cauchy sequence of points in a metric space is bounded.
🔗
🔗

Proof.
Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a Cauchy sequence of points in a metric space \(\of{ X , \rho } \text{.}\) Then there is a natural number \(n_{ 1 } \in \N \) so that \(\rho \of{ x_{ m } , x_{ n } } \lt 1 \) for all indices \(n \geq n_{ 1 } \text{.}\) Let
\begin{equation*} r = \max \of{ \set{ \rho \of{ x_{ 1 } , x_{ n } } , \dotsc , \rho \of{ x_{ n_{ 1 } - 1 } , x_{ 0 } } , \rho \of{ x_{ n_{ 1 } } , x_{ 0 } } + 1 } } \gt 0\text{.} \end{equation*}
For all indices \(n \in \N \text{,}\) if \(n \lt n_{ 1 } \text{,}\) then \(\rho \of{ x_{ n } , x_{ 0 } } \leq r \text{.}\) On the other hand, if \(n \geq n_{ 1 } \text{,}\) then
\begin{equation*} \rho \of{ x_{ n } , x_{ 0 } } \leq \rho \of{ x_{ n } , x_{ n_{ 1 } } } + \rho \of{ x_{ n_{ 1 } } , x_{ 0 } } \leq \rho \of{ x_{ n } , x_{ n_{ 1 } } } + 1 \leq r\text{.} \end{equation*}
Thus \(\set{ x_{ n } }_{ n = 0 }^{ \infty } \subseteq \mD_{ r } \of{ x_{ 0 } } \text{,}\) and so the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is bounded.
