Proposition 3.4.18. Metric characterization of boundedness.

A subset of a nonempty metric space is bounded if and only if it is contained in an open ball of finite radius.
🔗
🔗

Proof.
Let \(U \subseteq X \) be a subset of a non-empty metric space \(\of{ X , \rho } \text{.}\) First suppose that \(U \) is bounded, so that \(\diam \of{ U } \lt \infty \text{.}\) Since \(X \neq \emptyset \) is non-empty, it contains a point \(x \in X \text{.}\) If \(U = \emptyset \) is empty, then \(U = \emptyset \subseteq \mB_{ r } \of{ x } \) for any positive real number \(r \gt 0 \text{.}\)
🔗
On the other hand, if \(U \neq \emptyset \) is non-empty, then it contains a point \(u \in U \text{.}\) Let \(r = \diam \of{ U } + 1 \text{,}\) and note that
\begin{equation*} \rho \of{ u , v } \leq \sup_{ s , t \in U }{ \rho \of{ s , t } } = \diam \of{ U } \lt r \end{equation*}
for all points \(v \in U \text{,}\) and so \(U \subseteq \mB_{ r } \of{ u } \text{.}\)
🔗
Conversely, now suppose that \(U \subseteq \mB_{ r } \of{ x } \) for some point \(x \in X \text{.}\) Then Lemma 3.4.15 Monotonicity of the diameter and Lemma 3.4.14 Diameter and radius imply that
\begin{equation*} \diam \of{ U } \leq \diam \of{ \mB_{ r } \of{ x } } \leq 2 r \lt \infty\text{,} \end{equation*}
so that \(U \) is bounded.
