Proposition 7.1.6. Arithmetic of convergent series.

  1. Addition of convergent series.
    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) and \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converge, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } + y_{ n } } \text{,}\) and
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } + y_{ n } } = \sum_{ n = 0 }^{ \infty }{ x_{ n } } + \sum_{ n = 0 }^{ \infty }{ y_{ n } }\text{.} \end{equation*}
    🔗
    🔗
  2. Scalar multiplication of convergent series.
    Let \(c \in \R \) be a real number and \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ c x_{ n } } \text{,}\) and
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ c x_{ n } } = c \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{equation*}
    🔗
    🔗
🔗

Proof.
  1. Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ T_{ n } }_{ n = 0 }^{ \infty } \) be the sequences of partial sums
    \begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ k } } \amp T_{ n } \amp = \sum_{ k = 0 }^{ n }{ y_{ k } }\text{,} \end{align*}
    and denote by \(X \) and \(Y \) the corresponding values of the series
    \begin{align*} X \amp = \sum_{ n = 0 }^{ \infty }{ x_{ n } } = \lim_{ n \to \infty }{ S_{ n } }\\ Y \amp = \sum_{ n = 0 }^{ \infty }{ y_{ n } } = \lim_{ n \to \infty }{ T_{ n } }\text{.} \end{align*}
    Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} \abs{ S_{ n } - X } \lt \frac{ \epsilon }{ 2 } \end{equation*}
    and
    \begin{equation*} \abs{ T_{ n } - Y } \lt \frac{ \epsilon }{ 2 } \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) We observe that
    \begin{align*} \abs{ \sum_{ k = 0 }^{ n }{ x_{ k } + y_{ k } } - \of{ X + Y } } \amp = \abs{ S_{ n } + T_{ n } - X - Y } \leq \abs{ S_{ n } - X } + \abs{ T_{ n } - Y }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } + y_{ n } } \) converges to
    \begin{align*} \sum_{ n = 0 }^{ \infty }{ x_{ n } + y_{ n } } \amp = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ n } + y_{ n } } } = X + Y\\ \amp = \sum_{ n = 0 }^{ \infty }{ x_{ n } } + \sum_{ n = 0 }^{ \infty }{ y_{ n } }\text{.} \end{align*}
    🔗
    🔗
  2. If \(c = 0 \text{,}\) then
    \begin{equation*} \sum_{ k = 0 }^{ n }{ c x_{ k } } = \sum_{ k = 0 }^{ n }{ 0 } = 0 \end{equation*}
    for all indices \(n \in \N \text{,}\) and so
    \begin{align*} \sum_{ n = 0 }^{ \infty }{ c x_{ n } } \amp = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ c x_{ k } } } = \lim_{ n \to \infty }{ 0 } = 0\\ \amp = 0 \sum_{ n = 0 }^{ \infty }{ x_{ n } } = c \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{align*}
    🔗
    We may therefore assume that \(c \neq 0 \text{.}\) Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) be the sequence of partial sums
    \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ k } }\text{,} \end{equation*}
    and denote by \(X \) the corresponding value of the series
    \begin{equation*} X = \sum_{ n = 0 }^{ \infty }{ x_{ n } } = \lim_{ n \to \infty }{ S_{ n } }\text{.} \end{equation*}
    Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} \abs{ S_{ n } - X } \lt \frac{ \epsilon }{ \abs{ c } } \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) We observe that
    \begin{align*} \abs{ \sum_{ k = 0 }^{ n }{ c x_{ k } } - \of{ c X } } \amp = \abs{ c S_{ n } - c X } = \abs{ c } \abs{ S_{ n } - X }\\ \amp \lt \abs{ c } \of{ \frac{ \epsilon }{ \abs{ c } } } = \epsilon \end{align*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that the series \(\sum_{ n = 0 }^{ \infty }{ c x_{ n } } \) converges to
    \begin{align*} \sum_{ n = 0 }^{ \infty }{ c x_{ n } } \amp = \lim_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ c x_{ n } } } = c X\\ \amp = c \sum_{ n = 0 }^{ \infty }{ x_{ n } }\text{.} \end{align*}
