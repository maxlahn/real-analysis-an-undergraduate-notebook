Proposition 3.2.3. Uniqueness of sequential limits in a metric space.

Convergent sequences of points in metric spaces converge to unique points.
🔗
🔗

Proof.
Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \text{,}\) and suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to two points \(x , y \in X \text{.}\) We will show that \(x = y \text{.}\)
🔗
To that end, let \(\epsilon \) be a positive real number, and note that \(\frac{ \epsilon }{ 2 } \) is a positive real number. There are thus natural numbers \(m_{ \frac{ \epsilon }{ 2 } } , n_{ \frac{ \epsilon }{ 2 } } \in \N \) so that \(\rho \of{ x_{ n } , x } \lt \frac{ \epsilon }{ 2 } \) for all indices \(n \geq m_{ \frac{ \epsilon }{ 2 } } \) and \(\rho \of{ x_{ n } , y } \lt \frac{ \epsilon }{ 2 } \) for all indices \(n \geq n_{ \frac{ \epsilon }{ 2 } } \text{.}\)
🔗
Let \(p_{ \epsilon } = \max \of{ m_{ \frac{ \epsilon }{ 2 } } , n_{ \frac{ \epsilon }{ 2 } } } \text{,}\) and note that \(p_{ \epsilon } \geq m_{ \frac{ \epsilon }{ 2 } } \) and \(p_{ \epsilon } \geq n_{ \frac{ \epsilon }{ 2 } } \text{.}\) We conclude that
\begin{equation*} \rho \of{ x , y } \leq \rho \of{ x , x_{ p_{ \epsilon } } } + \rho \of{ x_{ p_{ \epsilon } } , y } = \rho \of{ x_{ p_{ \epsilon } } , x } + \rho \of{ x_{ p_{ \epsilon } } , y } \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon\text{.} \end{equation*}
In summary, we have shown that \(\rho \of{ x , y } \lt \epsilon \) for all positive real numbers \(\epsilon \gt 0 \text{.}\) Since \(\rho \of{ x , y } \geq 0 \) by Lemma 3.1.4 Metrics are non-negative, we conclude that \(\rho \of{ x , y } = 0 \) and hence \(x = y \text{.}\)
