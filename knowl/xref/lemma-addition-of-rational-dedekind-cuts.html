Lemma 2.2.11. Addition of rational Dedekind cuts.

\(X_{ p } + X_{ q } = X_{ p + q } \) for all rational numbers \(p , q \in \Q \text{.}\)
🔗
🔗

Proof.
Let \(r \in \Q \) be a rational number, and suppose first that \(r \in X_{ p } + X_{ q } \text{.}\) Then \(r = s + t \) for some rational numbers \(s \in X_{ p } \) and \(t \in X_{ q } \text{,}\) so that \(s \lt p \) and \(t \lt q \text{.}\) We observe that
\begin{equation*} r = s + t \lt p + q\text{,} \end{equation*}
and so \(r \in X_{ p + q } \text{.}\)
🔗
Conversely, now suppose that \(r \in X_{ p + q } \text{,}\) so that \(r \lt p + q \text{.}\) Consider the rational numbers
\begin{align*} s \amp = p + \frac{ r - \of{ p + q } }{ 2 } \amp t \amp = q + \frac{ r - \of{ p + q } }{ 2 }\text{.} \end{align*}
Since \(\of{ \frac{ r - \of{ p + q } }{ 2 } } \lt 0 \text{,}\) \(s \lt p \) and \(t \lt q \text{,}\) and so \(s \in X_{ p } \) and \(t \in X_{ q } \text{.}\) We conclude that
\begin{align*} r \amp = p + q + \of{ r - \of{ p + q } } = p + \frac{ r - \of{ p + q } }{ 2 } + q + \frac{ r - \of{ p + q } }{ 2 }\\ \amp = s + t \in X_{ p } + X_{ q }\text{.} \end{align*}
🔗
In summary, we have shown that \(r \in X_{ p } + X_{ q } \) if and only if \(r \in X_{ p + q } \text{,}\) and so \(X_{ p } + X_{ q } = X_{ p + q } \text{.}\)
