Theorem 2.3.9. Dedekind completeness of the real numbers.

The real number system \(\of{ \R , + , \cdot , \leq } \) is Dedekind complete.
🔗
🔗

Proof.
Let \(\emptyset \subsetneq U \subseteq \R \) be a non-empty subset of \(U \) which is bounded from above, and consider the indexed union
\begin{equation*} S = \bigcup_{ X \in U }{ X } = \setmid{ q \in \Q }{ q \in X \textrm{ for some } X \in U }\text{.} \end{equation*}
Since \(U \) is a non-empty collection of non-empty subsets of \(\Q \text{,}\) \(S \) is non-empty. Moreover, since \(U \) is bounded from above, there is some Dedekind cut \(Y \in \R \) so that \(X \subseteq Y \) for all \(X \in U \text{.}\) In particular, if \(q \in \Q \setminus Y \text{,}\) then \(q \notin X \) for all \(X \in U \text{,}\) and so \(q \notin S \text{.}\)
🔗
Let \(p , q \in \Q \) be rational numbers, and suppose that \(p \leq q \) and \(q \in S \text{.}\) Since \(q \in S \text{,}\) \(q \in X \) for some \(X \in U \text{,}\) and so \(p \in X \subseteq S \text{.}\)
🔗
Now let \(p \in S \text{,}\) so that \(p \in X \) for some \(X \in U \text{.}\) Since \(X \) does not have a maximum, there is some rational number \(q \in X \subseteq S \) so that \(p \lt q \text{.}\) We conclude that \(S \) does not have a maximum, and so is a Dedekind cut.
🔗
We note that (a) of Problem 1.2.5.5 Indexed intersections and unions implies that for a Dedekind cut \(Y \in \R \text{,}\) \(S \subseteq Y \) if and only if \(X \subseteq Y \) for all \(X \in U \text{;}\) that is, any upper bound for \(U \) in \(\R \) contains \(S \text{,}\) so that
\begin{equation*} S = \min \of{ \setmid{ Y \in \R }{ X \subseteq Y \textrm{ for all } X \in U } } = \sup \of{ U }\text{.} \end{equation*}
