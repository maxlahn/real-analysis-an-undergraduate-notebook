Theorem 2.3.9. Dedekind completeness of the real numbers.

Let \(\emptyset \subsetneq U \subseteq \R \) be a non-empty subset of the real numbers \(\R \text{.}\)
  1. If \(U \) is bounded from above, then \(U \) has a supremum in \(\R \text{.}\)
    🔗
    🔗
  2. If \(U \) is bounded from below, then \(U \) has an infimum in \(\R \text{.}\)
    🔗
    🔗
In particular, the real number system \(\of{ \R , + , \cdot , \leq } \) is Dedekind complete.
🔗
🔗

Proof.
  1. Consider the indexed union
    \begin{equation*} S = \bigcup_{ X \in U }{ X } = \setmid{ q \in \Q }{ q \in X \textrm{ for some } X \in U }\text{.} \end{equation*}
    We note that (a) of Problem 1.2.5.5 Indexed intersections and unions implies that for a Dedekind cut \(Y \in \R \text{,}\) \(S \subseteq Y \) if and only if \(X \subseteq Y \) for all \(X \in U \text{;}\) that is, any upper bound for \(U \) in \(\R \) contains \(S \text{,}\) so that
    \begin{equation*} S = \min \of{ \setmid{ Y \in \R }{ X \subseteq Y \textrm{ for all } X \in U } } = \sup \of{ U }\text{.} \end{equation*}
    🔗
    🔗
  2. Consider the indexed intersection
    \begin{equation*} I = \bigcap_{ X \in U }{ X } = \setmid{ q \in \Q }{ q \in X \textrm{ for all } X \in U }\text{.} \end{equation*}
    We note that (a) of Problem 1.2.5.5 Indexed intersections and unions implies that for a Dedekind cut \(Y \in \R \text{,}\) \(Y \subseteq I \) if and only if \(Y \subseteq X \) for all \(X \in U \text{;}\) that is, \(I \) contains any lower bound for \(U \) in \(\R \text{,}\) so that
    \begin{equation*} I = \max \of{ \setmid{ Y \in \R }{ Y \subseteq X \textrm{ for all } X \in U } } = \inf \of{ U }\text{.} \end{equation*}

    🔗
