Proposition 3.6.3. Convergent sequences are Cauchy.

Any convergent sequence of points in a metric space is Cauchy.
🔗
🔗

Proof.
Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \text{,}\) and suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to a limit \(x \in X \text{.}\)
🔗
Let \(\epsilon \gt 0 \) be a positive real number. Since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
\begin{equation*} \rho \of{ x_{ n } , x } \lt \frac{ \epsilon }{ 2 } \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular, we observe that
\begin{equation*} \rho \of{ x_{ m } , x_{ n } } \leq \rho \of{ x_{ m } , x } + \rho \of{ x , x_{ n } } = \rho \of{ x_{ m } , x } + \rho \of{ x_{ n } , x } \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{equation*}
for all indices \(m , n \geq n_{ \epsilon } \text{.}\) We conclude that the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is Cauchy.
