Lemma 2.4.2. Real numbers as complex numbers.

There is an injective map \(\iota \colon \R \to \C \) so that \(\iota \of{ x_{ 1 } + x_{ 2 } } = \iota \of{ x_{ 1 } } + \iota \of{ x_{ 2 } } \) and \(\iota \of{ x_{ 1 } x_{ 2 } } = \iota \of{ x_{ 1 } } \cdot \iota \of{ x_{ 2 } } \) for all real numbers \(x_{ 1 } , x_{ 2 } \in \R \text{.}\)
🔗
🔗

Proof.
Let \(\iota \colon \R \to \C \) be the function defined by the formula \(\iota \of{ x } = \of{ x , 0 } \text{.}\) Since projection \(\pi \colon \C \to \R \) onto the first factor is a left inverse to \(\iota \text{,}\) \(\iota \) is left-invertible and hence injective by (1) of Theorem 1.2.15 Invertibility. Moreover,
\begin{equation*} \iota \of{ x_{ 1 } + x_{ 2 } } = \of{ x_{ 1 } + x_{ 2 } , 0 } = \of{ x_{ 1 } , 0 } + \of{ x_{ 2 } , 0 } = \iota \of{ x_{ 1 } } + \iota \of{ x_{ 2 } }\text{,} \end{equation*}
and
\begin{align*} \iota \of{ x_{ 1 } x_{ 2 } } \amp = \of{ x_{ 1 } x_{ 2 } , 0 } = \of{ x_{ 1 } x_{ 2 } - 0 \cdot 0 , x_{ 1 } \cdot 0 - 0 \cdot x_{ 2 } }\\ \amp = \of{ x_{ 1 } , 0 } \cdot \of{ x_{ 2 } , 0 } = \iota \of{ x_{ 1 } } \cdot \iota \of{ x_{ 2 } } \end{align*}
for all real numbers \(x_{ 1 } , x_{ 2 } \in \R \text{.}\)
