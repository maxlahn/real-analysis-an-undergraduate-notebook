Example 6.3.8. Improper Riemann integration.

The following are examples and non-examples of improperly integrable functions and their improper Riemann integrals:
  • Let \(p \in \opint{ 0 }{ \infty } \setminus \set{ 1 } \) be a real number, and consider the function \(f \colon \clopint{ 1 }{ \infty } \) defined by the formula \(f \of{ x } = \frac{ 1 }{ x^{ p } } \text{.}\) We observe that
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \frac{ b^{ 1 - p } }{ 1 - p } - \frac{ a^{ 1 - p } }{ 1 - p } = \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } \end{equation*}
    for any compact subinterval \(\clint{ a }{ b } \subseteq \opint{ 1 }{ \infty } \text{.}\) We first note that if \(p \lt 1 \text{,}\) then \(1 - p \gt 0 \text{,}\) and so
    \begin{equation*} \lim_{ b \to \infty }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ b \to \infty }{ \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } } = \infty\text{.} \end{equation*}
    This implies that \(f \) is not improperly integrable in this case.
    🔗
    On the other hand, now suppose that \(p \gt 1 \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Fix real numbers \(1 \lt a_{ \epsilon } \leq b_{ \epsilon } \lt \infty \) so that
    \begin{align*} a_{ \epsilon } \amp \lt \of{ 1 - \frac{ \epsilon \of{ p - 1 } }{ 2 } }^{ \frac{ 1 }{ 1 - p } } \amp b_{ \epsilon } \gt \of{ \frac{ \epsilon \of{ p - 1 } }{ 2 } }^{ \frac{ 1 }{ 1 - p } }\text{.} \end{align*}
    We observe that
    \begin{align*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - \frac{ 1 }{ p - 1 } } \amp = \abs{ \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } + \frac{ 1 }{ 1 - p } } \leq \frac{ \abs{ b^{ 1 - p } } }{ p - 1 } + \frac{ \abs{ 1 - a^{ 1 - p } } }{ p - 1 }\\ \amp = \frac{ b^{ 1 - p } }{ p - 1 } + \frac{ 1 - a^{ 1 - p } }{ p - 1 } \leq \frac{ b_{ \epsilon }^{ 1 - p } }{ p - 1 } + \frac{ 1 - a_{ \epsilon }^{ 1 - p } }{ p - 1 }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
    for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subsetneq \opint{ 0 }{ \infty } \text{.}\) Thus \(f \) is improperly integrable, with improper Riemann integral
    \begin{equation*} \int_{ 1 }^{ \infty }{ f \of{ x } \, \diff{ x } } = \frac{ 1 }{ p - 1 }\text{.} \end{equation*}
    🔗
    🔗
  • Let \(p \in \opint{ 0 }{ \infty } \setminus \set{ 1 } \) be a real number, and consider the function \(f \colon \opclint{ 0 }{ 1 } \) defined by the formula \(f \of{ x } = \frac{ 1 }{ x^{ p } } \text{.}\) We observe that
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \frac{ b^{ 1 - p } }{ 1 - p } - \frac{ a^{ 1 - p } }{ 1 - p } = \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } \end{equation*}
    for any compact subinterval \(\clint{ a }{ b } \subseteq \opint{ 0 }{ 1 } \text{.}\) If We first note that if \(p \gt 1 \text{,}\) then \(1 - p \lt 0 \text{,}\) and so
    \begin{equation*} \lim_{ a \to 0 }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ a \to 0 }{ \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } } = \lim_{ a \to 0 }{ \frac{ a^{ 1 - p } - b^{ 1 - p } }{ p - 1 } } = \infty\text{.} \end{equation*}
    This implies that \(f \) is not improperly integrable in this case.
    🔗
    On the other hand, now suppose that \(0 \lt p \lt 1 \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Fix real numbers \(1 \lt a_{ \epsilon } \leq b_{ \epsilon } \lt \infty \) so that
    \begin{align*} a_{ \epsilon } \amp \lt \of{ \frac{ \epsilon \of{ 1 - p } }{ 2 } }^{ \frac{ 1 }{ 1 - p } } \amp b_{ \epsilon } \gt \of{ 1 - \frac{ \epsilon \of{ 1 - p } }{ 2 } }^{ \frac{ 1 }{ 1 - p } }\text{.} \end{align*}
    We observe that
    \begin{align*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - \frac{ 1 }{ 1 - p } } \amp = \abs{ \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } - \frac{ 1 }{ 1 - p } } \leq \frac{ \abs{ b^{ 1 - p } - 1 } }{ 1 - p } + \frac{ \abs{ a^{ 1 - p } } }{ 1 - p }\\ \amp = \frac{ 1 - b^{ 1 - p } }{ 1 - p } + \frac{ a^{ 1 - p } }{ 1 - p } \leq \frac{ 1 - b_{ \epsilon }^{ 1 - p } }{ 1 - p } + \frac{ a_{ \epsilon }^{ 1 - p } }{ 1 - p }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
    for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subsetneq \opint{ 0 }{ \infty } \text{.}\) Thus \(f \) is improperly integrable, with improper Riemann integral
    \begin{equation*} \int_{ 0 }^{ 1 }{ f \of{ x } \, \diff{ x } } = \frac{ 1 }{ 1 - p }\text{.} \end{equation*}
    🔗
    🔗
  • One question raised by the above examples is the nature of the case \(p = 1 \text{;}\) that is, consider the function \(f \colon \opint{ 0 }{ \infty } \) defined by the formula \(f \of{ x } = \frac{ 1 }{ x } \text{.}\) We will see that \(f \) is not improperly integrable on \(\opclint{ 0 }{ 1 } \) or on \(\clopint{ 1 }{ \infty } \text{.}\)
    🔗
    To that end, we first note that
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \ln \of{ b } - \ln \of{ a } = \ln \of{ \frac{ b }{ a } } \end{equation*}
    for any compact subinterval \(\clint{ a }{ b } \subseteq \opint{ 0 }{ \infty } \text{.}\) In particular, we note that
    \begin{equation*} \lim_{ a \to 0 }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ a \to 0 }{ \ln \of{ \frac{ b }{ a } } } = \infty \end{equation*}
    and
    \begin{equation*} \lim_{ b \to \infty }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ b \to \infty }{ \ln \of{ \frac{ b }{ a } } } = \infty\text{.} \end{equation*}
    These computations imply that the restrictions of \(f \) to the intervals \(\opclint{ 0 }{ 1 } \) and \(\clopint{ 1 }{ \infty } \) are not improperly integrable.
