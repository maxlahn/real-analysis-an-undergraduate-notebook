Proposition 7.1.10. Absolute/conditional series convergence.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\) If the series
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
converges, then its positive and negative parts either both converge, in which case the series
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \end{equation*}
converges, or they both diverge to \(\infty \text{,}\) in which case the series
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \end{equation*}
diverges to \(\infty \text{.}\)
🔗
🔗

Proof.
Let \(\of{ P_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ N_{ n } }_{ n = 0 }^{ \infty } \) be the sequences of partial sums
\begin{align*} P_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ n }^{ + } } \amp N_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ n }^{ - } }\text{.} \end{align*}
Since both \(x^{ + } \) and \(x^{ - } \) are non-negative for any real number \(x \in \R \text{,}\) we observe that
\begin{align*} P_{ n + 1 } \amp = \sum_{ k = 0 }^{ n + 1 }{ x_{ k }^{ + } } = \sum_{ k = 0 }^{ n }{ x_{ k }^{ + } } + x_{ n + 1 }^{ + } \geq P_{ n }\\ N_{ n + 1 } \amp = \sum_{ k = 0 }^{ n + 1 }{ x_{ k }^{ - } } = \sum_{ k = 0 }^{ n }{ x_{ k }^{ - } } + x_{ n + 1 }^{ - } \geq N_{ n }\text{;} \end{align*}
that is, the partial sums \(\of{ P_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ N_{ n } }_{ n = 0 }^{ \infty } \) are non-decreasing. The Monotone convergence theorem now implies that
\begin{align*} \lim_{ n \to \infty }{ P_{ n } } \amp = \sup_{ n \in \N }{ P_{ n } } \amp \lim_{ n \to \infty }{ N_{ n } } \amp = \sup_{ n \in \N }{ N_{ n } }\text{.} \end{align*}
In particular, each of the positive and negative parts \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } \) and \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \) either converges or diverges to \(\infty \text{.}\) It remains to show only that one cannot converge while the other diverges to \(\infty \text{.}\)
🔗
To that end, we first note that if the positive part \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } \) converges, then Lemma 7.1.9 Positive/negative parts and magnitude and Proposition 7.1.6 Arithmetic of convergent series imply that
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } - x_{ n } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } - \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
converges, in which case
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } + x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } + \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \end{equation*}
converges by another application of Lemma 7.1.9 Positive/negative parts and magnitude and (1) of Proposition 7.1.6 Arithmetic of convergent series.
🔗
Finally, we note that if the negative part \(\sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \) converges, then Lemma 7.1.9 Positive/negative parts and magnitude and (1) of Proposition 7.1.6 Arithmetic of convergent series imply that
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } = \sum_{ n = 0 }^{ \infty }{ x_{ n } + x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ x_{ n } } + \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \end{equation*}
converges, in which case
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } + x_{ n }^{ - } } = \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ + } } + \sum_{ n = 0 }^{ \infty }{ x_{ n }^{ - } } \end{equation*}
converges by another application of Lemma 7.1.9 Positive/negative parts and magnitude and (1) of Proposition 7.1.6 Arithmetic of convergent series.
