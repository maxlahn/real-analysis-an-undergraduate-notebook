Corollary 2.2.6. Ordering Dedekind cuts by containment.

The standard ordering \(\leq \) on the rational numbers \(\Q \) is the pullback of set containment \(\subseteq \) on the set \(\R \) of Dedekind cuts.
🔗
🔗

Proof.
Let \(q_{ 1 } , q_{ 2 } \in \Q \) be rational numbers. We note that
\begin{align*} X_{ q_{ 1 } } \amp = \setmid{ p \in \Q }{ p \lt q_{ 1 } }\\ X_{ q_{ 2 } } \amp = \setmid{ p \in \Q }{ p \lt q_{ 2 } }\text{.} \end{align*}
First suppose that \(q_{ 1 } \leq q_{ 2 } \text{.}\) If \(p \in X_{ q_{ 1 } } \text{,}\) then
\begin{equation*} p \lt q_{ 1 } \leq q_{ 2 } \end{equation*}
and so \(p \in X_{ q_{ 2 } } \text{;}\) that is,
\begin{equation*} \iota \of{ q_{ 1 } } = X_{ q_{ 1 } } \subseteq X_{ q_{ 2 } } = \iota \of{ q_{ 2 } }\text{,} \end{equation*}
so that \(q_{ 1 } \subseteq_{ \iota } q_{ 2 } \text{.}\)
🔗
Conversely, now suppose that \(q_{ 1 } \subseteq_{ \iota } q_{ 2 } \text{.}\) Then
\begin{equation*} X_{ q_{ 1 } } = \iota \of{ q_{ 1 } } \subseteq \iota \of{ q_{ 2 } } = X_{ q_{ 2 } }\text{.} \end{equation*}
If \(q_{ 1 } \gt q_{ 2 } \text{,}\) then
\begin{equation*} q_{ 2 } \lt \frac{ q_{ 1 } + q_{ 2 } }{ 2 } \lt q_{ 1 }\text{,} \end{equation*}
and so \(\frac{ q_{ 1 } + q_{ 2 } }{ 2 } \in X_{ q_{ 1 } } \setminus X_{ q_{ 2 } } \text{.}\) This would imply that \(X_{ q_{ 1 } } \not \subseteq X_{ q_{ 2 } } \text{,}\) and so we must have \(q_{ 1 } \leq q_{ 2 } \text{.}\)
🔗
In summary, we have shown that \(q_{ 1 } \leq q_{ 2 } \) if and only if \(q_{ 1 } \subseteq_{ \iota } q_{ 2 } \text{,}\) and so \(\leq \) and \(\subseteq_{ \iota } \) are the same binary relation on \(\Q \text{.}\)
