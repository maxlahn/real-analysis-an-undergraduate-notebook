Proposition 7.2.9 (Jean Le Rond d’Alembert). Ratio test.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of non-zero real numbers \(x_{ n } \in \R \setminus \set{ 0 } \text{.}\)
  1. If
    \begin{equation*} \limsup_{ n \to \infty }{ \abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } } \lt 1\text{,} \end{equation*}
    then the series \(\sum_{ n = 0 }^{ \infty }{ a_{ n } } \) converges absolutely.
    🔗
    🔗
  2. If
    \begin{equation*} \liminf_{ n \to \infty }{ \abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } } \gt 1\text{,} \end{equation*}
    then the series \(\sum_{ n = 0 }^{ \infty }{ a_{ n } } \) diverges.
    🔗
    🔗
🔗
🔗

Proof.
  1. Let \(L = \limsup_{ n \to \infty }{ \abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } } \lt 1 \text{,}\) and consider the positive real number
    \begin{equation*} r = \frac{ L + 1 }{ 2 } = L + \frac{ 1 - L }{ 2 } \lt 1 \end{equation*}
    Then there is a natural number \(m \in \N \) so that \(\abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } \leq r \) for all indices \(n \geq m \text{.}\) In particular, we see that
    \begin{equation*} 0 \leq \abs{ a_{ n } } \leq \of{ \frac{ \abs{ a_{ m } } }{ r^{ m } } } r^{ n } \end{equation*}
    for all indices \(n \geq m \text{.}\) The Direct comparison test now implies that the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ \abs{ a_{ n } } } \end{equation*}
    converges, and so the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a_{ n } } \end{equation*}
    converges absolutely by Corollary 7.2.4 Absolute convergence implies convergence.
    🔗
    🔗
  2. Let \(L = \liminf_{ n \to \infty }{ \abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } } \gt 1 \text{,}\) and consider the positive real number
    \begin{equation*} r = \frac{ L + 1 }{ 2 } = L - \frac{ L - 1 }{ 2 } \gt 1\text{.} \end{equation*}
    Then there is a natural number \(m \in \N \) so that \(\abs{ \frac{ a_{ n + 1 } }{ a_{ n } } } \geq r \) for all indices \(n \geq m \text{.}\) In particular, we see that
    \begin{equation*} \abs{ a_{ n } } \geq \of{ \frac{ \abs{ a_{ m } } }{ r^{ m } } } r^{ n } \geq \frac{ \abs{ a_{ m } } }{ r^{ m } } \end{equation*}
    for all indices \(n \geq m \text{,}\) and so the sequence \(\of{ a_{ n } }_{ n = 0 }^{ \infty } \) does not converge to \(0 \text{.}\) We conclude by Proposition 7.1.5 Convergent series have convergent terms implies that the series
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a_{ n } } \end{equation*}
    diverges.
    🔗
