Theorem 3.6.19 (Eduard Heine; Georg Cantor). Heine-Cantor theorem.

A continuous map from a compact metric space to a metric space is uniformly continuous.
🔗
🔗

Proof.
Let \(f \colon X \to Y \) be a map from a compact metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{,}\) and suppose that \(f \) is not uniformly continuous. Then there is a positive real number \(\epsilon \gt 0 \) so that for all positive real numbers \(\delta \gt 0 \text{,}\)
\begin{equation*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \geq \epsilon \end{equation*}
for some points \(x_{ 1 } , x_{ 2 } \in X \) with \(\rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\)
🔗
Let \(\of{ \delta_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of positive real numbers \(\delta_{ n } \gt 0 \) so that
\begin{equation*} \lim_{ n \to \infty }{ \delta_{ n } } = 0\text{.} \end{equation*}
For each index \(n \in \N \text{,}\) there are points \(x_{ 1 , n } , x_{ 2 , n } \in X \) so that \(\rho_{ X } \of{ x_{ 1 , n } , x_{ 2 , n } } \lt \delta_{ n } \) but \(\rho_{ Y } \of{ f \of{ x_{ 1 , n } } , f \of{ x_{ 2 , n } } } \geq \epsilon \text{.}\) Since \(X \) is compact, the sequence \(\of{ x_{ 2 , n } }_{ n = 0 }^{ \infty } \) has a convergent subsequence \(\of{ x_{ 2 , n_{ k } } }_{ k = 0 }^{ \infty } \text{;}\) that is,
\begin{equation*} \lim_{ k \to \infty }{ x_{ 2 , n_{ k } } } = x \end{equation*}
for some point \(x \in X \text{.}\) We will argue that \(\of{ x_{ 1 , n_{ k } } }_{ k = 0 }^{ \infty } \) also converges to \(x \text{.}\) Indeed, let \(\epsilon \gt 0 \) be a positive real number. Since \(\of{ \delta_{ n } }_{ n = 0 }^{ \infty } \) converges to \(0 \text{,}\) there is some natural number \(n_{ \epsilon } \in \N \) so that
\begin{equation*} \delta_{ n } \lt \frac{ \epsilon }{ 2 } \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{.}\) Moreover, since \(\of{ x_{ 2 , n_{ k } } }_{ k = 0 }^{ \infty } \) converges to \(x \text{,}\) there is a natural number \(k_{ \epsilon } \in \N \) so that
\begin{equation*} \rho_{ X } \of{ x_{ 2 , n_{ k } } , x } \lt \frac{ \epsilon }{ 2 } \end{equation*}
for all indices \(k \geq k_{ \epsilon } \text{.}\) Let \(m_{ \epsilon } = \max \of{ \set{ n_{ \epsilon } , k_{ \epsilon } } } \in \N \text{,}\) and note that Lemma 3.6.10 Increasing functions implies that \(n_{ k } \geq m_{ \epsilon } \) whenever \(k \geq m_{ \epsilon } \text{.}\) In particular, this implies that
\begin{align*} \rho_{ X } \of{ x_{ 1 , n_{ k } } , x } \amp \leq \rho_{ X } \of{ x_{ 1 , n_{ k } } , x_{ 2 , n_{ k } } } + \rho_{ X } \of{ x_{ 2 , n_{ k } } , x } \lt \delta_{ n } + \rho_{ X } \of{ x_{ 2 , n_{ k } } , x }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
for all indices \(k \geq m_{ \epsilon } \text{.}\) Thus \(\of{ x_{ 1 , n_{ k } } }_{ k = 0 }^{ \infty } \) also converges to \(x \text{.}\)
🔗
If \(f \) were continuous at \(x \text{,}\) then both \(\of{ f \of{ x_{ 1 , n_{ k } } } }_{ k = 0 }^{ \infty } \) and \(\of{ f \of{ x_{ 2 , n_{ k } } } }_{ k = 0 }^{ \infty } \) would converge to \(f \of{ x } \text{.}\) In this case, we would see that
\begin{align*} \epsilon \amp \leq \lim_{ k \to \infty }{ \rho_{ Y } \of{ f \of{ x_{ 1 , n_{ k } } } , f \of{ x_{ 2 , n_{ k } } } } } \leq \lim_{ k \to \infty }{ \of{ \rho_{ Y } \of{ f \of{ x_{ 1 , n_{ k } } } , f \of{ x } } + \rho_{ Y } \of{ f \of{ x_{ 2 , n_{ k } } } , x } } }\\ \amp = \lim_{ k \to \infty }{ \rho_{ Y } \of{ f \of{ x_{ 1 , n_{ k } } } , f \of{ x } } } + \lim_{ k \to \infty }{ \rho_{ Y } \of{ f \of{ x_{ 2 , n_{ k } } } , f \of{ x } } } = 0 + 0 = 0 \end{align*}
This contradiction implies that \(f \) is not continuous at \(x \text{.}\)
🔗
In summary, we have shown that if \(f \) is not uniformly continuous, then it is not continuous. Equivalently, if \(f \) is continuous, then it is uniformly continuous.
