Corollary 3.6.16. Completeness of the \(p \)-norm.

\(\of{ \R^{ n } , \norm{ \oparg }_{ p } } \) is a Banach space for all natural numbers \(n \in \N \) and extended real numbers \(1 \leq p \leq \infty \text{.}\)
🔗
🔗

Proof.
Let \(\of{ \vect{ x }_{ m } }_{ m = 0 }^{ \infty } \) be a Cauchy sequence of points \(\vect{ x }_{ m } = \of{ x_{ m , k } }_{ k = 1 }^{ n } \in \R^{ n } \) in the metric space \(\of{ \R^{ n } , d_{ p } } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(m_{ \epsilon } \gt 0 \) so that
\begin{equation*} d \of{ \vect{ x }_{ m } , \vect{ x }_{ p } } \lt \epsilon \end{equation*}
for all indices \(m , p \geq m_{ \epsilon } \text{.}\) We observe that for each index \(1 \leq k \leq n \text{,}\)
\begin{equation*} d \of{ x_{ m , k } , x_{ p , k } } = \abs{ x_{ m , k } - x_{ p , k } } \leq \norm{ \vect{ x }_{ m } - \vect{ x }_{ p } }_{ p } = d_{ p } \of{ \vect{ x }_{ m } , \vect{ x }_{ p } } \lt \epsilon \end{equation*}
for all indices \(m , p \geq m_{ \epsilon } \text{,}\) and so \(\of{ x_{ m , k } }_{ m = 0 }^{ \infty } \) is a Cauchy sequence of real numbers.
🔗
Corollary 3.6.15 Completeness of the real line now implies that this sequence converges to some real number
\begin{equation*} x_{ k } = \lim_{ m \to \infty }{ x_{ m , k } }\text{.} \end{equation*}
Let \(\vect{ x } = \of{ x_{ k } }_{ k = 1 }^{ n } \in \R^{ n } \text{.}\) Theorem 3.2.7 Sequential convergence in the \(p \)-metric and Problem 3.2.5.2 Sequential convergence in the infinity metric now imply that \(\of{ \vect{ x }_{ m } }_{ m = 0 }^{ \infty } \) converges to \(\vect{ x } \text{.}\)
🔗
Since every Cauchy sequence in \(\of{ \R^{ n } , d_{ p } } \) converges, this metric space is complete. We conclude that \(\of{ \R^{ n } , \norm{ \oparg }_{ p } } \) is a Banach space.
