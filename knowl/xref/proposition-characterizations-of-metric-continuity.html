Proposition 3.5.1. Characterizations of metric continuity.

Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) For a point \(c \in X \text{,}\) the following are equivalent:
  1. Convergence characterization of continuity.
    The map \(f \) converges at \(c \) to \(f \of{ c } \text{.}\)
    🔗
    🔗
  2. \(\epsilon \)-\(\delta \) characterization of continuity.
    For all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } \lt \epsilon \text{.}\)
    🔗
    🔗
  3. Neighborhood characterization of continuity.
    The pre-image \(f^{ -1 } \of{ N } \) of any neighborhood \(N \) of \(f \of{ c } \) in \(Y \) is a neighborhood of \(c \) in \(X \text{.}\)
    🔗
    🔗
  4. Sequential characterization of continuity.
    For every sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \text{,}\) if
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{,} \end{equation*}
    then
    \begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = f \of{ c }\text{.} \end{equation*}
    🔗
    🔗
🔗
🔗

Proof.
First suppose that \(f \) converges at \(c \) to \(f \of{ c } \text{,}\) and let \(\epsilon \gt 0 \text{.}\) Then there exists a positive real number \(\delta \gt 0 \) so that for all points \(x \in X \text{,}\) if \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } \lt \epsilon \text{.}\) We note that if \(\rho_{ X } \of{ x , c } = 0 \text{,}\) then the non-degeneracy of \(\rho_{ X } \) implies that \(x = c \text{.}\) In this case, \(f \of{ x } = f \of{ c } \text{,}\) and so \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } = 0 \text{.}\)
🔗
Now suppose that for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } \lt \epsilon \text{,}\) and let \(N \subseteq Y \) be a neighborhood of \(f \of{ c } \) in \(Y \text{.}\) Then \(\mB_{ \epsilon } \of{ f \of{ c } } \subseteq N \) for some positive real number \(\epsilon \gt 0 \text{.}\)
🔗
Since \(\epsilon \gt 0 \) is positive, there is a positive real number \(\delta \gt 0 \) so that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } \lt \epsilon \text{.}\) In particular,
\begin{equation*} f \of{ \mB_{ \delta } \of{ c } } \subseteq \mB_{ \epsilon } \of{ f \of{ c } } \subseteq N\text{,} \end{equation*}
and so \(\mB_{ \delta } \of{ c } \subseteq f^{ -1 } \of{ N } \text{;}\) that is, \(f^{ -1 } \of{ N } \) is a neighborhood of \(c \) in \(X \text{.}\)
🔗
Now suppose that the pre-image \(f^{ -1 } \of{ N } \) of any neighborhood \(N \) of \(f \of{ c } \) in \(Y \) is a neighborhood of \(c \) in \(X \text{,}\) and let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) so that
\begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{.} \end{equation*}
Let \(\epsilon \gt 0 \) be a positive real number. Then \(\mB_{ \epsilon } \of{ f \of{ c } } \) is a neighborhood of \(f \of{ c } \) in \(Y \text{,}\) and so \(f^{ -1 } \of{ \mB_{ \epsilon } \of{ f \of{ c } } } \) is a neighborhood of \(c \) in \(X \text{.}\) Thus
\begin{equation*} \mB_{ \delta } \of{ c } \subseteq f^{ -1 } \of{ \mB_{ \epsilon } \of{ f \of{ c } } } \end{equation*}
for some positive real number \(\delta \gt 0 \text{.}\) Since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(c \text{,}\) there is some natural number \(n_{ \epsilon } \in \N \) so that \(\rho_{ X } \of{ x_{ n } , c } \lt \delta \) for all indices \(n \geq n_{ \epsilon } \text{.}\) This implies that
\begin{equation*} f \of{ x_{ n } } \in f \of{ \mB_{ \delta } \of{ c } } \subseteq \mB_{ \epsilon } \of{ f \of{ c } } \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{,}\) and so \(\rho_{ Y } \of{ f \of{ x_{ n } } , f \of{ c } } \lt \epsilon \) for all such indices. We conclude that
\begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = f \of{ c }\text{.} \end{equation*}
🔗
Finally, suppose that for every sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \text{,}\) if
\begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{,} \end{equation*}
then
\begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = f \of{ c }\text{.} \end{equation*}
Then Theorem 3.2.19 Sequential characterization of map convergence implies that \(f \) converges at \(c \) to \(f \of{ c } \text{.}\)
