Lemma 4.1.8. Topological subspaces of metric spaces.

Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{.}\) Then \(\rest{ \tau_{ \rho } }_{ U } = \tau_{ \rest{ \rho }_{ U } } \text{.}\)
🔗
🔗

Proof.
Part (a) of Problem 3.4.5.1 Open and closed sets in metric subspaces implies that a subset \(V \subseteq U \) is open in \(U \) if and only if \(V = U \cap W \) for some open subset \(W \subseteq X \text{;}\) that is, \(V \in \tau_{ \rest{ \rho }_{ U } } \) if and only if \(V = U \cap W \) for some \(W \in \tau_{ \rho } \text{.}\) We conclude that \(\tau_{ \rest{ \rho }_{ U } } = \rest{ \tau_{ \rho } }_{ U } \text{.}\)
