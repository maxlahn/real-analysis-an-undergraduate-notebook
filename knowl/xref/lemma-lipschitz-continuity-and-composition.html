Lemma 3.5.22. Lipschitz continuity and composition.

Let \(f \colon X \to Y \) and \(g \colon Y \to Z \) be maps between metric spaces \(\of{ X , \rho_{ X } } \text{,}\) \(\of{ Y , \rho_{ Y } } \text{,}\) and \(\of{ Z , \rho_{ Z } } \text{.}\) If \(f \) and \(g \) are Lipschitz continuous, then so is their composition \(g \circ f \colon X \to Z \text{,}\) and \(L_{ g \circ f } \leq L_{ g } L_{ f } \text{.}\)
🔗
🔗

Proof.
We observe that
\begin{align*} \rho_{ Z } \of{ \of{ g \circ f } \of{ x_{ 1 } } , \of{ g \circ f } \of{ x_{ 2 } } } \amp = \rho_{ Z } \of{ g \of{ f \of{ x_{ 1 } } } , g \of{ f \of{ x_{ 2 } } } }\\ \amp \leq L_{ g } \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } }\\ \amp \leq L_{ g } L_{ f } \rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \end{align*}
for all points \(x_{ 1 } , x_{ 2 } \in X \text{.}\) We conclude that the composition \(g \circ f \) is Lipschitz continuous and \(L_{ g \circ f } \leq L_{ g } L_{ f } \text{.}\)
