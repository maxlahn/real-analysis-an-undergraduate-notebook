Lemma 5.2.4. Local extrema are stationary points.

Let \(f \colon X \to \R \) be a real-valued function defined on a subset \(X \subseteq \R \) which attains a local extremum at a point \(c \in X \) so that every neighborhood of \(c \) contains points strictly greater than \(c \) and points strictly less than \(c \text{.}\) If \(f \) is differentiable at \(c \text{,}\) then \(f' \of{ c } = 0 \text{;}\) that is, \(c \) is a stationary point of \(f \text{.}\)
🔗
🔗

Proof.
By contraposition. Suppose first that \(f' \of{ c } \gt 0 \) is positive. Then since \(\frac{ f' \of{ c } }{ 2 } \gt 0 \) is positive, there is some positive real number \(\delta \gt 0 \) so that
\begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt \frac{ f' \of{ c } }{ 2 } \end{equation*}
for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) In particular,
\begin{equation*} \frac{ f \of{ x } - f \of{ c } }{ x - c } \gt f' \of{ c } - \frac{ f' \of{ c } }{ 2 } = \frac{ f' \of{ c } }{ 2 } \gt 0 \end{equation*}
for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) so that \(f \of{ x } - f \of{ c } \) and \(x - c \) have the same sign; that is, so long as \(x \in \clint{ a }{ b } \) and \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then \(f \of{ x } \lt f \of{ c } \) if \(x \lt c \) and \(f \of{ x } \gt f \of{ c } \) if \(x \gt c \text{.}\) In particular, since the neighborhood \(\mB_{ \delta } \of{ c } = \opint{ c - \delta }{ c + \delta } \cap X \) contains points strictly less than \(c \) and contains points strictly larger than \(c \text{,}\) we conclude that \(f \) does not achieve a maximum or minimum at \(c \text{.}\)
🔗
Similarly, now suppose that \(f' \of{ c } \lt 0 \) is negative. Then since \(-\frac{ f' \of{ c } }{ 2 } \gt 0 \) is positive, there is some positive real number \(\delta \gt 0 \) so that
\begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt -\frac{ f' \of{ c } }{ 2 } \end{equation*}
for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) In particular,
\begin{equation*} \frac{ f \of{ x } - f \of{ c } }{ x - c } \lt -f' \of{ c } + \frac{ f' \of{ c } }{ 2 } = -\frac{ f' \of{ c } }{ 2 } \lt 0 \end{equation*}
for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) so that \(f \of{ x } - f \of{ c } \) and \(x - c \) have opposite sign; that is, so long as \(x \in \clint{ a }{ b } \) and \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then \(f \of{ x } \gt f \of{ c } \) if \(x \lt c \) and \(f \of{ x } \lt f \of{ c } \) if \(x \gt c \text{.}\) In particular, since the neighborhood \(\mB_{ \delta } \of{ c } = \opint{ c - \delta }{ c + \delta } \cap X \) contains points strictly less than \(c \) and contains points strictly larger than \(c \text{,}\) we conclude that \(f \) does not achieve a maximum or minimum at \(c \text{.}\)
