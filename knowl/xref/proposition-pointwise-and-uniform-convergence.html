Proposition 3.2.13. Pointwise and uniform convergence.

If a sequence of maps from a set to a metric space converges uniformly, then it converges pointwise.
🔗
🔗

Proof.
Suppose that a sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of maps \(f_{ n } \colon X \to Y \) from a set \(X \) to a metric space \(\of{ Y , \rho } \) converges uniformly to a map \(f \colon X \to Y \) from \(X \) to \(Y \text{.}\) Then for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
\begin{equation*} \rho \of{ f_{ n } \of{ x } , f \of{ x } } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \) and inputs \(x \in X \text{.}\) In particular, for each input \(x \in X \text{,}\)
\begin{equation*} \rho \of{ f_{ n } \of{ x } , f \of{ x } } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{,}\) and so the sequence \(\of{ f_{ n } \of{ x } }_{ n = 0 }^{ \infty } \) converges to \(f \of{ x } \text{.}\) We conclude that \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges pointwise to \(f \text{.}\)
