Lemma 3.4.6. Openness and closedness.

Open balls in metric spaces are open, and closed disks are closed.
🔗
🔗

Proof.
Fix a positive real number \(r \gt 0 \) and a point \(c \in X \) in a metric space \(\of{ X , \rho } \text{.}\) Let \(U = \mB_{ r } \of{ c } \) and \(V = \mD_{ r } \of{ c } \) be the open ball and closed disk of radius \(r \) and center \(c \text{,}\) respectively. We will show that \(U \) and \(V \) are open and closed in \(X \text{,}\) respectively.
🔗
To that end, first let \(u \in U \text{,}\) so that \(\rho \of{ u , c } \lt r \text{.}\) Let
\begin{equation*} s = r - \rho \of{ u , c }\text{.} \end{equation*}
We note that for a point \(x \in X \text{,}\) if \(\rho \of{ x , u } \lt s \text{,}\) then
\begin{align*} \rho \of{ x , c } \amp \leq \rho \of{ x , u } + \rho \of{ u , c } \lt s + r\\ \amp = r - \rho \of{ u , c } + \rho \of{ u , c } = r\text{,} \end{align*}
and so \(x \in U \text{.}\) Thus \(\mB_{ s } \of{ u } \subseteq \mB_{ r } \of{ c } = U \text{.}\) Since \(U \) contains an open ball centered at each of its points, it is a neighborhood of each of its points, and so \(U \) is open in \(X \text{.}\)
🔗
On the other hand, now suppose that \(x \in X \setminus V \text{,}\) so that \(\rho \of{ x , c } \gt r \text{.}\) Let
\begin{equation*} s = \rho \of{ x , c } - r\text{.} \end{equation*}
We note that for a point \(y \in X \text{,}\) if \(\rho \of{ y , x } \lt s \text{,}\) then
\begin{align*} r + s \amp = \rho \of{ x , c } \leq \rho \of{ x , y } + \rho \of{ y , c }\\ \amp = \rho \of{ y , x } + \rho \of{ y , c } \lt s + \rho \of{ y , c }\text{.} \end{align*}
We conclude that \(\rho \of{ y , c } \gt r \text{,}\) and so \(y \notin \mD_{ r } \of{ c } = V \text{.}\) Since \(X \setminus V \) contains an open ball centered at each of its points, it is a neighborhood of each of its points, and so \(X \setminus V \) is open in \(X \text{;}\) that is, \(V \) is closed in \(X \text{.}\)
