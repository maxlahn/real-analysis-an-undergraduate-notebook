Lemma 7.2.1. Comparison of non-negative series.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{,}\) and suppose that \(0 \leq x_{ n } \leq y_{ n } \) for all natural numbers \(n \in \N \text{.}\)
  1. If the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converges, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converge.
    🔗
    🔗
  2. If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) diverges, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) diverge.
    🔗
    🔗
🔗
🔗

Proof.
Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ T_{ n } }_{ n = 0 }^{ \infty } \) be the corresponding sequences of partial sums
\begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ k } } \amp T_{ n } \amp = \sum_{ k = 0 }^{ n }{ y_{ k } }\text{.} \end{align*}
We observe that
\begin{equation*} S_{ n + 1 } = \sum_{ k = 0 }^{ n + 1 }{ x_{ k } } = \sum_{ k = 0 }^{ n }{ x_{ k } } + x_{ n + 1 } \geq S_{ n } \end{equation*}
for all indices \(n \in \N \text{,}\) so that \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) is non-decreasing. Similarly, \(\of{ T_{ n } }_{ n = 0 }^{ \infty } \) is non-decreasing. The Monotone convergence theorem implies that
\begin{align*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \amp = \lim_{ n \to \infty }{ S_{ n } } = \sup_{ n \in \N }{ S_{ n } }\\ \sum_{ n = 0 }^{ \infty }{ y_{ n } } \amp = \lim_{ n \to \infty }{ T_{ n } } = \sup_{ n \in \N }{ T_{ n } }\text{.} \end{align*}
Finally, we observe that
\begin{equation*} \sup_{ n \in \N }{ S_{ n } } = \sup_{ n \in \N }{ \sum_{ k = 0 }^{ n }{ x_{ k } } } \leq \sup_{ n \in \N }{ \sum_{ k = 0 }^{ n }{ y_{ k } } } = \sup_{ n \in \N }{ T_{ n } } \end{equation*}
  1. If the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converges, then \(\sup_{ n \in \N }{ T_{ n } } \lt \infty \) is finite, and so
    \begin{equation*} \sup_{ n \in \N }{ S_{ n } } \leq \sup_{ n \in \N }{ T_{ n } } \lt \infty \end{equation*}
    is finite as well. This implies that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges.
    🔗
  2. If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) diverges, then \(\sup_{ n \in \N }{ S_{ n } } = \infty \) is infinite, and so
    \begin{equation*} \infty = \sup_{ n \in \N }{ S_{ n } } \leq \sup_{ n \in \N }{ T_{ n } } \leq \infty\text{;} \end{equation*}
    that is, \(\sup_{ n \in \N }{ T_{ n } } = \infty \) is infinite as well. This implies that the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) diverges.
    🔗
