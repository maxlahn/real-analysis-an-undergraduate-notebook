Theorem 5.2.5 (Pierre de Fermat). Interior extremum theorem.

Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \) which attains a local extremum at an interior point \(c \in \Int \of{ X } \text{.}\) If \(f \) is differentiable at \(c \text{,}\) then \(f' \of{ c } = 0 \text{;}\) that is, \(c \) is a stationary point of \(f \text{.}\)
🔗
🔗

Proof.
Any neighborhood \(N \in \Nbhd_{ X } \of{ c } \) of an interior point \(c \in \Int \of{ X } \) contains an open interval containing \(c \text{,}\) and therefore contains points strictly greater than \(c \) and points strictly less than \(c \text{.}\) The desired conclusion now follows immediately from Lemma 5.2.4 Local extrema are stationary points.
