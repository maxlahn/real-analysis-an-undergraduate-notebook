Theorem 2.3.10. Uniqueness of the real numbers.

If \(\of{ F , + , \cdot , \leq } \) is a Dedekind complete ordered field, then there is a bijection \(\varphi \colon \R \to F \) so that for all real numbers \(x , y \in \R \text{,}\) \(\varphi \of{ x + y } = \varphi \of{ x } + \varphi \of{ y } \text{,}\) \(\varphi \of{ x \cdot y } = \varphi \of{ x } \cdot \varphi \of{ y } \text{,}\) and if \(x \leq y \text{,}\) then \(\varphi \of{ x } \leq \varphi \of{ y } \text{.}\)
