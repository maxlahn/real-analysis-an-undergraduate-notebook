Theorem 3.6.13 (Bernard Bolzano; Karl Weierstrass). Bolzano-Weierstrass theorem.

Any bounded sequence of real numbers has a convergent subsequence.
🔗
🔗

Proof.
Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \) which is bounded in the Euclidean metric on \(\R \text{.}\) For each natural number \(m \in \N \text{,}\) consider the set
\begin{equation*} T_{ m } = \setmid{ x_{ n } \in \R }{ n \geq m }\text{.} \end{equation*}
There are two cases: either \(T_{ m } \) has a maximum for every index \(m \in \N \) or \(T_{ m } \) does not have a maximum for some index \(m \in \N \text{.}\) We will show that in either case, \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) has a monotone subsequence.
🔗
First suppose that \(T_{ m } \) has a maximum for each index \(m \in \N \text{.}\) Consider the sequence \(\of{ n_{ k } }_{ k = 0 }^{ \infty } \) of natural numbers \(n_{ k } \in \N \) defined recursively by
\begin{align*} n_{ 0 } \amp = \min \of{ \setmid{ n \in \N }{ x_{ n } = \max \of{ T_{ 0 } } } }\\ n_{ k + 1 } \amp = \min \of{ \setmid{ n \in \N }{ n \geq n_{ k } + 1 \textrm{ and } x_{ n } = \max \of{ T_{ n_{ k + 1 } } } } }\text{.} \end{align*}
Since \(n_{ m + 1 } \geq n_{ m } + 1 \gt n_{ m } \text{,}\) the sequence \(\of{ n_{ k } }_{ n = 0 }^{ \infty } \) is increasing, and so \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \) is a subsequence of \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{.}\) Moreover, we observe that
\begin{equation*} x_{ n_{ k + 1 } } = \max \of{ T_{ n_{ k + 1 } } } \leq \min \of{ T_{ n_{ k } } } = x_{ n_{ k } } \end{equation*}
for all indices \(k \in \N \text{,}\) and so \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \) is non-increasing.
🔗
On the other hand, now suppose that \(T_{ m } \) has no maximum for some index \(m \in \N \text{.}\) Consider the sequence \(\of{ n_{ k } }_{ k = 0 }^{ \infty } \) of natural numbers \(n_{ k } \in \N \) defined recursively by
\begin{align*} n_{ 0 } \amp = m\\ n_{ k + 1 } \amp = \min \of{ \setmid{ n \in \N }{ n \geq n_{ k } + 1 \textrm{ and } x_{ n } \gt x_{ n_{ k } } } }\text{.} \end{align*}
Since \(n_{ m + 1 } \geq n_{ m } + 1 \gt n_{ m } \text{,}\) the sequence \(\of{ n_{ k } }_{ n = 0 }^{ \infty } \) is increasing, and so \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \) is a subsequence of \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{.}\) Moreover, we observe that
\begin{equation*} x_{ n_{ k + 1 } } \gt x_{ n_{ k } } \end{equation*}
for all indices \(k \in \N \text{,}\) and so \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \) is increasing.
🔗
In either case, \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) has a monotone subsequence \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \text{.}\) Since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is bounded, so too is \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \text{,}\) and so Theorem 3.3.13 Monotone convergence theorem implies that \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \) converges.
