Proposition 3.6.6. Complete subsets are closed.

A complete subset of a metric space is closed.
🔗
🔗

Proof.
By contraposition. Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{,}\) and suppose that \(U \) is not closed in \(X \text{.}\) Then \(U \subsetneq \Cl \of{ U } = U \cup U' \) by (2) of Proposition 3.4.9 Interior/closure and Problem 3.4.5.3 Closure and limit points, and so \(U' \not \subseteq U \text{;}\) that is, there is some limit point \(x \in U' \) which is not an element of \(U \text{.}\)
🔗
Since \(x \in U' \) is a limit point of \(U \) in \(X \text{,}\)
\begin{equation*} x = \lim_{ n \to \infty }{ u_{ n } } \end{equation*}
for some sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) of points \(u_{ n } \in U \text{.}\) Since \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) converges in \(X \text{,}\) it is Cauchy. However, the limit of this Cauchy sequence of points in \(U \) does not lie in \(U \text{.}\) Thus \(U \) is not complete in \(X \text{.}\)
