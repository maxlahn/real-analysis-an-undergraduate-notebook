Theorem 4.1.14. Interior; closure; boundary.

Let \(U \) be a subset of a metric space \(\of{ X , \tau } \text{.}\)
  1. Interior.
    \(U \) is open in \(X \) if and only if \(\Int \of{ U } = U \text{.}\) More generally, \(U \) has interior
    \begin{equation*} \Int \of{ U } = \bigcup_{ V \in \mathcal{ O }_{ U } }{ V } = X \setminus \Cl \of{ X \setminus U }\text{,} \end{equation*}
    where \(\mathcal{ O }_{ U } \) is the collection of open sets in \(X \) which are contained in \(U \text{.}\) Finally, \(\Int \of{ \Int \of{ U } } = \Int \of{ U } \text{.}\)

    🔗
  2. Closure.
    \(U \) is closed in \(X \) if and only if \(\Cl \of{ U } = U \text{.}\) More generally, \(U \) has closure
    \begin{equation*} \Cl \of{ U } = \bigcap_{ V \in \mathcal{ C }_{ U } }{ V } = X \setminus \Int \of{ X \setminus U }\text{,} \end{equation*}
    where \(\mathcal{ C }_{ U } \) is the collection of closed sets in \(X \) which contain \(U \text{.}\) Finally, \(\Cl \of{ \Cl \of{ U } } = \Cl \of{ U } \text{.}\)
    🔗
    🔗
  3. Boundary.
    \(U \) has boundary \(\Bd \of{ U } = \Cl \of{ U } \cap \Cl \of{ X \setminus U } \text{.}\)
