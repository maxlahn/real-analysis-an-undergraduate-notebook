Problem 2. Uniform limits of uniformly continuous maps.

Let \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of uniformly continuous maps \(f_{ n } \colon X \to Y \) from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) Prove that if \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly, the uniform limit is also uniformly continuous.
