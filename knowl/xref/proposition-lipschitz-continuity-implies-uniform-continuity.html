Proposition 3.5.20. Lipschitz continuity implies uniform continuity.

If a map between metric spaces is Lipschitz continuous, then it is uniformly continuous and continuous.
🔗
🔗

Proof.
Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{,}\) and consider a positive real number \(\epsilon \gt 0 \text{.}\) There are two cases; either \(L_{ f } = 0 \text{,}\) or \(0 \lt L_{ f } \lt \infty \text{.}\)
🔗
If \(L_{ f } = 0 \text{,}\) then Proposition 3.5.19 Lipschitz constants and Lipschitz continuity implies that
\begin{equation*} 0 \leq \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \leq L_{ f } \rho_{ X } \of{ x_{ 1 } , x_{ 2 } } = 0 \rho_{ X } \of{ x_{ 1 } , x_{ 2 } } = 0 \lt \epsilon \end{equation*}
for all points \(x_{ 1 } , x_{ 2 } \in X \text{,}\) and so \(f \of{ x_{ 1 } } = f \of{ x_{ 2 } } \) for all points \(x_{ 1 } , x_{ 2 } \in X \text{.}\) In particular, this implies that \(f \) is constant and therefore uniformly continuous.
🔗
If on the other hand \(0 \lt L_{ f } \lt \infty \text{,}\) let \(\delta = \frac{ \epsilon }{ L_{ f } } \text{,}\) and note that Proposition 3.5.19 Lipschitz constants and Lipschitz continuity implies that
\begin{equation*} 0 \leq \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \leq L_{ f } \rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt L_{ f } \of{ \frac{ \epsilon }{ L_{ f } } } = \epsilon \end{equation*}
for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\) Thus \(f \) is uniformly continuous. We conclude that \(f \) is continuous by Proposition 3.5.12 Uniform continuity implies continuity.
