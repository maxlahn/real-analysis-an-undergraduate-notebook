Lemma 5.1.3. Differentiability implies continuity.

A real-valued function \(f \colon X \to \R \) on a subset \(X \subseteq \R \) is continuous at every point \(c \in \DL \of{ f } \text{.}\)
🔗
🔗

Proof.
Let \(f \colon X \to \R \) be a real-valued function on a subset \(X \subseteq \R \text{,}\) and suppose that \(f \) is differentiable at a point \(c \in X \text{.}\) Then there is a positive real number \(\delta_{ f } \gt 0 \) so that
\begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt 1 \end{equation*}
for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta_{ f } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number, and let
\begin{equation*} \delta = \min \of{ \set{ \delta_{ f } , \frac{ \epsilon }{ 1 + \abs{ f' \of{ c } } } } } \gt 0\text{.} \end{equation*}
We observe that
\begin{align*} \abs{ f \of{ x } - f \of{ c } } \amp = \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } \cdot \abs{ x - c } = \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } + f' \of{ c } } \cdot \abs{ x - c }\\ \amp \leq \of{ \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } + \abs{ f' \of{ c } } } \abs{ x - c }\\ \amp \lt \of{ 1 + \abs{ f' \of{ c } } } \delta \lt \of{ 1 + \abs{ f' \of{ c } } } \of{ \frac{ \epsilon }{ 1 + \abs{ f' \of{ c } } } } = \epsilon \end{align*}
for any point \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) and so we conclude that \(f \) is continuous at \(c \text{.}\)
