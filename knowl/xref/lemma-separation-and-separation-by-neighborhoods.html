Lemma 4.3.18. Separation by neighborhoods and separation.

Two points in a topological space which are separated by neighborhoods are separated.
🔗
🔗

Proof.
Let \(x_{ 1 } , x_{ 2 } \in X \) be points in a topological space \(\of{ X , \tau } \text{.}\) If \(x_{ 1 } \) and \(x_{ 2 } \) are separated by neighborhoods, then there are neighborhoods \(N_{ 1 } \subseteq X \) and \(N_{ 2 } \subseteq X \) of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(N_{ 1 } \cap N_{ 2 } = \emptyset \text{.}\) In particular, \(x_{ 1 } \notin N_{ 2 } \) and \(x_{ 2 } \notin N_{ 1 } \text{,}\) and so \(x_{ 1 } \) and \(x_{ 2 } \) are separated.
