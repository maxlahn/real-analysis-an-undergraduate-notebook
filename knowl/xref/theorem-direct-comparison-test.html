Theorem 7.2.2. Direct comparison test.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and \(\of{ z_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } , z_{ n } \in \R \text{,}\) and suppose that \(x_{ n } \leq y_{ n } \leq z_{ n } \) for all natural numbers \(n \in \N \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) and \(\sum_{ n = 0 }^{ \infty }{ z_{ n } } \) converge, then so does the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \text{.}\)
🔗
🔗

Proof.
Let \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ v_{ n } }_{ n = 0 }^{ \infty } \) be the sequences of real numbers \(u_{ n } , v_{ n } \in \R \) defined by the formulas
\begin{align*} u_{ n } \amp = y_{ n } - x_{ n } \amp v_{ n } \amp = z_{ n } - x_{ n }\text{.} \end{align*}
Then \(0 \leq u_{ n } \leq v_{ n } \) for all indices \(n \in \N \text{,}\) and the series
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ v_{ n } } = \sum_{ n = 0 }^{ \infty }{ \of{ z_{ n } - x_{ n } } } \end{equation*}
converges by Proposition 7.1.6 Arithmetic of convergent series. Thus the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converges by Lemma 7.2.1 Comparison of non-negative series.
