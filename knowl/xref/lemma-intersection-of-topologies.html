Lemma 4.2.3. Intersection of topologies.

The intersection of a collection of topologies on a set is a topology.
🔗
🔗

Proof.
Let \(\of{ \tau_{ j } }_{ j \in \mathcal{ J } } \) be an indexed family of topologies \(\tau_{ j } \in \Topol_{ X } \) on a set \(X \text{,}\) and let
\begin{equation*} \tau = \bigcap_{ j \in \mathcal{ J } }{ \tau_{ j } } \end{equation*}
be the intersection. Since \(\emptyset , X \in \tau_{ j } \) for each index \(j \in \mathcal{ J } \text{,}\) \(\emptyset , X \in \tau \text{;}\) that is, \(\tau \) is non-degenerate.
🔗
Now let \(\of{ U_{ k } }_{ k \in \mathcal{ K } } \) be an indexed family of sets \(U_{ k } \in \tau \text{.}\) We observe that \(U_{ k } \in \tau_{ j } \) for all indices \(j \in \mathcal{ J } \) and \(k \in \mathcal{ K } \text{,}\) and so the stability of each \(\tau_{ j } \) under unions implies that
\begin{equation*} \bigcup_{ k \in \mathcal{ K } }{ U_{ k } } \in \tau_{ j } \end{equation*}
for each index \(j \in \mathcal{ J } \text{.}\) Since this holds for all indices \(j \in \mathcal{ J } \text{,}\)
\begin{equation*} \bigcup_{ k \in \mathcal{ K } }{ U_{ k } } \in \tau\text{;} \end{equation*}
that is, \(\tau \) is stable under unions.
🔗
Finally let \(\of{ U_{ k } }_{ k = 1 }^{ n } \) be a finite sequence of sets \(U_{ k } \in \tau \text{.}\) We observe that \(U_{ k } \in \tau_{ j } \) for all indices \(j \in \mathcal{ J } \) and \(1 \leq k \leq n \text{,}\) and so the stability of each \(\tau_{ j } \) under finite intersection implies that
\begin{equation*} \bigcap_{ k = 1 }^{ n }{ U_{ k } } \in \tau_{ j } \end{equation*}
for each index \(j \in \mathcal{ J } \text{.}\) Since this holds for all indices \(j \in \mathcal{ J } \text{,}\)
\begin{equation*} \bigcup_{ k = 1 }^{ n }{ U_{ k } } \in \tau\text{;} \end{equation*}
that is, \(\tau \) is stable under finite intersections.
🔗
Since \(\tau \) is non-degenerate, stable under unions, and stable under finite intersections, it is a topology on \(X \text{.}\)
