Example 3.5.17. Norms are Lipschitz continuous.

Let \(\of{ V , \norm{ \oparg } } \) be a normed vector space. The Reverse triangle inequality implies that
\begin{equation*} d \of{ \norm{ \vect{ v }_{ 1 } } , \norm{ \vect{ v }_{ 2 } } } = \abs{ \norm{ \vect{ v }_{ 1 } } - \norm{ \vect{ v }_{ 2 } } } \leq \norm{ \vect{ v }_{ 1 } - \vect{ v }_{ 2 } } = 1 \norm{ \vect{ v }_{ 1 } - \vect{ v }_{ 2 } } \end{equation*}
for all vectors \(\vect{ v }_{ 1 } , \vect{ v }_{ 2 } \in V \text{,}\) and so the norm \(\norm{ \oparg } \colon V \to \R \) is Lipschitz continuous.
