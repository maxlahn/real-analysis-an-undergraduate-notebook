Problem 2. De Morgan’s laws.

(a)

Prove that \(S \setminus \of{ T \cap U } = \of{ S \setminus T } \cup \of{ S \setminus U } \) for all sets \(S \text{,}\) \(T \text{,}\) and \(U \text{.}\)
🔗
🔗

(b)

Prove that \(S \setminus \of{ T \cup U } = \of{ S \setminus T } \cap \of{ S \setminus U } \text{.}\)
🔗
🔗
Taken together, these results are called De Morgan’s laws.
