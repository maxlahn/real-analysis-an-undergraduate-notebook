Corollary 3.4.19. Norm characterization of boundedness.

A subset of a normed vector space is bounded if and only if it is contained in an open ball of finite radius centered at the origin.
🔗
🔗

Proof.
Let \(\of{ V , \norm{ \oparg } } \) be a normed vector space. By Proposition 3.4.18 Metric characterization of boundedness, it suffices to show that any bounded subset of \(V \) is contained in an open ball centered at \(\vect{ 0 } \text{.}\) To that end, let \(U \subseteq V \) be a bounded subset of \(V \text{.}\) Proposition 3.4.18 Metric characterization of boundedness implies that \(U \subseteq \mB_{ r } \of{ \vect{ v } } \) for some positive real number \(r \gt 0 \) and some vector \(\vect{ v } \text{.}\)
🔗
Let \(s = r + \norm{ \vect{ v } } \text{,}\) and observe that
\begin{align*} \norm{ \vect{ u } - \vect{ 0 } } \amp = \norm{ \vect{ u } - \vect{ v } + \vect{ v } } \leq \norm{ \vect{ u } - \vect{ v } } + \norm{ \vect{ v } }\\ \amp \lt r + \norm{ \vect{ v } } = s \end{align*}
for all \(\vect{ u } \in U \text{.}\) Thus \(U \subseteq \mB_{ s } \of{ \vect{ 0 } } \text{.}\)
