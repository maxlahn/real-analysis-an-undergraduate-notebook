Problem 2. Sequential convergence in the infinity metric.

Let \(m \in \N \) be a natural number, and consider a sequence \(\of{ \vect{ x }_{ n } }_{ n = 0 }^{ \infty } \) of points \(\vect{ x }_{ n } = \of{ x_{ 1 , n } , \dotsc , x_{ m , n } } \in \R^{ m } \text{.}\) Prove that for any vector \(\vect{ x } = \of{ x_{ 1 } , \dotsc , x_{ m } } \in \R \text{,}\) the following are equivalent:
  1. The sequence \(\of{ \vect{ x }_{ n } }_{ n = 0 }^{ \infty } \) converges to \(\vect{ x } \) in the \(\infty \)-metric \(d_{ \infty } \) on \(\R^{ m } \text{.}\)

    🔗
  2. For all indices \(1 \leq j \leq m \text{,}\) the sequence \(\of{ x_{ j , n } }_{ n = 0 }^{ \infty } \) converges to \(x_{ j } \) in the Euclidean metric \(d \) on \(\R \text{.}\)
