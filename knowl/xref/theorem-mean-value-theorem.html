Theorem 5.2.2 (Joseph-Louis Lagrange). Mean value theorem.

Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \subsetneq \R \text{.}\) If \(f \) is continuous on the closed interval \(\clint{ a }{ b } \) and differentiable on the open interval \(\opint{ a }{ b } \text{,}\) then
\begin{equation*} f' \of{ c } = \frac{ f \of{ b } - f \of{ a } }{ b - a } \end{equation*}
for some point \(a \lt c \lt b \text{.}\)
🔗
🔗

Proof.
Let \(g \colon \clint{ a }{ b } \to \R \) be the real-valued function defined by the formula
\begin{equation*} g \of{ x } = f \of{ x } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } x\text{.} \end{equation*}
Then \(g \) is continuous by Proposition 3.5.6 Vector arithmetic of continuous maps and differentiable on the open interval \(\opint{ a }{ b } \) by Proposition 5.1.4 Arithmetic of differentiable functions, with derivative
\begin{equation*} g' \of{ x } = f' \of{ x } - \frac{ f \of{ b } - f \of{ a } }{ b - a }\text{.} \end{equation*}
Moreover,
\begin{align*} g \of{ b } \amp = f \of{ b } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } b\\ \amp = f \of{ b } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } \of{ b - a } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } a\\ \amp = f \of{ b } - \of{ f \of{ b } - f \of{ a } } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } a\\ \amp = f \of{ b } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } a = g \of{ a }\text{.} \end{align*}
Lemma 5.2.1 Rolle’s lemma now implies that \(g' \of{ c } = 0 \) for some interior point \(a \lt c \lt b \text{;}\) that is,
\begin{equation*} f' \of{ c } = \frac{ f \of{ b } - f \of{ a } }{ b - a }\text{.} \end{equation*}
