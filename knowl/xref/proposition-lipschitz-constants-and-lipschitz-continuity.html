Proposition 3.5.19. Lipschitz constants and Lipschitz continuity.

A map \(f \colon X \to Y \) from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \) is Lipschitz continuous if and only if \(L_{ f } \lt \infty \text{,}\) in which case
\begin{equation*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \leq L_{ f } \rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \end{equation*}
for all points \(x_{ 1 } , x_{ 2 } \in X \text{.}\)
🔗
🔗

Proof.
We observe that
\begin{equation*} C = \setmid{ L \in \clopint{ 0 }{ \infty } }{ \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \leq L \rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \textrm{ for all } x_{ 1 } , x_{ 2 } \in X } \end{equation*}
is a subset of the real numbers, and so \(L_{ f } = \inf \of{ C } \lt \infty \) if and only if \(C \neq \emptyset \) is non-empty. That \(C \neq \emptyset \) is non-empty is precisely the Lipschitz continuity condition for \(f \text{,}\) and so \(f \) is Lipschitz continuous if and only if \(L_{ f } \lt \infty \text{.}\)
🔗
If \(C \neq \emptyset \) is non-empty, let \(\of{ l_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of elements \(l_{ n } \in L \) which converge to \(L_{ f } = \inf \of{ C } \text{.}\) We observe that
\begin{align*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \amp = \lim_{ n \to \infty }{ \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } }\\ \amp \leq \lim_{ n \to \infty }{ l_{ n } \rho_{ X } \of{ x_{ 1 } , x_{ 2 } } } = L_{ f } \rho \of{ x_{ 1 } , x_{ 2 } } \end{align*}
for all points \(x_{ 1 } , x_{ 2 } \in X \text{.}\)
