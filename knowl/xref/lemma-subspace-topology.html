Lemma 4.1.6. Subspace topology.

Fix a subset \(U \subseteq X \) of a topological space \(\of{ X , \tau } \text{.}\) Then the collection
\begin{equation*} \setmid{ U \cap V \in \ps \of{ X } }{ V \in \tau } \end{equation*}
is a topology on \(U \text{.}\)
🔗
🔗

Proof.
Denote by \(\tau' \) the collection
\begin{equation*} \tau' = \setmid{ U \cap V \in \ps \of{ X } }{ V \in \tau }\text{.} \end{equation*}
Since \(\tau \) is non-degenerate, \(\emptyset , X \in \tau \) are open in \(X \text{,}\) and so
\begin{equation*} \emptyset = U \cap \emptyset \in \tau' \end{equation*}
and
\begin{equation*} U = U \cap X \in \tau'\text{;} \end{equation*}
that is, \(\tau' \) is non-degenerate.
🔗
Now consider an indexed family \(\of{ W_{ j } }_{ j \in \mathcal{ J } } \) of sets \(W_{ j } \in \tau' \text{.}\) Then for each index \(j \in \mathcal{ J } \text{,}\) \(W_{ j } = U \cap V_{ j } \) for some open set \(V_{ j } \in \tau \) in \(X \text{.}\) Since \(\tau \) is stable under unions,
\begin{equation*} \bigcup_{ j \in \mathcal{ J } }{ V_{ j } } \in \tau \end{equation*}
is open in \(X \text{,}\) and so
\begin{equation*} \bigcup_{ j \in \mathcal{ J } }{ W_{ j } } = \bigcup_{ j \in \mathcal{ J } }{ \of{ U \cap V_{ j } } } = U \cap \bigcup_{ j \in \mathcal{ J } }{ V_{ j } } \in \tau'\text{;} \end{equation*}
that is, \(\tau' \) is stable under unions.
🔗
Finally, consider a finite sequence \(\of{ W_{ j } }_{ j = 1 }^{ m } \) of sets \(W_{ j } \in \tau' \text{.}\) Then for each index \(1 \leq j \leq m \text{,}\) \(W_{ j } = U \cap V_{ j } \) for some open set \(V_{ j } \in \tau \) in \(X \text{.}\) Since \(\tau \) is stable under finite intersections,
\begin{equation*} \bigcap_{ j = 1 }^{ m }{ V_{ j } } \in \tau \end{equation*}
is open in \(X \text{,}\) and so
\begin{equation*} \bigcap_{ j = 1 }^{ m }{ W_{ j } } = \bigcap_{ j = 1 }^{ m }{ \of{ U \cap V_{ j } } } = U \cap \bigcap_{ j = 1 }^{ m }{ V_{ j } } \in \tau'\text{;} \end{equation*}
that is, \(\tau' \) is stable under finite intersections.
🔗
Since \(\tau' \) is non-degenerate, stable under unions, and stable under finite intersections, it is a topology on \(U \text{.}\)
