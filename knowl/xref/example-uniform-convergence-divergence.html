Example 3.2.12. Uniform convergence/divergence.

The following are examples of uniformly convergent and divergent sequences of maps:
  • Consider the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of functions \(f_{ n } \colon \clint{ 0 }{ 1 } \to \clint{ 0 }{ 1 } \) defined by the formulae \(f_{ n } \of{ x } = x^{ n } \text{,}\) and let \(f \colon \clint{ 0 }{ 1 } \to \clint{ 0 }{ 1 } \) be the function defined piecewise by the formula
    \begin{equation*} f \of{ x } = \begin{cases} 0 \amp 0 \leq x \lt 1 \\ 1 \amp x = 1 \text{.}\end{cases} \end{equation*}
    We observe that
    \begin{align*} d \of{ f_{ n } \of{ x } , f \of{ x } } \amp = \abs{ f_{ n } \of{ x } - f \of{ x } } = \abs{ x^{ n } - 0 } = \abs{ x^{ n } } = x^{ n }\\ \amp \gt \of{ \frac{ 1 }{ 2^{ \frac{ 1 }{ n } } } }^{ n } = \frac{ 1 }{ 2 } \end{align*}
    for all positive integers \(n \geq 1 \) and inputs \(\frac{ 1 }{ \sqrt[ n ]{ 2 } } \leq x \lt 1 \text{.}\) We conclude that \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) does not converge uniformly to \(f \text{.}\)

  • Consider the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of functions \(f_{ n } \colon \R \to \clint{ -1 }{ 1 } \) defined by the formulae
    \begin{equation*} f_{ n } \of{ x } = \frac{ \sin \of{ n x } }{ n }\text{,} \end{equation*}
    and let \(f \colon \R \to \clint{ -1 }{ 1 } \) be the function defined by the formula \(f \of{ x } = 0 \text{.}\) For all positive real numbers \(\epsilon \gt 0 \text{,}\) the Archimedean principle implies that \(n_{ \epsilon } \cdot \epsilon \gt 1 \) for some positive integer \(n_{ \epsilon } \geq 1 \text{.}\) We observe that
    \begin{align*} d \of{ f_{ n } \of{ x } , f \of{ x } } \amp = \abs{ f_{ n } \of{ x } - f \of{ x } } = \abs{ \frac{ \sin \of{ n x } }{ n } - 0 } = \abs{ \frac{ \sin \of{ n x } }{ n } }\\ \amp = \frac{ \abs{ \sin \of{ n x } } }{ n } \leq \frac{ 1 }{ n } \leq \frac{ 1 }{ n_{ \epsilon } } \lt \epsilon \end{align*}
    for all indices \(n \geq n_{ \epsilon } \) and inputs \(x \in \R \text{.}\) We conclude that \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to \(f \text{.}\)
