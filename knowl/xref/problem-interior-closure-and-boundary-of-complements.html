Problem 2. Interior, closure, and boundary of complements.

Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{.}\)
🔗

(a)

Prove that \(\Int \of{ X \setminus U } = X \setminus \Cl \of{ U } \text{.}\)
🔗
🔗

(b)

Prove that \(\Cl \of{ X \setminus U } = X \setminus \Int \of{ U } \text{.}\)
🔗
🔗

(c)

Prove that \(\Bd \of{ X \setminus U } = \Bd \of{ U } = \Cl \of{ U } \cap \Cl \of{ X \setminus U } \text{.}\)
🔗
🔗

(d)

Prove that \(\Bd \of{ U } = \Cl \of{ U } \setminus \Int \of{ U } \text{.}\)
