Example 3.2.9. Pointwise convergence.

Consider the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of functions \(f_{ n } \colon \clint{ 0 }{ 1 } \to \clint{ 0 }{ 1 } \) defined by the formulae \(f_{ n } \of{ x } = x^{ n } \text{.}\) Since
\begin{equation*} \lim_{ n \to \infty }{ f_{ n } \of{ x } } = \lim_{ n \to \infty }{ x^{ n } } = \begin{cases} 0 \amp 0 \leq x \lt 1 \\ 1 \amp x = 1 \text{,}\end{cases} \end{equation*}
the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges pointwise to the function \(f \colon \clint{ 0 }{ 1 } \to \clint{ 0 }{ 1 } \) defined piecewise by the formula
\begin{equation*} f \of{ x } = \begin{cases} 0 \amp 0 \leq x \lt 1 \\ 1 \amp x = 1 \text{.}\end{cases} \end{equation*}
