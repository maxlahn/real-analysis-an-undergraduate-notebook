Lemma 3.6.10. Increasing functions.

\(f \of{ n } \geq n \) for any increasing function \(f \colon \N \to \N \text{.}\)
🔗
🔗

Proof.
By induction on \(n \in \N \text{.}\) For the base case \(n = 0 \text{,}\) we observe that \(f \of{ 0 } \in \N \) is a natural number, and so
\begin{equation*} f \of{ n } = f \of{ 0 } \geq 0 = n\text{.} \end{equation*}
🔗
For the inductive step, suppose for the inductive hypothesis that \(f \of{ n } \geq n \) for some natural number \(n \in \N \text{.}\) We observe that \(n \leq n + 1 \text{,}\) and so \(f \of{ n } \leq f \of{ n + 1 } \text{,}\) since \(f \) is non-decreasing. Moreover, \(n \neq n + 1 \text{,}\) and so \(f \of{ n } \neq f \of{ n + 1 } \text{,}\) since \(f \) is injective. In particular,
\begin{equation*} f \of{ n + 1 } \gt f \of{ n } \geq n \end{equation*}
by the inductive hypothesis, and so \(f \of{ n + 1 } \geq n + 1 \text{.}\)
