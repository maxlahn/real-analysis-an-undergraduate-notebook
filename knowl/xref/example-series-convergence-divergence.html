Example 7.1.4. Series convergence/divergence.

Consider the geometric series \(\sum_{ n = 0 }^{ \infty }{ a r^{ n } } \) of initial value \(a \in \R \) and ratio \(r \in \R \text{,}\) and let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) be the sequence of partial sums
\begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ a r^{ k } }\text{.} \end{equation*}
We will see that the convergence or divergence of this geometric series depends on both \(a \) and \(r \text{.}\)
  • We first observe that if \(a = 0 \text{,}\) then
    \begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ a r^{ k } } = \sum_{ k = 0 }^{ n }{ 0 } = 0 \end{equation*}
    for all indices \(n \in \N \text{,}\) and so
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \lim_{ n \to \infty }{ 0 } = 0\text{.} \end{equation*}
    🔗
    🔗
  • Now suppose that \(a \neq 0 \) and \(r = 0 \text{.}\) Then
    \begin{equation*} S_{ n } = a \end{equation*}
    for all indices \(n \in \N \text{,}\) and so
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \lim_{ n \to \infty }{ a } = a\text{.} \end{equation*}
    🔗
    🔗
  • Now suppose that \(a \neq 0 \) and \(0 \lt \abs{ r } \lt 1 \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. The Archimedean principle implies that
    \begin{equation*} n_{ \epsilon } \gt \frac{ \ln \of{ \epsilon } + \ln \of{ 1 - r } }{ \ln \of{ \abs{ r } } } - 1 \end{equation*}
    for some natural number \(n_{ \epsilon } \in \N \text{.}\) We observe that
    \begin{align*} \abs{ S_{ n } - \frac{ a }{ 1 - r } } \amp = \abs{ \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } - \frac{ a }{ 1 - r } } = \frac{ \abs{ -r^{ n + 1 } } }{ \abs{ 1 - r } }\\ \amp = \frac{ \abs{ r }^{ n + 1 } }{ 1 - r } \leq \frac{ \abs{ r }^{ n_{ \epsilon } + 1 } }{ 1 - r } \lt \epsilon \end{align*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) Thus the geometric series converges to
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \frac{ a }{ 1 - r }\text{.} \end{equation*}
    🔗
    🔗
  • Now suppose that \(a \gt 0 \) and \(r = 1 \text{.}\) Let \(B \in \R \) be a real number. The Archimedean principle implies that
    \begin{equation*} n_{ B } \gt \frac{ B }{ a } - 1 \end{equation*}
    for some natural number \(n_{ B } \in \N \text{.}\) We observe
    \begin{equation*} S_{ n } = \of{ n + 1 } a \geq \of{ n_{ B } + 1 } a \gt B \end{equation*}
    for all indices \(n \geq n_{ B } \text{.}\) Thus the geometric series diverges to \(\infty \text{;}\) that is,
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \infty\text{.} \end{equation*}
    🔗
    🔗
  • Now suppose that \(a \lt 0 \) and \(r = 1 \text{.}\) Let \(B \in \R \) be a real number. The Archimedean principle implies that
    \begin{equation*} n_{ B } \gt \frac{ B }{ a } - 1 \end{equation*}
    for some natural number \(n_{ B } \in \N \text{.}\) We observe
    \begin{equation*} S_{ n } = \of{ n + 1 } a \leq \of{ n_{ B } + 1 } a \lt B \end{equation*}
    for all indices \(n \geq n_{ B } \text{.}\) Thus the geometric series diverges to \(-\infty \text{;}\) that is,
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = -\infty\text{.} \end{equation*}
    🔗
    🔗
  • Now suppose that \(a \neq 0 \) and \(r = -1 \text{.}\) Then the geometric series has partial sums
    \begin{align*} S_{ n } \amp = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } = \frac{ a \of{ 1 - \of{ -1 }^{ n + 1 } } }{ 1 - \of{ -1 } } = \frac{ a \of{ 1 + \of{ -1 }^{ n + 1 } } }{ 2 }\\ \amp = \begin{cases} a \amp n \textrm{ is even} \\ 0 \amp n \textrm{ is odd} \end{cases} \end{align*}
    🔗
    🔗
  • Now suppose that \(a \gt 0 \) and \(r \gt 1 \text{.}\) Let \(B \in \R \) be a real number. The Archimedean principle implies that
    \begin{equation*} n_{ B } \gt \frac{ \ln \of{ a - B \of{ 1 - r } } - \ln \of{ a } }{ \ln \of{ r } } - 1 \end{equation*}
    for some natural number \(n_{ B } \in \N \text{.}\) We observe that
    \begin{equation*} S_{ n } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } \geq \frac{ a \of{ 1 - r^{ n_{ B } + 1 } } }{ 1 - r } \gt B \end{equation*}
    for all indices \(n \geq n_{ B } \text{.}\) Thus the geometric series diverges to \(\infty \text{;}\) that is,
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = \infty\text{.} \end{equation*}
    🔗
    🔗
  • Now suppose that \(a \lt 0 \) and \(r \gt 1 \text{.}\) Let \(B \in \R \) be a real number. The Archimedean principle implies that
    \begin{equation*} n_{ B } \gt \frac{ \ln \of{ a - B \of{ 1 - r } } - \ln \of{ a } }{ \ln \of{ r } } - 1 \end{equation*}
    for some natural number \(n_{ B } \in \N \text{.}\) We observe that
    \begin{equation*} S_{ n } = \frac{ a \of{ 1 - r^{ n + 1 } } }{ 1 - r } \leq \frac{ a \of{ 1 - r^{ n_{ B } + 1 } } }{ 1 - r } \lt B \end{equation*}
    for all indices \(n \geq n_{ B } \text{.}\) Thus the geometric series diverges to \(\infty \text{;}\) that is,
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ a r^{ n } } = \lim_{ n \to \infty }{ S_{ n } } = -\infty\text{.} \end{equation*}
    🔗
    🔗
  • Finally, suppose that \(a \neq 0 \) and \(r \lt -1 \text{.}\) We observe that
    \begin{equation*} \abs{ S_{ n + 1 } - S_{ n } } = \abs{ \sum_{ k = 0 }^{ n + 1 }{ a r^{ k } } - \sum_{ k = 0 }^{ n }{ a r^{ k } } } = \abs{ a r^{ n + 1 } } = \abs{ a } \abs{ r }^{ n + 1 } \geq 1 \end{equation*}
    for any index \(n \in \N \) so that
    \begin{equation*} n \geq -\frac{ \ln \of{ \abs{ a } } }{ \ln \of{ \abs{ r } } } - 1\text{.} \end{equation*}
    In particular, this implies that the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) cannot be Cauchy, and therefore cannot converge. So the geometric series diverges.
    🔗
    🔗
To summarize, the geometric series \(\sum_{ n = 0 }^{ \infty }{ a r^{ n } } \) converges if and only if \(a = 0 \) or \(\abs{ r } \lt 1 \text{.}\)
