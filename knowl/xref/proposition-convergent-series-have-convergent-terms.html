Proposition 7.1.5. Convergent series have convergent terms.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\) If the series
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
converges, then \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(0 \text{.}\)
🔗
🔗

Proof.
By contraposition. Suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{.}\) Then there is a positive real number \(\epsilon \gt 0 \) so that \(\abs{ x_{ n } - 0 } \geq \epsilon \) for infinitely many natural numbers \(n \in \N \text{.}\) Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) be the sequence of partial sums
\begin{equation*} S_{ n } = \sum_{ k = 0 }^{ n }{ x_{ n } }\text{.} \end{equation*}
For any positive integer \(n \geq 1 \) so that \(\abs{ x_{ n } - 0 } \geq \epsilon \text{,}\) we observe that
\begin{align*} \abs{ S_{ n } - S_{ n - 1 } } \amp = \abs{ \sum_{ k = 0 }^{ n }{ x_{ k } } - \sum_{ k = 0 }^{ n - 1 }{ x_{ k } } } = \abs{ x_{ n } }\\ \amp = \abs{ x_{ n } - 0 } \geq \epsilon\text{.} \end{align*}
Since this occurs for infinitely many positive integers \(n \geq 1 \text{,}\) we conclude that the sequence \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) cannot be Cauchy. Proposition 3.6.3 Convergent sequences are Cauchy now implies that \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and therefore the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{,}\) diverges.
