Theorem 3.6.22 (Eduard Heine; Émile Borel). Heine-Borel Theorem.

A subset of a metric space is compact if and only if it is complete and totally bounded.
🔗
🔗

Proof.
Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{,}\) and suppose first that \(U \) is compact. If \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) is a Cauchy sequence of points \(u_{ n } \in U \text{,}\) then compactness implies that \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) has a subsequence which converges to a limit in \(U \text{.}\) Proposition 3.6.12 Cauchy sequences with convergent subsequences implies that \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) converges to this limit. Since every Cauchy sequence in \(U \) converges to a limit in \(U \text{,}\) \(U \) is complete.
🔗
Now suppose for a contradiction that \(U \) is not totally bounded in \(X \text{.}\) Then there exists a positive real number \(\epsilon \gt 0 \) so that \(U \) is not contained in any finite union of open balls of radius \(\epsilon \text{.}\) In particular, there is a sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) of points \(u_{ n } \in U \) so that
\begin{equation*} u_{ n } \not \subseteq \bigcup_{ k = 0 }^{ n - 1 }{ \mB_{ \epsilon } \of{ u_{ k } } } \end{equation*}
for all indices \(n \in \N \text{.}\) Since \(U \) is compact, this sequence has a subsequence \(\of{ u_{ n_{ k } } }_{ k = 0 }^{ \infty } \) which converges to some point \(u \in U \text{.}\) In particular, there is a natural number \(k_{ \epsilon } \in \N \) so that
\begin{equation*} \rho \of{ u_{ n_{ k } } , u } \lt \frac{ \epsilon }{ 2 } \end{equation*}
for all indices \(k \geq k_{ \epsilon } \text{.}\) We observe that
\begin{align*} \rho \of{ u_{ n_{ k_{ \epsilon } + 1 } } , u_{ n_{ k_{ \epsilon } } } } \amp \leq \rho \of{ u_{ n_{ k_{ \epsilon } + 1 } } , u } + \rho \of{ u , u_{ n_{ k_{ \epsilon } } } } = \rho \of{ u_{ n_{ k_{ \epsilon } + 1 } } , u } + \rho \of{ u_{ n_{ k_{ \epsilon } } } , u }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon\text{,} \end{align*}
so that
\begin{equation*} u_{ n_{ k_{ \epsilon } + 1 } } \in \mB_{ \epsilon } \of{ u_{ n_{ k_{ \epsilon } } } } \subseteq \bigcup_{ k = 0 }^{ n_{ k_{ \epsilon } + 1 } - 1 }{ \mB_{ \epsilon } \of{ u_{ k } } }\text{.} \end{equation*}
This contradiction implies that \(U \) is totally bounded in \(X \text{.}\)
🔗
Conversely, now suppose that \(U \) is complete and totally bounded in \(X \text{.}\) Then Lemma 3.6.21 Sequences in totally bounded subsets implies that every sequence of points in \(U \) has a Cauchy subsequence, and completeness implies that such a subsequence converges to a limit in \(U \text{.}\) Thus every sequence of points in \(U \) has a subsequence which converges to a limit in \(U \text{;}\) that is, \(U \) is compact.
