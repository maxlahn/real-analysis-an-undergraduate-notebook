Theorem 5.2.6 (Jean-Gaston Darboux). Darboux’s theorem.

Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{.}\) If \(f \) is differentiable, then \(\im \of{ f' } = f' \of{ X } \) is an interval.
🔗
🔗

Proof.
Let \(a , b \in X \text{,}\) and suppose that \(a \lt b \text{.}\) There are three cases; either \(f' \of{ a } = f' \of{ b } \text{,}\) \(f' \of{ a } \lt f' \of{ b } \text{,}\) or \(f' \of{ a } \gt f' \of{ b } \text{.}\) If \(f \of{ a } = f \of{ b } \text{,}\) then \(\im \of{ f' } \) vacuously contains all points between \(f' \of{ a } \) and \(f' \of{ b } \text{.}\)
🔗
Suppose that \(f' \of{ a } \lt f' \of{ b } \text{,}\) let \(f' \of{ a } \lt r \lt f' \of{ b } \text{,}\) and consider the function \(g \colon X \to \R \) defined by the formula
\begin{equation*} g \of{ x } = f \of{ x } - r x\text{.} \end{equation*}
We observe that \(g' \of{ a } = f' \of{ a } - r \lt 0 \) and \(g' \of{ b } = f' \of{ b } - r \gt 0 \text{.}\) In particular, the argument in the proof of Lemma 5.2.4 Local extrema are stationary points implies that \(g \) does not attain a minimum value at \(a \) or \(b \text{.}\)
🔗
However, since \(g \) is continuous on the compact interval \(\clint{ a }{ b } \text{,}\) it attains a minimum value on \(\clint{ a }{ b } \text{.}\) Thus \(g \) attains a minimum value at some interior point \(c \in \opint{ a }{ b } \text{,}\) and so the Interior extremum theorem implies that \(g' \of{ c } = 0 \text{;}\) that is,
\begin{equation*} g' \of{ c } = f' \of{ c } - r\text{,} \end{equation*}
so that \(f' \of{ c } = r \text{.}\)
🔗
Now suppose that \(f' \of{ b } \lt f' \of{ a } \text{,}\) let \(f' \of{ b } \lt r \lt f' \of{ a } \text{,}\) and consider the function \(g \colon X \to \R \) defined by the formula
\begin{equation*} g \of{ x } = f \of{ x } - r x\text{.} \end{equation*}
We observe that \(g' \of{ a } = f' \of{ a } - r \gt 0 \) and \(g' \of{ b } = f' \of{ b } - r \lt 0 \text{.}\) In particular, the argument in the proof of Lemma 5.2.4 Local extrema are stationary points implies that \(g \) does not attain a maximum value at \(a \) or \(b \text{.}\)
🔗
However, since \(g \) is continuous on the compact interval \(\clint{ a }{ b } \text{,}\) it attains a maximum value on \(\clint{ a }{ b } \text{.}\) Thus \(g \) attains a maximum value at some interior point \(c \in \opint{ a }{ b } \text{,}\) and so the Interior extremum theorem implies that \(g' \of{ c } = 0 \text{;}\) that is,
\begin{equation*} g' \of{ c } = f' \of{ c } - r\text{,} \end{equation*}
so that \(f' \of{ c } = r \text{.}\)
