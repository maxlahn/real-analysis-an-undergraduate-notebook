Lemma 4.3.2. Sequential convergence in metrizable spaces.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points in a metric space \(\of{ X , \rho } \text{.}\) For any point \(x \in X \text{,}\) the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric space \(\of{ X , \rho } \) if and only if \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metrizable topological space \(\of{ X , \tau_{ \rho } } \text{.}\)
🔗
🔗

Proof.
First suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric space \(\of{ X , \rho } \text{,}\) and let \(N \subseteq X \) be a neighorhood of \(x \) in \(X \text{.}\) Then \(\mB_{ \epsilon } \of{ x } \subseteq N \) for some positive real number \(\epsilon \gt 0 \text{.}\) There is some natural number \(n_{ N } \in \N \) so that
\begin{equation*} \rho \of{ x_{ n } , x } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ N } \text{.}\) In particular, we observe that \(x_{ n } \in \mB_{ \epsilon } \of{ x } \subseteq N \) for all indices \(n \geq n_{ N } \text{.}\) Thus \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric topological space \(\of{ X , \tau_{ \rho } } \text{.}\)
🔗
Conversely, now suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric topological space \(\of{ X , \tau_{ \rho } } \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Since \(\mB_{ \epsilon } \of{ x } \) is a neighborhood of \(x \) in \(X \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that \(x_{ n } \in \mB_{ \epsilon } \of{ x } \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
\begin{equation*} \rho \of{ x_{ n } , x } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{.}\) Thus \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric space \(\of{ X , \rho } \text{.}\)
