Theorem 7.1.12 (Bernhard Riemann). Rearrangement theorem.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and suppose that the associated series
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
converges.
  1. If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely, then
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ \varphi \of{ n } } } = \sum_{ n = 0 }^{ \infty }{ x_{ n } } \end{equation*}
    for all bijections \(\varphi \colon \N \to \N \text{.}\)

    🔗
  2. If the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges conditionally, then for any extended real numbers \(-\infty \leq a \leq b \leq \infty \text{,}\) there is a bijection \(\varphi \colon \N \to \N \) so that
    \begin{align*} \liminf_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ \varphi \of{ n } } } } \amp = a \amp \limsup_{ n \to \infty }{ \sum_{ k = 0 }^{ n }{ x_{ \varphi \of{ n } } } } \amp = b\text{.} \end{align*}
    In particular, for any extended real number \(-\infty \leq c \leq \infty \text{,}\) there is a bijection \(\varphi \colon \N \to \N \) so that
    \begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ \varphi \of{ n } } } = c\text{.} \end{equation*}
