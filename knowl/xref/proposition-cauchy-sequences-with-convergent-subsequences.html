Proposition 3.6.12. Cauchy sequences with convergent subsequences.

If a Cauchy sequence of points in a metric space has a convergent subsequence, then it converges.
🔗
🔗

Proof.
Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a Cauchy sequence of points \(x_{ n } \in X \) in a metric space \(X \text{,}\) and suppose that some subsequence \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \) converges to a point \(x \in X \text{.}\) We will show that the entire sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) also converges to \(x \text{.}\)
🔗
To that end, let \(\epsilon \gt 0 \) be a positive real number. Since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is Cauchy, there is a natural number \(m_{ \epsilon } \in \N \) so that
\begin{equation*} \rho \of{ x_{ m } , x_{ n } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
for all indices \(m , n \geq m_{ \epsilon } \text{.}\) Since the subsequence \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \) converges to \(x \text{,}\) there is a natural number \(k_{ \epsilon } \in \N \) so that
\begin{equation*} \rho \of{ x_{ n_{ k } } , x } \lt \frac{ \epsilon }{ 2 } \end{equation*}
for all indices \(k \geq k_{ \epsilon } \text{.}\) Let \(n_{ \epsilon } = \max \of{ \set{ m_{ \epsilon } , k_{ \epsilon } } } \text{.}\) We observe that Lemma 3.6.10 Increasing functions implies that \(n_{ k } \geq n_{ \epsilon } \) for all indices \(k \geq n_{ \epsilon } \text{.}\) In particular,
\begin{equation*} \rho \of{ x_{ n } , x } \leq \rho \of{ x_{ n } , x_{ n_{ n } } } + \rho \of{ x_{ n_{ n } } , x } \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{.}\) Thus the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \text{.}\)
