Lemma 5.2.1 (Michel Rolle). Rolle’s lemma.

Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \subsetneq \R \text{.}\) If \(f \) is continuous on the closed interval \(\clint{ a }{ b } \) and differentiable on the open interval \(\opint{ a }{ b } \) and \(f \of{ a } = f \of{ b } \text{,}\) then \(f' \of{ c } = 0 \) for some point \(a \lt c \lt b \text{.}\)
🔗
🔗

Proof.
Let \(a \lt c \lt b \text{,}\) and suppose that \(f' \of{ c } \gt 0 \text{.}\) Then since \(\frac{ f' \of{ c } }{ 2 } \gt 0 \) is positive, there is some positive real number \(\delta \gt 0 \) so that
\begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt \frac{ f' \of{ c } }{ 2 } \end{equation*}
for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) In particular,
\begin{equation*} \frac{ f \of{ x } - f \of{ c } }{ x - c } \gt f' \of{ c } - \frac{ f' \of{ c } }{ 2 } = \frac{ f' \of{ c } }{ 2 } \gt 0 \end{equation*}
for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) so that \(f \of{ x } - f \of{ c } \) and \(x - c \) have the same sign; that is, so long as \(x \in \clint{ a }{ b } \) and \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then \(f \of{ x } \lt f \of{ c } \) if \(x \lt c \) and \(f \of{ x } \gt f \of{ c } \) if \(x \gt c \text{.}\) In particular, we conclude that \(f \) does not achieve a maximum or minimum at \(c \text{.}\)
🔗
Similarly, now suppose that \(f' \of{ c } \lt 0 \text{.}\) Then since \(-\frac{ f' \of{ c } }{ 2 } \gt 0 \) is positive, there is some positive real number \(\delta \gt 0 \) so that
\begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt -\frac{ f' \of{ c } }{ 2 } \end{equation*}
for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) In particular,
\begin{equation*} \frac{ f \of{ x } - f \of{ c } }{ x - c } \lt -f' \of{ c } + \frac{ f' \of{ c } }{ 2 } = -\frac{ f' \of{ c } }{ 2 } \lt 0 \end{equation*}
for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) so that \(f \of{ x } - f \of{ c } \) and \(x - c \) have opposite sign; that is, so long as \(x \in \clint{ a }{ b } \) and \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then \(f \of{ x } \gt f \of{ c } \) if \(x \lt c \) and \(f \of{ x } \lt f \of{ c } \) if \(x \gt c \text{.}\) In particular, we conclude that \(f \) does not achieve a maximum or minimum at \(c \text{.}\)
🔗
However, \(\clint{ a }{ b } \) is closed and bounded, and hence compact by Corollary 3.6.23 Compact subsets of Euclidean space. Since \(f \) is continuous and \(\clint{ a }{ b } \) is compact, Proposition 3.6.20 Continuous images of compact subsets implies that
\begin{equation*} \im \of{ f } = f \of{ \clint{ a }{ b } } = \setmid{ f \of{ x } \in \R }{ a \leq x \leq b } \end{equation*}
is compact and hence also closed and bounded. In particular, \(f \) attains a maximum \(\max_{ a \leq x \leq b }{ f \of{ x } } = \max \of{ \im \of{ f } } \) and a minimum \(\min_{ a \leq x \leq b }{ f \of{ x } } = \min \of{ \im \of{ f } } \text{.}\)
🔗
To summarize our argument so far, we have shown that \(f \) does not achieve a maximum or minimum value at any point where its derivative is non-zero, but \(f \) must achieve a maximum and minimum value somewhere in \(\clint{ a }{ b } \text{.}\) If \(f \) achieves a maximum or a minimum value at an interior point \(a \lt c \lt b \text{,}\) then the above argument shows that \(f' \of{ c } = 0 \text{.}\) Otherwise, \(f \) attains both its maximum and minimum values at the endpoints \(a \) and \(b \text{.}\) In this case, \(f \) must be constant because \(f \of{ a } = f \of{ b } \text{.}\) In particular, this implies that \(f' \of{ c } = 0 \) for all points \(a \lt c \lt b \text{.}\)
