Lemma 6.3.12. Comparison of non-negative improper integrals.

Let \(f , g \colon X \to \clopint{ 0 }{ \infty } \) be non-negative real-valued functions defined on an interval \(X \subseteq \R \text{,}\) and suppose that \(0 \leq f \of{ x } \leq g \of{ x } \) for all points \(x \in X \text{.}\) If the restriction of \(f \) to any compact subinterval of the interior \(\Int \of{ X } \) is integrable and \(g \) is improperly integrable, then \(f \) is improperly integrable, and
\begin{equation*} 0 \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
🔗
🔗

Proof.
Consider the nets \(\of{ F_{ \clint{ a }{ b } } }_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } } \) and \(\of{ G_{ \clint{ a }{ b } } }_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } } \) defined by the formulas
\begin{align*} F_{ \clint{ a }{ b } } \amp = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } \amp G_{ \clint{ a }{ b } } \amp = \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } } \end{align*}
for all compact subintervals \(\clint{ a }{ b } \in \mathcal{ K }_{ X } \) of the interior \(\Int \of{ X } \text{.}\) We first observe that these nets are order-preserving. Indeed, for any compact subintervals \(\clint{ a }{ b } , \clint{ c }{ d } \in \mathcal{ K }_{ X } \text{,}\) if \(\clint{ a }{ b } \subseteq \clint{ c }{ d } \text{,}\) then Chasles’ relation and Lemma 6.1.14 Riemann integration and comparison imply that
\begin{align*} F_{ \clint{ a }{ b } } \amp = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } }\\ \amp \leq \int_{ c }^{ a }{ f \of{ x } \, \diff{ x } } + \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } + \int_{ b }^{ d }{ f \of{ x } \, \diff{ x } }\\ \amp = \int_{ c }^{ d }{ f \of{ x } \, \diff{ x } } = F_{ \clint{ c }{ d } }\text{,} \end{align*}
and similarly that \(G_{ \clint{ a }{ b } } \leq G_{ \clint{ c }{ d } } \text{.}\) The net analogue of the Monotone convergence theorem implies that
\begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } } = \lim_{ \clint{ a }{ b } \uparrow }{ G_{ \clint{ a }{ b } } } = \sup_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } }{ G_{ \clint{ a }{ b } } }\text{.} \end{equation*}
🔗
We observe that for any compact subinterval \(\clint{ a }{ b } \in \mathcal{ K }_{ X } \) of the interior \(\Int \of{ X } \text{,}\)
\begin{align*} F_{ \clint{ a }{ b } } \amp = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } \leq \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } }\\ \amp \leq \sup_{ \clint{ c }{ d } \in \mathcal{ K }_{ X } }{ G \of{ \clint{ c }{ d } } } = \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } } \end{align*}
by Lemma 6.1.14 Riemann integration and comparison, and so another application of the net analogue of the Monotone convergence theorem implies that \(\of{ F_{ \clint{ a }{ b } } }_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } } \) converges upwards to
\begin{equation*} \lim_{ \clint{ a }{ b } \uparrow }{ F_{ \clint{ a }{ b } } } = \sup_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } }{ F_{ \clint{ a }{ b } } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
That is, \(f \) is improperly integrable, with improper integral
\begin{equation*} 0 \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
