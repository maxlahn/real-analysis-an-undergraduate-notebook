Lemma 7.1.7. Comparison of convergent series.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{.}\) If \(x_{ n } \leq y_{ n } \) for all indices \(n \in \N \) and the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) and \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converge, then
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } \leq \sum_{ n = 0 }^{ \infty }{ y_{ n } }\text{.} \end{equation*}
🔗
🔗

Proof.
Let \(\of{ S_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ T_{ n } }_{ n = 0 }^{ \infty } \) be the sequences of partial sums
\begin{align*} S_{ n } \amp = \sum_{ k = 0 }^{ n }{ x_{ k } } \amp T_{ n } \amp = \sum_{ k = 0 }^{ n }{ y_{ k } }\text{.} \end{align*}
Since \(x_{ k } \leq y_{ k } \) for each index \(0 \leq k \leq n \text{,}\) \(S_{ n } \leq T_{ n } \text{.}\) We conclude that
\begin{equation*} \sum_{ n = 0 }^{ \infty }{ x_{ n } } = \lim_{ n \to \infty }{ S_{ n } } \leq \lim_{ n \to \infty }{ T_{ n } } = \sum_{ n = 0 }^{ \infty }{ y_{ n } } \end{equation*}
by Proposition 3.3.2 Comparison of limits.
