Corollary 7.2.5. Limit comparison test.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{,}\) and suppose that \(x_{ n } \preccurlyeq y_{ n } \) as \(n \to \infty \text{.}\) If the series \(\sum_{ n = 0 }^{ \infty }{ y_{ n } } \) converges absolutely, then so too does the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \text{.}\)
🔗
🔗

Proof.
Since \(x_{ n } \preccurlyeq y_{ n } \) as \(n \to \infty \text{,}\) there is a sequence \(\of{ \lambda_{ n } }_{ n = 0 }^{ \infty } \) of non-negative real numbers \(\lambda_{ n } \geq 0 \) and a non-negative real number \(L \geq 0 \) so that
\begin{equation*} \lim_{ n \to \infty }{ \lambda_{ n } } = L\text{,} \end{equation*}
and \(\abs{ x_{ n } } = \lambda_{ n } \abs{ y_{ n } } \) for all indices \(n \in \N \text{.}\) Consider the positive real number
\begin{equation*} \epsilon \gt \sup_{ n \in \N }{ \abs{ \lambda_{ n } - L } } \geq 0\text{.} \end{equation*}
We observe that \(L - \epsilon \lt \lambda_{ n } \lt L + \epsilon \) for all indices \(n \in \N \text{,}\) and so
\begin{equation*} \of{ L - \epsilon } \abs{ y_{ n } } \lt \abs{ x_{ n } } \lt \of{ L + \epsilon } \abs{ y_{ n } } \end{equation*}
for all indices \(n \in \N \text{.}\) (2) of Proposition 7.1.6 Arithmetic of convergent series and the Direct comparison test imply that the series \(\sum_{ n = 0 }^{ \infty }{ \abs{ x_{ n } } } \) converges. Finally, Corollary 7.2.4 Absolute convergence implies convergence implies that the series \(\sum_{ n = 0 }^{ \infty }{ x_{ n } } \) converges absolutely.
