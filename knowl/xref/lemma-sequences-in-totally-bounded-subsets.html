Lemma 3.6.21. Sequences in totally bounded subsets.

If a subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \) is totally bounded, then every sequence of points in \(U \) has a Cauchy subsequence.
🔗
🔗

Proof.
If \(U = \emptyset \) is empty, then the desired result holds vacuously. We may therefore suppose that \(U \neq \emptyset \) is non-empty. Let \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(u_{ n } \in U \text{.}\) We aim to show that this sequence has a Cauchy subsequence. To that end, we first observe that since \(U \) is totally bounded in \(X \text{,}\) it is bounded by Proposition 3.4.24 Total boundedness implies boundedness, and so \(\diam \of{ U } \lt \infty \) is finite. let \(\of{ r_{ m } }_{ m = 0 }^{ \infty } \) be a sequence of positive real numbers \(r_{ n } \gt 0 \) so that \(r_{ 0 } \gt \diam \of{ U } \) and
\begin{equation*} \lim_{ m \to \infty }{ r_{ m } } = 0\text{.} \end{equation*}
We argue inductively that for each natural number \(m \in \N \text{,}\) there is a subsequence \(\of{ v_{ m , n } }_{ n = 0 }^{ \infty } \) of \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) whose entries are all contained in an open ball of radius \(r_{ m } \text{,}\) and moreover that if \(m \leq p \) then \(\of{ v_{ p , n } }_{ n = 0 }^{ \infty } \) is a subsequence of \(\of{ v_{ m , n } }_{ n = 0 }^{ \infty } \text{.}\)
🔗
Indeed, for the base case \(m = 0 \text{,}\) we observe that \(U \) is contained in an open ball of radius \(r_{ 0 } \gt \diam \of{ U } \) around any of its points, so we may take \(v_{ 0 , n } = u_{ n } \) for all indices \(n \in \N \text{.}\)
🔗
For the inductive step, suppose for the inductive hypothesis that for some natural number \(m \in \N \) the sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) has a subsequence \(\of{ v_{ m , n } }_{ n = 0 }^{ \infty } \) whose entries are all contained in an open ball of radius \(r_{ m } \text{.}\) Since \(U \) is totally bounded, it is contained in a union of finitely many open balls of radius \(r_{ m + 1 } \text{.}\) The pigeonhole principle implies that infinitely many entries of \(\of{ v_{ m , n } }_{ n = 0 }^{ \infty } \) lie in one of these open balls. Removing all other entries, we obtain a further subsequence \(\of{ v_{ m + 1 , n } }_{ n = 0 }^{ \infty } \) whose entries all lie in a ball of radius \(r_{ m + 1 } \text{.}\)
🔗
Consider the subsequence \(\of{ u_{ n_{ k } } }_{ k = 0 }^{ \infty } \) of \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) defined by the formula
\begin{equation*} u_{ n_{ k } } = v_{ n , n }\text{.} \end{equation*}
We will show that this subsequence is Cauchy. Indeed, let \(\epsilon \gt 0 \) be a positive real number. Since \(\of{ r_{ m } }_{ m = 0 }^{ \infty } \) converges to \(0 \text{,}\) there is a natural number \(m_{ \epsilon } \in \N \) so that
\begin{equation*} r_{ m } \lt \frac{ \epsilon }{ 2 } \end{equation*}
for all indices \(m \geq m_{ \epsilon } \text{.}\) Indeed, since \(\of{ u_{ n_{ k } } }_{ k = m_{ \epsilon } }^{ \infty } \) is a subsequence of \(\of{ v_{ m_{ \epsilon } , n } }_{ n = 0 }^{ \infty } \text{,}\) its entries all lie in an open ball of radius \(r_{ m } \lt \frac{ \epsilon }{ 2 } \text{.}\) In particular, the entries of \(\of{ u_{ n_{ k } } }_{ k = m_{ \epsilon } }^{ \infty } \) have distance strictly less than \(\epsilon \) from each other. Thus \(\of{ u_{ n_{ k } } }_{ k = 0 }^{ \infty } \) is Cauchy.
