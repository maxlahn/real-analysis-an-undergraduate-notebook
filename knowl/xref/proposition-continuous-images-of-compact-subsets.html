Proposition 3.6.20. Continuous images of compact subsets.

Let \(f \colon X \to Y \) be a continuous map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) If a subset \(U \subseteq X \) is compact, then its image \(f \of{ U } \subseteq Y \) is also compact.
🔗
🔗

Proof.
Let \(\of{ v_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(v_{ n } \in f \of{ U } \text{.}\) For each index \(n \in \N \text{,}\) there is some point \(u_{ n } \in U \) so that \(f \of{ u_{ n } } = v_{ n } \text{.}\) Since \(U \) is compact, the sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) has a convergent subsequence \(\of{ u_{ n_{ k } } }_{ k = 0 }^{ \infty } \text{.}\) Since \(f \) is continuous,
\begin{equation*} \lim_{ k \to \infty }{ v_{ n_{ k } } } = \lim_{ k \to \infty }{ f \of{ u_{ n_{ k } } } } = f \of{ \lim_{ n \to \infty }{ u_{ n_{ k } } } }\text{;} \end{equation*}
that is, the subsequence \(\of{ v_{ n_{ k } } }_{ k = 0 }^{ \infty } \) of \(\of{ v_{ n } }_{ n = 0 }^{ \infty } \) converges to a point in \(f \of{ U } \text{.}\) Since every sequence in \(f \of{ U } \) has a subsequence which converges to a limit in \(f \of{ U } \text{,}\) we conclude that \(f \of{ U } \) is compact.
