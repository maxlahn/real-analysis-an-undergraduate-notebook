Theorem 5.1.6. Chain rule.

Let \(f \colon X \to \R \) and \(g \colon Y \to \R \) be real-valued functions on subsets \(X , Y \subseteq \R \text{,}\) and suppose that \(f \of{ X } \subseteq Y \text{.}\) If \(f \) is differentiable at a point \(c \in X \) and \(g \) is differentiable at \(f \of{ c } \text{,}\) then \(g \circ f \colon X \to \R \) is differentiable at \(c \text{,}\) with derivative
\begin{equation*} \of{ g \circ f }' \of{ c } = g' \of{ f \of{ c } } f' \of{ c }\text{.} \end{equation*}
🔗
🔗

Proof.
We first argue that
\begin{equation*} \lim_{ x \to c }{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } } = g' \of{ f \of{ c } }\text{.} \end{equation*}
Indeed, let \(\epsilon \gt 0 \) be a positive real number. Since \(g \) is differentiable at \(f \of{ c } \text{,}\) there is a positive real number \(\eta \gt 0 \) so that
\begin{equation*} \abs{ \frac{ g \of{ y } - g \of{ f \of{ c } } }{ y - f \of{ c } } - g' \of{ f \of{ c } } } \lt \epsilon \end{equation*}
for all points \(y \in Y \) so that \(0 \lt \abs{ y - f \of{ c } } \lt \eta \text{.}\) Since \(f \) is differentiable at \(c \text{,}\) it is continuous at \(c \) by Lemma 5.1.3 Differentiability implies continuity, and so there is a positive real number \(\delta \gt 0 \) so that \(\abs{ f \of{ x } - f \of{ c } } \lt \eta \) for all points \(x \in X \) so that \(\abs{ x - c } \lt \delta \text{.}\) In particular, if \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then
\begin{equation*} \abs{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } - g' \of{ f \of{ c } } } \lt \epsilon\text{.} \end{equation*}
We conclude that
\begin{equation*} \lim_{ x \to c }{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } } = g' \of{ f \of{ c } }\text{.} \end{equation*}
🔗
We now observe that
\begin{align*} \lim_{ x \to c }{ \frac{ \of{ g \circ f } \of{ x } - \of{ g \circ f } \of{ c } }{ x - c } } \amp = \lim_{ x \to c }{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ x - c } }\\ \amp = \lim_{ x \to c }{ \of{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } } \of{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } }\\ \amp = \of{ \lim_{ x \to c }{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } } } \of{ \lim_{ x \to c }{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } }\\ \amp = g' \of{ f \of{ c } } f' \of{ c }\text{,} \end{align*}
and so \(g \circ f \) is differentiable at \(c \text{,}\) with derivative \(\of{ g \circ f }' \of{ c } = g' \of{ f \of{ c } } f' \of{ c } \text{.}\)
