Theorem 3.2.19. Sequential characterization of map convergence.

Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) For all points \(c \in X \) and \(l \in Y \text{,}\) \(f \) converges to \(l \) at \(c \) if and only if for all sequences \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \setminus \set{ c } \text{,}\) if
\begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{,} \end{equation*}
then
\begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = l\text{.} \end{equation*}
🔗
🔗

Proof.
First suppose that \(f \) converges to \(l \) at \(c \text{,}\) and consider a sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \setminus \set{ c } \) which converges to \(c \text{.}\) We observe that \(\rho_{ X } \of{ x_{ n } , c } \gt 0 \) for all indices \(n \in \N \text{.}\)
🔗
Let \(\epsilon \gt 0 \) be a positive real number. Then there is a positive real number \(\delta \gt 0 \) so that
\begin{equation*} \rho_{ Y } \of{ f \of{ x } , l } \lt \epsilon \end{equation*}
for all points \(x \in X \) so that \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{.}\) Since \(\delta \gt 0 \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
\begin{equation*} 0 \lt \rho_{ X } \of{ x_{ n } , c } \lt \delta \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular, this implies that
\begin{equation*} \rho_{ Y } \of{ f \of{ x_{ n } } , l } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that \(\of{ f \of{ x_{ n } } }_{ n = 0 }^{ \infty } \) converges to \(l \text{.}\)
🔗
Conversely, now suppose that \(f \) does not converge to \(l \) at \(c \text{.}\) Then there is a positive real number \(\epsilon \) so that for all positive real numbers \(\delta \gt 0 \text{,}\) there is a point \(x \in X \setminus \set{ c } \) so that
\begin{equation*} 0 \lt \rho_{ X } \of{ x , c } \lt \delta \end{equation*}
but
\begin{equation*} \rho_{ Y } \of{ f \of{ x } , l } \geq \epsilon\text{.} \end{equation*}
In particular, let \(\of{ \delta_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of positive real numbers \(\delta_{ n } \geq 0 \) which converges in the Euclidean metric to \(0 \text{.}\) For each index \(n \in \N \text{,}\) there is a point \(x_{ n } \in X \setminus \set{ c } \) so that
\begin{equation*} 0 \lt \rho_{ X } \of{ x_{ n } , c } \lt \delta_{ n } \end{equation*}
but
\begin{equation*} \rho_{ Y } \of{ f \of{ x_{ n } } , l } \geq \epsilon\text{.} \end{equation*}
Since
\begin{equation*} d \of{ \rho_{ X } \of{ x_{ n } , c } , 0 } = \abs{ \rho_{ X } \of{ x_{ n } , c } - 0 } = \rho_{ X } \of{ x_{ n } , c } \lt \delta_{ n } \end{equation*}
for all indices \(n \in \N \text{,}\) Proposition 3.2.6 Sequential convergence implies that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(c \) but \(\of{ f \of{ x_{ n } } }_{ n = 0 }^{ \infty } \) does not converge to \(l \text{.}\)
