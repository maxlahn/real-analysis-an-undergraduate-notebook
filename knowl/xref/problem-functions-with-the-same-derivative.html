Problem 1. Functions with the same derivative.

(a)

Let \(f \colon X \to \R \) be a differentiable real-valued function defined on an interval \(X \text{.}\) Prove that if \(f' \of{ x } = 0 \) for all \(x \in X \text{,}\) then \(f \) is constant.
🔗
🔗

(b)

Let \(f , g \colon X \to \R \) be differentiable real-valued functions defined on an interval \(X \text{.}\) Prove that if \(f' \of{ x } = g' \of{ x } \) for all \(x \in X \text{,}\) then \(f \) and \(g \) differ by a constant.
🔗
🔗
The above result will be important in Chapter 6 Riemann Integration, where we will use it to compare two anti-derivatives of the same continuous function on a closed interval.
