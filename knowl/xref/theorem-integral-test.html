Theorem 7.2.13 (Colin Maclaurin; Augustin-Louis Cauchy). Integral test.

Let \(f \colon \clopint{ a }{ \infty } \to \clopint{ 0 }{ \infty } \) be a continuous and non-increasing non-negative real-valued function defined on the half-closed, half-open interval \(\clopint{ a }{ \infty } \text{.}\) Then the series
\begin{equation*} \sum_{ n = a }^{ \infty }{ f \of{ n } } \end{equation*}
converges if and only if the improper integral
\begin{equation*} \int_{ a }^{ \infty }{ f \of{ x } \, \diff{ x } } \end{equation*}
converges.
