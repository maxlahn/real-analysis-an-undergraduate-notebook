Problem 1. Eventually constant sequences.

A sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of elements \(x_{ n } \in X \) of a set \(X \) is called eventually constant if there is a point \(x \in X \) and a natural number \(n_{ 0 } \in \N \) so that \(x_{ n } = x \) for all indices \(n \geq n_{ 0 } \text{.}\)
🔗

(a)

Prove that any eventually constant sequence of points in a metric space is convergent.
🔗
🔗

(b)

Prove that any sequence of points in a discrete metric space is convergent if and only if it is eventually constant.
🔗
🔗

(c)

Give an example of a sequence of real numbers which converges in the Euclidean metric \(d \) on \(\R \) but diverges in the discrete metric \(\delta_{ \R } \) on \(\R \text{.}\)
