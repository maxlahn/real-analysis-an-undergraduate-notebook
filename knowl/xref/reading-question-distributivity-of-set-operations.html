Reading Question 1. The distributive properties of set operations.

(a)

Prove that \(S \cap \of{ T \cup U } = \of{ S \cap T } \cup \of{ S \cap U } \) for all sets \(S \text{,}\) \(T \text{,}\) and \(U \text{.}\)
🔗
🔗

(b)

Prove that \(S \cup \of{ T \cap U } = \of{ S \cup T } \cap \of{ S \cup U } \) for all sets \(S \text{,}\) \(T \text{,}\) and \(U \text{.}\)
🔗
🔗
Taken together, these results are called the distributive properties of the set operations.
