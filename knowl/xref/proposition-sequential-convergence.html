Proposition 3.2.6. Sequential convergence.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \text{.}\) Then for any point \(x \in X \text{,}\)
\begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = x \end{equation*}
if and only if
\begin{equation*} \lim_{ n \to \infty }{ \rho \of{ x_{ n } , x } } = 0\text{.} \end{equation*}
🔗
🔗

Proof.
We observe that
\begin{equation*} d \of{ \rho \of{ x_{ n } , x } , 0 } = \abs{ \rho \of{ x_{ n } , x } - 0 } = \abs{ \rho \of{ x_{ n } , x } } = \rho \of{ x_{ n } , x } \end{equation*}
for all indices \(n \in \N \text{.}\) First suppose that
\begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = x\text{,} \end{equation*}
and let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that \(\rho \of{ x_{ n } , x } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
\begin{equation*} d \of{ \rho \of{ x_{ n } , x } , 0 } = \rho \of{ x_{ n } , x } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{,}\) and so
\begin{equation*} \lim_{ n \to \infty }{ \rho \of{ x_{ n } , x } } = 0\text{.} \end{equation*}
🔗
Conversely, now suppose that
\begin{equation*} \lim_{ n \to \infty }{ \rho \of{ x_{ n } , x } } = 0\text{,} \end{equation*}
and let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that \(d \of{ \rho \of{ x_{ n } , x } , 0 } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
\begin{equation*} \rho \of{ x_{ n } , x } = d \of{ \rho \of{ x_{ n } , x } , 0 } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{,}\) and so
\begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = x\text{.} \end{equation*}
