Lemma 3.4.14. Diameter and radius.

Let \(r \gt 0 \) be a positive real number and \(c \in X \) be a point in a metric space \(\of{ X , \rho } \text{.}\) The open ball \(\mB_{ r } \of{ c } \text{,}\) closed disk \(\mD_{ r } \of{ c } \text{,}\) and sphere \(\mS_{ r } \of{ c } \) of radius \(r \) and center \(c \) have diameter at most \(2 r \text{.}\)
🔗
🔗

Proof.
Since \(c \in \mB_{ r } \of{ c } \) the open ball \(\mB_{ r } \of{ c } \neq \emptyset \) is non-empty. Since
\begin{equation*} \rho \of{ u , v } \leq \rho \of{ u , c } + \rho \of{ c , v } = \rho \of{ u , c } + \rho \of{ v , c } \lt r + r = 2 r \end{equation*}
for all points \(u , v \in \mB_{ r } \of{ c } \text{,}\)
\begin{equation*} \diam \of{ \mB_{ r } \of{ c } } = \sup_{ u , v \in \mB_{ r } \of{ c } }{ \rho \of{ u , v } } \leq 2 r\text{.} \end{equation*}
🔗
Similarly, since \(c \in \mD_{ r } \of{ c } \) the closed disk \(\mD_{ r } \of{ c } \neq \emptyset \) is non-empty. Since
\begin{equation*} \rho \of{ u , v } \leq \rho \of{ u , c } + \rho \of{ c , v } = \rho \of{ u , c } + \rho \of{ v , c } \leq r + r = 2 r \end{equation*}
for all points \(u , v \in \mD_{ r } \of{ c } \text{,}\)
\begin{equation*} \diam \of{ \mD_{ r } \of{ c } } = \sup_{ u , v \in \mD_{ r } \of{ c } }{ \rho \of{ u , v } } \leq 2 r\text{.} \end{equation*}
🔗
If the sphere \(\mS_{ r } \of{ c } = \emptyset \) is empty, then \(\diam \of{ \mS_{ r } \of{ c } } = \diam \of{ \emptyset } = 0 \lt 2 r \text{.}\) On the other hand, if the sphere \(\mS_{ r } \of{ c } \neq \emptyset \) is non-empty, then we observe that
\begin{equation*} \rho \of{ u , v } \leq \rho \of{ u , c } + \rho \of{ c , v } = \rho \of{ u , c } + \rho \of{ v , c } \leq r + r = 2 r \end{equation*}
for all points \(u , v \in \mS_{ r } \of{ c } \text{,}\)
\begin{equation*} \diam \of{ \mS_{ r } \of{ c } } = \sup_{ u , v \in \mD_{ r } \of{ c } }{ \rho \of{ u , v } } \leq 2 r\text{.} \end{equation*}
