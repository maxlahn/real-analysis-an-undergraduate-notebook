Proposition 3.6.11. Subsequences of convergent sequences.

Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) in a metric space \(\of{ X , \rho } \text{.}\) If \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges in \(X \text{,}\) then any subsequence \(\of{ x_{ n_{ k } } }_{ k = 0 }^{ \infty } \) also converges in \(X \text{,}\) and
\begin{equation*} \lim_{ k \to \infty }{ x_{ n_{ k } } } = \lim_{ n \to \infty }{ x_{ n } }\text{.} \end{equation*}
🔗
🔗

Proof.
Let
\begin{equation*} x = \lim_{ n \to \infty }{ x_{ n } }\text{,} \end{equation*}
and consider a positive real number \(\epsilon \gt 0 \text{.}\) There is some natural number \(n_{ \epsilon } \in \N \) so that \(\rho \of{ x_{ n } , x } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\)
🔗
We observe that Lemma 3.6.10 Increasing functions implies that \(n_{ k } \geq n_{ \epsilon } \) for all indices \(k \geq n_{ \epsilon } \text{,}\) and so
\begin{equation*} \rho \of{ x_{ n_{ k } } , x } \lt \epsilon \end{equation*}
for all such indices. Thus
\begin{equation*} \lim_{ k \to \infty }{ x_{ n_{ k } } } = x = \lim_{ n \to \infty }{ x_{ n } }\text{.} \end{equation*}
