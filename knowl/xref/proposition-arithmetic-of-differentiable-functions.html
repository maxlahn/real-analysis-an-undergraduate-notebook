Proposition 5.1.4. Arithmetic of differentiable functions.

  1. Addition of differentiable functions.
    Let \(f , g \colon X \to \R \) be real-valued functions on a subset \(X \subseteq \R \text{.}\) For a point \(c \in X \text{,}\) if \(f \) and \(g \) are differentiable at \(c \text{,}\) then \(f + g \) is differentiable at \(c \text{,}\) and
    \begin{equation*} \of{ f + g }' \of{ c } = f' \of{ c } + g' \of{ c }\text{.} \end{equation*}
    🔗
    🔗
  2. Multiplication of differentiable functions.
    Let \(f , g \colon X \to \R \) be real-valued functions on a subset \(X \subseteq \R \text{.}\) For a point \(c \in X \text{,}\) if \(f \) and \(g \) are differentiable at \(c \text{,}\) then \(f \cdot g \) is differentiable at \(c \text{,}\) and
    \begin{equation*} \of{ f \cdot g }' \of{ c } = f' \of{ c } g \of{ c } + f \of{ c } g' \of{ c }\text{.} \end{equation*}
    🔗
    🔗
🔗

Proof.
  1. Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) and \(g \) are differentiable at \(c \text{,}\) there are positive real numbers \(\delta_{ f } , \delta_{ g } \gt 0 \) so that
    \begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta_{ f } \text{,}\) and
    \begin{equation*} \abs{ \frac{ g \of{ x } - g \of{ c } }{ x - c } - g' \of{ c } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta_{ g } \text{.}\) Let \(\delta = \min \of{ \set{ \delta_{ f } , \delta_{ g } } } \gt 0 \text{,}\) and note that
    \begin{align*} \abs{ \frac{ \of{ f + g } \of{ x } - \of{ f + g } \of{ c } }{ x - c } - \of{ f' \of{ c } + g' \of{ c } } } \amp = \abs{ \frac{ f \of{ x } + g \of{ x } - f \of{ c } - g \of{ c } }{ x - c } - f' \of{ c } - g' \of{ c } }\\ \amp = \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } + \frac{ g \of{ x } - g \of{ c } }{ x - c } - g' \of{ c } }\\ \amp \leq \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } + \abs{ \frac{ g \of{ x } - g \of{ c } }{ x - c } - g' \of{ c } }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) Thus \(f + g \) is differentiable at \(c \text{,}\) with derivative
    \begin{equation*} \of{ f + g }' \of{ c } = f' \of{ c } + g' \of{ c }\text{.} \end{equation*}
    🔗
    🔗
  2. Because utilizing the \(\epsilon \)-\(\delta \) characterization of convergence is slightly more complicated than it’s worth, we compute the derivative directly. Since \(f \) and \(g \) are differentiable at \(c \text{,}\)
    \begin{equation*} \lim_{ x \to c }{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } = f' \of{ c } \end{equation*}
    and
    \begin{equation*} \lim_{ x \to c }{ \frac{ g \of{ x } - g \of{ c } }{ x - c } } = g' \of{ c }\text{.} \end{equation*}
    Moreover, Lemma 5.1.3 Differentiability implies continuity implies that \(g \) is continuous at \(c \text{,}\) so that
    \begin{equation*} \lim_{ x \to c }{ g \of{ x } } = g \of{ c }\text{.} \end{equation*}
    We conclude that
    \begin{align*} \lim_{ x \to c }{ \frac{ \of{ f \cdot g } \of{ x } - \of{ f \cdot g } \of{ c } }{ x - c } } \amp = \lim_{ x \to c }{ \frac{ f \of{ x } g \of{ x } - f \of{ c } g \of{ x } + f \of{ c } g \of{ x } - f \of{ c } g \of{ c } }{ x - c } }\\ \amp = \lim_{ x \to c }{ \of{ \of{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } g \of{ x } + f \of{ c } \of{ \frac{ g \of{ x } - g \of{ c } }{ x - c } } } }\\ \amp = f' \of{ c } g \of{ c } + f \of{ c } g' \of{ c }\text{.} \end{align*}
    Thus \(f \cdot g \) is differentiable at \(c \text{,}\) with derivative \(\of{ f \cdot g }' \of{ c } = f' \of{ c } g \of{ c } + f \of{ c } g' \of{ c } \text{.}\)
