Proposition 3.2.23. Sequential characterization of limit points.

Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{.}\) A point \(c \in X \) is a limit point of \(U \) if and only if
\begin{equation*} c = \lim_{ n \to \infty }{ u_{ n } } \end{equation*}
for some sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) of points \(u_{ n } \in U \setminus \set{ c } \text{.}\)
🔗
🔗

Proof.
First suppose that \(c \) is a limit point of \(U \text{.}\) Then for each positive integer \(n \geq 1 \text{,}\) \(\frac{ 1 }{ n } \gt 0 \text{,}\) and so there is a point \(u_{ n } \in U \setminus \set{ c } \) so that
\begin{equation*} 0 \lt \rho \of{ u_{ n } , c } \lt \frac{ 1 }{ n }\text{.} \end{equation*}
We claim that \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) converges to \(c \text{.}\) Indeed, for any positive real number \(\epsilon \gt 0 \text{,}\) the Archimedean principle implies that there is a natural number \(n_{ \epsilon } \gt \frac{ 1 }{ \epsilon } \text{.}\) We observe that
\begin{equation*} \rho \of{ u_{ n } , c } \lt \frac{ 1 }{ n } \leq \frac{ 1 }{ n_{ \epsilon } } \lt \epsilon \end{equation*}
for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that
\begin{equation*} \lim_{ n \to \infty }{ u_{ n } } = c\text{.} \end{equation*}
🔗
Conversely, now suppose that
\begin{equation*} \lim_{ n \to \infty }{ u_{ n } } = c \end{equation*}
for some sequence \(\of{ u_{ n } }_{ n = 0 }^{ \infty } \) of points \(u_{ n } \in U \setminus \set{ c } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \gt 0 \) so that \(\rho \of{ u_{ n } , c } \lt \epsilon \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
\begin{equation*} 0 \lt \rho \of{ u_{ n_{ \epsilon } } , c } \lt \epsilon\text{,} \end{equation*}
since \(u_{ n_{ \epsilon } } \neq c \text{.}\) We conclude that \(c \) is a limit point of \(U \text{.}\)
