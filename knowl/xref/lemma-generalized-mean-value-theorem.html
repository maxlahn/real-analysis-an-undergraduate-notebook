Lemma 5.2.4. Generalized mean value theorem.

Let \(f , g , h \colon \clint{ a }{ b } \to \R \) be real-valued functions defined on a closed interval \(\clint{ a }{ b } \text{,}\) and consider the real-valued function \(D \colon \clint{ a }{ b } \to \R \) defined by the formula
\begin{align*} D \of{ x } \amp = \det \of{ \begin{matrix} f \of{ x } \amp g \of{ x } \amp h \of{ x } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} }\\ \amp = f \of{ x } \of{ g \of{ a } h \of{ b } - g \of{ b } h \of{ b } } - g \of{ x } \of{ f \of{ a } h \of{ b } - f \of{ b } h \of{ a } }\\ \amp \qquad + h \of{ x } \of{ f \of{ a } g \of{ b } - f \of{ b } g \of{ a } }\text{.} \end{align*}
If \(f \text{,}\) \(g \text{,}\) and \(h \) are continuous on the closed interval \(\clint{ a }{ b } \) and differentiable on the interior \(\opint{ a }{ b } \text{,}\) then \(D \) is differentiable on \(\opint{ a }{ b } \text{,}\) and \(D' \of{ c } = 0 \) for some interior point \(a \lt c \lt b \text{.}\)
🔗
🔗

Proof.
We observe that \(D \) is a linear combination of \(f \text{,}\) \(g \text{,}\) and \(h \text{,}\) and so is continuous on \(\clint{ a }{ b } \) by Proposition 3.5.6 Vector arithmetic of continuous maps and is differentiable on \(\opint{ a }{ b } \) by Proposition 5.1.4 Arithmetic of differentiable functions. Moreover,
\begin{equation*} D \of{ a } = \det \of{ \begin{matrix} f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} } \end{equation*}
and
\begin{equation*} D \of{ b } = \det \of{ \begin{matrix} f \of{ b } \amp g \of{ b } \amp h \of{ b } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} } \end{equation*}
are determinants of \(3 \times 3 \) matrices with repeated rows, and so \(D \of{ a } = D \of{ b } = 0 \) by a standard result of linear algebra. Alternatively, one can verify that \(D \of{ a } = D \of{ b } = 0 \) by direct computation. In any case, Rolle’s lemma now implies that \(D' \of{ c } = 0 \) for some interior point \(a \lt c \lt b \text{.}\)
