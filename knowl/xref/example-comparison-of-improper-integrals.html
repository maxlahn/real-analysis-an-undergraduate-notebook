Example 6.3.15. Comparison of improper integrals.

Let \(f \colon \clopint{ 1 }{ \infty } \to \R \) be the real-valued function defined by the formula
\begin{equation*} f \of{ x } = \frac{ a }{ x^{ 2 } + b } \end{equation*}
for some non-negative real numbers \(a , b \geq 0 \text{.}\) Since \(f \) is continuous, the restriction of \(f \) to any compact subinterval of \(\opint{ 1 }{ \infty } \) is integrable. We observe that
\begin{equation*} 0 \leq f \of{ x } = \frac{ a }{ x^{ 2 } + b } \lt \frac{ a }{ x^{ 2 } } \end{equation*}
for all points \(1 \leq x \lt \infty \text{.}\) Since \(\frac{ a }{ x^{ 2 } } \) is improperly integrable, the Comparison test for integral convergence implies that \(f \) is improperly integrable, with improper integral
\begin{equation*} 0 \leq \int_{ 1 }^{ \infty }{ f \of{ x } \, \diff{ x } } \leq \int_{ 1 }^{ \infty }{ \frac{ a }{ x^{ 2 } } \, \diff{ x } } = \frac{ a }{ 2 - 1 } = a\text{.} \end{equation*}
