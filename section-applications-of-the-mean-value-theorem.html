    Section 5.3 Applications of the Mean Value Theorem

    In this section, we introduce one of the fundamental results of differential calculus. The mean value theorem relates the instantaneous rate of change of a differentiable function given by its derivative and its average rate of change given by a difference quotient. While not immediately obvious, the mean value theorem has several deep consequences for the study of differentiable functions. We will derive the mean value theorem and exhibit several of these corollaries.
    🔗

    Subsection 5.3.1 Average and Instantaneous Rates of Change

    The average rate of change of a real-valued function \(f \colon X \to \R \) defined on some subset \(X \subseteq \R \) which contains a closed interval \(\clint{ a }{ b } \subseteq X \) is the difference quotient
    \begin{equation*} \frac{ f \of{ b } - f \of{ a } }{ b - a }\text{.} \end{equation*}
    In Section 5.1 Differentiability, we saw that the derivative of a differentiable function is a limit of such difference quotients; as such, the derivative is often interpreted as an instantaneous rate of change. The mean value theorem relates these two rates of change under some mild hypotheses on \(f \text{.}\)
    🔗
    Before we explore the Mean value theorem in its full generality, we prove a special case. The proof of the Mean value theorem will rely on the following supporting lemma:
    🔗

    Lemma 5.3.1 (Michel Rolle). Rolle’s lemma.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \subsetneq \R \text{.}\) If \(f \) is continuous on the closed interval \(\clint{ a }{ b } \) and differentiable on the open interval \(\opint{ a }{ b } \) and \(f \of{ a } = f \of{ b } \text{,}\) then \(f' \of{ c } = 0 \) for some point \(a \lt c \lt b \text{.}\)
    🔗
    🔗

    Proof.
    Let \(a \lt c \lt b \text{,}\) and suppose that \(f' \of{ c } \gt 0 \text{.}\) Then since \(\frac{ f' \of{ c } }{ 2 } \gt 0 \) is positive, there is some positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt \frac{ f' \of{ c } }{ 2 } \end{equation*}
    for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) In particular,
    \begin{equation*} \frac{ f \of{ x } - f \of{ c } }{ x - c } \gt f' \of{ c } - \frac{ f' \of{ c } }{ 2 } = \frac{ f' \of{ c } }{ 2 } \gt 0 \end{equation*}
    for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) so that \(f \of{ x } - f \of{ c } \) and \(x - c \) have the same sign; that is, so long as \(x \in \clint{ a }{ b } \) and \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then \(f \of{ x } \lt f \of{ c } \) if \(x \lt c \) and \(f \of{ x } \gt f \of{ c } \) if \(x \gt c \text{.}\) In particular, we conclude that \(f \) does not achieve a maximum or minimum at \(c \text{.}\)
    🔗
    Similarly, now suppose that \(f' \of{ c } \lt 0 \text{.}\) Then since \(-\frac{ f' \of{ c } }{ 2 } \gt 0 \) is positive, there is some positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt -\frac{ f' \of{ c } }{ 2 } \end{equation*}
    for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) In particular,
    \begin{equation*} \frac{ f \of{ x } - f \of{ c } }{ x - c } \lt -f' \of{ c } + \frac{ f' \of{ c } }{ 2 } = -\frac{ f' \of{ c } }{ 2 } \lt 0 \end{equation*}
    for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) so that \(f \of{ x } - f \of{ c } \) and \(x - c \) have opposite sign; that is, so long as \(x \in \clint{ a }{ b } \) and \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then \(f \of{ x } \gt f \of{ c } \) if \(x \lt c \) and \(f \of{ x } \lt f \of{ c } \) if \(x \gt c \text{.}\) In particular, we conclude that \(f \) does not achieve a maximum or minimum at \(c \text{.}\)
    🔗
    However, \(\clint{ a }{ b } \) is closed and bounded, and hence compact by Corollary 3.6.23 Compact subsets of Euclidean space. Since \(f \) is continuous and \(\clint{ a }{ b } \) is compact, Proposition 3.6.20 Continuous images of compact subsets implies that
    \begin{equation*} \im \of{ f } = f \of{ \clint{ a }{ b } } = \setmid{ f \of{ x } \in \R }{ a \leq x \leq b } \end{equation*}
    is compact and hence also closed and bounded. In particular, \(f \) attains a maximum \(\max_{ a \leq x \leq b }{ f \of{ x } } = \max \of{ \im \of{ f } } \) and a minimum \(\min_{ a \leq x \leq b }{ f \of{ x } } = \min \of{ \im \of{ f } } \text{.}\)
    🔗
    To summarize our argument so far, we have shown that \(f \) does not achieve a maximum or minimum value at any point where its derivative is non-zero, but \(f \) must achieve a maximum and minimum value somewhere in \(\clint{ a }{ b } \text{.}\) If \(f \) achieves a maximum or a minimum value at an interior point \(a \lt c \lt b \text{,}\) then the above argument shows that \(f' \of{ c } = 0 \text{.}\) Otherwise, \(f \) attains both its maximum and minimum values at the endpoints \(a \) and \(b \text{.}\) In this case, \(f \) must be constant because \(f \of{ a } = f \of{ b } \text{.}\) In particular, this implies that \(f' \of{ c } = 0 \) for all points \(a \lt c \lt b \text{.}\)
    🔗
    🔗
    We remark that the details of the above proof of Rolle’s lemma are necessary even if we have an understanding of the analysis of critical points and local extrema. Indeed, the result often taught in calculus classes that for a function \(f \colon X \to \R \text{,}\) if \(f \) is differentiable at a point \(c \in X \) and \(f' \of{ c } \gt 0 \text{,}\) then \(f \) is increasing near \(c \) is false; such a conclusion actually requires continuous differentiability near \(c \text{.}\)
    🔗

    Theorem 5.3.2 (Joseph-Louis Lagrange). Mean value theorem.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \subsetneq \R \text{.}\) If \(f \) is continuous on the closed interval \(\clint{ a }{ b } \) and differentiable on the open interval \(\opint{ a }{ b } \text{,}\) then
    \begin{equation*} f' \of{ c } = \frac{ f \of{ b } - f \of{ a } }{ b - a } \end{equation*}
    for some point \(a \lt c \lt b \text{.}\)
    🔗
    🔗

    Proof.
    Let \(g \colon \clint{ a }{ b } \to \R \) be the real-valued function defined by the formula
    \begin{equation*} g \of{ x } = f \of{ x } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } x\text{.} \end{equation*}
    Then \(g \) is continuous by Proposition 3.5.6 Vector arithmetic of continuous maps and differentiable on the open interval \(\opint{ a }{ b } \) by Proposition 5.1.4 Arithmetic of differentiable functions, with derivative
    \begin{equation*} g' \of{ x } = f' \of{ x } - \frac{ f \of{ b } - f \of{ a } }{ b - a }\text{.} \end{equation*}
    Moreover,
    \begin{align*} g \of{ b } \amp = f \of{ b } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } b\\ \amp = f \of{ b } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } \of{ b - a } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } a\\ \amp = f \of{ b } - \of{ f \of{ b } - f \of{ a } } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } a\\ \amp = f \of{ b } - \of{ \frac{ f \of{ b } - f \of{ a } }{ b - a } } a = g \of{ a }\text{.} \end{align*}
    Lemma 5.3.1 Rolle’s lemma now implies that \(g' \of{ c } = 0 \) for some interior point \(a \lt c \lt b \text{;}\) that is,
    \begin{equation*} f' \of{ c } = \frac{ f \of{ b } - f \of{ a } }{ b - a }\text{.} \end{equation*}
    🔗
    🔗

    Example 5.3.3. Hypotheses of the Mean value theorem.

    The following examples demonstrate that each of the hypotheses of the Mean value theorem is necessary:
    1. Let \(f \colon \clint{ 0 }{ 1 } \cup \clint{ 2 }{ 3 } \to \R \) be the real-valued function defined piecewise by the formula
      \begin{equation*} f \of{ x } = \begin{cases} 0 \amp 0 \leq x \leq 1 \\ 1 \amp 2 \leq x \leq 3 \text{.}\end{cases} \end{equation*}
      Then \(f \) is continuous on \(\clint{ 0 }{ 1 } \cup \clint{ 2 }{ 3 } \) and differentiable on the interior \(\opint{ 0 }{ 1 } \cup \opint{ 2 }{ 3 } \text{,}\) but
      \begin{equation*} f' \of{ x } = 0 \neq \frac{ 1 }{ 3 } = \frac{ 1 - 0 }{ 3 - 0 } = \frac{ f \of{ 3 } - f \of{ 0 } }{ 3 - 0 } \end{equation*}
      for all interior points \(x \in \opint{ 0 }{ 1 } \cup \opint{ 2 }{ 3 } \text{.}\) This example shows that \(f \) must be defined on a closed interval in order to guarantee the conclusions of the Mean value theorem.
      🔗
      🔗
    2. Let \(f \colon \clint{ 0 }{ 1 } \to \R \) be the real-valued function defined piecewise by the formula
      \begin{equation*} f \of{ x } = \begin{cases} 0 \amp 0 \leq x \lt 1 \\ 1 \amp x = 1 \text{.}\end{cases} \end{equation*}
      Then \(f \) is continuous on \(\clopint{ 0 }{ 1 } \) and differentiable on the interior \(\opint{ 0 }{ 1 } \text{,}\) but
      \begin{equation*} f' \of{ x } = 0 \neq 1 = \frac{ 1 - 0 }{ 1 - 0 } = \frac{ f \of{ 1 } - f \of{ 0 } }{ 1 - 0 } \end{equation*}
      for all interior points \(x \in \opint{ 0 }{ 1 } \text{.}\) This example shows that \(f \) must be continuous on the closed interval \(\clint{ 0 }{ 1 } \) in order to guarantee the conclusions of the Mean value theorem.
      🔗
      🔗
    3. Let \(f \colon \clint{ -1 }{ 1 } \to \R \) be the real-valued function defined by the formula \(f \of{ x } = \abs{ x } \text{.}\) Then \(f \) is continuous on \(\clint{ 0 }{ 1 } \) and differentiable at every interior point except \(x = 0 \text{,}\) but
      \begin{equation*} f' \of{ x } = \pm 1 \neq 0 = \frac{ 1 - 1 }{ 1 - \of{ -1 } } = \frac{ f \of{ 1 } - f \of{ -1 } }{ 1 - \of{ -1 } } \end{equation*}
      for all interior points \(x \in \opint{ -1 }{ 1 } \setminus \set{ 0 } \text{.}\) This example shows that \(f \) must be differentiable on the open interval \(\opint{ -1 }{ 1 } \) in order to guarantee the conclusions of the Mean value theorem.
      🔗
      🔗
    🔗
    🔗
    While all of the hypotheses of the Mean value theorem are necessary in order to guarantee its conclusion, they are sufficient as written. Indeed, a function \(f \colon \clint{ a }{ b } \to \R \) need not be differentiable at the endpoints \(a \) or \(b \) in order to apply the Mean value theorem; for an example, see the function defined by the formula
    \begin{equation*} f \of{ x } = \sqrt{ \of{ \frac{ a - b }{ 2 } }^{ 2 } - \of{ x - \frac{ a + b }{ 2 } }^{ 2 } }\text{,} \end{equation*}
    which is differentiable on the open interval \(\opint{ a }{ b } \) but not at the endpoints and yet satisfies the conclusions of the Mean value theorem.
    🔗
    🔗

    Subsection 5.3.2 Beyond the Mean Value Theorem

    Rolle’s lemma and the Mean value theorem are two of a constellation of similar results relating the derivatives of some differentiable functions to the average rates of change of said functions. Particularly useful among these results is the following lemma, from which the Mean value theorem and more can be derived:
    🔗

    Lemma 5.3.4. Generalized mean value theorem.

    Let \(f , g , h \colon \clint{ a }{ b } \to \R \) be real-valued functions defined on a closed interval \(\clint{ a }{ b } \text{,}\) and consider the real-valued function \(D \colon \clint{ a }{ b } \to \R \) defined by the formula
    \begin{align*} D \of{ x } \amp = \det \of{ \begin{matrix} f \of{ x } \amp g \of{ x } \amp h \of{ x } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} }\\ \amp = f \of{ x } \of{ g \of{ a } h \of{ b } - g \of{ b } h \of{ b } } - g \of{ x } \of{ f \of{ a } h \of{ b } - f \of{ b } h \of{ a } }\\ \amp \qquad + h \of{ x } \of{ f \of{ a } g \of{ b } - f \of{ b } g \of{ a } }\text{.} \end{align*}
    If \(f \text{,}\) \(g \text{,}\) and \(h \) are continuous on the closed interval \(\clint{ a }{ b } \) and differentiable on the interior \(\opint{ a }{ b } \text{,}\) then \(D \) is differentiable on \(\opint{ a }{ b } \text{,}\) and \(D' \of{ c } = 0 \) for some interior point \(a \lt c \lt b \text{.}\)
    🔗
    🔗

    Proof.
    We observe that \(D \) is a linear combination of \(f \text{,}\) \(g \text{,}\) and \(h \text{,}\) and so is continuous on \(\clint{ a }{ b } \) by Proposition 3.5.6 Vector arithmetic of continuous maps and is differentiable on \(\opint{ a }{ b } \) by Proposition 5.1.4 Arithmetic of differentiable functions. Moreover,
    \begin{equation*} D \of{ a } = \det \of{ \begin{matrix} f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} } \end{equation*}
    and
    \begin{equation*} D \of{ b } = \det \of{ \begin{matrix} f \of{ b } \amp g \of{ b } \amp h \of{ b } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} } \end{equation*}
    are determinants of \(3 \times 3 \) matrices with repeated rows, and so \(D \of{ a } = D \of{ b } = 0 \) by a standard result of linear algebra. Alternatively, one can verify that \(D \of{ a } = D \of{ b } = 0 \) by direct computation. In any case, Rolle’s lemma now implies that \(D' \of{ c } = 0 \) for some interior point \(a \lt c \lt b \text{.}\)
    🔗
    🔗
    One can use Lemma 5.3.4 Generalized mean value theorem to construct another proof of the Mean value theorem, but its real strength is in its generality. We include the following alternative proof of Lemma 5.3.4 Generalized mean value theorem for completeness:
    🔗

    Alternative proof of the Mean value theorem.
    Let \(g , h \colon \clint{ a }{ b } \to \R \) be the real-valued functions defined by the formulas \(g \of{ x } = x \) and \(h \of{ x } = 1 \text{,}\) and consider the function \(D \colon \clint{ a }{ b } \to \R \) defined as in Lemma 5.3.4 Generalized mean value theorem. Then
    \begin{align*} D \of{ x } \amp = \det \of{ \begin{matrix} f \of{ x } \amp g \of{ x } \amp h \of{ x } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} } = \det \of{ \begin{matrix} f \of{ x } \amp x \amp 1 \\ f \of{ a } \amp a \amp 1 \\ f \of{ b } \amp b \amp 1 \end{matrix} }\\ \amp = f \of{ x } \of{ a - b } - x \of{ f \of{ a } - f \of{ b } } + 1 \of{ f \of{ a } b - f \of{ b } a }\text{,} \end{align*}
    and so
    \begin{equation*} D' \of{ x } = f' \of{ x } \of{ a - b } - \of{ f \of{ a } - f \of{ b } }\text{.} \end{equation*}
    Lemma 5.3.4 Generalized mean value theorem implies that there is some interior point \(a \lt c \lt b \) so that \(D' \of{ c } = 0 \text{.}\) We observe that
    \begin{align*} 0 = D' \of{ c } \amp = f' \of{ c } \of{ a - b } - \of{ f \of{ a } - f \of{ b } }\\ f \of{ a } - f \of{ b } \amp = f' \of{ c } \of{ a - b }\\ \frac{ f \of{ b } - f \of{ a } }{ b - a } = \frac{ f \of{ a } - f \of{ b } }{ a - b } \amp = f' \of{ c }\text{.} \end{align*}
    🔗
    🔗
    Lemma 5.3.4 Generalized mean value theorem relates the derivatives of three differentiable functions, and the Theorem 5.3.2 Mean value theorem deals with the derivative of just one differentiable function. Intermediate between these results is the following result, which relates the derivatives of two differentiable functions:
    🔗

    Theorem 5.3.5 (Augustin-Louis Cauchy). Extended mean value theorem.

    Let \(f , g \colon \clint{ a }{ b } \to \R \) be real-valued functions defined on a closed interval \(\clint{ a }{ b } \subsetneq \R \text{.}\) If \(f \) and \(g \) are continuous on the closed interval \(\clint{ a }{ b } \) and differentiable on the open interval \(\opint{ a }{ b } \text{,}\) then
    \begin{equation*} f' \of{ c } \of{ g \of{ b } - g \of{ a } } = \of{ f \of{ b } - f \of{ a } } g' \of{ c } \end{equation*}
    for some point \(a \lt c \lt b \text{.}\)
    🔗
    🔗

    Proof.
    Let \(h \colon \clint{ a }{ b } \to \R \) be the constant real-valued function defined by the formula \(h \of{ x } = 1 \text{,}\) and consider the function \(D \colon \clint{ a }{ b } \to \R \) defined as in Lemma 5.3.4 Generalized mean value theorem. Then
    \begin{align*} D \of{ x } \amp = \det \of{ \begin{matrix} f \of{ x } \amp g \of{ x } \amp h \of{ x } \\ f \of{ a } \amp g \of{ a } \amp h \of{ a } \\ f \of{ b } \amp g \of{ b } \amp h \of{ b } \end{matrix} } = \det \of{ \begin{matrix} f \of{ x } \amp g \of{ x } \amp 1 \\ f \of{ a } \amp g \of{ a } \amp 1 \\ f \of{ b } \amp g \of{ b } \amp 1 \end{matrix} }\\ \amp = f \of{ x } \of{ g \of{ a } - g \of{ b } } - g \of{ x } \of{ f \of{ a } - f \of{ b } } + \of{ f \of{ a } g \of{ b } - f \of{ b } g \of{ a } }\text{,} \end{align*}
    and so
    \begin{equation*} D' \of{ x } = f' \of{ x } \of{ g \of{ a } - g \of{ b } } - g' \of{ x } \of{ f \of{ a } - f \of{ b } }\text{.} \end{equation*}
    Lemma 5.3.4 Generalized mean value theorem implies that there is some interior point \(a \lt c \lt b \) so that \(D' \of{ c } = 0 \text{.}\) We observe that
    \begin{align*} 0 = D' \of{ c } \amp = f' \of{ c } \of{ g \of{ a } - g \of{ b } } - g' \of{ c } \of{ f \of{ a } - f \of{ b } }\\ f' \of{ c } \of{ g \of{ b } - g \of{ a } } \amp = g' \of{ c } \of{ f \of{ b } - f \of{ a } }\text{.} \end{align*}
    🔗
    🔗
    We will use the Extended mean value theorem to compute certain limits taking indeterminate form.
    🔗

    Corollary 5.3.6 (Guillaume de l’Hôpital). L’Hôpital’s rule.

    Let \(f , g \colon \opint{ a }{ b } \to \R \) be real-valued functions on an open interval \(\opint{ a }{ b } \subseteq \R \text{,}\) and consider an interior point \(a \lt c \lt b \text{.}\) Suppose that either
    \begin{equation*} \lim_{ x \to c }{ f \of{ x } } = \lim_{ x \to c }{ g \of{ x } } = 0 \end{equation*}
    or
    \begin{equation*} \lim_{ x \to c }{ \abs{ f \of{ x } } } = \lim_{ x \to c }{ \abs{ g \of{ x } } } = \infty\text{.} \end{equation*}
    If \(f \) and \(g \) are differentiable on \(\opint{ a }{ b } \setminus c \text{,}\) \(g' \of{ x } \neq 0 \) for all \(x \in \opint{ a }{ b } \setminus \set{ c } \text{,}\) and
    \begin{equation*} \lim_{ x \to c }{ \frac{ f' \of{ x } }{ g' \of{ x } } } = L \end{equation*}
    for some extended real number \(L \in \clint{ -\infty }{ \infty } \text{,}\) then
    \begin{equation*} \lim_{ x \to c }{ \frac{ f \of{ x } }{ g \of{ x } } } = L \end{equation*}
    🔗
    🔗

    Proof.
    Since \(g \) is continuous on \(\opint{ a }{ b } \) and \(g' \of{ x } \neq 0 \) for all \(x \in \opint{ a }{ b } \setminus \set{ c } \text{,}\) \(g \of{ x } \) attains no local extrema on \(\opint{ a }{ b } \setminus \set{ c } \text{.}\) In particular, \(g \of{ x } \) is strictly monotone on \(\opint{ a }{ c } \) and on \(\opint{ b }{ c } \text{.}\) Without loss of generality, we may shrink the interval \(\opint{ a }{ b } \) so that \(g \of{ x } \neq 0 \) for all points \(x \in \opint{ a }{ b } \setminus \set{ c } \text{.}\)
    🔗
    For each point \(x \in \opint{ a }{ b } \setminus \set{ c } \text{,}\) let \(I_{ x } \) denote the interval with endpoints \(x \) and \(c \text{,}\) including \(x \) but not \(c \text{;}\) that is,
    \begin{equation*} I_{ x } = \begin{cases} \clopint{ x }{ c } \amp a \lt x \lt c \lt b \\ \opclint{ c }{ x } \amp a \lt c \lt x \lt b \text{.}\end{cases} \end{equation*}
    Moreover, let \(i , s \colon \opint{ a }{ b } \setminus \set{ c } \to \clint{ -\infty }{ \infty } \) be the extended real-valued functions defined by the formulas
    \begin{align*} i \of{ x } \amp = \inf_{ y \in I_{ x } }{ \frac{ f' \of{ y } }{ g' \of{ y } } } \amp s \of{ x } \amp = \sup_{ y \in I_{ x } }{ \frac{ f' \of{ y } }{ g' \of{ y } } }\text{.} \end{align*}
    We observe that since \(\lim_{ x \to c }{ \frac{ f' \of{ x } }{ g' \of{ x } } } = L \text{,}\)
    \begin{equation*} \lim_{ x \to c }{ i \of{ x } } = \lim_{ x \to c }{ s \of{ x } } = L\text{.} \end{equation*}
    🔗
    Consider distinct points \(y , z \in I_{ x } \text{.}\) Since the restriction of \(g \) to either \(\opclint{ a }{ c } \) or \(\clopint{ c }{ b } \) is strictly monotone and therefore injective, \(g \of{ y } \neq g \of{ z } \text{.}\) Moreover, the restrictions of \(f \) and \(g \) to the closed interval between \(y \) and \(z \) satisfy the hypotheses of Theorem 5.3.5 Extended mean value theorem, and so
    \begin{equation*} \frac{ f \of{ z } - f \of{ y } }{ g \of{ z } - g \of{ y } } = \frac{ f' \of{ t } }{ g' \of{ t } } \end{equation*}
    for some point \(t \in I_{ x } \) lying strictly between \(y \) and \(z \text{.}\) In particular, we conclude that
    \begin{equation*} i \of{ x } \leq \frac{ f \of{ z } - f \of{ y } }{ g \of{ z } - g \of{ y } } \leq s \of{ x } \end{equation*}
    for all \(x \in \opint{ a }{ b } \setminus \set{ c } \) and distinct points \(y , z \in I_{ x } \text{.}\)
    🔗
    We first suppose that
    \begin{equation*} \lim_{ x \to c }{ f \of{ x } } = \lim_{ x \to c }{ g \of{ x } } = 0\text{.} \end{equation*}
    Then the above argument implies that
    \begin{equation*} i \of{ x } \leq \frac{ \frac{ f \of{ x } }{ g \of{ x } } - \frac{ f \of{ y } }{ g \of{ x } } }{ 1 - \frac{ g \of{ y } }{ g \of{ x } } } \leq s \of{ x } \end{equation*}
    for all \(x \in \opint{ a }{ b } \) and \(y \in I_{ x } \setminus \set{ x } \text{.}\) Taking a limit as \(y \to c \text{,}\) we obtain
    \begin{equation*} i \of{ x } \leq \frac{ f \of{ x } }{ g \of{ x } } \leq s \of{ x }\text{.} \end{equation*}
    The Squeeze theorem and Theorem 3.2.19 Sequential characterization of map convergence now implies that
    \begin{equation*} \lim_{ x \to c }{ \frac{ f \of{ x } }{ g \of{ x } } } = L\text{.} \end{equation*}
    🔗
    We now suppose that
    \begin{equation*} \lim_{ x \to c }{ \abs{ f \of{ x } } } = \lim_{ x \to c }{ \abs{ g \of{ x } } } = \infty\text{.} \end{equation*}
    Then the above argument implies that
    \begin{equation*} i \of{ x } \leq \frac{ \frac{ f \of{ y } }{ g \of{ y } } - \frac{ f \of{ x } }{ g \of{ y } } }{ 1 - \frac{ g \of{ x } }{ g \of{ y } } } \leq s \of{ x } \end{equation*}
    for all \(x \in \opint{ a }{ b } \) and \(y \in I_{ x } \setminus \set{ x } \text{.}\) Taking limits as \(y \to c \text{,}\) we observe that
    \begin{equation*} \lim_{ y \to c }{ \frac{ f \of{ x } }{ g \of{ y } } } = \lim_{ y \to c }{ \frac{ g \of{ x } }{ g \of{ y } } } = 0\text{.} \end{equation*}
    We conclude that
    \begin{equation*} i \of{ x } \leq \liminf_{ y \in I_{ x } }{ \frac{ f \of{ y } }{ g \of{ y } } } \leq \limsup_{ y \in I_{ x } }{ \frac{ f \of{ y } }{ g \of{ y } } } \leq s \of{ x } \end{equation*}
    for all \(x \in \opint{ a }{ b } \setminus \set{ c } \text{.}\) The Squeeze theorem and Theorem 3.2.19 Sequential characterization of map convergence now implies that
    \begin{equation*} \lim_{ x \to c }{ \frac{ f \of{ x } }{ g \of{ x } } } = L\text{.} \end{equation*}
    🔗
    🔗
    While different in formulation than the other Mean value theorem-like results covered in this section, L’Hôpital’s rule also relates the values of some differentiable functions with the values of their derivatives.
