    Section 4.4 Continuity

    In this section, we extend the notion of continuity from the specific setting of maps between metric spaces to the broader setting of maps between topological spaces. As in metric geometry, a map between topological spaces is continuous at a point if the images of nearby points are nearby to the image of that point. We will see several characterizations of topological continuity which are analogous to the metric characterizations.
    🔗

    Subsection 4.4.1 Map Convergence and Continuity at a Point

    Other than the \(\epsilon \)-\(\delta \) characterization, all other characterizations of continuity for maps between metric spaces provided in Proposition 3.5.1 Characterizations of metric continuity may be generalized to maps between topological spaces. While the neighborhood characterization is identical, we have already seen that the point-set topology of general topological spaces requires us to consider nets of points rather than sequences. So the sequential characterization of continuity will become the net characterization. We begin with the convergence of maps between topological spaces.
    🔗

    Definition 4.4.1. Topological map convergence.

    A map \(f \colon X \to Y \) from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \) converges at a point \(c \in X \) to a point \(l \in Y \) if for all neighborhoods \(N \in \Nbhd_{ Y } \of{ l } \) of \(l \) in \(Y \text{,}\) there is a neighborhood \(M \in \Nbhd_{ X } \of{ c } \) of \(c \) in \(X \) so that \(f \of{ x } \in N \) for all points \(x \in M \setminus \set{ c } \text{.}\)
    🔗
    Such a map \(f \colon X \to Y \) is called convergent at a point \(c \in X \) if it converges at \(c \) to some point in \(Y \) and divergent at \(c \) otherwise if it does not converge at \(c \) to any point in \(Y \text{.}\) If such a map \(f \colon X \to Y \) converges at a point \(c \in X \) to a unique point \(l \in Y \text{,}\) then this unique point is called a limit, and is denoted
    \begin{equation*} \lim_{ x \to c }{ f \of{ x } } = l\text{.} \end{equation*}
    🔗
    🔗
    As with previous generalizations of concepts introduced in Chapter 3 Metric Spaces, the convergence of a map between metric spaces is equivalent to its convergence as a map between the underlying metrizable topological spaces.
    🔗

    Lemma 4.4.2. Map convergence for metrizable spaces.

    Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) For any points \(c \in X \) and \(l \in Y \text{,}\) \(f \) converges at \(c \) to \(l \) as a map between metric spaces if and only if \(f \) converges at \(c \) to \(l \) as a map from the metrizable space \(\of{ X , \tau_{ \rho_{ X } } } \) to the metrizable space \(\of{ Y , \tau_{ \rho_{ Y } } } \text{.}\)
    🔗
    🔗

    Proof.
    First suppose that \(f \) converges at \(c \) to \(l \) as a map between metric spaces, and let \(N \in \Nbhd_{ Y } \of{ l } \) be a neighborhood of \(l \) in \(Y \text{.}\) Then \(\mB_{ \epsilon } \of{ l } \subseteq N \) for some positive real number \(\epsilon \gt 0 \text{.}\) Since \(f \) converges at \(c \) to \(l \text{,}\) there is some positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x } , l } \lt \epsilon \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{.}\) Let \(M = \mB_{ \delta } \of{ c } \text{,}\) and note that \(M \in \Nbhd_{ X } \of{ c } \) is a neighborhood of \(c \) in \(X \text{.}\) Moreover, for all points \(x \in X \text{,}\) if
    \begin{equation*} x \in M \setminus \set{ c } = \mB_{ \delta } \of{ c } \setminus \set{ c } = \setmid{ x \in X }{ 0 \lt \rho_{ X } \of{ x , c } \lt \delta }\text{,} \end{equation*}
    then \(\rho_{ Y } \of{ f \of{ x } , l } \lt \epsilon \text{,}\) so that \(x \in \mB_{ \epsilon } \of{ l } \subseteq N \text{.}\) We conclude that \(f \) converges at \(c \) to \(l \) as a map between metrizable spaces.
    🔗
    Conversely, now suppose that \(f \) converges at \(c \) to \(l \) as a map between metrizable spaces, and let \(\epsilon \gt 0 \) be a positive real number. Then \(N = \mB_{ \epsilon } \of{ l } \in \Nbhd_{ Y } \of{ l } \) is a neighborhood of \(l \) in \(Y \text{,}\) and so there is some neighborhood \(M \in \Nbhd_{ X } \of{ c } \) so that \(f \of{ x } \in N \) for all points \(x \in M \setminus \set{ c } \text{.}\)
    🔗
    Since \(M \) is a neighborhood of \(c \text{,}\) \(\mB_{ \delta } \of{ c } \) for some positive real number \(\delta \gt 0 \text{.}\) In particular, for all points \(x \in X \text{,}\) if \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{,}\) then
    \begin{equation*} x \in \setmid{ x \in X }{ 0 \lt \rho_{ X } \of{ x , c } \lt \delta } = \mB_{ \delta } \of{ c } \setminus \set{ c } = M \setminus \set{ c }\text{,} \end{equation*}
    and so \(f \of{ x } \in N = \mB_{ \epsilon } \of{ l } \text{;}\) that is, \(\rho_{ Y } \of{ f \of{ x } , l } \lt \epsilon \text{.}\) We conclude that \(f \) converges at \(c \) to \(l \) as a map between metric spaces.
    🔗
    🔗
    Since the convergence of maps between metrizable topological spaces is precisely the convergence of maps between metric spaces, we already have extensive experience working with the convergence of such maps. For example, the convergence of maps between metrizable spaces may be characterized in terms of sequential convergence. However, only one of the implications relevant for such a characterization holds for topological spaces in general.
    🔗

    Proposition 4.4.3. Sequential “characterization” of map convergence.

    Let \(f \colon X \to Y \) be a map from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \text{.}\) If \(f \) converges at a point \(c \in X \) to a point \(l \in Y \text{,}\) then for all sequences \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \setminus \set{ c } \) converging to \(c \text{,}\) the sequence \(\of{ f \of{ x_{ n } } }_{ n = 0 }^{ \infty } \) converges to \(l \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \setminus \set{ c } \) converging to \(c \text{,}\) and consider a neighborhood \(N \in \Nbhd_{ Y } \of{ l } \) of \(l \) in \(Y \text{.}\) Since \(f \) converges at \(c \) to \(l \text{,}\) \(f \of{ M \setminus \set{ c } } \subseteq N \) for some neighborhood \(M \in \Nbhd_{ X } \of{ c } \) of \(c \) in \(X \text{.}\) Moreover, since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(c \text{,}\) there is some natural number \(n_{ M } \in \N \) so that \(x_{ n } \in M \) for all indices \(n \geq n_{ M } \text{.}\)
    🔗
    We observe that \(x_{ n } \in M \setminus \set{ c } \) and so
    \begin{equation*} f \of{ x_{ n } } \in f \of{ M \setminus \set{ c } } \subseteq N \end{equation*}
    for all indices \(n \geq n_{ M } \text{.}\) Thus the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges to \(l \text{.}\)
    🔗
    🔗
    One might hope to find a converse to Proposition 4.4.3 Sequential “characterization” of map convergence as exists for metric spaces, but unfortunately no such result holds for topological spaces in general. However, we can obtain a full characterization of map convergence by considering the convergence of arbitrary nets instead of only sequences.
    🔗

    Theorem 4.4.4. Net characterization of map convergence.

    Let \(f \colon X \to Y \) be a map from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \text{,}\) and fix points \(c \in X \) and \(l \in Y \text{.}\) Then the following are equivalent:
    1. The map \(f \) converges to \(c \) at \(l \text{.}\)
      🔗
      🔗
    2. For every net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \setminus \set{ c } \) indexed by an upwards directed set \(\of{ A , \precsim } \text{,}\) if \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges upwards to \(c \text{,}\) then \(\of{ f \of{ x_{ \alpha } } }_{ \alpha \in A } \) converges upwards to \(l \text{.}\)
      🔗
      🔗
    3. For every net \(\of{ x_{ \beta } }_{ \beta \in B } \) of points \(x_{ \beta } \in X \setminus \set{ c } \) indexed by a downwards directed set \(\of{ B , \precsim } \text{,}\) if \(\of{ x_{ \beta } }_{ \beta \in B } \) converges downwards to \(c \text{,}\) then \(\of{ f \of{ x_{ \beta } } }_{ \beta \in B } \) converges downwards to \(l \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    First suppose that \(f \) converges at \(c \) to \(l \text{,}\) and let \(\of{ x_{ \alpha } }_{ \alpha \in A } \) be a net of points \(x_{ \alpha } \in X \setminus \set{ c } \) indexed by an upwards directed set \(\of{ A , \precsim } \) which converges upwards to \(c \text{.}\) Let \(N \in \Nbhd_{ Y } \of{ l } \) be a neighborhood of \(l \) in \(Y \text{.}\) Since \(f \) converges at \(c \) to \(l \text{,}\) \(f \of{ M \setminus \set{ c } } \subseteq N \) for some neighborhood \(M \in \Nbhd_{ X } \of{ c } \) of \(c \) in \(X \text{.}\)
    🔗
    Moreover, since \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges upwards to \(c \text{,}\) there is an index \(\alpha_{ N_{ l } } \in A \) so that \(x_{ \alpha } \in M \) for all indices \(\alpha \succeq \alpha_{ N_{ l } } \text{.}\) In particular, \(x_{ \alpha } \in M \setminus \set{ c } \text{,}\) so that \(f \of{ x_{ \alpha } } \in N \) for all indices \(\alpha \succeq \alpha_{ N_{ l } } \text{.}\) We conclude that \(\of{ f \of{ x_{ \alpha } } }_{ \alpha \in A } \) converges upwards to \(l \text{.}\)
    🔗
    Now suppose that for every net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \setminus \set{ c } \) indexed by an upwards directed set \(\of{ A , \precsim } \text{,}\) if \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges upwards to \(c \text{,}\) then \(\of{ f \of{ x_{ \alpha } } }_{ \alpha \in A } \) converges upwards to \(l \text{.}\) Let \(\of{ x_{ \beta } }_{ \beta \in B } \) be a net of points \(x_{ \beta } \in X \setminus \set{ c } \) indexed by a downwards directed set \(\of{ B , \precsim } \) which converges downwards to \(c \text{.}\)
    🔗
    Let \(A = B \) and \(\succsim = \op{ \precsim } \) be the opposite of \(\precsim \text{,}\) as described in Problem 1.5.5.3 Opposite of an order. Since \(\of{ B , \precsim } \) is downwards directed, \(\of{ A , \succsim } \) is upwards directed. Moreover, one can check that the downwards convergence of \(\of{ x_{ \beta } }_{ \beta \in B } \) as a net indexed by \(\of{ B , \precsim } \) implies the upwards convergence of \(\of{ x_{ \alpha } }_{ \alpha \in A } \) as a net indexed by \(\of{ A , \succsim } \text{.}\) In particular, \(\of{ f \of{ x_{ \alpha } } }_{ \alpha \in A } \) converges upwards to \(l \) as a net indexed by \(\of{ A , \succsim } \text{,}\) which again implies that \(\of{ f \of{ x_{ \beta } } }_{ \beta \in B } \) converges downwards to \(l \) as a net indexed by \(\of{ B , \precsim } \text{.}\)
    🔗
    Finally, we wish to prove that if for every net \(\of{ x_{ \beta } }_{ \beta \in B } \) of points \(x_{ \beta } \in X \setminus \set{ c } \) indexed by a downwards directed set \(\of{ B , \precsim } \text{,}\) if \(\of{ x_{ \beta } }_{ \beta \in B } \) converges downwards to \(c \text{,}\) then \(\of{ f \of{ x_{ \beta } } }_{ \beta \in B } \) converges downwards to \(l \text{,}\) then \(f \) converges to \(c \) at \(l \text{.}\) We will prove the contrapositive implication.
    🔗
    To that end, suppose that \(f \) does not converge at \(c \) to \(l \text{.}\) Then there is a neighborhood \(N \in \Nbhd_{ Y } \of{ l } \) of \(l \) in \(Y \) so that for every neighborhood \(M \in \Nbhd_{ X } \of{ c } \) of \(c \) in \(X \text{,}\) there is some point \(x \in M \setminus \set{ c } \) so that \(f \of{ x } \notin N \text{.}\) Recall that the set \(\Nbhd_{ X } \of{ c } \) of neighborhoods of \(c \) in \(X \) is partially ordered and directed downwards by containment \(\subseteq \text{.}\) The Axiom of choice allows us to find an indexed family \(\of{ x_{ M } }_{ M \in \Nbhd_{ X } \of{ c } } \) of points \(x_{ N } \in X \) so that for each index \(M \in \Nbhd_{ X } \of{ c } \text{,}\) \(x_{ M } \in M \setminus \set{ c } \) but \(f \of{ x_{ M } } \notin N \text{.}\)
    🔗
    Since \(x_{ M } \notin N \) for all indices \(M \in \Nbhd_{ X } \of{ c } \text{,}\) the net \(\of{ f \of{ x_{ M } } }_{ M \in \Nbhd_{ X } \of{ c } } \) cannot converge downwards to \(l \text{.}\) It therefore suffices to show that the net \(\of{ x_{ M } }_{ M \in \Nbhd_{ X } \of{ c } } \) converges downwards to \(c \text{.}\) To that end, let \(M \in \Nbhd_{ X } \of{ c } \) be a neighborhood of \(c \) in \(X \text{.}\) Then
    \begin{equation*} x_{ P } \in P \subseteq M \end{equation*}
    for all indices \(P \subseteq M \text{;}\) that is, the net \(\of{ x_{ M } }_{ M \in \Nbhd_{ X } \of{ c } } \) converges downwards to \(c \text{.}\)
    🔗
    🔗
    We will use Theorem 4.4.4 Net characterization of map convergence to construct an analogue for the sequential characterization of continuity at a point.
    🔗

    Theorem 4.4.5. Characterizations of topological continuity.

    Let \(f \colon X \to Y \) be a map from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \text{.}\) For a point \(c \in X \text{,}\) the following are equivalent:
    1. Convergence characterization of continuity.
      The map \(f \) converges at \(c \) to \(f \of{ c } \text{.}\)
      🔗
      🔗
    2. Neighborhood characterization of continuity.
      The pre-image \(f^{ -1 } \of{ N } \) of any neighborhood \(N \in \Nbhd_{ Y } \of{ f \of{ c } } \) of \(f \of{ c } \) in \(Y \) is a neighborhood of \(c \) in \(X \text{.}\)
      🔗
      🔗
    3. Net characterization of continuity.
      For every net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \) indexed by an upwards directed set \(\of{ A , \precsim } \text{,}\) if \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges upwards to \(c \text{,}\) then \(\of{ f \of{ x_{ \alpha } } }_{ \alpha \in A } \) converges upwards to \(f \of{ c } \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    First suppose that \(f \) converges at \(c \) to \(f \of{ c } \text{,}\) and let \(N \in \Nbhd_{ Y } \of{ f \of{ c } } \) be a neighborhood of \(f \of{ c } \) in \(Y \text{.}\) Then \(f \of{ M \setminus \set{ c } } \subseteq N \) for some neighborhood \(M \in \Nbhd_{ X } \of{ c } \) of \(c \) in \(X \text{.}\) We observe that \(f \of{ c } \in N \) as well, so that \(f \of{ M } \subseteq N \text{.}\) Since \(M \) is a neighborhood of \(c \) in \(X \text{,}\) \(c \in U \subseteq M \) for some open set \(U \in \tau_{ X } \) in \(X \text{.}\) Therefore,
    \begin{equation*} x \in U \subseteq M \subseteq \setmid{ x \in X }{ f \of{ x } \in N } = f^{ -1 } \of{ N }\text{,} \end{equation*}
    and so the pre-image \(f^{ -1 } \of{ N } \in \Nbhd_{ X } \of{ c } \) is a neighborhood of \(c \) in \(X \text{.}\)
    🔗
    Now suppose that the pre-image \(f^{ -1 } \of{ N } \) of every neighborhood \(M \in \Nbhd_{ Y } \of{ f \of{ c } } \) of \(f \of{ c } \) in \(Y \) is a neighborhood of \(c \) in \(X \text{,}\) and let \(\of{ x_{ \alpha } }_{ \alpha \in A } \) be a net of points \(x_{ \alpha } \in X \) indexed by an upwards directed set \(\of{ A , \precsim } \) which converges upwards to \(c \text{.}\) Let \(N \in \Nbhd_{ Y } \of{ f \of{ c } } \) be a neighborhood of \(f \of{ c } \) in \(Y \text{.}\)
    🔗
    Since \(f^{ -1 } \of{ N } \) is a neighborhood of \(f \of{ c } \) in \(X \text{,}\) there is an index \(\alpha_{ N } \in A \) so that \(x_{ \alpha } \in f^{ -1 } \of{ N } \) for all indices \(\alpha \succeq \alpha_{ N } \text{.}\) In particular, \(f \of{ x_{ \alpha } } \in N \) for all indices \(\alpha \succeq \alpha_{ N } \text{,}\) and so the net \(\of{ f \of{ x_{ \alpha } } }_{ \alpha \in A } \) converges upwards to \(f \of{ c } \text{.}\)
    🔗
    Finally, now suppose that for every net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \) indexed by an upwards directed set \(\of{ A , \precsim } \text{,}\) if \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges upwards to \(c \text{,}\) then \(\of{ f \of{ x_{ \alpha } } }_{ \alpha \in A } \) converges upwards to \(f \of{ c } \text{.}\) Then Theorem 4.4.4 Net characterization of map convergence implies that \(f \) converges at \(c \) to \(f \of{ c } \text{.}\)
    🔗
    🔗

    Definition 4.4.6. Continuity.

    Let \(f \colon X \to Y \) be a map from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \text{.}\)
    • Continuity.
      \(f \) is continuous at a point \(c \in X \) if it satisfies any (and therefore all) of the conditions in Theorem 4.4.5 Characterizations of topological continuity. \(f \) is continuous if it is continuous at every point \(c \in X \text{.}\)
      🔗
      🔗
    • Discontinuity.
      \(f \) is discontinuous at a point \(c \in X \) if it does not satisfies any of the conditions in Theorem 4.4.5 Characterizations of topological continuity. \(f \) is discontinuous if it is discontinuous at some point \(c \in X \text{.}\)
      🔗
      🔗
    The set of continuous maps from \(X \) to \(Y \) is denoted \(\CDiff \of{ X , Y } \text{.}\) In the special case \(\of{ Y , \tau_{ Y } } = \of{ \R , \tau_{ d } } \text{,}\) the set of continuous, real-valued functions on a topological space \(\of{ X , \tau_{ X } } \) is denoted \(\CDiff \of{ X } = \CDiff \of{ X , \R } \text{.}\)
    🔗
    🔗

    Example 4.4.7. Continuity at a point.

    Let \(f \colon \R \to \R \) be the real-valued function defined piecewise by the formula
    \begin{equation*} f \of{ x } = \begin{cases} 0 \amp x = 0 \\ 1 \amp x \neq 0 \text{.}\end{cases} \end{equation*}
    While \(f \) is not continuous at \(0 \) when the domain and codomain are equipped with the Euclidean topology \(\tau_{ d } \text{,}\) we can construct a topology \(\tau \) on \(\R \) so that \(f \) is a continuous map from \(\of{ \R , \tau } \) to \(\of{ \R , \tau_{ d } } \text{.}\)
    🔗
    Specifically, let
    \begin{equation*} \tau = \setmid{ U \in \ps{ \R } }{ 0 \in U \textrm{ or } U = \emptyset }\text{.} \end{equation*}
    One can check that \(\tau \) is a topology on \(\R \) called the particular point topology. We see that if \(N \in \Nbhd_{ \of{ \R , \tau_{ d } } } \of{ 0 } \) is a neighborhood of \(0 \) in \(\of{ \R , \tau_{ d } } \text{,}\) then
    \begin{equation*} f^{ -1 } \of{ N } = \begin{cases} \R \amp 1 \in N \\ \set{ 0 } \amp 1 \notin N \text{.}\end{cases} \end{equation*}
    In either case, \(f^{ -1 } \of{ N } \) is an open neighborhood of \(0 \) in the particular point topology, and so \(f \) is continuous at \(0 \) as a map from \(\of{ \R , \tau } \) to \(\of{ \R , \tau_{ d } } \text{.}\)
    🔗
    🔗
    Many of the standard properties of continuous maps between metric spaces also apply to continuous maps between topological spaces. For example, continuity is preserved by composition.
    🔗

    Proposition 4.4.8. Composition of continuous maps.

    Let \(f \colon X \to Y \) and \(g \colon Y \to Z \) be maps between topological spaces \(\of{ X , \tau_{ X } } \text{,}\) \(\of{ Y , \tau_{ Y } } \text{,}\) and \(\of{ Z , \tau_{ Z } } \text{.}\) If for some point \(x \in X \text{,}\) \(f \) is continuous at \(x \) and \(g \) is continuous at \(f \of{ x } \text{,}\) then the composition \(g \circ f \) is continuous at \(x \text{.}\)
    🔗
    🔗

    Proof.
    Let \(W \in \Nbhd_{ Z } \of{ \of{ g \circ f } \of{ x } } \) be a neighborhood of \(\of{ g \circ f } \of{ x } = g \of{ f \of{ x } } \) in \(Z \text{.}\) Since \(g \) is continuous at \(f \of{ x } \text{,}\) the pre-image \(g^{ -1 } \of{ W } \in \Nbhd_{ Y } \of{ f \of{ x } } \) is a neighborhood of \(f \of{ x } \) in \(Y \text{.}\) Moreover, since \(f \) is continuous at \(x \text{,}\) the pre-image
    \begin{align*} f^{ -1 } \of{ g^{ -1 } \of{ W } } \amp = \setmid{ x \in X }{ f \of{ x } \in g^{ -1 } \of{ W } } = \setmid{ x \in X }{ g \of{ f \of{ x } } \in W }\\ \amp = \setmid{ x \in X }{ \of{ g \circ f } \of{ x } \in W } = \of{ g \circ f }^{ -1 } \of{ W }\text{.} \end{align*}
    Thus the neighborhood characterization of continuity in Theorem 4.4.5 Characterizations of topological continuity implies that \(g \circ f \) is continuous at \(x \text{.}\)

    🔗

    Corollary 4.4.9. Composition of continuous maps.

    The composition of continuous maps between topological spaces is continuous.

    Subsection 4.4.2 Continuous Maps between Topological Spaces

    While we have seen characterizations of continuity at a point, we will be more interested in maps which are continuous everywhere. For the remainder of this section, we will explore the properties of such maps, and define maximal and minimal topologies with respect to continuity. To begin, we observe that Corollary 3.5.4 Open set characterization of metric continuity holds for maps between topological spaces.
    🔗

    Proposition 4.4.10. Open set characterization of continuity.

    A map \(f \colon X \to Y \) from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \) is continuous if and only if the pre-image \(f^{ -1 } \of{ V } \) of every open set \(V \in \tau_{ Y } \) in \(Y \) is open in \(X \text{.}\)
    🔗
    🔗

    Proof.
    Suppose first that \(f \) is continuous, and let \(V \subseteq Y \) be an open subset of \(Y \text{.}\) Let \(c \in f^{ -1 } \of{ V } \text{.}\) Since \(V \) is open, it is a neighborhood of \(f \of{ c } \text{,}\) and so the neighborhood characterization of continuity in Theorem 4.4.5 Characterizations of topological continuity implies that \(f^{ -1 } \of{ V } \) is a neighborhood of \(c \text{.}\) Since this is true of every point \(c \in f^{ -1 } \of{ V } \text{,}\) \(f^{ -1 } \of{ V } \in \tau_{ X } \) is open in \(X \text{.}\)
    🔗
    Conversely, now suppose that the pre-image of every open set in \(Y \) is an open set in \(X \text{,}\) and consider a point \(c \in X \) and a neighborhood \(N \subseteq Y \) of \(f \of{ c } \) in \(Y \text{.}\) Then \(f \of{ c } \in V \subseteq N \) for some open set \(V \in \tau_{ Y } \text{,}\) and so \(f^{ -1 } \of{ V } \in \tau_{ X } \) is open in \(X \text{.}\) We observe that
    \begin{equation*} c \in f^{ -1 } \of{ V } = \setmid{ x \in X }{ f \of{ x } \in V } \subseteq \setmid{ x \in X }{ f \of{ x } \in N } = f^{ -1 } \of{ N }\text{,} \end{equation*}
    and so \(f^{ -1 } \of{ N } \) is a neighborhood of \(c \text{.}\) The neighborhood characterization of continuity in Theorem 4.4.5 Characterizations of topological continuity now implies that \(f \) is continuous at \(c \text{.}\) Since this holds for all points \(c \in X \text{,}\) \(f \) is continuous.
    🔗
    🔗

    Example 4.4.11. Continuity.

    The following are examples of continuous and discontinuous maps between topological spaces:
    • Any map \(f \colon X \to Y \) from a discrete topological space \(\of{ X , \top_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \) is continuous.
      🔗
      🔗
    • Any map \(f \colon X \to Y \) from a topological space \(\of{ X , \tau_{ X } } \) to an indiscrete topological space \(\of{ Y , \bot_{ Y } } \) is continuous.
      🔗
      🔗
    • Any constant map \(f \colon X \to Y \) from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \) is continuous.
      🔗
      🔗
    • Any non-constant map \(f \colon X \to Y \) from an indiscrete topological space \(\of{ X , \bot_{ X } } \) to a \(T_{ 0 } \) topological space \(\of{ Y , \tau_{ Y } } \) with at least two points is discontinuous.
      🔗
      🔗
    🔗
    🔗
    We will use the observations of Example 4.4.11 Continuity together with Theorem 4.2.6 Complete lattice of topologies as a platform for building topologies in such a way to guarantee the continuity of certain maps. First, however, we will require the following corollary:
    🔗

    Corollary 4.4.12. Continuity, coarsening, and refinement.

    Let \(f \colon X \to Y \) be a continuous map from a topological space \(\of{ X , \tau_{ X } } \) to a topological space \(\of{ Y , \tau_{ Y } } \text{.}\) Then for any refinement \(\tau_{ X }' \supseteq \tau_{ X } \) of \(\tau_{ X } \) and any coarsening \(\tau_{ Y }' \subseteq \tau_{ Y } \) of \(\tau_{ Y } \text{,}\) \(f \) is continuous as a map from \(\of{ X , \tau_{ X }' } \) to \(\of{ Y , \tau_{ Y }' } \text{.}\)
    🔗
    🔗

    Proof.
    Let \(V \in \tau_{ Y }' \) be an open set in \(\of{ Y , \tau_{ Y }' } \text{.}\) Since \(\tau_{ Y }' \subseteq \tau_{ Y } \text{,}\) \(V \in \tau_{ Y } \text{,}\) and so the continuity of \(f \) as a map from \(\of{ X , \tau_{ X } } \) to \(\of{ Y , \tau_{ Y } } \) implies that \(f^{ -1 } \of{ V } \in \tau_{ X } \) is an open set in \(\of{ X , \tau_{ X } } \text{.}\) Since \(\tau_{ X } \subseteq \tau_{ X }' \text{,}\) \(V \in \tau_{ X }' \text{.}\)
    🔗
    In summary, we have shown that for any open set \(V \in \tau_{ Y }' \text{,}\) the pre-image \(f^{ -1 } \of{ V } \in \tau_{ X }' \) is open. Thus \(f \) is a continuous map from \(\of{ X , \tau_{ X }' } \) to \(\of{ Y , \tau_{ Y }' } \text{.}\)
    🔗
    🔗
    To summarize Corollary 4.4.12 Continuity, coarsening, and refinement, we note that it is easy for a map to be continuous if the topology on its domain is very fine and the topology on its codomain is very coarse. For the same reason, it is very hard for a map to be continuous if the topology on its domain is very coarse and the topology on its codomain is very fine. We exploit this tension to define topologies which are just coarse enough or just fine enough to make certain maps continuous.
    🔗

    Definition 4.4.13. Final topology.

    The final topology on a set \(Y \) induced by an indexed family \(\of{ f_{ j } }_{ j \in \mathcal{ J } } \) of maps \(f_{ j } \colon X_{ j } \to Y \) from topological spaces \(\of{ X_{ j } , \tau_{ X_{ j } } } \) to a set \(Y \) is the finest topology on \(Y \) so that each map \(f_{ j } \colon X_{ j } \to Y \) is continuous. Concretely, the final topology \(\tau \) induced on \(Y \) by \(\of{ f_{ j } }_{ j \in \mathcal{ J } } \) is defined by
    \begin{equation*} \tau = \bigcap_{ j \in \mathcal{ J } }{ \setmid{ V \in \ps \of{ Y } }{ f_{ j }^{ -1 } \of{ V } \in \tau_{ X_{ j } } } }\text{.} \end{equation*}
    🔗
    🔗

    Example 4.4.14. Quotient topology.

    Let \(q \colon X \to X / { \equiv } \) be the quotient map associated to an equivalence relation \(\equiv \) on a topological space \(\of{ X , \tau } \text{.}\) Concretely, \(q \) sends a point \(x \in X \) to its equivalence class \(\class{ x }_{ \equiv } \text{.}\) The quotient topology on \(X / { \equiv } \) is the final topology induced by \(q \text{;}\) that is, the quotient topology is the finest topology on \(X / { \equiv } \) so that \(q \) is continuous. When \(X / { \equiv } \) is equipped with the quotient topology, the resulting topological space is called a quotient space.
    🔗
    🔗
    The final topology on a set can also be characterized in terms of the continuity of outgoing maps.
    🔗

    Lemma 4.4.15. Continuous maps from final spaces.

    Let \(\tau_{ Y } \) be the final topology on a set \(Y \) induced by an indexed family \(\of{ f_{ j } }_{ j \in \mathcal{ J } } \) of maps \(f_{ j } \colon X_{ j } \to Y \) from topological spaces \(\of{ X_{ j } , \tau_{ X_{ j } } } \) to \(Y \text{.}\) Then a map \(g \colon Y \to Z \) from \(\of{ Y , \tau_{ Y } } \) to a topological space \(\of{ X , \tau_{ X } } \) is continuous if and only if the composition \(g \circ f_{ j } \colon X_{ j } \to Z \) is continuous for all indices \(j \in \mathcal{ J } \text{.}\)
    🔗
    🔗

    Proof.
    If \(g \) is continuous, then \(g \circ f_{ j } \) is continuous for each index \(j \in \mathcal{ J } \) by Corollary 4.4.9 Composition of continuous maps. Thus it suffices to prove the converse implication. To that end, suppose that \(g \circ f_{ j } \) is continuous for each index \(j \in \mathcal{ J } \text{,}\) and let \(W \in \tau_{ Z } \) be an open set in \(Z \text{.}\) We wish to show that \(g^{ -1 } \of{ W } \in \tau_{ Y } \) is open in \(Y \text{.}\)
    🔗
    To that end, we note that
    \begin{equation*} f_{ j }^{ -1 } \of{ g^{ -1 } \of{ W } } = \of{ g \circ f_{ j } }^{ -1 } \of{ W } \in \tau_{ X } \end{equation*}
    is open in \(X \) for each index \(j \in \mathcal{ J } \text{,}\) and so
    \begin{equation*} g^{ -1 } \of{ W } \in \bigcap_{ j \in \mathcal{ J } }{ \setmid{ V \in \ps \of{ Y } }{ f_{ j }^{ -1 } \of{ V } \in \tau_{ X } } } = \tau_{ Y } \end{equation*}
    is open in \(Y \text{.}\) We conclude by the Proposition 4.4.10 Open set characterization of continuity that \(g \) is continuous.
    🔗
    🔗
    Dual to the notion of a final topology is that of an initial topology. While final topologies are as fine as possible while requiring the continuity of some incoming maps, initial topologies are as coarse as possible while requiring the continuity of some outgoing maps.
    🔗

    Definition 4.4.16. Initial topology.

    The initial topology on a set \(X \) induced by an indexed family \(\of{ f_{ j } }_{ j \in \mathcal{ J } } \) of maps \(f_{ j } \colon X \to Y_{ j } \) from a set \(X \) to topological spaces \(\of{ Y_{ j } , \tau_{ Y_{ j } } } \) is the coarsest topology on \(X \) so that each map \(f_{ j } \colon X \to Y_{ j } \) is continuous. Concretely, the initial topology \(\tau \) induced on \(X \) by \(\of{ f_{ j } }_{ j \in \mathcal{ J } } \) is
    \begin{equation*} \tau = \gen{ \bigcup_{ j \in \mathcal{ J } }{ \setmid{ f_{ j }^{ -1 } \of{ V } \in \ps \of{ X } }{ V \in \tau_{ Y_{ j } } } } }\text{.} \end{equation*}
    🔗
    🔗

    Example 4.4.17. Initial topologies.

    The following are examples of initial topologies:
    • The subspace topology \(\rest{ \tau }_{ U } \) on a subset \(U \subseteq X \) of a topological space \(\of{ X , \tau } \) is the initial topology induced by the inclusion map \(\iota \colon U \to X \text{.}\)
      🔗
      🔗
    • The product topology on a Cartesian product \(X = \prod_{ j \in \mathcal{ J } }{ Y_{ j } } \) of topological spaces \(\of{ Y_{ j } , \tau_{ X_{ j } } } \) is the initial topology induced by the indexed family \(\of{ \pi_{ j } }_{ j \in \mathcal{ J } } \) of projection maps \(\pi_{ j } \colon X \to Y_{ j } \text{.}\)
      🔗
      🔗
    🔗
    🔗
    The initial topology on a set can also be characterized in terms of the continuity of incoming maps. The proof of this characterization is slightly harder than the analogous result for final topologies, since in this case we have a subbase for the initial topology rather than an explicit description.
    🔗

    Lemma 4.4.18. Continuous maps to initial spaces.

    Let \(\tau_{ Y } \) be the initial topology on a set \(Y \) induced by an indexed family \(\of{ g_{ j } }_{ j \in \mathcal{ J } } \) of maps \(g_{ j } \colon Y \to Z_{ j } \) from \(Y \) to topological spaces \(\of{ Z_{ j } , \tau_{ Z_{ j } } } \text{.}\) Then a map \(f \colon X \to Y \) from a topological space \(\of{ X , \tau_{ X } } \) to \(\of{ Y , \tau_{ Y } } \) is continuous if and only if the composition \(g_{ j } \circ f \colon X \to Z_{ j } \) is continuous for all indices \(j \in \mathcal{ J } \text{.}\)
    🔗
    🔗

    Proof.
    If \(f \) is continuous, then \(g_{ j } \circ f \) is continuous for each index \(j \in \mathcal{ J } \) by Corollary 4.4.9 Composition of continuous maps. Thus it suffices to prove the converse implication. To that end, suppose that \(g_{ j } \circ f \) is continuous for each index \(j \in \mathcal{ J } \text{,}\) and let \(V \in \tau_{ Y } \) be an open set in \(Y \text{.}\) Then [provisional cross-reference: problem-explicit-descriptions-of-the-generated-topology] implies that
    \begin{equation*} V = \bigcup_{ k \in \mathcal{ K } }{ \bigcap_{ l = 1 }^{ p_{ k } }{ g_{ j_{ k , l } }^{ -1 } \of{ W_{ k , l } } } } \end{equation*}
    for some indices \(j_{ k , l } \in \mathcal{ J } \) and open sets \(W_{ k , l } \in \tau_{ Z_{ j_{ k , l } } } \text{.}\) Since topologies are stable under finite intersections and arbitrary unions,
    \begin{align*} f^{ -1 } \of{ V } \amp = f^{ -1 } \of{ \bigcup_{ k \in \mathcal{ K } }{ \bigcap_{ l = 1 }^{ p_{ k } }{ g_{ j_{ k , l } }^{ -1 } \of{ W_{ k , l } } } } } = \bigcup_{ k \in \mathcal{ K } }{ \bigcap_{ l = 1 }^{ p_{ k } }{ f^{ -1 } \of{ g_{ j_{ k , l } }^{ -1 } \of{ W_{ k , l } } } } }\\ \amp = \bigcup_{ k \in \mathcal{ K } }{ \bigcap_{ l = 1 }^{ p_{ k } }{ \of{ g_{ j_{ k , l } } \circ f }^{ -1 } \of{ W_{ k , l } } } } \in \tau_{ X } \end{align*}
    is open in \(X \text{,}\) and so \(f \) is continuous.
    🔗
    🔗
    Typically, the above examples of final and initial topologies are implicitly assumed, so that unless otherwise specified, quotient maps, subset inclusions, and projection maps of Cartesian products are continuous.
