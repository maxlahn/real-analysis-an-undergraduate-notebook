    Section 5.2 Analysis of Critical Points

    In this section, we analyze the local behavior of a real-valued function based on differentiability criteria and/or the value of the derivative. We will make a distinction between critical points and regular points and begin to develop tools to analyze the local behavior near each. Finally, we will also classify certain kinds of critical points based on several derivative tests.
    🔗

    Subsection 5.2.1 Local Behavior Near Critical Points

    The local behavior of a differentiable real-valued function near a point can be very different depending on the sign of the derivative at that point. We will make the distinction between critical points, where the derivative vanishes (or does not exist), and regular points, where the derivative is non-zero.
    🔗

    Definition 5.2.1. Critical/regular point/value.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{.}\)
    • Critical point/value.
      A point \(x \in X \) is called a critical point of \(f \) if either \(f' \of{ x } = 0 \text{,}\) in which case \(x \) is called a stationary (critical) point of \(f \text{,}\) or \(f \) is not differentiable at \(x \text{.}\)
      🔗
      A real number \(y \in \R \) is called a critical value of \(f \) if \(f \of{ x } = y \) for some critical point \(x \in X \text{.}\)
      🔗
      🔗
    • Regular point/value.
      A point \(x \in X \) is called a regular point of \(f \) if it is not a critical point of \(f \text{;}\) that is, \(x \) is a regular point of \(f \) if \(f \) is differentiable at \(x \) and \(f' \of{ x } \neq 0 \text{.}\)
      🔗
      A real number \(y \in \R \) is called a regular value of \(f \) if it is not a critical value of \(f \text{;}\) that is, \(y \) is a regular value of \(f \) if the pre-image
      \begin{equation*} f^{ -1 } \of{ y } = \setmid{ x \in X }{ f \of{ x } = y } \end{equation*}
      consists only of regular points of \(f \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 5.2.2. Critical/regular points/values.

    The following are examples of critical points, regular points, critical values, and regular values of functions:
    • Let \(f \colon \R \to \R \) be the function defined piecewise by the formula
      \begin{equation*} f \of{ x } = \sgn \of{ x } = \begin{cases} 1 \amp x \gt 0 \\ 0 \amp x = 0 \\ -1 \amp x \lt 0 \text{.}\end{cases} \end{equation*}
      Then every point \(x \in \R \) is a critical point of \(f \text{.}\) If \(x \neq 0 \text{,}\) then \(x \) is a stationary critical point of \(f \text{,}\) and if \(x = 0 \text{,}\) then \(x \) is a point of non-differentiability. Thus \(1 \text{,}\) \(0 \text{,}\) and \(-1 \) are critical values of \(f \text{,}\) and all other real numbers are regular values.
      🔗
      🔗
    • Let \(g \colon \R \to \R \) be the function defined piecewise by the formula
      \begin{equation*} g \of{ y } = \abs{ y } = \begin{cases} y \amp y \geq 0 \\ -y \amp y \lt 0 \text{.}\end{cases} \end{equation*}
      Then \(0 \) is the only critical point of \(g \text{,}\) and it is a point of non-differentiability. Thus \(0 \) is a critical value of \(g \text{,}\) and all other real numbers are regular values.
      🔗
      🔗
    • Let \(h \colon \R \to \R \) be the function defined by the formula \(h \of{ z } = z^{ 2 } \text{.}\) Then \(0 \) is the only critical point of \(h \text{,}\) and it is a stationary critical point. Thus \(0 \) is a critical value of \(g \text{,}\) and all other real numbers are regular values.
      🔗
      🔗
    🔗
    🔗
    One use of the critical points of a real-valued function is in finding local extrema, which occur when the restriction of a function to a neighborhood attains an extreme value on that neighborhood.
    🔗

    Definition 5.2.3. Local extrema.

    Let \(f \colon X \to \R \) be a real-valued function defined on a subset \(X \subseteq \R \text{.}\)
    • Local maximum.
      \(f \) attains a local maximum at a point \(x \in X \) if there is a neighborhood \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \) so that
      \begin{equation*} f \of{ y } \leq f \of{ x } \end{equation*}
      for all points \(y \in N \text{.}\)
      🔗
      🔗
    • Local minimum.
      \(f \) attains a local minimum at a point \(x \in X \) if there is a neighborhood \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \) so that
      \begin{equation*} f \of{ x } \leq f \of{ y } \end{equation*}
      for all points \(y \in N \text{.}\)
      🔗
      🔗
    Local extremum is a generic term which encompasses both local maxima and local minima.
    🔗
    🔗
    In fact, local extrema may only be attained at critical points. If a local extremum is attained at a point of non-differentiability, then this is clear. However, if the local extremum is attained at a point at which the function is differentiable, then this point is a stationary critical point. This is the content of the following lemma:
    🔗

    Lemma 5.2.4. Local extrema are stationary points.

    Let \(f \colon X \to \R \) be a real-valued function defined on a subset \(X \subseteq \R \) which attains a local extremum at a point \(c \in X \) so that every neighborhood of \(c \) contains points strictly greater than \(c \) and points strictly less than \(c \text{.}\) If \(f \) is differentiable at \(c \text{,}\) then \(f' \of{ c } = 0 \text{;}\) that is, \(c \) is a stationary point of \(f \text{.}\)
    🔗
    🔗

    Proof.
    By contraposition. Suppose first that \(f' \of{ c } \gt 0 \) is positive. Then since \(\frac{ f' \of{ c } }{ 2 } \gt 0 \) is positive, there is some positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt \frac{ f' \of{ c } }{ 2 } \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) In particular,
    \begin{equation*} \frac{ f \of{ x } - f \of{ c } }{ x - c } \gt f' \of{ c } - \frac{ f' \of{ c } }{ 2 } = \frac{ f' \of{ c } }{ 2 } \gt 0 \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) so that \(f \of{ x } - f \of{ c } \) and \(x - c \) have the same sign; that is, so long as \(x \in \clint{ a }{ b } \) and \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then \(f \of{ x } \lt f \of{ c } \) if \(x \lt c \) and \(f \of{ x } \gt f \of{ c } \) if \(x \gt c \text{.}\) In particular, since the neighborhood \(\mB_{ \delta } \of{ c } = \opint{ c - \delta }{ c + \delta } \cap X \) contains points strictly less than \(c \) and contains points strictly larger than \(c \text{,}\) we conclude that \(f \) does not achieve a maximum or minimum at \(c \text{.}\)
    🔗
    Similarly, now suppose that \(f' \of{ c } \lt 0 \) is negative. Then since \(-\frac{ f' \of{ c } }{ 2 } \gt 0 \) is positive, there is some positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt -\frac{ f' \of{ c } }{ 2 } \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) In particular,
    \begin{equation*} \frac{ f \of{ x } - f \of{ c } }{ x - c } \lt -f' \of{ c } + \frac{ f' \of{ c } }{ 2 } = -\frac{ f' \of{ c } }{ 2 } \lt 0 \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) so that \(f \of{ x } - f \of{ c } \) and \(x - c \) have opposite sign; that is, so long as \(x \in \clint{ a }{ b } \) and \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then \(f \of{ x } \gt f \of{ c } \) if \(x \lt c \) and \(f \of{ x } \lt f \of{ c } \) if \(x \gt c \text{.}\) In particular, since the neighborhood \(\mB_{ \delta } \of{ c } = \opint{ c - \delta }{ c + \delta } \cap X \) contains points strictly less than \(c \) and contains points strictly larger than \(c \text{,}\) we conclude that \(f \) does not achieve a maximum or minimum at \(c \text{.}\)
    🔗
    🔗
    A famous consequence of Lemma 5.2.4 Local extrema are stationary points due to Fermat occurs when we suppose the domain of the function in question is an interval. In this case, interior points automatically satisfy the hypothesis of Lemma 5.2.4 Local extrema are stationary points.
    🔗

    Theorem 5.2.5 (Pierre de Fermat). Interior extremum theorem.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \) which attains a local extremum at an interior point \(c \in \Int \of{ X } \text{.}\) If \(f \) is differentiable at \(c \text{,}\) then \(f' \of{ c } = 0 \text{;}\) that is, \(c \) is a stationary point of \(f \text{.}\)
    🔗
    🔗

    Proof.
    Any neighborhood \(N \in \Nbhd_{ X } \of{ c } \) of an interior point \(c \in \Int \of{ X } \) contains an open interval containing \(c \text{,}\) and therefore contains points strictly greater than \(c \) and points strictly less than \(c \text{.}\) The desired conclusion now follows immediately from Lemma 5.2.4 Local extrema are stationary points.
    🔗
    🔗
    One use of the Interior extremum theorem is to prove the following theorem of Darboux, which establishes an intermediate value property for the derivative of a differentiable function even if said function is not continuously differentiable.
    🔗

    Theorem 5.2.6 (Jean-Gaston Darboux). Darboux’s theorem.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{.}\) If \(f \) is differentiable, then \(\im \of{ f' } = f' \of{ X } \) is an interval.
    🔗
    🔗

    Proof.
    Let \(a , b \in X \text{,}\) and suppose that \(a \lt b \text{.}\) There are three cases; either \(f' \of{ a } = f' \of{ b } \text{,}\) \(f' \of{ a } \lt f' \of{ b } \text{,}\) or \(f' \of{ a } \gt f' \of{ b } \text{.}\) If \(f \of{ a } = f \of{ b } \text{,}\) then \(\im \of{ f' } \) vacuously contains all points between \(f' \of{ a } \) and \(f' \of{ b } \text{.}\)
    🔗
    Suppose that \(f' \of{ a } \lt f' \of{ b } \text{,}\) let \(f' \of{ a } \lt r \lt f' \of{ b } \text{,}\) and consider the function \(g \colon X \to \R \) defined by the formula
    \begin{equation*} g \of{ x } = f \of{ x } - r x\text{.} \end{equation*}
    We observe that \(g' \of{ a } = f' \of{ a } - r \lt 0 \) and \(g' \of{ b } = f' \of{ b } - r \gt 0 \text{.}\) In particular, the argument in the proof of Lemma 5.2.4 Local extrema are stationary points implies that \(g \) does not attain a minimum value at \(a \) or \(b \text{.}\)
    🔗
    However, since \(g \) is continuous on the compact interval \(\clint{ a }{ b } \text{,}\) it attains a minimum value on \(\clint{ a }{ b } \text{.}\) Thus \(g \) attains a minimum value at some interior point \(c \in \opint{ a }{ b } \text{,}\) and so the Interior extremum theorem implies that \(g' \of{ c } = 0 \text{;}\) that is,
    \begin{equation*} g' \of{ c } = f' \of{ c } - r\text{,} \end{equation*}
    so that \(f' \of{ c } = r \text{.}\)
    🔗
    Now suppose that \(f' \of{ b } \lt f' \of{ a } \text{,}\) let \(f' \of{ b } \lt r \lt f' \of{ a } \text{,}\) and consider the function \(g \colon X \to \R \) defined by the formula
    \begin{equation*} g \of{ x } = f \of{ x } - r x\text{.} \end{equation*}
    We observe that \(g' \of{ a } = f' \of{ a } - r \gt 0 \) and \(g' \of{ b } = f' \of{ b } - r \lt 0 \text{.}\) In particular, the argument in the proof of Lemma 5.2.4 Local extrema are stationary points implies that \(g \) does not attain a maximum value at \(a \) or \(b \text{.}\)
    🔗
    However, since \(g \) is continuous on the compact interval \(\clint{ a }{ b } \text{,}\) it attains a maximum value on \(\clint{ a }{ b } \text{.}\) Thus \(g \) attains a maximum value at some interior point \(c \in \opint{ a }{ b } \text{,}\) and so the Interior extremum theorem implies that \(g' \of{ c } = 0 \text{;}\) that is,
    \begin{equation*} g' \of{ c } = f' \of{ c } - r\text{,} \end{equation*}
    so that \(f' \of{ c } = r \text{.}\)
    🔗
    🔗
    We have thus far only explored the local behavior of functions near critical points, but there is also much to say of the behavior of a function near regular points. For example, if a differentiable function has only regular points, then it is strictly monotone.
    🔗

    Corollary 5.2.7. Monotonicity in the absence of critical points.

    Let \(f \colon X \to \R \) be a differentiable function defined on an interval \(X \subseteq \R \text{.}\) If \(f \) does not have any critical points in \(X \text{,}\) then \(f \) is strictly monotone.
    🔗
    🔗

    Proof.
    If \(f' \) takes both positive and negative values on \(X \text{,}\) then Darboux’s theorem implies that \(f' \of{ x } = 0 \) for some point \(x \in X \text{.}\) This contradiction implies that \(f' \) either takes only positive values on \(X \) or takes only negative values on \(X \text{.}\) We will prove the result in the case \(f' \of{ x } \gt 0 \) for all points \(x \in X \text{;}\) the case \(f' \of{ x } \lt 0 \) for all \(x \in X \) is similar.
    🔗
    Let \(a , b \in X \text{,}\) and suppose that \(a \lt b \text{.}\) Since \(f \) is continuous on the compact interval \(\clint{ a }{ b } \subseteq X \text{,}\) it attains a maximum value on \(\clint{ a }{ b } \text{.}\) If \(f \) attains a maximum value at an interior point \(c \in \opint{ a }{ b } \text{,}\) then the Interior extremum theorem implies that \(f' \of{ c } = 0 \text{.}\) This contradiction implies that \(f \) attains a maximum value at one of the endpoints \(a \) or \(b \text{.}\)
    🔗
    Since \(f' \of{ a } \gt 0 \) and any neighborhood of \(a \) in \(\clint{ a }{ b } \) contains points which are strictly larger than \(a \text{,}\) the argument in the proof of Lemma 5.2.4 Local extrema are stationary points implies that \(f \) does not attain a maximum value at \(a \text{.}\) Thus we conclude that \(f \of{ a } \lt f \of{ b } \text{.}\) Since \(a \) and \(b \) were chosen arbitrarily, \(f \) is increasing.
    🔗
    🔗
    Stronger versions of Corollary 5.2.7 Monotonicity in the absence of critical points are usually called the inverse function theorem, and establish the differentiability of the left inverse of any such function. You will have an opportunity to explore these additional conclusions in the problems for this section.
    🔗
    🔗

    Subsection 5.2.2 Classification of Critical Points

    While the previous results of this section are quite strong, we wish to establish even stronger characterizations of real-valued functions based on local analyses near critical points. However, these analyses will require us to consider critical points which are not themselves limits of critical points.
    🔗

    Definition 5.2.8. Isolated critical point.

    Let \(f \colon X \to \R \) be a real-valued function defined on a subset \(X \subseteq \R \text{.}\) A critical point \(x \in X \) of \(f \) is called isolated if there is a neighborhood \(N \in \Nbhd_{ X } \of{ x } \) so that \(N \setminus \set{ x } \) consists only of regular points of \(f \text{.}\)
    🔗
    🔗

    Example 5.2.9. Isolated critical points.

    The following are examples and non-examples of isolated critical points of real-valued functions:
    • Let \(f \colon \R \to \R \) be the continuous real-valued function defined piecewise by the formula
      \begin{equation*} f \of{ x } = \begin{cases} x \sin \of{ \frac{ 1 }{ x } } \amp x \neq 0 \\ 0 \amp x = 0 \text{.}\end{cases} \end{equation*}
      Then \(f \) has infinitely many non-zero isolated critical points which accumulate at the critical point \(0 \text{.}\)
      🔗
      🔗
    • Let \(g \colon \R \to \R \) be the continuous real-valued function defined by the formula \(g \of{ y } = \abs{ y } \text{.}\) Then \(g \) has one critical point at \(0 \text{,}\) which is isolated.
      🔗
      🔗
    • Let \(h \colon \clint{ -1 }{ 1 } \to \R \) be the continuous real-valued function defined by the formula
      \begin{equation*} h \of{ z } = \sqrt{ 1 - z^{ 2 } }\text{.} \end{equation*}
      Then \(h \) has three critical points at \(-1 \text{,}\) \(0 \text{,}\) and \(1 \text{,}\) each of which is isolated.
      🔗
      🔗
    🔗
    🔗
    If \(c \) is an isolated critical point of a continuous real-valued function defined on an interval, then continuity and Corollary 5.2.7 Monotonicity in the absence of critical points implies that the restrictions of \(f \) to some intervals \(\opclint{ c - \delta }{ c } \) and \(\clopint{ c }{ c + \delta } \) are strictly monotone. This can be used to detect the presence of a local extremum.
    🔗

    Theorem 5.2.10. First derivative test.

    Let \(f \colon X \to \R \) be a continuous real-valued function defined on an interval \(X \subseteq \R \text{.}\) If \(c \in \Int \of{ X } \) is an interior point of \(X \) in \(\R \) and an isolated critical point of \(f \text{,}\) then \(f \) attains a local extremum at \(c \) if and only if the derivative \(f' \) changes sign at \(c \text{.}\)
    🔗
    🔗

    Proof.
    Under these assumptions, the previous discussion applies; there is some positive real number \(\delta \gt 0 \) so that \(\opint{ c - \delta }{ c + \delta } \subseteq X \) so that \(f ' \) does not change sign on the intervals \(\opint{ c - \delta }{ c } \) and \(\opint{ c }{ c + \delta } \text{.}\)
    🔗
    If \(f' \) takes only positive values on both \(\opint{ c - \delta }{ c } \) and \(\opint{ c }{ c + \delta } \text{,}\) then the continuity of \(f \) and Corollary 5.2.7 Monotonicity in the absence of critical points implies that the restrictions of \(f \) to the intervals \(\opclint{ c - \delta }{ c } \) and \(\clopint{ c }{ c + \delta } \) are increasing. We conclude that the restriction of \(f \) to \(\opint{ c - \delta }{ c + \delta } \) is increasing, so that
    \begin{equation*} f \of{ c - \eta } \lt f \of{ c } \lt f \of{ c + \eta } \end{equation*}
    for all sufficiently small positive real numbers \(0 \lt \eta \lt \delta \text{.}\) In particular, this implies that \(f \) cannot attain a local extremum at \(c \text{.}\)
    🔗
    If \(f' \) takes only negative values on both \(\opint{ c - \delta }{ c } \) and \(\opint{ c }{ c + \delta } \text{,}\) then the continuity of \(f \) and Corollary 5.2.7 Monotonicity in the absence of critical points implies that the restrictions of \(f \) to the intervals \(\opclint{ c - \delta }{ c } \) and \(\clopint{ c }{ c + \delta } \) are decreasing. We conclude that the restriction of \(f \) to \(\opint{ c - \delta }{ c + \delta } \) is decreasing, so that
    \begin{equation*} f \of{ c - \eta } \gt f \of{ c } \gt f \of{ c + \eta } \end{equation*}
    for all sufficiently small positive real numbers \(0 \lt \eta \lt \delta \text{.}\) In particular, this implies that \(f \) cannot attain a local extremum at \(c \text{.}\)
    🔗
    If \(f' \) takes only positive values on \(\opint{ c - \delta }{ c } \) and only negative values on \(\opint{ c }{ c + \delta } \text{,}\) then the continuity of \(f \) and Corollary 5.2.7 Monotonicity in the absence of critical points implies that the restrictions of \(f \) to the intervals \(\opclint{ c - \delta }{ c } \) and \(\clopint{ c }{ c + \delta } \) are increasing and decreasing, respectively. We conclude that
    \begin{equation*} f \of{ c - \eta } \lt f \of{ c } \gt f \of{ c + \eta } \end{equation*}
    for all sufficiently small positive real numbers \(0 \lt \eta \lt \delta \text{.}\) In particular, this implies that \(f \) attains a local maximum at \(c \text{.}\)
    🔗
    Finally, if \(f' \) takes only negative values on \(\opint{ c - \delta }{ c } \) and only positive values on \(\opint{ c }{ c + \delta } \text{,}\) then the continuity of \(f \) and Corollary 5.2.7 Monotonicity in the absence of critical points implies that the restrictions of \(f \) to the intervals \(\opclint{ c - \delta }{ c } \) and \(\clopint{ c }{ c + \delta } \) are decreasing and increasing, respectively. We conclude that
    \begin{equation*} f \of{ c - \eta } \gt f \of{ c } \lt f \of{ c + \eta } \end{equation*}
    for all sufficiently small positive real numbers \(0 \lt \eta \lt \delta \text{.}\) In particular, this implies that \(f \) attains a local minimum at \(c \text{.}\)
    🔗
    🔗

    Example 5.2.11. Using the first derivative test.

    Let \(n \geq 1 \) be a positive integer, and consider the real-valued function \(f \colon \R \to \R \) defined by the formula \(f \of{ x } = x^{ n } \text{.}\) Recall that \(f \) is differentiable, with derivative \(f' \of{ x } = n x^{ n - 1 } \text{.}\) If \(n = 1 \text{,}\) then
    \begin{equation*} f' \of{ x } = 1 x^{ 0 } = 1 \neq 0 \end{equation*}
    for all points \(x \neq 0 \text{,}\) and so \(f \) has no critical points. However, if \(n \geq 2 \text{,}\) then
    \begin{equation*} f' \of{ x } = n x^{ n - 1 } \end{equation*}
    vanishes precisely when \(x = 0 \text{;}\) that is, \(0 \) is the only critical point of \(f \text{,}\) and it is a stationary critical point.
    🔗
    We observe that if \(n \geq 2 \) is even, then \(f' \of{ x } \lt 0 \) when \(x \lt 0 \) and \(f' \of{ x } \gt 0 \) when \(x \gt 0 \text{.}\) The First derivative test implies that \(f \) attains a local minimum at \(0 \) in this case.
    🔗
    On the other hand, if \(n \geq 2 \) is odd, then \(f' \of{ x } \gt 0 \) when \(x \neq 0 \text{.}\) The First derivative test implies that \(f \) does not attain a local extremum at \(0 \) in this case.
    🔗
    🔗
    When a real-valued function is twice-differentiable at an isolated stationary critical point, its second derivative can also sometimes be used to detect the presence of local extrema at critical points.
    🔗

    Corollary 5.2.12. Second derivative test.

    Let \(f \colon X \to \R \) be a differentiable real-valued function defined on an interval \(X \subseteq \R \text{.}\) Suppose that \(c \in \Int \of{ X } \) is an interior point of \(X \) in \(\R \) and an isolated stationary critical point of \(f \) at which \(f \) is twice-differentiable. If \(f'' \of{ c } \gt 0 \text{,}\) then \(f \) attains a local minimum at \(0 \text{,}\) and if \(f'' \of{ c } \lt 0 \text{,}\) then \(f \) attains a local maximum at \(0 \text{.}\)
    🔗
    🔗

    Proof.
    Since \(c \) is a stationary critical point of \(f \text{,}\) \(f' \of{ c } = 0 \text{.}\) Since \(\frac{ \abs{ f'' \of{ c } } }{ 2 } \gt 0 \) is a positive real number, there is a positive real number \(\delta \gt 0 \) so that \(\opint{ c - \delta }{ c + \delta } \subseteq X \) and
    \begin{equation*} \abs{ \frac{ f' \of{ x } - f' \of{ c } }{ x - c } - f'' \of{ c } } \lt \frac{ \abs{ f'' \of{ c } } }{ 2 } \end{equation*}
    for all points \(x \in \opint{ c - \delta }{ c + \delta } \text{.}\) If \(f'' \of{ c } \gt 0 \text{,}\) then
    \begin{equation*} \frac{ f' \of{ x } }{ x - c } = \frac{ f' \of{ x } - f' \of{ c } }{ x - c } \gt \frac{ f'' \of{ c } }{ 2 } \gt 0\text{,} \end{equation*}
    and so \(f' \of{ x } \) and \(x - c \) have the same sign; that is, \(f' \) takes only negative values on \(\opint{ c - \delta }{ c } \) and takes only positive values on \(\opint{ c }{ c + \delta } \text{.}\) The First derivative test now implies that \(f \) attains a local minimum at \(c \text{.}\)
    🔗
    On the other hand, if \(f'' \of{ c } \gt 0 \text{,}\) then
    \begin{equation*} \frac{ f' \of{ x } }{ x - c } = \frac{ f' \of{ x } - f' \of{ c } }{ x - c } \lt \frac{ f'' \of{ c } }{ 2 } \lt 0\text{,} \end{equation*}
    and so \(f' \of{ x } \) and \(x - c \) have opposite signs; that is, \(f' \) takes only positive values on \(\opint{ c - \delta }{ c } \) and takes only negative values on \(\opint{ c }{ c + \delta } \text{.}\) The First derivative test now implies that \(f \) attains a local maximum at \(c \text{.}\)
    🔗
    🔗

    Example 5.2.13. Using the second derivative test.

    Let \(n \geq 2 \text{,}\) and consider the real-valued function \(f \colon \R \to \R \) defined by the formula \(f \of{ x } = x^{ n } \text{.}\) Recall that \(f \) is differentiable, with derivative \(f' \of{ x } = n x^{ n - 1 } \) and second derivative \(f'' \of{ x } = n \of{ n - 1 } x^{ n - 2 } \text{.}\) We have seen in Example 5.2.11 Using the first derivative test that \(f \) has a single stationary critical point at \(0 \text{.}\)
    🔗
    We observe that if \(n = 2 \text{,}\) then \(f'' \of{ 0 } = 2 \cdot 1 = 2 \gt 0 \text{,}\) and so the Second derivative test implies that \(f \) attains a local minimum at \(0 \) in this case. However, if \(n \geq 3 \text{,}\) then
    \begin{equation*} f'' \of{ 0 } = n \of{ n - 1 } 0^{ n - 2 } = 0\text{,} \end{equation*}
    and so the Second derivative test is inconclusive.
    🔗
    🔗
    So we see that the Second derivative test may not be conclusive even for functions whose isolated critical points may be analyzed by the First derivative test.
