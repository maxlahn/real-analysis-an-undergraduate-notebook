    1.1.4 Exercises

    Determine whether or not the given object is an element of the given set. Write your answer using the notation \(\in \) or \(\notin \text{.}\)
    🔗

    1.1.4.1.

    Is \(3 \) an element of the set \(\set{ 1 , 2 , 3 } \text{?}\)
    🔗
    Answer.
    Yes, \(3 \in \set{ 1 , 2 , 3 } \text{.}\)
    🔗
    🔗

    1.1.4.2.

    Is \(5 \) an element of the set \(\set{ 3 , 9 , 12 } \text{?}\)
    🔗
    Answer.
    No, \(3 \notin \set{ 1 , 2 , 3 } \text{.}\)
    🔗
    🔗

    1.1.4.3.

    Is \(8 \) an element of the set \(\set{ 0 , 2 , 4 , \dotsc , 12 } \text{?}\)
    🔗
    Answer.
    If we interpret the roster notation as
    \begin{equation*} \set{ 0 , 2 , 4 , \dotsc , 12 } = \set{ 0 , 2 , 4 , 6 , 8 , 10 , 12 }\text{,} \end{equation*}
    then \(8 \in \set{ 0 , 2 , 4 , \dotsc , 12 } \text{.}\)
    🔗
    🔗

    1.1.4.4.

    Is \(50 \) an element of the set \(\set{ 0 , 1 , 4 , 9 , 16 , \dotsc } \text{?}\)
    🔗
    Answer.
    If we interpret the roster notation as
    \begin{equation*} \set{ 0 , 1 , 4 , 9 , 16 , \dotsc } = \setmid{ n^{ 2 } }{ n \in \set{ 0 , 1 , 2 , 3 , \dotsc } }\text{,} \end{equation*}
    then \(50 \notin \set{ 0 , 1 , 4 , 9 , 16 , \dotsc } \text{.}\)

    Let \(S \text{,}\) \(T \text{,}\) and \(U \) be the sets defined by
    \begin{align*} S \amp = \set{ 0 , 1 , 2 } \amp T \amp = \set{ 3 , 4 } \amp U \amp = \set{ 1 , 2 , 3 }\text{.} \end{align*}
    Determine whether or not the stated set containment is true or false.
    🔗

    1.1.4.8.

    Is \(S \subseteq U \text{?}\)
    🔗
    Answer.
    No, \(S \not \subseteq U \text{.}\)
    🔗
    🔗

    1.1.4.9.

    Is \(S \cap T \subsetneq U \text{?}\)
    🔗
    Answer.
    Yes, \(S \cap T \subsetneq U \text{.}\)
    🔗
    🔗
    Solution.
    Yes,
    \begin{equation*} S \cap T = \set{ 0 , 1 , 2 } \cap \set{ 3 , 4 } = \emptyset \subsetneq \set{ 1 , 2 , 3 } = U \end{equation*}
    🔗
    🔗

    1.1.4.10.

    Is \(U \subseteq S \cup T \text{?}\)
    🔗
    Answer.
    Yes, \(U \subseteq S \cup T \text{.}\)
    🔗
    🔗
    Solution.
    Yes,
    \begin{align*} U \amp = \set{ 1 , 2 , 3 } \subseteq \set{ 0 , 1 , 2 , 3 , 4 }\\ \amp = \set{ 0 , 1 , 2 } \cup \set{ 3 , 4 } = S \cup T \end{align*}

    1.1.4.11.

    Write down the power set \(\ps \of{ S } \) of the set \(S = \set{ 1 } \) in roster notation.
    🔗
    Answer.
    The power set \(\ps \of{ S } \) of the set \(S = \set{ 1 } \) is the set
    \begin{equation*} \ps \of{ S } = \set{ \emptyset , \set{ 1 } }\text{.} \end{equation*}
    🔗
    🔗
    Solution.
    Choosing a subset of the set \(S = \set{ 1 } \) is equivalent to making a unique binary choices of whether or not to include the element \(1 \text{.}\) We see that \(S \) has the following \(2 \) subsets: \(\emptyset \text{,}\) and \(\set{ 1 } \text{.}\) Therefore, the power set \(\ps \of{ S } \) of the set \(S = \set{ 1 } \) is the set
    \begin{equation*} \ps \of{ S } = \set{ \emptyset , \set{ 1 } }\text{.} \end{equation*}
    🔗
    🔗

    1.1.4.12.

    Write down the power set \(\ps \of{ T } \) of the set \(T = \set{ 1 , 2 } \) in roster notation.
    🔗
    Answer.
    The power set \(\ps \of{ T } \) of the set \(T = \set{ 1 , 2 } \) is the set
    \begin{equation*} \ps \of{ T } = \set{ \emptyset , \set{ 1 } , \set{ 2 } , \set{ 1 , 2 } }\text{.} \end{equation*}
    🔗
    🔗
    Solution.
    Choosing a subset of the set \(T = \set{ 1 , 2 } \) is equivalent to making a unique sequence of two binary choices of whether to include each element \(1 \) and \(2 \text{.}\) We see that \(T \) has the following \(4 \) subsets: \(\emptyset \text{,}\) \(\set{ 1 } \text{,}\) \(\set{ 2 } \text{,}\) and \(\set{ 1 , 2 } \text{.}\) Therefore, the power set \(\ps \of{ T } \) of the set \(S = \set{ 1 , 2 } \) is the set
    \begin{equation*} \ps \of{ T } = \set{ \emptyset , \set{ 1 } , \set{ 2 } , \set{ 1 , 2 } }\text{.} \end{equation*}
    🔗
    🔗

    1.1.4.13.

    Write down the power set \(\ps \of{ U } \) of the set \(U = \set{ 1 , 2 , 3 } \) in roster notation.
    🔗
    Answer.
    The power set \(\ps \of{ U } \) of the set \(U = \set{ 1 , 2 , 3 } \) is the set
    \begin{equation*} \ps \of{ U } = \set{ \emptyset , \set{ 1 } , \set{ 2 } , \set{ 3 } , \set{ 1 , 2 } , \set{ 1 , 3 } , \set{ 2 , 3 } , \set{ 1 , 2 , 3 } }\text{.} \end{equation*}
    🔗
    🔗
    Solution.
    Choosing a subset of the set \(U = \set{ 1 , 2 , 3 } \) is equivalent to making a unique sequence of three binary choices of whether to include each element \(1 \text{,}\) \(2 \text{,}\) and \(3 \text{.}\) We see that \(U \) has the following \(8 \) subsets: \(\emptyset \text{,}\) \(\set{ 1 } \text{,}\) \(\set{ 2 } \text{,}\) \(\set{ 3 } \text{,}\) \(\set{ 1 , 2 } \text{,}\) \(\set{ 1 , 3 } \text{,}\) \(\set{ 2 , 3 } \text{,}\) and \(\set{ 1 , 2 , 3 } \text{.}\) Therefore, the power set \(\ps \of{ U } \) of the set \(U = \set{ 1 , 2 , 3 } \) is the set
    \begin{equation*} \ps \of{ U } = \set{ \emptyset , \set{ 1 } , \set{ 2 } , \set{ 3 } , \set{ 1 , 2 } , \set{ 1 , 3 } , \set{ 2 , 3 } , \set{ 1 , 2 , 3 } }\text{.} \end{equation*}

    Solution.

    1.2.4.8. Images and pre-images.

    Let \(f_{ 4 } \colon \set{ 1 , 2 } \to \set{ \mathrm{ red } , \mathrm{ blue } } \) be the map from \(\set{ 1 , 2 } \) to \(\set{ \mathrm{ red } , \mathrm{ blue } } \) defined in Example 1.2.4 Maps; that is,
    \begin{equation*} f_{ 4 } = \set{ \of{ 1 , \mathrm{ blue } } , \of{ 2 , \mathrm{ blue } } }\text{.} \end{equation*}
    Compute the given images and pre-images. Express your answer in roster notation if necessary.
    🔗
    1.2.4.8.a
    Compute the images \(f_{ 4 } \of{ 1 } \) and \(f_{ 4 } \of{ 2 } \text{.}\)
    🔗
    Answer.
    \(f_{ 4 } \of{ 1 } = f_{ 4 } \of{ 2 } = \mathrm{ blue } \text{.}\)
    🔗
    🔗
    Solution.
    Since \(\of{ 1 , \mathrm{ blue } } \in f_{ 4 } \text{,}\) the image \(f_{ 4 } \of{ 1 } \) of \(1 \) under \(f_{ 4 } \) is
    \begin{equation*} f_{ 4 } \of{ 1 } = \mathrm{ blue }\text{.} \end{equation*}
    Similarly, since \(\of{ 2 , \mathrm{ blue } } \in f_{ 4 } \text{,}\) the image \(f_{ 4 } \of{ 2 } \) of \(2 \) under \(f_{ 4 } \) is
    \begin{equation*} f_{ 4 } \of{ 2 } = \mathrm{ blue }\text{.} \end{equation*}
    🔗
    🔗
    1.2.4.8.b
    Compute the image \(\im \of{ f_{ 4 } } \text{.}\)
    🔗
    Answer.
    \(\im \of{ f_{ 4 } } = \set{ \mathrm{ blue } } \text{.}\)
    🔗
    🔗
    Solution.
    Since \(f_{ 4 } \of{ x } = \mathrm{ blue } \) for all \(x \in \set{ 1 , 2 } \text{,}\) the image \(\im \of{ f_{ 4 } } \) of \(f_{ 4 } \) is
    \begin{equation*} \im \of{ f_{ 4 } } = f_{ 4 } \of{ \set{ 1 , 2 } } = \set{ \mathrm{ blue } }\text{.} \end{equation*}
    🔗
    🔗
    1.2.4.8.c
    Compute the pre-images \(f_{ 4 }^{ -1 } \of{ \mathrm{ red } } \) and \(f_{ 4 }^{ -1 } \of{ \mathrm{ blue } } \text{.}\)
    🔗
    Answer.
    \(f_{ 4 }^{ -1 } \of{ \mathrm{ red } } = \emptyset \) and \(f_{ 4 }^{ -1 } \of{ \mathrm{ blue } } = \set{ 1 , 2 } \text{.}\)
    🔗
    🔗

    Since \(f_{ 4 } \of{ x } = \mathrm{ blue } \) for all \(x \in \set{ 1 , 2 } \text{,}\) the pre-images \(f_{ 4 }^{ -1 } \of{ \mathrm{ red } } \) and \(f_{ 4 }^{ -1 } \of{ \mathrm{ blue } } \) of \(\mathrm{ red } \) and \(\mathrm{ blue } \) under \(f_{ 4 } \) are
