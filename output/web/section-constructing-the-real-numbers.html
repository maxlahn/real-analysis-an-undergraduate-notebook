    Section 2.2 Constructing the Real Numbers

    In this section, we construct the real number system \(\R \) by Dedekind cuts, and we explore the resultant properties of arithmetic and comparison. However, we will find the existence of such a formal construction and its properties more useful than the particular details of the construction itself, and we will shortly leave behind the perspective suggested by our construction.
    🔗

    Subsection 2.2.1 Cutting the Rational Numbers

    So far, our progression through the standard number systems \(\N \subsetneq \Z \subsetneq \Q \) has proceeded in order of containment. Every time we have expanded our perspective to consider larger number systems, it has resulted in only the acquisition of new desirable properties. This is an artefact of our focus on the analytical rather than say the number-theoretical; there are for example incredibly interesting properties of the natural numbers \(\N \) and the integers \(\Z \) which are lost in the jump to the rational numbers \(\Q \text{.}\)
    🔗
    However, we have yet to see any deficiencies with the rational number system \(\Q \) which would motivate seeking an extension. These deficiencies exist, and we will see in Section 2.3 The Complete Ordered Field and later in Section 3.6 Completeness and Compactness the benefits in working in the real numbers \(\R \text{.}\) As a brief example, we note that \(\Q \) can be written as a particular type of disjoint union \(\Q = X \sqcup Y \text{,}\) where
    \begin{align*} X \amp = \setmid{ q \in \Q }{ q \lt 0 \textrm{ or } q^{ 2 } \lt 2 }\\ Y \amp = \setmid{ q \in \Q }{ q \gt 0 \textrm{ and } q^{ 2 } \gt 2 }\text{.} \end{align*}
    are defined by strict inequalities. This decomposition of \(\Q \) is an example of a Dedekind cut, and we will see that such a decomposition of \(\R \) cannot exist.
    🔗

    Definition 2.2.1. Dedekind cut.

    A proper, non-empty subset \(\emptyset \subsetneq X \subsetneq \Q \) of the rational numbers \(\Q \) is called a Dedekind cut if it satisfies the following conditions:
    1. For all rational numbers \(q_{ 1 } , q_{ 2 } \in \Q \text{,}\) if \(q_{ 1 } \leq q_{ 2 } \) and \(q_{ 2 } \in X \text{,}\) then \(q_{ 1 } \in X \text{.}\)
      🔗
      🔗
    2. \(X \) does not have a maximum; that is, for all elements \(q_{ 1 } \in X \text{,}\) there is an element \(q_{ 2 } \in X \) so that \(q_{ 1 } \lt q_{ 2 } \text{.}\)
      🔗
      🔗
    The set of Dedekind cuts is denoted \(\R \text{.}\)
    🔗
    🔗

    Example 2.2.2. Dedekind cuts.

    For each rational number \(q \in \Q \text{,}\) consider the subset
    \begin{equation*} X_{ q } = \setmid{ p \in \Q }{ p \lt q } \end{equation*}
    of the rational numbers \(\Q \text{.}\) We observe that \(X_{ q } \) is a proper and non-empty subset of \(\Q \text{,}\) since it contains \(q - 1 \) but not \(q \) itself. Moreover, for all rational numbers \(p_{ 1 } , p_{ 2 } \in \Q \text{,}\) if \(p_{ 1 } \leq p_{ 2 } \) and \(p_{ 2 } \in X_{ q } \text{,}\) then
    \begin{equation*} p_{ 1 } \leq p_{ 2 } \lt q\text{,} \end{equation*}
    and so \(p_{ 1 } \in X_{ q } \text{.}\) Finally, for all elements \(p_{ 1 } \in X \text{,}\) we observe that
    \begin{equation*} p \lt p + \frac{ q - p }{ 2 } \lt p + \of{ q - p } = q\text{,} \end{equation*}
    so that \(p + \frac{ q - p }{ 2 } \in X_{ q } \text{.}\) In summary, we have shown that associated to each rational number \(q \in \Q \) is a Dedekind cut \(X_{ q } \text{.}\)
    🔗
    🔗
    We will see that the above construction realizes the rational numbers \(\Q \) as a subset of the set of Dedekind cuts. The Dedekind cuts which arise in this manner will be called rational. We will shortly see that not every Dedekind cut is rational.
    🔗

    Lemma 2.2.3. Rational Dedekind cuts.

    A Dedekind cut \(X \) is rational if and only if its complement \(\Q \setminus X \) has a minimum.
    🔗
    🔗

    Proof.
    Let \(X \) be a Dedekind cut, and suppose that \(X = X_{ q } \) for some rational number \(q \in \Q \text{.}\) Note that \(X = X_{ q } \) has complement
    \begin{equation*} \Q \setminus X = \Q \setminus X_{ q } = \setmid{ p \in \Q }{ p \notin X_{ q } } = \setmid{ p \in \Q }{ p \geq q }\text{.} \end{equation*}
    This set contains \(q \text{,}\) since \(q \geq q \text{.}\) Moreover, \(p \geq q \) for all elements \(p \in \Q \setminus X_{ q } \text{.}\) Thus \(\min \of{ \Q \setminus X } = q \text{.}\)
    🔗
    Conversely, now suppose that \(\Q \setminus X \) has a minimum element, say \(q = \min \of{ \Q \setminus X } \in \Q \text{.}\) Let \(p \in \Q \text{,}\) and suppose that \(p \geq q \text{.}\) If \(p \in X \text{,}\) then that would imply that \(q \in X \text{.}\) This contradiction implies that \(p \notin X \text{.}\) On the other hand, if \(p \lt q \text{,}\) then \(p \notin \Q \setminus X \text{,}\) since \(\min \of{ \Q \setminus X } = q \text{.}\) Thus
    \begin{equation*} X = \setmid{ p \in \Q }{ p \lt q } = X_{ q } \end{equation*}
    is rational.
    🔗
    🔗

    Proposition 2.2.4. Irrational Dedekind cuts.

    Not all Dedekind cuts are rational.
    🔗
    🔗

    Proof.
    Consider the subset
    \begin{equation*} X = \setmid{ q \in \Q }{ q \lt 0 \textrm{ or } q^{ 2 } \lt 2 } \end{equation*}
    of the rational numbers \(\Q \text{.}\) We observe that \(X \) is a non-empty and proper subset of \(\Q \text{,}\) since it contains \(1 \) but not \(2 \text{.}\) Let \(p_{ 1 } , p_{ 2 } \in \Q \) be rational numbers, and suppose that \(p_{ 1 } \leq p_{ 2 } \) and \(p_{ 2 } \in X \text{.}\) If \(p_{ 2 } \lt 0 \text{,}\) then
    \begin{equation*} p_{ 1 } \leq p_{ 2 } \lt 0\text{,} \end{equation*}
    and so \(p_{ 1 } \in X \text{.}\) On the other hand, if \(p_{ 2 }^{ 2 } \lt 2 \text{,}\) then either \(p_{ 1 } \lt 0 \) or \(0 \leq p_{ 1 } \leq p_{ 2 } \text{,}\) in which case \(p_{ 1 }^{ 2 } \leq p_{ 2 }^{ 2 } \lt 2 \text{.}\) In either case, we conclude that \(p_{ 1 } \in X \text{.}\)
    🔗
    Finally, let \(q \in X \text{.}\) If \(q \leq 0 \text{,}\) then let \(p = 1 \text{,}\) and note that \(p \in X \) and \(q \lt p \text{.}\) On the other hand, suppose that \(q \gt 0 \) and \(q^{ 2 } \lt 2 \text{,}\) and consider the rational number
    \begin{equation*} p = \frac{ 2 q + 2 }{ 2 + q } \in \Q\text{.} \end{equation*}
    Note that
    \begin{equation*} p = \frac{ 2 q + 2 }{ 2 + q } = \frac{ 2 q + q^{ 2 } }{ 2 + q } + \frac{ 2 - q^{ 2 } }{ 2 + q } = q + \frac{ 2 - q^{ 2 } }{ 2 + q } \gt q\text{,} \end{equation*}
    and
    \begin{align*} 2 - p^{ 2 } \amp = \frac{ 2 \of{ 2 + q }^{ 2 } }{ \of{ 2 + q }^{ 2 } } - \frac{ \of{ 2 q + 2 }^{ 2 } }{ \of{ 2 + q }^{ 2 } }\\ \amp = \frac{ 4 - 2 q^{ 2 } }{ \of{ 2 + q }^{ 2 } } = \frac{ 2 \of{ 2 - q^{ 2 } } }{ \of{ 2 + q }^{ 2 } } \gt 0\text{,} \end{align*}
    so that \(p^{ 2 } \lt 2 \text{;}\) that is, \(p \in X \text{.}\) We conclude that \(X \) is a Dedekind cut, and so it suffices to show that \(X \) is not rational.
    🔗
    To that end, we note that \(X \) has complement
    \begin{equation*} \Q \setminus X = \setmid{ q \in \Q }{ q \geq 0 \textrm{ and } q^{ 2 } \geq 2 }\text{.} \end{equation*}
    In fact, since \(q^{ 2 } \neq 2 \) for all rational numbers \(q \in \Q \) (this fact is proven in any introductory number theory course),
    \begin{equation*} \Q \setminus X = \setmid{ q \in \Q }{ q \geq 0 \textrm{ and } q^{ 2 } \gt 2 }\text{.} \end{equation*}
    We will show that \(\Q \setminus X \) has no minimum element. Indeed, let \(q \in \Q \setminus X \text{,}\) so that \(q \geq 0 \) and \(q^{ 2 } \gt 2 \text{.}\) We again consider the rational number
    \begin{equation*} p = \frac{ 2 q + 2 }{ 2 + q } \in \Q\text{.} \end{equation*}
    We see that \(p \geq 0 \text{.}\) Moreover, now that \(q^{ 2 } \gt 2 \text{,}\) we observe that
    \begin{equation*} p = \frac{ 2 q + 2 }{ 2 + q } = \frac{ 2 q + q^{ 2 } }{ 2 + q } + \frac{ 2 - q^{ 2 } }{ 2 + q } = q + \frac{ 2 - q^{ 2 } }{ 2 + q } \lt q \end{equation*}
    and
    \begin{align*} 2 - p^{ 2 } \amp = \frac{ 2 \of{ 2 + q }^{ 2 } }{ \of{ 2 + q }^{ 2 } } - \frac{ \of{ 2 q + 2 }^{ 2 } }{ \of{ 2 + q }^{ 2 } }\\ \amp = \frac{ 4 - 2 q^{ 2 } }{ \of{ 2 + q }^{ 2 } } = \frac{ 2 \of{ 2 - q^{ 2 } } }{ \of{ 2 + q }^{ 2 } } \lt 0\text{,} \end{align*}
    so that \(p^{ 2 } \gt 2 \text{.}\) In particular, \(p \lt q \) and \(p \in \Q \setminus X \text{.}\) Thus \(\Q \setminus X \) has no minimum element, and so Lemma 2.2.3 Rational Dedekind cuts implies that \(X \) is not rational.
    🔗
    🔗
    Once we define the arithmetic of Dedekind cuts, we will see that the Dedekind cut
    \begin{equation*} X = \setmid{ q \in \Q }{ q \lt 0 \textrm{ or } q^{ 2 } \lt 2 } \end{equation*}
    from the above proof of Proposition 2.2.4 Irrational Dedekind cuts represents the irrational real number \(\sqrt{ 2 } \text{.}\) First, however, we observe that the rational numbers \(\Q \) inject into \(\R \text{.}\)
    🔗

    Proposition 2.2.5. Rational numbers as real numbers.

    The map \(\iota \colon \Q \to \R \) defined by the formula \(\iota \of{ q } = X_{ q } \) is injective.
    🔗
    🔗

    Proof.
    Let \(q_{ 1 } , q_{ 2 } \in \Q \) be rational numbers, and suppose that \(\iota \of{ q_{ 1 } } = \iota \of{ q_{ 2 } } \text{.}\) As shown in the proof of Lemma 2.2.3 Rational Dedekind cuts, \(\min \of{ X_{ q } } = q \) for all rational numbers \(q \in \Q \text{.}\) Therefore,
    \begin{align*} q_{ 1 } \amp = \min \of{ X_{ q_{ 1 } } } = \min \of{ \iota \of{ q_{ 1 } } }\\ \amp = \min \of{ \iota \of{ q_{ 2 } } } = \min \of{ X_{ q_{ 2 } } } = q_{ 2 }\text{.} \end{align*}
    Thus \(\iota \colon \Q \to \R \) is injective.
    🔗
    🔗
    Going forward, we will often exploit the injection \(\iota \colon \Q \to \R \) to pretend that \(\Q \subseteq \R \) by identifying a rational number with its associated rational Dedekind cut. We will now construct a total order \(\leq \) on \(\R \) which extends the standard order on \(\Q \text{.}\)
    🔗
    🔗

    Subsection 2.2.2 Comparison of Dedekind Cuts

    Our two perspectives on the set \(\Q \) (as equivalence classes of fractions and as rational Dedekind cuts) yield two natural orderings: the standard ordering \(\leq \) and the partial order of set containment. In fact, these orderings agree.
    🔗

    Corollary 2.2.6. Ordering Dedekind cuts by containment.

    The standard ordering \(\leq \) on the rational numbers \(\Q \) is the pullback of set containment \(\subseteq \) on the set \(\R \) of Dedekind cuts.
    🔗
    🔗

    Proof.
    Let \(q_{ 1 } , q_{ 2 } \in \Q \) be rational numbers. We note that
    \begin{align*} X_{ q_{ 1 } } \amp = \setmid{ p \in \Q }{ p \lt q_{ 1 } }\\ X_{ q_{ 2 } } \amp = \setmid{ p \in \Q }{ p \lt q_{ 2 } }\text{.} \end{align*}
    First suppose that \(q_{ 1 } \leq q_{ 2 } \text{.}\) If \(p \in X_{ q_{ 1 } } \text{,}\) then
    \begin{equation*} p \lt q_{ 1 } \leq q_{ 2 } \end{equation*}
    and so \(p \in X_{ q_{ 2 } } \text{;}\) that is,
    \begin{equation*} \iota \of{ q_{ 1 } } = X_{ q_{ 1 } } \subseteq X_{ q_{ 2 } } = \iota \of{ q_{ 2 } }\text{,} \end{equation*}
    so that \(q_{ 1 } \subseteq_{ \iota } q_{ 2 } \text{.}\)
    🔗
    Conversely, now suppose that \(q_{ 1 } \subseteq_{ \iota } q_{ 2 } \text{.}\) Then
    \begin{equation*} X_{ q_{ 1 } } = \iota \of{ q_{ 1 } } \subseteq \iota \of{ q_{ 2 } } = X_{ q_{ 2 } }\text{.} \end{equation*}
    If \(q_{ 1 } \gt q_{ 2 } \text{,}\) then
    \begin{equation*} q_{ 2 } \lt \frac{ q_{ 1 } + q_{ 2 } }{ 2 } \lt q_{ 1 }\text{,} \end{equation*}
    and so \(\frac{ q_{ 1 } + q_{ 2 } }{ 2 } \in X_{ q_{ 1 } } \setminus X_{ q_{ 2 } } \text{.}\) This would imply that \(X_{ q_{ 1 } } \not \subseteq X_{ q_{ 2 } } \text{,}\) and so we must have \(q_{ 1 } \leq q_{ 2 } \text{.}\)
    🔗
    In summary, we have shown that \(q_{ 1 } \leq q_{ 2 } \) if and only if \(q_{ 1 } \subseteq_{ \iota } q_{ 2 } \text{,}\) and so \(\leq \) and \(\subseteq_{ \iota } \) are the same binary relation on \(\Q \text{.}\)
    🔗
    🔗
    Corollary 2.2.6 Ordering Dedekind cuts by containment implies that comparing rational numbers is the same as comparing their associated rational Dedekind cuts by containment. This gives us the template for how to compare Dedekind cuts in general: we compare by set containment.
    🔗

    Theorem 2.2.7. Comparison of Dedekind cuts.

    Set containment \(\subseteq \) is a total order on the set \(\R \) of Dedekind cuts.
    🔗
    🔗

    Proof.
    Since set containment is a partial order, it suffices to show only totality. To that end, let \(X , Y \in \R \) be Dedekind cuts, and suppose that \(X \not \subseteq Y \text{.}\) Then there is some rational number \(q \in X \) so that \(q \notin Y \text{.}\)
    🔗
    Let \(p \in Y \text{.}\) If \(q \leq p \text{,}\) then we would have \(q \in Y \text{,}\) and so we must have \(p \leq q \text{.}\) But this implies that \(p \in X \text{,}\) and so \(Y \subseteq X \text{.}\)
    🔗
    In summary, we have shown that for all Dedekind cuts \(X , Y \in \R \text{,}\) either \(X \subseteq Y \) or \(Y \subseteq X \text{.}\) Thus set containment \(\subseteq \) is a total order on the set \(\R \) of Dedekind cuts.
    🔗
    🔗
    Just as with the integers \(\Z \) and rational numbers \(\Q \text{,}\) we can use the standard ordering on \(\R \) to distinguish Dedekind cuts by their sign: either positive, negative, or zero.
    🔗

    Definition 2.2.8. Sign of a Dedekind cut.

    Recall that
    \begin{equation*} X_{ 0 } = \setmid{ q \in \Q }{ q \lt 0 } \end{equation*}
    is the rational Dedekind cut associated to the rational number \(0 \text{.}\)
    • Positivity.
      A Dedekind cut \(X \in \R \) is called positive if it strictly contains \(X_{ 0 } \text{;}\) that is, \(X \) is positive if \(X \supsetneq X_{ 0 } \text{.}\)
      🔗
      🔗
    • Negativity.
      A Dedekind cut \(X \in \R \) is called negative if it is strictly contained in \(X_{ 0 } \text{;}\) that is, \(X \) is negative if \(X \subsetneq X_{ 0 } \text{.}\)
      🔗
      🔗
    • Non-negativity.
      A Dedekind cut \(X \in \R \) is called non-negative if it contains \(X_{ 0 } \text{;}\) that is, \(X \) is non-negative if \(X \supseteq X_{ 0 } \text{.}\)
      🔗
      🔗
    • Non-positivity.
      A Dedekind cut \(X \in \R \) is called non-positive if it is contained in \(X_{ 0 } \text{;}\) that is, \(X \) is positive if \(X \subseteq X_{ 0 } \text{.}\)
      🔗
      🔗
    In particular, the sign of a Dedekind cut is either positive, negative, or zero.
    🔗
    🔗
    This classification of Dedekind cuts by sign will be useful in formalizing the multiplication of Dedekind cuts. We now proceed in that direction, extending the usual operations of arithmetic on \(\Q \) to binary operations on \(\R \) and determining their properties.
    🔗
    🔗

    Subsection 2.2.3 Addition of Dedekind Cuts

    Finally, we begin to define arithmetic for Dedekind cuts. We emphasize that the utility of what follows is neither the details of the construction nor the methods of proof, but rather the very fact that the operations exist with the same properties we would expect. That is to say, we will eventually lose sight of the particularities of the construction of the real number system by Dedekind cuts and treat real numbers as objects which obey the rules of arithmetic.
    🔗

    Lemma 2.2.9. Addition of Dedekind cuts.

    Given two Dedekind cuts \(X , Y \in \R \text{,}\) the set
    \begin{equation*} \setmid{ p + q \in \Q }{ p \in X \textrm{ and } q \in Y } \end{equation*}
    is a Dedekind cut.
    🔗
    🔗

    Proof.
    Denote by \(Z \) the set
    \begin{equation*} Z = \setmid{ p + q \in \Q }{ p \in X \textrm{ and } q \in Y }\text{.} \end{equation*}
    Since \(X \) and \(Y \) are Dedekind cuts, they are non-empty subsets of \(\Q \text{,}\) and so there are rational numbers \(p \in X \) and \(q \in Y \text{.}\) Thus \(p + q \in Z \text{,}\) and so \(Z \) is also non-empty.
    🔗
    On the other hand, \(X \) and \(Y \) are proper subsets of \(\Q \text{,}\) and so there are rational numbers \(r \in \Q \setminus X \) and \(s \in \Q \setminus Y \text{.}\) We observe that that \(r \gt p \) for all \(p \in X \) and \(s \gt q \) for all \(q \in Y \text{.}\) In particular, for all \(t \in Z \) there are rational numbers \(p \in X \) and \(q \in Y \) so that \(t = p + q \text{,}\) and so
    \begin{equation*} r + s \gt p + q = t \end{equation*}
    In particular, \(r + s \notin Z \text{,}\) and so \(Z \) is also a proper subset of \(\Q \text{.}\)
    🔗
    Now let \(r , s \in \Q \) be rational numbers, and suppose that \(s \leq r \) and \(r \in Z \text{.}\) We wish to show that \(s \in Z \text{.}\) To that end, we see that \(r = p + q \) for some rational numbers \(p \in X \) and \(q \in Y \text{.}\) Since \(s - r \leq 0 \text{,}\)
    \begin{equation*} q + \of{ s - r } \leq q + 0 = q \in Y\text{,} \end{equation*}
    and so \(q + \of{ s - r } \in Y \text{.}\) This implies that
    \begin{equation*} s = r + \of{ s - r } = p + \of{ q + \of{ s - r } } \in Z\text{.} \end{equation*}
    🔗
    It remains to show that \(Z \) does not have a maximum. To that end, let \(r_{ 1 } \in Z \text{,}\) so that \(r_{ 1 } = p_{ 1 } + q_{ 1 } \) for some rational numbers \(p_{ 1 } \in X \) and \(q_{ 1 } \in Y \text{.}\) Since \(X \) and \(Y \) are Dedekind cuts, they do not have maxima, and so \(p_{ 1 } \lt p_{ 2 } \) and \(q_{ 1 } \lt q_{ 2 } \) for some rational numbers \(p_{ 2 } \in X \) and \(q_{ 2 } \in Y \text{.}\) We conclude that \(r_{ 2 } = p_{ 2 } + q_{ 2 } \in Z \text{,}\) and that
    \begin{equation*} r_{ 1 } = p_{ 1 } + q_{ 1 } \lt p_{ 2 } + q_{ 2 } = r_{ 2 }\text{.} \end{equation*}
    Thus \(Z \) does not have a maximum, and so is a Dedekind cut.
    🔗
    🔗

    Definition 2.2.10. Addition of Dedekind cuts.

    The sum \(X + Y \) of two Dedekind cuts \(X , Y \in \R \) is the Dedekind cut defined by
    \begin{equation*} X + Y = \setmid{ p + q \in \Q }{ p \in X \textrm{ and } q \in Y }\text{.} \end{equation*}
    This defines a binary operation \(+ \) on the set \(\R \) of Dedekind cuts.
    🔗
    🔗
    We first observe that addition of rational Dedekind cuts mirrors the addition of the corresponding rational numbers.
    🔗

    Lemma 2.2.11. Addition of rational Dedekind cuts.

    \(X_{ p } + X_{ q } = X_{ p + q } \) for all rational numbers \(p , q \in \Q \text{.}\)
    🔗
    🔗

    Proof.
    Let \(r \in \Q \) be a rational number, and suppose first that \(r \in X_{ p } + X_{ q } \text{.}\) Then \(r = s + t \) for some rational numbers \(s \in X_{ p } \) and \(t \in X_{ q } \text{,}\) so that \(s \lt p \) and \(t \lt q \text{.}\) We observe that
    \begin{equation*} r = s + t \lt p + q\text{,} \end{equation*}
    and so \(r \in X_{ p + q } \text{.}\)
    🔗
    Conversely, now suppose that \(r \in X_{ p + q } \text{,}\) so that \(r \lt p + q \text{.}\) Consider the rational numbers
    \begin{align*} s \amp = p + \frac{ r - \of{ p + q } }{ 2 } \amp t \amp = q + \frac{ r - \of{ p + q } }{ 2 }\text{.} \end{align*}
    Since \(\of{ \frac{ r - \of{ p + q } }{ 2 } } \lt 0 \text{,}\) \(s \lt p \) and \(t \lt q \text{,}\) and so \(s \in X_{ p } \) and \(t \in X_{ q } \text{.}\) We conclude that
    \begin{align*} r \amp = p + q + \of{ r - \of{ p + q } } = p + \frac{ r - \of{ p + q } }{ 2 } + q + \frac{ r - \of{ p + q } }{ 2 }\\ \amp = s + t \in X_{ p } + X_{ q }\text{.} \end{align*}
    🔗
    In summary, we have shown that \(r \in X_{ p } + X_{ q } \) if and only if \(r \in X_{ p + q } \text{,}\) and so \(X_{ p } + X_{ q } = X_{ p + q } \text{.}\)
    🔗
    🔗

    Proposition 2.2.12. Addition of Dedekind cuts.

    Addition \(+ \) of Dedekind cuts has the following properties:
    1. Commutativity.
      \(X + Y = Y + X \) for all Dedekind cuts \(X , Y \in \R \text{.}\)
      🔗
      🔗
    2. Associativity.
      \(\of{ X + Y } + Z = X + \of{ Y + Z } \) for all Dedekind cuts \(X , Y , Z \in \R \text{.}\)
      🔗
      🔗
    3. Identity element.
      The rational Dedekind cut \(X_{ 0 } \) associated to \(0 \) is an additive identity element; that is, \(X + X_{ 0 } = X_{ 0 } + X = X \) for all Dedekind cuts \(X \in \R \text{.}\)
      🔗
      🔗
    4. Inverses.
      For all Dedekind cuts \(X \in \R \text{,}\) there is a Dedekind cut \(Y \in \R \) so that \(X + Y = X_{ 0 } \text{.}\)
      🔗
      🔗
    5. Compatibility with the standard order.
      For all Dedekind cuts \(W , X , Y , Z \in \R \text{,}\) if \(W \subseteq Y \) and \(X \subseteq Z \text{,}\) then \(W + X \subseteq Y + Z \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. We note that
      \begin{align*} X + Y \amp = \setmid{ p + q \in \Q }{ p \in X \textrm{ and } q \in Y }\\ \amp = \setmid{ q + p \in \Q }{ q \in Y \textrm{ and } p \in X } = Y + X \end{align*}
      for all Dedekind cuts \(X , Y \in \R \text{,}\) and so addition \(+ \) of Dedekind cuts is commutative.
      🔗
      🔗
    2. We note that
      \begin{align*} \of{ X + Y } + Z \amp = \setmid{ s + r \in \Q }{ s \in X + Y \textrm{ and } r \in Z }\\ \amp = \setmid{ \of{ p + q } + r \in \Q }{ p \in X \textrm{ and } q \in Y \textrm{ and } r \in Z }\\ \amp = \setmid{ p + \of{ q + r } \in \Q }{ p \in X \textrm{ and } q \in Y \textrm{ and } r \in Z }\\ \amp = \setmid{ p + t \in \Q }{ p \in X \textrm{ and } t \in Y + Z } = X + \of{ Y + Z }\text{.} \end{align*}
      for all Dedekind cuts \(X , Y , Z \in \R \text{,}\) and so addition \(+ \) of Dedekind cuts is associative.
      🔗
      🔗
    3. Let \(p \in \Q \) be a rational number, and suppose first that \(p \in X + X_{ 0 } \text{.}\) Then \(p = q + r \) for some rational numbers \(q \in X \) and \(r \in X_{ 0 } \text{.}\) Since
      \begin{equation*} X_{ 0 } = \setmid{ s \in \Q }{ s \lt 0 } \end{equation*}
      is the set of negative rational numbers,
      \begin{equation*} p = q + r \lt q + 0 = q \in X\text{,} \end{equation*}
      and so \(p \in X \text{.}\)
      🔗
      Conversely, now suppose that \(p \in X \text{.}\) Since \(X \) does not have a maximum, \(r \in X \) for some rational number \(r \gt p \text{.}\) Let \(s = p - r \in X_{ 0 } \text{,}\) and note that
      \begin{equation*} p = r + \of{ p - r } = r + s \end{equation*}
      is the sum of a rational number \(r \in X \) and a rational number \(p - r \in X_{ 0 } \text{.}\) We conclude that \(p \in X + X_{ 0 } \text{.}\)
      🔗
      In summary, we have shown that \(p \in X + X_{ 0 } \) if and only if \(p \in X \text{,}\) and so \(X + X_{ 0 } = X \text{.}\) That \(X_{ 0 } + X = X \) now follows from (1) above.
      🔗
      🔗
    4. There are two cases: either \(X \) is rational, or \(X \) is irrational. If \(X \) is rational, say \(X = X_{ q } \) for some rational number \(q \in \Q \text{,}\) then we may choose \(Y = X_{ -q } \text{,}\) since Lemma 2.2.11 Addition of rational Dedekind cuts implies that
      \begin{equation*} X + Y = X_{ q } + X_{ -q } = X_{ q + \of{ -q } } = X_{ 0 }\text{.} \end{equation*}
      🔗
      So we may suppose that \(X \) is irrational. Let
      \begin{equation*} Y = \setmid{ q \in \Q }{ -q \notin X }\text{.} \end{equation*}
      Since \(X \) is a non-empty proper subset of \(\Q \text{,}\) so too is its complement \(\Q \setminus X \text{,}\) which implies that \(Y \) is also non-empty and proper. We aim to show first that \(Y \) is a Dedekind cut.
      🔗
      To that end, let \(p , q \in \Q \) be rational numbers, and suppose that \(p \lt q \) and \(q \in Y \text{.}\) Then \(-q \notin X \text{,}\) and so \(-q \gt r \) for all rational numbers \(r \in X \text{.}\) We observe that
      \begin{equation*} -p \geq -q \gt r \end{equation*}
      for all rational numbers \(r \in X \text{,}\) and so \(-p \notin X \text{;}\) that is, \(p \in Y \text{.}\)
      🔗
      Now let \(q \in Y \text{,}\) so that \(-q \notin X \text{.}\) Since \(X \) is irrational, Lemma 2.2.3 Rational Dedekind cuts implies that \(\Q \setminus X \) does not have a minimum. Thus there is some rational number \(r \in \Q \setminus X \) so that \(r \lt -q \text{.}\) We conclude that \(-r \in Y \) and \(-r \gt q \text{,}\) so that \(Y \) does not have a maximum.
      🔗
      We have shown that \(Y \) is a Dedekind cut, but it remains to show that \(X + Y = X_{ 0 } \text{.}\) To that end, let \(r \in \Q \) be a rational number, and suppose first that \(r \in X + Y \text{.}\) Then \(r = p + q \) for some \(p \in X \) and \(q \in Y \text{.}\) Since \(-q \notin X \text{,}\) we must have \(p \lt -q \text{,}\) so that \(r = p + q \lt 0 \text{;}\) that is, \(r \in X_{ 0 } \text{.}\)
      🔗
      Conversely, now suppose that \(r \in X_{ 0 } \text{,}\) so that \(r \lt 0 \text{.}\) In particular, \(-r \gt 0 \text{.}\) If \(p + \of{ -r } \in X \) for all rational numbers \(p \in X \text{,}\) then \(X \) is not bounded from above, which would imply that \(X = \Q \text{.}\) Thus \(p - r \notin X \) for some rational number \(p \in X \text{.}\) We conclude that
      \begin{equation*} r = p + \of{ r - p } \in X + Y \end{equation*}
      is the sum of two rational numbers \(p \in X \) and \(r - p \in Y \text{.}\)
      🔗
      In summary, we have shown that \(r \in X + Y \) if and only if \(r \in X_{ 0 } \text{,}\) and so \(X + Y = X_{ 0 } \text{.}\)
      🔗
      🔗
    5. We observe that if \(W \subseteq Y \) and \(X \subseteq Z \text{,}\) then
      \begin{align*} W + X \amp = \setmid{ p + q \in \Q }{ p \in W \textrm{ and } q \in X }\\ \amp \subseteq \setmid{ p + q \in \Q }{ p \in Y \textrm{ and } q \in Z } = Y + Z\text{.} \end{align*}
      🔗
      🔗
    🔗
    All that remains is to define the multiplication of Dedekind cuts and derive relevant results about multiplication itself and its relation to addition and comparison.
    🔗
    🔗

    Subsection 2.2.4 Multiplication of Dedekind Cuts

    Finally, we define multiplication for Dedekind cuts. We will see that this definition depends in a complicated way on the signs of the two factors. As a result of this case-by-case definition of multiplication, we offer the remaining results of this section without proof.
    🔗

    Lemma 2.2.13. Multiplication of positive Dedekind cuts.

    Given two positive Dedekind cuts \(X , Y \in \R \text{,}\) the set
    \begin{equation*} \setmid{ p q \in \Q }{ p \in X \textrm{ and } q \in Y \textrm{ and } \of{ p \geq 0 \textrm{ or } q \geq 0 } } \end{equation*}
    is a Dedekind cut.
    🔗
    🔗

    Definition 2.2.14. Multiplication of Dedekind cuts.

    The product \(X \cdot Y \) of two Dedekind cuts \(X , Y \in \R \) is the Dedekind cut defined by the following formulae:
    • Zero.
      If either \(X = X_{ 0 } \) or \(Y = X_{ 0 } \text{,}\) then \(X \cdot Y = X_{ 0 } \text{.}\)
      🔗
      🔗
    • Positive times positive.
      If both \(X \) and \(Y \) are positive, then
      \begin{equation*} X \times Y = \setmid{ p q \in \Q }{ p \in X \textrm{ and } q \in Y \textrm{ and } \of{ p \geq 0 \textrm{ or } q \geq 0 } }\text{.} \end{equation*}
      🔗
      🔗
    • Positive times negative.
      If \(X \) is positive and \(Y \) is negative, then
      \begin{equation*} X \times Y = -\of{ X \times \of{ -Y } }\text{.} \end{equation*}
      🔗
      🔗
    • Negative times positive.
      If \(X \) is negative and \(Y \) is positive, then
      \begin{equation*} X \times Y = -\of{ \of{ -X } \times Y }\text{.} \end{equation*}
      🔗
      🔗
    • Negative times negative.
      If both \(X \) and \(Y \) are negative, then
      \begin{equation*} X \times Y = \of{ -X } \times \of{ -Y }\text{.} \end{equation*}
      🔗
      🔗
    This defines a binary operation \(\cdot \) on the set \(\R \) of Dedekind cuts.
    🔗
    🔗
    We end with a compilation of all relevant results about the arithmetic of Dedekind cuts. While one can verify these results, we omit the proofs of those that involve multiplication in order to simplify the narrative of exposition. Indeed, these proofs rely on casework which, while not difficult, would require more time than we can dedicate to this topic.
    🔗

    Theorem 2.2.15. Arithmetic of Dedekind cuts.

    The addition and multiplication of Dedekind cuts has the following properties:
    • Commutativity of addition.
      \(X + Y = Y + X \) for all Dedekind cuts \(X , Y \in \R \text{.}\)
      🔗
      🔗
    • Associativity of addition.
      \(\of{ X + Y } + Z = X + \of{ Y + Z } \) and \(\of{ X \cdot Y } \cdot Z = X \cdot \of{ Y \cdot Z } \) for all Dedekind cuts \(X , Y , Z \in \R \text{.}\)
      🔗
      🔗
    • Additive identity element.
      The rational Dedekind cut \(X_{ 0 } \) associated to \(0 \) is an additive identity element; that is, \(X + X_{ 0 } = X_{ 0 } + X = X \) for all Dedekind cuts \(X \in \R \text{.}\)
      🔗
      🔗
    • Additive inverses.
      For all Dedekind cuts \(X \in \R \text{,}\) there is a Dedekind cut \(-X \in \R \) so that \(X + \of{ -X } = \of{ -X } + X = X_{ 0 } \text{.}\)
      🔗
      🔗
    • Commutativity of multiplication.
      \(X \cdot Y = Y \cdot X \) for all Dedekind cuts \(X , Y \in \R \text{.}\)
      🔗
      🔗
    • Associativity of multiplication.
      \(\of{ X \cdot Y } \cdot Z = X \cdot \of{ Y \cdot Z } \) for all Dedekind cuts \(X , Y , Z \in \R \text{.}\)
      🔗
      🔗
    • Multiplicative identity element.
      The rational Dedekind cut \(X_{ 1 } \) associated to \(1 \) is a multiplicative identity element; that is, \(X \cdot X_{ 1 } = X_{ 1 } \cdot X = X \) for all Dedekind cuts \(X \in \R \text{.}\)
      🔗
      🔗
    • Multiplicative inverses.
      For all Dedekind cuts \(X \in \R \text{,}\) if \(X \neq X_{ 0 } \text{,}\) then there is a Dedekind cut \(X^{ -1 } \in \R \) so that \(X \cdot X^{ -1 } = X^{ -1 } \cdot X = X_{ 1 } \text{.}\)
      🔗
      🔗
    • Distributivity of multiplication over addition.
      For all Dedekind cuts \(X , Y , Z \in \R \text{,}\) both
      \begin{equation*} X \cdot \of{ Y + Z } = \of{ X \cdot Y } + \of{ X \cdot Z } \end{equation*}
      and
      \begin{equation*} \of{ X + Y } \cdot Z = \of{ X \cdot Z } + \of{ Y \cdot Z }\text{.} \end{equation*}
      🔗
      🔗
    • Compatibility of addition and the standard order.
      For all Dedekind cuts \(W , X , Y , Z \in \R \text{,}\) if \(W \subseteq Y \) and \(X \subseteq Z \text{,}\) then \(W + X \subseteq Y + Z \text{.}\)
      🔗
      🔗
    • Compatibility of multiplication and the standard order.
      For all Dedekind cuts \(X , Y \in \R \text{,}\) if \(X \) and \(Y \) are non-negative, then so too is their product \(X \cdot Y \text{.}\)
      🔗
      🔗
    🔗
    🔗
    All of the above properties of the arithmetic of Dedekind cuts not involving multiplication have already been proven. Again, we highlight that while proofs of the remaining parts are not too difficult to construct, they rely on significant casework involving signs; we unfortunately don’t have time to study these proofs in detail.
    🔗
