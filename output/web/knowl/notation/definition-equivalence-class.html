Definition 1.4.16. Equivalence class; quotient set.

Let \(\equiv \) be an equivalence relation on a set \(X \text{.}\)
  1. Equivalence class.
    The equivalence class \(\class{ x }_{ \equiv } \) of an element \(x \in X \) is the subset of \(X \) defined by
    \begin{equation*} \class{ x }_{ \equiv } = \setmid{ y \in X }{ x \equiv y }\text{;} \end{equation*}
    that is, \(\class{ x }_{ \equiv } \) is the set of elements which are equivalent to \(x \) under the relation \(\equiv \text{.}\)
    🔗
    🔗
  2. Quotient.
    The quotient \(X / { \equiv } \) of \(X \) by \(\equiv \) is the set of equivalence classes; that is,
    \begin{equation*} X / { \equiv } = \setmid{ \class{ x }_{ \equiv } \in \ps \of{ X } }{ x \in X }\text{.} \end{equation*}
    The quotient map \(\pi_{ \equiv } \colon X \to X / { \equiv } \) is the map from \(X \) to the quotient \(X / { \sim } \) defined by the formula \(\pi_{ \equiv } \of{ x } = \class{ x }_{ \equiv } \text{.}\)
    🔗
    If the set \(X \) is equipped with additional structure, then this structure might also descend to the quotient \(X / { \equiv } \text{.}\) In settings in which this is possible, we might distinguish between the quotient set \(X / { \equiv } \) and more structured quotient objects.
