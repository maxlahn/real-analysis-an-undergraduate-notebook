Convention 1.1.1. Roster notation.

It’s easy to completely describe a set which contains only a finite number of elements; we can simply write a list of those elements down! Concretely, if \(X \) is the set whose elements are precisely the objects \(x_{ 1 } , \dotsc , x_{ n } \text{,}\) then we may write
\begin{equation*} X = \set{ x_{ 1 } , \dotsc , x_{ n } } . \end{equation*}
The above notation for specifying sets is called roster notation.
🔗
Not all sets are finite, however, and it is obviously impossible to write down a complete roster of all of the elements of an infinite set. We can carefully use ellipses to indicate a set with an infinite roster whose elements follow some discernible pattern. For example, we will see in Section 1.3 Peano Arithmetic and the Natural Numbers [Skip] that the set \(\N \) of natural numbers can be written
\begin{equation*} \N = \set{ 0 , 1 , 2 , 3 , \dotsc }\text{.} \end{equation*}
Unfortunately, this extension of roster notation still does not suffice for all sets. For example, we will see in Section 1.6 Cardinality and Countability [SKIP] that there is no such roster for the set \(\R \) of real numbers.
