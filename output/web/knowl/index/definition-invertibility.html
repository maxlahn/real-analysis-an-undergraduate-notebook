Definition 1.2.11. Invertibility.

Let \(f \colon X \to Y \) be a map from a set \(X \) to a set \(Y \text{.}\)
  1. Left-invertibility.
    A map \(g \colon Y \to X \) from \(Y \) to \(X \) is a left inverse to \(f \) if \(g \circ f = \id_{ X } \text{.}\) \(f \) is called left-invertible if such a left inverse exists.
    🔗
    🔗
  2. Right-invertibility.
    A map \(g \colon Y \to X \) from \(Y \) to \(X \) is a right inverse to \(f \) if \(f \circ g = \id_{ Y } \text{.}\) \(f \) is called right-invertible if such a right inverse exists.
    🔗
    🔗
  3. Invertibility.
    A map \(g \colon Y \to X \) from \(Y \) to \(X \) is an inverse to \(f \) if it is both a left inverse and a right inverse to \(f \text{;}\) that is, \(g \) is an inverse to \(f \) if both \(g \circ f = \id_{ X } \) and \(f \circ g = \id_{ Y } \text{.}\) \(f \) is called invertible if such an inverse exists.
