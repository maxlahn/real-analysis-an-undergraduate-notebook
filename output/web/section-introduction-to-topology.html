    Section 4.1 Introduction to Topology

    In the previous chapter, we used the distance function on a metric space to provide a quantitative measure of how close two points were to each other. In this chapter, we will see that we can relax this to a more qualitative notion of closeness and still construct many of the point-set topological concepts defined for metric spaces. In particular, many of the definitions of the previous chapter can be equivalently defined in terms of open neighborhoods.
    🔗

    Subsection 4.1.1 Examples of Topologies

    A topology on a set is just a designation of open subsets, which are required to satisfy some of the important properties of open sets in metric spaces. Specifically, besides some non-degeneracy requirements, the collection of open sets in a topological space is required to be stable under arbitrary unions and finite intersections.
    🔗

    Definition 4.1.1. Topology.

    A collection \(\tau \subseteq \ps \of{ X } \) of subsets of a set \(X \text{,}\) which is called the ground set or underlying set and whose elements are called points, is called a topology on \(\ps \of{ X } \text{,}\) and its elements are called open, if it satisfies the following conditions:
    • Non-degeneracy.
      The empty set \(\emptyset \in \tau \) and the ground set \(X \) are open.
      🔗
      🔗
    • \(\cup \)-stability.
      For any indexed family \(\of{ U_{ j } }_{ j \in \mathcal{ J } } \) of open sets \(U_{ j } \in \tau \text{,}\) the union
      \begin{equation*} \bigcup_{ j \in \mathcal{ J } }{ U_{ j } } \in \tau \end{equation*}
      is open.
      🔗
      🔗
    • Finite \(\cap \)-stability.
      For any finite sequence \(\of{ U_{ j } }_{ j = 1 }^{ m } \) of open sets \(U_{ j } \in \tau \text{,}\) the intersection
      \begin{equation*} \bigcap_{ j = 1 }^{ m }{ U_{ j } } \in \tau \end{equation*}
      is open.
      🔗
      🔗
    In this case, the ordered pair \(\of{ X , \tau } \) is called a topological space.
    🔗
    🔗

    Example 4.1.2. Topological spaces.

    The following are examples of topological spaces:
    • Discrete topology.
      For any set \(X \text{,}\) the power set \(\ps \of{ X } \) of \(X \) is a topology on \(X \text{.}\) Considered in this context, \(\ps \of{ X } \) is called the discrete topology on \(X \) and is denoted \(\top_{ X } \text{.}\) The topological space \(\of{ X , \top_{ X } } \) is called a discrete (topological) space.
      🔗
      🔗
    • Indiscrete topology.
      For any set \(X \text{,}\) the set \(\bot_{ X } = \set{ \emptyset , X } \) is a topology on \(X \) called the discrete topology on \(X \text{.}\) The topological space \(\of{ X , \bot_{ X } } \) is called an indiscrete (topological) space.
      🔗
      🔗
    • Sierpiński space.
      The Sierpiński space is the topological space \(\of{ X , \tau } \) with ground set \(X = \set{ 0 , 1 } \) and topology \(\tau = \set{ \emptyset , \set{ 1 } , \set{ 0 , 1 } } \text{.}\) This topological space is a well-known simple counterexample to many false statements about topological spaces that feel true intuitively.
      🔗
      🔗
    🔗
    🔗

    Remark 4.1.3. Implied topologies.

    We will see that in general, there many topologies on a given set, no one of which can truly be considered canonical. However, sometimes if a topology \(\tau \) on a set \(X \) is clear from context, previously specified, or otherwise implied, some mathematicians will refer to the topological space \(\of{ X , \tau } \) by only the underlying set \(X \text{.}\)
    🔗
    🔗
    At the beginning of Chapter 3 Metric Spaces, we saw how some structures on a ground set induce others in a canonical way. For example, we saw that an inner product on a real or complex vector space induces a norm on that vector space, and that a norm on such a vector space induces a metric on the underlying set. In this way, we viewed an inner product space as a special kind of normed vector space and a normed vector space as a special kind of metric space. Similarly, we will now see that, in a metric space, the metric induces a topology on the ground set in a canonical way, so that we may view a metric space as a special kind of topological space.
    🔗

    Definition 4.1.4. Metric topology.

    The metric topology \(\tau_{ \rho } \) induced on a set \(X \) by a metric \(\rho \colon X \times X \to \R \) on \(X \) is the collection of open subsets in \(X \text{.}\) That \(\tau_{ \rho } \) is a topology on \(X \) follows immediately from (1), (2), and (4) of Proposition 3.4.10 Topology of a metric space.
    🔗
    A topology \(\tau \) on a set \(X \) is called metrizable if it is the metric topology induced by a metric on \(X \text{,}\) and non-metrizable otherwise. A topological space \(\of{ X , \tau } \) is called metrizable (resp. non-metrizable) if the topology is metrizable (resp. non-metrizable).
    🔗
    🔗

    Example 4.1.5. Metric topologies.

    The following are examples of metrizable and non-metrizable topologies:
    • The Euclidean topology \(\tau_{ d } \) on \(n \)-dimensional real coordinate space \(\R^{ n } \) is the metric topology induced by the Euclidean metric \(d \colon \R^{ n } \times \R^{ n } \to \R \text{.}\) This topology is also called the standard topology or the usual topology on \(\R^{ n } \text{.}\)
      🔗
      🔗
    • The discrete topology \(\top_{ X } \) on a set \(X \) is the metric topology induced by the discrete metric \(\delta_{ X } \colon X \times X \to \R \text{.}\) In particular, any discrete topological space is metrizable.
      🔗
      🔗
    • On the other hand, the indiscrete topology \(\bot_{ X } \) is non-metrizable unless \(\card{ X } \leq 1 \text{,}\) in which case \(\bot_{ X } = \top_{ X } \text{.}\)
      🔗
      🔗
    • The Sierpiński space \(\of{ \set{ 0 , 1 } , \set{ \emptyset , \set{ 1 } , \set{ 0 , 1 } } } \) is non-metrizable; that is, the topology \(\set{ \emptyset , \set{ 1 } , \set{ 0 , 1 } } \) is not induced on the ground set \(\set{ 0 , 1 } \) by any metric. More generally, a finite topological space is metrizable if and only if it is discrete.
      🔗
      🔗
    🔗
    🔗
    The above definition shows that we actually are already familiar with a special class of topological spaces; just as a metric space hides inside any normed vector space, so too does a topological space hide inside any metric space. However, as shown in the last two examples above, not every topological space arises in this manner. Moreover, there is in general no unique metric which induces a topology on a metrizable topological space; for example, any positive scalar multiple a metric induces the same topology on the underlying set.
    🔗
    In the same way that a metric induces a metric on any subset of its underlying set, a topology on a set induces a topology on any subset of its underlying set. For metric spaces, this subspace construction is a simple restriction of the metric to a subset of its domain. There is a similar, but slightly more intricate construction for topological spaces.
    🔗

    Lemma 4.1.6. Subspace topology.

    Fix a subset \(U \subseteq X \) of a topological space \(\of{ X , \tau } \text{.}\) Then the collection
    \begin{equation*} \setmid{ U \cap V \in \ps \of{ X } }{ V \in \tau } \end{equation*}
    is a topology on \(U \text{.}\)
    🔗
    🔗

    Proof.
    Denote by \(\tau' \) the collection
    \begin{equation*} \tau' = \setmid{ U \cap V \in \ps \of{ X } }{ V \in \tau }\text{.} \end{equation*}
    Since \(\tau \) is non-degenerate, \(\emptyset , X \in \tau \) are open in \(X \text{,}\) and so
    \begin{equation*} \emptyset = U \cap \emptyset \in \tau' \end{equation*}
    and
    \begin{equation*} U = U \cap X \in \tau'\text{;} \end{equation*}
    that is, \(\tau' \) is non-degenerate.
    🔗
    Now consider an indexed family \(\of{ W_{ j } }_{ j \in \mathcal{ J } } \) of sets \(W_{ j } \in \tau' \text{.}\) Then for each index \(j \in \mathcal{ J } \text{,}\) \(W_{ j } = U \cap V_{ j } \) for some open set \(V_{ j } \in \tau \) in \(X \text{.}\) Since \(\tau \) is stable under unions,
    \begin{equation*} \bigcup_{ j \in \mathcal{ J } }{ V_{ j } } \in \tau \end{equation*}
    is open in \(X \text{,}\) and so
    \begin{equation*} \bigcup_{ j \in \mathcal{ J } }{ W_{ j } } = \bigcup_{ j \in \mathcal{ J } }{ \of{ U \cap V_{ j } } } = U \cap \bigcup_{ j \in \mathcal{ J } }{ V_{ j } } \in \tau'\text{;} \end{equation*}
    that is, \(\tau' \) is stable under unions.
    🔗
    Finally, consider a finite sequence \(\of{ W_{ j } }_{ j = 1 }^{ m } \) of sets \(W_{ j } \in \tau' \text{.}\) Then for each index \(1 \leq j \leq m \text{,}\) \(W_{ j } = U \cap V_{ j } \) for some open set \(V_{ j } \in \tau \) in \(X \text{.}\) Since \(\tau \) is stable under finite intersections,
    \begin{equation*} \bigcap_{ j = 1 }^{ m }{ V_{ j } } \in \tau \end{equation*}
    is open in \(X \text{,}\) and so
    \begin{equation*} \bigcap_{ j = 1 }^{ m }{ W_{ j } } = \bigcap_{ j = 1 }^{ m }{ \of{ U \cap V_{ j } } } = U \cap \bigcap_{ j = 1 }^{ m }{ V_{ j } } \in \tau'\text{;} \end{equation*}
    that is, \(\tau' \) is stable under finite intersections.
    🔗
    Since \(\tau' \) is non-degenerate, stable under unions, and stable under finite intersections, it is a topology on \(U \text{.}\)
    🔗
    🔗

    Definition 4.1.7. Subspace topology.

    The subspace topology \(\rest{ \tau }_{ U } \) induced on a subset \(U \subseteq X \) of a topological space \(\of{ X , \tau } \) is the collection
    \begin{equation*} \rest{ \tau }_{ U } = \setmid{ U \cap V \in \ps \of{ X } }{ V \in \tau }\text{.} \end{equation*}
    This collection \(\rest{ \tau }_{ U } \) is a topology on \(U \) by Lemma 4.1.6 Subspace topology, and the topological space \(\of{ U , \rest{ \tau }_{ U } } \) is called a (topological) subspace of \(\of{ X , \tau } \text{.}\)
    🔗
    🔗
    It turns out that this notion of the restriction of a topology to a subspace is compatible with the restriction of a metric to a subspace. That is, the restriction of a metric topology is precisely the metric topology induced by the restriction of that metric to that subset.
    🔗

    Lemma 4.1.8. Topological subspaces of metric spaces.

    Let \(U \subseteq X \) be a subset of a metric space \(\of{ X , \rho } \text{.}\) Then \(\rest{ \tau_{ \rho } }_{ U } = \tau_{ \rest{ \rho }_{ U } } \text{.}\)
    🔗
    🔗

    Proof.
    Part (a) of Problem 3.4.5.1 Open and closed sets in metric subspaces implies that a subset \(V \subseteq U \) is open in \(U \) if and only if \(V = U \cap W \) for some open subset \(W \subseteq X \text{;}\) that is, \(V \in \tau_{ \rest{ \rho }_{ U } } \) if and only if \(V = U \cap W \) for some \(W \in \tau_{ \rho } \text{.}\) We conclude that \(\tau_{ \rest{ \rho }_{ U } } = \rest{ \tau_{ \rho } }_{ U } \text{.}\)
    🔗
    🔗
    One consequence of Lemma 4.1.8 Topological subspaces of metric spaces is that metric subspaces are topological subspaces. Just as with metric subspaces, we will often abuse notation and refer to a subspace topology with the same notation as the original topology, so that we may speak of a topological subspace \(\of{ U , \tau } \) of a topological space \(\of{ X , \tau } \text{;}\) here we really mean \(\of{ U , \rest{ \tau }_{ U } } \text{.}\)
    🔗
    🔗

    Subsection 4.1.2 Algebra of Open and Closed Sets

    The topology in a topological space elevates certain subsets of the ground set as open. In an analogous manner to our definition of closedness for subsets of a metric space, a subset of a topological space is called closed if and only if its complement is open.
    🔗

    Definition 4.1.9. Closed subset.

    A subset \(U \subseteq X \) of a topological space \(\of{ X , \tau } \) is called closed in \(X \) if its complement \(X \setminus U \in \tau \) is open in \(X \text{.}\)
    🔗
    🔗
    The defining properties of a topology impose constraints on the set of closed subsets of a topological space.
    🔗

    Lemma 4.1.10. Closed subsets of a topological space.

    Let \(\of{ X , \tau } \) be a topological space.
    1. The empty set \(\emptyset \) and the ground set \(X \) are closed in \(X \text{.}\)
      🔗
      🔗
    2. For any indexed family \(\of{ U_{ j } }_{ j \in \mathcal{ J } } \) of closed sets \(U_{ j } \) in \(X \text{,}\) the intersection
      \begin{equation*} \bigcap_{ j \in \mathcal{ J } }{ U_{ j } } \end{equation*}
      is closed in \(X \text{.}\)
      🔗
      🔗
    3. For any finite sequence \(\of{ U_{ j } }_{ j = 1 }^{ m } \) of closed sets \(U_{ j } \) in \(X \text{,}\) the union
      \begin{equation*} \bigcup_{ j = 1 }^{ m }{ U_{ j } } \end{equation*}
      is closed in \(X \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. The non-degeneracy of the topology \(\tau \) implies that \(\emptyset , X \in \tau \) are open in \(X \text{,}\) and so their complements \(\emptyset = X \setminus X \) and \(X = X \setminus \emptyset \) are closed in \(X \text{.}\)
      🔗
      🔗
    2. For each index \(j \in \mathcal{ J } \text{,}\) \(U_{ j } = X \setminus V_{ j } \) for some open subset \(V_{ j } \in \tau \text{.}\) The stability of the topology \(\tau \) under unions implies that
      \begin{equation*} \bigcup_{ j \in \mathcal{ J } }{ V_{ j } } \in \tau \end{equation*}
      is open in \(X \text{,}\) and so
      \begin{equation*} \bigcap_{ j \in \mathcal{ J } }{ U_{ j } } = \bigcap_{ j \in \mathcal{ J } }{ \of{ X \setminus V_{ j } } } = X \setminus \bigcup_{ j \in \mathcal{ J } }{ V_{ j } } \end{equation*}
      is closed in \(X \text{.}\)
      🔗
      🔗
    3. For each index \(1 \leq j \leq m \text{,}\) \(U_{ j } = X \setminus V_{ j } \) for some open subset \(V_{ j } \in \tau \text{.}\) The stability of the topology \(\tau \) under finite intersections implies that
      \begin{equation*} \bigcap_{ j = 1 }^{ m }{ V_{ j } } \in \tau \end{equation*}
      is open in \(X \text{,}\) and so
      \begin{equation*} \bigcup_{ j = 1 }^{ m }{ U_{ j } } = \bigcup_{ j = 1 }^{ m }{ \of{ X \setminus V_{ j } } } = X \setminus \bigcap_{ j = 1 }^{ m }{ V_{ j } } \end{equation*}
      is closed in \(X \text{.}\)
      🔗
      🔗
    🔗
    There is also a natural generalization of the notion of neighborhoods to the setting of topological spaces. Rather than requiring a neighborhood of a point in a topological space to contain an open ball centered around that point, we require that it contain some open subset which contains the point.
    🔗

    Definition 4.1.11. Neighborhood.

    A subset \(N \subseteq X \) of a topological space \(\of{ X , \tau } \) is called a neighborhood of a point \(x \in X \) in \(X \) if \(x \in U \subseteq N \) for some open set \(U \in \tau \) in \(X \text{.}\) The set of neighborhoods of \(x \) in \(X \) is variously denoted \(\Nbhd \of{ x } \text{,}\) \(\Nbhd_{ X } \of{ x } \text{,}\) and/or \(\Nbhd_{ \of{ X , \tau } } \of{ x } \text{,}\) depending on which information is clear from context.
    🔗
    🔗

    Example 4.1.12. Neighborhoods.

    Recall that the Sierpiński space \(\of{ X , \tau } \) is the topological space with ground set \(X = \set{ 0 , 1 } \) and topology \(\tau = \set{ \emptyset , \set{ 1 } , \set{ 0 , 1 } } \text{.}\) Thus \(X = \set{ 0 , 1 } \) is the only neighborhood of the point \(0 \text{,}\) but \(\set{ 1 } \) and \(\set{ 0 , 1 } \) are neighborhoods of the point \(1 \text{;}\) that is,
    \begin{align*} \Nbhd \of{ 0 } \amp = \set{ \set{ 0 , 1 } } \amp \Nbhd \of{ 1 } = \set{ \set{ 1 } , \set{ 0 , 1 } } \end{align*}
    🔗
    🔗
    Just as in a metric space, we will interpret the relationship of between a point in a topological space and a neighborhood to mean that the neighborhood contains all points which are “close enough” to that point. In a metric space, this notion of nearness for points can be quantifiably determined. In a topological space, however, we will use the concept of neighborhoods introduced above to obtain qualitative measures of closeness for points: two points are considered to be “close” in a topological space if many neighborhoods of one point also contain the other point.
    🔗
    The cognitive metaphor described above is called locality. For example, a point-set topological property can be said to hold locally if any point in the topological space has a neighborhood on which that property holds. Similarly, the local properties of a topological space are those which involve the existence of neighborhoods around any given point which satisfy certain conditions. These local properties of a topological space can be contrasted with its global properties, which hold on its entire ground set. For example, we will later see manifolds to witness strong local properties while having incredibly large variability in their global properties. We will see several examples of local properties, such as continuity, in the remainder of our investigation of topological spaces.
    🔗
    In many ways, the concept of topological spaces was created exactly to formalize the most general setting in which locality can be considered even in the absence of a metric to provide a quantitative measure of nearness for points. Because of the definition of the metric topology induced by a metric on its ground set, these notions of metric and topological locality coincide for metric topological spaces. That is, a metric space and its associated metric topological space have the same neighborhoods. This also implies that all notions in the context of metric spaces defined solely on neighborhoods can be reliably generalized to the context of topological spaces. In particular, we can use neighborhoods to define the interior, closure, and boundary of a subset of a topological space.
    🔗

    Definition 4.1.13. Interior; closure; boundary.

    Let \(U \subseteq X \) be a subset of a topological space \(\of{ X , \tau } \text{.}\)
    • Interior.
      A point \(x \in X \) is an interior point of \(U \) if \(U \in \Nbhd_{ X } \of{ x } \) is a neighborhood of \(x \) in \(X \text{.}\) The set of interior points of \(U \) is called the interior of \(U \) and is denoted \(\Int \of{ U } \) or \(U^{ \circ } \text{.}\)
      🔗
      🔗
    • Closure.
      A point \(x \in X \) is a point of closure of \(U \) in \(X \) if every neighborhood of \(x \) in \(X \) meets \(U \text{;}\) that is, \(x \) is a point of closure of \(U \) in \(X \) if \(N \cap U \neq \emptyset \) for any neighborhood \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \text{.}\) The set of points of closure of \(U \) in \(X \) is called the closure of \(U \) in \(X \) and is denoted \(\Cl \of{ U } \) or \(\overline{ U } \text{.}\)
      🔗
      🔗
    • Boundary.
      A point \(x \in X \) is a boundary point of \(U \) in \(X \) if every neighborhood of \(x \) in \(X \) meets both \(U \) and its complement \(X \setminus U \text{;}\) that is, \(x \) is a boundary point of \(U \) in \(X \) if \(N \cap U \neq \emptyset \) and \(N \setminus U \neq \emptyset \) for any neighborhood \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \text{.}\) The set of boundary points of \(U \) in \(X \) is called the boundary of \(U \) in \(X \) and is denoted \(\Bd \of{ U } \) or \(\partial U \text{.}\)
      🔗
      🔗
    🔗
    🔗
    That the above definitions are phrased in terms of neighborhoods implies that many of the related results in the setting of metric spaces also hold for topological spaces in general. Even better, the proofs of these results for metric spaces can easily be altered to construct proofs of their generalizations.
    🔗

    Theorem 4.1.14. Interior; closure; boundary.

    Let \(U \) be a subset of a metric space \(\of{ X , \tau } \text{.}\)
    1. Interior.
      \(U \) is open in \(X \) if and only if \(\Int \of{ U } = U \text{.}\) More generally, \(U \) has interior
      \begin{equation*} \Int \of{ U } = \bigcup_{ V \in \mathcal{ O }_{ U } }{ V } = X \setminus \Cl \of{ X \setminus U }\text{,} \end{equation*}
      where \(\mathcal{ O }_{ U } \) is the collection of open sets in \(X \) which are contained in \(U \text{.}\) Finally, \(\Int \of{ \Int \of{ U } } = \Int \of{ U } \text{.}\)
      🔗
      🔗
    2. Closure.
      \(U \) is closed in \(X \) if and only if \(\Cl \of{ U } = U \text{.}\) More generally, \(U \) has closure
      \begin{equation*} \Cl \of{ U } = \bigcap_{ V \in \mathcal{ C }_{ U } }{ V } = X \setminus \Int \of{ X \setminus U }\text{,} \end{equation*}
      where \(\mathcal{ C }_{ U } \) is the collection of closed sets in \(X \) which contain \(U \text{.}\) Finally, \(\Cl \of{ \Cl \of{ U } } = \Cl \of{ U } \text{.}\)
      🔗
      🔗
    3. Boundary.
      \(U \) has boundary \(\Bd \of{ U } = \Cl \of{ U } \cap \Cl \of{ X \setminus U } \text{.}\)
      🔗
      🔗
    🔗
    🔗
    The proof of Theorem 4.1.14 Interior; closure; boundary is nearly identical to the proofs of Proposition 3.4.9 Interior/closure, Proposition 3.4.9 Interior/closure, Theorem 3.4.11 Interior/closure, and Corollary 3.4.12 Idempotence of interior/closure and the solution to Problem 3.4.5.2 Interior, closure, and boundary of complements, and so it is left to the reader.
