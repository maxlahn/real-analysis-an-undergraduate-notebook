    Section 6.3 Improper Integration

    In this section, we expand the kinds of functions we consider as the integrands of Riemann integrals. Thus far, we have only allowed Riemann integrals of the form
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } }\text{,} \end{equation*}
    where \(f \colon \clint{ a }{ b } \to \R \) is a Riemann integrable (and therefore bounded) function defined on a closed interval. In this section, we relax both of these conditions while maintaining a grasp on some of the nice properties of the theory of Riemann integration.
    🔗

    Subsection 6.3.1 Exhaustion by Compact Intervals

    We begin with an example that illustrates the dangers of integrating real-valued functions on larger and larger compact intervals: we may lose coherent interpretations of such integrals in the limit.
    🔗

    Example 6.3.1. Subtlety of improper integration.

    Consider the real-valued function \(f \colon \R \to \R \) defined by the formula \(f \of{ x } = x \text{.}\) Then the Second fundamental theorem of calculus implies that
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \frac{ b^{ 2 } }{ 2 } - \frac{ a^{ 2 } }{ 2 } = \frac{ b^{ 2 } - a^{ 2 } }{ 2 } \end{equation*}
    for all real numbers \(-\infty \lt a \leq b \lt \infty \text{.}\) In particular, we observe that
    \begin{equation*} \lim_{ b \to \infty }{ \int_{ -b }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ b \to \infty }{ \frac{ b^{ 2 } - \of{ -b }^{ 2 } }{ 2 } } = \lim_{ b \to \infty }{ 0 } = 0 \end{equation*}
    but
    \begin{align*} \lim_{ b \to \infty }{ \int_{ 1 - b }^{ 1 + b }{ f \of{ x } \, \diff{ x } } } \amp = \lim_{ b \to \infty }{ \frac{ \of{ 1 + b }^{ 2 } - \of{ 1 - b }^{ 2 } }{ 2 } }\\ \amp = \lim_{ b \to \infty }{ \frac{ 1 + 2 b + b^{ 2 } - 1 + 2 b - b^{ 2 } }{ 2 } } = \lim_{ b \to \infty }{ \frac{ 4 b }{ 2 } }\\ \amp = \lim_{ b \to \infty }{ 2 b } = \infty\text{,} \end{align*}
    and
    \begin{align*} \lim_{ b \to \infty }{ \int_{ -1 - b }^{ -1 + b }{ f \of{ x } \, \diff{ x } } } \amp = \lim_{ b \to \infty }{ \frac{ \of{ -1 + b }^{ 2 } - \of{ -1 - b }^{ 2 } }{ 2 } }\\ \amp = \lim_{ b \to \infty }{ \frac{ 1 - 2 b + b^{ 2 } - 1 - 2 b - b^{ 2 } }{ 2 } } = \lim_{ b \to \infty }{ -\frac{ 4 b }{ 2 } }\\ \amp = \lim_{ b \to \infty }{ -2 b } = -\infty\text{.} \end{align*}
    This example serves to complicate what precisely is meant by the improper integral \(\int_{ -\infty }^{ \infty }{ f \of{ x } \, \diff{ x } } \text{.}\)
    🔗
    🔗
    Specifically, performing a Riemann integration on a non-compact interval will require additional care to ensure that said integral converges in a specific way. As in the case of Riemann integrals on compact intervals, we use nets to define the relevant mode of convergence.
    🔗

    Lemma 6.3.2. Compact subintervals are directed.

    For any interval \(X \subseteq \R \text{,}\) the set \(\mathcal{ K }_{ X } \) of all compact subintervals of the interior \(\Int \of{ X } \) is directed upwards.
    🔗
    🔗

    Proof.
    Let \(U , V \in \mathcal{ K }_{ X } \) be two compact subintervals of the interior \(\Int \of{ X } \text{.}\) Then \(U = \clint{ a }{ b } \) and \(V = \clint{ c }{ d } \) for some real numbers \(a , b , c , d \in \R \) so that \(a \leq b \) and \(c \leq d \text{.}\) Let
    \begin{equation*} W = \clint{ \min \of{ \set{ a , c } } }{ \max \of{ \set{ b , d } } }\text{.} \end{equation*}
    We observe that \(\min \of{ \set{ a , c } } \in \Int \of{ X } \) and \(\max \of{ \set{ b , d } } \in \Int \of{ X } \text{.}\) Since \(X \) is an interval, so too is \(\Int \of{ X } \text{.}\) We conclude that \(W \subseteq \Int \of{ X } \text{,}\) and so \(W \in \mathcal{ K }_{ X } \text{.}\) Of course \(U , V \subseteq W \text{.}\) Since every pair of elements of \(\mathcal{ K }_{ X } \) has a common upper bound, \(\mathcal{ K }_{ X } \) is directed upwards.
    🔗
    🔗
    The improper Riemann integrability of a real-valued function will be defined in terms of the convergence of certain nets of Riemann integrals defined on compact intervals. These nets will factor through the above directed set, and will be called interior exhaustions by compact subintervals.
    🔗

    Definition 6.3.3. Interior exhaustion by compact subintervals.

    Let \(\mathcal{ K }_{ X } \) be the directed set of compact subintervals of the interior \(\Int \of{ X } \) of an interval \(X \subseteq \R \text{.}\) A family \(\of{ K_{ \alpha } }_{ \alpha \in A } \) of such compact subintervals \(K_{ \alpha } \in \mathcal{ K }_{ X } \) indexed by an upwards directed set \(\of{ A , \preceq } \) is called an interior exhaustion of \(X \) by compact intervals if it is order-preserving and
    \begin{equation*} \Int \of{ X } = \bigcup_{ \alpha \in A }{ K_{ \alpha } }\text{.} \end{equation*}
    🔗
    🔗

    Lemma 6.3.4. Interior exhaustion by compact subintervals.

    Let \(\of{ K_{ \alpha } }_{ \alpha \in A } \) be a family of compact subintervals \(K_{ \alpha } \in \mathcal{ K }_{ X } \) of an interval \(X \subseteq \R \) indexed by an upwards directed set \(\of{ A , \preceq } \text{.}\) For each index \(\alpha \in A \text{,}\) write \(K_{ \alpha } = \clint{ a_{ \alpha } }{ b_{ \alpha } } \) for some real numbers \(-\infty \lt a_{ \alpha } \leq b_{ \alpha } \lt \infty \text{.}\)
    🔗
    Then \(\of{ K_{ \alpha } }_{ \alpha \in A } \) is an interior exhaustion of \(X \) by compact subintervals if and only if it satisfies the following conditions:
    1. For all indices \(\alpha , \beta \in A \text{,}\) if \(\alpha \preceq \beta \text{,}\) then \(a_{ \alpha } \geq a_{ \beta } \) and \(b_{ \alpha } \leq b_{ \beta } \text{.}\)
      🔗
      🔗
    2. The nets \(\of{ a_{ \alpha } }_{ \alpha \in A } \) and \(\of{ b_{ \alpha } }_{ \alpha \in A } \) have upwards limits
      \begin{align*} \lim_{ \alpha \uparrow }{ a_{ \alpha } } \amp = \inf \of{ X } \amp \lim_{ \alpha \uparrow }{ b_{ \alpha } } \amp = \sup \of{ X }\text{.} \end{align*}
      🔗
      🔗
    🔗
    🔗
    You will have an opportunity to prove Lemma 6.3.4 Interior exhaustion by compact subintervals in the problems for this section. One consequence is that Riemann integrals of integrable functions defined on compact intervals are limits of Riemann integrals on exhaustions by compact subintervals.
    🔗

    Proposition 6.3.5. Improper integrals on compact intervals.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\) If \(f \) is integrable, then
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \lim_{ \alpha \uparrow }{ \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } \end{equation*}
    for any interior exhaustion \(\of{ \clint{ a_{ \alpha } }{ b_{ \alpha } } }_{ \alpha \in A } \) of \(\clint{ a }{ b } \) by compact subintervals \(\clint{ a_{ \alpha } }{ b_{ \alpha } } \in \mathcal{ K }_{ \clint{ a }{ b } } \text{.}\)
    🔗
    🔗

    Proof.
    Since \(f \) is integrable, it is bounded, and so there is some positive real number \(B \gt 0 \) so that \(\abs{ f \of{ x } } \leq B \) for all points \(a \leq x \leq b \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Then Lemma 6.3.4 Interior exhaustion by compact subintervals implies that there is an index \(\alpha_{ \epsilon } \in A \) so that \(a_{ \alpha_{ \epsilon } } \lt a + \frac{ \epsilon }{ 2 B } \) and \(b_{ \alpha_{ \epsilon } } \gt b - \frac{ \epsilon }{ 2 B } \text{.}\) We observe that
    \begin{align*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } \amp = \abs{ \int_{ a }^{ a_{ \alpha } }{ f \of{ x } \, \diff{ x } } + \int_{ b_{ \alpha } }^{ b }{ f \of{ x } \, \diff{ x } } }\\ \amp \leq \abs{ \int_{ a }^{ a_{ \alpha } }{ f \of{ x } \, \diff{ x } } } + \abs{ \int_{ b_{ \alpha } }^{ b }{ f \of{ x } \, \diff{ x } } }\\ \amp \leq \int_{ a }^{ a_{ \alpha } }{ \abs{ f \of{ x } } \, \diff{ x } } + \int_{ b_{ \alpha } }^{ b }{ \abs{ f \of{ x } } \, \diff{ x } }\\ \amp \leq \int_{ a }^{ a_{ \alpha } }{ B \, \diff{ x } } + \int_{ b_{ \alpha } }^{ b }{ B \, \diff{ x } }\\ \amp \leq B \of{ a_{ \alpha } - a } + B \of{ b - b_{ \alpha } }\\ \amp \leq B \of{ a_{ \alpha_{ \epsilon } } - a } + B \of{ b - b_{ \alpha_{ \epsilon } } }\\ \amp \lt B \of{ \frac{ \epsilon }{ 2 B } } + B \of{ \frac{ \epsilon }{ 2 B } } = \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
    for all indices \(\alpha \succeq \alpha_{ \epsilon } \text{.}\) Thus
    \begin{equation*} \lim_{ \alpha \uparrow }{ \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Proposition 6.3.6. Riemann integrals and interior exhaustions.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \text{,}\) and suppose that the restriction of \(f \) to any compact subinterval of the interior \(\Int \of{ X } \) is integrable. Then for any real number \(I \in \R \text{,}\) the following are equivalent:
    1. For any interior exhaustion \(\of{ \clint{ a_{ \alpha } }{ b_{ \alpha } } }_{ \alpha \in A } \) of \(X \) by compact subintervals,
      \begin{equation*} \lim_{ \alpha \uparrow }{ \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } = I \end{equation*}
      🔗
      🔗
    2. For any positive real number \(\epsilon \text{,}\) there is a compact subinterval \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \in \mathcal{ K }_{ X } \) of \(\Int \of{ X } \) so that
      \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \epsilon \end{equation*}
      for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    First suppose that
    \begin{equation*} \lim_{ \alpha \uparrow }{ \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } = I \end{equation*}
    for any interior exhaustion \(\of{ \clint{ a_{ \alpha } }{ b_{ \alpha } } }_{ \alpha \in A } \) of \(X \) by compact subintervals. Then in particular we may choose the maximal such interior exhaustion \(\of{ K }_{ K \in \mathcal{ K }_{ X } } \text{,}\) obtaining the convergence
    \begin{equation*} \lim_{ \clint{ a }{ b } \uparrow }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = I\text{.} \end{equation*}
    Thus for any positive real number \(\epsilon \gt 0 \text{,}\) there is a compact subinterval \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \in \mathcal{ K }_{ X } \) so that
    \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \epsilon \end{equation*}
    for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{.}\)
    🔗
    Conversely, now suppose that for any positive real number \(\epsilon \gt 0 \text{,}\) there is a compact subinterval \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \in \mathcal{ K }_{ X } \) so that
    \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \epsilon \end{equation*}
    for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{,}\) and let \(\of{ \clint{ a_{ \alpha } }{ b_{ \alpha } } }_{ \alpha \in A } \) be an interior exhaustion of \(X \) by compact intervals \(\clint{ a_{ \alpha } }{ b_{ \alpha } } \text{.}\) Lemma 6.3.4 Interior exhaustion by compact subintervals implies that there is an index \(\alpha_{ \epsilon } \in A \) so that
    \begin{equation*} \clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a_{ \alpha_{ \epsilon } } }{ b_{ \alpha_{ \epsilon } } } \subseteq \Int \of{ X }\text{.} \end{equation*}
    We observe that
    \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \epsilon \end{equation*}
    for all indices \(\alpha \succeq \alpha_{ \epsilon } \text{,}\) since in this case
    \begin{equation*} \clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a_{ \alpha_{ \epsilon } } }{ b_{ \alpha_{ \epsilon } } } \subseteq \clint{ a_{ \alpha } }{ b_{ \alpha } } \subseteq \Int \of{ X }\text{.} \end{equation*}
    We conclude that
    \begin{equation*} \lim_{ \alpha \uparrow }{ \int_{ a_{ \alpha } }^{ b_{ \alpha } }{ f \of{ x } \, \diff{ x } } } = I\text{.} \end{equation*}
    🔗
    🔗

    Definition 6.3.7. Improper Riemann integral.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \text{.}\) \(f \) is called improperly integrable if the restriction of \(f \) to any compact subinterval of the interior \(\Int \of{ X } \) is integrable, and there is a real number \(I \in \R \) which satisfies either (and therefore both) of the conditions in Proposition 6.3.6 Riemann integrals and interior exhaustions. In this case, that \(\R \) is Hausdorff implies that the number \(I \) is uniquely defined by these properties. This number \(I \) is called the improper Riemann integral of \(f \text{,}\) and is denoted
    \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Example 6.3.8. Improper Riemann integration.

    The following are examples and non-examples of improperly integrable functions and their improper Riemann integrals:
    • Let \(p \in \opint{ 0 }{ \infty } \setminus \set{ 1 } \) be a real number, and consider the function \(f \colon \clopint{ 1 }{ \infty } \) defined by the formula \(f \of{ x } = \frac{ 1 }{ x^{ p } } \text{.}\) We observe that
      \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \frac{ b^{ 1 - p } }{ 1 - p } - \frac{ a^{ 1 - p } }{ 1 - p } = \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } \end{equation*}
      for any compact subinterval \(\clint{ a }{ b } \subseteq \opint{ 1 }{ \infty } \text{.}\) We first note that if \(p \lt 1 \text{,}\) then \(1 - p \gt 0 \text{,}\) and so
      \begin{equation*} \lim_{ b \to \infty }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ b \to \infty }{ \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } } = \infty\text{.} \end{equation*}
      This implies that \(f \) is not improperly integrable in this case.
      🔗
      On the other hand, now suppose that \(p \gt 1 \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Fix real numbers \(1 \lt a_{ \epsilon } \leq b_{ \epsilon } \lt \infty \) so that
      \begin{align*} a_{ \epsilon } \amp \lt \of{ 1 - \frac{ \epsilon \of{ p - 1 } }{ 2 } }^{ \frac{ 1 }{ 1 - p } } \amp b_{ \epsilon } \gt \of{ \frac{ \epsilon \of{ p - 1 } }{ 2 } }^{ \frac{ 1 }{ 1 - p } }\text{.} \end{align*}
      We observe that
      \begin{align*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - \frac{ 1 }{ p - 1 } } \amp = \abs{ \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } + \frac{ 1 }{ 1 - p } } \leq \frac{ \abs{ b^{ 1 - p } } }{ p - 1 } + \frac{ \abs{ 1 - a^{ 1 - p } } }{ p - 1 }\\ \amp = \frac{ b^{ 1 - p } }{ p - 1 } + \frac{ 1 - a^{ 1 - p } }{ p - 1 } \leq \frac{ b_{ \epsilon }^{ 1 - p } }{ p - 1 } + \frac{ 1 - a_{ \epsilon }^{ 1 - p } }{ p - 1 }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
      for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subsetneq \opint{ 0 }{ \infty } \text{.}\) Thus \(f \) is improperly integrable, with improper Riemann integral
      \begin{equation*} \int_{ 1 }^{ \infty }{ f \of{ x } \, \diff{ x } } = \frac{ 1 }{ p - 1 }\text{.} \end{equation*}
      🔗
      🔗
    • Let \(p \in \opint{ 0 }{ \infty } \setminus \set{ 1 } \) be a real number, and consider the function \(f \colon \opclint{ 0 }{ 1 } \) defined by the formula \(f \of{ x } = \frac{ 1 }{ x^{ p } } \text{.}\) We observe that
      \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \frac{ b^{ 1 - p } }{ 1 - p } - \frac{ a^{ 1 - p } }{ 1 - p } = \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } \end{equation*}
      for any compact subinterval \(\clint{ a }{ b } \subseteq \opint{ 0 }{ 1 } \text{.}\) If We first note that if \(p \gt 1 \text{,}\) then \(1 - p \lt 0 \text{,}\) and so
      \begin{equation*} \lim_{ a \to 0 }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ a \to 0 }{ \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } } = \lim_{ a \to 0 }{ \frac{ a^{ 1 - p } - b^{ 1 - p } }{ p - 1 } } = \infty\text{.} \end{equation*}
      This implies that \(f \) is not improperly integrable in this case.
      🔗
      On the other hand, now suppose that \(0 \lt p \lt 1 \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Fix real numbers \(1 \lt a_{ \epsilon } \leq b_{ \epsilon } \lt \infty \) so that
      \begin{align*} a_{ \epsilon } \amp \lt \of{ \frac{ \epsilon \of{ 1 - p } }{ 2 } }^{ \frac{ 1 }{ 1 - p } } \amp b_{ \epsilon } \gt \of{ 1 - \frac{ \epsilon \of{ 1 - p } }{ 2 } }^{ \frac{ 1 }{ 1 - p } }\text{.} \end{align*}
      We observe that
      \begin{align*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - \frac{ 1 }{ 1 - p } } \amp = \abs{ \frac{ b^{ 1 - p } - a^{ 1 - p } }{ 1 - p } - \frac{ 1 }{ 1 - p } } \leq \frac{ \abs{ b^{ 1 - p } - 1 } }{ 1 - p } + \frac{ \abs{ a^{ 1 - p } } }{ 1 - p }\\ \amp = \frac{ 1 - b^{ 1 - p } }{ 1 - p } + \frac{ a^{ 1 - p } }{ 1 - p } \leq \frac{ 1 - b_{ \epsilon }^{ 1 - p } }{ 1 - p } + \frac{ a_{ \epsilon }^{ 1 - p } }{ 1 - p }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
      for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subsetneq \opint{ 0 }{ \infty } \text{.}\) Thus \(f \) is improperly integrable, with improper Riemann integral
      \begin{equation*} \int_{ 0 }^{ 1 }{ f \of{ x } \, \diff{ x } } = \frac{ 1 }{ 1 - p }\text{.} \end{equation*}
      🔗
      🔗
    • One question raised by the above examples is the nature of the case \(p = 1 \text{;}\) that is, consider the function \(f \colon \opint{ 0 }{ \infty } \) defined by the formula \(f \of{ x } = \frac{ 1 }{ x } \text{.}\) We will see that \(f \) is not improperly integrable on \(\opclint{ 0 }{ 1 } \) or on \(\clopint{ 1 }{ \infty } \text{.}\)
      🔗
      To that end, we first note that
      \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = \ln \of{ b } - \ln \of{ a } = \ln \of{ \frac{ b }{ a } } \end{equation*}
      for any compact subinterval \(\clint{ a }{ b } \subseteq \opint{ 0 }{ \infty } \text{.}\) In particular, we note that
      \begin{equation*} \lim_{ a \to 0 }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ a \to 0 }{ \ln \of{ \frac{ b }{ a } } } = \infty \end{equation*}
      and
      \begin{equation*} \lim_{ b \to \infty }{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } = \lim_{ b \to \infty }{ \ln \of{ \frac{ b }{ a } } } = \infty\text{.} \end{equation*}
      These computations imply that the restrictions of \(f \) to the intervals \(\opclint{ 0 }{ 1 } \) and \(\clopint{ 1 }{ \infty } \) are not improperly integrable.
      🔗
      🔗
    🔗
    🔗

    Proposition 6.3.9. Arithmetic of improperly integrable functions.

    1. Addition of improperly integrable functions.
      Let \(f , g \colon X \to \R \) be real-valued functions defined on an interval \(X \text{.}\) If \(f \) and \(g \) are improperly integrable, then so is \(f + g \text{,}\) and
      \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \of{ f + g } \of{ x } \, \diff{ x } } = \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } + \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
      🔗
      🔗
    2. Scalar multiplication of improperly integrable functions.
      Let \(f \colon X \to \R \) be real-valued functions defined on an interval \(X \text{.}\) If \(f \) is improperly integrable, then so is \(c f \) for any real number \(c \in \R \text{,}\) and
      \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \of{ c f } \of{ x } \, \diff{ x } } = c \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
      🔗
      🔗
    🔗

    Proof.
    1. Let
      \begin{align*} I_{ f } \amp = \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \amp I_{ g } \amp = \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{align*}
      Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) and \(g \) are improperly integrable, there is a compact subinterval \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \in \mathcal{ K }_{ X } \) of the interior \(\Int \of{ X } \) so that
      \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I_{ f } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      and
      \begin{equation*} \abs{ \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } } - I_{ g } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{.}\) We observe that
      \begin{align*} \abs{ \int_{ a }^{ b }{ \of{ f + g } \of{ x } \diff{ x } } - \of{ I_{ f } + I_{ g } } } \amp = \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } + \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } } - I_{ f } - I_{ g } }\\ \amp \leq \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I_{ f } } + \abs{ \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } } - I_{ g } }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon\text{,} \end{align*}
      for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{.}\) We conclude that \(f + g \) is improperly integrable, with improper integral
      \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \of{ f + g } \of{ x } \, \diff{ x } } = I_{ f } + I_{ g } = \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } + \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
      🔗
      🔗
    2. If \(c = 0 \text{,}\) then \(c f = 0 f = 0 \) is improperly integrable, with
      \begin{align*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \of{ c f } \of{ x } \, \diff{ x } } \amp = \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ 0 \, \diff{ x } } = 0\\ \amp = 0 \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } = c \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } }\text{.} \end{align*}
      We may therefore suppose that \(c \neq 0 \text{.}\) Let
      \begin{equation*} I = \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
      Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) is improperly integrable, there is a compact subinterval \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \in \mathcal{ K }_{ X } \) of the interior \(\Int \of{ X } \) so that
      \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I } \lt \frac{ \epsilon }{ \abs{ c } } \end{equation*}
      for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{.}\) We observe that
      \begin{align*} \abs{ \int_{ a }^{ b }{ \of{ c f } \of{ x } \diff{ x } } - c I } \amp = \abs{ c \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - c I }\\ \amp = \abs{ c } \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } - I_{ f } }\\ \amp \lt \frac{ \abs{ c } \epsilon }{ \abs{ c } } = \epsilon\text{,} \end{align*}
      for all compact subintervals \(\clint{ a_{ \epsilon } }{ b_{ \epsilon } } \subseteq \clint{ a }{ b } \subseteq \Int \of{ X } \text{.}\) We conclude that \(c f \) is improperly integrable, with improper integral
      \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \of{ c f } \of{ x } \, \diff{ x } } = c I = c \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    To summarize, a function is improperly integrable if the proper Riemann integral of a restriction of said function to a compact subinterval of the interior of the domain can be made arbitrarily close to a given real number just by choosing the compact subinterval to be wide enough.

    Subsection 6.3.2 Tests for Integral Convergence

    We now explore several sufficient criteria for establishing improper Riemann integrability. We first observe that while a real-valued function \(f \) defined on compact intervals is Riemann integrable if and only if \(\abs{ f } \) is Riemann integrable, the same cannot be said of functions defined on non-compact intervals.
    🔗

    Example 6.3.10. Conditional convergence of improper integrals.

    Let \(f \colon \opint{ 0 }{ \infty } \to \R \) be the real-valued function defined by the formula
    \begin{equation*} f \of{ x } = \frac{ \sin \of{ x } }{ x }\text{.} \end{equation*}
    We don’t yet have the tools to verify this, but \(f \) is improperly Riemann integrable, while \(\abs{ f } \) is not. We might call the convergence of the corresponding improper integral of \(f \) conditional, in contrast with absolutely convergent improper integrals.
    🔗
    🔗

    Definition 6.3.11. Absolute/conditional Riemann integrability.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{.}\)
    • Absolute Riemann integrability.
      \(f \) is called absolutely Riemann integrable if \(\abs{ f } \) is improperly Riemann integrable. One might also describe the improper Riemann integral
      \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \end{equation*}
      as absolutely convergent in this case.
      🔗
      🔗
    • Conditional Riemann integrability.
      \(f \) is called conditionally Riemann integrable if it is improperly Riemann integrable but not absolutely Riemann integrable; that is \(f \) is conditionally Riemann integrable if \(f \) is improperly Riemann integrable but \(\abs{ f } \) is not. One might also describe the improper Riemann integral
      \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \end{equation*}
      as conditionally convergent in this case.
      🔗
      🔗
    🔗
    🔗
    We will show that absolute integrability implies improper integrability. This will follow from the comparison test for improper integrability, of which we first establish the following special case:
    🔗

    Lemma 6.3.12. Comparison of non-negative improper integrals.

    Let \(f , g \colon X \to \clopint{ 0 }{ \infty } \) be non-negative real-valued functions defined on an interval \(X \subseteq \R \text{,}\) and suppose that \(0 \leq f \of{ x } \leq g \of{ x } \) for all points \(x \in X \text{.}\) If the restriction of \(f \) to any compact subinterval of the interior \(\Int \of{ X } \) is integrable and \(g \) is improperly integrable, then \(f \) is improperly integrable, and
    \begin{equation*} 0 \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    Consider the nets \(\of{ F_{ \clint{ a }{ b } } }_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } } \) and \(\of{ G_{ \clint{ a }{ b } } }_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } } \) defined by the formulas
    \begin{align*} F_{ \clint{ a }{ b } } \amp = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } \amp G_{ \clint{ a }{ b } } \amp = \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } } \end{align*}
    for all compact subintervals \(\clint{ a }{ b } \in \mathcal{ K }_{ X } \) of the interior \(\Int \of{ X } \text{.}\) We first observe that these nets are order-preserving. Indeed, for any compact subintervals \(\clint{ a }{ b } , \clint{ c }{ d } \in \mathcal{ K }_{ X } \text{,}\) if \(\clint{ a }{ b } \subseteq \clint{ c }{ d } \text{,}\) then Chasles’ relation and Lemma 6.1.14 Riemann integration and comparison imply that
    \begin{align*} F_{ \clint{ a }{ b } } \amp = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } }\\ \amp \leq \int_{ c }^{ a }{ f \of{ x } \, \diff{ x } } + \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } + \int_{ b }^{ d }{ f \of{ x } \, \diff{ x } }\\ \amp = \int_{ c }^{ d }{ f \of{ x } \, \diff{ x } } = F_{ \clint{ c }{ d } }\text{,} \end{align*}
    and similarly that \(G_{ \clint{ a }{ b } } \leq G_{ \clint{ c }{ d } } \text{.}\) The net analogue of the Monotone convergence theorem implies that
    \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } } = \lim_{ \clint{ a }{ b } \uparrow }{ G_{ \clint{ a }{ b } } } = \sup_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } }{ G_{ \clint{ a }{ b } } }\text{.} \end{equation*}
    🔗
    We observe that for any compact subinterval \(\clint{ a }{ b } \in \mathcal{ K }_{ X } \) of the interior \(\Int \of{ X } \text{,}\)
    \begin{align*} F_{ \clint{ a }{ b } } \amp = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } \leq \int_{ a }^{ b }{ g \of{ x } \, \diff{ x } }\\ \amp \leq \sup_{ \clint{ c }{ d } \in \mathcal{ K }_{ X } }{ G \of{ \clint{ c }{ d } } } = \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } } \end{align*}
    by Lemma 6.1.14 Riemann integration and comparison, and so another application of the net analogue of the Monotone convergence theorem implies that \(\of{ F_{ \clint{ a }{ b } } }_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } } \) converges upwards to
    \begin{equation*} \lim_{ \clint{ a }{ b } \uparrow }{ F_{ \clint{ a }{ b } } } = \sup_{ \clint{ a }{ b } \in \mathcal{ K }_{ X } }{ F_{ \clint{ a }{ b } } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    That is, \(f \) is improperly integrable, with improper integral
    \begin{equation*} 0 \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Theorem 6.3.13. Comparison test for integral convergence.

    Let \(f , g , h \colon X \to \R \) be real-valued functions defined on an interval \(X \text{,}\) and suppose that \(f \of{ x } \leq g \of{ x } \leq h \of{ x } \) for all points \(x \in X \text{.}\) If the restriction of \(g \) to any compact subinterval of the interior \(\Int \of{ X } \) is integrable and \(f \) and \(h \) are improperly integrable, then \(g \) is improperly integrable, and
    \begin{equation*} \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ g \of{ x } \, \diff{ x } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ h \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    We note that \(g - f \) and \(h - f \) satisfy the hypotheses of Lemma 6.3.12 Comparison of non-negative improper integrals, and so the desired result now follows immediately from Lemma 6.3.12 Comparison of non-negative improper integrals and Proposition 6.3.9 Arithmetic of improperly integrable functions.
    🔗
    🔗

    Corollary 6.3.14. Absolute integrability implies improper integrability.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \text{.}\) If the restriction of \(f \) to every compact subinterval of the interior \(\Int \of{ X } \) is integrable and \(f \) is absolutely integrable, then \(f \) is improperly integrable, and
    \begin{equation*} \abs{ \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \abs{ f \of{ x } } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    Since \(f \) is absolutely integrable, \(\abs{ f } \) is improperly integrable. We observe that (2) of Proposition 6.3.9 Arithmetic of improperly integrable functions implies that \(-\abs{ f } \) is also improperly integrable. Since \(-\abs{ f \of{ x } } \leq f \of{ x } \leq \abs{ f \of{ x } } \text{,}\) the Comparison test for integral convergence implies that \(f \) is improperly integrable, with improper integral
    \begin{equation*} -\int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \abs{ f \of{ x } } \, \diff{ x } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \abs{ f \of{ x } } \, \diff{ x } }\text{.} \end{equation*}
    Taking absolute values, we obtain
    \begin{equation*} 0 \leq \abs{ \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ f \of{ x } \, \diff{ x } } } \leq \int_{ \inf \of{ X } }^{ \sup \of{ X } }{ \abs{ f \of{ x } } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Example 6.3.15. Comparison of improper integrals.

    Let \(f \colon \clopint{ 1 }{ \infty } \to \R \) be the real-valued function defined by the formula
    \begin{equation*} f \of{ x } = \frac{ a }{ x^{ 2 } + b } \end{equation*}
    for some non-negative real numbers \(a , b \geq 0 \text{.}\) Since \(f \) is continuous, the restriction of \(f \) to any compact subinterval of \(\opint{ 1 }{ \infty } \) is integrable. We observe that
    \begin{equation*} 0 \leq f \of{ x } = \frac{ a }{ x^{ 2 } + b } \lt \frac{ a }{ x^{ 2 } } \end{equation*}
    for all points \(1 \leq x \lt \infty \text{.}\) Since \(\frac{ a }{ x^{ 2 } } \) is improperly integrable, the Comparison test for integral convergence implies that \(f \) is improperly integrable, with improper integral
    \begin{equation*} 0 \leq \int_{ 1 }^{ \infty }{ f \of{ x } \, \diff{ x } } \leq \int_{ 1 }^{ \infty }{ \frac{ a }{ x^{ 2 } } \, \diff{ x } } = \frac{ a }{ 2 - 1 } = a\text{.} \end{equation*}
    🔗
    🔗
    The hypothesis that \(b \geq 0 \) is non-negative in Example 6.3.15 Comparison of improper integrals was necessary in order to obtain the given comparison. However, the same conclusion holds for negative \(b \lt 0 \text{.}\) One way to see this improper integrability is to apply the following result:
    🔗

    Theorem 6.3.16. Limit comparison test for integral convergence.

    Let \(f , g \colon X \to \R \) be real-valued functions defined on an interval \(X \text{,}\) and suppose that \(f \asymp g \) as \(x \to \inf \of{ X } \) and \(x \to \sup \of{ X } \text{.}\) If the restriction of \(f \) to any compact subinterval of the interior \(\Int \of{ X } \) is integrable and \(g \) is improperly integrable, then \(f \) is improperly integrable.
    🔗
    🔗
    We will see in Chapter 7 Infinite Series that several of these tests for improper integrability correspond to analogous tests for series convergence. This is one example of a deep relationship between integrals and series which will be explored further in [provisional cross-reference: chapter-lebesgue-integration].
