    Section 6.2 The Fundamental Theorems of Calculus

    In this section, we develop the two fundamental theorems of calculus. These theorems bridge the two halves of calculus: differential calculus and integral calculus. We will see that differentiation and integration are related operations, and in a sense inverse to each other.
    🔗

    Subsection 6.2.1 Differentiating Riemann Integrals

    Before we establish the first fundamental theorem of calculus, we will require two further properties of the Riemann integral. The first establishes a relation between integrals of the same function on adjacent closed intervals, and the second is an integral analogue of the triangle inequality.
    🔗

    Lemma 6.2.1 (Michel Chasles). Chasles’ relation.

    Let \(f \colon \clint{ a }{ c } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ c } \text{.}\) If \(f \) is Riemann integrable, then for any interior point \(a \lt b \lt c \text{,}\) the restrictions of \(f \) to the closed intervals \(\clint{ a }{ b } \) and \(\clint{ b }{ c } \) are Riemann integrable, and
    \begin{equation*} \int_{ a }^{ c }{ f \of{ x } \, \diff{ x } } = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } + \int_{ b }^{ c }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    Since \(f \) is Riemann integrable, there is a partition \(P_{ \epsilon } = \of{ x_{ k } }_{ k = 0 }^{ n } \) of \(\clint{ a }{ c } \) so that
    \begin{equation*} \mathcal{ U }_{ f } \of{ P } - \mathcal{ L }_{ f } \of{ P } \lt \epsilon \end{equation*}
    for all refinements \(P \succeq P_{ \epsilon } \text{.}\) Without loss of generality, we may suppose that \(b = x_{ j } \) for some index \(0 \lt j \lt n \text{.}\) Consider the partitions \(Q_{ \epsilon } = \of{ x_{ k } }_{ k = 0 }^{ j } \) and \(R_{ \epsilon } = \of{ k = j }^{ n } \) of \(\clint{ a }{ b } \) and \(\clint{ b }{ c } \text{.}\) We will show that the existence of \(Q_{ \epsilon } \) and \(R_{ \epsilon } \) implies the Riemann integrability of the restrictions of \(f \) to \(\clint{ a }{ b } \) and \(\clint{ b }{ c } \text{,}\) respectively.
    🔗
    Indeed, note that for any refinement \(Q \succeq Q_{ \epsilon } \text{,}\) we may form a refinement \(Q' \succeq P_{ \epsilon } \) by appending \(\of{ x_{ k } }_{ k = j + 1 }^{ n } \) as a suffix. We observe that
    \begin{align*} \mathcal{ U }_{ f } \of{ Q } - \mathcal{ L }_{ f } \of{ Q } \amp = \sum_{ k = 0 }^{ j - 1 }{ \of{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } - \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp \leq \sum_{ k = 0 }^{ n - 1 }{ \of{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } - \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp = \mathcal{ U }_{ f } \of{ Q' } - \mathcal{ L }_{ f } \of{ Q' } \lt \epsilon\text{.} \end{align*}
    Similarly, for any refinement \(R \succeq R_{ \epsilon } \text{,}\) we may form a refinement \(R' \succeq P_{ \epsilon } \) by appending \(\of{ x_{ k } }_{ k = 0 }^{ j - 1 } \) as a prefix. We observe that
    \begin{align*} \mathcal{ U }_{ f } \of{ R } - \mathcal{ L }_{ f } \of{ R } \amp = \sum_{ k = j }^{ n - 1 }{ \of{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } - \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp \leq \sum_{ k = 0 }^{ n - 1 }{ \of{ \sup_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } - \inf_{ x_{ k } \leq x \leq x_{ k + 1 } }{ f \of{ x } } } \of{ x_{ k + 1 } - x_{ k } } }\\ \amp = \mathcal{ U }_{ f } \of{ R' } - \mathcal{ L }_{ f } \of{ R' } \lt \epsilon\text{.} \end{align*}
    Thus the restrictions of \(f \) to \(\clint{ a }{ b } \) and \(\clint{ b }{ c } \) are Riemann integrable. It remains only to show that \(\int_{ a }^{ c }{ f \of{ x } \, \diff{ x } } = I \text{,}\) where
    \begin{equation*} I = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } + \int_{ b }^{ c }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    To that end, we observe that since \(f \) is bounded, there is a positive real number \(B \gt 0 \) so that \(\abs{ f \of{ x } } \leq B \) for all points \(a \leq x \leq b \text{.}\) Note that for any positive real number \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \abs{ \mathcal{ R }_{ f } \of{ Q , u } - \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } \lt \frac{ \epsilon }{ 3 } \end{equation*}
    for all tagged partitions \(\of{ Q , u } \) of \(\clint{ a }{ b } \) of mesh \(\mesh \of{ Q } \lt \delta \text{,}\)
    \begin{equation*} \abs{ \mathcal{ R }_{ f } \of{ R , v } - \int_{ b }^{ c }{ f \of{ x } \, \diff{ x } } } \lt \frac{ \epsilon }{ 3 } \end{equation*}
    for all tagged partitions \(\of{ R , v } \) of \(\clint{ b }{ c } \) of mesh \(\mesh \of{ R } \lt \delta \text{,}\) and
    \begin{equation*} \delta \leq \frac{ \epsilon }{ 6 B }\text{.} \end{equation*}
    Let \(\of{ P , t } \) be a tagged partition of \(\clint{ a }{ c } \) of mesh \(\mesh \of{ P } \lt \delta \text{,}\) where \(P = \of{ x_{ k } }_{ k = 0 }^{ n } \) and \(t = \of{ t_{ k } }_{ k = 0 }^{ n - 1 } \text{.}\) If \(x_{ j } = b \) for some index \(0 \lt j \lt n \text{,}\) then consider the tagged partitions \(\of{ Q , u } \) and \(\of{ R , v } \) of \(\clint{ a }{ b } \) and \(\clint{ b }{ c } \text{,}\) respectively, where
    \begin{align*} Q \amp = \of{ x_{ k } }_{ k = 0 }^{ j } \amp u \amp = \of{ t_{ k } }_{ k = 0 }^{ j - 1 }\\ R \amp = \of{ x_{ k } }_{ k = j }^{ n } \amp v \amp = \of{ t_{ k } }_{ k = j }^{ n - 1 }\text{.} \end{align*}
    These tagged partitions both have mesh less than \(\delta \text{,}\) and so
    \begin{align*} \abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \amp = \abs{ \sum_{ k = 0 }^{ n - 1 }{ f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } } - I }\\ \amp \leq \abs{ \sum_{ k = 0 }^{ j - 1 }{ f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } } - \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } }\\ \amp \qquad + \abs{ \sum_{ k = j }^{ n - 1 }{ f \of{ t_{ k } } \of{ x_{ k + 1 } - x_{ k } } } - \int_{ b }^{ c }{ f \of{ x } \, \diff{ x } } }\\ \amp = \abs{ \mathcal{ R }_{ f } \of{ Q } - \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } + \abs{ \mathcal{ R }_{ f } \of{ Q } - \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } }\\ \amp \lt \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } = \frac{ 2 \epsilon }{ 3 } \lt \epsilon\text{.} \end{align*}
    🔗
    On the other hand, if \(x_{ j } \neq b \) for all indices \(0 \lt j \lt n \text{,}\) then there is a unique index \(0 \leq j \lt n \) so that \(x_{ j } \lt b \lt x_{ j + 1 } \text{.}\) We may find a refinement \(\of{ P' , t' } \) of \(\of{ P , t } \) solely by adding in \(b \) and choosing tags \(y \) and \(z \) in the new subintervals \(\clint{ x_{ j } }{ b } \) and \(\clint{ b }{ x_{ j + 1 } } \text{.}\) We observe that the above computation applies to \(\of{ P' , t' } \text{,}\) and so
    \begin{align*} \abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \amp \leq \abs{ \mathcal{ R }_{ f } \of{ P , t } - \mathcal{ R }_{ f } \of{ P' , t' } } + \abs{ \mathcal{ R }_{ f } \of{ P' , t' } - I }\\ \amp \lt \abs{ f \of{ t_{ j } } \of{ x_{ j + 1 } - x_{ j } } - f \of{ y } \of{ b - x_{ j } } - f \of{ z } \of{ x_{ j + 1 } - b } } + \frac{ 2 \epsilon }{ 3 }\\ \amp \lt 2 B \delta + \frac{ 2 \epsilon }{ 3 } \leq \frac{ \epsilon }{ 3 } + \frac{ 2 \epsilon }{ 3 } = \epsilon\text{.} \end{align*}
    🔗
    In summary, we have shown that for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is some positive real number \(\delta \gt 0 \) so that \(\abs{ \mathcal{ R }_{ f } \of{ P , t } - I } \lt \epsilon \) for all tagged partitions \(\of{ P , t } \) of \(\clint{ a }{ c } \) of mesh \(\mesh \of{ P } \lt \delta \text{.}\) We conclude that
    \begin{equation*} \int_{ a }^{ c }{ f \of{ x } \, \diff{ x } } = I = \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } + \int_{ b }^{ c }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗
    So far, we have only allowed the notation
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } \end{equation*}
    when \(a \lt b \text{.}\) Chasles’ relation provides a way to extend this to allow for any real numbers \(a \) and \(b \text{.}\) For example, if \(a \gt b \text{,}\) then we define
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = -\int_{ b }^{ a }{ f \of{ x } , \diff{ x } }\text{.} \end{equation*}
    Similarly, if \(a = b \text{,}\) then we define
    \begin{equation*} \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } = 0\text{.} \end{equation*}
    You will have an opportunity in the problems for this section to prove that with these extensions of notation for Riemann integrals, Chasles’ relation still holds.
    🔗
    While the following result may seem innocuous at first glance, it is a deeply useful estimate which reflects the geometric structure of the vector space of Riemann integrable functions.
    🔗

    Proposition 6.2.2. Triangle inequality for Riemann integrals.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\) If \(f \) is Riemann integrable, then \(\abs{ f } \) is Riemann integrable, and
    \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } \leq \int_{ a }^{ b }{ \abs{ f \of{ x } } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    Since the function \(g \colon \R \to \R \) defined by the formula \(g \of{ x } = \abs{ x } \text{,}\) the composition \(g \circ f = \abs{ f } \) is Riemann integrable by Problem 6.1.4.1 More on integrability and continuity. Since \(0 \leq \abs{ f \of{ x } } \) for all points \(a \leq x \leq b \text{,}\)
    \begin{equation*} 0 = \int_{ a }^{ b }{ 0 \, \diff{ x } } \leq \int_{ a }^{ b }{ \abs{ f \of{ x } } \, \diff{ x } } \end{equation*}
    by Lemma 6.1.14 Riemann integration and comparison. Similarly, \(-\abs{ f \of{ x } } \leq f \of{ x } \leq \abs{ f \of{ x } } \) for all points \(a \leq x \leq b \text{,}\) and so
    \begin{equation*} -\int_{ a }^{ b }{ \abs{ f \of{ x } } \, \diff{ x } } = \int_{ a }^{ b }{ -\abs{ f \of{ x } } \, \diff{ x } } \leq \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } \leq \int_{ a }^{ b }{ \abs{ f \of{ x } } \, \diff{ x } } \end{equation*}
    by Lemma 6.1.14 Riemann integration and comparison. Thus
    \begin{equation*} \abs{ \int_{ a }^{ b }{ f \of{ x } \, \diff{ x } } } \leq \int_{ a }^{ b }{ \abs{ f \of{ x } } \, \diff{ x } }\text{.} \end{equation*}
    🔗
    🔗
    We are now ready to prove the first fundamental theorem of calculus. This foundational result establishes a relationship between differentiation integration: by integrating a continuous function \(f \text{,}\) we may obtain a differentiable function whose derivative is \(f \text{.}\)
    🔗

    Theorem 6.2.3. First fundamental theorem of calculus.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a continuous real-valued function defined on a closed interval \(\clint{ a }{ b } \text{,}\) and consider the real-valued function \(F \colon \clint{ a }{ b } \to \R \) defined by the formula
    \begin{equation*} F \of{ x } = \int_{ a }^{ x }{ f \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    Then \(F \) is differentiable, with derivative \(F' \of{ c } = f \of{ c } \) for all points \(a \leq c \leq b \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) is continuous at \(c \text{,}\) there is a positive real number \(\delta \gt 0 \) so that \(\abs{ f \of{ x } - f \of{ c } } \lt \frac{ \epsilon }{ 2 } \) for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) We observe that Chasles’ relation and the Triangle inequality for Riemann integrals together imply that
    \begin{align*} \abs{ \frac{ F \of{ x } - F \of{ c } }{ x - c } - f \of{ c } } \amp = \abs{ \frac{ 1 }{ x - c } \of{ \int_{ a }^{ x }{ f \of{ x } \, \diff{ x } } - \int_{ a }^{ c }{ f \of{ x } \, \diff{ x } } - f \of{ c } \of{ x - c } } }\\ \amp = \abs{ \frac{ 1 }{ x - c } \of{ \int_{ c }^{ x }{ f \of{ x } \, \diff{ x } } - \int_{ c }^{ x }{ f \of{ c } \, \diff{ x } } } }\\ \amp = \frac{ 1 }{ \abs{ x - c } } \abs{ \int_{ c }^{ x }{ f \of{ x } - f \of{ c } \, \diff{ x } } }\\ \amp = \frac{ 1 }{ \abs{ x - c } } \int_{ \min \of{ \set{ c , x } } }^{ \max \of{ \set{ c , x } } }{ \abs{ f \of{ x } - f \of{ c } } \, \diff{ x } }\\ \amp \leq \frac{ 1 }{ \abs{ x - c } } \int_{ \min \of{ \set{ c , x } } }^{ \max \of{ \set{ c , x } } }{ \frac{ \epsilon }{ 2 } \, \diff{ x } }\\ \amp = \frac{ \epsilon \of{ \max \of{ \set{ c , x } } - \min \of{ \set{ c , x } } } }{ 2 \abs{ x - c } }\\ \amp = \frac{ \epsilon \abs{ x - c } }{ 2 \abs{ x - c } } = \frac{ \epsilon }{ 2 } \lt \epsilon \end{align*}
    for all points \(x \in \clint{ a }{ b } \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) Thus \(F \) is differentiable at \(c \text{,}\) with derivative \(F' \of{ c } = f \of{ c } \text{.}\)
    🔗
    🔗
    Thus integrating a continuous function yields a differentiable function whose derivative is the integrand; we call such a function an anti-derivative (or primitive) of the integrand.
    🔗
    🔗

    Subsection 6.2.2 Integrating Derivatives

    The First fundamental theorem of calculus establishes a relationship between differentiation and Riemann integration: the function obtained by integrating a continuous function is differentiable, with derivative the integrand. We now seek to establish a relationship in the other direction; that is, we explore Riemann integrals of the derivative of a differentiable function. In this case, the moral is similar; integrating the derivative of a function yields information about that function itself.
    🔗

    Theorem 6.2.4. Second fundamental theorem of calculus.

    Let \(f \colon \clint{ a }{ b } \to \R \) be a real-valued function defined on a closed interval \(\clint{ a }{ b } \text{.}\) If \(f \) is continuously differentiable, then
    \begin{equation*} \int_{ a }^{ b }{ f' \of{ x } \, \diff{ x } } = f \of{ b } - f \of{ a }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    Let \(F \colon \clint{ a }{ b } \to \R \) be the real-valued function defined on \(\clint{ a }{ b } \) by the formula
    \begin{equation*} F \of{ x } = \int_{ a }^{ x }{ f' \of{ x } \, \diff{ x } }\text{.} \end{equation*}
    Then the Theorem 6.2.3 First fundamental theorem of calculus implies that \(F \) is differentiable, with derivative \(F' \of{ x } = f' \of{ x } \) for all points \(a \leq x \leq b \text{.}\)
    🔗
    Part (b) of Problem 5.3.4.1 Functions with the same derivative now implies that there is some real number \(c \in \R \) so that \(F \of{ x } = f \of{ x } + c \) for all points \(a \leq x \leq b \text{.}\) By evaluating at \(a \text{,}\) we observe that
    \begin{equation*} 0 = \int_{ a }^{ a }{ f' \of{ x } \, \diff{ x } } = F \of{ a } = f \of{ a } + c\text{,} \end{equation*}
    so that \(c = -f \of{ a } \text{.}\) Thus
    \begin{equation*} \int_{ a }^{ b }{ f' \of{ x } \, \diff{ x } } = F \of{ b } = f \of{ b } + c = f \of{ b } - f \of{ a }\text{.} \end{equation*}
    🔗
    🔗
    There are stronger versions of the Second fundamental theorem of calculus which do not require continuity of the integrand, but rather only Riemann integrability. However, we will only use the result as stated.
    🔗

    Example 6.2.5. Computing Riemann integrals using the Second fundamental theorem of calculus.

    The following are examples of how to use the Second fundamental theorem of calculus to compute a Riemann integral:
    • Consider the Riemann integral
      \begin{equation*} \int_{ 0 }^{ 4 }{ x^{ 3 } \, \diff{ x } }\text{.} \end{equation*}
      Instead of computing this Riemann integral as a limit of Riemann sums, we instead recognize that \(x^{ 3 } = f' \of{ x } \text{,}\) where \(f \colon \R \to \R \) is the continuously differentiable real-valued function defined by the formula \(f \of{ x } = \frac{ x^{ 4 } }{ 4 } \text{.}\) Thus the Theorem 6.2.4 Second fundamental theorem of calculus implies that
      \begin{align*} \int_{ 0 }^{ 4 }{ x^{ 3 } \, \diff{ x } } \amp = \int_{ 0 }^{ 4 }{ f' \of{ x } \, \diff{ x } } = f \of{ 4 } - f \of{ 0 }\\ \amp = \frac{ 4^{ 4 } }{ 4 } - \frac{ 0^{ 4 } }{ 4 } = 64 - 0 = 64\text{.} \end{align*}
      🔗
      🔗
    • Consider the Riemann integral
      \begin{equation*} \int_{ -\frac{ \pi }{ 2 } }^{ \frac{ \pi }{ 2 } }{ \cos \of{ y } \, \diff{ y } }\text{.} \end{equation*}
      Instead of computing this Riemann integral as a limit of Riemann sums, we instead recognize that \(\cos \of{ y } = g' \of{ y } \text{,}\) where \(g \colon \R \to \R \) is the continuously differentiable real-valued function defined by the formula \(g \of{ y } = \sin \of{ y } \text{.}\) Thus the Theorem 6.2.4 Second fundamental theorem of calculus implies that
      \begin{align*} \int_{ -\frac{ \pi }{ 2 } }^{ \frac{ \pi }{ 2 } }{ \cos \of{ y } \, \diff{ y } } \amp = \int_{ -\frac{ \pi }{ 2 } }^{ \frac{ \pi }{ 2 } }{ g' \of{ y } \, \diff{ y } } = g \of{ \frac{ \pi }{ 2 } } - g \of{ -\frac{ \pi }{ 2 } }\\ \amp = \sin \of{ \frac{ \pi }{ 2 } } - \sin \of{ -\frac{ \pi }{ 2 } } = 1 - \of{ -1 } = 2\text{.} \end{align*}
      🔗
      🔗
    • Consider the Riemann integral
      \begin{equation*} \int_{ 0 }^{ \pi }{ 2 z \sin \of{ 3 z } + 3 z^{ 2 } \cos \of{ 3 z } \, \diff{ z } }\text{.} \end{equation*}
      Instead of computing this Riemann integral as a limit of Riemann sums, we instead recognize that \(2 z \sin \of{ 3 z } + 3 z^{ 2 } \cos \of{ 3 z } = h' \of{ z } \text{,}\) where \(h \colon \R \to \R \) is the continuously differentiable real-valued function defined by the formula \(h \of{ z } = z^{ 2 } \sin \of{ 3 z } \text{.}\) Thus the Theorem 6.2.4 Second fundamental theorem of calculus implies that
      \begin{align*} \int_{ 0 }^{ \pi }{ 2 z \sin \of{ 3 z } + 3 z^{ 2 } \cos \of{ 3 z } \, \diff{ z } } \amp = \int_{ 0 }^{ \pi }{ h' \of{ z } \, \diff{ z } } = h \of{ \pi } - h \of{ 0 }\\ \amp = \pi^{ 2 } \sin \of{ 3 \pi } - 0^{ 2 } \sin \of{ 3 \cdot 0 } = 0 - 0 = 0\text{.} \end{align*}
      🔗
      🔗
    🔗
    🔗
    The Second fundamental theorem of calculus not only exposes another link between differential calculus and integral calculus, but also provides an invaluable tool for computing Riemann integrals without resorting to limits of nets of Riemann sums. Specifically, Second fundamental theorem of calculus implies that for continuous functions, Riemann integration is only as hard as computing anti-derivatives. However, we remark that computing anti-derivatives can still be quite difficult, even for some relatively simple integrands.
