    Section 3.5 Notions of Metric Continuity

    In this section, we present three distinct but related notions of continuity on a metric space. Informally, these forms of continuity are conditions related to the nature of the convergence of a function to its value at a point. We will in this section make this precise, and investigate the structure of continuous maps between metric spaces.
    🔗

    Subsection 3.5.1 Continuous Maps and Functions

    In calculus, you may have learned that a function of the real numbers is continuous if the function commutes with limits, if limits of the function agree with the values of the function. We will see that this is also the case for maps of metric spaces. More precisely, map of metric spaces is continuous at a point in its domain if its values can be made arbitrarily close to the image of that point just by choosing points close to that point.
    🔗

    Proposition 3.5.1. Characterizations of metric continuity.

    Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) For a point \(c \in X \text{,}\) the following are equivalent:
    1. Convergence characterization of continuity.
      The map \(f \) converges at \(c \) to \(f \of{ c } \text{.}\)
      🔗
      🔗
    2. \(\epsilon \)-\(\delta \) characterization of continuity.
      For all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } \lt \epsilon \text{.}\)
      🔗
      🔗
    3. Neighborhood characterization of continuity.
      The pre-image \(f^{ -1 } \of{ N } \) of any neighborhood \(N \) of \(f \of{ c } \) in \(Y \) is a neighborhood of \(c \) in \(X \text{.}\)
      🔗
      🔗
    4. Sequential characterization of continuity.
      For every sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \text{,}\) if
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{,} \end{equation*}
      then
      \begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = f \of{ c }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Proof.
    First suppose that \(f \) converges at \(c \) to \(f \of{ c } \text{,}\) and let \(\epsilon \gt 0 \text{.}\) Then there exists a positive real number \(\delta \gt 0 \) so that for all points \(x \in X \text{,}\) if \(0 \lt \rho_{ X } \of{ x , c } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } \lt \epsilon \text{.}\) We note that if \(\rho_{ X } \of{ x , c } = 0 \text{,}\) then the non-degeneracy of \(\rho_{ X } \) implies that \(x = c \text{.}\) In this case, \(f \of{ x } = f \of{ c } \text{,}\) and so \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } = 0 \text{.}\)
    🔗
    Now suppose that for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } \lt \epsilon \text{,}\) and let \(N \subseteq Y \) be a neighborhood of \(f \of{ c } \) in \(Y \text{.}\) Then \(\mB_{ \epsilon } \of{ f \of{ c } } \subseteq N \) for some positive real number \(\epsilon \gt 0 \text{.}\)
    🔗
    Since \(\epsilon \gt 0 \) is positive, there is a positive real number \(\delta \gt 0 \) so that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x } , f \of{ c } } \lt \epsilon \text{.}\) In particular,
    \begin{equation*} f \of{ \mB_{ \delta } \of{ c } } \subseteq \mB_{ \epsilon } \of{ f \of{ c } } \subseteq N\text{,} \end{equation*}
    and so \(\mB_{ \delta } \of{ c } \subseteq f^{ -1 } \of{ N } \text{;}\) that is, \(f^{ -1 } \of{ N } \) is a neighborhood of \(c \) in \(X \text{.}\)
    🔗
    Now suppose that the pre-image \(f^{ -1 } \of{ N } \) of any neighborhood \(N \) of \(f \of{ c } \) in \(Y \) is a neighborhood of \(c \) in \(X \text{,}\) and let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) so that
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{.} \end{equation*}
    Let \(\epsilon \gt 0 \) be a positive real number. Then \(\mB_{ \epsilon } \of{ f \of{ c } } \) is a neighborhood of \(f \of{ c } \) in \(Y \text{,}\) and so \(f^{ -1 } \of{ \mB_{ \epsilon } \of{ f \of{ c } } } \) is a neighborhood of \(c \) in \(X \text{.}\) Thus
    \begin{equation*} \mB_{ \delta } \of{ c } \subseteq f^{ -1 } \of{ \mB_{ \epsilon } \of{ f \of{ c } } } \end{equation*}
    for some positive real number \(\delta \gt 0 \text{.}\) Since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(c \text{,}\) there is some natural number \(n_{ \epsilon } \in \N \) so that \(\rho_{ X } \of{ x_{ n } , c } \lt \delta \) for all indices \(n \geq n_{ \epsilon } \text{.}\) This implies that
    \begin{equation*} f \of{ x_{ n } } \in f \of{ \mB_{ \delta } \of{ c } } \subseteq \mB_{ \epsilon } \of{ f \of{ c } } \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{,}\) and so \(\rho_{ Y } \of{ f \of{ x_{ n } } , f \of{ c } } \lt \epsilon \) for all such indices. We conclude that
    \begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = f \of{ c }\text{.} \end{equation*}
    🔗
    Finally, suppose that for every sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \text{,}\) if
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{,} \end{equation*}
    then
    \begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = f \of{ c }\text{.} \end{equation*}
    Then Theorem 3.2.19 Sequential characterization of map convergence implies that \(f \) converges at \(c \) to \(f \of{ c } \text{.}\)
    🔗
    🔗

    Definition 3.5.2. Continuity.

    Let \(f \colon X \to Y \) be a map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\)
    • Continuity.
      \(f \) is continuous at a point \(c \in X \) if it satisfies any (and therefore all) of the conditions in Proposition 3.5.1 Characterizations of metric continuity. \(f \) is continuous if it is continuous at every point \(c \in X \text{.}\)
      🔗
      🔗
    • Discontinuity.
      \(f \) is discontinuous at a point \(c \in X \) if it does not satisfies any of the conditions in Proposition 3.5.1 Characterizations of metric continuity. \(f \) is discontinuous if it is discontinuous at some point \(c \in X \text{.}\)
      🔗
      🔗
    The set of continuous maps from \(X \) to \(Y \) is denoted \(\CDiff \of{ X , Y } \text{.}\) In the special case \(\of{ Y , \rho_{ Y } } = \of{ \R , d } \text{,}\) the set of continuous, real-valued functions on a metric space \(\of{ X , \rho_{ X } } \) is denoted \(\CDiff \of{ X } = \CDiff \of{ X , \R } \text{.}\)
    🔗
    🔗

    Example 3.5.3. Continuity.

    The following are examples of continuous and discontinuous maps.
    • Any constant map between metric spaces is continuous.
      🔗
      🔗
    • The identity map \(\id_{ X } \colon X \to X \) on a metric space \(\of{ X , \rho } \) is continuous. More generally, the inclusion map \(\iota \colon U \to X \) of a metric subspace \(U \subseteq X \) is continuous.
      🔗
      🔗
    • Any map \(f \colon X \to Y \) from a discrete metric space \(\of{ X , \delta_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \) is continuous.
      🔗
      🔗
    • Let \(f \colon \R \setminus \set{ 0 } \to \R \) be the real-valued function defined by the formula
      \begin{equation*} f \of{ x } = \frac{ 1 }{ x }\text{.} \end{equation*}
      Then \(f \) is continuous. In particular, we note that \(f \) is neither continuous nor discontinuous at \(0 \text{,}\) since \(0 \) is not in the domain of \(f \text{.}\)
      🔗
      You may have been taught that \(f \) has a discontinuity at the point \(0 \text{,}\) but we will require more specific language. We can describe the behavior of \(f \) near \(0 \) by saying that \(f \) does not have a continuous extension to \(\R \text{.}\)
      🔗
      🔗
    🔗
    🔗
    A map of metric spaces is continuous at a point if and only if the outputs of the map can be made close to the image of that point solely by choosing inputs close to the point. Perhaps unsurprising in light of Theorem 3.2.19 Sequential characterization of map convergence is the fact that continuity is totally determined by the behavior of the map on convergent sequences.In fact, unlike the more general spaces we will investigate in Chapter 4 Topological Spaces, the answers to all point-set topological questions about metric spaces are captured by the behavior of sequences. Perhaps more surprising is the following characterization of continuity in terms of open sets.
    🔗

    Corollary 3.5.4. Open set characterization of metric continuity.

    A map \(f \colon X \to Y \) from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \) is continuous if and only if the pre-image of any open subset of \(Y \) is an open subset of \(X \text{.}\)
    🔗
    🔗

    Proof.
    Suppose first that \(f \) is continuous, and let \(V \subseteq Y \) be an open subset of \(Y \text{.}\) Let \(c \in f^{ -1 } \of{ V } \text{.}\) Since \(V \) is open, it is a neighborhood of \(f \of{ c } \text{,}\) and so the neighborhood characterization of continuity in Proposition 3.5.1 Characterizations of metric continuity implies that \(f^{ -1 } \of{ V } \) is a neighborhood of \(c \text{.}\) Since this is true of every point \(c \in f^{ -1 } \of{ V } \text{,}\) \(f^{ -1 } \of{ V } \) is open in \(X \text{.}\)
    🔗
    Conversely, now suppose that the pre-image of every open subset of \(Y \) is an open subset of \(X \text{,}\) and consider a point \(c \in X \) and a neighborhood \(N \subseteq Y \) of \(f \of{ c } \) in \(Y \text{.}\) Then \(\mB_{ r } \of{ f \of{ c } } \subseteq N \) for some positive real number \(r \gt 0 \text{.}\) Since \(\mB_{ r } \of{ c } \) is open in \(Y \text{,}\) \(f^{ -1 } \of{ \mB_{ r } \of{ f \of{ c } } } \) is open in \(X \) and is therefore a neighborhood of each of its points.
    🔗
    In particular, \(f \of{ c } \in \mB_{ r } \of{ f \of{ c } } \text{,}\) and so \(c \in f^{ -1 } \of{ \mB_{ r } \of{ f \of{ c } } } \text{.}\) We conclude that \(f^{ -1 } \of{ \mB_{ r } \of{ f \of{ c } } } \) is a neighborhood of \(c \text{.}\) The neighborhood characterization of continuity in Proposition 3.5.1 Characterizations of metric continuity now implies that \(f \) is continuous at \(c \text{.}\) Since this holds for all points \(c \in X \text{,}\) \(f \) is continuous.
    🔗
    🔗
    In general, proving that a given map between metric spaces is continuous can be annoyingly difficult. For example, if you want to use the \(\epsilon \)-\(\delta \) characterization of continuity, then finding a correct positive real number \(\delta > 0 \) for each positive real number \(\epsilon > 0 \) is not necessarily an easy task. The following results allow us to decompose such a problem into smaller parts, which may be much easier to solve than taking on the entire problem at once.
    🔗

    Proposition 3.5.5. Composition of continuous maps.

    Let \(f \colon X \to Y \) and \(g \colon Y \to Z \) be maps between metric spaces \(\of{ X , \rho_{ X } } \text{,}\) \(\of{ Y , \rho_{ Y } } \text{,}\) and \(\of{ Z , \rho_{ Z } } \text{.}\) If \(f \) is continuous at a point \(c \in X \) and \(g \) is continuous at \(f \of{ c } \text{,}\) then the composition \(g \circ f \colon X \to Z \) is continuous at \(c \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \text{,}\) and suppose that
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{.} \end{equation*}
    Since \(f \) is continuous at \(c \text{,}\)
    \begin{equation*} \lim_{ n \to \infty }{ f \of{ x_{ n } } } = f \of{ c }\text{.} \end{equation*}
    Since \(g \) is continuous at \(f \of{ c } \text{,}\)
    \begin{equation*} \lim_{ n \to \infty }{ \of{ g \circ f } \of{ x_{ n } } } = \lim_{ n \to \infty }{ g \of{ f \of{ x_{ n } } } } = g \of{ f \of{ c } } = \of{ g \circ f } \of{ c }\text{.} \end{equation*}
    Thus \(g \circ f \) is continuous at \(c \text{.}\)
    🔗
    🔗

    Proposition 3.5.6. Vector arithmetic of continuous maps.

    Let \(\of{ X , \rho } \) be a metric space and \(\of{ V , \norm{ \oparg } } \) be a normed vector space.
    1. Vector addition.
      Let \(f , g \colon X \to V \) be maps from \(X \) to \(V \text{.}\) If \(f \) and \(g \) are continuous at a point \(c \in X \text{,}\) then their pointwise sum \(f + g \) is continuous at \(c \text{.}\)
      🔗
      🔗
    2. Scalar multiplication.
      Let \(\alpha \) be a scalar and \(f \colon X \to V \) be a map from \(X \) to \(V \text{.}\) If \(f \) is continuous at a point \(c \in X \text{,}\) then the scalar multiplication \(\alpha f \) is continuous at \(c \text{.}\)
      🔗
      🔗
    3. Norm.
      Let \(f \colon X \to V \) be a map from \(X \) to \(V \text{.}\) If \(f \) is continuous at a point \(c \in X \text{,}\) then the norm \(\norm{ f } = \norm{ \oparg } \circ f \) is continuous at \(c \text{.}\)
      🔗
      🔗
    4. Inner product.
      Let \(f , g \colon X \to V \) be maps from \(X \) to \(V \text{.}\) If the norm \(\norm{ \oparg } \) on \(V \) is induced by an inner product \(\inner{ \oparg }{ \oparg } \) and \(f \) and \(g \) are continuous at a point \(c \text{,}\) then the pointwise inner product \(\inner{ f }{ g } \) is continuous at \(c \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) is continuous at \(c \text{,}\) there is a positive real number \(\delta_{ f } \gt 0 \) so that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta_{ f } \text{,}\) then \(\norm{ f \of{ x } - f \of{ c } } \lt \frac{ \epsilon }{ 2 } \text{.}\) Similarly, since \(g \) is continuous at \(c \text{,}\) there is a positive real number \(\delta_{ g } \gt 0 \) so that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta_{ g } \text{,}\) then \(\norm{ g \of{ x } - g \of{ c } } \lt \frac{ \epsilon }{ 2 } \text{.}\)
      🔗
      Let \(\delta = \min \of{ \set{ \delta_{ f } , \delta_{ g } } } \gt 0 \text{,}\) and note that for all points \(x \in X \text{,}\) if \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) then
      \begin{align*} \norm{ \of{ f + g } \of{ x } - \of{ f + g } \of{ c } } \amp = \norm{ f \of{ x } + g \of{ x } - f \of{ c } - g \of{ c } }\\ \amp \leq \norm{ f \of{ x } - f \of{ c } } + \norm{ g \of{ x } - g \of{ c } }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon\text{.} \end{align*}
      We conclude that \(f + g \) is continuous at \(c \text{.}\)
      🔗
      🔗
    2. Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \text{,}\) and suppose that
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{.} \end{equation*}
      Since \(f \) is continuous at \(c \text{,}\) we observe that
      \begin{align*} \lim_{ n \to \infty }{ \of{ \alpha f } \of{ x_{ n } } } \amp = \lim_{ n \to \infty }{ \alpha f \of{ x_{ n } } } = \alpha \lim_{ n \to \infty }{ f \of{ x_{ n } } }\\ \amp = \alpha f \of{ c } = \of{ \alpha f } \of{ c }\text{,} \end{align*}
      and so \(\alpha f \) is continuous at \(c \text{.}\)
      🔗
      🔗
    3. By Proposition 3.5.5 Composition of continuous maps, it suffices to show that \(\norm{ \oparg } \colon V \to \R \) is a continuous real-valued function on \(V \text{.}\) This follows directly from (3) of Proposition 3.3.1 Limits and vector arithmetic.
      🔗
      🔗
    4. Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \text{,}\) and suppose that
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = c\text{.} \end{equation*}
      Since \(f \) and \(g \) are continuous at \(c \text{,}\) we observe that
      \begin{align*} \lim_{ n \to \infty }{ \inner{ f }{ g } \of{ x_{ n } } } \amp = \lim_{ n \to \infty }{ \inner{ f \of{ x_{ n } } }{ g \of{ x_{ n } } } } = \inner{ \lim_{ n \to \infty }{ f \of{ x_{ n } } } }{ \lim_{ n \to \infty }{ g \of{ x_{ n } } } }\\ \amp = \inner{ f \of{ c } }{ g \of{ c } } = \inner{ f }{ g } \of{ c }\text{,} \end{align*}
      and so \(\inner{ f }{ g } \) is continuous at \(c \text{.}\)
      🔗
      🔗
    🔗

    Corollary 3.5.7. Arithmetic of continuous functions.

    Let \(f , g \colon X \to \R \) be real-valued functions on a metric space \(\of{ X , \rho } \text{.}\) If \(f \) and \(g \) are continuous at a point \(c \in X \text{,}\) then \(f + g \text{,}\) \(f - g \text{,}\) and \(f g \) are continuous at \(c \text{.}\)
    🔗
    Moreover, if \(f \) and \(g \) are continuous at at point \(c \in X \) and \(g \of{ x } \neq 0 \) for all points \(x \in X \text{,}\) then \(\frac{ f }{ g } \) is continuous at \(c \text{.}\)
    🔗
    🔗
    Having introduced the notion of continuity for maps between metric spaces, one natural question is to describe the relationship between continuity and the limiting behavior of sequences of maps. At first glance, it may seem plausible that the limit of a sequence of continuous functions which converges pointwise must also be continuous. This, however, is not the case.
    🔗

    Example 3.5.8. Discontinuous limits of sequences of continuous functions.

    Consider the sequence \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) of continuous real-valued functions \(f_{ n } \colon \clint{ 0 }{ 1 } \to \R \) defined by the formulae
    \begin{equation*} f_{ n } \of{ x } = x^{ n }\text{.} \end{equation*}
    We recall that \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges pointwise to the function \(f \colon \clint{ 0 }{ 1 } \to \R \) defined piecewise by the formula
    \begin{equation*} f \of{ x } =1 \begin{cases} 0 \amp 0 \leq x \lt 1 \\ 1 \amp x = 1 \text{.}\end{cases} \end{equation*}
    Even though each function \(f_{ n } \) is continuous, the pointwise limit \(f \) is not continuous at \(1 \text{.}\)
    🔗
    🔗
    So the pointwise limit of a sequence of continuous maps between metric spaces need not be continuous. However, if such a sequence of continuous maps converges uniformly, then the limit is a continuous map.
    🔗

    Theorem 3.5.9. Uniform limits of continuous maps.

    The limit of a uniformly convergent sequence of continuous maps between metric spaces is continuous.
    🔗
    🔗

    Proof.
    Let \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of continuous maps \(f_{ n } \colon X \to Y \) from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{,}\) and suppose that \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to a map \(f \colon X \to Y \text{.}\)
    🔗
    Fix a point \(c \in X \text{,}\) and let \(\epsilon \gt 0 \text{.}\) Since \(\of{ f_{ n } }_{ n = 0 }^{ \infty } \) converges uniformly to \(f \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} \rho_{ Y } \of{ f_{ n } \of{ x } , f \of{ x } } \lt \frac{ \epsilon }{ 3 } \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \) and points \(x \in X \text{.}\) Fix one such index \(n \geq n_{ \epsilon } \text{.}\) Since \(f_{ n } \) is continuous, there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \rho_{ Y } \of{ f_{ n } \of{ x } , f_{ n } \of{ c } } \lt \frac{ \epsilon }{ 3 } \end{equation*}
    for all points \(x \in X \) so that \(\rho_{ X } \of{ x , c } \lt \delta \text{.}\) We observe that
    \begin{align*} \rho_{ Y } \of{ f \of{ x } , f \of{ c } } \amp \leq \rho_{ Y } \of{ f \of{ x } , f_{ n } \of{ x } } + \rho_{ Y } \of{ f_{ n } \of{ c } , f_{ n } \of{ c } } + \rho_{ Y } \of{ f_{ n } \of{ c } , f \of{ c } }\\ \amp \lt \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } + \frac{ \epsilon }{ 3 } = \epsilon \end{align*}
    for all points \(x \in X \) so that \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) and so \(f \) is continuous at \(c \text{.}\) Since this holds for all points \(c \in X \text{,}\) we conclude that \(f \) is continuous.
    🔗
    🔗
    So, while the pointwise limit of a sequence of continuous maps between metric spaces need not in general be continuous, any such sequence which converges uniformly must converge to a continuous limit. Uniformity, or the relative independence of the “size” of neighborhoods of points in a space from position, is a useful property which will allow us to reconcile complex limiting behavior where several limits interact. We now turn to a strengthening of the notion of continuity based on this idea of uniformity.
    🔗
    🔗

    Subsection 3.5.2 Stronger Forms of Metric Continuity

    Continuity is a fundamental and useful tool for mathematical analysis of maps between metric spaces. However, there are many pathological examples of maps which are continuous and yet do not behave as well as we might like. Therefore, we now turn our attention to a stronger notion of continuity, that of uniform continuity. At the beginning of this section, we saw a definition for metric continuity which posited the existence of a positive real number \(\delta \) for each point in the domain and each positive real number \(\epsilon \text{.}\) Informally, a map between metric spaces is uniformly continuous if the \(\delta \) associated to a given \(\epsilon \) may be chosen independent of position in the domain.
    🔗

    Definition 3.5.10. Uniform continuity.

    A map \(f \colon X \to Y \) from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \) is called uniformly continuous if for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \lt \epsilon \end{equation*}
    for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\)
    🔗
    The set of uniformly continuous maps from \(X \) to \(Y \) is denoted \(\UC \of{ X , Y } \text{.}\) In the special case \(\of{ Y , \rho_{ Y } } = \of{ \R , d } \text{,}\) the set of uniformly continuous real-valued functions on \(X \) is denoted \(\UC \of{ X } = \UC \of{ X , \R } \text{.}\)
    🔗
    🔗
    Note that uniform continuity does not apply at a specific point, but rather over the entire domain of a map. It does not make sense to say that a map between metric spaces is uniformly continuous at a point.
    🔗

    Example 3.5.11. Uniform continuity.

    The following are examples of uniformly continuous and not uniformly continuous maps between metric spaces:
    • Any constant map between metric spaces is uniformly continuous. Indeed, fix metric spaces \(\of{ X , \rho_{ X } } \) and \(\of{ Y , \rho_{ Y } } \text{,}\) and consider a point \(y \in Y \text{.}\) The constant map \(f \colon X \to Y \) from \(X \) to \(Y \) defined by the formula \(f \of{ x } = y \) satisfies the condition
      \begin{equation*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } = \rho_{ Y } \of{ y , y } = 0 \end{equation*}
      for all points \(x_{ 1 } , x_{ 2 } \in X \text{.}\) Thus for a given positive real number \(\epsilon \gt 0 \text{,}\) we may choose any positive real number \(\delta \gt 0 \) and check that this choice verifies the uniform continuity condition.
      🔗
      🔗
    • The inclusion map of a metric subspace is uniformly continuous. Indeed, fix a subset \(U \subseteq X \) of a metric space \(\of{ X , \rho } \text{,}\) and note that the inclusion map \(\iota \colon U \to X \) satisfies the condition
      \begin{equation*} \rho \of{ \iota \of{ u_{ 1 } } , \iota \of{ u_{ 2 } } } = \rho \of{ u_{ 1 } , u_{ 2 } } \end{equation*}
      for all points \(u_{ 1 } , u_{ 2 } \in U \text{.}\) Thus for a given positive real number \(\epsilon \gt 0 \text{,}\) we may choose \(\delta = \epsilon \gt 0 \) and check that this choice verifies the uniform continuity condition.
      🔗
      🔗
    • The real-valued function \(f \colon \R \to \R \) defined by the formula \(f \of{ x } = x^{ 2 } \) is continuous but not uniformly continuous. Indeed, for any positive real number \(\delta \gt 0 \text{,}\) let
      \begin{align*} x_{ 1 } \amp = \frac{ 1 }{ 2 \delta } \amp x_{ 2 } \amp = \frac{ 1 + \delta^{ 2 } }{ 2 \delta }\text{.} \end{align*}
      We observe that
      \begin{gather*} \abs{ x_{ 1 } - x_{ 2 } } = \abs{ \frac{ 1 }{ 2 \delta } - \frac{ 1 + \delta^{ 2 } }{ 2 \delta } } = \abs{ \frac{ \delta^{ 2 } }{ 2 \delta } } = \frac{ \delta }{ 2 } \lt \delta\text{,} \end{gather*}
      but
      \begin{equation*} \abs{ x_{ 1 } + x_{ 2 } } = \abs{ \frac{ 1 }{ 2 \delta } + \frac{ 1 + \delta^{ 2 } }{ 2 \delta } } = \abs{ \frac{ 2 + \delta^{ 2 } }{ 2 \delta } } = \frac{ 2 + \delta^{ 2 } }{ 2 \delta } = \frac{ 1 }{ \delta } + \frac{ \delta }{ 2 }\text{,} \end{equation*}
      which implies that
      \begin{align*} \abs{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } \amp = \abs{ x_{ 1 }^{ 2 } - x_{ 2 }^{ 2 } } = \abs{ \of{ x_{ 1 } - x_{ 2 } } \of{ x_{ 1 } + x_{ 2 } } } = \abs{ x_{ 1 } - x_{ 2 } } \cdot \abs{ x_{ 1 } + x_{ 2 } }\\ \amp = \of{ \frac{ \delta }{ 2 } } \of{ \frac{ 1 }{ \delta } + \frac{ \delta }{ 2 } } = \frac{ 1 }{ 2 } + \frac{ \delta^{ 2 } }{ 4 } \gt \frac{ 1 }{ 2 }\text{.} \end{align*}
      In particular, for the positive real number \(\epsilon = \frac{ 1 }{ 2 } \text{,}\) there is no positive real number \(\delta \gt 0 \) for which the uniform continuity criterion is satisfied.
      🔗
      🔗
    🔗
    🔗
    The definitions of continuity and uniform continuity are very similar at first glance. In fact, despite the above example of a continuous but not uniformly continuous function, it’s not difficult to see that uniform continuity implies continuity.
    🔗

    Proposition 3.5.12. Uniform continuity implies continuity.

    Any uniformly continuous map between metric spaces is continuous.
    🔗
    🔗

    Proof.
    Let \(f \colon X \to Y \) be a uniformly continuous map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{.}\) Consider a point \(x \in X \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) is uniformly continuous, there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \lt \epsilon \end{equation*}
    for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\) In particular, we observe that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x } , f \of{ x } } \lt \epsilon \end{equation*}
    for all points \(x \in X \) so that \(\rho_{ X } \of{ x , c } \lt \delta \text{,}\) and so \(f \) is continuous at \(c \text{.}\) Since \(c \) was chosen to be an arbitrary point in \(X \text{,}\) \(f \) is continuous.
    🔗
    🔗
    Continuous maps between metric spaces (or other more general spaces) are fundamental objects in point-set topology. This is because lots of topological properties of spaces, which we will examine in the following section and chapter, are preserved under continuous maps. However, some of the more geometric properties, which start to approach notions of size, are not preserved under all continuous maps in general, but only under uniformly continuous maps. In the previous section, we introduced a notion of boundedness for subsets. While the image of a bounded subset of a metric space under a continuous map is not necessarily bounded, the image of a totally bounded subset of a metric space under a uniformly continuous map is totally bounded.
    🔗

    Proposition 3.5.13. Uniform continuity and total boundedness.

    The image of a totally bounded subset of a metric space under a uniformly continuous map between metric spaces is totally bounded.
    🔗
    🔗

    Proof.
    Let \(f \colon X \to Y \) be a uniformly continuous map from a metric space \(\of{ X , \rho_{ X } } \) to a metric space \(\of{ Y , \rho_{ Y } } \text{,}\) and consider a totally bounded subset \(U \subseteq X \text{.}\) We wish to show that \(f \of{ U } \) is totally bounded in \(Y \text{.}\)
    🔗
    To that end, let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) is uniformly continuous, there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \lt \epsilon \end{equation*}
    for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\) In particular, this implies that
    \begin{equation*} f \of{ \mB_{ \delta } \of{ x } } \subseteq \mB_{ \epsilon } \of{ f \of{ x } } \end{equation*}
    for all points \(x \in X \text{.}\)
    🔗
    Since \(U \) is totally bounded in \(X \text{,}\) there is a finite list \(x_{ 1 } , \dotsc , x_{ n } \in X \) so that
    \begin{equation*} U \subseteq \bigcup_{ k = 1 }^{ n }{ \mB_{ \delta } \of{ x_{ k } } }\text{.} \end{equation*}
    We observe that
    \begin{align*} f \of{ U } \amp \subseteq f \of{ \bigcup_{ k = 1 }^{ n }{ \mB_{ \delta } \of{ x_{ k } } } } = \bigcup_{ k = 1 }^{ n }{ f \of{ \mB_{ \delta } \of{ x_{ k } } } }\\ \amp \subseteq \bigcup_{ k = 1 }^{ n }{ \mB_{ \epsilon } \of{ f \of{ x_{ k } } } }\text{,} \end{align*}
    and so \(f \of{ U } \) is totally bounded in \(Y \text{.}\)
    🔗
    🔗
    So the uniformly continuous image of a totally bounded subset of a metric space is totally bounded. Just as in the case of plain continuity, the set of uniformly continuous maps from a metric space to a normed vector space itself forms a vector space under pointwise addition and scalar multiplication.
    🔗

    Proposition 3.5.14. Vector arithmetic and uniform continuity.

    Let \(\of{ X , \rho } \) be a metric space and \(\of{ V , \norm{ \oparg } } \) be a normed vector space.
    1. Vector addition.
      If two maps \(f , g \colon X \to V \) from \(X \) to \(Y \) are uniformly continuous, then their pointwise sum \(f + g \colon X \to V \) is also uniformly continuous.
      🔗
      🔗
    2. Scalar multiplication.
      If a map \(f \colon X \to V \) is uniformly continuous, then any pointwise scalar multiple \(\alpha f \) is also uniformly continuous.
      🔗
      🔗
    3. Norm.
      If a map \(f \colon X \to V \) is uniformly continuous, then its pointwise norm \(\norm{ f } = \norm{ \oparg } \circ f \) is also uniformly continuous.
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) and \(g \) are continuous, there are positive real numbers \(\delta_{ f } , \delta_{ g } \gt 0 \) so that
      \begin{equation*} \norm{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho \of{ x_{ 1 } , x_{ 2 } } \lt \delta_{ f } \) and
      \begin{equation*} \norm{ g \of{ x_{ 1 } } - g \of{ x_{ 2 } } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho \of{ x_{ 1 } , x_{ 2 } } \lt \delta_{ g } \text{.}\) Let \(\delta = \min \of{ \set{ \delta_{ f } , \delta_{ g } } } \gt 0 \text{.}\) We observe that
      \begin{align*} \norm{ \of{ f + g } \of{ x_{ 1 } } - \of{ f + g } \of{ x_{ 2 } } } \amp = \norm{ f \of{ x_{ 1 } } + g \of{ x_{ 1 } } - f \of{ x_{ 2 } } - g \of{ x_{ 2 } } }\\ \amp \leq \norm{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } + \norm{ g \of{ x_{ 1 } } - g \of{ x_{ 2 } } }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
      for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{,}\) and so \(f + g \) is uniformly continuous.
      🔗
      🔗
    2. Let \(\epsilon \gt 0 \) be a positive real number. If \(\alpha = 0 \text{,}\) then \(\alpha f = 0 f = \vect{ 0 } \) is a constant map and therefore is uniformly continuous. We may therefore suppose that \(\alpha \neq 0 \) is non-zero.
      🔗
      Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) is uniformly continuous, there is a positive real number \(\delta \gt 0 \) so that
      \begin{equation*} \norm{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } \lt \frac{ \epsilon }{ \abs{ \alpha } } \end{equation*}
      for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\) We observe that
      \begin{align*} \norm{ \of{ \alpha f } \of{ x_{ 1 } } - \of{ \alpha f } \of{ x_{ 2 } } } \amp = \norm{ \alpha f \of{ x_{ 1 } } - \alpha f \of{ x_{ 2 } } } = \norm{ \alpha \of{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } }\\ \amp = \abs{ \alpha } \norm{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } \lt \abs{ \alpha } \of{ \frac{ \epsilon }{ \abs{ \alpha } } } = \epsilon \end{align*}
      for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{,}\) and so \(\alpha f \) is uniformly continuous.
      🔗
      🔗
    3. Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) is uniformly continuous, there is a positive real number \(\delta \gt 0 \) so that
      \begin{equation*} \norm{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } \lt \epsilon \end{equation*}
      for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\) We observe that Proposition 3.1.5 Reverse triangle inequality implies that
      \begin{align*} \abs{ \norm{ f } \of{ x_{ 1 } } - \norm{ f } \of{ x_{ 2 } } } \amp = \abs{ \norm{ f \of{ x_{ 1 } } } - \norm{ f \of{ x_{ 2 } } } } = \abs{ \norm{ f \of{ x_{ 1 } } } - \norm{ f \of{ x_{ 2 } } } }\\ \amp = \abs{ \norm{ f \of{ x_{ 1 } } - \vect{ 0 } } - \norm{ f \of{ x_{ 2 } } - \vect{ 0 } } }\\ \amp \leq \norm{ f \of{ x_{ 1 } } - f \of{ x_{ 2 } } } \lt \epsilon \end{align*}
      for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{,}\) so that \(\norm{ f } \) is uniformly continuous.
      🔗
      🔗
    🔗
    A natural question to ask is whether the same holds for the pointwise product of uniformly continuous real-valued functions on a metric space. In fact, we have seen that this is not necessarily the case: the real-valued function \(f \colon \R \to \R \) defined by the formula \(f \of{ x } = x \) is uniformly continuous, but the pointwise product \(\of{ f \cdot f } \of{ x } = f \of{ x } \cdot f \of{ x } = x^{ 2 } \) is not uniformly continuous. However, since uniformly continuous maps are continuous and because the product of two continuous, real-valued functions is continuous, the pointwise product of two uniformly continuous, real-valued functions on a metric space is continuous.
    🔗
    Just as in the case of continuous maps, the composition of uniformly continuous maps is uniformly continuous. This allows us to simplify the proofs of uniform continuity for a vast class of maps.
    🔗

    Proposition 3.5.15. Composition of uniformly continuous maps.

    The composition of uniformly continuous maps between metric spaces is uniformly continuous.
    🔗
    🔗

    Proof.
    Let \(f \colon X \to Y \) and \(g \colon Y \to Z \) be uniformly continuous maps between metric spaces \(\of{ X , \rho_{ X } } \text{,}\) \(\of{ Y , \rho_{ Y } } \text{,}\) and \(\of{ Z , \rho_{ Z } } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Since \(g \) is uniformly continuous, there is a positive real number \(\eta \gt 0 \) so that
    \begin{equation*} \rho_{ Z } \of{ g \of{ y_{ 1 } } , g \of{ y_{ 2 } } } \lt \epsilon \end{equation*}
    for all points \(y_{ 1 } , y_{ 2 } \in Y \) so that \(\rho_{ Y } \of{ y_{ 1 } , y_{ 2 } } \lt \eta \text{.}\) Moreover, since \(f \) is uniformly continuous, there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \lt \eta \end{equation*}
    for all points \(x_{ 1 } , x_{ 2 } \in X \) so that \(\rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{.}\)
    🔗
    We observe that for all points \(x_{ 1 } , x_{ 2 } \in X \) if \(\rho_{ X } \of{ x_{ 1 } , x_{ 2 } } \lt \delta \text{,}\) then \(\rho_{ Y } \of{ f \of{ x_{ 1 } } , f \of{ x_{ 2 } } } \lt \eta \text{,}\) and so
    \begin{equation*} \rho_{ Z } \of{ \of{ g \circ f } \of{ x_{ 1 } } , \of{ g \circ f } \of{ x_{ 2 } } } = \rho_{ Z } \of{ g \of{ f \of{ x_{ 1 } } } , g \of{ f \of{ x_{ 2 } } } } \lt \epsilon\text{.} \end{equation*}
    We conclude that \(g \circ f \) is uniformly continuous.
