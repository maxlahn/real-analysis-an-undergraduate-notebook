    Section 4.3 Convergence and Separation

    We are now ready to reexamine limiting behavior such as convergence and divergence in the more general setting of topological spaces. In the previous chapter, we explored the convergence of objects such as sequences and maps in the context of metric spaces. In a metric space, we had the benefit of a metric granting us a quantitative measure of closeness upon which our formulation of convergence relied. In a general topological space, however, we don’t explicitly have access to the same kind of data to measure how close points are to each other. Instead, we must rely on other qualitative measures of locality to formalize limiting behavior.
    🔗
    We will see that, in contrast to the relatively amenable case of convergence in a metric space, topological convergence can be far more outlandish. For example, some convergent sequences and maps in some topological spaces converge to more than point, and many of the reasonable results from the previous chapter don’t hold in certain classes of topological spaces. In particular, many point-set topological notions such as continuity and compactness cannot in general be described in sequential terms as in the context of metric spaces. With this in mind, we will briefly introduce sequential convergence in topological spaces, but we will almost immediately generalize this to discuss the limiting behavior of a more general class of indexed families of points. Then we will discuss the separation axioms, which will allow us to consider certain classes of topological spaces in which limiting behavior is more well-behaved.
    🔗

    Subsection 4.3.1 Sequential Convergence and Beyond

    In the previous chapter, we defined convergence in a metric space in a way which relied explicitly on the metric in question. In topological spaces, however, we must rely only on what data is available from the topology. Instead of defining sequential convergence and divergence in terms of some distance function, we will define it in terms of the neighborhoods of points. A sequence of points in a topological space is said to converge to a point if the values of the sequence are eventually contained in any neighborhood of the putative limit.
    🔗

    Definition 4.3.1. Sequential convergence/divergence in a topological space.

    A sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \) in a topological space \(\of{ X , \tau } \) converges to a point \(x \in X \) if for every neighborhood \(N \) of \(x \) in \(X \text{,}\) there is a natural number \(n_{ N } \) so that \(x_{ n } \in N \) for all indices \(n \geq n_{ N } \text{.}\)
    🔗
    A sequence of points in a topological space is called convergent if it converges to some point and divergent otherwise if it does not converge to any point.
    🔗
    🔗
    We first observe that the above notion of sequential convergence coincides precisely with our previous notion of sequential convergence in metric spaces whenever a topological space is metrizable.
    🔗

    Lemma 4.3.2. Sequential convergence in metrizable spaces.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points in a metric space \(\of{ X , \rho } \text{.}\) For any point \(x \in X \text{,}\) the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric space \(\of{ X , \rho } \) if and only if \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metrizable topological space \(\of{ X , \tau_{ \rho } } \text{.}\)
    🔗
    🔗

    Proof.
    First suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric space \(\of{ X , \rho } \text{,}\) and let \(N \subseteq X \) be a neighorhood of \(x \) in \(X \text{.}\) Then \(\mB_{ \epsilon } \of{ x } \subseteq N \) for some positive real number \(\epsilon \gt 0 \text{.}\) There is some natural number \(n_{ N } \in \N \) so that
    \begin{equation*} \rho \of{ x_{ n } , x } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ N } \text{.}\) In particular, we observe that \(x_{ n } \in \mB_{ \epsilon } \of{ x } \subseteq N \) for all indices \(n \geq n_{ N } \text{.}\) Thus \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric topological space \(\of{ X , \tau_{ \rho } } \text{.}\)
    🔗
    Conversely, now suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric topological space \(\of{ X , \tau_{ \rho } } \text{,}\) and let \(\epsilon \gt 0 \) be a positive real number. Since \(\mB_{ \epsilon } \of{ x } \) is a neighborhood of \(x \) in \(X \text{,}\) there is a natural number \(n_{ \epsilon } \in \N \) so that \(x_{ n } \in \mB_{ \epsilon } \of{ x } \) for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
    \begin{equation*} \rho \of{ x_{ n } , x } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) Thus \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \) in the metric space \(\of{ X , \rho } \text{.}\)
    🔗
    🔗
    One consequence of Lemma 4.3.2 Sequential convergence in metrizable spaces is that we have already explored plenty of examples of convergent and divergent sequences in metrizable topological spaces, and we are familiar with the properties of sequential convergence in metrizable topological spaces. For example, Lemma 4.3.2 Sequential convergence in metrizable spaces and Proposition 3.2.3 Uniqueness of sequential limits in a metric space implies that limits of convergent sequences in metrizable topological spaces are unique.
    🔗

    Corollary 4.3.3. Uniqueness of sequential limits in metrizable spaces.

    Convergent sequences of points in metrizable topological spaces converge to unique points.
    🔗
    🔗
    One might hope that Corollary 4.3.3 Uniqueness of sequential limits in metrizable spaces could be extended to apply to sequential convergence in all topological spaces, metrizable and non-metrizable. However, our familiar intuition regarding such convergence can break down in non-metrizable spaces.
    🔗

    Example 4.3.4. Sequential convergence/divergence in non-metrizable spaces.

    The following are examples of convergent and divergent sequences in non-metrizable topological spaces:
    • Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of points \(x_{ n } \in X \) in an indiscrete topological space \(\of{ X , \bot_{ X } } \text{.}\) For any point \(x \in X \text{,}\) since the only neighborhood of \(x \) in \(X \) is \(X \) itself, the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(x \text{.}\)
      🔗
      🔗
    • Recall that the Sierpiński space \(\of{ X , \tau } \) is the topological space with ground set \(X = \set{ 0 , 1 } \) and topology \(\tau = \set{ \emptyset , \set{ 1 } , \set{ 0 , 1 } } \text{.}\) Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be the constant sequence of points \(x_{ n } \in X \) defined by the formula \(x_{ n } = 1 \text{.}\)
      🔗
      The two neighborhoods of \(1 \) in \(X \) are \(\set{ 1 } \) and \(\set{ 0 , 1 } \text{,}\) and these neighborhoods both contain every entry of the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{.}\) In particular, the entries of \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) eventually lie in any neighborhood of \(1 \text{,}\) so that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(1 \text{.}\)
      🔗
      However, the only neighborhood of \(0 \) in \(X \) is \(\set{ 0 , 1 } \text{,}\) and this neighborhood contains every entry of the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{.}\) In particular, the entries of \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) eventually lie in any neighborhood of \(0 \text{.}\) So \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) also converges to \(0 \text{.}\)
      🔗
      🔗
    🔗
    🔗
    The above example shows that in our generalization of metric spaces to topological spaces, we have lost at least one nice property of limiting behavior; sequences of points can converge to more than one limit. This by itself is not cause to abandon our study of the limiting behavior of sequences; we will see that many of the topological spaces encountered in practice are Hausdorff, a class of topological spaces in which convergent sequences converge to unique limits, even if these spaces are not metrizable.
    🔗
    The true reasons for our shift in focus from sequences to more general indexed families of points called nets are more subtle, and they are concerned with adapting the sequential characterizations of many of the point-set topological notions introduced in Chapter 3 Metric Spaces. For example, while we have seen characterizations of continuity and compactness in terms of the convergence of sequences, such characterizations are not extended to topological spaces in general. Indeed, there are topological spaces for which the limiting behavior of sequences alone is not sufficient data to fully describe central point-set topological properties such as continuity or compactness.
    🔗

    Example 4.3.5. The cocountable topology.

    The cocountable topology \(\tau \) on a set \(X \) is the set
    \begin{equation*} \tau = \setmid{ U \in \ps \of{ X } }{ U = \emptyset \textrm{ or } X \setminus U \textrm{ is countable} }\text{.} \end{equation*}
    One can verify that \(\tau \) is a topology on \(X \) for which all convergent sequences are eventually constant. We have seen in Problem 3.2.5.1 Eventually constant sequences that the discrete topology has the same property. Moreover, if \(X \) is uncountable, then \(\tau \) is not the discrete topology on \(X \text{.}\)
    🔗
    In particular, if \(X \) is uncountable, then sequential convergence in the cocountable topology \(\tau \) on \(X \) is precisely the same as sequential convergence in the discrete topology \(\top_{ X } \) on \(X \text{,}\) even though these topologies are quite different.
    🔗
    🔗
    The above example of a topological space whose point-set topological properties cannot be defined solely in terms of the convergence/divergence of sequences motivates the following broadening of our scope to include more general indexed families of points. Instead of only considering families indexed by the natural numbers \(\N \text{,}\) we allow the indexing sets to be particular types of preordered sets called directed sets.
    🔗

    Definition 4.3.6. Directed set.

    A preordered set \(\of{ A , \precsim } \) is called upwards directed (resp. downwards directed) if every finite set of elements in \(A \) has a common upper bound (resp. common lower bound). An family \(\of{ x_{ \alpha } }_{ \alpha \in A } \) indexed by a directed set \(A \) is called a net.
    🔗
    🔗

    Example 4.3.7. Directed sets.

    The following are examples of directed sets.
    • Any totally ordered set is directed both upwards and downwards. Indeed, given two elements \(x , y \in X \) in a totally ordered set \(\of{ X , \leq } \text{,}\) either \(x \leq y \text{,}\) in which case \(x \leq x , y \leq y \text{,}\) or \(y \leq x \text{,}\) in which case \(y \leq x , y \leq x \text{.}\)
      🔗
      🔗
    • The power set \(\ps \of{ X } \) of a set \(X \) is directed both upwards and downwards. Indeed, given two subsets \(U , V \subseteq X \text{,}\)
      \begin{equation*} U \cap V \subseteq U , V \subseteq U \cup V\text{.} \end{equation*}
      🔗
      🔗
    • Fix a point \(c \in X \) in a metric space \(\of{ X , \rho } \text{,}\) and let \(\precsim_{ c } \) denote the binary relation on \(X \setminus \set{ c } \) defined so that \(x \precsim_{ c } y \) if and only if \(\rho \of{ x , c } \leq \rho \of{ y , c } \text{.}\) Then the preordered set \(\of{ X \setminus \set{ c } , \precsim_{ c } } \) is directed both upwards and downwards.
      🔗
      🔗
    • Fix a point \(x \in X \) in a topological space \(\of{ X , \tau } \text{.}\) The set \(\Nbhd \of{ x } \) of neighborhoods of \(x \) in \(X \) is partial ordered by containment \(\subseteq \text{,}\) and \(\Nbhd \of{ x } \) is directed both upwards and downwards. Indeed, the intersection and union of any finite collection of neighborhoods of \(x \) in \(X \) is itself a neighborhood of \(x \) in \(X \text{.}\)
      🔗
    • Let \(a , b \in \R \) be real numbers, and suppose that \(a \leq b \text{.}\) A finite partition of the closed interval \(\clint{ a }{ b } \) is a finite sequence \(\of{ x_{ j } }_{ j = 0 }^{ m } \) so that \(x_{ 0 } = a \) and \(x_{ m } = b \text{.}\) Given two such partitions \(P \) and \(Q \text{,}\) we write \(P \preceq Q \) if \(P \) is a subsequence of \(Q \text{.}\) Considered with this binary relation, the set of finite partitions of \(\clint{ a }{ b } \) is directed both upwards and downwards. This directed set will be an important part of the definition of the Riemann integral in Section 6.1 Riemann Sums.
      🔗
      🔗
    🔗
    🔗

    Definition 4.3.8. Net convergence.

    Let \(\of{ x_{ \alpha } }_{ \alpha \in A } \) be a net of points \(x_{ \alpha } \in X \) in a topological space \(\of{ X , \tau } \) indexed by a directed set \(\of{ A , \preceq } \text{.}\)
    • Upwards convergence.
      Suppose that the indexing set \(A \) is upwards directed. A net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \) converges upwards to a point \(x \in X \) if for all neighborhoods \(N \in \Nbhd \of{ x } \) of \(x \) in \(X \text{,}\) there is an index \(\alpha_{ N } \in A \) so that \(x_{ \alpha } \in N \) for all indices \(\alpha \succeq \alpha_{ N } \text{.}\)
      🔗
      The net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) is called upwards convergent if it converges upward to a point in \(X \text{,}\) and \(\of{ x_{ \alpha } }_{ \alpha \in A } \) is called upwards divergent if it does not converge upwards to any point in \(X \text{.}\)
      🔗
      If \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges upwards to a unique point \(x \in X \text{,}\) then this point is called the upwards limit of \(\of{ x_{ \alpha } }_{ \alpha \in A } \) and is denoted
      \begin{equation*} \lim_{ \alpha \uparrow }{ x_{ \alpha } } = x\text{.} \end{equation*}
      🔗
      🔗
    • Downwards convergence.
      Suppose that the indexing set \(A \) is downwards directed. A net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \) converges downwards to a point \(x \in X \) if for all neighborhoods \(N \in \Nbhd \of{ x } \) of \(x \) in \(X \text{,}\) there is an index \(\alpha_{ N } \in A \) so that \(x_{ \alpha } \in N \) for all indices \(\alpha \preceq \alpha_{ N } \text{.}\)
      🔗
      The net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) is called downwards convergent if it converges downward to a point in \(X \text{,}\) and \(\of{ x_{ \alpha } }_{ \alpha \in A } \) is called downwards divergent if it does not converge downwards to any point in \(X \text{.}\)
      🔗
      If \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges downwards to a unique point \(x \in X \text{,}\) then this point is called the downwards limit of \(\of{ x_{ \alpha } }_{ \alpha \in A } \) and is denoted
      \begin{equation*} \lim_{ \alpha \downarrow }{ x_{ \alpha } } = x\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Remark 4.3.9. Direction of convergence.

    If the indexing set \(A \) of a net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) of points \(x_{ \alpha } \in X \) in a topological space \(\of{ X , \tau } \) is directed either only upwards or only downwards, then one may speak of the convergence or limit of said net without specifying the direction. Similarly, we may avoid specifying the direction of convergence explicitly if it is clear from context.
    🔗
    🔗
    We will see that all interesting point-set topological notions can be defined in terms of the convergence of nets. For example, we now give such characterizations of limit points and isolated points.
    🔗

    Definition 4.3.10. Limit/isolated points.

    Consider a subset \(U \subseteq X \) of a topological space \(\of{ X , \tau } \text{.}\)
    • Limit point.
      We say that \(U \) accumulates at a point \(x \in X \) if \(N \cap U \not \subseteq \set{ x } \) for all neighborhoods \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \text{.}\) In this case, \(x \) is called a limit point (or accumulation point) of \(U \) in \(X \text{.}\) The set of such limit points of \(U \) in \(X \) is called the derived set of \(U \) and is denoted \(U' \text{.}\)
      🔗
      🔗
    • Isolated point.
      We say that a point \(x \in X \) is isolated from \(U \) if \(N \cap U \subseteq \set{ x } \) for some neighborhood \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \text{.}\) If this condition holds for some point \(x \in U \text{,}\) then \(x \) is called an isolated point of \(U \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proposition 4.3.11. Net characterization of limit points.

    Let \(U \subseteq X \) be a subset of a topological space \(\of{ X , \tau } \text{.}\) A point \(x \in X \) is a limit point of \(U \) in \(X \) if and only if some net \(\of{ u_{ \alpha } }_{ \alpha \in A } \) of points \(u_{ \alpha } \in U \setminus \set{ x } \) converges to \(x \text{.}\)
    🔗
    🔗

    Proof.
    First suppose that \(x \in X \) is a limit point of \(U \) in \(X \text{.}\) Then for each neighborhood \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \text{,}\) there is a point \(u \in N \cap U \setminus \set{ x } \text{.}\) The Axiom of choice allows us to choose an indexed family \(\of{ u_{ N } }_{ N \in \Nbhd_{ X } \of{ x } } \) of points \(u_{ N } \in U \setminus \set{ x } \) so that \(u_{ N } \in N \) for all indices \(N \in \Nbhd_{ X } \of{ x } \text{.}\)
    🔗
    We observe that for each neighborhood \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \text{,}\)
    \begin{equation*} u_{ M } \in M \subseteq N \end{equation*}
    for all indices \(M \subseteq N \text{.}\) Thus \(\of{ u_{ N } }_{ N \in \Nbhd_{ X } \of{ x } } \) converges downwards to \(x \text{.}\)
    🔗
    Conversely, suppose that \(x \in X \) is isolated from \(U \text{.}\) Then \(N \cap U \subseteq \set{ x } \) for some neighborhood \(N \in \Nbhd_{ X } \of{ x } \) of \(x \) in \(X \text{.}\) Let \(\of{ u_{ \alpha } }_{ \alpha \in A } \) be a net of points \(u_{ \alpha } \in U \setminus \set{ x } \text{.}\) We observe that \(u_{ \alpha } \notin N \) for all indices \(\alpha \in A \text{,}\) and so \(\of{ u_{ \alpha } }_{ \alpha \in A } \) does not converge to \(x \text{.}\)
    🔗
    🔗
    The main utility of net convergence is in generalizing the sequential characterizations of various point-set topological notions to general topological spaces. Indeed, all sequential characterizations of such properties for metric spaces have analogs in terms of the convergence of nets. However, we will see that additional hypotheses on the spaces in question will allow us to recover these sequential characterizations, even if they do not hold in the most general case. For example, first-countability is sufficient (although not necessary) to guarantee the equivalence of the general topological notions with their sequential counterparts.
    🔗
    🔗

    Subsection 4.3.2 The Separation Axioms

    The non-degeneracy of a metric implies that any two distinct points in a metric space are separated by some positive distance, and hence are the centers of disjoint metric open balls of positive radius. These separation properties of a metric space have strong implications for the uniqueness of limits. For general topological spaces, there is a zoo of distinct yet related versions of these separation axioms which seek to compare how a given topology separates points relative to the discrete and indiscrete topologies.
    🔗
    The indiscrete topological spaces are the least separated among all topological spaces. If a topological space \(\of{ X , \tau } \) is indiscrete, then there is no point-set topological way to distinguish between the points of \(X \text{.}\) At the very least, all separation axioms must address this glaring pathology.
    🔗

    Definition 4.3.12. Topological distinguishability.

    Let \(\of{ X , \tau } \) be a topological space.
    • Topological indistinguishability.
      Two points \(x_{ 1 } , x_{ 2 } \in X \) are called topologically indistinguishable if they have precisely the same neighborhoods
      \begin{equation*} \Nbhd \of{ x_{ 1 } } = \Nbhd \of{ x_{ 2 } }\text{;} \end{equation*}
      that is, \(x_{ 1 } \) and \(x_{ 2 } \) are topologically indistinguishable if for any subset \(N \subseteq X \text{,}\) \(N \) is a neighborhood of \(x_{ 1 } \) in \(X \) if and only if \(N \) is a neighborhood of \(x_{ 2 } \) in \(X \text{.}\)
      🔗
      🔗
    • Topological distinguishability.
      Two points \(x_{ 1 } , x_{ 2 } \in X \) are called topologically distinguishable if
      \begin{equation*} \Nbhd \of{ x_{ 1 } } \neq \Nbhd \of{ x_{ 2 } }\text{;} \end{equation*}
      that is, \(x_{ 1 } \) and \(x_{ 2 } \) are topologically indistinguishable if there is some subset \(N \subseteq X \) which is a neighborhood of one of \(x_{ 1 } \) and \(x_{ 2 } \) but not a neighborhood of the other.
      🔗
      🔗
    A topological space \(\of{ X , \tau } \) is called \(T_{ 0 } \) or Kolmogorov if all pairs of distinct points in \(X \) are topologically distinguishable.
    🔗
    🔗

    Example 4.3.13. \(T_{ 0 } \) spaces.

    The following are examples and non-examples of \(T_{ 0 } \) spaces:
    • Any two points \(x_{ 1 } , x_{ 2 } \in X \) in an indiscrete space \(\of{ X , \bot_{ X } } \) are topologically indistinguishable. As such, any indiscrete space with at least two points is not \(T_{ 0 } \text{.}\)
      🔗
      🔗
    • The points \(0 \) and \(1 \) in the Sierpiński space \(\of{ X , \tau } \) with ground set \(X = \set{ 0 , 1 } \) and topology \(\tau = \set{ \emptyset , \set{ 1 } , \set{ 0 , 1 } } \) are topologically distinguishable, since \(\set{ 1 } \) is a neighborhood of \(1 \) in \(X \) but not a neighborhood of \(0 \) in \(X \text{.}\) In particular, \(\of{ X , \tau } \) is \(T_{ 0 } \text{.}\)
      🔗
      🔗
    🔗
    🔗
    We have previously seen that sequential limits in the Sierpiński space are not unique, and so \(T_{ 0 } \) is not a strong enough separation axiom to impose unique limits. One issue of separability in the Sierpiński space is that every neighborhood of \(0 \) contains \(1 \text{.}\) The following separation axiom aims to address this issue.
    🔗

    Definition 4.3.14. Separation.

    Two points \(x_{ 1 } , x_{ 2 } \in X \) in a topological space \(\of{ X , \tau } \) are called separated if there are neighborhoods \(N_{ 1 } \subseteq X \) and \(N_{ 2 } \subseteq X \) of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(x_{ 1 } \notin N_{ 2 } \) and \(x_{ 2 } \notin N_{ 1 } \text{.}\)
    🔗
    A topological space \(\of{ X , \tau } \) is called \(T_{ 1 } \) or Fréchet if all pairs of distinct points in \(X \) are separated.
    🔗
    🔗

    Example 4.3.15. \(T_{ 1 } \) spaces.

    The following are examples and non-examples of \(T_{ 1 } \) spaces:
    • The points \(0 \) and \(1 \) in the Sierpiński space \(\of{ X , \tau } \) with ground set \(X = \set{ 0 , 1 } \) and topology \(\tau = \set{ \emptyset , \set{ 1 } , \set{ 0 , 1 } } \) are not separated, since every neighborhood of \(0 \) in \(X \) contains \(1 \text{.}\) Since two distinct points are not separated, the Sierpiński space is not \(T_{ 1 } \text{.}\)
      🔗
      🔗
    • A subset \(U \subseteq X \) of a set \(X \) is called cofinite if its complement \(X \setminus U \) is finite. The cofinite subsets of \(X \) comprise a topology \(\tau \) on \(X \) called the cofinite topology on \(X \text{.}\)
      🔗
      If \(X \) is finite, then every subset of \(X \) is cofinite, and so the cofinite topology on \(X \) is discrete. However, if \(X \) is infinite, then for any distinct points \(x_{ 1 } , x_{ 2 } \in X \text{,}\) \(N_{ 1 } = X \setminus \set{ x_{ 2 } } \) and \(N_{ 2 } = X \setminus \set{ x_{ 1 } } \) are neighborhoods of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(x_{ 1 } \notin N_{ 2 } \) and \(x_{ 2 } \notin N_{ 1 } \text{,}\) and so \(x_{ 1 } \) and \(x_{ 2 } \) are separated. Since any pair of distinct points are separated, \(\of{ X , \tau } \) is \(T_{ 1 } \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Lemma 4.3.16. Topological distinguishability and separation.

    Two separated points in a topological space are topologically distinguishable.
    🔗
    🔗

    Proof.
    Let \(x_{ 1 } , x_{ 2 } \in X \) be points in a topological space \(\of{ X , \tau } \text{.}\) If \(x_{ 1 } \) and \(x_{ 2 } \) are separated, then there are neighborhoods \(N_{ 1 } \in \Nbhd \of{ x_{ 1 } } \) and \(N_{ 2 } \in \Nbhd \of{ x_{ 2 } } \) of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(x_{ 1 } \notin N_{ 2 } \) and \(x_{ 2 } \notin N_{ 1 } \text{.}\) In particular, \(N_{ 1 } \in \Nbhd \of{ x_{ 1 } } \setminus \Nbhd \of{ x_{ 2 } } \) is a neighborhood of \(x_{ 1 } \) but not a neighborhood of \(x_{ 2 } \text{,}\) and so \(x_{ 1 } \) and \(x_{ 2 } \) are topologically distinguishable.
    🔗
    🔗

    Proposition 4.3.17. \(T_{ 0 } \) and \(T_{ 1 } \) spaces.

    Any \(T_{ 1 } \) space is \(T_{ 0 } \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\of{ X , \tau } \) be a \(T_{ 1 } \) space. Then any two distinct points \(x_{ 1 } , x_{ 2 } \in X \) are separated, and so Lemma 4.3.16 Topological distinguishability and separation implies that \(x_{ 1 } \) and \(x_{ 2 } \) are topologically distinguishable. Since any two distinct points are topologically distinguishable, \(\of{ X , \tau } \) is \(T_{ 0 } \text{.}\)
    🔗
    🔗
    Although \(T_{ 1 } \) is a much stronger separation axiom than \(T_{ 0 } \text{,}\) it is still not strong enough to force the uniqueness of sequential/net limits. Indeed, we note that the sequence \(\of{ n }_{ n = 0 }^{ \infty } \) of natural numbers converges in the cofinite topology on \(\N \) to every single natural number. One issue here is that while distinct points in a \(T_{ 1 } \) space have distinct neighborhoods, they might not have disjoint neighborhoods. The following and final separation axiom we will consider here aims to address this issue.
    🔗

    Definition 4.3.18. Separation by neighborhoods.

    Two points \(x_{ 1 } , x_{ 2 } \in X \) in a topological space \(\of{ X , \tau } \) are called separated by neighborhoods if there are neighborhoods \(N_{ 1 } \in \Nbhd \of{ x_{ 1 } } \) and \(N_{ 2 } \in \Nbhd \of{ x_{ 2 } } \) of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(N_{ 1 } \cap N_{ 2 } = \emptyset \text{.}\)
    🔗
    A topological space \(\of{ X , \tau } \) is called \(T_{ 2 } \) or Hausdorff if all pairs of distinct points in \(X \) are separated by neighborhoods.
    🔗
    🔗

    Example 4.3.19. \(T_{ 2 } \) spaces.

    The following are examples and non-examples of \(T_{ 2 } \) spaces:
    • If \(X \) is an infinite set, then no two cofinite subsets of \(X \) are disjoint. Indeed, given two such cofinite subsets \(U , V \subseteq X \text{,}\)
      \begin{equation*} X \setminus \of{ U \cap V } = \of{ X \setminus U } \cup \of{ X \setminus V } \end{equation*}
      is the union of two finite sets and is therefore finite. Since \(X \) is infinite and \(U \cap V \) is cofinite, \(U \cap V \neq \emptyset \) is non-empty.
      🔗
      In particular, if \(X \) is an infinite set, then the above argument implies that the cofinite topology on \(X \) is not \(T_{ 2 } \text{,}\) since any neighborhoods of any two distinct points \(x_{ 1 } , x_{ 2 } \in X \) intersect.
      🔗
      🔗
    • Let \(\of{ X , \rho } \) be a metric space, and consider two distinct points \(x_{ 1 } , x_{ 2 } \in X \text{.}\) The non-degeneracy of the metric \(\rho \) implies that \(\rho \of{ x_{ 1 } , x_{ 2 } } \gt 0 \text{.}\) Note that for any point \(x \in X \text{,}\) if \(\rho \of{ x , x_{ 1 } } \lt \frac{ \rho \of{ x_{ 1 } , x_{ 2 } } }{ 2 } \text{,}\) then Proposition 3.1.5 Reverse triangle inequality implies that
      \begin{align*} \rho \of{ x , x_{ 2 } } \amp \geq \abs{ \rho \of{ x_{ 1 } , x_{ 2 } } - \rho \of{ z , x_{ 1 } } } \geq \rho \of{ x_{ 1 } , x_{ 2 } } - \rho \of{ z , x_{ 1 } }\\ \amp \gt \rho \of{ x_{ 1 } , x_{ 2 } } - \frac{ \rho \of{ x_{ 1 } , x_{ 2 } } }{ 2 } = \rho \of{ x_{ 1 } , x_{ 2 } }\text{.} \end{align*}
      Similarly, if \(\rho \of{ x , x_{ 2 } } \lt \frac{ \rho \of{ x_{ 1 } , x_{ 2 } } }{ 2 } \text{,}\) then \(\rho \of{ x , x_{ 2 } } \gt \frac{ \rho \of{ x_{ 1 } , x_{ 2 } } }{ 2 } \text{.}\) In particular, let \(N_{ i } = \mB_{ \frac{ \rho \of{ x_{ 1 } , x_{ 2 } } }{ 2 } } \of{ x_{ i } } \in \Nbhd \of{ x_{ i } } \) for each \(i \in \set{ 1 , 2 } \text{,}\) and note that \(N_{ 1 } \cap N_{ 2 } = \emptyset \text{.}\) Thus every metrizable space is \(T_{ 2 } \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Lemma 4.3.20. Separation by neighborhoods and separation.

    Two points in a topological space which are separated by neighborhoods are separated.
    🔗
    🔗

    Proof.
    Let \(x_{ 1 } , x_{ 2 } \in X \) be points in a topological space \(\of{ X , \tau } \text{.}\) If \(x_{ 1 } \) and \(x_{ 2 } \) are separated by neighborhoods, then there are neighborhoods \(N_{ 1 } \in \Nbhd \of{ x_{ 1 } } \) and \(N_{ 2 } \in \Nbhd \of{ x_{ 2 } } \) of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(N_{ 1 } \cap N_{ 2 } = \emptyset \text{.}\) In particular, \(x_{ 1 } \notin N_{ 2 } \) and \(x_{ 2 } \notin N_{ 1 } \text{,}\) and so \(x_{ 1 } \) and \(x_{ 2 } \) are separated.
    🔗
    🔗

    Proposition 4.3.21. \(T_{ 1 } \) and \(T_{ 2 } \) spaces.

    Any \(T_{ 2 } \) space is \(T_{ 1 } \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\of{ X , \tau } \) be a \(T_{ 2 } \) space. Then any two distinct points \(x_{ 1 } , x_{ 2 } \in X \) are separated by neighborhoods, and so Lemma 4.3.20 Separation by neighborhoods and separation implies that \(x_{ 1 } \) and \(x_{ 2 } \) are separated. Since any two distinct points are separated, \(\of{ X , \tau } \) is \(T_{ 1 } \text{.}\)
    🔗
    🔗
    The main attraction of the \(T_{ 2 } \) separation axiom is that it is the minimal required hypotheses on a topological space to guarantee the uniqueness of limits for convergent sequences and nets of points.
    🔗

    Theorem 4.3.22. Uniqueness of limits in \(T_{ 2 } \) spaces.

    If a net of points in a \(T_{ 2 } \) space converges, then it converges to a unique limit.
    🔗
    🔗

    Proof.
    Let \(\of{ x_{ \alpha } }_{ \alpha \in A } \) be a net of points \(x_{ \alpha } \in X \) in a \(T_{ 2 } \) space \(\of{ X , \alpha } \) indexed by a directed set \(\of{ A , \precsim } \text{.}\) We will prove the result in the case \(A \) is directed upwards; the downwards directed case is entirely analogous.
    🔗
    Suppose for a contradiction that the net \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges upwards to two distinct points \(x_{ 1 } , x_{ 2 } \in X \text{.}\) Since \(\of{ X , \tau } \) is \(T_{ 2 } \text{,}\) \(x_{ 1 } \) and \(x_{ 2 } \) are separated by neighborhoods; that is, there are neighborhoods \(N_{ 1 } \in \Nbhd \of{ x_{ 1 } } \) and \(N_{ 2 } \in \Nbhd \of{ x_{ 2 } } \) of \(x_{ 1 } \) and \(x_{ 2 } \) in \(X \text{,}\) respectively, so that \(N_{ 1 } \cap N_{ 2 } = \emptyset \text{.}\) Since \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges to both \(x_{ 1 } \) and \(x_{ 2 } \text{,}\) there are indices \(\alpha_{ N_{ 1 } } , \alpha_{ N_{ 2 } } \in A \) so that \(x_{ \alpha } \in N_{ 1 } \) for all indices \(\alpha \succsim \alpha_{ N_{ 1 } } \) and \(x_{ \alpha } \in N_{ 2 } \) for all indices \(\alpha \succsim \alpha_{ N_{ 2 } } \text{.}\)
    🔗
    Since \(A \) is directed upwards, there is some index \(\alpha \in A \) so that \(\alpha_{ N_{ 1 } } , \alpha_{ N_{ 2 } } \preceq \alpha \text{.}\) We conclude that \(x_{ \alpha } \in N_{ 1 } \) and \(x_{ \alpha } \in N_{ 2 } \text{,}\) and so \(x_{ \alpha } \in N_{ 1 } \cap N_{ 2 } = \emptyset \text{.}\) This contradiction implies that \(\of{ x_{ \alpha } }_{ \alpha \in A } \) converges to at most one point in \(X \text{.}\)
    🔗
    🔗
    While there are many separation axioms beyond \(T_{ 0 } \text{,}\) \(T_{ 1 } \text{,}\) and \(T_{ 2 } \text{,}\) their utility is highly context-dependent and field-specific. However, the \(T_{ 2 } \)/Hausdorff property is ubiquitous throughout all of point-set topology and real analysis.
