    Section 2.4 Beyond the Real Number System

    In this section, we address several common extensions to the real number system \(\R \text{.}\) Some of these, like the complex numbers and the quaternions, see extensions to arithmetic (at the cost of some of the ordered field axioms). Others, like the extended real numbers, abandon arithmetic altogether in favor of certain order-theoretic properties.
    🔗

    Subsection 2.4.1 The Complex Numbers

    Despite not playing a large role in the field of real analysis, the complex number system is ubiquitous throughout mathematics and merits at least a brief mention. The extension of the real numbers to the complex numbers ameliorates an algebraic insufficiency of \(\R \text{,}\) namely that it does not contain the roots of all polynomials. For example, there is no real number \(x \in \R \) so that \(x^{ 2 } + 1 = 0 \text{.}\)
    🔗

    Definition 2.4.1. Complex number.

    A complex number is an ordered pair \(z = \of{ x , y } \) of real numbers \(x , y \in \R \text{,}\) the first of which is called the real part and is denoted \(\Re \of{ z } = x \) and the second of which is called the imaginary part and is denoted \(\Im \of{ z } = y \text{.}\) The set of all complex numbers is denoted \(\C \text{.}\)
    🔗
    The sum \(z_{ 1 } + z_{ 2 } \) and product \(z_{ 1 } z_{ 2 } \) of two complex numbers \(z_{ 1 } , z_{ 2 } \in \C \) are the complex numbers defined by the formulae
    \begin{align*} z_{ 1 } + z_{ 2 } \amp = \of{ \Re \of{ z_{ 1 } } + \Re \of{ z_{ 2 } } , \Im \of{ z_{ 1 } } + \Im \of{ z_{ 2 } } }\\ z_{ 1 } z_{ 2 } \amp = \of{ \Re \of{ z_{ 1 } } \cdot \Re \of{ z_{ 2 } } - \Im \of{ z_{ 1 } } \cdot \Im \of{ z_{ 2 } } , \Re \of{ z_{ 1 } } \cdot \Im \of{ z_{ 2 } } + \Im \of{ z_{ 1 } } \cdot \Re \of{ z_{ 2 } } }\text{.} \end{align*}
    The imaginary unit \(i \) is the complex number \(\of{ 0 , 1 } \text{,}\) and we note that
    \begin{equation*} i \cdot i = \of{ 0 , 1 } \cdot \of{ 0 , 1 } = \of{ 0 \cdot 0 - 1 \cdot 1 , 0 \cdot 1 + 1 \cdot 0 } = \of{ -1 , 0 }\text{.} \end{equation*}
    🔗
    🔗

    Lemma 2.4.2. Real numbers as complex numbers.

    There is an injective map \(\iota \colon \R \to \C \) so that \(\iota \of{ x_{ 1 } + x_{ 2 } } = \iota \of{ x_{ 1 } } + \iota \of{ x_{ 2 } } \) and \(\iota \of{ x_{ 1 } x_{ 2 } } = \iota \of{ x_{ 1 } } \cdot \iota \of{ x_{ 2 } } \) for all real numbers \(x_{ 1 } , x_{ 2 } \in \R \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\iota \colon \R \to \C \) be the function defined by the formula \(\iota \of{ x } = \of{ x , 0 } \text{.}\) Since projection \(\pi \colon \C \to \R \) onto the first factor is a left inverse to \(\iota \text{,}\) \(\iota \) is left-invertible and hence injective by (1) of Theorem 1.2.15 Invertibility. Moreover,
    \begin{equation*} \iota \of{ x_{ 1 } + x_{ 2 } } = \of{ x_{ 1 } + x_{ 2 } , 0 } = \of{ x_{ 1 } , 0 } + \of{ x_{ 2 } , 0 } = \iota \of{ x_{ 1 } } + \iota \of{ x_{ 2 } }\text{,} \end{equation*}
    and
    \begin{align*} \iota \of{ x_{ 1 } x_{ 2 } } \amp = \of{ x_{ 1 } x_{ 2 } , 0 } = \of{ x_{ 1 } x_{ 2 } - 0 \cdot 0 , x_{ 1 } \cdot 0 - 0 \cdot x_{ 2 } }\\ \amp = \of{ x_{ 1 } , 0 } \cdot \of{ x_{ 2 } , 0 } = \iota \of{ x_{ 1 } } \cdot \iota \of{ x_{ 2 } } \end{align*}
    for all real numbers \(x_{ 1 } , x_{ 2 } \in \R \text{.}\)
    🔗
    🔗
    As in previous extensions of the usual number systems, we will use the injective map \(\iota \colon \R \to \C \) defined in Lemma 2.4.2 Real numbers as complex numbers to view the real numbers \(\R \) as a subset of the complex numbers \(\C \text{.}\) As a first example of this, we will denote the complex number \(\of{ x , y } \) as \(x + y i \) going forward.
    🔗

    Definition 2.4.3. Complex conjugate.

    The conjugate \(\overline{ z } \) of a complex number \(x + y i \in \C \) is the complex number \(\overline{ z } = x - y i \text{.}\)
    🔗
    🔗

    Lemma 2.4.4. Complex conjugates.

    For all complex numbers \(z \in \C \text{,}\) \(z \overline{ z } \) is a non-negative real number, and \(z \overline{ z } \) is positive if and only if \(z \neq 0 \) is non-zero
    🔗
    🔗

    Proof.
    Let \(z = x + y i \in \C \) be a complex number, and note that
    \begin{equation*} z \overline{ z } = \of{ x + y i } \of{ x - y i } = \of{ x^{ 2 } + y^{ 2 } } + 0 i = x^{ 2 } + y^{ 2 } \end{equation*}
    is a sum of squares of real numbers, and hence is non-negative. Moreover, \(z \overline{ z } = x^{ 2 } + y^{ 2 } \) is positive unless \(x = y = 0 \text{,}\) in which case \(z = 0 \) as well.
    🔗
    🔗

    Definition 2.4.5. Magnitude of a complex number.

    The magnitude \(\abs{ z } \) of a complex number \(z \in \C \) is the non-negative real number defined by \(\abs{ z }^{ 2 } = z \overline{ z } \text{.}\)
    🔗
    🔗

    Proposition 2.4.6. The field of complex numbers.

    \(\of{ \C , + , \oparg } \) is a field.
    🔗
    🔗
    While the complex numbers \(\C \) are a field, they are not an ordered field.
    🔗

    Proposition 2.4.7. Orders on the complex numbers.

    There is no total order \(\leq \) on the complex numbers \(\C \) so that \(\of{ \C , + , \cdot , \leq } \) is an ordered field.
    🔗
    🔗
    So the addition of the non-real complex numbers to the real number system \(\R \) comes at the expense of some of the ordered field axioms. We will see that this is also true of further extensions; for example, multiplication of quaternions is not commutative.
    🔗
    🔗

    Subsection 2.4.2 Infinity

    🔗

    Definition 2.4.8. Extended real number.

    An extended real number is either a real number or one of two infinite elements \(\infty \) or \(-\infty \text{.}\) The set of extended real numbers is denoted \(\overline{ \R } = \R \cup \set{ \infty , -\infty } \text{.}\)
    🔗
    The standard ordering \(\leq \) on the real numbers \(\R \) is extended to a total order on \(\overline{ \R } \) by requiring \(-\infty \leq x \leq \infty \) for all real numbers \(x \in \R \text{.}\)
    🔗
    🔗

    Definition 2.4.9. Interval.

    Let \(a , b \in \overline{ \R } \) be extended real numbers so that \(a \leq b \text{.}\)
    1. Closed interval.
      The closed interval \(\clint{ a }{ b } \) from \(a \) to \(b \) is the subset of the extended real numbers \(\overline{ \R } \) defined by
      \begin{equation*} \clint{ a }{ b } = \setmid{ x \in \overline{ \R } }{ a \leq x \leq b }\text{.} \end{equation*}
      🔗
      🔗
    2. Open interval.
      The open interval \(\opint{ a }{ b } \) from \(a \) to \(b \) is the subset of the extended real numbers \(\overline{ \R } \) defined by
      \begin{equation*} \opint{ a }{ b } = \setmid{ x \in \overline{ \R } }{ a \lt x \lt b }\text{.} \end{equation*}
      🔗
      🔗
    3. Half-closed, half-open interval.
      The half-closed, half-open interval \(\clopint{ a }{ b } \) from \(a \) to \(b \) is the subset of the extended real numbers \(\overline{ \R } \) defined by
      \begin{equation*} \clopint{ a }{ b } = \setmid{ x \in \overline{ \R } }{ a \leq x \lt b }\text{.} \end{equation*}
      🔗
      🔗
    4. Closed interval.
      The half-open, half-closed interval \(\opclint{ a }{ b } \) from \(a \) to \(b \) is the subset of the extended real numbers \(\overline{ \R } \) defined by
      \begin{equation*} \opclint{ a }{ b } = \setmid{ x \in \overline{ \R } }{ a \lt x \leq b }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Example 2.4.10. Intervals.

    The following are examples of intervals:
    • (Extended) real numbers.
      The real numbers \(\R \) and the extended real numbers \(\overline{ \R } \) are open and closed intervals, respectively; concretely, \(\R = \opint{ -\infty }{ \infty } \) and \(\overline{ \R } = \clint{ -\infty }{ \infty } \text{.}\)
      🔗
      🔗
    • Dedekind cuts.
      Given a real number \(x \in \R \text{,}\) the Dedekind cut \(X \) corresponding to \(x \) is \(X = \Q \cap \opint{ -\infty }{ x } \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Theorem 2.4.11. Suprema and infima.

    Any subset of the extended real numbers \(\overline{ \R } \) has a supremum in \(\overline{ \R } \text{.}\)
    🔗
    🔗

    Proof.
    Let \(U \subseteq \overline{ \R } \) be a subset of the extended real numbers \(\R \text{.}\) If \(\infty \in U \text{,}\) then \(\sup \of{ U } = \max \of{ U } = \infty \text{.}\) If \(\infty \notin U \) and \(U \cap \R \) is not bounded from above, then
    \begin{equation*} \sup \of{ U } = \sup \of{ U \cap \R } = \infty\text{.} \end{equation*}
    If \(\infty \notin U \) and \(U \cap \R \neq \emptyset \) is bounded from above, then
    \begin{equation*} \sup \of{ U } = \sup \of{ U \cap \R }\text{.} \end{equation*}
    Finally, if \(\infty \notin U \) and \(U \cap \R = \emptyset \text{,}\) then \(\sup \of{ U } = -\infty \text{.}\)
    🔗
    🔗
