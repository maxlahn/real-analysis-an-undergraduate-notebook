    Section 5.4 Higher Order Approximations

    In this section, we explore the properties of the Taylor approximations of a multiply differentiable function. In a sense which we will make precise, these polynomials are the best possible approximations for such a function near a given point. We will also compute the error in such approximations by means similar to the Mean value theorem.
    🔗

    Subsection 5.4.1 Dominance and Asymptotics

    How can we compare the speed at which two functions converge to \(0 \) or diverge to infinity? We may be able to see graphically that while both \(x^{ 2 } \) and \(x^{ 4 } \) converge at \(0 \) to \(0 \text{,}\) \(x^{ 4 } \) converges far more quickly. One attempt to quantify observations of this type is the family of related binary relations comprising the notion of asymptotic comparison.
    🔗

    Definition 5.4.1. Asymptotic comparison.

    Let \(f , g \colon X \to \R \) be real-valued functions defined on a subset \(X \subseteq \R \text{,}\) and fix a limit point \(c \in X' \text{.}\)
    • Asymptotic dominance.
      We say that \(f \) is asymptotically dominated by \(g \) near \(c \) if
      \begin{equation*} \abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \end{equation*}
      for some non-negative real-valued function \(\lambda \colon X \to \clopint{ 0 }{ \infty } \) and non-negative real number \(0 \leq L \lt \infty \) so that
      \begin{equation*} \lim_{ x \to c }{ \lambda \of{ x } } = L\text{.} \end{equation*}
      In this case, we write \(f \preccurlyeq g \) as \(x \to c \text{.}\)
      🔗
      🔗
    • Asymptotic comparability.
      We say that \(f \) and \(g \) are asymptotically comparable near \(c \) if
      \begin{equation*} \abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \end{equation*}
      for some non-negative real-valued function \(\lambda \colon X \to \clopint{ 0 }{ \infty } \) and positive real number \(0 \lt L \lt \infty \) so that
      \begin{equation*} \lim_{ x \to c }{ \lambda \of{ x } } = L\text{.} \end{equation*}
      In this case, we write \(f \asymp g \) as \(x \to c \text{.}\)
      🔗
      🔗
    • Asymptotic.
      We say that \(f \) is asymptotic to \(g \) near \(c \) if
      \begin{equation*} \abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \end{equation*}
      for some non-negative real-valued function \(\lambda \colon X \to \clopint{ 0 }{ \infty } \) so that
      \begin{equation*} \lim_{ x \to c }{ \lambda \of{ x } } = 1\text{.} \end{equation*}
      In this case, we write \(f \sim g \) as \(x \to c \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 5.4.2. Asymptotic comparison.

    The following are examples of asymptotic dominance, asymptotic comparability, and asymptotics:
    • Consider two power functions \(f , g \colon \opint{ 0 }{ \infty } \to \R \) defined by the formulas \(f \of{ x } = a x^{ p } \) and \(g \of{ x } = b x^{ q } \) for some real numbers \(a , b , p , q \in \R \) so that \(a , b \neq 0 \text{.}\) Suppose that \(p \leq q \text{,}\) and consider the real-valued function \(\lambda \colon \opint{ 0 }{ \infty } \to \R \) defined by the formula
      \begin{equation*} \lambda \of{ x } = \abs{ \frac{ a }{ b } } x^{ p - q }\text{.} \end{equation*}
      We observe that
      \begin{align*} \abs{ f \of{ x } } \amp = \abs{ a x^{ p } } = \abs{ a } \cdot \abs{ x }^{ p } = \abs{ a } x^{ p }\\ \amp = \frac{ \abs{ a } }{ \abs{ b } } x^{ p - q } \cdot \abs{ b } x^{ q } = \abs{ \frac{ a }{ b } } x^{ p - q } \cdot \abs{ b x^{ q } } = \lambda \of{ x } \abs{ g \of{ x } } \end{align*}
      for all points \(0 \lt x \lt \infty \text{,}\) and
      \begin{align*} \lim_{ x \to \infty }{ \lambda \of{ x } } \amp = \lim_{ x \to \infty }{ \abs{ \frac{ a }{ b } } x^{ p - q } } = \abs{ \frac{ a }{ b } } \lim_{ x \to \infty }{ x^{ p - q } }\\ \amp = \abs{ \frac{ a }{ b } } \cdot 0 = 0\text{,} \end{align*}
      since \(p - q \lt 0 \text{.}\) We conclude that \(f \preccurlyeq g \) as \(x \to \infty \text{.}\)
      🔗
      On the other hand, \(\abs{ g \of{ x } } = \of{ \frac{ 1 }{ \lambda \of{ x } } } \abs{ f \of{ x } } \) for all points \(0 \lt x \lt \infty \text{,}\) and
      \begin{align*} \lim_{ x \to 0 }{ \frac{ 1 }{ \lambda \of{ x } } } \amp = \lim_{ x \to 0 }{ \frac{ 1 }{ \abs{ \frac{ a }{ b } } x^{ p - q } } } = \lim_{ x \to 0 }{ \abs{ \frac{ b }{ a } } x^{ q - p } }\\ \amp = \abs{ \frac{ b }{ a } } \lim_{ x \to 0 }{ x^{ q - p } } = \abs{ \frac{ b }{ a } } \cdot 0 = 0\text{,} \end{align*}
      since \(q - p \gt 0 \text{.}\) We conclude that \(g \preccurlyeq f \) as \(x \to 0 \text{.}\)
      🔗
      🔗
    • Let \(f \colon \R \setminus \set{ x_{ 1 } , \dotsc , x_{ n } } \to \R \) be a rational function with formula
      \begin{equation*} f \of{ x } = \frac{ a_{ m } x^{ m } + a_{ m - 1 } x^{ m - 1 } + \dotsb + a_{ 2 } x^{ 2 } + a_{ 1 } x + a_{ 0 } }{ b_{ n } x^{ n } + b_{ n - 1 } x^{ n - 1 } + \dotsb + b_{ 2 } x^{ 2 } + b_{ 1 } x + b_{ 0 } } \end{equation*}
      in standard form, and consider the power functions \(g , h \colon \opint{ 0 }{ \infty } \to \R \) defined by the formulas
      \begin{align*} g \of{ x } \amp = x^{ m - n } \amp h \of{ x } \amp = \of{ \frac{ a_{ m } }{ b_{ n } } } x^{ m - n }\text{.} \end{align*}
      Let \(\lambda \colon \opint{ 0 }{ \infty } \setminus \set{ x_{ 1 } , \dotsc , x_{ n } } \to \R \) be the real-valued function defined by the formula
      \begin{equation*} \lambda \of{ x } = \frac{ a_{ m } + a_{ m - 1 } x^{ -1 } + \dotsb + a_{ 2 } x^{ 2 - m } a_{ 1 } x^{ 1 - m } + a_{ 0 } x^{ -m } }{ b_{ n } + b_{ n - 1 } x^{ -1 } + \dotsb + b_{ 2 } x^{ 2 - n } + b_{ 1 } x^{ 1 - n } + b_{ 0 } x^{ -n } }\text{.} \end{equation*}
      We observe that
      \begin{align*} \lambda \of{ x } \abs{ g \of{ x } } \amp = x^{ m - n } \abs{ \frac{ a_{ m } + a_{ m - 1 } x^{ -1 } + \dotsb + a_{ 2 } x^{ 2 - m } a_{ 1 } x^{ 1 - m } + a_{ 0 } x^{ -m } }{ b_{ n } + b_{ n - 1 } x^{ -1 } + \dotsb + b_{ 2 } x^{ 2 - n } + b_{ 1 } x^{ 1 - n } + b_{ 0 } x^{ -n } } }\\ \amp = \of{ \frac{ x^{ m } }{ x^{ n } } } \abs{ \frac{ a_{ m } + a_{ m - 1 } x^{ -1 } + \dotsb + a_{ 2 } x^{ 2 - m } a_{ 1 } x^{ 1 - m } + a_{ 0 } x^{ -m } }{ b_{ n } + b_{ n - 1 } x^{ -1 } + \dotsb + b_{ 2 } x^{ 2 - n } + b_{ 1 } x^{ 1 - n } + b_{ 0 } x^{ -n } } }\\ \amp = \abs{ \frac{ a_{ m } x^{ m } + a_{ m - 1 } x^{ m - 1 } + \dotsb + a_{ 2 } x^{ 2 } + a_{ 1 } x + a_{ 0 } }{ b_{ n } x^{ n } + b_{ n - 1 } x^{ n - 1 } + \dotsb + b_{ 2 } x^{ 2 } + b_{ 1 } x + b_{ 0 } } } = \abs{ f \of{ x } }\text{,} \end{align*}
      and
      \begin{align*} \lim_{ x \to \infty }{ \lambda \of{ x } } \amp = \lim_{ x \to \infty }{ \frac{ a_{ m } + a_{ m - 1 } x^{ -1 } + \dotsb + a_{ 2 } x^{ 2 - m } a_{ 1 } x^{ 1 - m } + a_{ 0 } x^{ -m } }{ b_{ n } + b_{ n - 1 } x^{ -1 } + \dotsb + b_{ 2 } x^{ 2 - n } + b_{ 1 } x^{ 1 - n } + b_{ 0 } x^{ -n } } }\\ \amp = \frac{ a_{ m } }{ b_{ n } } \in \opint{ 0 }{ \infty }\text{.} \end{align*}
      We conclude that \(f \asymp g \) as \(x \to \infty \text{.}\)
      🔗
      Moreover,
      \begin{align*} \abs{ \frac{ b_{ n } }{ a_{ m } } } \lambda \of{ x } \abs{ h \of{ x } } \amp = \abs{ \frac{ b_{ n } }{ a_{ m } } } \lambda \of{ x } \abs{ \of{ \frac{ a_{ m } }{ b_{ n } } } x^{ m - n } }\\ \amp = \lambda \of{ x } \abs{ g \of{ x } } = \abs{ f \of{ x } }\text{,} \end{align*}
      and
      \begin{equation*} \lim_{ x \to \infty }{ \abs{ \frac{ b_{ n } }{ a_{ m } } } \lambda \of{ x } } = \abs{ \frac{ b_{ n } }{ a_{ m } } } \lim_{ x \to \infty }{ \lambda \of{ x } } = \abs{ \frac{ b_{ n } }{ a_{ m } } } \abs{ \frac{ a_{ m } }{ b_{ n } } } = 1 \text{.} \end{equation*}
      We conclude that \(f \sim h \) as \(x \to \infty \text{.}\)
      🔗
      🔗
    🔗
    🔗
    One can see from the definitions that if two functions are asymptotic, then they are asymptotically comparable. Moreover, if two functions are asymptotically comparable, then each asymptotically dominates the other. In fact, the converse implication also holds.
    🔗

    Lemma 5.4.3. Asymptotic comparison.

    Let \(f , g \colon X \to \R \) be real-valued functions defined on a subset \(X \subseteq \R \text{,}\) and fix a limit point \(c \in X' \text{.}\) Then \(f \asymp g \) as \(x \to c \) if and only if both \(f \preccurlyeq g \) and \(g \preccurlyeq f \) as \(x \to c \text{.}\)
    🔗
    🔗

    Proof.
    First suppose that \(f \asymp g \) as \(x \to c \text{.}\) Then there is a non-negative real-valued function \(\lambda \colon X \to \clopint{ 0 }{ \infty } \) and a positive real number \(0 \lt L \lt \infty \) so that \(\abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \) for all \(x \in X \) and
    \begin{equation*} \lim_{ x \to c }{ \lambda \of{ x } } = L\text{.} \end{equation*}
    Since \(0 \leq L \lt \infty \text{,}\) we conclude that \(f \preccurlyeq g \) as \(x \to c \text{.}\) Moreover, we observe that
    \begin{equation*} \abs{ g \of{ x } } = \abs{ g \of{ x } } \of{ \frac{ \lambda \of{ x } }{ \lambda \of{ x } } } = \of{ \frac{ 1 }{ \lambda \of{ x } } } \abs{ f \of{ x } }\text{,} \end{equation*}
    and
    \begin{equation*} \lim_{ x \to c }{ \frac{ 1 }{ \lambda \of{ x } } } = \frac{ 1 }{ \lim_{ x \to c }{ \lambda \of{ x } } } = \frac{ 1 }{ L } \in \opint{ 0 }{ \infty }\text{,} \end{equation*}
    so that \(g \preccurlyeq f \) as \(x \to c \text{.}\)
    🔗
    Now suppose that both \(f \preccurlyeq g \) and \(g \preccurlyeq f \) as \(x \to c \text{.}\) Then there are non-negative real-valued functions \(\lambda , \mu \colon X \to \clopint{ 0 }{ \infty } \) and non-negative real numbers \(L , M \in \clopint{ 0 }{ \infty } \) so that \(\abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \) and \(\abs{ g \of{ x } } = \mu \of{ x } \abs{ f \of{ x } } \) for all \(x \in X \) and
    \begin{align*} \lim_{ x \to c }{ \lambda \of{ x } } \amp = L \amp \lim_{ x \to c }{ \mu \of{ x } } \amp = M\text{.} \end{align*}
    We first observe that for any point \(x \in X \text{,}\) if any one of \(\lambda \of{ x } \text{,}\) \(\mu \of{ x } \text{,}\) \(f \of{ x } \text{,}\) or \(g \of{ x } \) is \(0 \text{,}\) then \(f \of{ x } = g \of{ x } = 0 \text{.}\)
    🔗
    There are two cases: either there is a sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of points \(x_{ n } \in X \setminus \set{ c } \) converging to \(c \) so that \(f \of{ x_{ n } } , g \of{ x_{ n } } \neq 0 \) for all \(n \in \N \text{,}\) or no such sequence exists. If there is such a sequence, we observe that
    \begin{align*} \lambda \of{ x_{ n } } \mu \of{ x_{ n } } \amp = \lambda \of{ x_{ n } } \mu \of{ x_{ n } } \abs{ \frac{ f \of{ x_{ n } } g \of{ x_{ n } } }{ f \of{ x_{ n } } g \of{ x_{ n } } } } = \abs{ \frac{ \lambda \of{ x_{ n } } f \of{ x_{ n } } }{ g \of{ x_{ n } } } } \cdot \abs{ \frac{ \mu \of{ x_{ n } } g \of{ x_{ n } } }{ f \of{ x_{ n } } } }\\ \amp = \abs{ \frac{ g \of{ x_{ n } } }{ g \of{ x_{ n } } } } \cdot \abs{ \frac{ f \of{ x_{ n } } }{ f \of{ x_{ n } } } } = 1 \end{align*}
    for all \(n \in \N \text{,}\) and so
    \begin{align*} L M \amp = \of{ \lim_{ n \to \infty }{ \lambda \of{ x_{ n } } } } \of{ \lim_{ n \to \infty }{ \mu \of{ x_{ n } } } }\\ \amp = \lim_{ n \to \infty }{ \lambda \of{ x_{ n } } \mu \of{ x_{ n } } } = \lim_{ n \to \infty }{ 1 } = 1\text{.} \end{align*}
    In particular, we conclude that \(L , M \neq 0 \) are non-zero, so that \(f \asymp g \text{.}\)
    🔗
    On the other hand, if no such sequence exists, then \(f \of{ x } = g \of{ x } = 0 \) for all \(x \in X \) sufficiently close to \(c \text{.}\) Let \(\nu \colon X \to \R \) be the real-valued function defined piecewise by the formula
    \begin{equation*} \nu \of{ x } = \begin{cases} \lambda \of{ x } \amp f \of{ x } \neq 0 \\ 1 \amp f \of{ x } = 0 \text{.}\end{cases} \end{equation*}
    Then \(\nu \of{ x } \abs{ f \of{ x } } = \abs{ g \of{ x } } \) and
    \begin{equation*} \lim_{ x \to c }{ \nu \of{ x } } = 1\text{,} \end{equation*}
    and so \(f \asymp g \text{.}\)
    🔗
    🔗

    Definition 5.4.4. Strict asymptotic dominance.

    Let \(f , g \colon X \to \R \) be real-valued functions defined on a subset \(X \subseteq \R \text{,}\) and fix a limit point \(c \in X' \text{.}\) We say that \(f \) is strictly asymptotically dominated by \(g \) near \(c \) if \(f \preccurlyeq g \) but \(f \not \asymp g \) as \(x \to c \text{.}\) In this case, we write \(f \prec g \) as \(x \to c \text{.}\)
    🔗
    🔗
    We will shortly find the following characterization of strict asymptotic dominance useful:
    🔗

    Proposition 5.4.5. Strict asymptotic dominance.

    Let \(f , g \colon X \to \R \) be real-valued functions defined on a subset \(X \subseteq \R \text{,}\) and fix a limit point \(c \in X' \text{.}\) If \(g \of{ x } \neq 0 \) for all \(x \in X \setminus \set{ c } \text{,}\) then \(f \prec g \) if and only if
    \begin{equation*} \lim_{ x \to c }{ \frac{ f \of{ x } }{ g \of{ x } } } = 0\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    Let \(\lambda \colon X \to \clopint{ 0 }{ \infty } \) be the non-negative real-valued function defined by the formula
    \begin{equation*} \lambda \of{ x } = \abs{ \frac{ f \of{ x } }{ g \of{ x } } }\text{.} \end{equation*}
    Then \(\abs{ f \of{ x } } = \lambda \of{ x } \abs{ g \of{ x } } \) for all \(x \in X \text{,}\) and
    \begin{equation*} \lim_{ x \to c }{ \lambda \of{ x } } = \lim_{ x \to c }{ \abs{ \frac{ f \of{ x } }{ g \of{ x } } } } = \abs{ \lim_{ x \to c }{ \frac{ f \of{ x } }{ g \of{ x } } } }\text{.} \end{equation*}
    We conclude that \(f \prec g \) if and only if
    \begin{equation*} \lim_{ x \to c }{ \frac{ f \of{ x } }{ g \of{ x } } } = 0\text{.} \end{equation*}
    🔗
    🔗
    While we will mainly utilize the language of asymptotic comparison to describe the error in a Taylor approximation, these ideas are ubiquitous throughout mathematical analysis and applied mathematics.
    🔗
    🔗

    Subsection 5.4.2 Polynomial Approximations of Differentiable Functions

    We now arrive at one of the fundamental results in differential calculus. Taylor’s theorem establishes a best possible polynomial approximation \(p \) for a multiply differentiable function \(f \) near a given point. We quantify the quality of this approximation by asymptotically comparing the difference \(f - p \) to well-known power functions vanishing at \(c \) at high order.
    🔗

    Theorem 5.4.6 (Brook Taylor). Taylor’s theorem.

    Let \(f \colon X \to \R \) be a real-valued function defined on a subset \(X \subseteq \R \text{.}\) If \(f \) is \(k \)-times differentiable at a point \(c \in X \text{,}\) then there is a unique polynomial function \(p \) of degree at most \(k \) so that \(f \of{ x } - p \of{ x } \prec \of{ x - c }^{ k } \text{.}\)
    🔗
    🔗

    Proof.
    For uniqueness, let \(p , q \colon \R \to \R \) be polynomial functions of degree at most \(k \text{,}\) and suppose that \(f \of{ x } - p \of{ x } \prec \of{ x - c }^{ k } \) and \(f \of{ x } - q \of{ x } \prec \of{ x - c }^{ k } \text{.}\) Then
    \begin{equation*} 0 \leq \abs{ \frac{ p \of{ x } - q \of{ x } }{ \of{ x - c }^{ k } } } \leq \abs{ \frac{ f \of{ x } - p \of{ x } }{ \of{ x - c }^{ k } } } + \abs{ \frac{ f \of{ x } - q \of{ x } }{ \of{ x - c }^{ k } } } \end{equation*}
    for all \(x \in X \text{.}\) The Theorem 3.3.3 Squeeze theorem now implies that
    \begin{equation*} \lim_{ x \to c }{ \abs{ \frac{ p \of{ x } - q \of{ x } }{ \of{ x - c }^{ k } } } } = 0\text{,} \end{equation*}
    so that \(p \of{ x } - q \of{ x } \prec \of{ x - c }^{ k } \) as \(x \to c \text{.}\) This polynomial \(p \of{ x } - q \of{ x } \) can be written in the form
    \begin{equation*} p \of{ x } - q \of{ x } = a_{ 0 } + a_{ 1 } \of{ x - c } + a_{ 2 } \of{ x - c }^{ 2 } + \dotsb + a_{ k } \of{ x - c }^{ k } \end{equation*}
    for some real numbers \(a_{ 0 } , \dotsc , a_{ k } \in \R \text{.}\) For each index \(0 \leq j \leq k \text{,}\) we observe that
    \begin{equation*} \lim_{ x \to c }{ \abs{ \frac{ p \of{ x } - q \of{ x } }{ \of{ x - c }^{ j } } } } = \of{ \lim_{ x \to c }{ \abs{ \frac{ p \of{ x } - q \of{ x } }{ \of{ x - c }^{ k } } } } } \of{ \lim_{ x \to c }{ \abs{ \of{ x - c }^{ k - j } } } } = 0 \cdot 0 = 0\text{.} \end{equation*}
    If \(j = 0 \text{,}\) then
    \begin{align*} 0 \amp = \lim_{ x \to c }{ \abs{ \frac{ p \of{ x } - q \of{ x } }{ \of{ x - c }^{ 0 } } } } = \lim_{ x \to c }{ \abs{ p \of{ x } - q \of{ x } } }\\ \amp = \lim_{ x \to c }{ \abs{ a_{ 0 } + a_{ 1 } \of{ x - c } + a_{ 2 } \of{ x - c }^{ 2 } + \dotsb + a_{ k } \of{ x - c }^{ k } } } = \abs{ a_{ 0 } }\text{.} \end{align*}
    If \(j = 1 \text{,}\) then
    \begin{align*} 0 \amp = \lim_{ x \to c }{ \abs{ \frac{ p \of{ x } - q \of{ x } }{ \of{ x - c }^{ 1 } } } } = \lim_{ x \to c }{ \abs{ \frac{ p \of{ x } - q \of{ x } }{ x - c } } }\\ \amp = \lim_{ x \to c }{ \abs{ a_{ 1 } + a_{ 2 } \of{ x - c }^{ 1 } + \dotsb + a_{ k } \of{ x - c }^{ k - 1 } } } = \abs{ a_{ 1 } }\text{.} \end{align*}
    Continuing in this manner, we conclude that \(a_{ 0 } = a_{ 1 } = \dotsb = a_{ k } = 0 \text{,}\) so that \(p = q \text{.}\)
    🔗
    For existence, let \(p \colon \R \to \R \) be the polynomial function defined by the formula
    \begin{equation*} p \of{ x } = f \of{ c } + f' \of{ c } \of{ x - c } + \frac{ f'' \of{ c } \of{ x - c }^{ 2 } }{ 2 } + \dotsb + \frac{ f^{ \of{ k } } \of{ c } \of{ x - c }^{ k } }{ k! }\text{.} \end{equation*}
    We observe that \(p^{ \of{ j } } \of{ c } = f^{ \of{ j } } \of{ c } \) for all \(0 \leq j \leq c \text{.}\) We will show that \(f \of{ x } - p \of{ x } \prec \of{ x - c }^{ k } \) by repeated applications of L’Hôpital’s rule. Indeed,
    \begin{align*} \lim_{ x \to c }{ \frac{ f \of{ x } - p \of{ x } }{ \of{ x - c }^{ k } } } \amp = \lim_{ x \to c }{ \frac{ f' \of{ x } - p' \of{ x } }{ k \of{ x - c }^{ k - 1 } } } = \lim_{ x \to c }{ \frac{ f'' \of{ x } - p'' \of{ x } }{ k \of{ k - 1 } \of{ x - c }^{ k - 2 } } }\\ \amp = \dotsb = \lim_{ x \to c }{ \frac{ f^{ \of{ k - 1 } } \of{ x } - p^{ \of{ k - 1 } } \of{ x } }{ k! \of{ x - c } } }\\ \amp = \of{ \frac{ 1 }{ k! } } \of{ \lim_{ x \to c }{ \frac{ f^{ \of{ k - 1 } } \of{ x } - f^{ \of{ k - 1 } } \of{ c } }{ x - c } } - \lim_{ x \to c }{ \frac{ p^{ \of{ k - 1 } } \of{ x } - p^{ \of{ k - 1 } } \of{ c } }{ x - c } } }\\ \amp = \frac{ f^{ \of{ k } } \of{ c } - p^{ \of{ k } } \of{ c } }{ k! } = \frac{ 0 }{ k! } = 0\text{,} \end{align*}
    so that \(f \of{ x } - p \of{ x } \prec \of{ x - c }^{ k } \text{.}\)
    🔗
    🔗
    In summary, if a real-valued function \(f \) is \(k \)-times differentiable at a point \(c \text{,}\) then the unique polynomial of degree at most \(k \) with the same value, and derivatives as \(f \) up to order \(k \) is the best possible polynomial approximation of \(f \) near \(c \text{.}\) This polynomial is called the Taylor approximation of \(f \) at \(c \text{.}\)
    🔗

    Definition 5.4.7. Taylor approximation/remainder.

    Let \(f \colon X \to \R \) be a real-valued function defined on a subset \(X \subseteq \R \text{.}\) If \(f \) is \(k \)-times differentiable at a point \(c \in X \text{,}\) then the unique polynomial \(P^{ k }_{ c } \of{ f , x } \) of degree at most \(k \) so that \(f \of{ x } - P^{ k }_{ c } \of{ f , x } \prec \of{ x - c }^{ k } \) is called the order \(k \) Taylor approximation of \(f \) at \(c \text{,}\) and \(R^{ k }_{ c } \of{ f , x } = f \of{ x } - P^{ k }_{ c } \of{ f , x } \) is called the order \(k \) Taylor remainder of \(f \) at \(c \text{.}\)
    🔗
    🔗
    The content of Taylor’s theorem is not in finding the Taylor approximation, but rather in bounding the Taylor remainder. Under stronger hypotheses on \(f \text{,}\) one can find explicit formulas for the Taylor remainder. For example, the following result utilizes Theorem 5.3.5 Extended mean value theorem to compute a family of such an explicit formulas.
    🔗

    Theorem 5.4.8. Mean value form of the Taylor remainder.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{,}\) and suppose that \(f \) is \(k \)-times differentiable at an interior point \(c \in \Int \of{ X } \text{,}\) with order \(k \) Taylor approximation \(P^{ k }_{ c } \of{ f , x } \) and order \(k \) Taylor remainder \(R^{ k }_{ c } \of{ f , x } \text{.}\)
    🔗
    Fix a point \(x \in X \text{,}\) and a real-valued function \(G \colon I_{ x } \to \R \) defined on the closed interval \(I_{ x } \) between \(c \) and \(x \text{.}\) If both \(f^{ \of{ k } } \) and \(G \) are continuous on \(I_{ x } \) and differentiable on the open interval \(\Int \of{ I_{ x } } \text{,}\) and if \(G \) has no critical points on \(\Int \of{ I_{ x } } \text{,}\) then
    \begin{equation*} R^{ k }_{ c } \of{ f , x } = \of{ \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - y }^{ k } }{ k! } } \of{ \frac{ G \of{ x } - G \of{ c } }{ G' \of{ y } } } \end{equation*}
    for some interior point \(y \in \Int \of{ I_{ x } } \text{.}\)
    🔗
    🔗

    Proof.
    Consider the real-valued function \(F \colon X \to \R \) defined by the formula
    \begin{equation*} F \of{ y } = f \of{ y } + f' \of{ y } \of{ x - y } + \frac{ f'' \of{ y } \of{ x - y }^{ 2 } }{ 2 } + \dotsb + \frac{ f^{ \of{ k } } \of{ y } \of{ x - y }^{ k } }{ k! }\text{.} \end{equation*}
    We observe that \(F \) is continuous on the closed interval \(I_{ x } \) and differentiable on the open interval \(\Int \of{ I_{ x } } \text{,}\) with derivative
    \begin{align*} F' \of{ y } \amp = f' \of{ y } + \of{ f'' \of{ y } \of{ x - y } - f' \of{ y } } + \of{ \frac{ f^{ \of{ 3 } } \of{ y } \of{ x - y }^{ 2 } }{ 2 } - f'' \of{ y } \of{ x - y } }\\ \amp \qquad + \dotsb + \of{ \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - y }^{ k } }{ k! } - \frac{ f^{ \of{ k } } \of{ y } \of{ x - y }^{ k - 1 } }{ \of{ k - 1 }! } }\\ \amp = \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - y }^{ k } }{ k! }\text{.} \end{align*}
    By the Theorem 5.3.5 Extended mean value theorem, there is some interior point \(y \in \Int \of{ I_{ x } } \) so that
    \begin{equation*} F' \of{ y } \of{ G \of{ x } - G \of{ c } } = \of{ F \of{ x } - F \of{ c } } G' \of{ y }\text{.} \end{equation*}
    We observe that \(F \of{ x } = f \of{ x } \) and \(F \of{ c } = P^{ k }_{ c } \of{ f , x } \text{,}\) so that
    \begin{align*} R^{ k }_{ c } \of{ f , x } \amp = f \of{ x } - P^{ k }_{ c } \of{ f , x } = F \of{ x } - F \of{ c }\\ \amp = F' \of{ y } \of{ \frac{ G \of{ x } - G \of{ c } }{ G' \of{ y } } }\\ \amp = \of{ \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - y }^{ k } }{ k! } } \of{ \frac{ G \of{ x } - G \of{ c } }{ G' \of{ y } } }\text{.} \end{align*}
    🔗
    🔗
    The utility of Theorem 5.4.8 Mean value form of the Taylor remainder is in choosing specific functions \(G \) in order to obtain particularly nice explicit formulas for the Taylor remainder. For example, we obtain the Lagrange form of the Taylor remainder, which is a higher order generalization of the Mean value theorem.
    🔗

    Corollary 5.4.9 (Joseph-Louis Lagrange). Lagrange form of the Taylor remainder.

    Let \(f \colon X \to \R \) be a real-valued function defined on an interval \(X \subseteq \R \text{,}\) and suppose that \(f \) is \(k \)-times differentiable at an interior point \(c \in \Int \of{ X } \text{,}\) with order \(k \) Taylor approximation \(P^{ k }_{ c } \of{ f , x } \) and order \(k \) Taylor remainder \(R^{ k }_{ c } \of{ f , x } \text{.}\)
    🔗
    Fix a point \(x \in X \text{.}\) If \(f^{ \of{ k } } \) is continuous on the closed interval \(I_{ x } \) between \(c \) and \(x \) and differentiable on the open interval \(\Int \of{ I_{ x } } \text{,}\) then
    \begin{equation*} R^{ k }_{ c } \of{ f , x } = \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - c }^{ k + 1 } }{ \of{ k + 1 }! } \end{equation*}
    for some interior point \(y \in \Int \of{ I_{ x } } \text{.}\)
    🔗
    🔗

    Proof.
    This follows immediately from Theorem 5.4.8 Mean value form of the Taylor remainder by taking \(G \of{ y } = \of{ x - y }^{ k + 1 } \text{.}\) Indeed, in this case,
    \begin{align*} R^{ k }_{ c } \of{ f , x } \amp = \of{ \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - y }^{ k } }{ k! } } \of{ \frac{ G \of{ x } - G \of{ c } }{ G' \of{ y } } }\\ \amp = \of{ \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - y }^{ k } }{ k! } } \of{ \frac{ - \of{ x - c }^{ k + 1 } }{ \of{ k + 1 } \of{ x - y }^{ k } \of{ -1 } } }\\ \amp = \frac{ f^{ \of{ k + 1 } } \of{ y } \of{ x - c }^{ k + 1 } }{ \of{ k + 1 }! } \end{align*}
    for some interior point \(y \in \Int \of{ I_{ x } } \text{.}\)
    🔗
    🔗
    We observe that Corollary 5.4.9 Lagrange form of the Taylor remainder is precisely the Mean value theorem when \(k = 0 \text{.}\) Other important forms of the Taylor remainder can be found by choosing different functions \(G \text{.}\) You will have an opportunity to explore the Cauchy form of the Taylor remainder in the problems for this section.
