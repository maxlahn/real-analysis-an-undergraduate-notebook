    Section 3.3 Limits in the Euclidean Metric

    In the previous section, we defined and explored the convergence and divergence of sequences and maps in the context of general metric spaces. In this section, however, we turn our attention to the limiting behavior in Euclidean spaces specifically. Euclidean spaces, being (at least in low dimensions) good models of the space in which we live, are the metric spaces in which our intuitions about distance are most accurate and useful.
    🔗

    Subsection 3.3.1 Limits and Arithmetic

    Much of our work in this text will rely on limits taken in Euclidean spaces, and the material introduced in this section is fundamental to the field of real analysis. Euclidean spaces are not just metric objects, however; as normed vector spaces, Euclidean spaces have a vector space structure as well as a norm and an inner product. We will see that Euclidean limits preserve this additional structure; for example, linear combinations of convergent sequences of real coordinate vectors converge in the Euclidean metric to the linear combination of the limits. In fact, this holds true in any normed vector space.
    🔗

    Proposition 3.3.1. Limits and vector arithmetic.

    Let \(\norm{ \oparg } \) be a norm on a real or complex vector space \(V \text{,}\) and consider the induced metric \(\rho \) on \(V \text{.}\)
    1. Vector addition.
      For all convergent sequences \(\of{ \vect{ v }_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ \vect{ w }_{ n } }_{ n = 0 }^{ \infty } \) of vectors \(\vect{ v }_{ n } , \vect{ w }_{ n } \in V \text{,}\)
      \begin{equation*} \lim_{ n \to \infty }{ \of{ \vect{ v }_{ n } + \vect{ w }_{ n } } } = \lim_{ n \to \infty }{ \vect{ v }_{ n } } + \lim_{ n \to \infty }{ \vect{ w }_{ n } }\text{.} \end{equation*}
      🔗
      🔗
    2. Scalar multiplication.
      For all scalars \(\alpha \) and convergent sequences \(\of{ \vect{ v }_{ n } }_{ n = 0 }^{ \infty } \) of vectors \(\vect{ v }_{ n } \in V \text{,}\)
      \begin{equation*} \lim_{ n \to \infty }{ \alpha \vect{ v }_{ n } } = \alpha \lim_{ n \to \infty }{ \vect{ v }_{ n } }\text{.} \end{equation*}
      🔗
      🔗
    3. Norm.
      For all convergent sequences \(\of{ \vect{ v }_{ n } }_{ n = 0 }^{ \infty } \) of vectors \(\vect{ v }_{ n } \in V \text{,}\)
      \begin{equation*} \lim_{ n \to \infty }{ \norm{ \vect{ v }_{ n } } } = \norm{ \lim_{ n \to \infty }{ \vect{ v }_{ n } } }\text{.} \end{equation*}
      🔗
      🔗
    4. Inner product.
      If the norm \(\norm{ \oparg } \) is induced by an inner product \(\inner{ \oparg }{ \oparg } \) on \(V \text{,}\) then for all convergent sequences \(\of{ \vect{ v }_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ \vect{ w }_{ n } }_{ n = 0 }^{ \infty } \) of vectors \(\vect{ v }_{ n } , \vect{ w }_{ n } \in V \text{,}\)
      \begin{equation*} \lim_{ n \to \infty }{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } } = \inner{ \lim_{ n \to \infty }{ \vect{ v }_{ n } } }{ \lim_{ n \to \infty }{ \vect{ w }_{ n } } }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Let \(\vect{ v } = \lim_{ n \to \infty }{ \vect{ v }_{ n } } \) and \(\vect{ w } = \lim_{ n \to \infty }{ \vect{ w }_{ n } } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Since \(\frac{ \epsilon }{ 2 } \gt 0 \) is a positive real number, there are natural numbers \(m_{ \epsilon } , n_{ \epsilon } \in \N \) so that
      \begin{equation*} \rho \of{ \vect{ v }_{ n } , \vect{ v } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      for all indices \(n \geq m_{ \epsilon } \) and
      \begin{equation*} \rho \of{ \vect{ w }_{ n } , \vect{ w } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) Let \(p_{ \epsilon } = \max \of{ m_{ \epsilon } , n_{ \epsilon } } \in \N \text{,}\) and note that
      \begin{align*} \rho \of{ \vect{ v }_{ n } + \vect{ w }_{ n } , \vect{ v } + \vect{ w } } \amp = \norm{ \vect{ v }_{ n } + \vect{ w }_{ n } - \of{ \vect{ v } + \vect{ w } } } = \norm{ \vect{ v }_{ n } - \vect{ v } + \vect{ w }_{ n } - \vect{ w } }\\ \amp \leq \norm{ \vect{ v }_{ n } - \vect{ v } } + \norm{ \vect{ w }_{ n } - \vect{ w } } = \rho \of{ \vect{ v }_{ n } , \vect{ v } } + \rho \of{ \vect{ w }_{ n } , \vect{ w } }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
      for all indices \(n \geq p_{ \epsilon } \text{.}\) We conclude that
      \begin{equation*} \lim_{ n \to \infty }{ \of{ \vect{ v }_{ n } + \vect{ w }_{ n } } } = \vect{ v } + \vect{ w }\text{.} \end{equation*}
      🔗
      🔗
    2. Let \(\vect{ v } = \lim_{ n \to \infty }{ \vect{ v }_{ n } } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Note that
      \begin{align*} \rho \of{ \alpha \vect{ v }_{ n } , \alpha \vect{ v } } \amp = \norm{ \alpha \vect{ v }_{ n } - \alpha \vect{ v } } = \abs{ \alpha } \norm{ \vect{ v }_{ n } - \vect{ v } }\\ \amp = \abs{ \alpha } \rho \of{ \vect{ v }_{ n } , \vect{ v } } \end{align*}
      for all indices \(n \in \N \text{.}\) If \(\alpha = 0 \text{,}\) then
      \begin{equation*} \rho \of{ \alpha \vect{ v }_{ n } , \alpha \vect{ v } } = \abs{ \alpha } \rho \of{ \vect{ v }_{ n } , \vect{ v } } = 0 \cdot \rho \of{ \vect{ v }_{ n } , \vect{ v } } = 0 \lt \epsilon \end{equation*}
      for all indices \(n \in \N \text{.}\) We conclude that in this case,
      \begin{equation*} \lim_{ n \to \infty }{ \alpha \vect{ v }_{ n } } = \alpha \vect{ v }\text{.} \end{equation*}
      🔗
      Now suppose that \(\alpha \neq 0 \text{.}\) Since \(\frac{ \epsilon }{ \abs{ \alpha } } \gt 0 \) is a positive real number, there is a natural number \(n_{ \epsilon } \in \N \) so that
      \begin{equation*} \rho \of{ \vect{ v }_{ n } , \vect{ v } } \lt \frac{ \epsilon }{ \abs{ \alpha } } \end{equation*}
      for all indices \(n \geq m_{ \epsilon } \text{.}\) In particular,
      \begin{equation*} \rho \of{ \alpha \vect{ v }_{ n } , \alpha \vect{ v } } = \abs{ \alpha } \rho \of{ \vect{ v }_{ n } , \vect{ v } } \lt \abs{ \alpha } \of{ \frac{ \epsilon }{ \abs{ \alpha } } } = \epsilon\text{.} \end{equation*}
      We conclude that in this case,
      \begin{equation*} \lim_{ n \to \infty }{ \alpha \vect{ v }_{ n } } = \alpha \vect{ v }\text{.} \end{equation*}
      🔗
      🔗
    3. Let \(\vect{ v } = \lim_{ n \to \infty }{ \vect{ v }_{ n } } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \) so that
      \begin{equation*} \rho \of{ \vect{ v }_{ n } , \vect{ v } } \lt \epsilon \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We observe that Proposition 3.1.5 Reverse triangle inequality implies that
      \begin{align*} d \of{ \norm{ \vect{ v }_{ n } } , \norm{ \vect{ v } } } \amp = \abs{ \norm{ \vect{ v }_{ n } } - \norm{ \vect{ v } } } = \abs{ \norm{ \vect{ v }_{ n } - \vect{ 0 } } - \norm{ \vect{ v } - \vect{ 0 } } }\\ \amp = \abs{ \rho \of{ \vect{ v }_{ n } , \vect{ 0 } } - \rho \of{ \vect{ v } , \vect{ 0 } } } \leq \rho \of{ \vect{ v }_{ n } , \vect{ v } } \lt \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \text{,}\) and so
      \begin{equation*} \lim_{ n \to \infty }{ \norm{ \vect{ v }_{ n } } } = \norm{ \vect{ v } }\text{.} \end{equation*}
      🔗
      🔗
    4. Let \(\vect{ v } = \lim_{ n \to \infty }{ \vect{ v }_{ n } } \) and \(\vect{ w } = \lim_{ n \to \infty }{ \vect{ w }_{ n } } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. We observe that
      \begin{align*} d \of{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } , \inner{ \vect{ v } }{ \vect{ w } } } \amp = \abs{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } - \inner{ \vect{ v } }{ \vect{ w } } }\\ \amp = \abs{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } - \inner{ \vect{ v } }{ \vect{ w }_{ n } } + \inner{ \vect{ v } }{ \vect{ w }_{ n } } - \inner{ \vect{ v } }{ \vect{ w } } }\\ \amp = \abs{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } - \inner{ \vect{ v } }{ \vect{ w }_{ n } } } + \abs{ \inner{ \vect{ v } }{ \vect{ w }_{ n } } - \inner{ \vect{ v } }{ \vect{ w } } }\\ \amp = \abs{ \inner{ \vect{ v }_{ n } - \vect{ v } }{ \vect{ w }_{ n } } } + \abs{ \inner{ \vect{ v } }{ \vect{ w }_{ n } - \vect{ w } } }\\ \amp \leq \norm{ \vect{ v }_{ n } - \vect{ v } } \cdot \norm{ \vect{ w } } + \norm{ \vect{ v } } \cdot \norm{ \vect{ w }_{ n } - \vect{ w } }\\ \amp = \rho \of{ \vect{ v }_{ n } , \vect{ v } } \cdot \norm{ \vect{ w } } + \norm{ \vect{ v } } \cdot \rho \of{ \vect{ w }_{ n } , \vect{ w } } \end{align*}
      for all indices \(n \in \N \) by the Cauchy--Schwarz inequality. There are four cases, depending on whether or not \(\vect{ v } \) and \(\vect{ w } \) are zero or non-zero vectors. If \(\vect{ v } = \vect{ w } = \vect{ 0 } \text{,}\) then
      \begin{equation*} d \of{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } , \inner{ \vect{ v } }{ \vect{ w } } } \leq \rho \of{ \vect{ v }_{ n } , \vect{ v } } \cdot \norm{ \vect{ w } } + \norm{ \vect{ v } } \cdot \rho \of{ \vect{ w }_{ n } , \vect{ w } } = 0 + 0 = 0 \lt \epsilon\text{.} \end{equation*}
      🔗
      If \(\vect{ v } = \vect{ 0 } \) and \(\vect{ w } \neq \vect{ 0 } \text{,}\) then there is a natural number \(n_{ \epsilon } \in \N \) so that
      \begin{equation*} \rho \of{ \vect{ v }_{ n } , \vect{ v } } \lt \frac{ \epsilon }{ \norm{ \vect{ w } } } \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We observe that
      \begin{align*} d \of{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } , \inner{ \vect{ v } }{ \vect{ w } } } \amp \leq \rho \of{ \vect{ v }_{ n } , \vect{ v } } \cdot \norm{ \vect{ w } } + \norm{ \vect{ v } } \cdot \rho \of{ \vect{ w }_{ n } , \vect{ w } }\\ \amp \lt \of{ \frac{ \epsilon }{ \norm{ \vect{ w } } } } \norm{ \vect{ w } } + 0 = \epsilon + 0 = \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\)
      🔗
      If \(\vect{ v } \neq \vect{ 0 } \) and \(\vect{ w } = \vect{ 0 } \text{,}\) then there is a natural number \(n_{ \epsilon } \in \N \) so that
      \begin{equation*} \rho \of{ \vect{ w }_{ n } , \vect{ w } } \lt \frac{ \epsilon }{ \norm{ \vect{ v } } } \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We observe that
      \begin{align*} d \of{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } , \inner{ \vect{ v } }{ \vect{ w } } } \amp \leq \rho \of{ \vect{ v }_{ n } , \vect{ v } } \cdot \norm{ \vect{ w } } + \norm{ \vect{ v } } \cdot \rho \of{ \vect{ w }_{ n } , \vect{ w } }\\ \amp \lt 0 + \norm{ \vect{ v } } \of{ \frac{ \epsilon }{ \norm{ \vect{ w } } } } \norm{ \vect{ w } } = 0 + \epsilon = \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\)
      🔗
      Finally, if \(\vect{ v } \neq \vect{ 0 } \) and \(\vect{ w } \neq \vect{ 0 } \text{,}\) then there are natural numbers \(m_{ \epsilon } , n_{ \epsilon } \in \N \) so that
      \begin{equation*} \rho \of{ \vect{ v }_{ n } , \vect{ v } } \lt \frac{ \epsilon }{ 2 \norm{ \vect{ w } } } \end{equation*}
      for all indices \(n \geq m_{ \epsilon } \) and
      \begin{equation*} \rho \of{ \vect{ w }_{ n } , \vect{ w } } \lt \frac{ \epsilon }{ 2 \norm{ \vect{ v } } } \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) Let \(p_{ \epsilon } = \max \of{ \set{ m_{ \epsilon } , n_{ \epsilon } } } \text{.}\) We observe that
      \begin{align*} d \of{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } , \inner{ \vect{ v } }{ \vect{ w } } } \amp \leq \rho \of{ \vect{ v }_{ n } , \vect{ v } } \cdot \norm{ \vect{ w } } + \norm{ \vect{ v } } \cdot \rho \of{ \vect{ w }_{ n } , \vect{ w } }\\ \amp \lt \of{ \frac{ \epsilon }{ 2 \norm{ \vect{ w } } } } \norm{ \vect{ w } } + \norm{ \vect{ v } } \of{ \frac{ \epsilon }{ 2 \norm{ \vect{ v } } } } = \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
      for all indices \(n \geq p_{ \epsilon } \text{.}\)
      🔗
      In all cases, we conclude that
      \begin{equation*} \lim_{ n \to \infty }{ \inner{ \vect{ v }_{ n } }{ \vect{ w }_{ n } } } = \inner{ \vect{ v } }{ \vect{ w } }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    Proposition 3.3.1 Limits and vector arithmetic details the ways in which the metric structure induced on a vector space by a norm or inner product interacts nicely with the additional structure of the vector space. In the real numbers \(\R \text{,}\) there are similar interactions between the metric structure and the standard ordering \(\leq \text{.}\)
    🔗

    Proposition 3.3.2. Comparison of limits.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be convergent sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{.}\) If \(x_{ n } \leq y_{ n } \) for all indices \(n \in \N \text{,}\) then
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } \leq \lim_{ n \to \infty }{ y_{ n } }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    By contraposition. Let \(x = \lim_{ n \to \infty }{ x_{ n } } \) and \(y = \lim_{ n \to \infty }{ y_{ n } } \text{,}\) and suppose that \(x \gt y \text{.}\) Consider the positive real number
    \begin{equation*} \epsilon = \frac{ x - y }{ 2 }\text{.} \end{equation*}
    Then there are natural numbers \(m_{ \epsilon } , n_{ \epsilon } \in \N \) so that
    \begin{equation*} d \of{ x_{ n } , x } \lt \epsilon \end{equation*}
    for all indices \(n \geq m_{ \epsilon } \) and
    \begin{equation*} d \of{ y_{ n } , y } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) Let \(p_{ \epsilon } = \max \of{ \set{ m_{ \epsilon } , n_{ \epsilon } } } \in \N \text{.}\) We observe that
    \begin{equation*} x - x_{ p_{ \epsilon } } \leq \abs{ x_{ p_{ \epsilon } } - x } = d \of{ x_{ p_{ \epsilon } } , x } \lt \epsilon = \frac{ x - y }{ 2 } \end{equation*}
    and
    \begin{equation*} y_{ p_{ \epsilon } } - y \leq \abs{ y_{ p_{ \epsilon } } - y } = d \of{ y_{ p_{ \epsilon } } , y } \lt \epsilon = \frac{ x - y }{ 2 }\text{,} \end{equation*}
    so that
    \begin{equation*} y_{ p_{ \epsilon } } \lt \frac{ x + y }{ 2 } \lt x_{ p_{ \epsilon } }\text{.} \end{equation*}
    🔗
    In summary, we have shown that if \(x \gt y \text{,}\) then \(x_{ n } \gt y_{ n } \) for some index \(n \in \N \text{.}\) Taking the contrapositive, we arrive at the desired result.
    🔗
    🔗
    This is as good a place as any to introduce another useful result concerning the relationship between sequential convergence in the real line \(\R \) and the standard ordering \(\leq \text{.}\) Called the Squeeze theorem, this result can be used cleverly to avoid lengthy convergence arguments.
    🔗

    Theorem 3.3.3. Squeeze theorem.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and \(\of{ z_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } , z_{ n } \in \R \text{.}\) If
    \begin{equation*} x_{ n } \leq y_{ n } \leq z_{ n } \end{equation*}
    for all indices \(n \in \N \) and \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ z_{ n } }_{ n = 0 }^{ \infty } \) converge to the same real number \(l \in \R \text{,}\) then \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) converges to \(l \text{.}\)
    🔗
    🔗

    Proof.
    Let \(\epsilon \gt 0 \) be a positive real number. Then there are natural numbers \(m_{ \epsilon } , n_{ \epsilon } \in \N \) so that
    \begin{equation*} d \of{ x_{ n } , l } \lt \epsilon \end{equation*}
    for all indices \(n \geq m_{ \epsilon } \) and
    \begin{equation*} d \of{ z_{ n } , l } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) Let \(p_{ \epsilon } = \max \of{ \set{ m_{ \epsilon } , n_{ \epsilon } } } \in \N \text{,}\) and note that
    \begin{equation*} y_{ n } - l \leq z_{ n } - l \leq \abs{ z_{ n } - l } = d \of{ z_{ n } , l } \lt \epsilon \end{equation*}
    and
    \begin{equation*} l - y_{ n } \leq l - x_{ n } \leq \abs{ x_{ n } - l } = d \of{ x_{ n } , l } \lt \epsilon \end{equation*}
    for all indices \(n \geq p_{ \epsilon } \text{.}\) In particular, we conclude that
    \begin{equation*} d \of{ y_{ n } , l } = \abs{ y_{ n } - l } = \max \of{ \set{ y_{ n } - l , l - y_{ n } } } \lt \epsilon \end{equation*}
    for all indices \(n \geq p_{ \epsilon } \text{,}\) and so \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) converges to \(l \text{.}\)
    🔗
    🔗

    Example 3.3.4. Squeeze theorem.

    Since \(0 \leq \frac{ 1 }{ n^{ 2 } } \leq \frac{ 1 }{ n } \) for all positive integers \(n \geq 1 \) and
    \begin{equation*} \lim_{ n \to \infty }{ 0 } = \lim_{ n \to \infty }{ \frac{ 1 }{ n } } = 0\text{,} \end{equation*}
    we can conclude by the Squeeze theorem that
    \begin{equation*} \lim_{ n \to \infty }{ \frac{ 1 }{ n^{ 2 } } } = 0 \end{equation*}
    without worrying about a lengthy convergence argument.
    🔗
    🔗
    Proposition 3.3.1 Limits and vector arithmetic and Proposition 3.3.2 Comparison of limits further justify the choice to emphasize the limiting behavior of objects on the real line \(\R \) in the rest of this section; as we have already seen in Section 3.2 Convergence and Limits, these results further emphasize that knowledge of such limiting behavior can be used to make conclusions about the limiting behavior of a wide variety of metric objects.

    Subsection 3.3.2 Divergence to Infinity

    In some ways, the binary distinction between convergence and divergence may be viewed as more coarse than an analyst might like. On the real line \(\R \text{,}\) we can make more qualitative statements about the limiting behavior of certain divergent sequences and maps to alleviate this issue somewhat. We now consider the special case of divergence of a sequence or map to infinity. Some sequences increase or decrease without bound. Such sequences can be said to have infinite limits, even though they don’t converge to any real number.
    🔗

    Definition 3.3.5. Sequential divergence to infinity.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\)
    • Divergence to \(\infty \).
      The sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is said to diverge to \(\infty \) if for each real number \(B \in \R \text{,}\) there is a natural number \(n_{ B } \in \N \) so that \(x_{ n } \gt B \) for all indices \(n \geq n_{ B } \text{.}\) In this case, we write
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = \infty\text{.} \end{equation*}
      🔗
      🔗
    • Divergence to \(-\infty \).
      The sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is said to diverge to \(-\infty \) if for each real number \(B \in \R \text{,}\) there is a natural number \(n_{ B } \in \N \) so that \(x_{ n } \lt B \) for all indices \(n \geq n_{ B } \text{.}\) In this case, we write
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = -\infty\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Example 3.3.6. Sequential divergence to infinity.

    The following are examples and non-examples of sequences of real numbers which diverge to infinity.
    • The sequence \(\of{ n }_{ n = 0 }^{ \infty } = \of{ 0 , 1 , 2 , 3 , \dotsc } \) diverges to \(\infty \text{;}\) that is,
      \begin{equation*} \lim_{ n \to \infty }{ n } = \infty\text{.} \end{equation*}
      🔗
      🔗
    • The sequence \(\of{ \of{ -1 }^{ n } n }_{ n = 0 }^{ \infty } = \of{ 0 , -1 , 2 , -3 , \dotsc } \) diverges, but it does not diverge to \(\infty \) or \(-\infty \text{.}\)
      🔗
      🔗
    🔗
    🔗
    There are also versions of divergence to infinity for real-valued functions on metric spaces.
    🔗

    Definition 3.3.7. Function divergence to infinity.

    Let \(f \colon X \to \R \) be a real-valued function on a metric space \(\of{ X , \rho } \text{.}\)
    • Divergence to \(\infty \).
      The function \(f \) is said to diverge to \(\infty \) at a point \(c \in X \) if for each real number \(B \in \R \text{,}\) there is a positive real number \(\delta \gt 0 \) so that \(f \of{ x } \gt B \) for all points \(x \in X \) so that \(0 \lt \rho \of{ x , c } \lt \delta \text{.}\)
      🔗
      In this case, if \(c \) is a limit point of \(X \text{,}\) then we write
      \begin{equation*} \lim_{ x \to c }{ f \of{ x } } = \infty\text{.} \end{equation*}
      🔗
      🔗
    • Divergence to \(-\infty \).
      The function \(f \) is said to diverge to \(-\infty \) at a point \(c \in X \) if for each real number \(B \in \R \text{,}\) there is a positive real number \(\delta \gt 0 \) so that \(f \of{ x } \lt B \) for all points \(x \in X \) so that \(0 \lt \rho \of{ x , c } \lt \delta \text{.}\)
      🔗
      In this case, if \(c \) is a limit point of \(X \text{,}\) then we write
      \begin{equation*} \lim_{ x \to c }{ f \of{ x } } = -\infty\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Example 3.3.8. Function divergence to infinity.

    The following are examples and non-examples of real-valued functions on metric spaces which diverge to infinity
    • Consider the real-valued function \(f \colon \R \setminus \set{ 1 } \to \R \) defined by the formula
      \begin{equation*} f \of{ x } = -\frac{ 1 }{ \of{ x - 1 }^{ 2 } }\text{.} \end{equation*}
      Then \(f \) diverges to \(-\infty \) at \(1 \text{;}\) that is,
      \begin{equation*} \lim_{ x \to 1 }{ -\frac{ 1 }{ x^{ 2 } } } = -\infty\text{.} \end{equation*}
      🔗
      🔗
    • Consider the real-valued function \(g \colon \R \setminus \set{ 0 } \to \R \) defined by the formula
      \begin{equation*} g \of{ y } = \frac{ 1 }{ y }\text{.} \end{equation*}
      Then \(g \) diverges at \(0 \text{,}\) but it does not diverge to \(\infty \) or \(-\infty \) at \(0 \text{.}\)
      🔗
      🔗
    🔗
    🔗
    Divergence of a sequence of real numbers or a real-valued function to infinity is a strong statement about the limiting behavior of such a sequence or function. However, since there is no metric on the extended real number system which agrees with the Euclidean metric on the real numbers, we cannot view divergence to infinity as convergence in a metric space of which the real line is a metric subspace. We will see in Chapter 4 Topological Spaces a way in which the situation of divergence to infinity can be said to be a form of convergence to an extended real number, namely the infinite quantities \(\infty \) and \(-\infty \text{.}\)
    🔗
    In many ways, the symbols \(\infty \) and \(-\infty \) can be viewed as one-sided “reciprocals” of \(0 \text{.}\) While division by zero is left undefined for very important arithmetical reasons, it turns out that divergence of a sequence of nonzero real numbers to infinity implies the Euclidean convergence of the reciprocals to zero.
    🔗

    Proposition 3.3.9. Reciprocals of infinite limits.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of positive real numbers \(x_{ n } \gt 0 \text{.}\) Then
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = \infty \end{equation*}
    if and only if
    \begin{equation*} \lim_{ n \to \infty }{ \frac{ 1 }{ x_{ n } } } = 0\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    First suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(\infty \text{,}\) and let \(\epsilon \gt 0 \text{.}\) Then \(\frac{ 1 }{ \epsilon } \in \R \) is a real number, and so there is a natural number \(n_{ \epsilon } \in \N \) so that
    \begin{equation*} x_{ n } \gt \frac{ 1 }{ \epsilon } \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
    \begin{equation*} d \of{ \frac{ 1 }{ x_{ n } } , 0 } = \abs{ \frac{ 1 }{ x_{ n } } - 0 } = \abs{ \frac{ 1 }{ x_{ n } } } = \frac{ 1 }{ x_{ n } } \lt \epsilon \end{equation*}
    for all indices \(n \geq n_{ \epsilon } \text{,}\) and so \(\of{ \frac{ 1 }{ x_{ n } } }_{ n = 0 }^{ \infty } \) converges to \(0 \text{.}\)
    🔗
    Conversely, now suppose that \(\of{ \frac{ 1 }{ x_{ n } } }_{ n = 0 }^{ \infty } \) converges to \(0 \text{,}\) and let \(B \in \R \) be a real number. If \(B \leq 0 \) is non-positive, then
    \begin{equation*} x_{ n } \gt 0 \geq B \end{equation*}
    for all indices \(n \in \N \text{.}\) On the other hand, if \(B \gt 0 \) is positive, then \(\frac{ 1 }{ B } \gt 0 \) is a positive real number, and so there is a natural number \(n_{ B } \) so that
    \begin{equation*} d \of{ \frac{ 1 }{ x_{ n } } , 0 } \lt \frac{ 1 }{ B } \end{equation*}
    for all indices \(n \geq n_{ B } \text{.}\) In particular,
    \begin{equation*} x_{ n } = \abs{ x_{ n } } = \frac{ 1 }{ \abs{ \frac{ 1 }{ x_{ n } } - 0 } } = \frac{ 1 }{ d \of{ \frac{ 1 }{ x_{ n } } , 0 } } \gt B \end{equation*}
    for all indices \(n \geq n_{ B } \text{,}\) and so \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(\infty \text{.}\)
    🔗
    🔗
    So, as far as limiting behavior of sequences of real numbers goes, the infinite quantities \(\infty \) and \(-\infty \) behave like one-sided reciprocals of zero. It’s incredibly important to avoid assuming anything stronger than what is explicitly stated in the proposition above. Specifically, the hypothesis that the sequence in question have positive real number values is crucial, and the statement is not necessarily true without this requirement.
    🔗
    A sequence of real numbers diverges to \(\infty \) or \(-\infty \) if it increases or decreases, respectively, without bound. This notion of boundedness is directly related to the one introduced in Section 1.5 Introduction to Order Theory for subsets of partially ordered sets. Informally, a map with codomain a partially ordered set is considered to be bounded if its image is bounded.
    🔗

    Definition 3.3.10. Map boundedness.

    Let \(f \colon X \to Y \) be a map from a set \(X \) to a partially ordered set \(\of{ Y , \preceq } \text{.}\)
    • Upper bound.
      An output \(y \in Y \) is an upper bound for the map \(f \) if it is an upper bound for the image \(\im \of{ f } = f \of{ X } \text{;}\) that is, \(y \) is an upper bound for \(f \) if \(f \of{ x } \preceq y \) for all inputs \(x \in X \text{.}\)
      🔗
      The map \(f \) is called bounded from above if there is an upper bound for \(f \text{,}\) and unbounded from above if there is no such upper bound.
      🔗
      🔗
    • Lower bound.
      An output \(y \in Y \) is a lower bound for the map \(f \) if it is a lower bound for the image \(\im \of{ f } = f \of{ X } \text{;}\) that is, \(y \) is a lower bound for \(f \) if \(y \preceq f \of{ x } \) for all inputs \(x \in X \text{.}\)
      🔗
      The map \(f \) is called bounded from below if there is a lower bound for \(f \text{,}\) and unbounded from below if there is no such lower bound.
      🔗
      🔗
    • Boundedness.
      The map \(f \) is called bounded if it is both bounded from above and bounded from below, and \(f \) is called unbounded otherwise if it is either unbounded from above or unbounded from below (or both).
      🔗
      🔗
    🔗
    🔗

    Example 3.3.11. Sequential boundedness in the real line.

    A sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } \in \R \) is bounded if and only if there are real numbers \(a , b \in \R \) such that \(a \leq x_{ n } \leq b \) for all indices \(n \in \N \text{.}\) For example, the sequence \(\of{ \frac{ 1 }{ n } }_{ n = 1 }^{ \infty } \) is bounded, because
    \begin{equation*} 0 \lt \frac{ 1 }{ n } \leq 1 \end{equation*}
    for all indices \(n \geq 1 \text{.}\)
    🔗
    🔗
    Clearly, any sequence of real numbers or any real-valued function which diverges to infinity cannot be bounded. However, the converse is not true; unbounded sequences need not diverge to infinity. We have already seen one such example of this in Example 3.3.8 Function divergence to infinity.
    🔗
    Considered as a real-valued function on the set \(\N \) of natural numbers, a sequence of real numbers is a map whose codomain is a totally ordered set. However, the domain of such a sequence is also totally ordered. Because the metric structure on the real line \(\R \) can be described in terms of the standard ordering \(\leq \text{,}\) sequences which preserve these orders have special convergence properties. Such sequences are called monotone.
    🔗

    Definition 3.3.12. Monotonicity.

    Let \(f \colon X \to Y \) be a map from a partially ordered set \(\of{ X , \preceq_{ X } } \) to a partially ordered set \(\of{ Y , \preceq_{ Y } } \text{.}\)
    • Isotonicity.
      The map \(f \) is called non-decreasing, order-preserving, or isotone if for all inputs \(x_{ 1 } , x_{ 2 } \in X \text{,}\) if \(x_{ 1 } \preceq_{ X } x_{ 2 } \text{,}\) then \(f \of{ x_{ 1 } } \preceq_{ Y } f \of{ x_{ 2 } } \text{.}\) The map \(f \) is called increasing, strictly order-preserving, or strictly isotone if it is non-decreasing and injective.
      🔗
      🔗
    • Antitonicity.
      The map \(f \) is called non-increasing, order-reversing, or antitone if for all inputs \(x_{ 1 } , x_{ 2 } \in X \text{,}\) if \(x_{ 1 } \preceq_{ X } x_{ 2 } \text{,}\) then \(f \of{ x_{ 2 } } \preceq_{ Y } f \of{ x_{ 1 } } \text{.}\) The map \(f \) is called decreasing, strictly order-reversing, or strictly antitone if it is non-increasing and injective.
      🔗
      🔗
    • Monotonicity.
      The map \(f \) is called monotone if it is either non-decreasing or non-increasing, and \(f \) is called strictly monotone if it is either increasing or decreasing.
      🔗
      🔗
    🔗
    🔗
    It turns out that all monotone sequences of real numbers have limits, in the sense that a monotone sequence of real numbers either converges to a real number or diverges to infinity. In fact, something slightly stronger is true; the limit of a non-decreasing sequence exists and is its supremum, and the limit of a non-increasing sequence exists and is its infimum. This useful fact is a property of the extended real number system \(\R \text{.}\) Other totally ordered number subsystems, such as the rational numbers \(\Q \text{,}\) do not enjoy this property, since suprema and infima of sets need not exist in these number systems, which are Dedekind incomplete in the sense introduced in Section 2.3 The Complete Ordered Field.
    🔗

    Theorem 3.3.13. Monotone convergence theorem.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\)
    1. If \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is non-decreasing, then
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = \sup_{ n \in \N }{ x_{ n } }\text{.} \end{equation*}
      🔗
      🔗
    2. If \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is non-increasing, then
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = \inf_{ n \in \N }{ x_{ n } }\text{.} \end{equation*}
      🔗
      🔗
    In particular, if \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is bounded and monotone, then it is convergent.
    🔗
    🔗

    Proof.
    1. We observe that \(\set{ x_{ n } }_{ n = 0 }^{ \infty } \neq \emptyset \) is non-empty, and so \(\sup_{ n \in \N }{ x_{ n } } = \sup \of{ \set{ x_{ n } }_{ n = 0 }^{ \infty } } \neq -\infty \text{.}\) There are two cases; either \(\sup_{ n \in \N }{ x_{ n } } = \infty \) or \(\sup_{ n \in \N }{ x_{ n } } \in \R \) is a real number.
      🔗
      First suppose that \(\sup_{ n \in \N }{ x_{ n } } = \infty \text{,}\) and let \(B \in \R \) be a real number. Since
      \begin{equation*} B \lt \infty = \sup_{ n \in \N }{ x_{ n } }\text{,} \end{equation*}
      \(B \) is not an upper bound for \(\set{ x_{ n } }_{ n = 0 }^{ \infty } \text{;}\) that is, \(x_{ n_{ B } } \gt B \) for some natural number \(n_{ B } \in \N \text{.}\) We observe that since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is non-decreasing,
      \begin{equation*} x_{ n } \geq x_{ n_{ B } } \gt B \end{equation*}
      for all indices \(n \geq n_{ B } \text{,}\) and so
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = \infty = \sup_{ n \in \N }{ x_{ n } }\text{.} \end{equation*}
      🔗
      On the other hand, now suppose that \(S = \sup_{ n \in \N }{ x_{ n } } \in \R \) is a real number, and let \(\epsilon \gt 0 \) be a positive real number. Since
      \begin{equation*} S - \epsilon \lt S = \sup_{ n \in \N }{ x_{ n } }\text{,} \end{equation*}
      \(S - \epsilon \) is not an upper bound for \(\set{ x_{ n } }_{ n = 0 }^{ \infty } \text{;}\) that is, \(x_{ n_{ \epsilon } } \gt S - \epsilon \) for some natural number \(n_{ \epsilon } \in \N \text{.}\) Since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is non-decreasing,
      \begin{equation*} S - \epsilon \lt x_{ n_{ \epsilon } } \leq x_{ n } \leq S \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{,}\) and so
      \begin{align*} d \of{ x_{ n } , S } \amp = \abs{ x_{ n } - S } = S - x_{ n }\\ \amp \lt S - \of{ S - \epsilon } = \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = S = \sup_{ n \in \N }{ x_{ n } }\text{.} \end{equation*}
      🔗
      🔗
    2. We observe that \(\set{ x_{ n } }_{ n = 0 }^{ \infty } \neq \emptyset \) is non-empty, and so \(\inf_{ n \in \N }{ x_{ n } } = \inf \of{ \set{ x_{ n } }_{ n = 0 }^{ \infty } } \neq \infty \text{.}\) There are two cases; either \(\inf_{ n \in \N }{ x_{ n } } = -\infty \) or \(\inf_{ n \in \N }{ x_{ n } } \in \R \) is a real number.
      🔗
      First suppose that \(\inf_{ n \in \N }{ x_{ n } } = -\infty \text{,}\) and let \(B \in \R \) be a real number. Since
      \begin{equation*} B \gt -\infty = \inf_{ n \in \N }{ x_{ n } }\text{,} \end{equation*}
      \(B \) is not a lower bound for \(\set{ x_{ n } }_{ n = 0 }^{ \infty } \text{;}\) that is, \(x_{ n_{ B } } \lt B \) for some natural number \(n_{ B } \in \N \text{.}\) We observe that since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is non-increasing,
      \begin{equation*} x_{ n } \leq x_{ n_{ B } } \lt B \end{equation*}
      for all indices \(n \geq n_{ B } \text{,}\) and so
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = -\infty = \inf_{ n \in \N }{ x_{ n } }\text{.} \end{equation*}
      🔗
      On the other hand, now suppose that \(I = \inf_{ n \in \N }{ x_{ n } } \in \R \) is a real number, and let \(\epsilon \gt 0 \) be a positive real number. Since
      \begin{equation*} I + \epsilon \gt S = \inf_{ n \in \N }{ x_{ n } }\text{,} \end{equation*}
      \(I + \epsilon \) is not a lower bound for \(\set{ x_{ n } }_{ n = 0 }^{ \infty } \text{;}\) that is, \(x_{ n_{ \epsilon } } \lt I + \epsilon \) for some natural number \(n_{ \epsilon } \in \N \text{.}\) Since \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is non-increasing,
      \begin{equation*} I + \epsilon \gt x_{ n_{ \epsilon } } \geq x_{ n } \geq I \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{,}\) and so
      \begin{align*} d \of{ x_{ n } , I } \amp = \abs{ x_{ n } - I } = x_{ n } - I\\ \amp \lt I + \epsilon - I = \epsilon \end{align*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) We conclude that
      \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } = I = \inf_{ n \in \N }{ x_{ n } }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    What we have just shown will prove incredibly useful; in particular, we will use the fact that all bounded, monotone sequences of real numbers are convergent several times throughout this chapter. The converse is not true; while convergent sequences of real numbers are bounded, not all such sequences need be monotone.

    Subsection 3.3.3 Upper and Lower Limits

    If a sequence of points in a metric space is convergent, then its image has exactly one limit point. More generally, studying the limit points of the image of a sequence of points is a fruitful exercise regardless of whether or not the series converges. We will see that the Dedekind completeness of the real numbers \(\R \) allows us to characterize these limit points via the upper and lower limits.
    🔗

    Lemma 3.3.14. Monotonicity of suprema/infima.

    Let \(U , V \subseteq X \) be subsets of a partially ordered set \(\of{ X , \preceq } \text{,}\) and suppose that \(U \subseteq V \text{.}\)
    1. If \(U \) and \(V \) have suprema, then \(\sup \of{ U } \leq \sup \of{ V } \text{.}\)
      🔗
      🔗
    2. If \(U \) and \(V \) have infima, then \(\inf \of{ U } \geq \inf \of{ V } \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. If \(U \subseteq V \text{,}\) then every upper bound for \(V \) is an upper bound for \(U \text{,}\) and so
      \begin{align*} \sup \of{ U } \amp = \min \of{ \setmid{ x \in X }{ u \preceq x \textrm{ for all } u \in U } }\\ \amp \leq \min \of{ \setmid{ x \in X }{ v \preceq x \textrm{ for all } v \in V } } = \sup \of{ V }\text{.} \end{align*}
      🔗
      🔗
    2. If \(U \subseteq V \text{,}\) then every lower bound for \(V \) is a lower bound for \(U \text{,}\) and so
      \begin{align*} \inf \of{ U } \amp = \max \of{ \setmid{ x \in X }{ x \preceq u \textrm{ for all } u \in U } }\\ \amp \geq \min \of{ \setmid{ x \in X }{ x \preceq v \textrm{ for all } v \in V } } = \inf \of{ V }\text{.} \end{align*}
      🔗
      🔗
    🔗

    Definition 3.3.15. Upper/lower limit.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\)
    • Upper limit.
      The sequence \(\of{ \sup_{ n \geq m }{ x_{ n } } }_{ m = 0 }^{ \infty } \) is non-increasing, and so by the Monotone convergence theorem has a well-defined limit in the extended real numbers \(\R \cup \set{ \pm \infty } \text{.}\) This limit is called the upper limit or limit supremum of the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and is denoted
      \begin{equation*} \limsup_{ n \to \infty }{ x_{ n } } = \lim_{ m \to \infty }{ \sup_{ n \geq m }{ x_{ n } } } = \inf_{ m \in \N }{ \sup_{ n \geq m }{ x_{ n } } }\text{.} \end{equation*}
      🔗
      🔗
    • Lower limit.
      The sequence \(\of{ \inf_{ n \geq m }{ x_{ n } } }_{ m = 0 }^{ \infty } \) is non-decreasing, and so by the Monotone convergence theorem has a well-defined limit in the extended real numbers \(\R \cup \set{ \pm \infty } \text{.}\) This limit is called the lower limit or limit infimum of the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) and is denoted
      \begin{equation*} \liminf_{ n \to \infty }{ x_{ n } } = \lim_{ m \to \infty }{ \inf_{ n \geq m }{ x_{ n } } } = \sup_{ m \in \N }{ \inf_{ n \geq m }{ x_{ n } } }\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Example 3.3.16. Upper/lower limits.

    Consider the sequence
    \begin{equation*} x_{ n } = \of{ -1 }^{ n } \of{ 1 + \frac{ 1 }{ n } } = \of{ -1 }^{ n } \of{ \frac{ n + 1 }{ n } }\text{.} \end{equation*}
    Then \(\limsup_{ n \to \infty }{ x_{ n } } = 1 \text{,}\) and \(\liminf_{ n \to \infty }{ x_{ n } } = -1 \text{.}\)
    🔗
    🔗

    Proposition 3.3.17. Properties of upper limits.

    Upper limits of sequences of real numbers have the following properties:
    1. A sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } \in \R \) is bounded from above if and only if
      \begin{equation*} \limsup_{ n \to \infty }{ x_{ n } } \lt \infty\text{.} \end{equation*}
      🔗
      🔗
    2. For any sequences \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } , y_{ n } \in \R \text{,}\)
      \begin{equation*} \limsup_{ n \to \infty }{ \of{ x_{ n } + y_{ n } } } \leq \limsup_{ n \to \infty }{ x_{ n } } + \limsup_{ n \to \infty }{ y_{ n } } \end{equation*}
      whenever the right-hand side of the above inequality is well-defined.
      🔗
      🔗
    3. For any non-negative real number \(\alpha \in \clopint{ 0 }{ \infty } \) and sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } \in \R \text{,}\)
      \begin{equation*} \limsup_{ n \to \infty }{ \alpha x_{ n } } = \alpha \limsup_{ n \to \infty }{ x_{ n } } \end{equation*}
      whenever the right-hand side of the above equality is well-defined.
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is bounded from above. Then there is a real number \(B \in \R \) so that \(x_{ n } \leq B \) for all indices \(n \in \N \text{.}\) In particular, for all natural numbers \(m \in \N \text{,}\) \(x_{ n } \leq B \) for all indices \(n \geq m \text{,}\) and so \(\sup_{ n \geq m }{ x_{ n } } \leq B \text{.}\) Proposition 3.3.2 Comparison of limits implies that
      \begin{equation*} \limsup_{ n \to \infty }{ x_{ n } } = \lim_{ n \to \infty }{ \sup_{ n \geq m }{ x_{ n } } } \leq B \lt \infty\text{.} \end{equation*}
      🔗
      Conversely, now suppose that \(\limsup_{ n \to \infty }{ x_{ n } } \lt \infty \text{.}\) For each natural number \(m \in \N \text{,}\) let \(S_{ m } = \sup_{ n \geq m }{ x_{ n } } \text{,}\) and let
      \begin{equation*} S = \lim_{ m \to \infty }{ S_{ m } } = \lim_{ m \to \infty }{ \sup_{ n \geq m }{ x_{ n } } } = \limsup_{ n \to \infty }{ x_{ n } }\text{.} \end{equation*}
      Since \(1 \) is a positive real number, there is a natural number \(m_{ 1 } \in \N \) so that \(d \of{ S_{ m } , S } \lt 1 \) for all indices \(m \geq m_{ 1 } \text{.}\) In particular,
      \begin{equation*} S_{ m_{ 1 } } - S \leq \abs{ S_{ m_{ 1 } } - S } = d \of{ S_{ m_{ 1 } } , S } \lt 1\text{,} \end{equation*}
      and so \(\sup_{ n \geq m_{ 1 } }{ x_{ n } } = S_{ m_{ 1 } } \lt S + 1 \text{.}\) Let
      \begin{equation*} B = \max \of{ \set{ x_{ 0 } , x_{ 1 } , \dotsc , x_{ m_{ 1 } - 1 } , S + 1 } }\text{,} \end{equation*}
      and note that \(x_{ n } \leq B \) for all indices \(n \in \N \text{.}\) Since such an upper bound exists, we conclude that \(\of{ x_{ n } }_{ n = 1 }^{ \infty } \) is bounded from above.
      🔗
      🔗
    2. For each natural number \(m \in \N \text{,}\) let \(S_{ m } = \sup_{ n \geq m }{ x_{ n } } \) and \(T_{ m } = \sup_{ n \geq m }{ y_{ n } } \text{.}\) We observe that \(x_{ n } + y_{ n } \leq S_{ m } + T_{ m } \) for all natural numbers \(m \in \N \) and indices \(n \geq m \text{.}\) Thus
      \begin{equation*} \sup_{ n \geq m }{ \of{ x_{ n } + y_{ n } } } \leq S_{ m } + T_{ m } \end{equation*}
      for all natural numbers \(m \in \N \text{,}\) and so Proposition 3.3.2 Comparison of limits and (1) of Proposition 3.3.1 Limits and vector arithmetic together imply that
      \begin{align*} \limsup_{ n \to \infty }{ \of{ x_{ n } + y_{ n } } } \amp = \lim_{ n \to \infty }{ \sup_{ n \geq m }{ \of{ x_{ n } + y_{ n } } } } \leq \lim_{ m \to \infty }{ \of{ S_{ m } + T_{ m } } }\\ \amp = \lim_{ m \to \infty }{ S_{ m } } + \lim_{ m \to \infty }{ T_{ m } } = \limsup_{ n \to \infty }{ x_{ n } } + \limsup_{ n \to \infty }{ y_{ n } }\text{.} \end{align*}
      🔗
      🔗
    3. If \(\alpha = 0 \text{,}\) then our hypotheses imply that \(\limsup_{ n \to \infty }{ x_{ n } } \in \R \) is a real number, and so
      \begin{equation*} \limsup_{ n \to \infty }{ \alpha x_{ n } } = \limsup_{ n \to \infty }{ 0 } = 0 = 0 \limsup_{ n \to \infty }{ x_{ n } }\text{.} \end{equation*}
      Thus we may suppose that \(\alpha \gt 0 \) is positive. In this case, multiplication by \(\alpha \) is a strictly order-preserving bijection of \(\R \cup \set{ \pm \infty } \text{,}\) and so
      \begin{gather*} \sup_{ n \geq m }{ \alpha x_{ n } } = \sup \of{ \set{ \alpha x_{ n } }_{ n = m }^{ \infty } } = \alpha \sup \of{ \set{ x_{ n } }_{ n = m }^{ \infty } } = \alpha \sup_{ n \geq m }{ x_{ n } } \end{gather*}
      for all natural numbers \(m \in \N \text{.}\) We conclude that
      \begin{align*} \limsup_{ n \to \infty }{ \alpha x_{ n } } \amp = \lim_{ m \to \infty }{ \sup_{ n \geq m }{ \alpha x_{ n } } } = \lim_{ m \to \infty }{ \alpha \sup_{ n \geq m }{ x_{ n } } }\\ \amp = \alpha \lim_{ m \to \infty }{ \sup_{ n \geq m }{ x_{ n } } } = \alpha \limsup_{ n \to \infty }{ x_{ n } }\text{.} \end{align*}
      🔗
      🔗
    🔗
    One natural follow-up from Proposition 3.3.17 Properties of upper limits is the question of negative scalings of sequences: If \(\alpha \lt 0 \) is a negative real number and \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) is a sequence of real numbers \(x_{ n } \in \R \text{,}\) what is the upper limit \(\limsup_{ n \to \infty }{ \alpha x_{ n } } \text{?}\)
    🔗

    Lemma 3.3.18. Upper and lower limits.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers. Then
    \begin{equation*} \limsup_{ n \to \infty }{ \of{ -x_{ n } } } = -\liminf_{ n \to \infty }{ x_{ n } } \end{equation*}
    and
    \begin{equation*} \liminf_{ n \to \infty }{ \of{ -x_{ n } } } = -\limsup_{ n \to \infty }{ x_{ n } }\text{.} \end{equation*}
    Here we define \(-\of{ \infty } = -\infty \) and \(-\of{ -\infty } = \infty \text{.}\)
    🔗
    🔗

    Proof.
    We observe that
    \begin{align*} \sup_{ n \geq m }{ \of{ -x_{ n } } } \amp = \min \of{ \setmid{ x \in \clint{ -\infty }{ \infty } }{ -x_{ n } \leq x \textrm{ for all } n \geq m } }\\ \amp = \min \of{ \setmid{ x \in \clint{ -\infty }{ \infty } }{ -x \leq x_{ n } \textrm{ for all } n \geq m } }\\ \amp = \min \of{ \setmid{ -x \in \clint{ -\infty }{ \infty } }{ x \leq x_{ n } \textrm{ for all } n \geq m } }\\ \amp = -\max \of{ \setmid{ -x \in \clint{ -\infty }{ \infty } }{ x \leq x_{ n } \textrm{ for all } n \geq m } } = -\inf_{ n \geq m }{ x_{ n } } \end{align*}
    for all natural numbers \(m \in \N \text{,}\) and so
    \begin{align*} \limsup_{ n \to \infty }{ \of{ -x_{ n } } } \amp = \lim_{ n \to \infty }{ \sup_{ n \geq m }{ \of{ -x_{ n } } } }\\ \amp = \lim_{ n \to \infty }{ -\inf_{ n \geq m }{ x_{ n } } }\\ \amp = -\lim_{ n \to \infty }{ \inf_{ n \geq m }{ x_{ n } } } = -\liminf_{ n \to \infty }{ x_{ n } }\text{.} \end{align*}
    Applying this result to the sequence \(\of{ -x_{ n } }_{ n = 0 }^{ \infty } \text{,}\) we see that
    \begin{align*} -\limsup_{ n \to \infty }{ x_{ n } } \amp = -\limsup_{ n \to \infty }{ \of{ -\of{ -x_{ n } } } }\\ \amp = -\of{ -\liminf_{ n \to \infty }{ \of{ -x_{ n } } } } = \liminf_{ n \to \infty }{ \of{ -x_{ n } } }\text{.} \end{align*}
    🔗
    🔗
    In addition to answering our question about the behavior of upper limits under scaling by negative real numbers, we can use Lemma 3.3.18 Upper and lower limits to translate results about upper limits into results about lower limits. For example, each of the properties in Proposition 3.3.17 Properties of upper limits has an analogue for lower limits.
    🔗

    Corollary 3.3.19. Properties of lower limits.

    Lower limits of sequences of real numbers have the following properties:
    1. A sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } \in \R \) is bounded from below if and only if
      \begin{equation*} \liminf_{ n \to \infty }{ x_{ n } } \gt -\infty\text{.} \end{equation*}
      🔗
      🔗
    2. For any sequences \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } , y_{ n } \in \R \text{,}\)
      \begin{equation*} \liminf_{ n \to \infty }{ \of{ x_{ n } + y_{ n } } } \geq \liminf_{ n \to \infty }{ x_{ n } } + \liminf_{ n \to \infty }{ y_{ n } } \end{equation*}
      whenever the right-hand side of the above inequality is well-defined.
      🔗
      🔗
    3. For any non-negative real number \(\alpha \in \clopint{ 0 }{ \infty } \) and sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of real numbers \(x_{ n } \in \R \text{,}\)
      \begin{equation*} \liminf_{ n \to \infty }{ \alpha x_{ n } } = \alpha \liminf_{ n \to \infty }{ x_{ n } } \end{equation*}
      whenever the right-hand side of the above equality is well-defined.
      🔗
      🔗

    Finally, we end with a characterization of convergence and divergence to infinity in terms of upper and lower limits.
    🔗

    Theorem 3.3.20. Convergence and upper and lower limits.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) be a sequence of real numbers \(x_{ n } \in \R \text{.}\)
    1. Convergence.
      For any real number \(l \in \R \text{,}\) the sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(l \) if and only if
      \begin{equation*} \limsup_{ n \to \infty }{ x_{ n } } = \liminf_{ n \to \infty }{ x_{ n } } = l\text{.} \end{equation*}
      🔗
      🔗
    2. Divergence to \(\infty \).
      The sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(\infty \) if and only if
      \begin{equation*} \liminf_{ n \to \infty }{ x_{ n } } = \infty\text{.} \end{equation*}
      🔗
      🔗
    3. Divergence to \(-\infty \).
      The sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(-\infty \) if and only if
      \begin{equation*} \limsup_{ n \to \infty }{ x_{ n } } = -\infty\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. For each natural number \(m \in \N \text{,}\) let \(S_{ m } = \sup_{ n \geq m }{ x_{ n } } \) and \(I_{ m } = \inf_{ n \geq m }{ x_{ n } } \text{.}\) First suppose that \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(l \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number. Then there is a natural number \(n_{ \epsilon } \in \N \) so that
      \begin{equation*} l - \epsilon \lt x_{ n } \lt l + \epsilon \end{equation*}
      for all indices \(n \geq n_{ \epsilon } \text{.}\) In particular,
      \begin{equation*} l - \epsilon \lt I_{ m } \leq S_{ m } \lt l + \epsilon \end{equation*}
      for any natural number \(m \geq n_{ \epsilon } \text{,}\) and so
      \begin{equation*} l - \epsilon \leq \lim_{ m \to \infty }{ I_{ m } } \leq \lim_{ m \to \infty }{ S_{ m } } \leq l + \epsilon \end{equation*}
      by Proposition 3.3.2 Comparison of limits. Since this holds for all positive real numbers \(\epsilon \gt 0 \text{,}\)
      \begin{equation*} \limsup_{ m \to \infty }{ x_{ n } } = \liminf_{ n \to \infty }{ x_{ n } } = l\text{.} \end{equation*}
      🔗
      Conversely, now suppose that
      \begin{equation*} \limsup_{ m \to \infty }{ x_{ n } } = \liminf_{ n \to \infty }{ x_{ n } } = l\text{.} \end{equation*}
      Let \(\epsilon \gt 0 \) be a positive real number. Then there are natural numbers \(m_{ \epsilon } , n_{ \epsilon } \in \N \) so that \(d \of{ S_{ m } , l } \lt \epsilon \) for all indices \(m \geq m_{ \epsilon } \) and \(d \of{ I_{ m } , l } \lt \epsilon \) for all indices \(m \geq n_{ \epsilon } \text{.}\) Let \(p_{ \epsilon } = \max \of{ \set{ m_{ \epsilon } , n_{ \epsilon } } } \in \N \text{,}\) and note that
      \begin{align*} x_{ n } - l \amp \leq S_{ p_{ \epsilon } } - l \leq \abs{ S_{ p_{ \epsilon } } - l }\\ \amp = d \of{ S_{ p_{ \epsilon } } , l } \lt \epsilon \end{align*}
      and
      \begin{align*} l - x_{ n } \amp \leq l - I_{ p_{ \epsilon } } \leq \abs{ I_{ p_{ \epsilon } } - l }\\ \amp = d \of{ I_{ p_{ \epsilon } } , l } \lt \epsilon \end{align*}
      for all indices \(n \geq p_{ \epsilon } \text{.}\) We conclude that
      \begin{align*} d \of{ x_{ n } , l } = \abs{ x_{ n } - l }\\ \amp = \max \of{ \set{ x_{ n } - l , l - x_{ n } } } \lt \epsilon \end{align*}
      for all indices \(n \geq p_{ \epsilon } \text{,}\) and so \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) converges to \(l \text{.}\)
      🔗

    Reading Questions 3.3.5 Problems

    In contrast with the exercises, solving the following problems will require you to engage more deeply with the course material.     1. Limits and scalar multiplication.

    Let \(\norm{ \oparg } \) be a norm on a real or complex vector space \(V \text{.}\) Prove that
    \begin{equation*} \lim_{ n \to \infty }{ \alpha_{ n } \vect{ v }_{ n } } = \lim_{ n \to \infty }{ \alpha_{ n } } \lim_{ n \to \infty }{ \vect{ v }_{ n } } \end{equation*}
    for any convergent sequences \(\of{ \alpha_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ \vect{ v }_{ n } }_{ n = 0 }^{ \infty } \) of scalars \(\alpha_{ n } \) and vectors \(\vect{ v }_{ n } \in V \text{.}\)
    🔗
    🔗

    2. Limits and division.

    Prove that
    \begin{equation*} \lim_{ n \to \infty }{ \frac{ 1 }{ x_{ n } } } = \frac{ 1 }{ \lim_{ n \to \infty }{ x_{ n } } } \end{equation*}
    for every sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of non-zero real numbers \(x_{ n } \in \R \setminus \set{ 0 } \) which converges to a non-zero real number limit
    \begin{equation*} \lim_{ n \to \infty }{ x_{ n } } \neq 0\text{.} \end{equation*}
    🔗
    🔗

    3. Squeezing to infinity.

    Let \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) be sequences of real numbers \(x_{ n } , y_{ n } \in \R \text{.}\)
    🔗
    (a)
    Prove that if \(x_{ n } \leq y_{ n } \) for all indices \(n \in \N \) and \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(\infty \text{,}\) then \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(\infty \text{.}\)
    🔗
    🔗
    (b)
    Prove that if \(x_{ n } \leq y_{ n } \) for all indices \(n \in \N \) and \(\of{ y_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(-\infty \text{,}\) then \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) diverges to \(-\infty \text{.}\)
    🔗
    🔗
    We can interpret the above results as versions of the Squeeze theorem for divergence to infinity.
    🔗
    🔗

    4. Reciprocals of infinite limits.

    Prove that a sequence \(\of{ x_{ n } }_{ n = 0 }^{ \infty } \) of negative real numbers \(x_{ n } \lt 0 \) diverges to \(-\infty \) if and only if
    \begin{equation*} \lim_{ n \to \infty }{ \frac{ 1 }{ x_{ n } } } = 0\text{.} \end{equation*}

    🔗
    🔗
    (b)
