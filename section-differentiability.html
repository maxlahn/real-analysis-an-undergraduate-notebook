    Section 5.1 Differentiability

    The fundamental object in differential calculus is the differentiable function and its derivative. In this section, we formally differentiability as a property of real-valued functions defined on subsets of the real line \(\R \text{.}\) We will develop techniques of differentiation, compile a list of differentiable functions, and compare the regularities of various functions.
    🔗

    Subsection 5.1.1 Introduction to Differentiation

    A real-valued function defined on a subset of the real line is called differentiable at a point if it can be well-approximated by a linear function in a neighborhood of that point. In this case, the derivative of the function gives the slope of this local linear approximation.
    🔗

    Definition 5.1.1. Differentiability.

    A real-valued function \(f \colon X \to \R \) on a subset \(X \subseteq \R \) is called differentiable at a point \(c \in X \cap X' \) if there is a real number \(D \in \R \) so that for all positive real numbers \(\epsilon \gt 0 \text{,}\) there is a positive real number \(\delta \gt 0 \) so that
    \begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - D } \lt \epsilon \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{;}\) that is, \(f \) is differentiable at \(c \) if \(c \) is a limit point of \(X \) in \(\R \) and
    \begin{equation*} \lim_{ x \to c }{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } = D\text{.} \end{equation*}
    In this case, the above limit is called the derivative of \(f \) at \(c \) and is denoted \(f' \of{ c } = D \text{.}\)
    🔗
    The differentiability locus \(\DL \of{ f } \) of \(f \) is the subset of \(X \cap X' \) comprised by the points at which \(f \) is differentiable. The function \(f \) is called differentiable if \(\DL \of{ f } = X \cap X' \text{.}\) The derivative of \(f \) is the real-valued function \(f' \colon \DL \of{ f } \to \R \text{.}\)
    🔗
    🔗

    Example 5.1.2. Differentiability.

    The following are examples of differentiable functions:
    • Let \(f \colon \R \to \R \) be a constant function defined by the formula \(f \of{ x } = a \) for some real number \(a \in \R \text{,}\) and consider a point \(c \in \R \text{.}\) Since for any \(\epsilon \gt 0 \text{,}\)
      \begin{align*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - 0 } \amp = \abs{ \frac{ a - a }{ x - c } }\\ \amp = \abs{ \frac{ 0 }{ x - c } } = \abs{ 0 } = 0 \lt \epsilon \end{align*}
      for all points \(x \in \R \setminus \set{ c } \text{,}\) \(f \) is differentiable at \(c \text{,}\) with derivative \(f' \of{ c } = 0 \text{.}\) Since \(c \) was chosen arbitrarily, \(f \) has differentiability locus \(\DL \of{ f } = \R = \R \cap \R' \text{,}\) so that \(f \) is differentiable.
      🔗
      🔗
    • Let \(g \colon \R \to \R \) be a linear function defined by the formula \(g \of{ x } = a x + b \) for some real numbers \(a , b \in \R \text{,}\) and consider a point \(c \in \R \text{.}\) Since for any positive real number \(\epsilon \gt 0 \text{,}\)
      \begin{align*} \abs{ \frac{ g \of{ x } - g \of{ c } }{ x - c } - a } \amp = \abs{ \frac{ \of{ a x + b } - \of{ a c + b } }{ x - c } - a } = \abs{ \frac{ a x + b - a c - b }{ x - c } - a }\\ \amp = \abs{ \frac{ a x - a c }{ x - c } - a } = \abs{ \frac{ a \of{ x - c } }{ x - c } - a }\\ \amp = \abs{ a - a } = \abs{ 0 } = 0 \lt \epsilon \end{align*}
      for all points \(x \in \R \setminus \set{ c } \text{,}\) \(f \) is differentiable at \(c \text{,}\) with derivative \(f' \of{ c } = 0 \text{.}\) Since \(c \) was chosen arbitrarily, \(g \) has differentiability locus \(\DL \of{ g } = \R = \R \cap \R' \text{,}\) so that \(g \) is differentiable.
      🔗
      🔗
    • Let \(h \colon \R \to \R \) be the quadratic function defined by the formula \(h \of{ x } = x^{ 2 } \text{,}\) and consider a point \(c \in \R \text{.}\) For any positive real number \(\epsilon \gt 0 \text{,}\) let \(\delta = \epsilon \gt 0 \text{.}\) We observe that
      \begin{align*} \abs{ \frac{ h \of{ x } - h \of{ c } }{ x - c } - 2 c } \amp = \abs{ \frac{ x^{ 2 } - c^{ 2 } }{ x - c } - 2 c } = \abs{ \frac{ \of{ x + c } \of{ x - c } }{ x - c } - 2 c }\\ \amp = \abs{ x + c - 2 c } = \abs{ x - c } \lt \delta = \epsilon \end{align*}
      for all points \(x \in \R \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) We conclude that \(h \) is differentiable at \(c \text{,}\) with derivative \(h' \of{ c } = 2 c \text{.}\) Since \(c \) was chosen arbitrarily, \(h \) has differentiability locus \(\DL \of{ h } = \R = \R \cap \R' \text{,}\) so that \(h \) is differentiable.
      🔗
      🔗
    🔗
    🔗
    Extensions of the above examples can be used to compute the derivatives of a plethora of differentiable functions. Specifically, we will shortly see how to compute the derivative of a complicated function by breaking it down into smaller differentiable pieces. First, however, we observe that differentiability at a point is a stronger condition than continuity at that point.
    🔗

    Lemma 5.1.3. Differentiability implies continuity.

    A real-valued function \(f \colon X \to \R \) on a subset \(X \subseteq \R \) is continuous at every point \(c \in \DL \of{ f } \text{.}\)
    🔗
    🔗

    Proof.
    Let \(f \colon X \to \R \) be a real-valued function on a subset \(X \subseteq \R \text{,}\) and suppose that \(f \) is differentiable at a point \(c \in X \text{.}\) Then there is a positive real number \(\delta_{ f } \gt 0 \) so that
    \begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt 1 \end{equation*}
    for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta_{ f } \text{.}\) Let \(\epsilon \gt 0 \) be a positive real number, and let
    \begin{equation*} \delta = \min \of{ \set{ \delta_{ f } , \frac{ \epsilon }{ 1 + \abs{ f' \of{ c } } } } } \gt 0\text{.} \end{equation*}
    We observe that
    \begin{align*} \abs{ f \of{ x } - f \of{ c } } \amp = \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } \cdot \abs{ x - c } = \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } + f' \of{ c } } \cdot \abs{ x - c }\\ \amp \leq \of{ \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } + \abs{ f' \of{ c } } } \abs{ x - c }\\ \amp \lt \of{ 1 + \abs{ f' \of{ c } } } \delta \lt \of{ 1 + \abs{ f' \of{ c } } } \of{ \frac{ \epsilon }{ 1 + \abs{ f' \of{ c } } } } = \epsilon \end{align*}
    for any point \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{,}\) and so we conclude that \(f \) is continuous at \(c \text{.}\)
    🔗
    🔗
    While differentiable functions are continuous, continuous functions need not be differentiable. For example, the absolute value function \(\abs{ x } \) is continuous, but \(\abs{ x } \) is not differentiable at the point \(x = 0 \text{.}\)
    🔗
    We now observe that differentiability is preserved under the pointwise addition, subtraction, and multiplication of functions.
    🔗

    Proposition 5.1.4. Arithmetic of differentiable functions.

    1. Addition of differentiable functions.
      Let \(f , g \colon X \to \R \) be real-valued functions on a subset \(X \subseteq \R \text{.}\) For a point \(c \in X \text{,}\) if \(f \) and \(g \) are differentiable at \(c \text{,}\) then \(f + g \) is differentiable at \(c \text{,}\) and
      \begin{equation*} \of{ f + g }' \of{ c } = f' \of{ c } + g' \of{ c }\text{.} \end{equation*}
      🔗
      🔗
    2. Multiplication of differentiable functions.
      Let \(f , g \colon X \to \R \) be real-valued functions on a subset \(X \subseteq \R \text{.}\) For a point \(c \in X \text{,}\) if \(f \) and \(g \) are differentiable at \(c \text{,}\) then \(f \cdot g \) is differentiable at \(c \text{,}\) and
      \begin{equation*} \of{ f \cdot g }' \of{ c } = f' \of{ c } g \of{ c } + f \of{ c } g' \of{ c }\text{.} \end{equation*}
      🔗
      🔗
    🔗

    Proof.
    1. Let \(\epsilon \gt 0 \) be a positive real number. Since \(f \) and \(g \) are differentiable at \(c \text{,}\) there are positive real numbers \(\delta_{ f } , \delta_{ g } \gt 0 \) so that
      \begin{equation*} \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta_{ f } \text{,}\) and
      \begin{equation*} \abs{ \frac{ g \of{ x } - g \of{ c } }{ x - c } - g' \of{ c } } \lt \frac{ \epsilon }{ 2 } \end{equation*}
      for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta_{ g } \text{.}\) Let \(\delta = \min \of{ \set{ \delta_{ f } , \delta_{ g } } } \gt 0 \text{,}\) and note that
      \begin{align*} \abs{ \frac{ \of{ f + g } \of{ x } - \of{ f + g } \of{ c } }{ x - c } - \of{ f' \of{ c } + g' \of{ c } } } \amp = \abs{ \frac{ f \of{ x } + g \of{ x } - f \of{ c } - g \of{ c } }{ x - c } - f' \of{ c } - g' \of{ c } }\\ \amp = \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } + \frac{ g \of{ x } - g \of{ c } }{ x - c } - g' \of{ c } }\\ \amp \leq \abs{ \frac{ f \of{ x } - f \of{ c } }{ x - c } - f' \of{ c } } + \abs{ \frac{ g \of{ x } - g \of{ c } }{ x - c } - g' \of{ c } }\\ \amp \lt \frac{ \epsilon }{ 2 } + \frac{ \epsilon }{ 2 } = \epsilon \end{align*}
      for all points \(x \in X \) so that \(0 \lt \abs{ x - c } \lt \delta \text{.}\) Thus \(f + g \) is differentiable at \(c \text{,}\) with derivative
      \begin{equation*} \of{ f + g }' \of{ c } = f' \of{ c } + g' \of{ c }\text{.} \end{equation*}
      🔗
      🔗
    2. Because utilizing the \(\epsilon \)-\(\delta \) characterization of convergence is slightly more complicated than it’s worth, we compute the derivative directly. Since \(f \) and \(g \) are differentiable at \(c \text{,}\)
      \begin{equation*} \lim_{ x \to c }{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } = f' \of{ c } \end{equation*}
      and
      \begin{equation*} \lim_{ x \to c }{ \frac{ g \of{ x } - g \of{ c } }{ x - c } } = g' \of{ c }\text{.} \end{equation*}
      Moreover, Lemma 5.1.3 Differentiability implies continuity implies that \(g \) is continuous at \(c \text{,}\) so that
      \begin{equation*} \lim_{ x \to c }{ g \of{ x } } = g \of{ c }\text{.} \end{equation*}
      We conclude that
      \begin{align*} \lim_{ x \to c }{ \frac{ \of{ f \cdot g } \of{ x } - \of{ f \cdot g } \of{ c } }{ x - c } } \amp = \lim_{ x \to c }{ \frac{ f \of{ x } g \of{ x } - f \of{ c } g \of{ x } + f \of{ c } g \of{ x } - f \of{ c } g \of{ c } }{ x - c } }\\ \amp = \lim_{ x \to c }{ \of{ \of{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } g \of{ x } + f \of{ c } \of{ \frac{ g \of{ x } - g \of{ c } }{ x - c } } } }\\ \amp = f' \of{ c } g \of{ c } + f \of{ c } g' \of{ c }\text{.} \end{align*}
      Thus \(f \cdot g \) is differentiable at \(c \text{,}\) with derivative \(\of{ f \cdot g }' \of{ c } = f' \of{ c } g \of{ c } + f \of{ c } g' \of{ c } \text{.}\)
      🔗
      🔗
    🔗
    In fact, modest hypotheses on the denominator of a quotient of differentiable functions implies that such a quotient is also differentiable. You will have an opportunity to prove this quotient rule in the problems for this section. First, however, we observe the following immediate corollary of Proposition 5.1.4 Arithmetic of differentiable functions:
    🔗

    Corollary 5.1.5. Differentiability of polynomials.

    Polynomial functions are differentiable at every real number.
    🔗
    🔗
    We can combine functions in more ways than just pointwise arithmetic. One of the fundamental such operations is composition. Here we see that the composition of two differentiable functions is also differentiable.
    🔗

    Theorem 5.1.6. Chain rule.

    Let \(f \colon X \to \R \) and \(g \colon Y \to \R \) be real-valued functions on subsets \(X , Y \subseteq \R \text{,}\) and suppose that \(f \of{ X } \subseteq Y \text{.}\) If \(f \) is differentiable at a point \(c \in X \) and \(g \) is differentiable at \(f \of{ c } \text{,}\) then \(g \circ f \colon X \to \R \) is differentiable at \(c \text{,}\) with derivative
    \begin{equation*} \of{ g \circ f }' \of{ c } = g' \of{ f \of{ c } } f' \of{ c }\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    We first argue that
    \begin{equation*} \lim_{ x \to c }{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } } = g' \of{ f \of{ c } }\text{.} \end{equation*}
    Indeed, let \(\epsilon \gt 0 \) be a positive real number. Since \(g \) is differentiable at \(f \of{ c } \text{,}\) there is a positive real number \(\eta \gt 0 \) so that
    \begin{equation*} \abs{ \frac{ g \of{ y } - g \of{ f \of{ c } } }{ y - f \of{ c } } - g' \of{ f \of{ c } } } \lt \epsilon \end{equation*}
    for all points \(y \in Y \) so that \(0 \lt \abs{ y - f \of{ c } } \lt \eta \text{.}\) Since \(f \) is differentiable at \(c \text{,}\) it is continuous at \(c \) by Lemma 5.1.3 Differentiability implies continuity, and so there is a positive real number \(\delta \gt 0 \) so that \(\abs{ f \of{ x } - f \of{ c } } \lt \eta \) for all points \(x \in X \) so that \(\abs{ x - c } \lt \delta \text{.}\) In particular, if \(0 \lt \abs{ x - c } \lt \delta \text{,}\) then
    \begin{equation*} \abs{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } - g' \of{ f \of{ c } } } \lt \epsilon\text{.} \end{equation*}
    We conclude that
    \begin{equation*} \lim_{ x \to c }{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } } = g' \of{ f \of{ c } }\text{.} \end{equation*}
    🔗
    We now observe that
    \begin{align*} \lim_{ x \to c }{ \frac{ \of{ g \circ f } \of{ x } - \of{ g \circ f } \of{ c } }{ x - c } } \amp = \lim_{ x \to c }{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ x - c } }\\ \amp = \lim_{ x \to c }{ \of{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } } \of{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } }\\ \amp = \of{ \lim_{ x \to c }{ \frac{ g \of{ f \of{ x } } - g \of{ f \of{ c } } }{ f \of{ x } - f \of{ c } } } } \of{ \lim_{ x \to c }{ \frac{ f \of{ x } - f \of{ c } }{ x - c } } }\\ \amp = g' \of{ f \of{ c } } f' \of{ c }\text{,} \end{align*}
    and so \(g \circ f \) is differentiable at \(c \text{,}\) with derivative \(\of{ g \circ f }' \of{ c } = g' \of{ f \of{ c } } f' \of{ c } \text{.}\)
    🔗
    🔗
    The Chain rule is one of the most important foundational results in differential calculus, and has important generalizations to the differentiability of maps between higher-dimensional Euclidean spaces.
    🔗
    🔗

    Subsection 5.1.2 Regularity and Smoothness

    For real-valued functions which are differentiable at many points in their domain, we can view the derivative not just as a number, but rather as a real-valued function which itself may be subject to analysis. A natural question in this setting is whether we can differentiate this derivative itself. This is not always possible; the derivative of a differentiable function need not itself be differentiable. In fact, such a derivative need not even be continuous. Differentiable functions whose derivative is itself differentiable are called twice differentiable, and the derivative of the derivative of such a function is called its second derivative. Continuing in such a manner, we may speak of \(n \)-times differentiable functions and their \(n \)th derivatives.
    🔗

    Definition 5.1.7. Higher order differentiability.

    Fix a real-valued function \(f \colon X \to \R \) on a subset \(X \subseteq \R \text{.}\) The higher order differentiability properties of \(f \) are defined recursively as follows:
    • \(f \) is \(0 \)-times differentiable, its \(0 \)-times differentiability locus is \(\DL^{ 0 } \of{ f } = X \text{,}\) and its \(0 \)th derivative is \(f^{ \of{ 0 } } = f \colon \DL^{ 0 } \of{ f } \to \R \text{.}\)
      🔗
      🔗
    • Suppose that \(f \) has \(k \)-times differentiability locus \(\DL^{ k } \of{ f } \) and \(k \)th derivative \(f^{ \of{ k } } \colon \DL^{ k } \of{ f } \to \R \text{.}\) The \(\of{ k + 1 } \)-times differentiability locus \(\DL^{ k + 1 } \of{ f } \) is the differentiability locus
      \begin{align*} \DL^{ k + 1 } \of{ f } \amp = \DL \of{ f^{ \of{ k } } } = \setmid{ x \in \DL^{ k } \of{ f } }{ f^{ \of{ k } } \textrm{ is differentiable at } x }\\ \amp \subseteq \DL^{ k } \of{ f } \cap \of{ \DL^{ k } \of{ f } }'\text{.} \end{align*}
      The \(\of{ k + 1 } \)st derivative \(f^{ \of{ k + 1 } } \) of \(f \) is the derivative
      \begin{equation*} f^{ \of{ k + 1 } } = \of{ f^{ \of{ k } } }' \colon \DL^{ k + 1 } \of{ f } \to \R\text{.} \end{equation*}
      Then \(f \) is \(\of{ k + 1 } \)-times differentiable if \(f^{ \of{ k } } \) is differentiable at every point of \(\DL^{ k } \of{ f } \cap \of{ \DL^{ k } \of{ f } }' \text{;}\) that is, \(f \) is \(\of{ k + 1 } \)-times differentiable if
      \begin{equation*} \DL^{ k + 1 } \of{ f } = \DL^{ k } \of{ f } \cap \of{ \DL^{ k } \of{ f } }'\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Example 5.1.8. Higher order differentiability.

    The following are examples of higher order derivatives of functions:
    • Since polynomial functions are differentiable, and their derivatives are polynomials (which are also differentiable), every polynomial function is \(k \)-times differentiable for all \(k \in \N \text{.}\)
      🔗
      🔗
    • Fix a natural number \(k \in \N \text{,}\) and consider the power function \(p \colon \R \to \R \) defined by the formula \(p \of{ x } = x^{ k + \frac{ 1 }{ 3 } } \text{.}\) Once we have explored the calculus of power series in Section 7.3 Power Series, we will see that \(p \) is \(k \)-times differentiable but not \(\of{ k + 1 } \)-times differentiable.
      🔗
      🔗
    🔗
    🔗
    As previously mentioned, the derivative of a differentiable function need not be continuous. Requiring continuity in the derivatives of a function yield the concept of regularity. Intuitively, the regularity of a function determines how many of its derivatives are continuous.
    🔗

    Definition 5.1.9. Regularity.

    A real-valued function \(f \colon X \to \R \) on a subset \(X \subseteq \R \) is called \(k \)-times continuously differentiable if it is \(k \)-times differentiable and its \(k \)th derivative \(f^{ \of{ k } } \colon \DL^{ k } \of{ f } \to \R \) is continuous. The set of \(k \)-times continuously differentiable functions on \(X \) is denoted \(\CDiff^{ k } \of{ X } \text{.}\)
    🔗
    🔗

    Example 5.1.10. Regularity.

    The following are examples of functions of different regularity:
    • Since polynomial functions are continuous and differentiable, and their derivatives are polynomials (which are also continuous and differentiable), every polynomial function is \(k \)-times continuously differentiable for all \(k \in \N \text{.}\)
      🔗
      🔗
    • Fix a natural number \(k \in \N \text{,}\) and consider the power function \(p \colon \R \to \R \) defined by the formula \(p \of{ x } = x^{ k + \frac{ 1 }{ 3 } } \text{.}\) Once we have explored the calculus of power series in Section 7.3 Power Series, we will see that \(p \) is \(k \)-times continuously differentiable but not \(\of{ k + 1 } \)-times differentiable; that is \(p \in \CDiff^{ k } \of{ \R } \setminus \CDiff^{ k + 1 } \of{ \R } \text{.}\)
      🔗
      🔗
    • Let \(f \colon \R \to \R \) be the real-valued function defined piecewise by the formula
      \begin{equation*} f \of{ x } = \begin{cases} x^{ 2 } \sin \of{ \frac{ 1 }{ x } } \amp x \neq 0 \\ 0 \amp x = 0 \text{.}\end{cases} \end{equation*}
      Then \(f \) is differentiable but not continuously differentiable.
      🔗
      🔗
    🔗
    🔗

    Lemma 5.1.11. Monotonicity of regularity classes.

    For any subset \(X \subseteq \R \text{,}\)
    \begin{equation*} \CDiff^{ 0 } \of{ X } \supseteq \CDiff^{ 1 } \of{ X } \supseteq \CDiff^{ 2 } \of{ X } \supseteq \CDiff^{ 3 } \of{ X } \supseteq \dotsb\text{.} \end{equation*}
    Moreover, the intersection \(\bigcap_{ k = 0 }^{ \infty }{ \CDiff^{ k } \of{ X } } \) is non-empty.
    🔗
    🔗

    Proof.
    Let \(k \in \N \) be a natural number, and suppose that \(f \in \CDiff^{ k + 1 } \of{ X } \text{;}\) that is, \(f \colon X \to \R \) is a \(\of{ k + 1 } \)-times continuously differentiable real-valued function on \(X \text{.}\) Since \(f \) is \(\of{ k + 1 } \)-times differentiable, it is \(k \)-times differentiable, and its \(k \)th derivative \(f^{ \of{ k } } \colon \DL^{ k } \of{ f } \to \R \) is itself differentiable. Lemma 5.1.3 Differentiability implies continuity implies that \(f^{ \of{ k } } \) is continuous at every point \(x \in \DL^{ k } \of{ f } \cap \of{ \DL^{ k } \of{ f } }' \text{.}\)
    🔗
    On the other hand, if \(x \in \DL^{ k } \of{ f } \setminus \of{ \DL^{ k } \of{ f } }' \text{,}\) then \(x \) is an isolated point of \(\DL^{ k } \of{ f } \text{,}\) and therefore \(f^{ \of{ k } } \) is automatically continuous at \(x \text{.}\) Thus \(f^{ \of{ k } } \) is continuous, and so \(f \in \CDiff^{ k } \of{ X } \) is \(k \)-times continuously differentiable.
    🔗
    We have already seen that constant functions are continuously differentiable, and their derivatives are also constant functions. Thus any constant function is \(k \)-times continuously differentiable for all \(k \in \N \text{,}\) and so
    \begin{equation*} \bigcap_{ k = 0 }^{ \infty }{ \CDiff^{ k } \of{ X } } \neq \emptyset\text{.} \end{equation*}
    🔗
    🔗

    Definition 5.1.12. Smoothness.

    A real-valued function \(f \colon X \to \R \) on a subset \(X \subseteq \R \) is called smooth if it is \(k \)-times continuously differentiable for all \(k \in \N \text{.}\) The set of smooth functions on \(X \) is denoted
    \begin{equation*} \CDiff^{ \infty } \of{ X } = \bigcup_{ k = 0 }^{ \infty }{ \CDiff^{ k } \of{ X } }\text{.} \end{equation*}
    🔗
    🔗
    There are several interesting topologies on the space \(\CDiff^{ k } \of{ X } \) of \(k \)-times differentiable functions on a subset \(X \subseteq \R \) In general, the uniform convergence of a sequence of continuously differentiable functions does not imply the uniform convergence of its derivatives. However, if the derivative converge uniformly, then the uniform limit of the functions is differentiable, and its derivative is the uniform limit of the derivatives.
    🔗

    1. The quotient rule.

    🔗
    🔗

    (b)

    Let \(g \colon X \to \R \setminus \set{ 0 } \) be a non-zero real-valued function defined on a subset \(X \subseteq \R \text{.}\) Prove that if \(g \) is differentiable at a point \(c \in X \cap X' \text{,}\) then \(\frac{ 1 }{ g } \) is differentiable at \(c \text{,}\) with derivative
    \begin{equation*} \of{ \frac{ 1 }{ g } }' \of{ c } = -\frac{ g' \of{ c } }{ g \of{ c }^{ 2 } }\text{.} \end{equation*}
    🔗
    🔗

    (c)

    Let \(f , g \colon X \to \R \) be real-valued functions defined on a subset \(X \subseteq \R \text{.}\) Prove that if \(g \of{ x } \neq 0 \) for all points \(x \in X \) and \(f \) and \(g \) are differentiable at a point \(c \in X \cap X' \text{,}\) then \(\frac{ f }{ g } \) is differentiable at \(c \text{,}\) with derivative
    \begin{equation*} \of{ \frac{ f }{ g } }' \of{ c } = \frac{ f' \of{ c } g \of{ c } - f \of{ c } g' \of{ c } }{ g \of{ c }^{ 2 } }\text{.} \end{equation*}
